# 총괄 답변 — 게임 품질과 촬영 기준

사용자 직접 회의 요청을 확인했다. 아래는 총괄 결정이며, 홍보팀 수신·합의나 제품 시각 PASS를 뜻하지 않는다.

## 현재 판단

MD의 A급 이상 기준을 충족하지 못했다. 특히 다크드루이드의 원본 재현과 모션은 사용자가 거절했으며, 기술 검사 통과로 이를 완료 처리하지 않는다. 거절된 입체 모델은 본편 연결에서 제외하고 원본 스프라이트 표시 경로를 복구했다. 열린 게임에 복구 코드가 적용됐다는 실행 확인은 아직 없다.

총괄의 마지막 완료 정본은 migration checkout `/Users/fordeargamers/Projects/exoduser-migration-20261001`, commit `5f51d5d17ecea289e73dfb37bd20bc54c3be8e66`이다. 그 이후 변경 여부를 이번 회의에서 다시 조사하지 않았다. working game에는 소유자가 확인되지 않은 185B 변경이 있어, HEAD와 working 화면을 같은 버전으로 취급하지 않는다. 홍보팀 관측 game SHA는 해당 관측 시점의 값이다.

홍보팀의 source-version-verdict에 따라 옛 3333 영상과 staged 영상은 최신본 홍보 후보에서 제외한다. 옛 영상의 피격·가독성 문제를 현재 게임의 확정 결함으로 옮기지 않는다. Steam 실행 파일과 개발본의 동등성도 미확인이다.

이 단위의 현재 상태는 미완료다. 홍보용 기검참 작업을 추가로 병렬 착수해 사용자가 지적한 드루이드 작업을 밀어내지 않는다. 현재 기검참의 실제 문제 여부는 촬영 기준선이 확보된 뒤 확인한다.

## 안전한 재촬영 진입 조건

기존 3387만 후보로 사용한다. 실제 entry와 SAVE_DIR, API 전달·저장 격리가 미확인이므로 현재는 촬영 준비 완료가 아니다. 새 서버·슬롯을 추정해 만들거나 기존 사용자 탭을 reload하지 않는다.

재촬영 전에 총괄이 로드된 실행 경로, URL/query, game 및 소비 모듈/에셋의 고정 snapshot, 설정, 저장 대상의 안전성을 확보해야 한다. `ch1Three=1`·`ch1Rig=1` 값이나 파일 해시만으로 실제 활성화를 인정하지 않고 현재 지형·캐릭터·스킬이 화면에 보이는지도 확인한다. 기존 권한 거절 목적은 다른 경로로 우회하지 않는다.

조건 충족 뒤 홍보팀이 열린 전투 공간에서 실제 속도의 접근 → 준비 → 공격 → 적 반응 → 처치/진행을 한 연속 장면으로 촬영한다. 무적·밸런스 변경, 속도 조작, 불리한 구간을 숨기는 편집으로 제품 품질을 대신하지 않는다. 실음향도 연속 재생으로 확인한다. 로고·문구·음악 편집은 읽히는 현행 원본 확보 뒤 홍보팀이 맡는다.

현재 판정: 게임 품질 미완료 / 거절 모델 제외 / 재촬영 보류 / 공개 승인 없음.
