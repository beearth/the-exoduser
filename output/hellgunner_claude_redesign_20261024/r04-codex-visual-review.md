# R04 실제 비교 검수 — 넓은 바디 크롬

실제 수신한 JPEG를 view_image original로 열어 R02/R03과 비교했다. 원본 파일은 1536×2688 JPEG이며 R03의 1152×2048 PNG와 포맷/캔버스가 다르다. UI 선택은 9:16이었고 실제 규격은 수신 원본을 따른다. 파일을 PNG로 변환하거나 업스케일해 검수한 것이 아니다.

| 항목 | 실제 관측/판정 |
|---|---|
| 사용자 선호 총 | 화면 오른쪽에 세워진 긴 총열·큰 원통·측면 고리·갈라진 개머리판, 검정/적색 라인/실버 부품과 인물 대비 큰 비례가 유지됨. 총을 쥔 자연 왼손(화면 오른쪽)의 위치/쥐는 모양도 유지. 편집/리사이즈/JPEG 출력이므로 픽셀 동일을 주장하지 않음 |
| 얼굴/은발/의수 | 성인 얼굴/눈매/입가, 은백색 포니테일·언더컷, 화면 왼쪽의 오른 로봇팔/기계손과 기본자세 유지. 얼굴/총을 가리는 새 장비 없음 |
| 크롬 면 | R03의 가는 선이 목/쇄골·어깨, 옆구리/복부 가장자리, 골반/허벅지, 정강이를 따라 넓은 반사 금속 면으로 커짐. 피부 경계를 따라 흐르는 매끈한 크롬과 따뜻한 피부가 구분됨. 전체 몸을 덮는 분절 갑주로 되돌아가지 않음 |
| 노출/복장 | R03의 불투명 검은 홀터 크롭톱·적색 안감 비대칭 랩스커트 유지. 어깨, 복부, 옆구리, 트임 쪽 허벅지/다리 노출이 남아 있고 가슴/골반 중심은 의복으로 덮임 |
| 신발 | 발가락이 드러나는 스트랩 샌들이 폐쇄형 검정 앵클부츠/실버 장식으로 바뀜. 가는 높은 굽은 남아 있어 플랫 전투 부츠라고 기록하지 않음 |
| 품질/프레임 | 피부/금속/검은 천의 대비와 얼굴/총 가독성이 유지됨. 전신과 총 전체가 프레임에 들어오며 배경 불티/반짝이 점 장식은 관측되지 않음. 금속 표면의 반사 하이라이트는 크롬 재질 표현 |

**VISUAL VERDICT: RETOUCH** — 사용자 선호 총/은발 보존, 노출 유지와 옆구리/골반의 넓은 크롬 면은 반영됐다. 목/어깨에는 가는 선이 남아 있고, 다리의 긴 크롬 면은 일부 경계가 피부 위에 얹힌 리본처럼 읽혀 후속 미감 보정 여지가 있다. 사용자가 전체 미감/최종 정본을 채택한 것은 아니며 게임 아트 교체·3D 메시/리깅/기계 구조/사격/사운드/배포 검증이 아니다. 크롬의 실제 폭3~5cm나 피부 매립 깊이는 2D 원화로 측정/구현한 값이 아니다. Claude 보고의 cm 추정도 실측값으로 채택하지 않는다.
