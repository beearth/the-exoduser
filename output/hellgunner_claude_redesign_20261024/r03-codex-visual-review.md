# R03 실제 비교 검수 — 바디 크롬 1차

R02와 실제 R03 PNG(1152×2048)를 원본 크기로 열어 비교했다.

| 항목 | 실제 관측 |
|---|---|
| 사용자 선호 총 | 화면 오른쪽에 수직으로 놓인 총의 상단 총열/큰 원통/측면 고리·그립/갈라진 하단 개머리판·적색 띠·실버 부품, 인물과의 길이/두께 비례가 유지됨. 총을 쥔 인물의 자연 **왼손**(화면 오른쪽) 위치/손가락도 유지. 픽셀 동일/기계적 작동 검증은 아님 |
| 얼굴/은발 | 성인 얼굴의 눈매/입가/시선과 은백색 높은 포니테일/언더컷이 유지됨 |
| 의수 | 화면 왼쪽의 인물 오른 로봇팔/기계손 형태 유지. 가려졌던 견갑 제거 후 맨살 어깨→위팔 중간 원형 관절의 접합부는 새로 그려짐 |
| 실제 의상/노출 | 분절 갑주와 전신 슈트가 사라지고 불투명 검은 홀터 크롭톱·적색 안감의 비대칭 랩스커트로 변경. 어깨/옆구리/복부/트임 쪽 허벅지와 다리가 드러남. 가슴/골반 중심은 의복으로 덮임 |
| 크롬 | 목/쇄골/어깨/복부/골반/다리에 피부와 연결된 은색 인레이가 생겼으나 가늘고 갈라지는 선 위주로 보여 바디 크롬의 면/입체감이 약함 |
| 신발 변형 | 원래 미래형 부츠가 발가락이 드러나는 스트랩 샌들 힐로 변경됨. 원래 부츠를 유지한 결과로 기록하지 않음 |
| 미감/프레임 | 피부·크롬·검은 천의 대비와 얼굴/총 가독성은 실제 생김. 배경 불티/도트 장식은 관측되지 않음. 전신·총 전체 프레임 유지 |

**VISUAL VERDICT: RETOUCH.** 노출과 사용자 선호 총 보존은 반영됐고, 크롬의 폭/면적과 게임용 신발은 후속 보정한다. R04는 R03을 편집 대상으로 크롬을 피부에 매립된 넓고 매끈한 금속 면으로 키우고, 피부 노출과 검은 톱/랩은 유지하며 폐쇄형 미래 부츠로 바꾼다. 총/얼굴/은발/의수를 다시 설계하지 않는다.

Claude 보고의 자연손 좌우 표현 중 일부는 부정확하다. 이미지에서 총을 쥔 손은 화면 오른쪽/인물의 왼손이며 이 기록을 따른다. 총의 실제 발사 구조·3D/게임 구현·사용자 최종 채택은 이번 원화 비교로 확인하지 않았다.
