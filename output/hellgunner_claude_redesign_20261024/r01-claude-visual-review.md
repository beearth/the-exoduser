# 헬거너 r01 검수 (C02와 비교, 읽기 전용)

두 이미지를 직접 열어 확인했습니다. 좌표는 원본 픽셀 기준 근사값입니다.

**1. 코어 유지**
| 코어 | 관측 | 판정 |
|---|---|---|
| 성인 여성 | 성숙한 이목구비와 화장, 성인 체형 | 유지 |
| 오른 로봇팔 | 오른쪽 소매가 없고, 어깨부터 은색 의수 | 유지 |
| 리볼버 라이플 | 대형 드럼과 굵은 총열은 보임. 개머리판은 판독이 약함 | 부분 |
| 미래 시대 | 의수 말고는 문장(紋章), 십자 휘장, 체인 같은 고딕/빅토리안 요소가 주도 | 약함 |

**2. C02와의 차이**
| 항목 | C02 | r01 |
|---|---|---|
| 얼굴 | 앳된 인상, 청색 아이피스 | 성숙한 인상, 한쪽 입꼬리 미소, 오른눈 적색 모노클 |
| 헤어 | 백금색 단발 | 흑발 비대칭, 한쪽은 넘겨서 땋음 |
| 의상 | 크롭 재킷, 바디슈트, 숏츠, 맨다리 | 롱코트에 비대칭 자락 |
| 실루엣 | 좁은 세로형, 다리가 주 실루엣 | 조인 허리에서 자락이 퍼지는 삼각형 |
| 자세 | 정지 스탠스, 총은 등에 멤 | 보행 중, 총을 아래로 들고 있음 |

색과 신발만 바꾼 수준이 아니라 별개의 안입니다.

**3. 매력 요소 (제안일 뿐, 취향 판단은 사용자 몫)**
| 요소 | 효과 |
|---|---|
| 높은 깃 | 얼굴을 액자처럼 감쌈 |
| 적색 모노클과 적색 안감 | 색이 서로 호응함 |
| 검정 가죽과 은색 의수의 비대칭 | 시선에 긴장감을 줌 |
| 한계 | 흔한 '고딕 헌터' 원형이고 장식이 초점을 분산시킴. 매력이 얼굴과 코트에서만 나오고 총과의 관계에서는 나오지 않아, 사수로서의 카리스마는 약함 |

**4. 결함**
| 항목 | 관측 | 심각도 |
|---|---|---|
| 총 구조 | 드럼(≈205-385, 1150-1380)이 총열 옆에 따로 붙은 통처럼 보임. 평행 레일까지 겹쳐 총구가 하나로 읽히지 않음 | 높음 |
| 개머리판 | 상단(≈285-372, 765-877)이 박스형 블록이라 견착용으로 안 읽힘 | 중 |
| 그립 | 의수 손(≈378, 960)이 장식부를 쥐고 있어 방아쇠 위치를 알 수 없음 | 중 |
| 무게감 | 상체가 곧게 서 있어 프롬프트의 '무게로 기울기'가 반영 안 됨 | 중 |
| 장식 과다 | 라펠, 벨트, 무릎, 부츠, 밑단, 실린더에 문장이 반복됨 | 중 |
| 노출 | 가슴 컷아웃. C02보다 노출은 줄었고, 유지 여부는 선택 사항 | 낮음 |
| 점도트 | 배경의 적색 불씨 점이 몇 개 있음. 패턴은 아님 | 낮음 |
| 얼굴 뭉개짐 / 마네킹 자세 / 장난감 재질 | 보이지 않음 | 없음 |
| 프레임 | 전신이 다 들어옴. 총구가 왼쪽 끝(≈x30)에 바짝 붙음 | 낮음 |
| 가림 | 총의 반대면, 코트에 가려진 허리 뒤쪽은 판단 보류 | 보류 |

**VISUAL VERDICT: RETOUCH** (이 제작안 내부 검수 한정)

**국소교정 1개:** 총만 다시 그립니다. 드럼을 하나뿐인 굵은 총열과 같은 축에 두고, 의수 손에서 돌출 그립과 방아쇠울이 보이게 합니다. 개머리판은 의수 팔뚝 아래로 뻗은 골격형으로 바꿉니다. 각인 장식은 빼고 무광 건메탈에 붉은 약실 발광을 넣습니다. 이렇게 하면 총의 판독이 살아나고 미래 시대 느낌도 같이 보강됩니다. 몸에 남은 고딕 휘장은 이 교정 범위 밖이라 그대로 남습니다.
