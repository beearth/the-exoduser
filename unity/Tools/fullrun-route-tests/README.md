# 자연 진행 QA 경로 회귀 검사

`run.ps1 -Output I:/EXODUSER-Storage/<검사폴더>`는 실제 `NativeGame.FullRunQa.cs`의
목표 선택 분기를 추출해 현재 Core와 함께 실행한다. Unity Vector2만 순수 기하
구현으로 치환한다. 필드 구멍·게이트, 가까운 전투, 먼 아레나 보스, 보스 부활
대기, 열린 아레나 출구를 검사한다. 아레나에서 필드 좌표를 선택하던 수정 전에는
5개 중 2개가 실패했다. Player·입력·충돌·GPU·자연 완주를 검증하는 도구는 아니다.

`run.ps1`와 정책 검사기의 활성 csproj·obj·임시 폴더와 .NET 홈은 NTFS의
프로젝트 `Library`를 사용한다. 지정한 I: 출력에는 완료된 로그·소스·결과만 내보낸다.

`modal.ps1 -Output <I: 검사폴더>`는 실제 `NativeGame.Update`의 입력 경계를
추출한다. 난이도 모달의 배경 hotkey 차단, 정상 입력, 비활성 창 차단 3가지를
검사한다. 실제 Player의 IMGUI 키 이벤트 검수는 별도다.

`run.ps1`는 방어 입력 선택의 실제 두 대입도 추출한다. 물리탄/패링 불가탄은
회피, 마법탄은 충분한 MP가 있을 때 Q를 선택하는지 4개 검사를 추가했다.
Q를 물리탄에도 쓰던 수정 전에는 9개 중 1개가 실패했다.

현재 경로·정책 회귀는 총69건이다. 실제 Player는 공용
`I:\EXODUSER-Storage\unity-jobs\bin\exo-unity.ps1`로만 무창·무음·세이브 격리 실행한다.
코드 b8214e5095의 정식14/M1 23단계/자연12는 드루이드 최종 처치와 로비 복귀까지
확인했다. 자연12는 정상 재도전7회 뒤 `parryOnly` 입력 옵션을1회 전환했으며,
그 설정을 시작부터 쓴 새판·무사망 완주 증거로 확대하지 않는다.
