## 1. 표현 가드레일

### 1-1. 확장성 표현 규칙 (BLOCK B 핵심)

메타버스, 평행 현실, 다중 시대 개념은 서사 배경 전용이다.
디지털, 글리치, 홀로그램, 네온, 깨끗한 SF 표면을 직접 노출하지 않는다.

확장성은 잔류의 법칙을 통과한 형태로만 보여준다.

| 금지 | 대체 |
|---|---|
| 깨끗한 로봇 | 기계였던 것. 부식된 금속에 살이 융합, 케이블이 힘줄처럼 늘어짐, 관절에 이끼와 녹 |
| 현대 총기 든 군인 | 총이었던 것. 총열이 팔뼈와 접합, 탄창이 갈비뼈에 박힘 |
| SF 파워아머 | 갑주였던 것. 판금이 피부로 자라 들어감, 내부가 비어 있지 않음 |
| 네온 사이버 광원 | 잔불, 인광, 부패 발광만 사용 |

원칙: 원형의 흔적은 2개에서 3개만 남기고 나머지는 Berserk + FromSoftware 문법으로 붕괴시킨다.

### 1-2. 스포일러 티어

- BLOCK A 컷 7 (환생 불가)는 인게임 S1 티어라 사용 가능.
- 마케팅 버전에서 "역사상 단 한 번의 예외가 있었다" 류 표현 절대 금지. 최초의 탈주자를 역산당한다.
- 전생, 두 번째 탈출, 최초의 탈주자는 두 버전 모두 노출 금지.
- 네메시아, 지옥왕, 아이들, 배신자는 프롤로그에 등장하지 않는다. 프롤로그는 세계 설명 전용.

### 1-3. 스케일 규칙

캐릭터 180cm 현실 비율 기준. 문 210cm, 횃불 40cm, 상자 60cm, 바위 50에서 150cm, 나무 800에서 1200cm. 미적 과장 금지. 거인 계열만 예외 명시.

### 컷별 화면 지시

**p12 / B01**
거대한 잿더미 평원. 서로 다른 시대의 잔해가 지층처럼 쌓임. 청동 투구, 판금 흉갑, 부식된 금속 판재가 같은 층에 뒤섞임. 안개.
비고: 시대 혼재를 지형으로 먼저 제시. 캐릭터 없음.

**p13 / B02 - 이 콘티의 핵심 컷**
무기 더미의 근접. 한 프레임 안에: 고대 청동 검, 중세 대검, 화승총, 부식된 기계 팔 하나가 같은 잿더미에 반쯤 묻혀 있음. 전부 같은 녹과 재를 뒤집어씀. 어느 것도 강조되지 않음.
카메라: 매우 느린 측면 트래킹.
나레이션 없음. 침묵.
비고: 확장성을 한 컷으로 전달한다. 말로 설명하지 않는 것이 훨씬 강하다. 기계 팔은 SF 부품이 아니라 다른 유물들과 동일한 부식과 질감을 공유해야 한다. 여기서 톤이 어긋나면 컷 전체가 실패한다.

**p14 / B03**
두 실루엣이 같은 안개 속에 나란히 서 있음. 하나는 대검을 쥔 판금 갑주. 하나는 금속 골격에 살이 융합된 형체. 둘 다 역광, 얼굴 보이지 않음. 크기와 자세는 대등.
비고: 대비가 아니라 동등함을 보여준다. 어느 쪽도 이질적이지 않다.

**p15 / B04**
하늘에서 떨어지는 무수한 형체. 대부분 실루엣. 낙하 궤적이 전부 하나의 붉은 균열로 수렴. 시대와 형태가 제각각이지만 방향은 동일.
비고: 수렴의 법칙 시각화. 개별 형체는 알아볼 수 없을 만큼 작게.

**p16 / B05**
기계였던 것의 근접. 부식된 금속 흉곽에 살이 자라 들어감. 케이블이 힘줄처럼 늘어지고 끝이 신경과 접합. 관절에 이끼와 녹. 한쪽 눈 자리에 렌즈 잔해, 다른 쪽은 인간의 눈.
비고: BLOCK B 전체에서 가장 실패 위험이 높은 컷. 깨끗한 로봇으로 나오면 폐기하고 재생성. 부패와 융합이 금속보다 우세해야 한다.

**p17 / B06**
아득한 상공에서 낙하하는 형체들의 원경. 균열이 계속 새 영혼을 삼킴. 끝이 보이지 않음.
비고: 로드맵 훅. 콘텐츠가 계속 추가된다는 메시지를 서사로 처리.
