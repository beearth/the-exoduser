# SKILL mortar 확정 경로 최소 후보 최종 결속

기존 mortar-confirm-source의 MP 재검사 결함을 이어간다. 기존 후보와 17검사를 보존한다. 현재 본편/easy의 실제 aim-start→확정 분기→fireMaliceMortar를 함께 추출해 MP가 조준중 감소했을 때 기존 결함과 후보 가드를 검증한다. 단독 함수 반복만 하지 않는다. MBjust/release 입력, RMB/Escape 취소 우선, 저MP 조준유지 뒤 MP회복 재확정, 성공 후 중복입력 차단, iceMortar 상태와 원 호출/SFX/RNG 횟수를 비교한다. actual source 제어흐름을 fixture와 명확히 분리한다.

다른 SKILL 후보와 겹치는 guard/함수 소유가 있으면 확인하고 최소 patch 적용 가능성을 기록한다. 생산 직접 적용0, 새 비용/쿨/밸런스/천둥말뚝 duration 변경0. 결함이 추가로 확인될 때에만 좁은 미적용 patch를 만든다. 소유 mortar-confirm-dispatch-*에 실제 반례/회귀 코드·증거·receipt/result만 작성한다. 기존 자료·초안·생산·공유docs·Git·queue·게임·서버·새세션·에이전트 변경0. 담당MD/AGENTS를 읽고 한국어로 한 건 인계한다.
