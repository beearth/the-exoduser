# UIUX-FILTER-FOCUS

기존 UIUX 세션 다음 한 건. AGENTS와 UI-04/인벤토리 SSOT, production-integration-result 및 이전 카드 제거 회귀를 읽는다. 같은 작업 진행/대기와 기존 초안을 보존한다.

UI-04 남은 필터/유골함 경계를 실제 소스에서 검증한다. 단순 카드삭제 재실행이 아니라 필터 변경으로 현재 선택 카드가 화면에서 빠질 때, 필터 결과 0개일 때, 유골함 탭 전환/복귀 시 새로 연결된 키보드 초점 계약이 유지되는지 실제 필터 이벤트와 렌더 경로를 포함하여 재현한다. 양쪽 HTML에서 추출하고 가짜 필터 모델로 원 로직을 대체하지 않는다. 확인된 결함이 있으면 기존 RED를 보존하고 최소 후보 패치 및 수정 회귀를 만든다. 결함이 없으면 조사한 분기를 명시하며 임의 변경하지 않는다.
