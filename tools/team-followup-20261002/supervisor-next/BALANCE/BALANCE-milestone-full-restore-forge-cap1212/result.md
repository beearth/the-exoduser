## 결과와 소유

- 작업: BALANCE-milestone-full-restore-forge-1204.
- 저장 epoch: capacity-after-6a39b828-1212. 이번 반복은 result.md와 checks.mjs 두 파일만 생성한다.
- checks.mjs는 성공한 stdin 실행 스크립트 원문 보존이다. 저장 뒤 실행·재검사 0회. 앞선 실패 스크립트는 별도 파일로 생성하지 않으며 아래 실패 원출력을 그대로 보존한다.
- 운영 game.html/game-easy-test.html, 공유 docs, Git, 사용자 save, 실제 게임·브라우저 변경 0.
- 전체 dbRestore 및 실제 renderForge/openPanel/_doAiEnhance/aiEnhance 소스 연결을 VM에서 실행했다. 외부 JSON의 enh:1e309가 Infinity로 복원된 뒤 UI 강화 호출에서 원문 TypeError를 재현했다.
- 두 소스판 × 비정상/정상 × 원문/후보 = 성공 실행 8건. 이전 standalone 검사는 재실행하지 않았다.
- 후보는 복원 스키마와 잘못된 enh 값 자체를 바꾸지 않는다. 표시 및 선택 버튼에서 유한값을 확인하고, 실제 강화 호출은 목표/비용 계산 전에 '강화 입력 오류'로 반환한다.

## 검증 한계와 실패 기록

처음 두 시도는 추출기 템플릿 보간 오류로 source 실행 전 실패했다. 세 번째는 VM realm 객체의 prototype 차이를 deepStrictEqual로 비교하여 실패했다. trace를 호출 시점 JSON snapshot으로 비교하는 하니스 수정 뒤 Node exit0으로 8건 assertion을 통과했다. 성공 stdout은 도구 출력 한도로 중간이 잘렸다. 이후 전체 JSON parse도 Warning 접두어 때문에 실패했다. 잘린 원출력을 복구한 완전한 출력으로 주장하지 않는다. 원본 스크립트·보존된 도구 receipt·완전한 source SHA/patch metadata를 함께 남긴다.

DOM, atlas, storage, skill repair, 효과, 음향, save는 명시적 대역이다. 실제 외부 save/API나 native UI·복원 오류 UX·게임 진행/시연 PASS는 미입증이다.
