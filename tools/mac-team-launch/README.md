# Mac 11팀 세션 등록 준비

현재 Claude 작업공간 신뢰 확인이 남아 있으며 이 파일들을 만든 것은 팀 실행이 아니다. 사용자가 정확한 프로젝트 폴더를 신뢰하도록 직접 확인한 뒤에만 총괄이 실행한다. 신뢰/권한 설정은 이 도구가 변경하지 않는다.

점검: `python3 tools/mac-team-launch/launch_teams.py` (읽기 전용)
등록: `python3 tools/mac-team-launch/launch_teams.py --launch`

고정 UUID/이름으로 기존 inventory를 대조한다. 여러 일치·결과 불명·이전 실패는 자동 재시도하지 않는다. 성공 후 각 세션 inventory를 확인하고 launch-receipt.json에 남긴다. 등록 메시지는 확인 후 대기이며 게임/빌드/파일편집을 실행하지 않는다. 실제 담당 작업 인계와 검수는 별도로 수행한다. 동시 무거운 작업1개, 지원 하위 담당은 총괄 포함4개. PC 기존 팀은 재가동하지 않는다.

다시 실행할 때 UUID를 재생성하지 않는다. 실패 영수증을 삭제해서 중복 실행하지 말고 실제 세션을 확인한 뒤 담당이 판단한다. 사용자 홈/프로젝트 경로는 현재 Mac 인수 환경 기준이다.
