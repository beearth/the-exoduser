# HELL 시장 포지셔닝 — 정통 루팅 ARPG 계보 내 위치

최종수정: 2026.06.02

---

## 시장 정의

정통 루팅 ARPG 계보: **Diablo 2 → Path of Exile → Grim Dawn → Last Epoch → PoE2**

### 시장 구조: 소수 거인 과점

| 타이틀 | 평시 동접 | 리그/시즌 동접 | 비고 |
|--------|----------|--------------|------|
| PoE2 | ~30,000 | ~350,000 | 리그 시작 시 10배+ 급증 |
| Last Epoch | ~1,000 | ~150,000 | 시즌 없으면 동접 사망 |

**핵심 화폐**: 엔드게임 무한 그라인드 + 리그/시즌 반복성.  
리그 없으면 출시 1개월 후 동접 사망이 이 시장의 디폴트.

## 포지셔닝 결론

### 정면 경쟁 금지

정통 디아2 혈통 ARPG로 PoE2와 정면 경쟁 **불가능**.  
이유: 엔드게임/리그/경제 시스템을 1인 개발로 충족 불가.

### 타겟 포지션: Last Epoch식 "사이 포지션" 변종

```
PoE2 (과복잡 하드코어) ←── HELL ──→ 스타일액션 (스토리 부재)
```

| 축 | PoE2 | **HELL** | 스타일액션 (Hades 등) |
|----|------|----------|---------------------|
| 빌드 깊이 | 극상 | 중상 | 얕음 |
| 스토리 | 배경 | **중심** | 중심 |
| 루팅 | 극상 | 중상 | 없음~얕음 |
| 진입장벽 | 높음 | **중간** | 낮음 |
| 엔드게임 | 무한 | 제한적 | 없음 |

### 정체성 한줄 정의

> **루팅 깊이를 가진 스토리 중심 다크판타지 ARPG**

## 게임 디자인 함의

### HELL은 스토리 완결형

- 라이브서비스 리그 시스템 없이는 장기 동접 유지 불가가 **이 시장의 디폴트**
- 따라서 "동접 장기유지" 기대치를 낮추고 **"판매량 + 완성도 평판"** 지표로 성공 정의
- 엔드게임은 "무한 콘텐츠"가 아닌 **"빌드 실험 + 도전 무대"**로 설계

### EA 아키타입 추가 = 약식 시즌

- EA 기간 중 분기별 아키타입(클래스/빌드) 추가로 **라이브옵스 리듬** 확보
- 리그 시스템 없이도 EA 동접 유지하는 전략
- 콘텐츠 추가 시점에 맞춰 할인/이벤트 병행
