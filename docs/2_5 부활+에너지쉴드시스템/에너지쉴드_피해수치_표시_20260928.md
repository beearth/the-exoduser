# 에너지쉴드 피해 수치 표시 (2026-09-28 구현)

적 에너지쉴드가 플레이어 공격을 흡수하면 실제 흡수량을 청색 피해 숫자로 표시한다. HP 피해가 0이어도 숫자를 생략하지 않는다. 쉴드가 깨져 피해가 HP까지 넘치면 쉴드 흡수량과 HP 피해량을 각각 표시한다. 지속 피해(DOT)는 기존 전투 텍스트 밀도 규칙에 따라 쉴드 숫자를 띄우지 않는다.

| 항목 | 코드 위치 | 현재 계약 |
|---|---|---|
| 흡수량 | `game.html` `hurtE` | `min(e.eShield, dmg)`; 모든 공격 배율 확정 후 계산 |
| 쉴드 잔량 | `game.html` `hurtE` | `max(0, 이전 e.eShield - dmg)` |
| HP 오버플로우 | `game.html` `hurtE` | `max(0, dmg - 흡수량)`; 기존 HP 피해 처리 경로 유지 |
| 쉴드 피해 숫자 | `game.html` `hurtE` | 흡수량이 0보다 크고 DOT가 아닐 때 표시, 위치 `e.y - 70`, 수명 45프레임, 크기 48 |
| 색상/숫자 시트 | `game.html` `_buildNumAtlas`, 전투 텍스트 렌더 | `#66ddff`가 숫자 아틀라스 3행(0부터 셀 때 인덱스 2)의 청색 스타일을 선택 |
| HP 피해 숫자 | `game.html` `hurtE`, 메인 루프 | HP 피해가 있을 때 기존 최고 피해 숫자 표시 규칙 적용 |

검수 기준: 쉴드만 맞으면 쉴드 잔량 감소와 청색 숫자를 함께 확인한다. 쉴드 파괴 타격에서는 청색 흡수량과 HP 피해 숫자를 모두 확인한다. 쉴드가 없는 적의 HP 피해 표시는 기존과 같아야 한다.
