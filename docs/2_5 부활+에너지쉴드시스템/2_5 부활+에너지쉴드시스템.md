### 보스 (e.ib) — 2단계 부활 시스템

#### 1차: 즉시 부활 (`hurtE` 내부, HP=0 순간 처리)
- **풀피(100%) 즉시 부활**, `e.alive=false` 없이 바로 `return` — 보스 절대 사망 안 함
- **확률 공식**: `max(0, 200% + 스테이지×5% - (deaths-1)×15% - 신성력)`
- **부활력 포인트** (`_revPts`): 초기값 `200 + round(si × 5.882)` (si0=200, si34=400). 부활당 기본 10 + 신성력·존·완벽처치 보너스 소모
- 성공 조건: `_revPts > 0` AND 확률 통과 (둘 다 필요)
- 부활마다: ATK ×1.5(H7:×2), SPD ×1.25(상한 1.6, H7 2.0), maxPoise ×1.5, 패턴쿨 -30f(하한 60f, H7 20f) / **현재 포이즈는 maxPoise의 25%로 세팅** (기존 100% 리셋 → 2026-05-13 수정). 상태 `recover` 90f + `reviveIframes=90`(1.5초 무적), eShield·eShieldMax=0
- **재소환 연출 시퀀스** (2026-05-08 개선):
  1. 부활 폭발 (구 위치) — `playVFXAng('boss_revive_boom', oldX, oldY, r×7/64, 5, ...)` 호출. 단 `registerVFX('boss_revive_boom',…)`가 파일 미존재로 주석 처리(2026-06-28)되어 시트 미등록 → 호출은 no-op, 실제 표시는 `_addBlastLight(r×3)`·파티클 링뿐
  2. 보스 투명화 — `e._spawnT=55`, 알파=`max(0,1−_spawnT/20)` → 처음 35f 완전 숨김, 마지막 20f 페이드인 (총 55f)
  3. 텔레포트 → 플레이어 뒤로 이동 (거리 80+deaths×20, 각도 facing+π±0.4)
  4. 부활 폭발 (새 위치) — 동일 호출 (`boss_revive_boom`, r×7/64, frameTime 5 — 위와 같이 미등록 no-op) + `_addTpBolt`
  5. 40f 후: `_bossReviveGrandVFX` 발동 (`e._bossReviveVFXPending=40` 카운트다운)
- **`_bossReviveGrandVFX(e, vfxR)`**: 백색 플래시 14f + 3중 충격파 파티클 링 + 블래스트 라이트 3층(r×14/9/5) + 히트스톱 16f + 슬로우모 90f + 진동 30 + 크로마 왜곡 18f
- **부활 시 크기 축소**: `e.r = max(10, ~~(origR × max(0.40, _revPts/_maxRevPts)))`. VFX는 축소 전 크기(`_vfxR1`) 기준. "▼ X%" 텍스트 표시
  - 예시(si0, _maxRevPts=200): 부활 1회(190pt)→95%, 7회(130pt)→65%, 13회(70pt)→40%
- 부활 충격파: 반경 100+deaths×30, 피해 atk×(0.5+deaths×0.15) 마법, 넉백 12
- deaths≥2: 전방위 분노 폭발탄 8+deaths×4발. 10%확률 동반부활(이전 처치 보스 1마리, HP 40%·ATK 50%)

#### 2차: 폴백 부활 (`_reviveTimer` 3초 카운트다운, 1차 실패 시)
- 1차 실패(포인트 고갈 or 확률 미달) → `e.alive=false` → 3초 대기 → 재판정
- **확률 공식**: `max(0, 150% + 스테이지×5% - deaths×25% - 신성력)`
- 성공 시 **HP 50%** 로 부활 (eShield 삭제됨, 2026-05-10), 부활력 −10, `recover` 60f + `reviveIframes=90`. void 포탈 + `_spawnT=55` + `_bossReviveVFXPending=40` 동일 적용 (크기 축소 포함)
- 발동 조건: `!e._bossRevJudged`일 때만 타이머 설정. 1차 즉시 부활이 성공하면 `_bossRevJudged=true`가 되어 이후 사망에서는 폴백이 걸리지 않음(폴백 성공 시에만 false로 리셋)
- 포인트 0이면 확률 무관 자동 실패 → 완전 사망

#### 공통
- 신성력(antiRevive) + 구속의 영역(15%~30%)으로 억제 가능
- **무기 3종 기본 신성력**: 아이템 생성 base 표(weapon/shield/bow)에 antiRevive 1~20% 랜덤 롤(`0.01+0.19×rand()³`)이 정의돼 있으나, 생성 함수가 이 값을 아이템 필드·affixes로 복사하지 않아 **현재 런타임 미적용**(신성력은 `_eqAffix('antiRevive')` = 장착 어픽스 합만 사용)
- `e._origR`: 최초 부활 시 저장되는 원본 r값 (이후 크기 축소 기준)

### 일반몹 (!e.ib)
- 1회만 부활(`e._revived`). 부활 대기 `_reviveTimer` 일반 90f / 엘리트 120f 후 **50% 구울 변환, 50% 본모습 부활**(본모습=HP 100%·포이즈 풀·추격 상태)
- 부활력: 기본 50% + 100Lv당 +10% (엘리트2+ 기본 60%)
  - Lv100: 60%, Lv500: 100%, Lv1000: 150%(확정, 단 1회 제한)
  - 최종 확률 = max(0, 부활력 − 신성력(antiRevive 어픽스 합) − 구속의 영역)
- 구울 3종 (`_ghoulType`, 원본 e.r 기준): 소형 etype100(r≤24), 중형 101(25~39), 대형 102(r≥40). 엘리트2+ 시체는 한 단계 위. 구울 HP·ATK = 원본 mhp·baseAtk ×2
- **벽 끼임 구출 실패**: 플레이어 위치로 강제 이동 (kb 초기화)

### 신성력 (억제 + 언데드 데미지 보너스)
- 어픽스 `antiRevive`(group arev): 목걸이·팔찌 T1~T5 4/8/12/16/20%, 반지 T1~T5 2/4/8/12/16%
- 무기 base 롤(1~20%)은 정의만 있고 미적용(위 공통 절 참조)
- 합산 상한 없음 (코드에 cap 없음)
- 구속의 영역 fireZone: 15%~30% (Lv1=15%, Lv10=30%)
- **언데드 데미지 보너스** (2026-04-11 신규): 신성력 1%당 언데드 적에게 데미지 +1% (`hurtE`에서 `dmg×(1+_eqAffix('antiRevive'))` 적용). 대상 etype: `_UNDEAD_ET`(4,10,12,14,23,40,47,82,83,85) + `e._isGhoul`. 보스 제외

### 악마화 부활 (플레이어) — 🔲 부분 구현

#### 핵심 컨셉
- 레벨이 오를수록 악마의 힘이 깨어남
- 사망 시 "악마화 vs 인간 유지" 선택지 (영구 분기, 1회 선택, 되돌릴 수 없음)

#### 부활 규칙 — 악마화 부활 패시브 (`pDemon`, 구 스킬 `demonRevive`는 PASSIVES.pDemon으로 이관)
- **AP 패시브(PASSIVE_DEF `pDemon` ☠ 악마성, 최대 Lv10)** — 부활 강화 (버튼 없음, 자동 발동)
- 미습득이어도 자연부활력+장비로 부활 가능 (스킬은 강화용)

#### 부활력 공식
`부활력% = min(100, max(0, 자연부활력 + 스킬Lv×2 + 장비보너스 - 인간성Lv×10))`

| 요소 | 부활력 | 비고 |
|---|---|---|
| 자연부활력 | `floor(P.lv×0.03)` | Lv100=3%, Lv500=15%, Lv1000=30% |
| 패시브 (`pDemon`) | Lv당 부활확률+2% (최대 Lv10=+20%), 쿨-30초/Lv | 부활 강화 패시브 (미습득이어도 자연부활 가능) |
| 장비 어픽스 | (revivePow + _iRevPow×0.01)×100 | 악마의 팔찌 등 |
| 부활의 영역 (`weakRev` 존) | 10%+(Lv−1)×1% | 스킬 영역 안에서 |
| **인간성 (`pHuman`)** | **Lv당 부활력 -10** | **부활력 감소 패시브 (트레이드오프)** |

#### 쿨다운

## 에너지 쉴드 (2026-04-17 레벨 성장 변경, bonusShield 슬롯 분리)
- **Lv1부터 기본 제공** (공식: `100 + INT×5 + bonusShield + shieldFlat어픽스`)
  - **NO Lv×1 직접 보너스** — INT 스탯만으로 증가
  - INT = STATS.int + eqInt + floor(Lv×0.5)로 자동 성장

  - **shieldFlat 어픽스**: 방어구 슬롯 전용 (armor/shield/gloves/pants/boots/cloak), T1~T5 120/200/400/600/840

### hurtP 쉴드 처리 구현 (2026-05-13 최종)

#### 흡수 공식
0. 선처리: 돌진(`P.s==='charge'`) 중 ×0.3, 한방캡 `min(a, ~~(mhp×0.33))`(캡 발동 시 iframes 60)
1. DR 적용: 물리→`a=max(1,~~(dmg×(1-pDR)))`, 마법(magic/parry)→`a=max(1,~~(dmg×(1-eDR)))`. pDR/eDR = def/(def+2500)(+physDR), DR_CAP 상한
2. barrier 어픽스: `a=max(0,a-_barV)` (고정 데미지 감소)
3. 조건부 DR 어픽스: healthyDef/injuredDR/dotDR/bossDR/closeDR/farDR (합산 최대 50%)
4. 최소 데미지: `a=max(1,~~(P.mhp×0.005))`
5. **쉴드가 먼저 흡수**: `P.shield -= a`, 오버플로우→HP (`a=overflow`)
6. 쉴드 없으면 `a` 그대로 HP로

- **플레이어 hurtP에는 DOT 예외가 없다**: `opts.dot` 피해도 같은 경로로 쉴드가 먼저 흡수한다(몬스터 hurtE의 DOT 제외 규칙과 다름). 쉴드 피격 시마다 `shieldRegenT=180`

- 핵심: 쉴드와 HP는 **완전히 동일한 모든 방어 계산**을 공유 → 쉴드 방어 횟수 = HP 방어 횟수
- 설계 변경 이유: 이전 구현은 barrier/조건부DR이 HP에만 적용되어 쉴드가 HP보다 훨씬 약했음

#### 버그 수정 (2026-05-12 → 2026-05-13)
- 2026-05-12: 쉴드 완전흡수 시 `_minDmg`가 HP를 깎던 버그 → `_shFullBlock` 플래그로 수정
- 2026-05-13: barrier/조건부DR이 쉴드 적용 이후에 계산되어 HP에만 유리하던 버그 → 쉴드 체크를 모든 DR 이후로 이동

### 쉴드 자동 리젠
- 피격 시 3초(180f) 쿨다운 (`shieldRegenT=180`), 쿨다운 소진 후 리젠 시작
- **레벨업 시 쉴드 회복 없음** (HP/ST/MP만 20% 회복)
- 쿨다운 감소 속도: `pShieldCdMul()` = `1 - min(0.3, pMRegen×0.03)` (마력회복 패시브 -3%/lv, 최대 -30%)
- 리젠량/f: `(0.3 + (STATS.int + floor(Lv×0.5))×0.003) × pMRegenMul()` — 장비 INT·intFlat은 리젠에 미포함(쉴드 최대치에는 포함)
- `pMRegenMul()` = `1 + pMRegen×0.03` (+3%/lv, MP/쉴드 리젠 배율)
