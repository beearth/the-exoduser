## 인계 원칙

공용 코드 충돌은 파일 전체가 아닌 함수·데이터·호출 지점과 영향 범위를 적어 담당 팀과 총괄에 전달한다. 테스트 PASS, 실제 패키지 화면, 저장 복원, 외부 전달은 각각 별도 단계로 기록한다. 단일 HEAD만으로 미커밋 변경을 포함한 산출물을 설명하지 않는다.
