## 코드 보호 전략 (출시 필수)

### 단계별 적용 계획

| 단계 | 방법 | 시점 | 보호 수준 | 비고 |
|------|------|------|----------|------|
| 1 | **Minify** | 데모 | ★☆☆☆ | Terser로 공백/주석 제거, 파일 크기 60%↓ |
| 2 | **Obfuscation** | EA 출시 | ★★☆☆ | javascript-obfuscator로 변수명 치환, 문자열 암호화, 제어흐름 변환 |
| 3 | **WASM 변환** | 정식 출시 | ★★★★ | 핵심 로직(데미지 공식, 아이템 생성, 세이브 검증)을 C/Rust → WASM 컴파일 |
| 4 | **서버 권위** | 온라인 모드 | ★★★★★ | 드롭 테이블, 강화 확률, 경제 밸런스를 서버에서 처리 |

### WASM 변환 대상 (정식 출시 목표)

| 모듈 | 현재 위치 | WASM 이관 시 효과 |
|------|----------|-----------------|
| 데미지 공식 | `hurtE()`, `_skMul()`, `elMul()` | 수치 해킹 차단 |
| 아이템/어픽스 생성 | `rollAffix()`, `rollItem()` | 드롭 조작 차단 |
| 세이브 직렬화+검증 | `dbSave()`, `dbLoad()` | 세이브 변조 차단 (HMAC 서명) |
| 경험치/레벨업 | `addExp()`, `_calcMaxExp()` | 레벨 해킹 차단 |
| 강화 확률 | 제련/결정/어픽스 리롤 | 확률 조작 차단 |
| 난수 생성기 | `Math.random()` 대체 | 시드 예측 차단 (xorshift128+ in WASM) |

### 구현 방법 (Rust → WASM)
```
[Rust 소스] → wasm-pack build → game_core.wasm + JS 바인딩
game.html에서 import → 핵심 함수 호출만 JS, 연산은 WASM 내부
```
- **언어**: Rust (wasm-bindgen) — 메모리 안전 + 최적 WASM 크기
- **빌드**: `wasm-pack build --target web --release`
- **크기 예상**: 핵심 로직만 ~50-100KB .wasm

## BOOTH_MODE — 부스/전시 어트랙트 모드 (2026-08-22 신설, game.html)

무인 전시 부스용 인게임 어트랙트/자동리셋/조작안내 시스템. **기본 OFF**(`var _BOOTH_MODE=false`), GXG 빌드 생성 시에만 sed로 true 치환. OFF일 때 코드 전량 `if(_BOOTH_MODE)` 가드 → 기존 동작 100% 동일(회귀 0, 오버레이 캔버스 미생성).

### 전역 (game.html, _PARRY_WIN 인근)
`_BOOTH_MODE`(빌드 스위치) · `_boothIdle`(유휴 프레임) · `_boothHUD`/`_boothCtx`(전용 오버레이 캔버스·ctx) · `_boothRunF`(런 프레임) · `_boothDeadF`(사망 카운트다운, -1=비활성) · `_boothReloading`(리로드 중복가드) · `_boothW`/`_boothH`(리사이즈 비교)

### 동작
| 트리거 | 프레임 | 동작 |
|---|---|---|
| 입력(key/mouse move/down) | — | `_boothIdle=0` (핸들러 3곳, 새 리스너 없음) |
| 유휴 60초 | 3600f | 어트랙트 오버레이 on (rgba .72 + "아무 키나 눌러 시작"/PRESS ANY KEY, `Math.sin(_gameFrame*.05)` 페이드) |
| 유휴 90초 | 5400f | `location.reload()` 풀 리로드 (완전 초기화) |
| 사망 | die() fallen | `_boothDeadF=180` (중복 설정 방지) → 3초 카운트다운 표시 → `location.reload()` |

- 유휴/리셋 로직: `update()` 내 `_gameFrame++` 직후(per-frame 보장). 렌더: `loop()` 말미 `_boothDraw()`.
- 리셋은 **인게임 재시작 함수 부재**로 `location.reload()` 채택(유저 확정 2026-08-22). GXG 빌드는 **부팅 시 1-1 자동시작 배선 필요**(별도).

### 조작 HUD (`_boothDraw`)
전용 오버레이 캔버스(z-index 99999, pointer-events:none, 부팅 1회 생성, 리사이즈 시 width/height 갱신). 하단 72px, 5칸 균등: 키캡 + KO/EN 2줄 병기.
`WASD 이동/Move · Q 무지개 패링/Rainbow Parry · E 빨강 패링/Red Parry · SHIFT 체인 드라이브/Chain Drive · 우클릭 마법/Magic`

### GXG 빌드 생성 (sed)
```
sed -i "s/var _BOOTH_MODE=false/var _BOOTH_MODE=true/" game.html
```
커밋에는 **항상 false**로 포함(STEP 7). 어트랙트/사망 문구는 _T 로컬라이즈(26개국어 전파 완료), HUD 라벨은 고정 이중언어.
