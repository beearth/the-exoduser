# AAA 게임 트레일러 제작 방식과 EXODUSER 기획안

> **2026-10-09 후속 결과:** [기존 Steam·최신 공개 원화로 만든30초 아트 티저](TRAILER_ART_REFRESH_20261009.md). 리서치의75초 게임플레이 대표편과 별도다. 본편 보스 촬영 대기·사용자 검토·미게시 상태를 유지한다.

조사일: 2026-10-08. 대상: **EXODUSER: HELL LORD / FOR DEAR GAMERS**.

공개된 AAA 제작 사례에서는 트레일러 방향을 브리프로 정하고, 스토리보드·참고 영상·애니매틱으로 장면과 시간을 구체화한다. 가져올 핵심은 **시청자에게 남길 메시지와 그것을 증명할 장면을 먼저 정하는 제작 방식**이다. 아래에는 공개 자료로 확인한 사실과 EXODUSER에 제안하는 양식을 구분했다. 회사별 비공개 내부 기획서 원본을 공통 표준으로 제시하는 문서는 아니다.

EXODUSER에는 **실제 전투를 중심으로 한 대표 트레일러**를 우선 기획하는 방향을 제안한다. 조사 이후 사용자가 홍보팀 협의와 실제 트레일러 제작을 지시했다. 후속 **30초 1차 편집본의 실제 타임라인·소재·검수·납품 상태**는 [제작 기록](HERO_TRAILER_PRODUCTION_20261008.md)을 따른다. 아래 75초는 추가 촬영이 필요한 확장 가설이며 현재 납품 길이가 아니다. 재사용 가능한 작성 양식은 [트레일러 기획서 템플릿](TRAILER_CREATIVE_BRIEF_TEMPLATE.md)에 있다.

## 공개된 기획서 양식

게임 트레일러 편집자 Derek Lieu는 실제로 받은 브리프를 종합한 가이드에서 **정해진 표준 형식은 없다**고 설명한다. 게임 소개, 핵심 메시지, 캠페인 목표, 톤, 참고 영상, 길이, 배포처, 납품 정보를 짧게 전달하는 방식이다. [공개 브리프 가이드](https://www.derek-lieu.com/blog/2024/9/2/how-to-make-a-creative-brief-for-a-game-trailer)

직접 참고할 공개 양식은 [Game Trailer Creative Brief Template](https://docs.google.com/document/d/158QrEz5r0W7MArgID6bzvIP8LieCSIx7-150P-Y5zvM/edit?usp=sharing)이다. 실무자가 공개한 범용 양식이며 특정 AAA 회사의 내부 문서는 아니다. EXODUSER용 양식은 이를 그대로 번역하지 않고, 아래 제작 사례와 프로젝트의 촬영 계약을 함께 반영해 구성했다.

## EXODUSER에 제안하는 기획서 구성

아래 문서명·표의 열·분량은 프로젝트용 제안이다. script, storyboard, animatic 등의 실제 사용은 앞의 제작 사례로 확인되지만, 이 묶음 전체가 AAA 공통 규격이라는 뜻은 아니다.

| 문서 또는 시안 | 답해야 할 질문 | 작성 항목 |
|---|---|---|
| 크리에이티브 브리프 | 누구에게 무엇을 전달하고 어떤 행동을 유도하는가 | 목적, 타깃, 단일 메시지, 핵심 매력, CTA, 범위 |
| 연출안 Treatment | 어떤 감정과 영상 언어로 전달하는가 | 콘셉트, 감정 변화, 시각·음악 방향, 레퍼런스의 채택 이유 |
| 구성표 Beat sheet | 어떤 순서로 이해시키고 고조시키는가 | 구간, 시청자의 질문, 전달 내용, 긴장·해소 |
| 화면과 소리 대본 AV script | 각 구간에 무엇이 보이고 들리는가 | 시간, 화면·액션, 자막·대사, 음악·SFX, 증명할 메시지 |
| 스토리보드 | 관객의 시선이 어디에 머물러야 하는가 | 대표 프레임, 동작, 주목 대상, 샷 ID |
| 애니매틱 또는 러프 편집 | 실제 시간 안에서 이해되고 흥미로운가 | 임시 화면·소리, 컷 순서, 길이, 버전 |
| 촬영표와 소재 목록 | 무엇을 어떤 조건에서 확보해야 하는가 | 빌드, 재현 조건, 원본·구간, 담당, 확보 상태 |
| 제작 일정과 납품표 | 언제 무엇을 확정하고 어떤 파일을 전달하는가 | 단계별 검토, 책임자, 비율·언어·플랫폼·CTA별 출력 |

한 개의 기획서 안에 이 내용을 묶어도 된다. 검토용 문서의 앞부분은 목적과 콘셉트로, 뒷부분은 컷 표와 제작 정보로 구성한다. 편집은 Assembly → Rough Cut → Fine Cut → Finishing의 단계로 다듬는 실무 예시가 있다. [편집 작업 흐름](https://www.derek-lieu.com/blog/2022/10/24/basic-game-trailer-editing-workflow)

발주·협업 시에는 실행 가능한 빌드, 촬영 도구 안내, 원본 음악·효과음·대사, 로고·폰트, 마케팅 문구와 엔드카드 정보를 함께 전달한다. [트레일러 편집자가 요청하는 소재 목록](https://www.derek-lieu.com/blog/2019/11/5/game-trailer-editor-asset-list)

원본 이력: [촬영 manifest](FRESH_CAPTURE_MANIFEST_20261008.md), [37초 및 세로편 편집 계약](VIDEO_EDIT_PLAN_20261008.md). 새 일반 플레이와 소재 인계는 [홍보팀 검토](HERO_TRAILER_PROMOTION_REVIEW_20261008.md), 실제 30초 편집은 [후속 제작 기록](HERO_TRAILER_PRODUCTION_20261008.md)을 따른다. 기존 파일의 존재를 사용자 장면 승인으로 간주하지 않는다.

패링 장면은 현행 게임 계약을 따른다. **무지개탄 blackBean은 Q만으로 패링하며 E 패링은 불가**, Q 성공 시 블루콩 유도반사다. 이는 기존 확정사항의 재기록이며 시스템 변경 제안이 아니다. 모든 공격이 반사된다는 인상을 주는 카피나 편집은 피한다.

### 75초 화면과 소리 구성 예시

아래 시간은 EXODUSER 초안이다. AAA의 표준 길이나 기존 영상의 실제 컷 분석이 아니다. 소리를 줄이거나 강조하는 연출도 신규 대표편의 제안이며, 기존 37초 원음 유지 계약에는 적용하지 않는다.

| 시간 | 화면과 액션 | 소리 방향 | 전달할 내용 | 소재 상태 |
|---|---|---|---|---|
| 0–4초 | 투사체가 다가오고 플레이어가 패링해 되돌리는 완결된 액션 | 접근음→패링→반사 결과를 또렷하게 | 이 게임의 반격은 직접 조작에서 나온다 | 기존 패링 원본에서 후보 선정 |
| 4–10초 | 실제 플레이 시점의 전투와 짧은 지옥 강하의 전제 | 공간음 위에 음악 시작 | 다크판타지 ARPG의 장르와 주인공 동기 | 연결 소재 선정 필요 |
| 10–25초 | 스킬을 조합하면서 적을 제어·처치하는 차이 | 행동마다 분명한 타격과 리듬 | 조합이 전투 방식을 바꾼다 | 조합 전후 증거 추가 필요 |
| 25–39초 | 드롭→장비 선택→그 결과가 드러나는 전투 | 잠깐 밀도를 낮춘 뒤 재진입 | 루팅과 빌드 선택의 의미 | 신규 소재 필요 |
| 39–54초 | 보스의 위협에 대응하고 공격 기회를 만드는 플레이 | 전조음·대응음으로 긴장 형성 | 물량전과 다른 집중의 순간 | 공개 범위·소재 선정 필요 |
| 54–69초 | 앞에서 이해한 패링·스킬을 더 강렬한 전투로 확장 | 음악 고조와 액션 결과를 정렬 | 익힌 힘으로 전투를 장악하는 쾌감 | 기존·추가 소재 조합 검토 |
| 69–75초 | 게임 로고와 무료 데모 CTA | 마지막 타격의 여운과 마무리 | 직접 체험할 다음 행동 | 현행 브랜드 자산 사용 |

초반에 장르와 차별점을 알리고 이후 내용을 확장하는 원칙은 전문 편집자의 설명을 참고했다. 구체적인 0–4초 배치와 75초 구성은 본 프로젝트의 제안이다. [장르와 훅을 빠르게 제시하는 이유](https://www.derek-lieu.com/blog/2022/10/24/how-to-hook-the-audience-and-how-quickly-to-do-it)

오디오는 화면의 보조 장식으로 미루지 않고 액션·정보·흥미를 함께 설계한다. 이는 게임 광고용 음악·SFX·대사·믹스의 역할을 다루는 실무 발표의 주제와 연결된다. [GDC The Sound of Excitement](https://www.gdcvault.com/play/1023259/The-Sound-of-Excitement-Creating)

## Steam 첫 영상에 반영할 기준

Steam은 출시 절차에 트레일러를 요구하며, **첫 영상은 실제 플레이 시점의 게임플레이 중심**으로 구성할 것을 강하게 권고한다. HUD도 이해에 도움이 될 수 있다. 첫인상을 줄 시간이 10초 미만이거나 무음으로 재생되는 환경을 고려해야 한다. [Steamworks 공식 트레일러 문서](https://partner.steamgames.com/doc/store/trailer)

| 구분 | 공식 문서의 내용 | 반영할 사항 |
|---|---|---|
| 노출 | 첫 두 유효 트레일러가 스크린샷보다 먼저 표시 | 대표 플레이편과 보조 영상의 순서 지정 |
| 자동 미리보기 | 첫 영상의 여러 지점에서 1초씩 6개를 추출해 6초 마이크로트레일러 생성, 직접 수정 불가 | 전반에 식별 가능한 플레이 장면 배치 |
| 업로드 권고 | 최대 1920×1080, 30/29.97 또는 60/59.94fps, 5,000Kbps 이상. 16:9·H.264·AAC 선호 | 플랫폼용 납품표에 명시 |
| 사용자 대표 이미지 | 영상 속 프레임을 사용하며 1920×1080 JPG/PNG | 실제 영상의 대표 장면을 후보로 지정 |

위 표는 같은 [Steamworks 문서](https://partner.steamgames.com/doc/store/trailer)의 2026-10-08 확인 내용이다. 특정 길이를 Steam 필수 조건으로 정하거나 시네마틱을 금지하는 규정으로 해석하지 않는다.

## 제작과 검토를 위한 운영 제안

| 단계 | 검토할 구체적인 결과 | 다음 단계에 필요한 판단 |
|---|---|---|
| 브리프·연출안 | 메시지, 타깃, 주요 증거, 레퍼런스 | 이번 영상이 남길 기억과 목적이 분명한가 |
| 구성표·애니매틱 | 임시 화면과 소리로 재생되는 전체 시안 | 장면의 인과와 감정 흐름이 이해되는가 |
| 촬영·러프 편집 | 실제 플레이로 교체한 영상 | 주장한 매력을 실제 장면이 증명하는가 |
| 편집 확정 | 컷 순서·길이·문구가 정리된 버전 | 부족한 장면과 중복 정보가 해소됐는가 |
| 마감·납품 | 최종 영상, 자막, 엔드카드, 플랫폼별 파생본 | 실제 재생·청취·표기·출력 검수를 통과했는가 |

일정은 위 결과별로 담당·제출일·피드백 마감일을 정한다. 비용은 기획, 추가 촬영, 편집·그래픽, 음악·사운드, 번역·버전 제작, 재작업 여유를 분리해 견적을 받는다. 확인되지 않은 AAA 평균 제작비나 표준 제작 기간을 예산 근거로 사용하지 않는다.

검수는 화질·코덱 외에도 오탈자, 읽을 수 있는 문자 배치, 게임 버그, 불필요한 UI, 프레임 혼합·순간 삽입, 오디오 동기·팝 노이즈, 버전 식별까지 포함한다. [실무 트레일러 QC 목록](https://www.derek-lieu.com/blog/2022/7/11/quality-control-check-list-for-game-trailers)

크리에이티브 검토에서는 처음 보는 사람에게 보여준 후 **어떤 게임인지, 무엇이 기억나는지, 직접 해보고 싶은지**를 자신의 말로 설명하게 한다. 무음 재생에서도 행동과 결과가 이해되는지 확인한다. 조회수와 함께 제공 가능한 채널의 시청 유지·링크 클릭·데모 유입을 비교하되, 매체·유입·길이가 다른 영상의 수치를 그대로 우열로 판단하지 않는다. 이 검토 질문과 비교 방식은 프로젝트용 제안이다.

## 다음 기획에서 결정할 사항

| 결정 항목 | 현재 초안의 기준 |
|---|---|
| 최우선 목적 | 무료 데모 체험 유도 |
| 중심 매력 | 패링 반격과 스킬 조합. 실제 장면의 이해도에 따라 우선순위 조정 |
| 스토리 분량 | 복수와 강하의 전제만 짧게 제시 |
| 루팅의 증거 | 대표편에서 다룰 경우 추가 소재 확보 |
| 보스·스포일러 | 공개할 장면과 보존할 발견 요소 지정 |
| 길이 | 홍보팀 후속 협의에 따라 확보 원본으로 30초 1차 편집본 제작. 45–75초 확장에는 보스·선택 전후·루팅 증거 추가 필요 |
| 음악 | 기존 사용 가능 음원과 원본 효과음을 검토한 뒤 방향 결정 |

이번 조사로 추가한 정보는 공개 제작 사례, 실무 양식, 대표편 브리프와 장면 구성 가설이다. 게임 코드·시스템 수치·맵·기존 영상은 변경하지 않았다.
