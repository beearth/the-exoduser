## 다음 순서

1. 기존 Steam 게임 창을 완전히 닫고, Steam 라이브러리에서 **「기본 공개 버전」**을 실행한다. 내장 로비/API가 개발 서버의 `development:true`나 프로젝트 `saves/` 슬롯을 사용하지 않는지 확인한다.
2. 실제 기본 공개 실행에서 한국어 메뉴, 첫 플레이 구간의 이동·공격 안내, 새 캐릭터 생성 영상의 한국어 자막을 확인한다. 저장 변경은 기존 데이터를 덮지 않는 임시 검증 자료로 수행하고 백업을 보존한다.
3. Steamworks 상점 편집의 게시 대기 변경 전체를 확인한다. 목록이 한국어 인터페이스/자막 지원 범위와 `Captions available` 해제만 포함할 때에만 게시한다. 다른 변경이 섞이면 게시하지 않고 전체 목록을 확인한다.
4. 게시 반영을 서버/미리보기에서 확인한 뒤 Notes 초안을 Steamworks에 입력한다.
5. 조건이 모두 통과하고 재심사 대기 상태가 아닌 경우에만 `검토 가능으로 표시`를 실행한다. 서버 화면의 제출 상태를 확인한다.
