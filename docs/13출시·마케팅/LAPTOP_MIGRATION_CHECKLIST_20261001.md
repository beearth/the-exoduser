# 노트북 개발 환경 이전 준비 — 2026-10-01

사용자: “노트북으로 이 환경을 다 넣어서 해도 될 것 같다.” 이후 사용자 답변과 첨부 주문 내역으로 **14인치 MacBook Pro, M5 Pro, CPU 15코어·GPU 16코어, 통합 메모리 24GB·SSD 1TB**를 확인했다. macOS 세부 버전·실제 여유 공간·접근 연결은 미확인이다. 현재는 이전 준비 단계이며 PC의 에이전트와 작업은 유지한다.

## 대상 Mac에 대한 판단과 변경 필요 사항

- 위 사양은 EXODUSER 소스 개발·문서·에이전트 운영을 옮길 후보로 적합하다는 총괄 판단이다. 실제 11팀 동시 작업·다중 브라우저·게임 검수의 메모리 압박과 프레임 시간은 아직 측정하지 않았다. 무거운 게임 실행·인코딩·빌드는 겹치지 않게 운영한다.
- 현재 `build-nwjs.mjs`는 `platform: 'win'`, `arch: 'x64'`, `.ico`, Windows `ffmpeg.dll` 후처리로 고정돼 있다. Mac 개발 환경 이전과 macOS 실행 패키지 제작은 별도 작업이다. Windows 빌드 계약을 덮어쓰지 않고 Mac 후보 경로를 별도로 만든 뒤 검수한다.
- 현재와 같은 버전 **NW.js 0.111.2의 macOS ARM64 일반/SDK 배포판이 공식 제공**된다. 이는 엔진 배포판의 존재 확인이며 EXODUSER의 Mac 실행·영상 코덱·저장 검수 통과를 뜻하지 않는다. [NW.js 공식 0.111.2 배포 안내](https://nwjs.io/blog/v0.111.2/)
- `G:\exoduser`·Node/Chrome 실행 경로·PowerShell 명령·Windows용 설치 의존성은 Mac에서 그대로 사용할 수 없다. Mac용 의존성을 재설치하고 실제 앱 경로를 지정한다. 비밀값·사용자 세이브·실행 중인 터미널 세션을 통째 복사하지 않는다.
- 운영 제안: Mac을 주 개발·팀 관리 장치로 준비하고, 기존 PC는 전환 검수가 끝날 때까지 정상 실행본·복구 지점 및 Windows 최종 패키지 검수용으로 유지한다. 실제 담당 장치 전환은 아직 하지 않았다.

## 실제 이전 순서

1. 확인된 Mac 사양을 기준으로 macOS 버전·여유 공간·접근 경로를 확인한다. 현재 PC 작업은 계속 유지한다.
2. 전환 직전에 팀별 미완료 변경을 기록하고 GitHub 복구 ref와 필요한 비Git 자료 목록을 확정한다. 01:44 이후 변경은 위 복구본에 자동 포함되지 않는다.
3. 노트북의 별도 체크아웃에 소스·문서·필수 에셋을 복구하고 도구·의존성·인증·하드코딩 경로를 확인한다.
4. 로비→캐릭터→전투→아이템/설정→저장→재실행을 검수한다. 영상·오디오 로드와 API도 확인한다.
5. 고유 출력 경로에 후보 빌드를 만들고 해당 노트북에서 프레임 시간과 긴 프레임을 측정한다. 현재 PC의 FPS를 노트북 결과로 대체하지 않는다.
6. 검수 통과 후 팀 실행 위치와 자동화의 담당 PC를 전환한다. 기존 PC 복구본·정상 실행본은 유지한다.

이전 완료 기준은 파일 복사가 아니라 위 실행·저장·빌드 검수와 팀 인수다. 노트북의 실제 이전·설치·로그인·실행은 아직 수행하지 않았다.
