## 5. 매 소재 실행·기록

1. 실제 변경·소스 브랜치/커밋·정본 문서·공개 가능한 구현 범위를 확인한다. 개발 프리뷰와 공개 Steam 데모를 구분한다.

3. 사용자 승인 범위와 실제 계정 권한·약관 상태를 충족한 뒤 게시하고, 공개 URL·공개 범위·Steam 링크를 직접 확인한다. 제출/처리 중 상태를 공개 완료로 세지 않는다.
4. 소재별 기록은 **주제·소스 버전·게시 URL/상태·UTM·시청 유지·Steam 유입·구체적 피드백·다음 개선** 8개 필드로 시작한다. UTM 미표시를 0으로 단정하거나 본게임 UTM을 데모 다운로드 수로 해석하지 않는다.
