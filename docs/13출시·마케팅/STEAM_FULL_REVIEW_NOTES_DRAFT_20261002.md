# 본편 영문 심사노트 초안 — 아직 미제출

실제 Windows 정상 플레이 및 Steam 설치본 검수 뒤 새 BuildID를 추가하고 제출한다. 현재 준비된 수정내용만 기술한다. 새 BuildID·검수 완료를 만들어 쓰지 않는다.

> This submission is for EXODUSER: HELL LORD, AppID 4749590 / DepotID 4749591. The previous upload used the demo configuration by mistake. The replacement Windows build uses an explicit full-game target. The full lobby uses the official-game character creation and selection flow, and the demo welcome/entry flow is not used. The Chapter 1-1 demo ending, demo level cap, and demo content restrictions apply only to the separate demo target. The full target uses the existing seven-chapter, 35-stage game progression.
>
> Spanish is Spanish - Spain (es), and Portuguese is Portuguese - Brazil (ptbr). To change language, use the language selector on the opening/main-menu screens, or open Settings and use Game → System → Language. Select “Español (España)” or “Português (Brasil)”. The selected language is saved and carried into the game. The store-language declarations have been corrected to these regional variants.
>
> Settings, Combat Skills, Forge, and Growth titles now select small, medium, or large nameplates according to the rendered translation width. The metal nameplate expands while the knight ornament keeps its size for the current screen layout. Longer titles such as “Habilidades de Combate” remain inside the plate; on narrow windows, the title wraps and the plate grows in height. The Brazil-language Settings title is “Configurações”, and the Spain-language title is “Ajustes”.
>
> The in-game purchase declaration has been removed from the Content Survey because this build does not contain in-game purchases. The mature-content survey has also been updated and published. The separate demo AppID 5337590 is not part of this submission.
