## KO

### 새 기능
- 실버 헬 1차 이식 — 타이틀 메뉴·공통 창·스킬창·인벤·설정·HUD를 은빛·흑철·지옥의 눈 톤으로 통일
- 첫 화면 리마스터 — 눈알 로고 3D(A 은빛 단조강)·붉은 태양 절벽 배경·Kling 4.0 반복 영상
- SND-08 §6.5 트랙 C 웹 — 채택 예고음 4키·드루이드 연출음 3키 연결
- 첫 화면 타이틀 메뉴 — 로고 C + 흑철 판 버튼 줄 (디자인총괄 시안 채택)
- SND-08 RM-1 1차 판정 실행 — 가공본 13개·r2 3키 재생성 기록, 카탈로그 r2 3키 (청음 대기)
- SND-08 RM-1 트랙 B tell_parry·tell_grab + B2 드루이드 연출음 5키 × 3후보 생성 — 카탈로그·기록 (청음 대기)
- SND-08 RM-1 트랙 B A8 2키(amb_toxic_river·toxic_bubble) × 3후보 생성 — 카탈로그·기록 (청음 대기)
- SND-08 RM-1 트랙 B 신규 7키 × 3후보 생성 — 카탈로그·기록 (청음 대기)
- SND-02 SFX Forge R2 채택 4키 반영 — 치명타·버튼 hover/confirm·1장 앰비언스
- 전사 기본 기동 = 구르기, 전격이동은 마법사 계열 전용 + 키 설정 "구르기(방향키 +)" (번역 No.3372~3385, 28언어)
- 스킬 창 [K] 조용한 단계 — 좌우 판·제목·버튼, 제단·슬롯 유지
- VFX-02 2차 4묶음 — 빙결 4종·물 2종 교체 (승인 에셋 재채색, 비용 0)
- STY-12 펫 보스 처치 대사 — 1-1 드루이드 침강 도주용 2줄 (번역 No.3350~3351, 28언어) + 검수 PASS·번들 사고 기록
- STY-12 1장 보스 한 줄 대사 자막(#bossLine) + 번역 No.3343~3349 28언어
- 설정 화면 조용한 단계 — ui-quiet-tier.css, #settings 범위, 새 글자 없음
- VFX-10 지옥강타 베이지 덮개 → 국소 백열 코어, 용암 정점 +0.19→+0.074초 (시각만, 판정·수치 불변)
- VFX-12 — 공통 폭발 크기 곡선 앞당김(_boomGrow) + 기동불꽃 화면 주황 덮개 제거
- STY-D9 1-1 다크드루이드 마지막 사망 = 땅속 침강 도주 (표시만 교체, 수치 무변경)
- VFX-02 2차 3묶음 — 아케인 3종·독 2종 시트 재채색 교체 (A안)
- VFX-02 2차 3묶음 — 아케인 3종·독 2종 시트 재채색 교체 (A안)
- AD3 1단계 — 적 공격 예고음 TELL 우선순위·플레이어/명중 결과 오용 제거

### 개선
- lang 전수 감사 2차 — _L(데이터) 쌍 27개 언어 보충 (No.3500~3587) + 감사 도구
- lang 전수 감사 1차 — 27개 언어 누락·한글 잔존 보충 (No.3389~3472)
- 번역 누락 3건 복구 — 자동 투자 예약 9문구 + 기본 조작 실습 개정 11문구 (27개 언어)
- publish Killu blood-tears v3 web cinematic

### 버그 수정

- exclude unused CH1 authoring masters from upload
