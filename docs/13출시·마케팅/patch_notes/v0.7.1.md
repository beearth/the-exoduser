## KO

### 새 기능
- 기검참 실버+블랙 — GPT Image 2.5 sunburst 실버 시트 재생성, 1·2·3타 색 틴트 폐지, 검은 잉크 층(일반 합성)
- Skill Forge 합성 문양 고급화 — 흑철 위 고딕 장미창 시길 각인 + 파낸 룬 궤도, 선택 슬롯 테 원근 보정
- 포션 퀵슬롯 폐지(자동 물약만) + 스킬 합성 전용 만렙 랩
- K 스킬 창 전면 교체 — 3D 합성 제단 (Skill Forge, three r186)

### 버그 수정
- Skill Forge 아이콘이 홈 중심에서 쏠리던 원근 시차 제거 (테 납작·아이콘 면을 테 앞면 깊이로)
- Skill Forge 홈·아이콘 정합 — 원화 가운데 정사각 크롭, 슬롯 정원, 제단 룬 홈을 실제 배치에 맞춰 새김 + 소켓 우물
- Skill Forge 3D 원판 중심을 소켓 고리 중심에 맞춤 + 원판이 소켓을 감싸게
- Skill Forge 중앙 정렬 고정 + 아이콘 프레임 채움 + 트레이 한 줄 균형

### 밸런스
- 악의 약화 해제 타이머 제거 + 최대 10단(+300%)
