`private-business/`는 Git 추적 제외 폴더다. 원본 파일, 사업자등록번호, 개인 식별 정보, 상세 연락처는 이 로컬 폴더에서만 관리한다. 이 안내 문서와 제외 규칙만 소스 관리에 포함한다. 따라서 다른 PC에서 Git 저장소만 복제하면 원본 자료는 없으며, 별도의 로컬 자료 전달이 필요하다.

출품·사업자 관련 문서를 작성할 때 위 원본을 먼저 참고한다. 브랜드명과 법적 상호를 혼동하지 않으며, 원본에 없는 사실·권리 동의·서명·제출 승인을 추정하지 않는다. 보관은 외부 업로드나 최종 신청서 제출과 별개다.
