## 2. 엘든 링 스타일 — 가져올 것과 가져오지 않을 것

엘든 링 공개 스토리 트레일러에서 배우는 것은 **구조와 리듬**이다. 대사·음악·자막 서체·장면 구도는 가져오지 않는다.

| 엘든 링 문법 | EXODUSER로 옮기는 방식 |
|---|---|
| 얼굴 없는 노년 내레이터가 신화를 낭독 | **네메시아의 목소리**로 지옥의 법칙을 낭독. 끝까지 얼굴을 숨기다가 마지막에 처음 드러낸다(D1) |
| 세계의 붕괴 사건(파쇄)으로 시작 | 모든 세계의 악의가 하나의 지옥으로 흘러드는 **수렴**으로 시작 |
| 반신들을 이름+이명 카드로 한 명씩 소개 | 각 장의 **군주(장 보스)**를 이름+칭호 카드로 소개. 7장 지옥왕은 실루엣과 옥좌만 |
| 느린 카메라, 거대한 원경, 암전 사이의 침묵 | 정지 원화의 2.5D 패럴랙스 + 연기·불씨 미세 모션, 컷 사이 0.5~1초 암전 |
| 합창이 쌓이다 마지막에 폭발 | 저음 합창 → 군주 카드마다 북 한 번 → 몽타주에서 정점 → 무음 → 타이틀 |
| 주인공(빛바랜 자)을 부르는 마지막 명령 | 네메시아의 부름 + 전사의 첫 대사로 응답 → 태그라인 "THOSE WHO DEFY THE FALL." |

## 5. 제작 방식

과거 기록상 AI 영상으로 전투 안무를 만드는 방식은 5회 실패했다(메모리 ai-video-gen-limits). 엘든 링 스토리 트레일러도 대부분 느린 카메라와 정지에 가까운 화면이다. 그래서 **원화 키프레임 + 2.5D 카메라 + 실제 게임 플레이**로 만든다.

| 단계 | 내용 | 담당 | 비용 |
|---|---|---|---|
| P0 기획 승인 | 이 문서, 결정 D1~D5 | 사용자 · 스토리 총괄 | 0 |
| P1 애니매틱 | 기존 소재와 임시 정지 화면으로 120초 러프 편집, 임시 내레이션, 임시 음악(「네메시아의 강림 V3」). **승인 게이트** | 단순작업(Sonnet)이 조립, 스토리 총괄이 검수 | ElevenLabs만 사용(크레딧 여유) |
| P2 키프레임 | 신규 원화 약 12장: 군주 6, 지옥 원경 3, 중첩 1, 지옥왕 실루엣 1, 네메시아 정면 1. 환경은 MagicLight Seedream 5.0 Pro, LOCK 캐릭터는 GPT 이미지. 장마다 반려 2회면 멈추고 보고 | 디자인총괄 판정, 아트 파이프라인 | MagicLight 포인트 |
| P3 모션 | 원화를 전경·중경·배경 레이어로 나누어 2.5D 패럴랙스. 연기·불씨·천 같은 환경 미세 모션만 AI 이미지→영상 허용, 전투 안무 금지 | 단순작업 + 디자인총괄 판정 | MagicLight 영상 소량 |

| P6 마감 | 편집, 자막 29개 언어(번역목록 등록), 60·30초 컷다운, 사용자 최종 검수 | 단순작업 + 스토리 총괄 | 0 |
