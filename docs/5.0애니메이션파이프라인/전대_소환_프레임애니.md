# 전대 소환(ancestorSummon) 프레임 애니메이션 파이프라인

전대 = 유골함(유니크 콜렉션)으로 해금하는 **역사적 악인 해골전사** 자율 전투 소환체. 소환 시 **거대 1기**만 소환(수→위력·체력·덩치 환산). 이 문서는 소환체 프레임 애니 규약·생성·와이어링을 정의한다.

## 프레임 세트 (전대별 3장)
- **idle**: `img/vfx_ancestor/ancestor_{id}.png` — 대기(기본 스프라이트, 풀에서 로드)
- **windup**: `ancestor_{id}_windup.png` — 무기 치켜듦/뒤로 젖힘(공격 예비동작)
- **strike**: `ancestor_{id}_strike.png` — 무기 후려침/찌름(강타 순간)
- 규격: 투명 RGBA 1024×1024, 다크 페인터리 픽셀, 청염(조상 영혼불). `giant_wargod`만 별도 파생.

## 생성 방법 (일관성)
- **Higgsfield nano-banana(nano_banana_pro)** + `image_references`에 각 전대의 idle을 넣어 **동일 캐릭터**로 windup/strike 포즈만 변주.
- 프롬프트 규약: "Use the reference image's EXACT character (…무기…). Redraw the SAME character in a WINDUP/STRIKE pose: …. Same proportions/armor/colors/style." → 배경 단색 → `rembg` 컷아웃 → 1024 리사이즈.
- 재현: `tmp/record_*`/배치 스크립트. 레퍼런스 job_id는 원본 로스터 생성분.

## 런타임 와이어링 (game.html)
- **프레임 테이블**: `window._ancFrames = _ANC_SPRITE_POOL.map(src => ({windup:{im,tc}, strike:{im,tc}}))` — 경로는 idle 경로에서 `_windup/_strike` 파생. 인덱스별 스펙트럴 청기 틴트(rgba(120,160,255,.13)) 캐시(원색 보존).
- **공격 타이머** `a._atkT`: 근접 타격 시 `_atkT=1`, 매 프레임 `-sp*0.09` 감쇠(~11f). `a._atkDir`=타겟 방향.
- **프레임 선택** (렌더): `_t>0.72`→windup / `0.30<_t≤0.72`→strike / 그 외 idle. 프레임 미로드 시 절차적 스윙 폴백.
- **절차적 보강**(전 전대 공통): 앞으로 돌진(_lx/_ly)·스케일 펀치(_punch)·idle 숨쉬기(_breath)·이동 흔들림·강타 청염 슬래시 아크. 프레임 사용 시 스윙 회전(_sw)은 0.18배로 축소(포즈에 이미 포함).
- **크기**: `_aSz=180*a.big` (유골함 등급/스택으로 a.big 최대 ~1.7).
