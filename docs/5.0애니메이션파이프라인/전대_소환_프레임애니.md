# 전대 소환(ancestorSummon) — 철갑 전대 단일 연출 파이프라인

> 2026-09-06 재입력 회수 적용: [최신 회수 계약](./전대_재입력_회수.md). 자동 주기 폭발은 폐지했으며 기존 300f 함수·테스트는 호환 경로만 다룬다.

전대는 유골함 콜렉션으로 해금하는 단일 거대 자율 소환체다. 2026-09-04부터 역사적 악인 7종 랜덤 로스터와 별도 공격 프레임은 폐기했으며, **철갑 전대 1기**의 중량감·지면 연출·대검 탄막흡수 폭발에 집중한다.

- 비율은 현재 시트의 선 자세 머리·발 위치를 기준으로 보정한 값이다. 검을 든 스윙은 위쪽 여백이 커 전체 출력 높이가 크지만 몸의 기준 신장은 같다. 에셋 교체 시 이 보정값도 재측정한다.
- 강림 시트: `ancestor_iron_warlord_emerge_v1.png`은 2172×724 RGBA, 가로 6등분(셀 362×724)이다. `_emergeT/_emergeMaxT=96`의 진행률로 `floor(progress×6)`을 0~5 clamp해 재생한다. 전체 그림의 상하 부유·통째 회전으로 대체하지 않는다.
- 설치 시트: `ancestor_iron_warlord_plant_v2.png`은 6프레임(대검 올림→무릎/상체 하강→강한 박기→양손 고정→룬 접지)이다. 설치 시작 후 첫 72f에 `floor(plantProgress×6)`으로 0→5를 재생하고, 다음 60f는 마지막 박힌 자세에서 붉게 충전한다.
- 보행 시트: `ancestor_iron_warlord_walk_v2.png`은 6프레임(좌우 발 접지·통과·반동, 관절·망토·저검 각 변화)이다. `a._moving=1`일 때 `_walkFrame=floor(_walkT/8)%6`으로 재생한다. 구 v1은 절대 로드하지 않는다.
- 스윙 시트: `ancestor_iron_warlord_swing_v4.png`은 8프레임(가드→어깨/골반 뒤로 싣기→**깊은 윈드업 정지**→인상→**머리 위 apex 정지**→짧고 무거운 사선 내려찍기→강철청색 검로 팔로스루→낮은 회복)이다. `a._atkT>0`이면 `_ancestorSwingFrame(_atkT)`이 0→7을 재생한다. `a._atkT`는 `sp×.026`으로 감쇠해 약 **38 시뮬레이션 프레임**(브라우저 30fps 검증에서 18 표시 프레임, 약 0.6초)을 유지한다. 설치/강림보다 우선하지 않는다.
- 묘지 무대 시안은 런타임에서 제거했다. 통째 PNG를 전대 뒤/앞에 겹치는 방식은 맵의 원근·충돌·다른 유닛 z-order와 연결되지 않아 억지 콜라주가 된다. 후속 소환 연출은 맵 오브젝트처럼 분리된 바닥 균열·후방 석주·전방 occluder를 개별 월드 좌표/레이어로 제작한 뒤에만 연결한다.
- 구 `ancestor_{giant_warlord,giant_wargod,sunwukong,yeopo,hangwu,chiyou,vlad}*.png`, `ancestor_idle_1.png`와 windup/strike 프레임은 삭제됨.

## 전투 상태 연결

- 자동 주기 대검 설치는 폐지했다. 전대 생존 중 스킬 재입력으로만 회수 폭발을 시작한다(쿨·MP 검사 우회, 비용 및 쿨 갱신 없음).
- 자율 전투 중 반경 190px 일반 탄막을 최대 24발 저장한다. 재입력 시 72f 설치 + 60f 붉은 충전 후 폭발하며, 충전 동안 이동·공격·추가 흡수는 정지한다.
- `blackBean`은 Q 전용 유도반사 규칙을 위해 흡수하지 않으며, 아군탄·mine/trap/web/poisonZone도 제외한다.
- 전대는 시간 제한이 없으며 HP 0 또는 재입력 시 132f 칼 꽂기·충전 후 폭발로 소멸한다. 적 일반 투사체는 플레이어·허수아비·전대 중 가까운 살아 있는 대상을 향한다. `blackBean`은 Q 전용 계약을 유지해 전대를 표적/피격하지 않는다.
- 전대 근처의 적은 `38×big + 적r + 18px` 안에서 30f마다 가장 높은 적 하나를 확인해 **내구도 1타**를 준다. 일반 탄막도 **1타**이며 원본 `p.dmg`·`atk`는 전대 내구도에 적용하지 않는다. 전대는 정확히 100번째 피격에서 132f 칼 꽂기·충전을 시작하고 저장 탄막 피해로 폭발한 뒤 제거된다. 신규 유골함 `ancHP`는 수치형 최대HP `30/60/90/120/150%`; 구세이브 `ancDur`은 값 1당 +30% HP로 읽는다.
- 저장 완료 시 `_detonateAncestorSword()`가 지면 폭발과 피해 판정을 담당한다. 수치 공식은 `docs/2_1 스킬관리+합체시스템+자원/2_1 스킬관리+합체시스템.md`의 전대 소환 표를 SSOT로 한다.
