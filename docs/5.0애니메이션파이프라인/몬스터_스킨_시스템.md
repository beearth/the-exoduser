### 방향 파일명
`south`, `south_east`, `east`, `north_east`, `north`, `north_west`, `west`, `south_west`

## 코드 상수

```
_MOB8_TOTAL = 40   // 아틀라스 내 몹 총 수
_MOB8_COLS  = 8    // 아틀라스 열 수 (행 = ceil(40/8) = 5)
```

## 스킨 배정 (스폰 시)

`mkEn()` → `_assignMobSkin(e)`:
```
seed = (etype × 7 + floor(homeX × 31)) & 0x7fffffff
idx  = seed % _MOB8_TOTAL
col  = idx % _MOB8_COLS
row  = floor(idx / _MOB8_COLS)
```
- 보스(`e.ib`)는 제외 — `atlas_bosses.png`로 별도 렌더
- meta/JSON 로드 불필요, col/row 즉시 확정
- etype + 스폰 좌표 기반 결정적 시드 → 같은 몹은 항상 같은 스킨

## 렌더 경로 (2026-08-09 기준)

### 1. 일반 렌더 — WebGL2 우선, Canvas 폴백
```
if(e._mob8Col === undefined) → 즉시 col/row 계산
_prepEnemyInstanced() → e._mob8dir && e._mobCh이면 16개 텍스처 버킷에 적재
  idle 8방향 + 이동 walk 8방향, 적 본체 512 + walk 오버레이 512개 한도
  성공 → e._ensGLMode=1 → 본문 Canvas drawImage 건너뜀 (중복 방지)
  실패/미준비 → e._ensGLMode=0 → 아래 Canvas 폴백
_ch8Atlas[1].dirs[방향키] → drawImage(col*cell, row*cell, cell, cell)
이동 중 walk 존재 → drawImage((col*framesPerMob+frame)*cell, row*cell, cell, cell) 오버레이
방향 미로드 시 → south 폴백
아틀라스 미로드 시 → _usedSpr=true (투명, 동그라미 안 그림)
```

GPU 배치는 `Float32Array`/`Uint16Array` 재사용 버퍼만 사용한다. 보스·구울·슬라임과 상태 효과는 이 경로에 포함하지 않으며, Canvas 렌더를 계속 사용한다.
