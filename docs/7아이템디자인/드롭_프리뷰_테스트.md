# 월드 장비 드롭 프리뷰 테스트

## 실행 주소

로컬 Node 서버(`C:\nvm4w\nodejs\node.exe server.cjs`, 포트 `3333`)를 실행한 뒤 아래 주소로 접속한다.

`http://127.0.0.1:3333/game.html?test=1&slot=drop-preview&stage=1&dropPreview=1`

## 범위와 안전성

| 항목 | 값 |
|---|---|
| 활성 조건 | URL 쿼리 `dropPreview=1` |
| 시작 스테이지 | `stage=1` |
| 저장 슬롯 | `drop-preview` |
| 저장 | `dbSave`를 빈 비동기 함수로 교체해 비활성화 |
| 생성 시점 | 스테이지 초기화 완료 후 게임 시작 시 1회 |
| 생성 수 | 장비 `5`개 |
| 월드 드롭 보존 상한 | 기존 `_wiPush` 규칙의 `20`개 |

## 생성 샘플

| 순서 | 슬롯 | 속성 | 희귀도 | 플레이어 기준 위치 |
|---:|---|---|---:|---|
| 1 | weapon | 화염 (`EL.F`) | 1 | `(-96, -44)` |
| 2 | bow | 냉기 (`EL.I`) | 2 | `(-48, -18)` |
| 3 | ring1 | 어둠 (`EL.D`) | 3 | `(0, -44)` |
| 4 | armor | 번개 (`EL.L`) | 4 | `(48, -18)` |
| 5 | helmet | 신성 (`EL.H`) | 5 | `(96, -44)` |

`dropPreview`가 없으면 프리뷰 생성 및 저장 비활성화 코드는 실행되지 않는다.

## 드랍 빔 v3 — 10단 확장 구조 (2026-08-10)

- 아틀라스: `img/fx/world_item_drop_beams_v3_01/02.png` — 512²타일 2열×5행(10타일), 프레임 2장
- **beamTier 1~10 = 타일 0~9**: 1 백은 / 2 초록 / 3 파랑 / 4 보라 / 5 금 / 6 레드 / 7 핑크 / 8 청록(ANCIENT) / 9 흑+적(VOID) / 10 백금(EXODUS)
- 선택 전담 헬퍼 `_getWorldDropBeamTier(item)`: **layerLv(1~10) 우선, 없으면 rarity 폴백** `[0,2,3,4,5,6]` — FINAL DECISION LOCK의 layerLv 도입 시 렌더 코드 무수정
- 그리드 하드코딩 제거: 타일=정사각(폭/COLS), 행수는 이미지 높이에서 파생. 아틀라스에 없는 단수는 무표시(안전)
- 검증: dropPreview(r1~5) + layerLv 1/7/8/9/10 콘솔 주입으로 10빔 동시 렌더 확인
- **알려진 제약**: 9단(VOID)의 검은 연기는 additive('lighter') 합성 특성상 거의 표현되지 않음(코어 적색 빔만 표시). 연기 보존하려면 source-over + 알파 원본 필요 — 추후 결정
- 소스: 8~10단은 `img/fx/아이템빛기둥_원본/` 티어 시트에서 크롭 (f1=디자인시트 대형 빔, f2=애니시트 F5)
