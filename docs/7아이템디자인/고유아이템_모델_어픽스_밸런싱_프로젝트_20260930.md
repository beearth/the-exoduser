# 고유아이템 모델·어픽스 밸런싱 프로젝트

> 시작: 2026-09-30 · 책임: 아이템 모델/어픽스 밸런싱 · 상태: **설계·원화 검토 중, 본게임 미구현**

프로젝트 진입점: [`unique-item-project/README.md`](../../unique-item-project/README.md).

2026-10-01 진행·소유권: [ITEM 팀 작업 대장](ITEM_TEAM_MASTER.md)에 본인 MagicLight/검수 탭, 22개 작업 ID와 원본 회수 대조를 기록했다. [게임 적용 계약](UNIQUE_ITEM_GAME_INTEGRATION_CONTRACT_20261001.md)은 현행 생성·드롭·세이브·아이콘 경로를 확인한 PM-009 사전 설계다. 검수 페이지와 대조 도구는 `unique-item-project/`에 있으며, 게임 파일은 수정하지 않았다.

## 목표와 원천

22개 보라색 고유아이템을 각각 **보이는 물체 하나 + 플레이 결정을 바꾸는 어픽스 하나**로 완성한다. 이름·형태·현재 원화는 [보라색 고유아이템 카탈로그](보라색_고유아이템_카탈로그_20260930.md), 효과·하중상 롤·코드 훅은 [유니크 어픽스 리스트 D절](유니크_어픽스_리스트.md)이 단일 원천이다. 이 문서는 제작·판정·위험 관리 장부이며 수치의 두 번째 원천이 아니다. 기존 A~C절과 `2_3 돌진+패링+방패시스템`은 건드리지 않는다.

현재 `game.html`의 `UNIQUE_SPECIAL`은 슬롯 기반 기존 12종이며, UI-01~22와 U-D01~22의 실제 드롭·장착·효과·저장·번역은 미구현이다. `affix-mini-project/`는 문서 수치를 읽는 모의 실험대일 뿐 실제 게임 밸런스 증거가 아니다. 본게임 적용 여부를 원화 완성이나 모의 실험 통과와 혼동하지 않는다.
