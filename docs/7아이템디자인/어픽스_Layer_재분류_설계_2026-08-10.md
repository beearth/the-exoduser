## 1. 추천 Layer 구조

| Layer | 정체성 | 한 줄 정의 |
|---|---|---|
| **L1 Foundation** | 캐릭터 기반 | STR/DEX/INT/VIT/LCK/근성 + 복합 스탯 |
| **L2 Resource·Mobility** | 자원/기동/유틸 | 최대자원·코스트·리젠·쿨다운·이속·파밍 |
| **L3 Defense·Sustain** | 생존 | DEF·HP·쉴드·DR·저항·회복·생존 발동 |
| **L4 Element·Status** | 속성·상태이상 | 속성뎀·DoT·상태 부여/강화/지속 |
| **L5 Attack Style** | 공격 방식 | 공속·시전·사거리·투사체·AoE·타입뎀 |
| **L6 Conditional·Synergy** | 조건부·시너지 | 조건부 뎀·처치/타격 프록·흡수·콤보·스킬 |
| **L7 Damage Addition** | 추가 피해 | 플랫 물리/마법/5속성 + 무조건 %증폭 |
| **L8 Critical** | 치명타 | 크리 수치 + 크리 발동 |
| **L9 Rage** | 분노 | 분노 수치·획득·상태·프록 (패링 연계) |
| **L10 Ultimate** | 궁극기 | 궁극 피해·충전·지속·발동·변형 |

- 유저 가설(L1~L6) 대비 수정점: **L2에 '기동(이속/돌진/회피쿨)'을 흡수**(자원=조작성 축), **L4를 '속성 공격+상태이상'으로 한정**(속성 *저항*은 전부 L3 생존으로) — 플레이어가 "L4 = 내 공격에 속성/상태를 붙이는 층, L3 = 맞을 때 층"으로 즉시 구분 가능.
- 하위→상위 발전 곡선: L1~L3 기초 수치 → L4~L5 전문화 → L6 시너지 → L7~L8 증폭 → L9~L10 시스템 변형. 설계 원칙(§5) 충족.

## 2. Layer별 A/B 서브슬롯

**A=수치/기초, B=기능/발동** 패턴은 L3·L4·L6·L8에서 자연스럽게 성립하고, L1·L2·L7은 "A=단일, B=복합/전역"으로 변형 적용이 낫다. 억지 분할이 불필요한 층은 FLEX.

| Layer | A | B |
|---|---|---|
| L1 | 단일 스탯 (strFlat…) | 복합 스탯 (allStat, hyb*, 공+체 하이브리드) |
| L2 | 자원 수치 (최대치·리젠·코스트·쿨다운) | 기동+유틸 (이속·돌진·물약·파밍) |
| L3 | 수치 방어 (DEF·HP·쉴드·DR·저항) | 발동 생존 (반사·가시·정화·불굴·부활·피격/막기 프록) |
| L4 | 속성 강화 수치 (DmgPct·Pen·Duration·상태강화) | 상태 부여 발동 (DoT·OnHit·Burst·변환) |
| L5 | 속도·사거리·타입뎀% | 투사체/기하 조작 (관통·다중·스플래시·연쇄·이중타) |
| L6 | 조건부 수치 (vs대상·HP/자원 상태·거리) | 발동 프록 (처치·흡수·콤보·스택) + sk* (FLEX) |
| L7 | 플랫 추가 피해 | 무조건 % 증폭 (atkPctAll·endAllDmg·magicDmg) |
| L8 | 크리 확률/배율 | 크리 시 발동 (onCrit* 6종 + 조건 크리) |
| L9 | 분노 수치 (최대치·피해·획득) | 분노 프록 (패링 적립·소진 폭발·상태 중 효과) |
| L10 | 궁극 수치 (피해·충전·지속·쿨) | 궁극 발동/변형 (사용/종료 프록·메커니즘 변화) |

## 4. 반드시 살릴 DEAD TOP 후보 (FIX 우선순위)

빌드 다양성 기여도 × 구현 난이도 기준:

1. **doubleStrike / multiShot** — 이중타·다중발사, 빌드 변형력 최상
2. **원소 Pen 5종 + elemPenAll** — 저항 관통 축 신설 (속성 빌드 종결 스탯)
3. **원소 Burst 5종 / Duration 5종** — 속성 프록·DoT 연장 (DoT 시스템 기존재, 구현 용이)
4. **shieldBypass** — eShield 시스템 기존재, 몹 쉴드 관통 카운터
5. **flat damage 7종** (flatPhys/Magic/5속성) — L7의 뼈대
6. **pierce 3종 + splash 2종 + chainDmgKeep** — 석궁/투사체 빌드 축 (왕관 스플래시 코드 기존재)
7. **igniteDmg/frostbiteDmg/shockDmg** — 감전(_shockStk) 등 상태 시스템 기존재
8. **killStreakDmg/Spd, momentumDmg, ringDmgPerCombo, neckComboMax** — 루프형 플레이 패턴 생성
9. **atkPctAll / endAllDmg** — L7-B 전역 증폭
10. **hybFireIce / hybLightDark / hybElemDotDmg** — 이중 속성 하이브리드
11. **리젠 6종** (st/mp/hp RegenFlat/Pct) — L2/L3 기초
12. **overhealShield** — 과치유→쉴드 전환 (생명팔찌 정체성)
13. **onDodgeDmg / onBlockHeal / onBlockMana / onHitDefBoost** — 방어 행동 프록
14. **critMultiOnLowHP / hybCritLeech** — L8-B 보강
15. **armorShred / dotTickRate / stack 2종** — 디버프·DoT 조작

## 7. sk* 스킬강화 20종 — 배치 분석

- **결론: L6-B(FLEX) 배치 + 계열 통합 REWORK 권장.** 별도 "Skill Affix 체계" 신설은 Layer 20슬롯 구조와 이중 구조가 되어 비권장.
- 문제: 개별 스킬 20종을 그대로 풀에 넣으면 (1) 내 빌드와 무관한 스킬 어픽스가 드랍 풀을 희석, (2) Synthesis로 스킬이 합체되면 원본 스킬 어픽스의 적용 대상이 모호.
- 재설계 제안: 20종 → **계열형 5~7종**으로 통합: 근접기강화(회전참/연쇄참/거인강타/유령보행), 광선기강화(옴니빔/지옥광선/화염빔), 투사체기강화(미사일/청탄/폭렬탄/악의사냥), 오라·장판기강화(화염오라/가시오라/암흑기둥/역병), 포격기강화(악의폭풍/악의박격/연쇄돌격), 구체기강화(화구/빙구)
- Synthesis 연동: "합체 스킬 사용 시 +X%" / "성급 N 이상 스킬 강화" 같은 신규 형태가 L6-B 또는 L10-B에 적합.

## 8. Archetype 20종 — 판정

- 효과 자체가 전부 기존 어픽스의 복제(§5 MERGE 맵 참조)이고, 클래스 강제도 아니어서 **개별 어픽스로서는 존재 가치 없음 → 전량 MERGE**.
- 살릴 경우의 유일한 형태: **"테마 세트" 시스템으로 REWORK** — 같은 아키타입 어픽스 2~3부위 장착 시 세트 보너스. 자유 빌드 철학과 충돌하지 않고 오히려 방향성 제시. 단 신규 시스템이므로 우선순위 낮음.

# 별도 질문 답변

**Q1. 풀이 10 Layer × 2 Slot에 충분한가?**
총량은 충분(402 → MERGE 정리 후 실질 고유 효과 약 300). 그러나 분포가 하위 층에 몰려 있어 "20슬롯을 다 채울 수 있는가"보다 **"상위 층(L7~L10)에 넣을 것이 있는가"가 문제**. L7~L10 합계 42종(그중 WORKING 22)뿐.

**Q2. Layer별 불균형?**
심각함. L6(93)·L3(80)·L4(69) vs L9(7)·L10(0). MERGE 후에도 L3~L6는 각 40~70종, L9~L10은 한 자릿수. sk* 20종을 계열 5~7종으로 통합하면 L6가 73→58 수준으로 완화되지만 근본 해결은 상위 층 신규 제작.

**Q3. 신규 어픽스가 가장 필요한 Layer?**
**L10 (기존 0종)** > L9 (전용 2종) > L7-B (전역 증폭 3종뿐). L10은 A/B 합쳐 최소 8~10종 신규 필요.

**Q4. DEAD 236 중 살릴 가치가 높은 것?**
- FIX(소비 코드만 붙이면 즉시 가치): **약 95종**
- REWORK(재설계 후 가치): sk* 20 + 패링→분노 3 + 포이즈 2 = **약 25종**
- MERGE(효과는 유효하나 ID 통합이 나음): 약 99종
- RC/NR(제거·보류): 약 17종
→ **실질 생존 가치 약 120종(FIX+REWORK), 통합 흡수까지 포함하면 219종의 '효과'가 재활용됨.**

**Q5. 아이템이 Passive Tree를 대체하려면 무엇이 가장 부족한가?**
1. **빌드를 바꾸는 변형(transformative) 어픽스 부재** — 현재 402종 중 메커니즘을 바꾸는 것은 elemConvert·doubleStrike·multiShot 정도. 나머지는 전부 수치 나열. Passive Tree의 키스톤(keystone)에 해당하는 "대가를 치르고 규칙을 바꾸는" 어픽스가 필요 (예: "쉴드 없음, HP 2배" / "크리 불가, 모든 타격 +40%").
2. **루프 생성 어픽스 부족** — 스택·전환·환급형(killStreak, ringDmgPerCombo, overhealShield)이 전부 DEAD. 이들이 살아야 "패링→분노→폭발→흡수" 같은 순환 빌드가 성립.
3. **시스템 축(분노/궁극기/합체) 연결 어픽스 전무** — L9/L10 공백이 곧 이 문제.
4. **어픽스 간 태그/시너지 참조 부재** — "화상 부여" 어픽스와 "화상 대상 뎀업" 어픽스는 있지만 이를 묶는 태그 체계가 없어 드랍/제작 유도가 불가능.

**Q6. Skill Synthesis와 시너지를 내려면?**
- **계열형 스킬 강화** (개별 20종 대신): "근접기/광선기/투사체기/오라기/포격기/구체기 피해 +X%"
- **합체 결과물 강화**: "합체 스킬 피해 +X%", "성급 ★N 이상 스킬 강화"
- **합체 재료 보존/강화**: "합체 시 흡수 스킬 보너스 +1", "합체 스킬 자원 소모 -X%"
- **스킬 발동 연계 프록**: "스킬 사용 시 다음 평타 강화", "같은 계열 스킬 연속 사용 시 중첩"
- 이 형태들은 L6-B(계열 강화)와 L10-B(합체 메커니즘)에 분산 배치하는 것이 자연스러움.

## 1. 402 매핑 평가

분포 자체는 "현재 게임이 무엇을 쌓아왔는가"를 정확히 반영한다: 하위(생존·조건부) 과잉, 상위(증폭·크리·분노·궁극) 공백. 매핑의 문제가 아니라 **원본 풀의 편식**이 문제다. 따라서 해결책은 재배치가 아니라 ① 하위 레이어 MERGE 정리 ② 상위 레이어 신규 설계다.

## 2. 가장 큰 문제 5

1. **상위 레이어 공백** — L7~L10 합계 42종(그중 WORKING 22), L10=0. 성장 종착부(빌드 완성 단계)에 뽑을 것이 없다.
2. **DEAD 236(59%)** — 드랍 풀 오염. 특히 w80짜리 flatPhysDmg 등 고가중치 무효 어픽스가 유효 슬롯을 잠식.
3. **L3·L6 정체성 혼합** — L3=방어+저항+회복+부활+반격(80), L6=조건부수치+프록+흡수+스킬강화(93). 층 번호만 보고 예측 불가.
4. **빌드 변화형 부족** — 402 중 순수 수치형 ~290(72%). 프록 ~40, 조건부 ~50, 루프형 ~10, 변형형 ~10. 키스톤(트레이드오프)형 **0**.
5. **시스템 축 미연결** — Synthesis/분노/궁극기를 참조하는 어픽스가 사실상 없음(rage 2종뿐). 레이어 간 상호참조(크리→분노, 분노→궁)도 0.

## 6. L3 과밀(80) 해결

원인 분해: 수치방어 17 + 동일기능 중복 17(fireDR≡fireRes 등) + 저항 12 + RC 5 + 리젠 3 + 발동생존 11 + 팔찌 7 + 엔드/아키 8.
해법: **이동 없이 MERGE(17)+RC(5)로 58까지 감량** + A/B 재정의(A=피해감소/B=회복·반격). 저항의 L4 이동안은 기각 — "L4=내 공격, L3=맞을 때" 구분이 더 중요.

## 7. L6 과밀(93) 해결

분해: 조건부뎀 35 · 처치발동 10 · 흡수 7 · 회피/기타 프록 8 · 콤보 4 · 스킬 21(sk20+skillBoost) · 엔드/아키/기타 8.
판정: A(진짜 L6) = 조건부뎀 대부분·처치·흡수·콤보 / **B(이동)** = 상태이상 대상 뎀업 6종→L4-B / **C(시스템 연결)** = sk* 계열(Synthesis) / **D** = MERGE 15건.
결과 93 → 약 60. 흡수(leech)는 L3-B 이동안도 검토했으나 "공격으로 유지하는 루프"라는 시너지 정체성이 강해 L6-B 유지.

## 9. Archetype 20종 처리

효과가 전부 기존 어픽스 복제(스탯 12·전투 8)이므로 **기본 처분 = 전량 MERGE**.
단, EXODUSER에 클래스는 없지만 **무기 7종**은 있다 — "클래스 강제"가 아닌 **플레이스타일 조건**으로의 REWORK 가치는 실재:
- 예: "대검 장착 중 스태거 +X"(arcWarrior 계승), "석궁 장착 중 관통 +X"(arcRanger), "견갑 들면 반격 +X"(arcTank), "단검류 후방타 +X"(arcAssassin), "왕관 다속성 빔 +1"(arcMage)
- 이 형태면 wtype 데이터가 이미 있어 조건 판정 구현이 쉽고, L5/L6에 자연 편입된다.
**추천: MERGE 확정 + 위 5종을 "무기타입 조건 어픽스" 신규 후보로 별도 등재**(이름 자산만 재활용). 세트 시스템은 보류.

## 10. L7 확정안

**범위: 플랫 전용(안A)이 아니라 플랫+변환·증폭(안B) — B 추천.** 플랫만으로는 A/B 슬롯을 못 채우고(플랫 10종), 증폭·변환은 다른 층 어디에도 정체성이 없다.
- L7-A (플랫): flatPhys/Magic/5속성(7, FIX), sharpAtk·brutalAtk·ruinAtk(3, KEEP) — endAtkFlat 흡수, min/max 제거
- L7-B (변환·증폭): magicDmg, atkPctAll, endAllDmg(←neckAllDmg) + **elemConvert(L4→L7-B 이관, 물리→속성 "변환"의 원형)** + 신규 2~3(예: "최고 속성으로 변환 X%", "단일 대상 증폭", "쉴드 있는 적 증폭")
- **Penetration은 L4 잔류** — 저항 관통은 속성 빌드의 종결 스탯. L4에 있어야 "속성 빌드는 L4를 판다"가 성립.

## 11. L8 확정안

구조 그대로 확정: A=크리 수치(critRate, critDmgW, 근접/마법/사격 크리 3종) 통합 후 6종, B=onCrit 6종+critMultiOnLowHP+hybCritLeech 8종. 합 14 — A/B 각 6~8로 하한선 충족하나 여유가 없어 **신규 3 권장**: "크리 시 분노 +X"(L9 연결), "저항 관통 크리", "연속 크리 시 증폭". 통합으로 작아진 것은 문제 아님 — 크리는 어차피 전 빌드가 탐내는 층이라 희소성이 곧 가치.

## 12. L9 분노 — 재활용 vs 신규

시스템 사실: 분노는 패링으로만 적립, 스페이스(대왕치기)로 소비, 기본 100 상한.
**재활용 9종**: rageMaxFlat·rageDmg(KEEP) / parryBonus·parryExplosion·recentParryDmg·onParryBurst·afterParryShield(패링=적립 수단 → "분노 적립/발동"으로 REWORK) / killStreakDmg·killStreakSpd("처치 시 분노 +X / 분노 감쇠 정지"로 REWORK — 연속처치 루프를 분노 루프로 전환)
**신규 8종 후보**:
- L9-A(경제): rageGainPct(적립량%), rageOnKill(처치 적립), rageKeepOnSpend(소비 시 X% 보존), rageStartCombat(전투 시작 보유)
- L9-B(상태 메커니즘): rageAtkSpd(분노 50% 이상 시 공속), rageDR(분노 보유 중 DR), rageLeech(분노 중 흡혈), rageSpendNova(대왕치기 시 추가 폭발)
구현성: 전부 기존 P.rage 훅 확장으로 가능(신규 시스템 불필요). 목표 풀 17.

## 13. L10 궁극기 — 신규 설계 (목록만)

전제 결정 필요: "궁극기"의 정의. **추천 = ult:true 필살기(Z)** 기준. 대왕치기는 분노 소비기이므로 L9 소속, 데빌포스(Q)는 별개 자원.

구현 가능형 (기존 스킬 시스템 훅 확장):
- L10-A: ultDmg(필살기 피해%), ultCdRed(필살기 전용 쿨감 — 일반 쿨감과 분리), ultCostRed(MP 30% 소모 감소), ultRange(범위%), ultStun(경직/스턴 연장)
- L10-B: onUltKillReset(필살기로 처치 시 쿨다운 X% 환급), onUltCastBuff(시전 후 X초 강화), onUltRageFill(시전 시 분노 +X — L9 연결), onUltCleanse(시전 시 정화/무적 프레임)
시스템 추가 필요형 (2단계):
- ultCharge(게이지 충전식 전환 전제 — 현재는 쿨다운제라 불가), ultMechMod(스킬별 메커니즘 변형 — 오망성 흡인/폭발 전환 등, 필살기별 분기 코드 필요), ultDouble(2회 연속 시전)
목표 풀 12 (구현 가능형 9 우선).

## 16. REMOVE_CANDIDATE 7종 최종 검토

- **resMax 5종: 제거 확정 권고.** 저항 캡 시스템 부재. 대체 아이디어 1건만 기록: DR_CAP(75%)은 실존하므로 "DR 상한 +1~5%" 신규(drCapUp)는 엔드게임 가치 있음 — resMax의 정신적 후계.

## 17. Passive Tree 대체 가능성

```js

{id:'poisonDot', type:0, tiers:[...], unit:'dps', slots:['wpn'], group:'poison', weight:100,

```

- 추출물(어픽스석): 신규 아이템 타입 `{type:'affixStone', affixId, tier, value}` — layer는 정의 파생. INV.bag 격자 호환 위해 slot:'stone' 유사 처리.

- "동일 Layer 슬롯에만 이식"은 정의 조회만으로 판정 가능 — 추가 필드 불필요.
- 저단 아이템 가치: 저단도 해당 층 어픽스는 최고 rollTier 가능(현행 유지) → 추출 공급원 성립.

## LOCK-10. Migration 전략 (구현 안 함)

**핵심: 마이그레이션하지 않는 마이그레이션 — 병행 세대(generation) 방식.**
- `layerLv` 없는 아이템 = 구세대: 기존 로직 그대로 동작(롤·표시·전투). 강제 재배치 없음 → 20슬롯 규칙 위반 아이템이 생기지 않음.
- 신규 드랍부터 layerLv 부여. 리롤(rerollAffixes)은 아이템 세대 판별 후 분기(구세대는 구 롤 유지 — 세대 승격은 별도 콘텐츠로).
- 위험 점검: 장착/창고/월드드랍(직렬화 전체 보존 — 필드 추가만이라 안전) / 리롤(세대 분기 필수 — 미분기 시 구아이템이 신규 규칙으로 돌변) / 강화·결정(별도 필드라 무관) / DROP 7종(로드 시 정의 부재 → 어픽스 무효·표기 잔존: `_fixItem` 체인에 고아 정리 1줄 추가) / DEMO·EA(sed 플래그 3종은 어픽스와 무관 — 동기화 절차 불변).
- rollAffixes._c 캐시가 layer 필터를 반영하도록 캐시 키 확장 필요(구현 시 주의점으로 기록).
