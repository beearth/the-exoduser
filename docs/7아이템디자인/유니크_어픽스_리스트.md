## C. 신규 후보 구현 체크리스트 (부위 확정 후)

1. `UNIQUE_SPECIAL`에 슬롯 키로 항목 추가 (`roll` 사용). U-N02는 `%` 표기라 툴팁에 `{p}` 치환 추가 필요 (현재는 `{s}`만 지원).
2. 효과 코드: U-N01 분노 래치 + 쿨 회복 / U-N02 경로 판정 + 디버프 + `hurtE` 곱 + 디버프 타이머 감소(`e._shockDRT` 옆) / U-N03 `_fireKiSlashCrescent` 피해식에 `×(1+_uEq('_uKiChargeDmg'))` (차징 단계 조건).
3. 하/중/상옵 표기: 툴팁에서 roll 구간 비율로 라벨 계산.
4. 번역: 새 문구 `번역대상_전체목록.md` 등록 + 전 언어 lang 파일 반영.
5. 문서: 이 파일 상태를 "구현"으로 갱신 + `exoduser-item-system-full.md` 유니크 표에 행 추가.
6. 테스트: 분노 에지 1회 발동 / 쿨 회복량 / 경로 판정 / 디버프 배율·지속·갱신 / 전류장판 중첩 / 차징 단계별 배율(0단 미적용).
