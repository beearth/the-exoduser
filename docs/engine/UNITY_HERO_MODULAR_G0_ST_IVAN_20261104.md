## 1. 공통 조립 계약

- 아래 S/I 번호는 **조립 기능 단위**다. Tripo 메시 개수와 1:1이라는 뜻이 아니다. 수령 때 `원본 메시명→S/I 번호→뼈→재질` 대응표를 만들고, 양쪽 파트는 미러 복제만으로 확정하지 않는다. 원본 생성 파일은 덮어쓰지 않고 실제 조립 프로젝트에서 수정한다.
- 금속·단검·총·허브·통·버클·메달은 각 조각이 한 뼈 100%. 두 뼈에 걸치는 판은 관절에서 나누고 위 판으로 아래 판 경계를 덮는다. 판 전체를 혼합 스킨하지 않는다. 판금 늘림은 전사 §6-1대로 최대 1.15배, 초과하면 파트 형상 재제작.
- 몸 바탕(피부·속옷)과 천·머리만 혼합 가중치. 최대 4개/정점, 합 1, 무가중 정점 0. 천·포니테일에 다리 뼈 가중치 0. 옷의 고정 뿌리만 몸통/Hips에 연결하고 끝은 전용 체인.
- 원본 Humanoid 뼈 이름·부모 구조 24개는 §3대로 보존하고 길이 수정 후 Avatar를 다시 확인한다. 보조뼈·소켓은 Humanoid 매핑 밖이며 모두 scale=(1,1,1). 소켓의 위치·회전 오프셋은 수령 파트 정렬 후 기록한다. 아래 이름·부모는 설계안이며 현재 GLB에 이미 존재한다고 주장하지 않는다.
- 좌우는 캐릭터 기준. 표의 L/R은 두 개의 독립 파트·소켓. `Spine02→Spine01→Spine`은 아래→중간→위 척추다. Unity Humanoid의 Spine/Chest/UpperChest와 원본 이름을 혼동하지 않는다.
- 재질은 전사의 금속·가죽·천·피부 4분류를 공유하되 캐릭터 팔레트는 유지한다. 실버테일 은발·흑철, 아이반 피부·남색 천·탁한 황동·약병 색을 전사 색으로 맞추지 않는다. 머리카락은 천 분류 안의 별도 텍스처 영역으로 처리 가능. 전체 25k~40k tri 목표, 잔점 텍스처 0.

## 4. 비율표 — 조립 전에 수정할 것

- H는 캐릭터 보드의 모델 키(실버테일 1.72m, 아이반 1.85m). 화면 배율은 두 영웅 모두 ×0.87이며, 실버테일까지 1.61u로 키우지 않는다. 새 머리에서 머리카락 꼭대기가 달라져도 모델 H와 해부학적 두피 높이를 혼동하지 않는다.
- 위팔=Arm→ForeArm, 아래팔=ForeArm→Hand, 허벅지=UpLeg→Leg, 정강이=Leg→Foot의 rest 관절 간 3D 거리. 좌/우를 평균내 숨기지 않고 나란히 적는다.
- 손 길이는 `Hand` 가중치≥0.5인 정점 중 아래팔 진행 방향 투영이 가장 먼 정점을 골라 손목→그 정점의 3D 거리로 잰 **메시 손끝 추정**. 검증된 손가락 뼈 길이가 아니다. 실버테일 char1 정점 L56642/R68451, 아이반 L76186/R84199. 이 ID는 이번 Blender 5.2.3 임포트의 char1 기준이며, 감면/재임포트 메시의 ID와 혼용하지 않는다.
- 팔 내린 손끝=(어깨 Y−위팔−아래팔−손)/H, 팔 벌린 폭=(양쪽 Arm 관절폭+좌우 위팔·아래팔·손)/H의 **완전 신전 기하 추정**. 현재 A포즈 손끝 Y/폭을 그대로 합격선과 비교하지 않았다. 손목 꺾임·주먹/펼친 손 차이는 후속 straight-hand 포즈에서 재측정.

## 6. 수령 후 실행 순서·파이프라인 교훈

1. Tripo 실버테일 2차 15파트(전사 기록 task `214c3a56`), 아이반 19파트(`d381fefe`)와 머리 교체 15파트의 실제 PC 경로·메시명·앞/뒤를 확인한다. **측면 입력은 오른쪽 칸**. 실버테일 1차처럼 등에도 얼굴·가슴이 생기면 수령 즉시 FAIL.
2. 얼굴·목 경계·손끝·두피·턱 랜드마크를 지정해 §4를 다시 채운다. 위팔/어깨·머리·다리 목표 결정 후 기존 뼈 이름/부모를 보존해 길이를 고친다. 옛 단일 메시를 잘라 살리지 않는다.
3. S/I 대응표대로 새 파트를 정렬한다. 금속 100%·천 독립 체인·등 소켓을 먼저 확인한다. 팔판 늘림 1.15배 초과는 재제작. 비율을 못 맞춘 파트에 텍스처부터 입히지 않는다.
4. 관절 포즈와 허브 접힘·배낭·총 조합으로 BVH 수치와 보이는 틈/관통을 함께 확인한다. 허용표에 없는 rest 맞춤 결함은 면제하지 않는다. 같은 핵심 결함 2회면 방법을 바꾼다.
5. 합격 조립본에만 Tripo 텍스처→파트별 아틀라스/톤 보정. 기존 전사 교훈의 업로드 각도 Y+90°는 뷰포트 정면을 실제로 확인한 뒤 적용한다. 이번 G0에는 생성·비용 승인 없음.
6. 무료 기존 경로로 Unity 임포트·컴파일, Mac에서 §5의 34°·1x/3x·10초 무음 실게임 판정. 전사 Mac 미판정은 두 영웅의 PASS 근거로 쓰지 않는다. 캐릭터 보드/사용자 실행본 변경은 담당 총괄 후속 범위.
