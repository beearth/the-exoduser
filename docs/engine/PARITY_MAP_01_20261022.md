## 검수·성능

원본 청크 바이트 동일 64/64. 기존 테스트는 명시적으로 `--map11=off`에서 원래의 전체 판정을 유지한다: test_map_look 16/0, test_p3002_spawn_holes 298/0, test_p2003a_lighting 10/0. test_map_look은 **레거시 비제품 표현 강화 전용**으로 재분류했다. 제품은 test_parity_map_01(원본 벽 샘플 197xx·시작·14소환굴·지역 분모·40px 경로·줌·컨셉 미상주)을 별도로 검수한다. 최종 제품 19,771개/실패0(컨셉 texture cache 미상주 포함). 정확한 출력은 checks.json/tests-final.log를 따른다. PC 테스트는 수정하지 않았다.

상태 주입 없는 E2E는 기존 UI 생성/Space 홀드/레슨의 실제 건너뛰기 버튼/W·LMB 입력만 사용한다. 좌표·HP·경험치·아이템·보스 신호 주입 0. 자연 boss→clear→lobby 미완주이므로 NOT_READY. 초기 진단 1회에는 생성 중인 새 PNG import가 완료되지 않았고, 재진입 2회에는 기존 격리 기록/active-save 계약으로 새 캐릭터 진입이 거부되었으므로 완성 검수로 세지 않는다. 최종 실행은 새로운 격리 namespace의 빈 슬롯을 선택하며 삭제하지 않는다. 실제 field 진입 후 30초 W/LMB 입력에서 (4020,7420)→(4017.114,7044.465), 처치0·HP0·provider_ready=true를 관측했다. 결과는 NOT_READY다. 요청한 단회 검수와 별개로 이 진단 재시도가 발생했음을 숨기지 않는다.

GUI 성능 1회: 1920×1080 시작 필드 10초/3177프레임, focus lost0, p95 5.032ms/p99 5.721ms, draw137, Godot reported video memory p95 2,671,485,683 bytes / texture 2,635,053,299 bytes. game_on=true·적0이므로 밀집 전투/전체맵/PC 성능은 미측정이다. 이 단회 측정 뒤 북문·포탈 Sprite2D 3개와 원본 시체나무 tone/나무 알파 셰이더 보정을 추가했으므로 최종 commit 전체 비용 재측정은 하지 않았다. macOS 통합 메모리에서 엔진 보고치를 전용 VRAM 실측으로 확대 해석하지 않는다.
