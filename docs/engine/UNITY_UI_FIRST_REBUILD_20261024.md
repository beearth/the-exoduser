# Unity UI/UX 우선 이식 · 후속 재제작 — 2026-10-24

사용자 최신 추가 지시: HUD가 화면에 붙어 있는 일체감을 만들도록 [UI 도킹 작업](UNITY_UI_DOCK_20261024.md)을 인트로와 병렬로 진행한다. HUD·인벤토리·독립 검토의 소유 파일을 분리하고 기존 EXODUSER 아트를 재사용한다. 이전의 로비 단독 우선 지시는 이 추가 병렬 작업을 금지하는 의미가 아니다.

최신 세부 우선순위: 사용자 “일단 게임 로비부터 인트로 시네마틱같은것들만 잘 옴겨”에 따라 **게임 실행 첫 화면·로비·인트로/시네마틱**을 먼저 이식한다. 현재 단위 [UNITY-LOBBY-01](UNITY_LOBBY_20261024.md)의 실제 화면/영상/음향/입력 흐름을 우선 검수하며, 아래 일반 UI 후보 목록이 이 순서를 덮어쓰지 않는다.

사용자 확정: “그러니까 일단 그것들만 잘 이식하고 유니티로 세로맵 모션 임펙트등 거의 다 다시할 생각하고”. 앞 대화의 UI/UX·기존 아트/데이터 재사용을 먼저 완성하고, 맵·모션·이펙트는 이후 Unity에 맞게 대부분 새로 제작하는 방향이다. ‘세로’는 문맥상 ‘새로’로 이해하며 세로 화면/세로형 맵 지시로 해석하지 않는다.
