## 0. 무엇을 바꾸나 — 한 줄

웹 독버섯 거인은 드루이드 기술 풀을 거의 그대로 빌린 "갓 쓴 드루이드"라 고유한 싸움이 없다. 리모델링은 **"자기 밭만 살린 농부"** 하나로 묶는다. 거인은 아레나의 이랑에 **씨를 뿌리고, 6초 뒤 반드시 수확**한다. 플레이어가 그 사이 싹을 베어 두면 수확은 허탕이 되고 큰 반격 틈이 생긴다. 목숨 2개 = 페이즈 2개, 기술 10개. 쓰러지면 스스로를 다시 밭에 심고, 남아 있던 싹을 빨아들여 껍질(쉴드)을 만든다.

**이 보스만의 한 가지: 씨 뿌리기 → 6초 → 수확.** "밭을 먼저 갈아엎어라"를 배우는 보스다. 마지막 대사 "…아직 거둘 때가 아닌데."(STY-12, 번역 No.3345)가 이 규칙에서 그대로 나온다.

## 1. 지키는 것 (바꾸지 않음)

- 이름 "독버섯 거인"(`HELL_BOSSES[0][1]`, 코드가 진실), 원형 = **농부**(STY-D8 확정): 가뭄에 마을 물길을 막아 자기 밭만 살렸고, 썩은 땅에 스스로를 심어 몸이 밭이 되고 갓이 수확물이 됐다(`CH1_STORY_SPINE_20261027.md` §3).
- 실루엣 축(디자인 바이블 `BOSS_01_FOREST_NORMAL_POISON_MUSHROOM_GIANT.md`): 검은 갓 + 줄기 몸 + 곤봉, 주먹·발차기 언어 없음. 흔적: 곤봉 = 농기구 자루가 굳은 것, 갓에 박힌 녹슨 낫, 주변 바닥 이랑. 3D 외형(BX-12)은 이 축을 따른다.
- 마지막 사망 대사 1줄 "…아직 거둘 때가 아닌데." — 웹 키 체계 그대로 **`die1`**(`_BOSS_LINES.die1`, 호출 `_bossLine('die'+si)`, si=1), 번역 No.3345. 마지막 목숨이 끝날 때만 띄운다(웹도 부활 판정이 걸린 사망에서는 띄우지 않음). 등장 대사는 없다(STY-12에 `intro1` 없음, 새로 만들지 않음).
- 플레이어 쪽 규칙: 패링·돌진·방패·포이즈(2_3 수정 금지), 에너지쉴드 계약(CLAUDE.md), 피해 공식, 독 상태(EL.P) 규칙.
- 보스 AI 틀: 이식된 `_bossAI` 점수·콤보·쿨다운 엔진 + RM-B0 공통 실행 틀(보스별 기술 세트·전용 규칙 partial). 기술표·페이즈표·목숨 규칙만 독버섯 거인 전용으로 갈아 끼운다.
- 보스 레벨·기준 HP·ATK: mkEn 보스 공식 그대로. si1이므로 `H = floor(H0 × 1.02)`(si0 대비 +2%), ATK `floor((75+L×2.9)×.6×dm)` 동일.

- **총 유효 체력 = 기준 HP × 1.55**(1.0 + 0.55). 웹 확률 부활(revPts·125%+…)은 **이 보스에 한해** 쓰지 않는다(RM-B1과 같은 원칙). 리메이크 플래그를 끈 si1은 지금 그대로다.
- **목표 전투 시간**(초기값, RB2-5에서 조정): 1-2 도달 기준 장비·레벨(Lv 10~15, 1-1 보상 장비 + 필드 드랍)로 **P1 55초 / P2 40초, 합계 1분 35초 ± 25초**.
  - 근거: 장 중간 보스라 1-1(2분 10초, 기준 HP × 2.0)보다 짧게. 체력 배수 1.55/2.0 ≈ 0.78 → 같은 장비라면 약 1분 40초. 1-2는 플레이어 장비가 조금 나아 1분 35초를 목표로 둔다. 크게 벗어나면 기준 HP 배율을 고치고 목숨 비율(1.0/0.55)은 유지한다.
- **쓰러짐(1회째, 120틱)**: 보스 무적, AI 정지, 보스가 만든 위험물(장판·독물·포자 구름) 전부 제거. 단 **싹은 남는다**. 강제 수확 예약(§3.2)은 취소된다.
  - 쓰러짐 120틱째에 남아 있는 싹을 **전부 빨아들여** P2 쉴드가 된다. 플레이어는 쓰러짐 동안에도 싹을 벨 수 있다(쉬는 시간의 할 일 = 드루이드의 "뿌리 3타"와 다른 방식).
  - 흡수 연출: 싹마다 거인 쪽으로 뿌리 줄이 당겨지고(쓰러짐 마지막 40틱), 120틱에 싹이 꺼지며 쉴드가 찬다.
- **에너지쉴드**: P1 0. P2 진입 때 **목숨 HP × (10% + 5%p × 흡수한 싹 수)**, 흡수 수는 최대 4로 센다(최대 30%). 쉴드→HP 순서(계약 그대로).
- **두 번째 쓰러짐**: 침강·도주 같은 특수 연출 없음, 일반 처치 경로(보상·StageFlow 출구). 남은 싹·독물·구름은 시들어 사라지고 피해를 주지 않는다.

## 4. 텔레그래프 규칙

- **페이즈가 올라도 텔레그래프는 짧아지지 않는다(TeleM 1).** 빨라지는 것은 쿨다운 배율(P1 1.0 / P2 0.8)과 이동 속도(P1 1.0 / P2 1.15 — 갓을 잃어 가벼워짐)뿐이다. 웹 TeleM(최저 0.25)은 쓰지 않는다.
- 표시 3종(색은 디자인총괄 아트 바이블에서 확정, 독 색은 `UNITY_ART_BIBLE_V1_20261026.md` §6 색상각 40~65°):
  - **① 패링 가능 근접 섬광**: 1·2번. 곤봉 끝 섬광 1회 + 짧은 둔탁한 나무·쇠 소리.
  - **② 바닥 예고**: 3·4·5·7·8·9·10번. 어두운 독액 얼룩이 점점 진해짐. 원색·네온 금지.
  - **③ 잡기류 긴 예고**: 이 보스는 쓰지 않는다(잡기 없음). 대신 수확(7번)이 70f로 가장 긴 예고 — 보스 자세(낫을 치켜듦) 고정 + 싹마다 ②.
- **피해 없는 표시**: 씨앗이 떨어질 자리(6번)는 ②가 아니라 작은 씨앗 그림자로 따로 그린다(밟아도 피해 없음을 처음부터 다르게 보이게). 싹의 자라는 단계는 예고가 아니라 물체 모습이다.
- **동시 예고 최대 2개.** 셈: 한 번의 수확 = 1개(싹 수와 무관), 물길 돌리기 띠 2줄 = 1개, 씨앗 표시·싹은 세지 않음. 보스는 이미 예고 2개가 떠 있으면 ② 기술을 새로 시작하지 않는다(① 근접은 가능).
- 물길 돌리기(5번)가 유지되는 240f 동안 다른 ② 기술은 1개까지만 겹친다(위 규칙 그대로).

## 5. 아레나 요구 (맵 총괄 전달용 — 보스전 총괄이 모아서 전달)

- **지름·충돌·진입·출구·보스 시작 좌표는 현행 그대로**(D8). si1 → `SiToHell` 0 → `BossArenaLayout` 원형(Type 0): 격자 128×108(40px 타일, 5120×4320px), 중심 타일 (64,54), 원 반지름 51타일(2040px), 진입 타일 (64,103), 출구 타일 (64,2), 보스 시작 타일 (64,54). 1-1과 같은 판이다.
- **이랑 5줄**(필수, 판정에 쓰임): 아레나 중심 기준 세로 오프셋 **−960 / −480 / 0 / +480 / +960px**의 동서 방향 띠, 폭 160px. 바닥 높이는 그대로(걸을 수 있음, 충돌 없음). 씨앗 자리(6번)·물길 띠(5번)가 이 좌표를 쓴다. 시각은 "썩은 밭의 이랑": 갈아엎은 흙 고랑, 고랑 사이 두둑에 시든 작물 그루터기. Core는 이 다섯 좌표를 데이터로 가진다(맵 메시와 별개). 진입로(남)·출구(북)는 이랑을 가로지른다.
- **서쪽 수문**(시각, 판정 없음): 아레나 서쪽 가장자리(원 밖 외곽)에 돌·나무로 막힌 낡은 수문과 마른 물길. 물길 돌리기(5번) 예고 때 여기서 독물이 넘쳐 이랑으로 들어온다. 출구(북)·진입(남)을 가리지 않는다. 서사 흔적: "마을 물길을 막아 자기 밭만 살렸다".
- **엄폐물 없음**(의도): 드루이드의 뿌리 기둥과 대비되는 트인 밭. 땅 울림(10번)은 구르기로 넘는 기술이라 막을 것이 없어야 한다.
- **바깥 수로(보스전 총괄 결정 2026-10-28, 맵 총괄 A1 명세 대조 뒤)**: 1-2는 같은 원형 판이지만 1-1의 독액 수로(`M_ToxicFlow`)를 그대로 흐르게 두지 않는다. 같은 고리 자리(걷는 원 바깥 r 2060~2200px)는 평소에는 **마른 물길**이다. 독물은 5번 물길 돌리기 예고(70f) 동안 서쪽 수문에서만 넘쳐 들어온다. 맵은 "수문 흐름 0~1" 파라미터 하나를 노출하고, Timeline 연결은 보스 쪽이다. 이유: 마을 물길을 막아 말렸다는 서사이고, 평소에 독이 흐르면 5번 예고가 묻힌다. 기둥은 Core 세트 `PillarCount` 0을 그대로 읽는다(맵이 4개를 기본으로 두지 않는다).
- 외곽(보행 불가): 버섯 군락(1-2 장소 의미 "숲이 먹은 자들을 키우는 밭"), 사람 형체가 비치는 묵은 버섯 둔덕. 바닥 흙은 1-1과 같은 검붉은 흙 계열에 이랑 패턴. 독 점광은 아트 바이블 V1 §6·L-2 ③ 범위.
- 카메라: 보스전 줌 0.80(이식본 그대로, Cinemachine).

### 6.2 3D 모델·애니메이션 메모 (보스 보드 §8.3~8.5 경로, 순서 3번째)

- **리깅 방식(보스전 총괄 결정 2026-10-28)**: Meshy 리깅은 인간형 전용이다(캐릭터 총괄 조사). 그래서 **Meshy 인간형 리그**를 쓰고, 인간형 골격에 없는 **갓 뼈 2개(부풀기·흔들림)와 낫 뼈 1개는 Unity에서 추가**한다. 몸은 줄기 몸통 + 뿌리 다리 2개 + 팔 2개(오른손 곤봉)로, 인간형 리그에 그대로 맞는 구성이다. P2 부러진 갓은 같은 리그에 다른 갓 메시를 단다(낫 뼈는 P2에서 숨김). Ludo Pro는 쓰지 않는다.
- **외형 DESIGN LOCK 요구**: 아직 없다. 보드 §8.3 ⓪에 따라 새로 써야 한다(제안 경로 `docs/11내러티브·로어디자인/POISON_MUSHROOM_GIANT_DESIGN_LOCK.md`, 판정 디자인총괄). 고정할 사양: 검은 갓 + 줄기 몸 + 곤봉 실루엣(주먹·발차기 언어 없음), 곤봉 = 굳은 농기구 자루, 갓에 박힌 녹슨 낫(P1만 — P2는 낫이 빠진 부러진 갓), **두 다리(뿌리 다리)·두 팔, 인간형 리그 호환**(Meshy 인간형 리깅이 붙는 비율·관절 위치), 사람 형체·얼굴 노출 없음, 독 발광은 아트 바이블 V1 §6 색상각, 점묘·잔점 금지. "악역도 매력적으로" 원칙은 실루엣·자세·갓 질감으로. 작성은 3D 제작 세션 몫이고 이 명세 범위 밖이다.
- **클립 목록**(보드 §8.4 기준): 기본 4(대기·걷기·제자리 회전 좌·우) + 기술 10×3(1·2·9번 연타는 공유) + 반응 3(가벼운 피격·포이즈 붕괴 90f·패링당함) + 목숨 전환 2(쓰러져 다시 심기 120f 루프·새 갓 돋으며 일어서기) + 끝 1(갓부터 썩어 무너짐) + 싹 3단계·익음·터짐(소품 애니메이션) ≈ **40클립 + 싹 소품 5**. Core 프레임이 정답이고 Animator는 재생 속도만 맞춘다(M6).
- 유료 비용(시트·메시·애니메이션)은 사용자 확인 대상(보드 §8.3).
