## 2. oracle (`unity/Tools/dash-parry-oracle/`)

- 생성: `export.cjs --source G:/exoduser/game.html` → `oracle.json`(5.5MB). 줄 번호가 아니라 **앵커 문자열**로 블록을 찾고 줄 범위·sha256을 `oracle.json.blocks`에 기록, 앵커가 없으면 `source drift`로 즉시 실패, `--check`는 블록 해시가 다르면 거절(종료 코드 1). 추출 당시 game.html sha256 `d73d6919…2c8c5`(65,695줄, 작업 트리 파일 — 미커밋 수정이 섞일 수 있어 블록 해시가 기준).
- 실행: `run.cjs --project <unity> --out <runs> --label <이름>` → .NET 8, `DashParryTests.csproj`가 Core의 6개 파일(Js/ParryRules/ParryRewards/ChainDash/PlayerPoise/EnemyPoiseRules)만 컴파일. 허용오차 부동소수 상대 1e-9, 정수·불리언·문자열 정확 일치.
- **손으로 옮긴 기대값 0** — 모든 `out`은 원문 블록 실행 결과. 래퍼는 `scope`에 선언된 이름만 돌려주고 나머지는 `ReferenceError`(숨은 스텁 없음). 무동작 허용 목록은 `_T`·`_addBoom`·`_addSkProf`·`_autoShieldThrow`·`_cancelProjCharge`·`_dark02Impact`·`_gpVibrate`·`_petOnParry`·`_petSayCD`·`_playSwordBack`·`_r`·`_rainbowImpact`·`_startSilvertailAttackMotion`·`addParts`·`addTxt`·`doHitFlash`·`playSample`·`poolPart`·`showPH`, `SFX.*`(오디오/텍스트/파티클/펫 훅뿐; 수치에 영향 없음). 상세는 `README.md`.
- 격자: 축마다 단일 값 변화 + 시드 고정 난수 조합(`grid()`), 작은 섹션은 전수 곱. 장비 값 0/경계/최대, 단 1/2/3, 보스/일반, 빨콩/무지개/일반, 창 경계 ±1프레임 포함.
