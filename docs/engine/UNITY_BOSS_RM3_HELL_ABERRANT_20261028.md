## 0. 무엇을 바꾸나 — 한 줄

웹 지옥기형은 웹 공용 풀에서 10개를 빌린 "콩 탄막도 쏘는 짐승"이고, 페이즈는 HP 구간 5개, 부활은 확률 판정이다. 리모델링은 **"숲을 빠져나가려는 것을 쫓아 물어 오는 어미 짐승"** 한 가지 정체성으로 묶는다. 탄은 하나도 쏘지 않는 순수 근접 사냥꾼이고, 기술은 8개, **목숨 2개 = 페이즈 2개**다. 첫 목숨을 잃으면 쓰러지지 않고 **아레나 가장자리의 빈 둥지로 뛰어가 그 앞에 엎드린다.** 일어설 때는 네 발 사냥 짐승에서 두 발로 선 광분 짐승이 된다.

### 0.1 이 보스만의 한 가지 — 빈 둥지

아레나 서쪽 가장자리에 **빈 둥지**가 있다(서사 STY-D8: 어머니, 굴 안에는 아이가 아닌 빈 둥지만). 전투 규칙 두 개가 이 한 점에 묶인다.

1. **굴로 물어 가기**(6번): 잡히면 둥지 쪽으로 끌려간다. 둥지에 닿기 전에 빠져나오지 못하면 둥지 앞에 내동댕이쳐진다. 맵의 "끌려간 자국"(STY 1-3 장소 의미)이 실제 규칙이 된다. 플레이어는 둥지에서 먼 쪽에서 싸울수록 안전하다는 것을 배운다.
2. **빈 둥지 앞의 애도**(목숨 전환, §2): 첫 목숨이 끝나면 둥지로 뛰어가 3초 동안 등을 보이고 엎드린다. **무적이 아니다.** 이때 준 피해는 두 번째 목숨에서 깎인다(상한 있음). 드루이드의 "무적 쓰러짐 + 뿌리 3타 보상"과 반대로, 보상은 "등을 보인 어미를 칠 것인가"라는 위치·결단으로 얻는다.

## 1. 지키는 것 (바꾸지 않음)

- 이름 "지옥기형"(STY-D10), 원화의 꼬리 실루엣(꼬리 = 등에 업던 포대기가 살과 붙은 것, STY-D8), 마지막 사망 대사 **"…밥 먹을 시간인데."**(EN "…It's time to eat.", 번역 No.3346, STY-12). 이 대사는 최종 사망(두 번째 목숨 끝)에서만 띄운다.
- 플레이어 쪽 규칙: 패링·돌진·방패·포이즈(2_3 수정 금지), 에너지쉴드 계약(CLAUDE.md), 피해 공식.
- 보스 AI 틀(이식된 `_bossAI` 점수·콤보·쿨다운 엔진)은 그대로 쓰고, **기술표·페이즈표·목숨 규칙만** 지옥기형 전용으로 갈아 끼운다. 끼우는 자리는 RM-B0(보스 공통 실행 틀)이 만든다.
- 기준 HP·ATK = 이식본 mkEn 보스 공식 그대로(si2는 `×(1+2×.02)=×1.04`). 리메이크는 목숨별 비율만 정한다.
- 아레나 지름·타일 충돌·진입·출구 좌표(§5).
- 웹에서 버리는 것: si2 얼굴 기술 score+2, si2 전조 ×1.4(대신 §4의 고정 최소 예고를 쓴다), 확률 부활(125%+…·포인트 소모 — **지옥기형에 한해** 쓰지 않음, 드루이드와 같은 판단), 기술 이름 떠오르는 글자(`🦅 도약!` 등 이모지 문구 — UI 규칙상 쓰지 않고 예고 3종 표시로만 알린다).

## 2. 페이즈 = 목숨 (HP 곡선)

| 페이즈 | 목숨 | 체력(기준 HP 대비) | 몸 크기 | 쉴드 | 성격 | 들어갈 때 연출 |
|---|---|---|---|---|---|---|
| P1 사냥 | 1 | 100% | 100% (네 발, 낮은 자세) | 0 | 맴돌다가 덮친다. 거리 300 안팎을 유지하며 틈을 본다. 읽기 쉬운 단타와 도약 | 아레나 중앙에서 빈 포대기 끝을 핥다가 고개를 든다(60f, 무적, 공격 없음) → 낮은 울음 → 시작 |
| P2 굶주림 | 2 | 60% | 115% (두 발로 일어섬, 포대기 꼬리가 풀려 길어짐) | 0 | 곧장 파고든다. 내려찍기·울부짖음·발톱 3타째 물기가 더해진다 | 빈 둥지 애도(아래) → 둥지 앞에서 **울부짖음**(8번, 45f 예고) 1회 → 시작 |
| 끝 | — | 0 | — | — | — | 둥지 쪽으로 기어감(최대 90f, 무적, 공격 없음) → 쓰러짐 → 대사 "…밥 먹을 시간인데." → 일반 처치 경로(보상·출구 개방) |

- **총 유효 체력 = 기준 HP × 1.6**(1.0 + 0.6). 예: Lv10·난이도 기본에서 기준 HP 121,193 → P1 121,193 / P2 72,715.
- **에너지쉴드 0.** 마법 보호가 없는 짐승이다. 드루이드(P2·P3 15%)와 구분하고, 중간 보스라 전투를 짧게 하기 위함. 웹 mkEn이 만드는 쉴드(eShield=H)는 리모델링 켠 경우 0으로 덮는다.
- **목숨 전환 — 빈 둥지 애도:**
  1. P1 체력 0 → 즉시 공격·예고 전부 취소, 둥지 지점(§5)으로 **도약 45f**(덮치기와 같은 포물선, 착지 피해 없음, 도약 중 무적).
  2. 둥지 앞에서 **애도 180f(3초)**: 등을 아레나 중앙 쪽으로 보이고 엎드려 둥지를 코로 민다. 공격 없음, **무적 아님**, 넉백·경직 받지 않음.
  3. 애도 중 받은 피해는 **P2 목숨 체력에서** 깎는다. 단, P2 체력은 애도 피해로 **P2 목숨 체력의 70% 아래로 내려가지 않는다**(최대 30% = 기준 HP의 18%까지).
  4. 애도 끝 → 몸 115%로 일어섬(Timeline 30f, 무적) → 울부짖음 예고 45f → P2.
- 목표 전투 시간(초기값, 플레이 테스트로 조정): 1-3 도달 기준 장비·레벨(1-1·1-2 클리어 직후의 시작 무기+필드 드랍, 초기 가정 Lv 12~18 — RB3-5에서 실측 레벨로 고친다)로 **P1 55초 / 전환 5초 / P2 40초, 합계 1분 40초 안팎(목표 1분 40초 ± 25초)**.
  - 근거: 장 중간 보스는 1-1(2분 ± 30초)보다 짧게 권장(공통 지시 §2). 드루이드 명세의 "유효 체력 2.15(쉴드 포함) → 2분 10초" 비율(약 60초 / 기준 HP 1.0)을 그대로 대면 1.6 → 약 97초. 애도 보상(최대 0.18)을 다 받으면 약 87초, 못 받으면 약 97초라 범위 안이다.
  - 시간이 크게 벗어나면 기준 HP 배율을 고치고, 목숨 비율(1.0 / 0.6)과 애도 상한(70%)은 유지한다.

**물어 가기 규칙(6번):**
- 잡은 순간 플레이어를 입 앞에 고정하고, 보스가 **둥지 지점(§5) 쪽으로 5px/틱**으로 뒷걸음질쳐 끈다. 최대 120f(최대 600px).
- 끄는 동안 20f마다 ATK×0.3(합 최대 6회).
- **빠져나오기**: 끄는 동안 보스가 3번 맞으면 놓친다(드루이드 §8.4와 같은 Core 해석, 입력 키 직접 읽지 않음). 놓치면 보스 **비틀거림 40f**(반격 틈).
- 둥지 반지름 150 안에 닿으면: **둥지 앞 내동댕이** ATK×2.2 KB18, 뒤이어 보스는 둥지 앞에서 30f 멈춘다(먹이를 놓는 동작).
- 120f가 끝날 때까지 둥지에 못 닿으면: 그 자리에서 던지기 ATK×1.5 KB14.
- 보스 회복 없음(드루이드와 구분).

**사냥 본능 규칙(기술 아님, AI 선택 규칙):** 플레이어가 보스에게서 700 이상 떨어진 상태가 180틱(3초) 이어지면, 다음 기술은 **덮치기**(쿨다운이 남아 있으면 **사냥 돌진**)를 쿨다운을 무시하고 1회 강제한다. 예고 길이는 그대로다. 숲을 빠져나가려는 것을 쫓는 짐승(STY 1-3 "사냥터")이자, 멀리서만 싸우는 플레이를 끌어당기는 장치다. 울부짖음 최대 반지름(1100)과 함께 "멀리 있으면 쫓기고, 붙으면 고리를 넘어야 한다"는 거리 판단을 만든다.

빼는 것(웹 si2 10기술 중): `beanStorm`(빨간콩 탄막 — 탄, 원색 예고, 짐승 정체성 밖), `fan`(확산탄 — 탄), `spin`(웹 R500 + 탄 — 꼬리치기와 역할 겹침), `sweep` 전방형(꼬리치기 후방형으로 흡수). 더하는 것: `grab`→6번, `shock`→8번.

**이 보스는 탄을 하나도 쏘지 않는다.** 웹 sweep의 P2 바람탄 5발도 없앴다. 따라서 보스 탄 패링 반사(RM-B1 §9.4)는 대상이 없다 — 리모델링 지옥기형에는 **탄 반사 없음**을 명시한다.

## 4. 텔레그래프 규칙

- **페이즈가 올라도 텔레그래프는 짧아지지 않는다(TeleM 1).** 빨라지는 것은 쿨다운 배율(P1 1.0 / P2 0.75)과 이동 속도(1.0 / 1.2)뿐이다. 웹 si2 전조 ×1.4와 TeleM(최저 0.25)은 쓰지 않고 §3의 값을 그대로 쓴다.
- 표시 3종(색은 디자인총괄 아트 바이블에서 확정, 원색·네온 금지):
  - **패링 가능 섬광**: 발톱 끝(1번 1·2타, 4번 매 도약, 5번) / 꼬리 끝(2번) / 치켜든 앞발(7번)에 섬광 1회 + 짧은 소리.
  - **바닥 예고**: 1번 3타 물기 부채꼴, 3번 착지점 원(추적 22f 동안 따라오다가 고정 18f에 진해짐), 4·5번 진행선, 7번 몸 앞 원, 8번 고리. 1-3 바닥 흙 위에서 읽히는 어두운 핏빛 얼룩이 점점 진해지는 방식.
  - **잡기 긴 예고**: 6번만. 고개를 낮추고 입을 벌린 자세 고정 60f + 눈 빛. 끄는 동안은 둥지까지의 **끌림 흔적**(바닥 자국)을 보여 줘 "어디로 끌려가는지"를 알린다.
- 한 번에 화면에 겹치는 예고는 최대 2개(울부짖음 고리 진행 + 다음 기술 예고 1개까지).
- 예고 목록 API(RM-B1 §9 → RM-B0에서 일반화)에 낼 모양: 1 `Cone`(3타는 `GroundDecal`), 2 `Cone`(방향 = 보는 방향 + π), 3 `Circle`(추적 중에도 매 틱 갱신, `Remaining`은 착지까지), 4·5 `Line`, 6 잡기 전 `GrabEyes` / 끄는 동안 `Trail`(플레이어 → 둥지) + `Circle`(둥지 r150), 7 `Circle`(중심 = 몸 앞 90px), 8 `RingGap`(틈 각 0). 새 모양은 필요 없다.

## 7. 열린 질문

### 7.1 보스전 총괄 결정이 필요한 것 (이 명세의 기본값으로 진행, 바꿀 때만 기록)

1. **애도가 무적이 아님**: 드루이드 쓰러짐(무적 120틱 + 뿌리 3타)과 다른 방식이다. 기본값 = 무적 아님, 애도 피해는 P2 체력에서 차감, P2 체력 70% 하한. 공통 지시의 "목숨 사이 연출" 해석을 보스마다 달리해도 되는지.
2. **그루터기 3개를 Core 장애물로 추가**: "충돌 불변"을 타일 충돌 불변으로 해석하고, 장치는 RM-B1 뿌리 기둥처럼 Core 장애물로 넣었다. 돌진 기절 90f는 이 보스의 핵심 반격 틈이다.
3. **신규 2개의 범위**: 꼬리치기(웹 `tailSwipe`, sweep 실행기 후방 확장)와 물어 가기(grab 실행기 끌기 확장)를 신규로 셌다. 덮치기 추적→고정·몰이 도약 예고 고정·내려찍기 앞 중심 등은 "기존 실행기 수치·판정 변경"으로 보았다.

### 7.2 사용자에게 물을 것

- 없음(이 명세는 유료 크레딧을 쓰지 않는다). 보스 3D 외형(BX-12, No Rest for the Wicked 수준, 사용자 확정 2026-10-28 "전 보스 모델링부터 재제작")은 이 행동 명세가 확정된 뒤 보스전 총괄 배정을 따르고, 유료 생성이 필요하면 그때 사용자 확인.
