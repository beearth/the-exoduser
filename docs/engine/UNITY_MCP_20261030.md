## 확인한 제약

- 이번 제한된 호출 환경의 첫 UPM IPC가 30초 실패했다. 최근 성공한 UI 실행기의 자식 환경 준비 구간을 재사용한 두 번째 실행은 IPC .3초 연결·서버 준비 72.3초였다. 단일 원인 확정이나 전역 환경 복구로 주장하지 않는다.
- Unity 6000.6에서 숫자 instanceID 리소스/컴포넌트 지정이 일부 실패했다. find_gameobjects로 대상 확인 후 고유 이름·전체 경로와 search_method=by_name/by_path를 명시한다.
- read_console은 일부 정상 ExoJobServer 로그를 Exception으로 오분류한다. types=error 개수만으로 실패/무오류 판정하지 않고 message·stack와 실제 Editor 로그를 대조한다. 예상 오류 조회 자체는 성공했다.
- batch 기본 PNG는 640×480이다. 캡처 전 임시 1920×1080 RenderTexture를 camera.targetTexture에 지정하고 aspect=16/9, PNG 헤더로 결과 확인 후 해제한다. Screen Space Overlay UI는 이 카메라 렌더에 포함되지 않는다.
- 모델 프리팹에서 일반 .prefab 생성 시 unlink_if_instance=true가 필요하다. 제품 모델 원본을 덮어쓰지 않는다.
- 이번 검수는 에디터 저작 씬이다. 전체 게임/Mac/Steam·아트 PASS가 아니다. 임시 중앙 나무는 제품 맵으로 채택하지 않았다.
