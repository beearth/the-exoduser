## 근거·재현과 한계

원격 heads/main 로그·각 SHA의 보고서 해당 절과 `_out/<ID>/DONE.txt` 앞10줄을 정적으로 대조했다. 최신 tip이 DONE보다 앞서 있는04/05/08/16/20/21/25b/34/38/40/43 및 A/common은 **원격 tip/후속 보고서**를 우선하고 옛 BLOCKED를 덮어썼다. 예: 06c·19r/ui·22r·23b는 옛06/19/22/23 차단 후속이고,25는 옛 ac283e13 대신25b를 사용했다. main에 있는 PC runtime a28117c1를 아직 없는 owner로 취급하지 않는다.

이번 집계에서 main에 포함된 직접 demo tip은13개였으며, 기능 HOLD4개(16/17/18/27)를 부분으로 분리해 요약의 완료9개로 셌다. 79행의 상태 합계는 활성78+삭제1과 일치한다. 한 family 묶음의 검사 수를 etype별 자연 전투 완료로 나누거나, 초기16개 지원9→11 후보를 자연29종 전체 지원으로 세지 않는다. P2-008b b406e4bc는 main 미포함이며 미검수 후보로 유지한다. main P2-008a/fix의 재사용 대상20도 새 Marker/자연 ingress 확인을 생략하지 않는다.

번호 밖 선행도 별도로 남는다: common `1f0a71fb`·EL-01 `654845e4`·MAP11 provider 후보는 main 미병합이다. perf `aaf52dc0`는 Mac 최적화/진단 제출이지만 `FULL_30_MAX_TARGET_NOT_MET`이며 PC 초상 캐시 PCI-13 후속이 남는다. 이들을 독립 DEMO11 번호 완료 수에 중복 가산하지 않는다. 갭의 종주 목표60fps(약16.7ms)와 개별120Hz/8.33ms fixture 벤치를 혼동하지 않으며, 평균·p95/p99/최대·룩/개체/탄·환경을 고정한 통합 실창 인수가 필요하다.
