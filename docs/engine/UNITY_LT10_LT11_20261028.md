## 원인과 계약

| 항목 | 관찰 | 확인한 원인·정상 조건 |
|---|---|---|
| LT-10 | M1이 처치 `18/15`에서 지옥문을 강제 개방 | 1-1은 전역 처치 비율로 열리지 않는다. 실제 200×200 맵의 4개 지역을 각각 80% 이상 채우고 대응 앵글러를 모두 처치해야 한다. M1의 `07c`가 `TotalSpawned=0`으로 재설정한 뒤 손으로 소환한 적 15마리만 분모에 넣어 `18/15`가 나온다. M1 `10`의 `FieldBossDone=true`·`ForceUnlock()`은 검수 경로의 우회다. |

LT-10 M1 후속은 `09c` 단계에서 지역별 실제 `RegKill` 처치 경로, 앵글러 네 마리의 `HurtFieldMobs`·사망 경로를 통과한 뒤 `Stage.CheckRooms`가 자연스럽게 `BossUnlocked`를 켜는지 검사한다. 보스 게이트나 앵글러 완료 플래그를 직접 설정하지 않는다. 필드 총 소환 계획 168을 복원해 `18/15`라는 하네스 임시 분모를 후속 화면에 남기지 않는다. 전투와 처치는 스크립트 구동이며 실제 OS 키 입력이나 7,000px 이동의 증거는 아니다.

LT-11은 최종 Linear 설치본 `63daee099`의 숨은 데스크톱 HUD 스모크에서 `activeSkill=kiSlash`, `iconDrawn=true`, 세 가지 HUD 상태 캡처를 확인했다. `unity-hud-full.png`와 `unity-hud-empty.png`를 직접 보아 첫 슬롯에 아이콘이 그려진 것을 확인했다. Player 영수증은 사용자 창 감지 0, 잔존 프로세스 0, 세이브 변경 0이며, 출력은 `I:/EXODUSER-Storage/codex-takeover/integrator-final/lt11-hidden-63daee099/`이다. 숨은 실행은 HUD 영수증 작성 뒤 시험용 종료 시점에 소유 Player를 정리했다.
