The WebP menu plate is decoded to a 1200×256 RGB PNG with `sips`; pixels are not resized or generated. Other included media is copied byte-for-byte. The trait glyph atlas rasterizes the exact 15 source Unicode strings plus the crest star with CoreText `AppleColorEmoji`, then applies the source `.ti-g` CSS filters in order (`grayscale(.85) sepia(.85) saturate(1.12) brightness(.96) hue-rotate(-6deg)`) per pixel; the ring atlas applies circular alpha clipping to the five source emblems and uses grayscale at 0.35 brightness for locked classes. A separately clipped circular chain overlay prevents square corners in the five-item rail. The right trait panel now uses the original `blackiron/sigil.png` texture under a dark tint, with source-style crest and corner brackets. The sigil is byte-identical to the Mac original (SHA-256 `e6b317e675a9a18e50220c657e99b5e985adcadbb56d369c786fd48c62860cda`); the current PC asset receipt did not contain a copy for cross-check.

## Layout behavior

The visual screen draws in physical viewport pixels so its IMGUI layout follows the source CSS rather than scaling all 1920×1080 coordinates uniformly. The source measurements at 1920×1080 put the left and right information panels at `(64, 143.992, 340, 717.508)` and `(1516, 143.992, 340, 717.508)`; the Create button is `(1207.063, 1003.5, 132.938, 46.5)`. At 1280×720 the source measurements are `(51.195, 128.467, 332.797, 384.211)` and `(896.008, 127.195, 332.797, 384.211)`, with the Create button at `(887.063, 651.906, 132.938, 46.5)`. Source left children are vertically centered as a group; the implementation positions job, name, description and portrait from the captured 720p/1080p DOM coordinates. Thumbnail texture coordinates preserve centered horizontal crop and top alignment. The right trait frame is transparent outside its own box and matches the captured viewport size and row starts. The character rail uses continuous round strokes built from overlapping arc quads, without rectangular selection borders; emblem and chain pixels are alpha-clipped to circles. The 15 trait symbols and crest star use the source Unicode glyphs rasterized to a small atlas with the original CSS bronze filter, avoiding platform-dependent tofu fallback. Korean heading/job/name-title styles explicitly use Nanum Myeongjo while the English styles use Cinzel. The name dialog remains 440×333.5 pixels at both sizes, centered with 48px/40px interior padding; its 1280×720 position is `(420, 193.25)`. The 1280×720 source measurements place title at `(461, 242.25, 358, 32.5)`, description at y282.75, name label at y329.25, input at `(461, 358.25, 358, 53)`, and buttons at `(461, 431.25, 173, 46.5)` and `(646, 431.25, 173, 46.5)`.

The full-screen preview video files are in `unity/Assets/StreamingAssets/Lobby/`, matching `NativeLobbyVideo`’s `Application.streamingAssetsPath/Lobby` lookup. It uses a looping, muted `NativeLobbyVideo` instance. Its helper component follows application focus and disposes the decoder and render texture when the lobby is destroyed. The existing lobby decoder and shared lifecycle files are not changed by this presentation unit. The native character presentation is source-backed at the code and media level. Root visual review confirmed the generated glyph and circular clipping, then found that the three static-keyart classes need the compact source lock treatment; their large central chain is now limited to Silvertail, while static-keyart uses a 72px chain and bottom release label. This last layout adjustment awaits the next integrated capture.
