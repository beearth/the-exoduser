# 1-1 거대 고목 가림 투명화 (2026-11-05)

표현 전용이다. Core 변경 0, 카메라 변경 0. 코드 `unity/Assets/Exoduser/Runtime/NativeGame.A2TreeOcclusion.cs`, 호출 `Remodel3DLate`.

## 규칙

| 항목 | 값 |
|---|---|
| 대상 | a2Root 바로 아래 `A2_Hollow_Loft_Tree`, `A2_Ancient_Rotten_Tree`, `A2 전경 바깥 거목`, `A2 外곽 *` 중 높이 4u 이상. 소품·천막·바위·카드는 제외 |
| 판정 단위 | 그루별. 가리는 인스턴스만 페이드하고 같은 종류의 다른 나무는 불투명 유지 |
| 시선 | 카메라 → 플레이어 3점(높이 .25·.85·1.45u), 카메라 → 플레이어 주변 화면 높이 1/3 안의 살아 있는 적(최대 40) |
| 메시 판정 | 정점을 .7u 셀로 올린 집합을 선분이 지나는지 본다. 읽을 수 없는 메시(RF3 Ancient_Tree)는 경계 상자 중심의 줄기 원기둥(반경 .35배) 근사 |
| 목표 끝 | 시선 끝 .45u는 검사하지 않는다. 밑동에 붙어 선 몸은 가림으로 보지 않는다 |
| 알파 | .30, 페이드 .15초, 벗어난 뒤 유지 .25초 |
| 방식 | URP Lit 투명 재질 교체(`Resources/Art/map/a2/occlusion/A2_TreeFade_{Normal,Full}.mat`). 디더링 없음 |
| 붙은 소품 | 수피 이끼·버섯은 나무가 페이드할 때 숨긴다. 공중에 뜨지 않게 하기 위함 |
| QA 인자 | `--a2-tree-fade-off`: 판정은 돌고 그리기는 불투명 유지(이전·이후 비교용) |

불투명 복귀 때 원래 재질과 빈 프로퍼티 블록으로 되돌린다.

## 한계

- RF3 Ancient_Tree는 메시를 읽을 수 없어 줄기 근사다. 가지가 가리는 경우는 페이드되지 않을 수 있다. 정확히 하려면 FBX의 Read/Write를 켜야 하며 메모리가 는다.
- 페이드된 나무도 지면 그림자는 그대로 남는다.
- 겹친 가지의 투명 정렬은 ZWrite 끔이라 앞뒤가 정확하지 않다.
- 보스방 나무는 대상이 아니다. a2Root 아래 필드 나무만 본다.
- 실제 사람 조작, 영상, 3840은 확인하지 않았다.
