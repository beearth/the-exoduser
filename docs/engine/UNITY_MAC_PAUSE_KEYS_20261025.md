# Mac 일시정지·설정 키보드 / 포커스 — 2026-10-25

범위: 기존 NativePauseMenu/NativeGame에서 ESC→메뉴→설정→뒤로→재개를 키보드로 연결. 기존 화면/소리 콜백과 세션 설정을 재사용하며 저장·전투 공식·영상은 변경하지 않는다.

- ↑↓ 또는 Tab/Shift+Tab은 선택, Enter/Space는 확인, Home/End는 처음/끝, ←→는 탭·FPS·음량 조절. 화면/소리의 값 조절은 5%/기존 FPS 목록 단계다.
- 키를 놓기 전에는 다음 동작을 받지 않는다. 하위 메뉴에서 ESC/뒤로는 부모 항목의 선택을 복구한다. 종료 창은 취소가 기본이며 포커스 상실/복귀 시 종료 선택도 취소로 돌린다.
- 전투 중 창 포커스를 잃으면 일시정지하며 돌아와도 자동 재개하지 않는다. 설정/종료 창은 그대로 유지하고 새 입력을 기다린다. 사망 화면 ESC는 전투를 재개하지 않는다.
- 선택 테두리와 키 안내를 제공한다. 오래된 UI fixture의 탭 접근은 새 공개 탐색 모델로 바꿨고 설정 검사 프로젝트의 partial 의존성을 갱신했다.

검수: 새 순수 탐색 모델 33/33 PASS. 실제 Player·화면·OS 키보드/창 포커스 검수는 빌드 후 기록한다. 빌드 전 정상 commit/push와 원격 SHA 대조를 진행한다.

현재 설정은 실행 세션에만 적용된다. 일반 저장 파일/PC/Godot/기존 영상/전체29개언어·RTL 인수와 무관하다. 새 팀·자동화·PC 재시작은 없다.
