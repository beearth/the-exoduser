## 표시와 저장 호출부

NativeGame.CombatSave가 실제 복원 시 RestoreChargeSkill을 호출하고 캡처 때 ActiveChargeSk를 채운다. 9개 Core 파일만 반영하면 이 호출부가 빠지므로 함께 인수해야 한다. 독립 읽기 검토에서도 이 통합 위험을 확인했다. 일반 저장 복원은 사망 재충전 함수를 호출하지 않아 저장된 HP/MP/ST/쉴드를 임의 회복시키지 않는다.

SkillDockBinding.ForgeHostForWindow는 실제 _FUSE_PAIRS/HOST_OVERRIDE의 모체 집합과 원문 분기를 사용한다. Shift 기본charge에서 충돌을 학습하면 정보판과 제단 명칭은chargeBoost로 바뀐다. 기본charge/parry 정보는 레벨·습득/강화 버튼을 표시하지 않으며 기본 사슬의 명시 장착은 유지한다. charge/chargeBoost는 실제 SKILL_ICONS와 같은 이미지 별칭을 사용한다.

기존 초기48정의는 실제46스킬+기본표시2개였다. 빠진9개 메타데이터(chargeBoost,bladeDash,fanShot,guardian,chainAssault,chainSlam,chainSlash,hellRay,shieldThrow)를 실제55목록에서 보충해57정의·중복0이다. 메타데이터 보충은 해당46개 실행 이식이 아니다. 원문 설명의 구형 “3회·Lv3마다·쿨5초” 문구와 실행 공식은 다르며 위 표는 실제 코드값을 기록한다. 제단 모체 이후의6구슬·로드맵/합체 조작은 후속 검수 범위다.
