- 대상: `codex/unity-mac-20261024` tip `9d4c43501`을 PC에서 Windows x64 Player로 빌드(Unity 6000.4.8f1, 빌드 성공).
- 빌드 전 필요: `Tools/restore-lobby-media.cjs`, `Tools/restore-warrior-story.cjs` 실행(영상 2개를 Git 조각에서 재조립). 이걸 안 하면 `PortVerification.Build`가 영상 누락으로 멈춘다.

- 웹 기준 캡처: 2026-10-22 웹 1920×1080(`G:/exoduser-wt/_out/parity/web`). 스킬 창은 그 뒤 웹이 개편됐다(구슬 배치·중앙 탈착 fab7a167c). 스킬 창은 최신 웹으로 다시 찍어야 한다.
- 비교 이미지: `unity_pc_win_refs/`(왼쪽=웹, 오른쪽=Unity Windows).

## Windows 전용 확인
- 빌드·실행·캡처 모두 D3D 기본 경로에서 오류 없이 동작했다.
- 글꼴 깨짐·해상도 잘림은 이번 캡처 범위에서 보이지 않았다.
- 실제 키 입력 플레이(수동)는 아직 하지 않았다.
