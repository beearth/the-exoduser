# 보스 리모델링 RM-B1 — 1-1 다크드루이드 (2026-10-27)

작성: 보스전 총괄. 배정·구현: CTO → PC Sonnet 세션. 판정: 보스전 총괄(전투), 디자인총괄(시각), 사운드총괄(소리).
근거: 사용자 지시 "이식작업은 대충 된거같으니까 유니티 리모델링 작업들어간다 오늘부터"(CTO 전달). 바탕 = 이식본 unity/main `df43aa110`(웹 23기술·5페이즈·부활·STY-D9 침강, druid-boss-oracle 0불일치).

## 0. 무엇을 바꾸나 — 한 줄

웹 드루이드는 공용 기술 풀에서 23개를 빌려 온 "무엇이든 하는 보스"이고, 페이즈는 HP 구간 5개, 부활은 확률 판정이다. 리모델링은 **"빌린 수명으로 버티는 늙은 숲지기"** 한 가지 정체성으로 기술을 12개로 줄이고, **목숨 3개 = 페이즈 3개**로 묶는다. 쓰러질 때마다 몸이 줄고(빌린 수명이 빠져나감, STY-D8), 마지막에는 땅속으로 달아난다(STY-D9).

## 1. 지키는 것 (바꾸지 않음)

- 이름·원화·침강 도주 연출·대사 5줄(STY-12): 등장 "새 거름이 떨어졌군." / 침강 "숲은 아직 배고프다. 둥지에서 보자." 등.
- si0에서 완전히 죽지 않는다. 최종 사망은 si3(기생수의 둥지)에서. 이번 범위는 si0만.
- 플레이어 쪽 규칙: 패링·돌진·방패·포이즈(2_3 수정 금지), 에너지쉴드 계약(CLAUDE.md), 피해 공식.
- 보스 AI 틀(이식된 `_bossAI` 점수·콤보·쿨다운 엔진)은 그대로 쓰고, **기술표·페이즈표·부활 규칙만** 드루이드 전용으로 갈아 끼운다.

## 2. 페이즈 = 목숨 (HP 곡선)

| 페이즈 | 목숨 | 체력(기준 HP 대비) | 몸 크기 | 성격 | 들어갈 때 연출 |
|---|---|---|---|---|---|
| P1 숲지기 | 1 | 100% | 100% | 지팡이·뿌리로 거름을 "거두는" 근접 위주. 읽기 쉬운 단타 | 등장 대사 → 지팡이로 바닥 3번 두드림(아레나 뿌리 4개가 솟음) |
| P2 뿌리 각성 | 2 | 60% | 85% | 땅속 잠행·뿌리 추적·거름 일으키기. 아레나를 쓴다 | 첫 쓰러짐 → 무릎 꿇고 뿌리가 등에 꽂힘(2.0초) → 줄어든 몸으로 일어남 |
| P3 수명 소진 | 3 | 40% | 70% | 독액 해일·포자·심장 박동. 빠르지만 텔레그래프는 줄이지 않는다 | 두 번째 쓰러짐 → 같은 연출, 껍질이 벗겨지고 독액 강 수위가 오름 |
| 끝 | — | 0 | — | — | 세 번째 쓰러짐 → STY-D9 침강 도주 + 대사 → 출구 개방 |

- **총 유효 체력 = 기준 HP × 2.0**(1.0+0.6+0.4). 기준 HP는 이식본 mkEn 보스 공식(레벨·난이도) 그대로 쓴다. 웹 확률 부활(125%+…, 포인트 소모)은 **드루이드에 한해** 쓰지 않는다. 다른 보스는 각자 리모델링 전까지 현행 부활 시스템을 유지한다.
- 목표 전투 시간(초기값, 플레이 테스트로 조정): 1-1 도달 기준 장비·레벨(Lv 5~10, 시작 무기+필드 드랍)로 **P1 50초 / P2 45초 / P3 35초, 합계 2분 10초 안팎**. 시간이 크게 벗어나면 기준 HP 배율을 고치고, 페이즈 비율(1.0/0.6/0.4)은 유지한다.
- 쓰러짐 연출(2.0초) 동안 보스는 무적이다. 플레이어가 그 사이 **뿌리(등에 꽂힌 것)를 3회 때리면** 다음 목숨 체력이 −10%p(최대 1회). 숲과 이어진 끈을 끊는다는 서사 보상이자, 쉬는 시간에도 할 일을 준다.
- 에너지쉴드: P1 0, P2·P3 진입 때 목숨 체력의 15%(쉴드→HP 순서, 계약 그대로).

## 4. 텔레그래프 규칙

- **페이즈가 올라도 텔레그래프는 짧아지지 않는다.** 빨라지는 것은 기술 사이 간격(쿨다운 배율 P1 1.0 / P2 0.8 / P3 0.65)과 이동 속도(1.0 / 1.1 / 1.2)뿐이다. 웹 TeleM(최저 0.25)은 쓰지 않는다.
- 표시 3종(색은 디자인총괄 아트 바이블에서 확정):
  - **패링 가능 근접**: 무기 끝 섬광 1회 + 짧은 금속음.
  - **피해야 하는 범위**: 바닥 예고(어두운 독액 얼룩이 점점 진해짐). 원색·네온 금지.
  - **잡기**: 보스 눈이 빛나고 손을 뻗는 자세 고정(60f) — 유일하게 긴 예고, 구르기로 피하는 기술임을 배우게 한다.
- 한 번에 화면에 겹치는 예고는 최대 2개(추적 장판 제외).

## 5. 아레나 요구 (맵 총괄과 공동, BX-04)

- 바닥: 1-1과 같은 검붉은 흙(현행 웹 흙 타일 유지). 지름은 현행 아레나 그대로(충돌·진입·출구 좌표 불변, D8).
- **뿌리 기둥 4개**(P1 진입 때 솟음): 원형 배치, 반지름은 아레나의 0.55. 탄·균열·심장 박동을 막는 엄폐물이자 땅속 잠행 출구. 부서지지 않는다.
- **가장자리 독액 수로**: 아레나 둘레를 도는 얕은 독액 강(사용자 지시 "1-1은 독액강이 흐르는 썩은숲"). 재질 = 맵 총괄 RM-1의 URP 재질 `M_ToxicFlow`(경로는 완성 뒤 맵 총괄이 통보). 보행 불가 띠라 실제 지름은 줄지 않게 바깥에 둔다. P3에서 수위가 오르는 연출(판정 변화 없음), 독액 해일의 출발점.
- 카메라: 보스전 줌 0.80(이식본 그대로).

## 12. 리뷰용 실행 인자 (2026-10-28, PC Sonnet 세션, 브랜치 `claude/unity-pc-rmb1-20261027` = `d1bac7735`, 보스전 총괄 지시)

리모델 플래그 기본값(`DruidRemodelSettings.Default = false`)과 기본 실행 경로는 그대로 두고, 리뷰할 때만 쓰는 런타임(Core 밖) 인자 두 개를 넣었다. 둘 다 `NativeReviewArgs`(`Runtime/NativeReviewArgs.cs`)가 읽고, 적용은 `NativeGame.ReviewArgs.cs`에 있다.

| 인자 | 동작 |
|---|---|
| `--unity-druid-remodel` | 각 판의 `Simulation`을 만든 직후(`ResetRun`, 아레나 입장 전) `Simulation.DruidRemodel = true`. `DruidRemodelSettings.Default`는 false 유지 |
| `--unity-boss-direct <스테이지>` | 로비에서 입장하면 첫 연습을 건너뛰고(`EnterFromLobby`) 1-1 문 타일(`Stage.Exits[1]`)에서 시작한다: `FieldBossDone = true`, `ForceUnlock()`, 플레이어를 문 타일 중심에 놓고 HP 가득·무적 600틱. 값이 없으면 0. 0 외의 값은 경고만 남기고 무시(보스 방이 1-1뿐). 문 타일 위에서 시작하므로 입력 대기가 풀리면 바로 암전·이름 카드로 들어간다 |

- 두 인자 중 하나라도 있으면 전투 저장을 쓰지 않는다(`CombatSaveAllowed`): 강제로 연 상태가 사용자 세이브에 남지 않게 한다.
- 두 인자는 "테스트 인자" 판정(`areaTitleAllowed`)에서 제외해 지역 제목이 그대로 나온다.
- 확인용 `--unity-review-args-capture -output <dir> --unity-druid-remodel --unity-boss-direct 0`: 새 캐릭터로 로비를 지나 입장하고 6가지를 검사한다 — 로비에서 입장, `DruidRemodel` 켜짐(기본값 꺼짐), 첫 연습 생략, 문 타일 위·문 열림·앵글러 처치 처리, 문을 지나 보스 아레나 열림, 아레나의 드루이드가 리모델(기둥 4개). 결과 `<dir>/review-args.json`.
- 실행은 공용 실행기 `unity/Tools/devtools/exo-unity.ps1`로만 한다(`build`, `player -AllowPlayer`).
