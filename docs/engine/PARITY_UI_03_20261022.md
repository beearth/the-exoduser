## 문자열·범위·정리

원본 `_L`60쌍을 native source_en에 연결했다. 기존 전체목록에 없는11개는 No.3496–3506으로 추가하고 원문 CRLF/prefix byte를 보존했다. lang26개 파일에는 기존 번역을 덮지 않고 원본 `_L`의 EN 폴백만 전파했다. 해당 언어의 새 번역 완료로 보고하지 않는다.

R은 읽기 전용으로 사용했다. 지정 WT에서만 fetch·import·실행·본인 변경 staging/commit·비강제 branch push를 수행한다. 실제 제품 namespace 사용 없음. PID81277 보존, 최대3 Godot gate 사용. 실행마다 isolated override를 적용하고 실행 종료 후 원래 부재 상태로 복원한다. 외부 캡처 도구는 `_out`에만 두며 제품 트리에 merge하지 않는다. PC 실행/동기화·투자 빌드 전체 품질 완료를 주장하지 않는다.

후속 표시 검수 중 기존 `native_demo11_auto_crossbow.gd:57`의 deferred 수명 Nil 오류1건을 관측했다. UI-01에도 남은 원 문제이며 PC 전투 범위이므로 수정하지 않았다. 원 실패 로그를 보존하고 UI-only 캡처는 전투 gate를 끈 별도 표시 하니스에서 분리했다. 전체 GUI 실행이 무오류라고 주장하지 않는다.

최종 GUI 장착 증거: `gui-forge-persistence/capture.out`의 `forge_equip`은 숫자2 슬롯 null→iceOrb, persistence SETTLED/committed=true/saved=true를 보였고 같은 실행의 `forge_disk`도 hellsave_demo.json의 skillSlots[1]=iceOrb를 재독했다. durability_verified=false를 유지하며 fsync 내구성 완료로 확대하지 않는다.
