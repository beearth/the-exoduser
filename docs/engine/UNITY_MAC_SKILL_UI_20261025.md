## 이번 연결

- K로 열기/닫기, ESC로 스킬 창만 우선 닫기. 방향키·Home/End·1~4로 슬롯 선택. HUD 슬롯 클릭도 해당 상세로 연결한다. 열린 동안 시뮬레이션을 멈추고 닫으면 이전 실행상태를 복원한다.
- LMB 기검참의 현재 레벨·원본 설명·장착 상태를 표시한다. 기본무기 개발 실행에서 기검참을 장착할 때만 Config.ActiveAttack을 바꾸며 플레이어·자원·경험치·장비를 초기화하지 않는다. 행동 중·사망·다른 슬롯 배정은 거부한다.
- 원본 LMB 목록은 kiSlash/whirlwind다. weapon을 새 스킬로 만들지 않는다. 회전참 실행기는 미이식이라 사용 가능 목록에 추가하지 않는다.
- 숫자 칸은 스킬이다. 잔여 QSLOTS 물약 UI를 복원하지 않는다. 다른 12슬롯에는 미지원 안내와 기검참 보기만 제공하며 가짜 습득·발동은 없다.
- HUD는 실제 Player.State·Stamina·KiChargeTicks로 준비/체력 부족/공격 회복/차지 단계와 진행바를 표시한다. KiCooldownTicks는 현재 Tick의 발동 조건에서 읽히지 않으므로 가짜 쿨다운 제한을 추가하지 않았다.
- HUD 슬롯 위 클릭의 월드 공격을 막고, 창 닫기 클릭은 버튼 해제까지 다음 일반 공격으로 넘기지 않는다. 표준 화면→HUD 변환이며 기존 자동 마우스 좌표 문제의 임의 보정이 아니다.
