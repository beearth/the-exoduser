# 중앙 HUD와 양측 인벤토리 설계 — 2026-10-24

상태: 구현 전 목표 구도. 실제 Mac Player 렌더·직접 입력·사용자 디자인 인수와 구분한다. 사용자 최신 “디아블로식이 나은거같아 저렇게하면 전체화면 디자인이 너무 어려워”를 따른다. 특정 작품의 고유 아트를 복제하지 않는다. 이전 전체폭 도킹은 2c37d3817에서 복구 가능하다.

## 확인된 문제

- NativeHudDockLayout은 폭 전체 44px 받침과 화면 양끝 구슬을 사용한다. 초광폭에서 구슬과 슬롯 사이가 늘어나는 구조다.
- NativeHud의 MP/ST 라벨 8px·최대값 11px는 720p 균등 배율에서 약5.3/7.3 물리픽셀이 된다.
- NativeInventoryDock은 화면 전체를 세 열로 덮는다. 장비/가방/상세가 동일한 강조를 받으며 전투 장면이 모두 가려진다.
- 인벤토리 상단 조작문·하단 개발상태·장비영역 미이식 안내가 상시 노출된다. 상세 옵션은 콘텐츠 길이와 무관한 고정 y축으로 내려가 버튼과 겹칠 수 있다.
- 실제 소스 아트는 검은 철·탁한 금색·해골 장식이 이미 강하다. 추가 테두리보다 장식의 사용 범위를 줄이는 편이 적절하다.
- Mac 실제 Unity 화면은 아직 없다. PC PNG는 이 Mac에서 접근하지 못했으므로 위 문제는 현행 코드와 직접 열어 본 원본 이미지의 근거다.

## 공통 원칙

1920×1080 설계 공간을 균등 축소하며 초광폭에서는 중앙 여백만 늘린다. 본문20/보조18/제목28px, 숫자18~24px. 720p에서 보조문자12px를 최소로 삼는다. 기존 EXODUSER 철 표면과 금색을 헤더·구분선·선택 상태에 제한하고 바탕은 낮은 명도다. 붉은색/청색/녹색은 기존 자원 의미를 보존한다. 장식과 입력 영역은 같은 좌표를 사용한다.

## 구현과 검수 경계

NativeHud/Layout와 NativeInventory/Dock의 표현만 변경한다. InventoryState/시뮬레이션/세이브/영상 원본은 수정하지 않는다. 소켓 표시와 클릭 영역, 가방 좌표와 드롭 변환을 함께 검수한다. 선택·장착·해제·정리·드래그·닫기·pause/resume, 두 독립 스크롤 및 1280×720/1920×1080/2560×1080 실화면을 확인하기 전에는 디자인 완료·Mac PASS를 선언하지 않는다.
