# Unity 이식 마스터 보드 — 100% 분모 (2026-10-26 신설)

목표는 **웹 게임 전체를 Unity로 이식하는 것(100%)** 이다. 이 표의 행 전체가 분모다. 진행률은 이 표 기준으로만 말하고, 테스트 수·커밋 수·문서 수로 대신하지 않는다.

- 기준 원본: `game.html` · `index.html` (main). 기준 원칙은 **UI·게임 시스템 = 웹 그대로**(2026-10-26 사용자 확정 "UI는 일단 그대로 이식하고"). 맵·모션·이펙트는 웹 구조 위에서 Unity로 새로 제작해도 된다(2026-10-24 사용자 확정).
- 담당
  - 전체총괄: PC Claude "유니티 이식 전체 총괄" 세션
  - PC 구현: PC Claude "유니티 이식 맥북 총괄" 세션(Git 경유)
  - Mac 구현: Codex, 브랜치 `unity/main`(10-27 전환 확인, 끝 `b6b4f5ec4`). 이전 `codex/unity-mac-20261024`는 퇴역(새 커밋 없음)
  - Unity 줄기(병합 대상): `unity/main` (2026-10-27 신설, 시작점 codex/unity-mac-20261024 끝). PC·Codex 작업 브랜치는 unity/main으로만 병합하고 main으로는 병합하지 않는다. Codex 전환 확인됨(10-27). PC→Codex 공지(INBOX)는 main과 unity/main 두 곳. 규칙: CLAUDE.md §엔진별 버전 분리
- 상태 표기
  - `0 미착수`
  - `1 일부`: 소스는 있지만 웹과 다르거나 범위가 일부만 있음
  - `2 웹동일 소스`: 소스와 비교 이미지까지 일치
  - `3 실플레이 인수`: 사람이 직접 입력해 확인함
- **리메이크 진입 조건 = A군·B군·D군·E01~E03 상태 2 이상** (2026-10-27 사용자 지시 "ux ui다 들어갔으면 이제 유니티버전으로 다시만들자"). 이 조건이 차면 Unity 리메이크로 넘어간다.
- **C03·C04·F군 = "동작" 기준**: 나중에 Unity에서 새로 만들 것이라 돌아가기만 하면 된다(사용자 "보스전 대충구현해", "맵도 대충하고"). 이 행들은 웹과 같은 시각·비교 이미지를 요구하지 않는다. 상태 2 = 게임에서 끝까지 동작, 3 = 사람이 플레이해 동작 확인.
- 100%는 모든 행이 `3`인 상태다.
- 판정 근거: 각 담당 보고서. 이 표를 갱신할 때는 근거 문서 링크를 같이 바꾼다.

## 배정 순서 (총괄 결정)

**M1 "1-1 한 판 완주" 최우선 (2026-10-27 사용자 지시, CTO 전달).** 사람이 Unity 빌드로 로비→전사→1-1 일반몹→드루이드 보스→클리어→저장까지 웹과 같게 플레이한다. 위 표의 **[M1]** 16행(B01·B02·B03·B05·B07·B08·B09·B10·B11·C01·C03·C04·C07·D01·D05·E03)을 3(실플레이 인수)까지 올리는 것이 목표다.

1. **Codex(Mac) — 씬·진행**: C04 1-1 전 구간 → C01 몹 연결(PC Core 사용) → C07 진행·클리어 → C03 드루이드 연결 → B01·B02·B09 수동 인수 준비.
2. **PC(맥북 총괄 + Sonnet) — Core 계산·원본 oracle**: B07·c01 병합 완료 → D05 → B03(1-1 스킬) → B10 → D01 → B08 → E03. 순서는 맥북 총괄이 의존성에 맞게 바꿀 수 있다. Simulation·Native* 연결은 patch로 Codex에 넘긴다.
3. **보스전 총괄**: C01 Core(CX-03~) → C03 1-1 드루이드 명세·Core·검수.
4. **3 실플레이 인수**: M1 동선이 이어지면 사용자가 직접 플레이해 판정한다.

- **A군 동결**: 지금 상태(1·2)에서 멈춘다. RETOUCH·시각 다듬기는 M1 뒤. M1 동선을 막는 결함(예: A22 클리어 결과·A23 보스 바 이벤트 연결, A21 사망)만 고친다.
- **F군 동결**: 맵 3D·조명·모션·VFX는 M1 동안 기존 임시 에셋을 쓴다. `claude/unity-pc-map3d-20261026`(5108c7098)은 M1 동안 unity/main 병합 보류.
- M1 밖 행(B04·B06·B12·C02·C05·C06·D02~D04·D06·D07·E04·E07·E08)은 M1 뒤 배정.
- PC→unity/main 병합 요청 창구는 맥북 총괄 한 곳. 같은 파일을 두 담당이 동시에 고치지 않는다. 파일 소유는 협약 §2를 따른다.
