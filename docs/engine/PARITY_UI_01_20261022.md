## 검수·격리·한계

- 실제 저장 폴더 `EXODUSER-Godot-Native-First`는 실행/테스트로 열지 않았다. synthetic 문자열의 accepts_namespace만 검사했다.
- runtime은 임시 override의 격리 user dir만 사용했다. 테스트/E2E/캡처마다 경로와 PID를 구분하며 PID 81277은 보존했다.
- 비교 도구는 `fae057f7f:tools/parity/`에서 `_out/PARITY-UI-01/tools/`로 꺼냈다. 제품 트리에 merge하지 않았다.
- 웹은 기존 PARITY-MAP-01 소유 node server.cjs(3333)에 Playwright Chrome의 별도 프로필로 접속했다. 서버를 재시작/종료하지 않았다. 웹 game.html과 source_snapshot SHA 대조는 외부 보고에 남긴다.
- 처음 웹 Tab/K 캡처는 레슨이 키를 가로채 UI가 안 열린 무효 캡처였다. 최종 UI 캡처에서는 원본 openPanel 함수를 호출했다. 사망 캡처는 P.hp=0을 사용했다. 이는 화면 비교 하니스이며 E2E와 구분한다.
- 외부 UI 캡처에는 별도 test 상태 주입이 포함될 수 있으므로 자연 플레이 완료 증거로 사용하지 않는다. 기존 E2E는 자체 checkpoint 범위를 구분해 보고하며 단순 PASS 개수로 완주를 주장하지 않는다.
- UI 문구를 추가하지 않았다. 번역 대상 목록과 lang 파일의 기존 CRLF는 변경하지 않았다.
- 맵·카메라·run.cmd·main.tscn·PC 생명주기 core/계약·PC 테스트를 변경하지 않았다.
- 최종 테스트 요약, 캡처 경로, 남은 차이와 SHA: `~/exoduser-wt/_out/PARITY-UI-01/DONE.txt`.
