# Unity 보스전 이식 보드 — 보스전 총괄 (2026-10-26 신설)

이 문서는 Unity 이식 마스터 보드(`UNITY_PORT_MASTER_20261026.md`)의 보스 관련 행을 쪼갠 하위 보드다. 진행률은 마스터 보드 행 상태(0/1/2/3)로만 말하고, 이 표는 그 행을 채우기 위한 작업 단위 목록이다.

- 담당: PC Claude **"보스전 총괄"** 세션 — 보스전 명세·원본 추적·검수·인수. 구현은 Sonnet 단순작업 세션, 배정은 전체총괄·맥북 총괄과 협의.

- 시각 판정: 디자인 총괄. 보스 BGM·보이스·SFX: 사운드총괄 협조. 아레나 맵 비주얼: 맵 총괄 협조.
- 상태 표기는 마스터 보드와 같다: `0 미착수` / `1 일부` / `2 웹동일 소스` / `3 실플레이 인수`.

## 6. 작업 방식

- Core 계산은 B군과 같은 방식: 원본 함수 줄 범위 추출 → Node VM oracle → C# 새 파일 대조. Codex 소유 `Simulation.cs`·`NativeGame` 수정은 patch + PC_TO_MAC_INBOX(main·codex 브랜치 두 곳).

보스 클립 공통 조건(공급원과 무관):
1. 공급원은 혼합안으로 한다. 라이브러리 클립이나 Text to Motion을 원형으로 쓰고, Unity에서 재타이밍·발 고정·IK를 손으로 잡는다. 보스는 **무기를 쥔 손 수에 맞춰** 원형을 고른다. 한 손 무기(곤봉·지팡이 한 손)는 라이브러리, 두 손 무기는 TM을 쓴다. 보스용 유료 TM 추가 생성은 지금은 하지 않는다.
2. 발동 첫 프레임 = 타격 자세. 무기 끝이나 손이 그 기술 판정 도형(바닥 원·직사각형)에 닿는 프레임이 Core `active` 시작과 같아야 한다.
3. 예비동작과 발동 동안 두 발은 바닥에 고정한다(미끄러짐 0, 루트 이동은 표시 보정만).
4. 회복 중 가장 낮은 자세는 회복 길이의 1/3 이하로만 유지한다. 그다음 일어서기 시작해야 목숨 전환 쓰러짐과 구분된다.
5. 판정은 1x 게임 시점(55°)으로 본다. 측면 띠만으로는 인수하지 않는다.
6. 60fps FBX의 실제 키 간격은 Unity 임포트 때 확인한다(이번 자료는 전부 GLB 30fps 기준).
