## 원본 대조 도구의 경계

최신 웹을 다시 추출한다. 적 예고음 _playTell은 기존 음향 호출처럼 수치 하니스 범위 밖으로 명시했다. 번역은 무반환 _T 스텁 대신 원문 문자열과 같은 소스의 localization-runtime.js를 사용한다. 기동 탈출의 구 함수명은 최신 _canMobility/activateMobility로 연결했다. 드루이드 침강 함수는 한 줄 대신 구문 전체를 추출하며 외부 투사체 입력은 빈 통제 배열이다. 해당 검사는 실제 청취·화면·전체 게임 완료가 아니다.
