# Godot "우리식 개조" 전략 — 2026-10-20

사용자 결정(2026-10-20): "고도를 잘 우리식으로 개종해서 써보자". Unity 전환은 하지 않는다.
계기: No Rest for the Wicked 수준의 그림을 원함. 이 게임의 느낌은 엔진이 아니라 아트 방향(쿼터뷰 3D 모델·
유화풍 셰이더·실시간 조명/그림자/안개·후처리)에서 나온다는 판단(PC 총괄 답변, 같은 날).

## 1. 원칙

| # | 원칙 | 이유 |
|---|---|---|
| 1 | **원본 동일 레이어는 건드리지 않는다.** 시뮬레이션(전투·AI·수치·RNG)과 원본 화면 재현(P2-003a 조명 등)은 지금 계약 그대로 | 이식 테스트 수백 종이 원본 동일을 검사한다. 룩 개조가 이걸 깨면 이식 진척을 잃는다 |
| 2 | **강화 표시는 별도 레이어·토글.** 그래픽 옵션 "원본 / 강화" 두 모드. 기본 회귀 테스트는 원본 모드에서 그대로 돈다 | 원본 대조 검수와 새 그림 실험을 동시에 유지 |

| 5 | **판정은 스크린샷 1x로 사용자가.** 수치(FPS·밝기)는 보조 | 작업물 퀄리티 최우선 규칙 |

## 2. 개조 3단계 — 아래 단계일수록 비싸다

| 단계 | 무엇 | 언제 쓰나 | 비용 |
|---|---|---|---|
| L1 프로젝트 안 | 셰이더(.gdshader), 2D/3D 조명 노드, WorldEnvironment 후처리, 머티리얼, 파티클, 렌더러 설정 | **지금부터 기본.** 그림 품질 대부분은 여기서 해결 | 낮음. 엔진 업그레이드 그대로 따라감 |
| L2 GDExtension(C++) | 엔진을 고치지 않고 붙이는 네이티브 모듈 — 적 수백 마리 갱신·충돌 질의 같은 핫패스 | GDScript 실측 병목이 확인된 경우만 | 중간. Win·Mac 각각 빌드 필요 |
| L3 엔진 포크 | Godot 소스를 고친 자체 빌드 + 자체 export 템플릿 | L1·L2로 불가능한 한계가 실제로 확인된 경우만 | 높음. 업그레이드마다 병합, Win/Mac 템플릿 직접 빌드·서명 |

현재 L2·L3는 필요 근거 없음. **포크하지 않는다**(재검토 조건: 위 표의 "언제 쓰나" 충족 + 사용자 승인).

## 4. 렌더러 선택 — 룩 테스트로 정한다

| 기능 | Compatibility(현행) | Forward+ |
|---|---|---|
| 2D 조명·2D 그림자·노멀맵 | 가능 | 가능 |
| 커스텀 셰이더·글로우 후처리 | 가능(일부 제한) | 가능 |
| 3D 실시간 그림자 | 가능(단순) | 가능 |
| SDFGI·VoxelGI 전역조명, 볼류메트릭 안개, SSAO, SSR | **불가** | 가능 |
| Mac | OpenGL 경로 | Metal 경로 |

No Rest식 3D 룩(안개 속 빛줄기·간접광)은 Forward+ 기능에 기댄다. 2D 강화만이면 Compatibility로도 된다.
렌더러 전환 여부는 아래 LOOK-001의 Mac 실측 FPS와 화면으로 결정한다(미결정).

## 5. LOOK-001 룩 테스트 사양 (Mac 자동 작업)

- 장면: 1-1 시작점 (4020,7420) 주변 한 구역, 같은 카메라·같은 시각(고정 시드), 1920×1080.
- 비교안 4개:

| 안 | 내용 |
|---|---|
| A 현행 | 원본 모드 그대로(기준) |
| B 2D 강화 | A 위에: 원본 스프라이트에서 파생한 노멀맵(결정적 도구) + PointLight2D(플레이어·횃불·소환굴 광) + LightOccluder2D 그림자 + 안개 셰이더 강화 + 색보정 |
| C 3D 강화(Forward+) | 원근 3D 모드 + DirectionalLight3D 그림자 + 볼류메트릭 안개 + SSAO + 글로우 |
| D 3D 강화(Compatibility) | C와 같은 구성에서 Compatibility로 되는 것만 |

- 산출물: 안별 스크린샷(전체 + 1x 확대 크롭 3곳), 2×2 격자 비교 시트, Mac FPS(평균·최저, 30초), 변경 파일·토글 위치.
- 범위: 별도 브랜치 `codex/look-001-20261020`. 기본 실행 화면·원본 모드·회귀 테스트 변화 0(test_contracts·p2003a·p2002a 등 그대로 통과). 원본 에셋 불변, 파생 노멀맵은 `godot/assets/derived/`에만.
- 판정: 사용자가 격자 시트를 보고 B(2D 강화) / C·D(3D) / 보류 중 고른다. 총괄은 "완료"가 아니라 "비교 자료 준비"로 보고.

## 6. 순서

1. 이식(원본 동일)은 계속 우선. 룩 작업은 별도 트랙으로 병행하고 원본 테스트 회귀 0을 지킨다.
2. LOOK-001 결과로 방향과 렌더러를 정한다.
3. 정한 방향을 "강화 모드" 레이어로 화면 단위 확장(맵 → 캐릭터 → VFX → UI 연출).
