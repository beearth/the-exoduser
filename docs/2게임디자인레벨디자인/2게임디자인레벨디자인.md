| 항목 | 값 |
|---|---|

| 최대 기록 | `G.comboMax` (세션 내 최고 콤보) |

| 타이머 표시 | `comboTimerHud` — 1콤보 이상 시 남은 초 표시 (원시 comboTimer<300f: hot #ff9290, <600f: ember #ffb17a, 그 외 gold #ffda87; 초 표시는 60으로 나눠 소수 첫자리 반올림) |

| 스테이지 초기화 | `initStage()` 시 combo=0, comboTimer=0 리셋 |

### 콤보 보상 보너스
콤보 보너스 + 난이도 보너스 합산. 캡 없음.
| 항목 | 공식 | 예시 |
|---|---|---|
| 기본 처치 보상 | 모든 적 처치 시 기본 보상 `+2`에 **획득 배율 x2 적용** | 일반몹 1킬 = +4 |
| 콤보 보너스 | `floor(combo/100) × 5%` | 100콤보=+5%, 500=+25%, 2000=+100% |
| 난이도 보너스 | `OPT.diff × 10%` | 0단=0%, 1단=+10%, 10단=+100% |
| 최종 배율 | `1 + 콤보보너스 + 난이도보너스` | 500콤보+5단 = 1+0.25+0.50 = ×1.75 |
| 적용 대상 | 악의(기본 처치 보상, 엘리트/보스 즉시 자동수급+트레일), 경험치(addExp 배율) | 악의는 worldItems 안 거침, 즉시 G.mats 가산 |
| 일반 난이도(0단) | 보너스 없음 (콤보 보너스만) | |

## 지옥문 개방 / 보스방 입장 조건 (2026-09-30 [REGION] 개편 — 구 2026-06-27 전역 80% 규칙 대체)

스테이지 클리어 흐름: **4분면 지역 클리어 → 지옥문 개방 → 보스방 입장 → 보스 처치 → 클리어**.
큰 오픈맵에서 "어디를 잡아야 하는지" 안내가 없던 문제를 해결하기 위해, 맵을 타일 중점 기준 4분면(0북서/1북동/2남서/3남동, `G._regions`)으로 나누고 **지역 4곳 전부 클리어**를 개방 조건으로 한다. 지역별 임계값은 구 규칙과 동일한 80%라 총 난이도는 대략 유지된다.

| 항목 | 값 |
|---|---|
| 지역 분할 | `_regionInit(si)` — 타일 중점(mw/2, mh/2) 4분면. 한 변 180타일 이상 오픈필드만(`G.mw>=180&&G.mh>=180`) — 소형 맵(한 변 180타일 미만 — 던전·소환굴·보스아레나)은 지역 없음 |
| 지역 total | 해당 분면 소환굴 스폰량 합(`_spawnHoleCount`) — `G._totalSpawned`와 동일 기준 (방/복도 스폰·소환몹 미포함) |
| 지역 kills | **스폰 위치**(`e._homeX/_homeY`) 귀속 처치 수(`_regKill`). 방/복도/소환몹 킬 포함 — 구 전역 규칙과 동일하게 모든 킬 카운트 |
| 지역 클리어 | `kills/total >= 0.80` (+게이트 지역 한정 문지기 보너스 +0.10, 1e-9 부동소수 보정) AND (CH1-1) 담당 앵글러 사망. 래치(한번 클리어되면 유지) |
| 개방 조건 | 지역 4곳 전부 클리어(`_regionClearedCount()>=4`) 시 `G._bossUnlocked=true`. CH1-1 `_fbDone` 이중 안전망 유지 |
| 문지기 비중 | 문지기(`_isGateGuard`) 처치 시 `G._gateGuardKilled=true` → **문지기 스폰 지역(`G._regGateIdx`)에만** 진행도 +10% (구: 전역 +10% — 전역 총량의 10%가 한 지역 총량의 10%로 이동해 체감 난이도 유사) |
| 소프트락 방지 | 빈 지역(total 0 + 앵글러 없음)은 초기화 시 조용히 클리어. 지역 없는 맵에서 `G._totalSpawned<=0`이면 즉시 개방 |
| 개방 연출 | `🔥 지옥문이 열렸습니다` 팝업(#44aaff) + `SFX.victory` (기존 유지) |
| 지역 정화(클리어) 연출 | [2026-09-30 3차 디자인] N<4일 때만 전용 `#regionBanner` purge 모드 — KR `{지역명} — 정화` / EN `REGION PURGED · N / 4` + 금 젬 + 지옥불 플레어 + `SFX.magic` + 고양이 대사(region_clear). 4/4은 지옥문 개방 연출에 인계. 구 showPH 초록 토스트 제거 |
| 지역 입장 배너 | 지역 경계 통과 시 전용 `#regionBanner`(#areaTitle 계열 Hell Gothic, top 28%): KR 지역명(명조 제목체+속성색 젬+금 헤어라인) / EN 대문자(Cinzel) / 상태줄 `처치 k / t (· 앵글러 생존)`. blur-in/out 2.7s. 히스테리시스 1.5타일 + 5초 쿨다운(스팸 방지) |
| 봉인 중 입장 시도 | 출구 밟으면 차단, 45프레임마다 `지옥문이 봉인됨 — 지역 클리어 N/4` 안내(#ff5544). 지역 없는 맵은 구 문구(처치 N% (80% 필요)) |
| 방향 화살표 | 화면 가장자리 화살표(`_drawRegionArrow`)가 가장 가까운 미클리어 지역의 잔존몹 centroid(또는 생존 앵글러)를 가리킴. 개방 후엔 지옥문(#66ccff). 목표가 화면 안이면 숨김. 타겟 20프레임 재계산·무할당 |
| 지역명 | CH1-1: 북서 · 어둠 / 북동 · 번개 / 남서 · 물 / 남동 · 불 (앵글러 속성 테마). 기타 스테이지: 북서/북동/남서/남동 |
| HUD | `지역 처치` 카운터 = **현재 지역** kills/total(클리어 지역은 총량 캡). stageProgressFill = 지역 클리어 N/4 비율 |
| 폴백(구 규칙) | 지역 없는 맵(소형 맵): `G._stageKills / G._totalSpawned + (문지기 +0.10) >= 0.80` |
| 입장 처리 | 개방 후 출구 밟으면 `G._bossLoadPhase=1` → 보스 아레나 로딩 (기존 유지) |
| 초기화 | `initStage`(재도전 포함) 시 `_regionInit`로 전체 리셋. `_loadZone` 시 `_bossUnlocked=false`, `_gateGuardKilled=false` 리셋 |
| 테스트 | `test/regionClearGate.test.js` 7건 (귀속/임계/앵글러/빈지역/문지기보너스/개방규칙) |

### 보스방 입구(출구 타일) 비주얼
- `_drawGateSwirl(ctx,cx,cy,sz,t,unlocked)` 절차적 소용돌이 (이미지 미사용)
- **봉인(빨강)**: `#cc2200~#ff6020` 계열, 라벨 `▼ 지옥문 봉인 (지역 N/4) ▼` (#ff6644) — [REGION] 2026-09-30; 지역 없는 맵은 구 라벨 `▼ 지옥문 봉인 (80% 처치) ▼`
- **개방(파랑)**: `#0066cc~#20a0ff` 계열, 라벨 `▼ 보스방 ▼` (#66ccff)
- 출구 중앙 + 거점 출구 두 곳 모두 동일 헬퍼 사용 (이전 보라색 `_drawPortal` 대체)

## 스테이지 타임어택

| 항목 | 값 |
|---|---|
| 변수 | `G.stageTime` (틱 단위, 60fps), `G._totalSpawned`, `G._stageKills`, `G.playTime` (총 플레이타임, 틱) |
| 초기화 | `initStage()` 시 stageTime=0, _stageKills=0. `_totalSpawned`는 맵 생성 시 소환굴 총 스폰량 합산으로 확정 (S:50, M:100, L:100). 벽 타일 스폰 실패 시 분모 차감 (충돌체 위 스폰은 허용). 신성한 땅은 소환굴 제거 불가 |
| 증가 | 매 프레임 `G.stageTime += sp`, **모든 사망 경로**에서 _stageKills++ (분모 _totalSpawned는 고정) |

### 랭킹 점수 공식
`score = max(0, kills×10 + comboMax×5 + parries×3 - time(초)×2 - deaths×100)`
- 처치수와 시간이 핵심 변수
- 패링/콤보 보너스, 사망 페널티

## 레벨 디자인 원칙 (2026-08-16)

맵유형·에리어 배정·제작 페이즈의 상세는 `docs/4.1맵디자인+설정/맵유형_확장기획.md`가 소스다. **한 장 구성**(장면·비움·유니크)은 `맵구성_1장.md`부터 장별로 적는다. 여기에는 전투/진행에 영향을 주는 원칙만 적는다.

### 공간 원칙
- **대표맵(장 오프너)은 field.** 던전은 특별맵만 (11 빙판길, 16 화산심장, 33 지옥탑 — 예약).
- 일반 스테이지도 지금은 field. 크기 200×200.
- 복제하는 것은 골격. 바꾸는 것은 컨셉. 던전 스텁을 그대로 켜지 않음.
- 시작 6시, 출구 12시. `genFromTemplate`만.

### 진행 구조 (스테이지별 밀도/템포)

같은 벌판에서 밀도·기믹만 올린다.

| 층 역할 | 밀도 | 소환굴 | 템포 |
|---------|------|--------|------|
| X-1 오프너 | 낮음. 랜드마크가 주인공 | 8~10 | 넓은 벌떼. 바이옴 소개 |
| 중반 | 중~고. 지형이 길을 만듦 | 8~12 | 기믹 + 전투 |
| 장 피날레 | 고. 중앙 비움 | 10~15 | 문지기, 지옥문 |

지옥문 규칙은 전 맵 동일 — [REGION] 2026-09-30부터 4분면 지역 4곳 클리어(지역별 처치 80%), 소형 맵(한 변<180타일)만 구 전역 80% 폴백. 소환굴을 구석에 숨기지 않음.

### 난이도 커브
- 몬스터 레벨: `monLv=(hell+1)*100` (1장 100 … 7장 700). 맵유형 확장으로 이 숫자는 바꾸지 않음.
- 장 길이: 1장 4 / 2장 6 / 3장 4 / 4장 7(최장) / 5장 5 / 6장 6 / 7장 3(최단·최고난이도).
- 기믹(빙판·용암·점액)은 전투 난이도와 별개 축. 4장 이전에 타일 기믹 런타임을 연다.

- 전투 밸런스 공식 (스탯/DPS는 `14밸런스+수치테이블/`가 소스)
- 미니보스 본맵 배치 타이밍 (확장기획 P1: 1-3에 1기)
