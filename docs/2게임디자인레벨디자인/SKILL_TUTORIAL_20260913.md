# 요청하지 않은 스킬별 튜토리얼 제거 — 2026-09-13

사용자는 스킬별 튜토리얼의 신규 추가를 요청하지 않았음을 명시했다. 이전 문서의 “사용자 확정” 표기는 잘못된 기록이며 철회한다. 추가된 개별 스킬 안내를 제거하고 기존 튜토리얼을 사용한다.

| 항목 / 적용 위치 | 현재 계약 |
|---|---|
| 추가 팝업 | `skill-tutorial.js`, `skill-tutorial.css` 제거. 얼음보주 등 개별 안내와 `스킬 연습` 버튼을 표시하지 않음 |
| 게임 연결 | 일반/쉬운 HTML의 로드·tick·습득 snapshot/record·사용 used·저장 serialize/restore 연결 전부 제거 |
| 기존 1단계 | `parry-lesson.js`의 기초 전투 12과제. 기본 진입 시 이동 안내로 시작 |
| 기존 2단계 | 1단계 완료 후 `resource-practice.js`의 자원·그로기 실습으로 자동 연결. 명시적 `resourceTutorial=0`만 생략 |
| 후속 안내 | 기존 `system-lesson.js` 유지. 추가 팝업 CSS가 기존 시스템 안내를 숨기던 규칙도 제거 |
| 세이브 호환 | 기존 파일에 남은 `skillTutorial` 필드는 읽지 않으며 새 저장에 기록하지 않음. 캐릭터·스킬·기존 튜토리얼 건너뛰기 상태를 초기화하지 않음 |
| 검증 | `tools/test-original-tutorial.cjs`가 양쪽 HTML의 실제 update 시작 구간을 실행해 기본 1단계 시작·2단계 연결·추가 훅 부재 확인. 기존 기초/자원/시스템 회귀 검사 수행 |
