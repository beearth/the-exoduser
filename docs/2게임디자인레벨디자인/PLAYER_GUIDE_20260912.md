# 별도 플레이어 가이드 — 2026-09-12

1단 전투·2단 자원 실습 종료 후 시스템 튜토리얼이 자동으로 이어진다. 아래 정적 참고 페이지는 별도로 유지한다.

`game-guide.html`은 기본 조작과 전리품·회복을 다시 읽는 한국어 정적 페이지다. 게임 내 자동 튜토리얼을 추가하는 파일은 아니다. 이동·좌/우클릭 포함 11단계 `parry-lesson.js` 확장과 병렬로 작업하기 위해 별도 파일로 제공한다.

접속: `http://localhost:3333/game-guide.html` (기존 `server.cjs` 사용). 게임 내 메뉴 링크는 아직 연결하지 않았다. 배포하려면 해당 HTML을 별도로 포함해야 한다.

| 안내 | 확인한 구현 | 표시 범위 |
|---|---|---|
| 마법/물리 패링 | `parry-lesson.js`: `labels`, `hit` | Q 마법, E 물리; 실제 반사로 성공 |
| 홀딩 | `watchHold` | Q 충전 후 해제, E 3단계 검격; 프레임/시간 대신 게이지 기준 안내 |
| 사슬/전격이동 | `tick`, `allowKey` | Shift 발사/이동, 방향+Space; 방향키는 연습에서 임시 추가 |
| 분노 | `hit`, `tick`, `rageCast` | 패링 축적 100%, 확대 안내 후 이동 키 없이 Space |
| 아이템 줍기 | `game.html`: `BINDS.interact`, 월드 아이템 키 안내 | 기본 R |
| 장비 | `BINDS.inventory`, `equipItem`, `renderInv` 장착 버튼 | 기본 Tab, 조건 확인 후 장착 |

기본 키 안내이며 세이브/런타임의 사용자 바인딩을 읽지 않는다. 연습에서 임시 제공하는 스킬/자원과 실전 습득·장착 조건을 구분해 안내한다. 게임 상태, 저장 데이터, 잠긴 패링 설계, 기존 튜토리얼 파일은 변경하지 않는다.

구성: 앵커 목차, 3개 섹션/14개 카드, 좁은 화면 1열, 키보드 포커스 표시, 인쇄 스타일. 외부 폰트·이미지·스크립트 의존성 없음.

검증: HTML 태그 중첩, 카드 14개, ID 중복 없음, 목차 링크 대상 존재를 검사해 통과했다. 현재 환경에 Playwright 패키지가 없고 localhost 연결도 실패하여 브라우저 렌더링과 HTTP 제공은 확인하지 못했다.
