# 시스템 튜토리얼 — 실습 후 자동 안내

2026-09-12 사용자 요청으로 시스템 가이드를 다시 연결했다. 일반 전투 1단·자원/그로기 2단이 모두 종료되면 별도 시작 버튼 없이 자동 표시한다. 실습 중에는 표시하지 않는다.

| 항목 | 실제 완료 조건 |
|---|---|
| 장비 획득 | pickupItem 성공, 가방/장착 슬롯에 객체 존재 |
| 인벤토리 | 인벤토리 패널 열림 |
| 장착 확인 | 장착 슬롯 선택 또는 equipItem 성공 |
| 능력치 | 능력치 패널 열림 |
| 스킬 | 스킬 패널 열림 |
| 대장간 | 대장간 패널 열림, 강화 소비 불필요 |
| 자동 회복 | HP 증가·악의 1 감소·쿨다운 생성 확인 |

순서는 자유이며 실제 행동으로만 체크한다. 건너뛰기는 성공과 구분한다. 접기·항목 건너뛰기·종료를 제공한다. 키 표시는 현재 바인딩을 따른다. 게임/저장 상태를 바꾸지 않는 관찰 UI이며, 앞선 실습의 해골눈·자원 설명은 반복하지 않는다. JS/CSS는 양쪽 게임 HTML에서 로드하고 update·획득·장착·자동회복 성공 지점에 연결한다.

검증: `node --experimental-vm-modules tools/test-system-lesson.cjs`. 실습 대기, 실제 행동 성공/실패, 퍼즈 중 메뉴 관찰, 키 변경, 건너뛰기/종료, 입력 해제 전파, 상태 보존 및 HTML 구문을 검사한다.

배포에는 system-lesson.js와 system-lesson.css도 포함한다.

수료 배지 3종을 구현했다. 시스템 7항목 실제 완료 시 지옥의 개척자를 지급하며 건너뛰기는 미지급이다. 브라우저 슬롯별 저장·모음 UI·중복 차단은 [배지 사양](TUTORIAL_BADGES_20260912.md)을 따른다. 별도 챌린지/능력치 보상은 미구현이다.

2026-09-12 건너뛰기: 1·2단의 `연습 건너뛰기`는 브라우저 공통 `exoduser:tutorial-skipped:v1=1`을 저장한다. 이후 일반·자원·시스템 튜토리얼은 자동 시작하지 않는다. 시스템 안내의 개별 항목 건너뛰기는 기존처럼 해당 항목에만 적용한다.

2026-09-12 명시적 다시보기: URL `tutorial=1`로 열면 저장된 건너뛰기 설정을 이번 접속에만 무시한다. 기존 localStorage 값은 보존하며, 다시보기 중 건너뛰면 그 접속에서도 즉시 닫힌다. 일반 URL에서는 계속 자동 안내하지 않는다. 3333 확인 링크: `/game-easy-test.html?test=1&slot=tutorial-review&stage=0&tutorial=1`.
