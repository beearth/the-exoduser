# 시스템 튜토리얼 — 실습 후 자동 안내

2026-09-12 사용자 요청으로 시스템 가이드를 다시 연결했다. 현재 일반 진행은 전투1단→자원·그로기2단이 모두 종료되면 별도 시작 버튼 없이 시스템 안내를 표시한다. 1단에서2단으로 연결되는 동안 active가 유지되어 시스템 안내가 끼어들지 않는다. 실습 중에는 표시하지 않는다. 요청하지 않은 스킬별 팝업과 기존 시스템 안내를 숨기던 해당 CSS 규칙은 제거했다.

| 항목 | 실제 완료 조건 |
|---|---|
| 장비 획득 | pickupItem 성공, 가방/장착 슬롯에 객체 존재 |
| 인벤토리 | 인벤토리 패널 열림 |
| 장착 확인 | 장착 슬롯 선택 또는 equipItem 성공 |
| 능력치 | 능력치 패널 열림 |
| 스킬 | 스킬 패널 열림 |
| 대장간 | 대장간 패널 열림, 강화 소비 불필요 |
| 자동 회복 | HP 증가·악의 1 감소·쿨다운 생성 확인 |

순서는 자유이며 실제 행동으로만 체크한다. 건너뛰기는 성공과 구분한다. 접기·항목 건너뛰기·종료를 제공한다. 키 표시는 현재 바인딩을 따른다. 게임/저장 상태를 바꾸지 않는 관찰 UI이며, 앞선 실습의 해골눈·자원 설명은 반복하지 않는다. JS/CSS는 양쪽 게임 HTML에서 로드하고 update·획득·장착·자동회복 성공 지점에 연결한다.

검증: `node --experimental-vm-modules tools/test-system-lesson.cjs`. 실습 대기, 실제 행동 성공/실패, 퍼즈 중 메뉴 관찰, 키 변경, 건너뛰기/종료, 입력 해제 전파, 상태 보존 및 HTML 구문을 검사한다.

배포에는 system-lesson.js와 system-lesson.css도 포함한다.

수료 배지 3종을 구현했다. 시스템 7항목 실제 완료 시 지옥의 개척자를 지급하며 건너뛰기는 미지급이다. 브라우저 슬롯별 저장·모음 UI·중복 차단은 [배지 사양](TUTORIAL_BADGES_20260912.md)을 따른다. 별도 챌린지/능력치 보상은 미구현이다.

2026-09-12 건너뛰기: 1·2단의 `연습 건너뛰기`는 캐릭터별 `exoduser:tutorial-skipped:v2:char:<UUID>` 또는 `exoduser:tutorial-skipped:v2:slot:<슬롯명>`에 1을 저장한다(식별자는 encodeURIComponent). 이후 해당 캐릭터의 일반·자원·시스템 튜토리얼만 자동 시작하지 않는다. 새 캐릭터 생성 시 첫 1-1 진입은 안내한다. 시스템 안내의 개별 항목 건너뛰기는 기존처럼 해당 항목에만 적용한다.

2026-09-12 명시적 다시보기: URL `tutorial=1`로 열면 저장된 건너뛰기 설정을 이번 접속에만 무시한다. 기존 localStorage 값은 보존하며, 다시보기 중 건너뛰면 그 접속에서도 즉시 닫힌다. 건너뛴 캐릭터의 일반 URL에서는 계속 자동 안내하지 않는다. 3333 확인 링크: `/game-easy-test.html?test=1&slot=tutorial-review&stage=0&tutorial=1`.


## 2026-09-21 시스템 안내 영어 보완

system-lesson.js의 7단계·버튼·상태·접근성 문구를 기존 _L에 연결했다. 열린 안내는 다음 표시 tick에서 현재 언어로 갱신하며 단계 체크·건너뛰기·DOM 자식을 보존한다. t(ko,en,values), steps getter, lastStatus(id/skipped), 언어를 포함한 bindingSignature를 사용한다. 신규 KO·EN 원본 34개는 번역 수집기가 검색하며 타 언어 미등록 키는 영어 폴백이다. 전체 영어/29언어 지원 완료나 Steam 배포 완료를 뜻하지 않는다. [구현·원문 표·남은 작업](../16번역·로컬라이제이션/STEAM_LANGUAGE_RESUME_20260921.md).
