## 이후 첫 사용 시 안내 후보

| 후보 | 확인/설계 범위 |
|---|---|
| 장비 비교·교체·분해 | 현재 장착 슬롯 확인 또는 장착 성공까지만 안내. 비교 수치 읽기와 재료 회수는 첫 필요 시 별도 안내. 실제 장비 파괴/재화 소비를 필수 수료 조건으로 두지 않는 방향 제안 |
| 스테이지 목표/출구 | 소환굴·필드 적·출구 조건은 개별 시스템에 존재. 현재 28항목에는 목표 HUD와 출구 해제 설명이 없음. 해당 스테이지의 실제 잠금 이유를 읽어 상황별 안내하는 방향 제안. 맵 수치/좌표/배치 변경 없음 |
| 현재 키·게임패드 안내 통일 | 시스템 안내는 현재 바인딩을 조회하지만 기초 좌/우클릭·Space·Ctrl 등 일부 안내는 고정 문구. 이번 Shift 문제처럼 저장 키와 실제 입력 경로가 일치하는지 동작별 점검 필요 |
