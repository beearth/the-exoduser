# 현재 미션 바로 아래 설명

| 항목 | 구현 |
|---|---|
| 배치 | `placeDetails()`가 진행 중인 체크 행 바로 다음에 `.lesson-details`를 이동한다. 이동·좌/우클릭·가시덫·패링·사슬·분노 및 자원 실습에 적용 |
| 내용 | 기존 hint·홀딩 충전·분노 게이지를 하나의 details 컨테이너로 묶는다. 설명과 게이지가 다음 미션 행보다 먼저 나온다 |
| 갱신 | render마다 현재 미션 행에 맞춰 같은 DOM을 이동한다. 미션별 복제, 부모 textContent 교체, 체크박스/진행 상태 초기화 없음 |
| 자원 안내 | 체크리스트를 숨기는 안내 단계는 안내 블록 다음에 표시. Q/E/Shift 자원 소모 실습은 현재 기술 행 바로 아래에 표시. 기존 자원 readout은 hint 다음 위치 유지 |
| 반응형 | 현재 행과 details는 그리드 전체 열을 차지한다. details 좌측25px·하단8px 패딩, hint 최소높이0·위3px/아래10px 여백 |
| 캐시 | 배치 변경 당시 JS/CSS는 `20260913-mission-details1`. 현재 parry-lesson.js는 `20260913-dash-five1`, CSS는 기존 배치 버전 유지 |
| 검증 | 기존 패링·자원 회귀 검사 통과. 로컬 브라우저에서 E 홀딩 설명·충전 게이지가 현재 행 아래/Shift 행 위에 표시됨을 확인. 기초 과제 및 자원 과제 전환 시 DOM 인접 위치 확인 |
