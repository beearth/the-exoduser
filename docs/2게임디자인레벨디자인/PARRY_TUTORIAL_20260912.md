# 1-1 시작 패링 튜토리얼

일반 `game.html`과 밸런스 시험용 `game-easy-test.html`은 `parry-lesson.js`와 `parry-lesson.css`를 로드한다. `G.stage === 0`(1-1) 시작 연출 종료 후 실행하며 안내를 읽는 동안 `update()`를 정지한다. 해당 스테이지 진입당 1회 실행한다. 완료 여부는 세이브에 영구 저장하지 않는다. 단, 연습 건너뛰기는 캐릭터별 localStorage v2 키로 저장하여 해당 캐릭터의 재접속에서만 모든 튜토리얼 자동 시작을 차단한다. 새 캐릭터는 첫 1-1 진입 시 반드시 안내한다. 저장소 사용 불가 시 현재 세션에서만 기억한다.

첫 안내만 정지한다. 성공 시 게임 틱·애니메이션을 유지하고 체크박스를 성공으로 바꾼다. 각 성공은 90틱 후 다음 연습으로 자동 진행(단발 연습 탄 발사 유예 45틱), 열한 번째 성공은 90틱 후 [2단계 자원·그로기 실습](RESOURCE_PRACTICE_20260912.md) 실습으로 자동 진행한다(추가 시작 버튼 없음). 2단계까지 완료하거나 건너뛰면 원래 1-1 전투로 복귀한다. 성공 후 추가 버튼 입력은 없다. 연습 중 패링 hitStop/slowMo도 적용하지 않는다. 실패하면 해당 단계의 자세와 탄을 초기화하고 60틱 후 재발사하며 이미 완료한 체크는 유지한다. 홀딩을 일찍 풀거나 한 번의 해제로 3발을 반사하지 못하면 탄 무리와 충전을 초기화하고 60틱 후 같은 단계를 재시도한다. 이전 시도의 반사 수는 누적하지 않으며 같은 탄의 중복 판정도 제외한다. 분노 축적 단계는 마법탄 10발을 동시에 발사하며 실제 패링 보상 공식을 그대로 사용한다. 100 도달 시 바로 성공 처리한다. 미달이면 남은 적대 탄이 모두 반사·소멸한 뒤 45틱 비행 표시와 60틱 대기를 거쳐 다음 10발을 발사한다. 일부 반사만으로 남은 탄을 회수하지 않는다. 건너뛰기는 체크를 성공으로 바꾸지 않고 전투로 복귀한다. E로 마법 연습 탄을 반사하는 것은 차단한다.

## 연습 UI 디자인

사용자의 GPT 디자인 요청에 따라 연결된 GPT 이미지 생성 도구로 검은 금속·흑석·황동 장식 배경을 제작했다. 별도 API 키를 사용하는 직접 API 호출은 수행하지 않았다. 기존 HUD의 외부 이미지 금지 원칙은 이번 명시적 이미지 생성 요청에 해당하는 튜토리얼 배경에만 예외로 적용한다.
