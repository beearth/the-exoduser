## 1. 표시 시점 / 흐름

보스 사망(`checkRooms` 아레나 보스 체크, `G.bossAlive=false` 지점)에 **클리어 타임 스냅샷**(`G._bossClearT`, 초) → 아레나 출구 밟기(`G.stageCleared=true`) 시 `_showClearResult()`가 기존 `#stageClear` 패널 상단의 **`#clearResult`** 블록을 채움 → 기존 `#clearStats` 상세/`#nextBtn` 흐름 유지. **데모(1장 1스테이지)**: 결과 패널 → `데모 종료` 버튼 → `nextStage()` → `#demoEnd` — 데모 종료 화면 **이전에** 표시됨. 키보드/게임패드 진행(기존 nextBtn 흐름) 무변경.

## 2. 클리어 타임 정의

- `G.stageTime` 사용 — **update() 루프 틱**(60fps 단위)이라 `G.on=false`(오프닝 시네마틱), `G.paused`, 튜토리얼/레슨 오버레이(`_parryLesson.tick()`이 update를 조기 반환) 동안 **자동으로 흐르지 않음** (증분 위치 game.html update 내 `G.stageTime+=sp`, 모든 조기 반환 뒤). 검증 완료.
- 스냅샷은 **보스 사망 시점**(출구까지 걷는 시간 미포함). 사망 재도전은 `initStage` 리셋 경로면 타임도 리셋(기존 `_sStats`와 동일 규칙), 아레나 게이트 리스폰이면 누적.
- `G._bossClearT`는 `_regionInit`(initStage마다 호출)에서 `null` 리셋. 표시 시 결측이면 `stageTime` 폴백.

## 4. 기준시간(par) / 기준점수(parScore)

- **par = 90 + `G._totalSpawned` × 2.5 (초)** — 1장 1스테이지(데모): 168스폰 → **510초 = 8:30**.
  - **산정 근거**: QA 문서에 스테이지 클리어 실측 타임 데이터가 없어(2026-09-30 기준) 추정치로 확정 — 오픈필드 킬당 이동+전투 ~2.5초(200×200 맵, 소환굴 14개 분산) + 고정 오버헤드 90초(시작 안전지대→첫 교전, 문지기, 앵글러 4기상, 보스 아레나 진입/연출). 브라우저 자동 검증의 무전투 도달만으로도 ~1분 소요. 실측 데이터 확보 시 이 계수만 갱신하면 됨(코드 `_clearParTime` 1곳).
- **parScore = `_totalSpawned` × 10 + 3,500** — 전 스폰 처치(1,680) + 지역 2,000 + 보스 1,000 + 여유 500 근사. 1장1스테이지=5,180.

## 5. 랭크 (S/A/B/C/D — par 시간·점수 결합)

랭크 포인트 rp (최대 6):
| 축 | 조건 → 점수 |
|---|---|
| 시간 (ratio = clearSec/par) | ≤0.7 → 3 / ≤1.0 → 2 / ≤1.5 → 1 / 초과 → 0 |
| 점수 | ≥parScore → 2 / ≥parScore×0.6 → 1 / 미만 → 0 |
| 무사망 | +1 |

**rp ≥6 = S / ≥4 = A / ≥3 = B / ≥2 = C / 그 외 D.** 색: S #ffcc44 / A #66ffaa / B #88ccff / C #ccaa88 / D #886655 (`_RANK_COL`).
예: 5:00 무사망 고득점=S(6) · 8:00 무사망=A(5) · 11:00 1사망 중간점수=C(2) · 방치 후 클리어=D.

## 6. 베스트 기록 (세이브)

- `G._clearRecords[si] = {t:최소 클리어초, s:최대 점수, r:최고 랭크}` — 필드별 독립 베스트(`_clearRecordMerge`).
- 직렬화: `game.clearRecords` — 세이브 빌더 4곳 + `dbRestore` 복원. **구세이브 결측 = `{}` = 기록 없음** (첫 클리어가 기록 생성; 마이그레이션 변환 불필요). `15 세이브+데이터구조.md` 동기화.
- 표시: 시간/점수 각각 종전 기록 경신 시 `✦신기록!` (첫 클리어는 표시 안 함 — 비교 대상 없음). 하단 `🏆 베스트 t / s / r` 상시.
