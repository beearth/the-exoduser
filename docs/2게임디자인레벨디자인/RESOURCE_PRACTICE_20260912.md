# 2단계 자원·그로기 실습

`resource-practice.js`는 `parry-lesson.js`의 격리된 월드·입력 제한·UI·원상 복구를 공유한다. 1단 8항목 성공 후 90틱 뒤 시작 버튼 없이 2단 실습으로 자동 진행한다. 2단은 최초 60틱 발사 유예를 유지한다. 2단은 10항목이며 설명만 읽거나 키만 눌러서는 완료되지 않는다. 두 실습 종료 후 원래 전투로 복귀하며 시스템 튜토리얼이 자동 시작한다.

## 보호막 흡수 설명·아이템 보정 (2026-09-12)

| 항목 | 실제 값·공식 |
|---|---|
| 기본 | 피해 흡수 30% |
| 수호신 `pGuard` | 레벨당 +2%p, 최대10레벨 |
| 견갑 `shieldBlockDR` | 블록흡수의 옵션 T0~T4: +4/7/11/16/22%p |
| 합산 `pGuardAbsorb()` | `min(.50, .30 + PASSIVES.pGuard*.02 + _eqAffix('shieldBlockDR'))` |
| 이번 3발 홀딩 | 패링 시간 경과 후 흡수율 `min(.25,pGuardAbsorb()*.5)` → 기본15%, 최대25%. 흡수 후 정수 피해에1.3배 적용. HP 최소1 |
| 설명·표시 | 기본/패시브/아이템/상한 및 홀딩 페널티 설명, 현재 합산 흡수율과 이번 실습 적용률을 별도 표시 |

정의만 존재하던 `shieldBlockDR`을 두 게임 HTML의 `pGuardAbsorb()`에 연결했다. 원래 50% 상한과 패링 실패 시25% 상한은 유지한다. 해당 공용 함수를 쓰는 실전 보호막과 튜토리얼2에 함께 적용하며, 패시브만 따로 계산하는 회전참 흡수율은 바꾸지 않는다. 따라서 아이템 보정은 설명뿐 아니라 실제 피해에 반영된다.

검증: 두 HTML의 실제 함수를 읽어 기본30%, 패시브1레벨32%, 아이템4%p→34%, 아이템22%p→상한50%, 패시브·아이템 합산 상한을 확인했다. 최대HP1000에서 2단 연습 탄을 홀딩으로 받을 때 무옵션22/아이템4%p20/아이템22%p19 피해 및 표시50%/25%를 검사해 통과했다.

수료 배지: 모든 체크를 실제로 완료하면 1단은 지옥의 첫걸음, 2단은 불굴의 생존자를 지급한다. 건너뛰기는 미지급. [배지 저장·UI 사양](TUTORIAL_BADGES_20260912.md).

2026-09-12 이동 허용: 연습 시작 후 모든 자원 단계에서 WASD/방향키 입력을 허용하고 매 틱·단계 진입 시 위치 강제 복귀를 제거했다. 그로기 등 실제 캐릭터 상태의 이동 제한은 유지한다. 4연속 피격 단계에서 탄을 피해서 4회 피격에 못 미치고 모든 탄이 소멸하면 75틱 후 같은 실습을 재시작한다.
