2026-09-27 사용자 지정으로 이 폴더의 실버테일 키아트 6장은 프로젝트에서 제거했다. 현행 공식 원본 2장은 [실버테일 공식 이미지](../../../archetypes/silvertail/SILVERTAIL_KEYART_CANON_20260927.md)를 따른다. 전투용 스프라이트와 VFX는 별개이다.
