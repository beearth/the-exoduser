## 2. 연결 지점 (조사 결과: 4키 모두 지금 게임에 전용 소리가 없다 → 새로 연결)
| 키 | 연결 | 조건·음량 |
|---|---|---|
| `crit_heavy` | `hurtE` 안 치명타 판정 블록(`_isCrit=true;` 직후) | `!isDot&&!noSound&&_critSfxCd<=0`일 때 `playSample('crit_heavy',.45,_r(1,.05))`, `_critSfxCd=12`. `_critSfxCd`는 `_hitSfxCd` 옆에 선언하고 같은 곳(`if(_hitSfxCd>0)_hitSfxCd--;`)에서 감소. 우선순위는 기본 분류(HIT)로 둔다 |
| `ui_button_hover` | `document`에 위임 리스너 1개: `pointerover`에서 `e.target.closest('button')`이 바뀌었을 때 | 같은 버튼 재진입 무시, 60ms 쿨다운, `.disabled`/`disabled` 제외, 음량 .25 |
| `ui_button_confirm` | `document` `click`(capture) 위임: 대상이 `button`일 때 | 클릭 처리기가 자기 소리를 냈으면 겹치지 않게 한다 — `playSample`·`playTone`·`playNoise`에서 `_lastSfxAt=performance.now()`를 기록하고, click 뒤 `setTimeout(0)`에서 `_lastSfxAt`가 클릭 시각 이후로 갱신되지 않았을 때만 재생. 80ms 쿨다운, 음량 .35 |
| `amb_hell_forest_bed` | `BGM.play(key,force)`에서 `this._curKey=key;` 직후 `_ambSync(key)` 호출 | `key==='hell1'`이면 `createBufferSource`로 루프 시작, 그 외(보스·사망·승리·대장간·다른 장)는 `_stopLoop(ref,800)`로 페이드 정지. 음량 .15. 버퍼가 아직 없으면 fetch·decode 뒤 여전히 원할 때만 시작. `_startLoop(key,vol)`은 이름 충돌로 사용하지 않음 |

- 쿨다운·음량은 1차값이다. 반영 뒤 실제 게임 녹음으로 조정한다.
- UI 위임 리스너는 로비(`index.html`)에는 넣지 않는다(game.html 전용). 버튼 소리 범위 전수는 AD2에서 따로.
