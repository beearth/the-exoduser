## 3. 공통 발견

| 발견 | 내용 | 승격 때 처리 |
|---|---|---|
| 음량 과다 | 디코드 기준 최대 +1~+5dBFS(0dB 초과). 기존 게임 파일(heavy_hit·sword_parry 등)도 비슷하게 뜨겁다 | 승격 시 -1dBTP 리미트 + 같은 역할 기존 파일과 RMS 맞춤 |
| 초저역 쏠림 | `crit_heavy` 3개·`giant_slam_cast` 3개가 250Hz 아래 99% 이상. 작은 스피커에서 거의 안 들릴 위험 | crit_heavy 재생성, giant_slam은 v3 중역 확인 후 판단 |
| 프롬프트 실패 | `button_hover`=반복 똑똑똑(7~8회), `button_confirm`=걸쇠 없이 쉬익 잡음 | hover는 첫 똑 자르기 또는 재생성, confirm 재생성 |
| 늦은 정점 | `blade_flesh` 3개 모두 정점 150~200ms 뒤 | 앞부분 약 120ms 자르기 |
| 루프 이음매 | `hell_forest_bed` v1 끝이 처음보다 5.9dB 큼 | 끝-처음 크로스페이드 가공 |
