## 2. 공통 음악 언어

- 악기와 공간: 낮은 현악·심연 금관·뼈/나무/사슬 타악, 짧은 잔향. 지옥의 넓은 어둠 위에 드문 빛이 드러나는 구조. 필드 곡은 주제가의 전면적 클라이맥스보다 낮은 밀도로 두어 전투 예고음과 보이스가 묻히지 않게 한다.
- 형식: 가사 없는 인스트루멘털. 2~3분의 반복 가능한 본체, 시작·끝의 갑작스런 큰 히트와 트레일러식 상승을 피한다. 정확한 루프 편집과 믹스 게인은 채택 후 원본을 듣고 정한다.
- 배제: 밝은 모험 선율, 신스·EDM·전자 효과, 맑은 차임, 긴 효과음 리버브, 보스전처럼 계속 최대 음량인 합창. 기존 작품의 고유 선율·편곡을 복제하지 않는다.
- 후보 판정: 후보별 장면 적합성은 사용자 청음으로 결정한다. RMS·피크·길이 측정은 결함 선별용이며 음악 선택의 근거가 아니다.

## 4. 제작·채택 게이트

1. 각 슬롯은 먼저 **서로 다른 해석 2개**를 만든다. 생성 전 비용과 사용 가능한 서비스·상한을 확인한다. 새 유료 크레딧 지출은 인계 공통 규칙에 따라 별도 사용자 확인 전 실행하지 않는다.
2. 사용자에게 장면 카드·기존 2~3곡·새 후보를 같은 음량으로 비교하게 한다. 후보가 모두 안 맞으면 `none/retry`를 유지한다.
3. 채택 파일만 길이·진피크·루프 이음매·게임 SFX/보이스 위의 마스킹을 검사한다. 실게임 청음에서 BGM이 예고음·피격음을 가리면 믹스부터 조정한다.
4. `game.html` `BGM` 큐를 바꿀 때 `6사운드디자인.md` 표, DEMO/EA, Unity 별도 줄기의 실제 파일·키·빌드 검증을 각각 갱신한다. 후보 파일을 만든 것만으로 재생 풀 24곡을 달성했다고 쓰지 않는다.
