## 2. R8 청음 세트

- 대상: 8카드(숲 바탕음, 생체나무 맥동·호흡, 드루이드 등장·퇴장, 보스 처치, 출구 열림·진입). 새 키 8개 × 해석 3개 × 변형 3 = 72개다. 지금 게임 소리 2줄(숲 바탕음·가라앉기)과 합쳐 74줄이다. 피크 −18dB 미만으로 키운 변형 2개에는 주의 표시를 달았다.
- 영상(소리와 같은 시각에 재생):
  - 숲·생체나무·출구: 같은 원화를 쓰는 웹 1-1의 같은 장소 10초 영상(`web3d-r9` 녹화)이다.
  - 생체나무: 원화가 움직이지 않아서, 소리 박자에 맞춘 맥동(4초마다 부풂·붉은빛)과 호흡(6초 주기) 연출 시안을 입혔다.

## 2.2 Unity 배선 — 고르면 파일만 넣는다 (2026-11-04, CTO 배정)

R8·R9의 키와 시각은 Unity에 이미 연결돼 있다. 사용자가 고른 가공본을 **`unity/Assets/Exoduser/Resources/Audio/RM1/<키>.mp3`** 이름으로 넣으면 코드 수정 없이 바로 난다.
- 우선순위: 키 이름 파일 → 대체 파일(`NativeSoundWire.Fallbacks`) → 기록만(Receipt "no file yet").
- 시각은 Core 틱 기준이고, Core 코드·수치는 바꾸지 않았다.
