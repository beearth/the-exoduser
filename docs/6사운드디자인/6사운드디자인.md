#### 이벤트 디렉터 규칙

1. **중요도 선점**: 사망(100) > 궁극·위기(85~75) > 패링(80) > 피격·강공격(65~60) > 정예 처치(55) > 경공격·회피(35) 순이다. 더 높은 줄이 재생되면 낮은 줄은 끊지 않고 해당 이벤트만 생략한다.

3. **상태 전환 1회성**: 저체력은 30%를 **처음 통과할 때만**, 회복 후 다시 30% 아래로 내려갈 때 재무장한다. 부활·정예 처치도 한 사건당 한 줄만 허용한다.

### 8. 포맷 규칙 — 확정 사실과 제안

**확정 사실(코드·실측으로 확인된 것)**

| 항목 | 사실 |
|---|---|
| 로더 | SFX는 `fetch`→`decodeAudioData`라 mp3·wav 어느 쪽이든 읽힌다(확장자 제한 코드 없음). BGM은 `Audio` 요소라 브라우저가 지원하는 포맷이면 된다 |
| 보이스 | 전부 mp3·44.1kHz·128kbps, 모노 위주(스테레오 11개). ElevenLabs `mp3_44100_128` 출력을 그대로 쓴 결과와 일치 |
| SFX Forge 산출물 | ElevenLabs 기본 출력(mp3 44.1kHz 모노 128kbps)을 `−1.0 dBTP` 천장으로 가공해 승격한다(`sfx/tell/`·`sfx/ui/`·`sfx/ambient/` 신규 파일이 이 규격) |
| **SFX 가공 기본값 (2026-10-28 사운드 총괄 결정)** | 신규 SFX는 **35Hz 하이패스(4차) → −1.0 dBTP 정규화** 순서로 가공한다. 생성 원본은 40Hz 아래에 에너지가 몰려 있는 경우가 많아, 들리지 않는 초저역이 −1dBTP 천장을 먹으면 들리는 부분이 약 4~10dB 작아진다(드루이드 2차 후보 실측). 기존 채택본은 재가공하지 않고, 영향 측정은 [SFX_HPF_AUDIT_20261028.md](SFX_HPF_AUDIT_20261028.md) |
| 샘플레이트 혼재 | 같은 폴더 안에 44.1k와 48k가 섞인 곳이 있다(`death`·`monster`·`skillsound` 등). `AudioContext`가 재생 때 맞추므로 동작에는 영향이 없다 |
| 비트레이트 혼재 | SFX mp3는 128k·192k가 대부분이고 256k·320k 일부(`magic`·`swing`·`misc/footstep`), 64k 1개 |
| wav | SFX wav 10개 중 코드에 등록된 것은 2개(`hit/player_projectile_impact.wav` 모노 0.04MB, `weapon/bow_releasE.wav` 1.0초 스테레오 0.18MB). 나머지 8개는 미등록. BGM wav 17개는 1.16GB 중 대부분을 차지한다 |

| 번호 | 제안 | 근거 |
