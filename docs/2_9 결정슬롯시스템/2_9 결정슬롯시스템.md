## 2026-09-27 장비칸 이미지와 보석 홈

보석함 장비칸은 정사각형 원화에 맞춰 카드도 `aspect-ratio:1`로 표시한다(최소 높이72px). `_itemSkin(item,96)`을 생성하고 이미지가 카드 안쪽1px를 채우되 확대·잘림 없이 `object-fit:contain`을 사용한다. 넓은 화면은 5열×6행, 700px 이하는 4열, 480px 이하는 3열 자동 흐름이다. 좁은 화면에서 중앙 인물 장식은 숨긴다. 빈 홈과 장착된 홈은 스킨 위 하단에 위치한다. 빈 홈은 검은 중심과 어두운 2px 링을 유지한다. `pointer-events:none`인 아이콘은 홈 클릭·드래그 드롭을 가리지 않는다. 장착 조건·홈 수·아이템 옵션·저장 구조는 바뀌지 않는다. 현행 CSS 캐시는 `inventory-gems-finish.css?v=20260927-square-art2`.

## 2026-09-27 보석 단독 드래그 표시

보유 보석 좌클릭 홀드 후 6px 이상 이동하면 58×58px 보석 그림만 커서 중앙을 따라간다(투과 영역 64×64px, `aria-hidden=true`, `pointer-events:none`). 기존 이름이 붙은 드래그 카드와 배경은 제거한다. 수량 1개 묶음은 드래그 중 원래 칸의 그림을 숨기고, 여러 개 묶음은 나머지 수량을 나타내기 위해 그림을 유지한다. 취소·외부 드롭은 원래 칸 표시를 복구하며 장착·저장이 일어나지 않는다. 호환 빈 홈 드롭의 원본 객체·장비·홈·부위 재검증과 성공 시 1개 장착·저장 경로는 기존 계약을 따른다. 당시 CSS 캐시는 `inventory-gems-finish.css?v=20260927-gem-only1`.

## 2026-09-27 빈 결정 홈 시각 규칙

보석함 장비판의 빈 홈(`data-filled=false`)은 가운데가 검은 홀이다. 기존 `◇` 표식은 시각적으로 숨기고 금속 외곽 링으로 위치를 드러낸다. 호환 선택(`data-ready=true`)과 드래그 대상(`data-drop-target=true`)은 중심을 계속 검게 둔 채 테두리·외부 광택만 강하게 표시한다. 드래그 CSS는 실제 상태가 기록되는 `#invCrystalsPanel[data-gem-dragging=true]`를 참조한다. 채워진 홈은 실제 보석 이미지와 고유색 테두리로 구별한다. 접근성 이름, 홈 크기, 부위 제한, 장착·탈착, 수치·저장은 그대로다. 당시 CSS 캐시는 `inventory-gems-finish.css?v=20260927-gem-only1`.

## 2026-09-27 보석함 포인터·드래그 장착 계약

보석함 칸의 정확한 hover를 위해 비활성 `.panel:not(.on)`의 모든 자식 포인터 입력을 막는다. 닫힌 능력치 창의 자식 `pointer-events:auto`가 보석 칸 위에 겹쳐 실제 hover를 가로채던 문제를 해결한다. 보유 보석 좌클릭 누름은 즉시 `_invCrSelected`를 설정하고 기존 호환 빈 홈 강조를 갱신한다. 누른 채 6px 이상 이동하면 입력 투과 드래그 아이콘을 보이고, 커서 아래의 호환 빈 홈만 드롭 대상으로 강조한다. 마우스를 놓을 때 `CRYSTAL_BAG`의 원본 보석 참조·현재 장비 객체·빈 홈·`CRYSTAL_DEFS[id].slots`를 다시 확인해 성공한 경우에만 `attachCrystal`과 `dbSaveNow()`를 호출한다. 그 외 위치에 놓거나 Escape/포인터 취소하면 장착·저장 없이 표시를 정리한다. 클릭 장착·탈착 및 키보드 조작은 유지한다. `inventory-gems-finish.css?v=20260927-gem-drag1`.

| 입력 | 선택/드래그 중 강조 | 놓은 뒤 결과 |
|---|---|---|
| 호환 빈 홈 | 카드 `ready`, 홈 `data-ready=true`, 커서 아래 홈 `data-drop-target=true` | 보유 1개 이동·해당 홈 장착·저장 |

## 2026-09-27 고유 보석 전면 교체 — 현행 SSOT

18개 `CRYSTAL_DEFS`의 현행 시각 자산은 [보석함 아트 매핑](../3.1%20ui%20hud%20디자인/GEM_ATELIER_20260927.md)의 로컬 투명 3×3 시트 2장이다. `_crArt`가 id 순서의 시트·행·열을 정하고 보석함/장착 홈/대장간 아이콘이 이를 공유한다. 기존 `form`·`sigil`·`svg`는 로딩 실패 폴백과 텍스트 표기로만 남긴다. 이번 아트 변경에서 아래 옵션 배율·성급·슬롯·세이브 계약은 유지한다.

### 빈 홈 장착 피드백 (2026-09-27 최신)

채워진 장비 홈에 마우스가 들어가거나 키보드 초점이 오면 그 홈의 **장착 보석 자체**를 왼쪽 감정판에 잠시 표시한다. 이름·성급·강화·2~3개 실효 옵션·설정 문구는 보유 보석과 같은 렌더를 사용하며 성급 행에 `장착 중: <부위>` / `Equipped: <slot>`을 추가한다. 홈을 벗어나거나 초점을 잃으면 기존 선택 보유 보석의 감정판으로 복귀한다. 미리보기는 주머니·장착 상태·저장을 수정하지 않는다.

보유 보석을 선택하면 장착 장비의 17부위 중 해당 보석 `slots`에 속하면서 **빈 홈이 있는** 카드만 `data-socket-state=ready`로 표시한다. 호환되지만 모든 홈이 찬 카드는 `full`, 비호환 카드는 `incompatible`이다. 기존 `data-compatible`와 실제 장착 검증은 유지한다. 비어 있고 호환되는 버튼에만 `data-ready=true`를 붙이고 보석 고유색(`--socket-gem`)으로 홈 테두리·광택을 표시한다. 이미 장착된 보석 홈은 해당 보석색 테두리를 쓰되 탈착 기능은 그대로다. 장비판 안내는 선택 시 `readyCount`(호환 빈 홈 합계)와 장착 지시, 미선택 시 기존 장착/탈착 안내를 표시한다. 저장·전투 수치·비용은 변경하지 않는다. 현행 CSS 캐시는 `inventory-gems-finish.css?v=20260927-gem-only1`.

**세이브 전환:** `dbRestore()`에서 구 id 18개를 위 표의 같은 순서 고유 id로 1:1 전환한다. `star`, `enh`, 수량, 장착 위치는 보존하고 보유 주머니·장착 장비·가방 장비·창고 장비의 홈에 모두 적용한다. 한 번 저장되면 새 id로 직렬화된다. 구 id의 드롭/제작은 더 이상 발생하지 않는다.

장비에 **결정 슬롯**(소켓)을 두고, **악의결정**(보석)을 장착하여 추가 스탯을 부여하는 시스템.

## 결정 슬롯

### 기본 규칙
- 장비 드롭 시 **소켓 수 랜덤** (1~4개) — 소켓 수 = 결정 티어
- weapon, bow 포함 전 장비 대상
- 빈 슬롯 = 효과 없음, 결정 장착 시 즉시 스탯 반영
- 탈착 자유 (비용 없음, 파괴 없음)

### 소켓 수 확률 (드롭 시 결정)
| 소켓 수 | 티어 | 확률 |
|---|---|---|
| 1개 | 1티어 | 50% |
| 2개 | 2티어 | 30% |
| 3개 | 3티어 | 15% |
| 4개 | 4티어 | 5% |

### 데이터 구조
```js
item.socketCount = 1~4          // 드롭 시 랜덤 결정
item.crystals = [null, ...]     // socketCount 길이 배열, null=빈칸
```

## 강화

### 공식
- 결정 강화 비용: `악의 = 결정기본가 × (1 + 강화레벨 × 0.5)` + **동급 결정 1개** (같은 종류 + 같은 성급)
- 성공률: 100% (실패 없음, 재료 결정 + 악의 소모)
- 강화 효과: 강화레벨당 **+10%** (1강=+10%, 10강=+100%=2배, 20강=+200%=3배)
- 강화 상한: **+20강**

### 강화 비용 테이블 (1성 기준)
| 강화 | 비용 (악의) | 누적 |
|---|---|---|
| 0→1 | 500 | 500 |
| 1→2 | 750 | 1,250 |
| 5→6 | 1,750 | 6,250 |
| 9→10 | 2,750 | 16,250 |
| 14→15 | 4,000 | 36,250 |
| 19→20 | 5,250 | 60,250 |

- 성급 보정: 2성 ×1.5, 3성 ×2.5, 4성 ×4, 5성 ×7

## 획득

### 드롭
- 일반몹: 15%×dropBonus, 1~2성 (1성 80%, 2성 20%)
- 엘리트: 15%×dropBonus, 1~2성 (1성 50%, 2성 50%)
- 보스: 80%, 2~4성 (4성 40%, 3성 42%, 2성 18%)
- 장보스(챕터 최종): 80%, 2~5성 (5성 5%, 4성 25%, 3성 45%, 2성 25%)

### 분해
- 결정 분해 → **결정 가루** 획득
- 결정 가루로 원하는 종류의 결정 제작 가능

### 제작 (가루)
- **결정 가루 × N** → 원하는 종류 + 성급의 결정 제작
- 비용: 1성=50가루, 2성=200가루, 3성=500가루, 4성=1500가루, 5성=5000가루
- 분해 환급: 제작비의 50%

### 제작 (악의 → 1성 결정)
- **악의 50** → HP/MP/ST 결정만 제작 가능 (`craft:true` 플래그)
- ATK/크리/치명/원소/유틸 등 나머지 결정은 **드랍으로만** 획득
- 대장간 💎결정 → 🔨분해/제작 서브탭 하단

### 합성 (성급 업그레이드)
- **같은 종류 3개** 합성 → 1성급 상승
- 예: 1성 HP결정 × 3 → 2성 HP결정 × 1
- 강화 수치는 리셋 (0강으로)
- 최대 5성 (`CRYSTAL_STAR[4]`) — star≥4 결정은 합성 불가

### ⚡ 최상위 일괄합성 (bulk synth)
- 대장간 💎결정 → 🔄합성 서브탭 상단 **⚡ 최상위 일괄합성** 버튼
- 동작: 현재 선택한 분류 안에서 합성 가능한 모든 그룹을 반복 합성 → 더 이상 3개 모이는 그룹이 없을 때까지
- 새로 생성된 결과물도 다음 반복에서 다시 합성 대상이 됨 (연쇄 상승)
- 버튼 비활성: 합성 가능한 그룹(같은 id+star 3개 이상, star<4)이 하나도 없을 때
- 완료 시 `addTxt` "일괄합성 완료 ×N" 알림 (N=총 합성 횟수)
- 영문 번역: "Bulk Synth to Top" / "Bulk synth done"
