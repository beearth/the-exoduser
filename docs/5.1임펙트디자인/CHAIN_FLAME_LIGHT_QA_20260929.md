# 기동불꽃 과광원·잔광 재발 방지 기록 (2026-09-29)

사용자가 Shift+우클릭 광원이 과하고 사라지는 속도가 느리다고 지시했으며, 반복 문제가 되므로 MD로 남기도록 재확정했다. 향후 기동불꽃·장판 조명·착지 VFX를 수정할 때 이 기준과 [현재 수치 계약](사슬기동_착지임팩트_실사시트_20260904.md)을 먼저 읽는다.

## 원인과 적용 기준

화면 전체 섬광, 가산 착지 시트, 불바닥 조명이 동시에 켜져 주변 바닥과 캐릭터 대비를 약하게 만들었다. 불바닥 광원이 장판의 전체 수명 동안 유지되고 중첩으로 수명이 늘어날 때 잔광도 길게 남는 구조였다.

| 항목 | 유지해야 할 기준 |
|---|---|
| 장판 조명 라우팅 | `assaultFlame` 전용 분기를 일반 `el===EL.F` 분기보다 먼저 처리한다. 공용 화염 광원으로 되돌리지 않는다. |
| 광원 범위·세기 | `r*1.35`, `(.24+sin(_gameFrame*.13+_fzL)*.03)*max(0,1-t/24)^2` |
| 잔광 종료 | 나이 `t>=24f`이면 광원을 추가하지 않는다. 중첩 장판의 `maxT` 비율로 잔광을 늘리지 않는다. |
| 중첩·풀 재사용 | `t=0`으로 갱신할 때 24f의 짧은 잔광만 다시 시작한다. |
| 착지 시트 | `chain_assault_impact`: speed `4`, baseAlpha `.5`, 9프레임·36f (60fps 기준 약 0.6초) |
| 화면 섬광 | 티어 1/2/3의 `G._flashT=.6/.8/1`, alpha 최대 `.108/.144/.18` |
| 전투 계약 | 피해·범위·장판 수명·스택·기폭은 시각 감쇠와 분리한다. |
| 반영 파일 | `game.html`, `game-easy-test.html` 양쪽을 동기화한다. |

사용자 최신 지시 없이 위 광량·범위·잔광을 다시 높이거나 길게 만들지 않는다. 다른 화염·얼음·보스·환경 광원 수정 시에도 기동불꽃 전용 분기를 보존한다.
