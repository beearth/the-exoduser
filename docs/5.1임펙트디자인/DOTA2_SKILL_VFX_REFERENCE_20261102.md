## 목적과 현재 단계

사용자 지시: “스킬이나 임펙트 도타에서 영감을 많이 얻어서 게임제작에 쓸거니까”. 스킬의 형태·전달 방식·접촉 표현·상태 식별을 EXODUSER 제작에 활용한다. 캐릭터 외형 연구보다 스킬/VFX를 우선한다.

**현재 단계: 공식 설명 확인 + 시연 화면 표본 관찰 + 제작 제안.** 아래 적용안은 EXODUSER의 채택·구현 결과가 아니다. 공식 사이트 시연의 전체 시간축, 프레임별 정점·수명, 사운드는 검수하지 않았다. 수치 측정이나 도타 최신 클라이언트 실플레이 검수로 취급하지 않는다.

| 책임 | 범위 |
|---|---|
| 레퍼런스 담당 | 출처·관찰 범위·연출 분해·EXODUSER 적용 후보·검수 기준 정리 |
| VFX 총괄 | 기존 기준과 후보 조율·디자인 채택·실제 게임 시각 판정 |
| 구현 담당 | 승인된 대상의 에셋·이벤트 연결·폴백·성능 확인 |

상위 기준은 [VFX 총괄](VFX_LEAD_MASTER_20261026.md), [통합 컨셉](../0마스터플랜/EXODUSER_DESIGN_CONCEPT_V1_20261026.md), [VFX 구현 가이드](VFX_구현가이드.md)다. 기존 팔레트·범위·수명 기준을 이 문서에서 재정의하지 않는다.

## 우선 제작 검토안

아래는 구현 담당이 검토할 초안이다. 기존 스킬 이벤트·좌표·시간을 읽어 표현하며 피해 이벤트나 시간을 새로 만들지 않는다. 신규 스킬 기획은 현재 스킬 개선과 별도 제안으로 관리한다.

### A. 대검 베기 — D2-07

| 단계 | 제작 제안 | 검수 질문 |
|---|---|---|
| 준비 | 기존 무기 자세·동작으로 방향 전달 | VFX 없이도 베는 방향이 읽히는가? |
| 발동 | 무기 날을 따라 얇고 방향성 있는 궤적 | 무기 축·손·타격 방향이 일치하는가? |
| 접촉 | 실제 피격 이벤트의 위치에 국소 코어와 재질 반응 | 빗맞힘과 명중을 구별할 수 있는가? |
| 회수 | 밝은 궤적은 먼저 정리하고 잔여층은 약하게 | 다음 공격과 적 예고를 가리지 않는가? |

검수할 기존 문제는 VFX 총괄 §2.7의 두꺼운 평타 초승달·접점 부족 기록이다. 현재 빌드에도 같은 결함이 남아 있는지는 새 캡처로 확인해야 한다.

### B. 선형 화염 — D2-03

| 단계 | 제작 제안 | 검수 질문 |
|---|---|---|
| 준비 | 기존 시전 위치와 방향을 식별 | 장판 공격과 구별되는가? |
| 발동 | 진행 앞면에 초점을 두고 본체와 뒤쪽 연기를 분리 | 어디로 움직이며 어느 부분이 공격 중인지 읽히는가? |
| 접촉 | 실제 명중 이벤트에서 대상별 짧은 반응 | 궤적이 지나간 뒤 엉뚱한 곳에서 폭발하지 않는가? |
| 잔류 | 기존 일반 합성 연기·그을음 기준 사용 | 잔류물이 지속 피해 지역처럼 오해되지 않는가? |

후보는 업화선 등의 현행 이벤트 계약을 먼저 확인해 선정한다. 이름만 비슷한 스킬을 자동 연결하지 않는다.

| 콤보 | 1·2타의 간결한 검격과 3타 충전의 큰 해방감을 같은 형태 언어로 연결 | 1·2타 즉시 발사·3타 홀드/해제·충전 단계·피해 계약 보존 |
| 재질 | 현행 은빛 칼날과 검은 잉크 잔여층 위에서 형태를 연구 | 케즈의 색을 우리 전사 팔레트로 자동 복사하지 않음 |

대조 근거: `game.html`의 `_fireKiSlashCrescent`, `spawnCrescent`, `_drawRadiantKiSlash`, `_playKiSlashHit`. 현재 H5는 `assets/vfx/ki_slash_silver_sheet.png`를 사용하며 은빛 본체와 일반 합성 검은 그림자층·약한 칼날 잔상을 분리한다. 이 소스 관찰을 Unity의 현재 외형 증거로 확대하지 않는다. 입력·충전 기준은 [기검참 홀드 계약](../2_1%20스킬관리+합체시스템+자원/KISLASH_HOLD_CHARGE_20260927.md)을 따른다.

관찰 한계: 공식 Echo Slash 설명과 선택된 시연 화면을 확인했으나 연속 프레임 분석·잔상 지연·효과 수명·명중 정점은 아직 측정하지 않았다. 위 형태 분해는 제작 제안이다.

### 전사 대지 충격·분노폭발 ← Echo Slam

공식 출처: [Earthshaker 능력 시연](https://www.dota2.com/hero/earthshaker)의 Echo Slam. 중심의 지면 타격과 주변 적에서 발생하는 충격이라는 구조를 참고한다.

H5에는 독립 스킬명 `대지충격`이 이번 검색에서 확인되지 않았다. `VFX_구현가이드.md`의 “지옥강타 1 대지 충격 보강”, `game.html`의 `giantSlam` 설명(지면 타격·원형 진동파·분노 분류), [초반 전투 기준](../14밸런스+수치테이블/EARLY_COMBAT_5_7_1_20260910.md)의 “분노폭발은 Space 지옥강타1”을 대조했다. 따라서 사용자 표현을 별도 신규 스킬 두 개로 확정하지 않고 **지옥강타/분노폭발 계열의 레퍼런스 매칭**으로 기록한다.

| 층 | 제작 방향 | 검수 질문 |
|---|---|---|
| 시작 | 무기 또는 몸의 지면 접점에 힘이 모임 | 내리찍는 접점과 효과 중심이 일치하는가? |
| 중심 충격 | 접점에서 짧고 강한 코어·지면 파열 | 넓은 반투명 원 대신 지면을 친 무게가 읽히는가? |
| 확산 | 균열·흙·파편이 중심에서 바깥으로 향하는 구조 | 실제 피해 범위가 효과보다 과하게 좁거나 넓어 보이지 않는가? |
| 대상 반응 | 실제 피격 이벤트에 국소 반응을 연결 | 다수 적이 맞아도 중심 충격과 적 위험 표시가 남는가? |
| 분노 강조 | 현재 분노량·강화 상태가 실제로 표현에 전달되는 계약인지 먼저 확인 후 강도 차등 검토 | 단순 색칠 대신 무게 차이를 느끼되 화면 전체가 밝아지지 않는가? |

Echo Slam의 적별 추가 피해·인원수에 따른 효과를 우리 스킬 규칙으로 옮기지 않는다. 바깥으로 퍼지는 VFX를 위해 실제 광역 피해를 지연시키거나 순차 판정으로 바꾸지 않는다. 효과의 최대 범위·전조·접점·피해 시점은 기존 대상 스킬 계약에 맞춘다.
