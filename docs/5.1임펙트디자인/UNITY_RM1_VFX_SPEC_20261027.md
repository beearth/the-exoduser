# Unity 리모델링 1-1 슬라이스(RM-1) VFX 명세 — 임펙트 총괄 (2026-10-27)

- 근거: 사용자 지시(CTO 전달 10-27) 「이식작업은 대충 된거같으니까 유니티 리모델링 작업들어간다 오늘부터」. 첫 목표 = 1-1 리모델링 슬라이스(맵 RM-1 + 다크드루이드 리모델링). VFX 총괄 담당 = 이 슬라이스의 Unity VFX.
- 기준: [VFX_LEAD_MASTER](VFX_LEAD_MASTER_20261026.md) §2(팔레트·3단계·합성), §2.7(타격 6원칙·크기 기준). 웹 쪽 교체에서 얻은 결론을 Unity에서는 **처음부터** 지킨다.
- 판정: 임펙트 총괄 1x → 디자인총괄 최종. 구현 = vfx-simple(Sonnet). 유료 생성은 이 단위에 넣지 않는다(필요하면 총괄에게 보고 → 사용자 확인).
- 웹 쪽 VFX 교체 흐름(VFX-02 5·6묶음, VFX-11·13, D17)은 **보류** — 이 슬라이스가 끝난 뒤 다시 본다.

## 4. 드루이드 3종 (R2)

- 반려 2번이면 같은 방향으로 계속하지 않고 총괄이 방향을 다시 정한다.

## 6. 금지

- `Runtime/Core/*`·판정·수치·사운드 타이밍 변경, 새 Unity 패키지(내장 모듈 제외), 유료 생성, main 브랜치에 Unity 코드, 타사 에셋 반입.
- 기존 사용자 창·게임 서버 재시작, 창 자동 열기. 같은 이유 2회 실패면 멈추고 보고.
- 커밋은 경로 지정, 비강제 push, 기록 다시 쓰기 금지.
