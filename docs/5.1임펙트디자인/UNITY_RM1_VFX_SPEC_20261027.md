# Unity 리모델링 1-1 슬라이스(RM-1) VFX 명세 v2 — 임펙트 총괄 (2026-10-27)

- 근거: 사용자 확정 「Unity 리모델링」(CLAUDE.md `cf506002d`) — 이식한 전투 Core는 그대로 두고 표현은 Unity 도구로 새로 만든다. **VFX = URP 위의 VFX Graph·Shader Graph.** 웹 스프라이트 시트는 임시로만 쓴다(그래프 안 플립북 텍스처로 재사용 가능).
- 범위(유니티 총괄 지정, 10-27): **① 기검참 ② 독 폭발 ③ 드루이드 텔레그래프 3종 ④ 독액 기포.** 1-1 슬라이스 = 맵 RM-1(START~R2, 독액강 썩은숲) + 다크드루이드 RM-B1.
- 시작 조건: RM-0(URP 전환)이 `unity/main`에 병합된 뒤 제작. 그 전에는 이 명세만 준비한다. 배정은 유니티 총괄.
- 판정: 시각 = 디자인총괄, 손맛 = 보스전 총괄 + 임펙트 총괄. 임펙트 총괄은 1x 캡처 1차 판정 후 넘긴다.
- 기준: [VFX_LEAD_MASTER](VFX_LEAD_MASTER_20261026.md) §2(팔레트·3단계·합성)·§2.7(타격 6원칙·크기 기준), 아트 바이블 v2(`../4.1맵디자인+설정/MAP_ART_BIBLE_v2_20261026.md`) V6·C6·D5, 맵 보드 §6.2 T2.
- v1(같은 날, Built-in 파이프라인·SpriteRenderer 전제)은 이 v2로 대체한다. v1 구현은 착수 직후 중지했고 산출물은 쓰지 않는다.

## 3. 대상 4종

크기는 §2.7.3(지름 ÷ 캐릭터 키). 시점 0 = 명중·발동 틱.

### 3.1 기검참 (1·2·3타 + 3타 충전 단계)

| 항목 | 내용 |
|---|---|
| 신호 | `FeedbackKind.KiSlashHit`·`KiChargeFlash`(현 `KiSlashView`·`KiImpactView` 입력 그대로). 콤보 7/7/7 박자·판정 불변 |
| 층 | ① 궤적 = VFX Graph **파티클 스트립**, 앞날만 HDR, 꼬리는 뼈색으로 식으며 0~0.12초에 소멸, 두께 ≤ 캐릭터 키 0.15(원칙 6) ② 명중마다 `VFXS_Core` 0.3~0.5×(3타 0.6×), +2틱 정점 ③ `VFXS_Shards` 은·뼈색 6~10개, 타격 방향 ±35°, 0.08~0.2초 ④ 3타만: `SG_GroundDecal` 베인 자국(그을음, 알파) 1.5초 ⑤ 3타 충전 tier마다 크기 ×(1+0.4·tier) |
| 색 | 물리 `#efe6d2`/`#9a8a72`/`#2a2220`, 코어 `#fff4d0`(HDR) |
| 1x 기준 | 정점 ≤ +0.067초, 코어 상위1% ≥240, 0.15초 뒤 궤적 잔존 0, 1·2·3타가 크기로 구분됨 |
| 임시 텍스처 | 현 `ki_slash_silver_sheet`·`ki_slash_hit_silver_sheet`는 비교 기준으로만, 최종은 절차 스트립 |

### 3.2 독 폭발 (드루이드 독탄·독 오브 착탄, 독 웅덩이 생성 순간)

| 항목 | 내용 |
|---|---|
| 신호 | 독 투사체 소멸(착탄) + `druidPoison`/독 웅덩이 생성 틱(현 `NativeBossView`가 읽는 목록) |
| 층 | ① `VFXS_Core` 0.5× — 백열이 아니라 **창백한 독 코어** `#c8e8a8`(HDR) ② 본체: 독액 덩어리 튐 = 메시 조각 8~12개 + 짧은 독 플립북(임시 `Poison_MediumImpact`), 방향은 투사체 진행 방향 쪽으로 쏠림, 0.15~0.35초 ③ 독기 `VFXS_Mist` 0.6~0.8초, 낮게 깔림 ④ 바닥 독 얼룩 `SG_GroundDecal` 1.5초(시각 전용 — 판정 있는 독 웅덩이 표현은 RM-B1 보스 명세 몫, 겹쳐도 테두리가 읽혀야 함) |
| 색 | 적 독 `#c8e8a8`/`#5f8a2e`/`#1c2810`. 색상각 85~95° 100%, 라임(65~80°)·순녹(110°+) 0. 맵 독액(40~65°, 아트 바이블 D5)과 나란히 놓고 **VFX가 먼저 읽힘** |
| 1x 기준 | 정점 ≤ +0.067초, M 단계 지름 2.5~4×, 0.8초 뒤 바닥 얼룩만 남음. 현 이식본의 불악마 구슬 회색화(`#66dd22` 곱)보다 어둡고 탁함 |

### 3.3 드루이드 텔레그래프 3종

RM-B1 드루이드 명세 §4의 3기술에 붙인다. 기술 이름이 확정되기 전까지 **판정 모양 3종**으로 만들어 두고, 확정되면 기술별 크기·시간만 연결한다.

| 모양 | 예(현 Core 상태) | 그래프 |
|---|---|---|
| 원형 착지·분출 | `bossDruidErupt` 직전(침강 후 솟음), `bossSlamWind`, `bossJumpWind` | `SG_GroundDecal` 원, `_Radius` = Core 판정 반경 |
| 직선 돌진 | `bossChargeWind`, `bossPoisonDash`, `bossMultiDashWind` | 직선 폭·길이 = Core 판정 폭·거리 |
| 부채꼴 휩쓸기·탄막 | `bossSweepWind`, `bossFanWind`, `bossDruidVolleyWind` | 부채꼴 각·반경 = Core 값 |

| 항목 | 내용 |
|---|---|
| 신호 | 상태가 `…Wind`/`…Prep`으로 바뀐 틱 → 실행 상태로 바뀐 틱. 남은 틱으로 `_Progress` |
| 표현 | ① 얇은 테두리 + 안쪽 채움이 **바깥에서 안으로 차오름**(덜 찬 부분 = 남은 시간) ② 실행 60~90ms 전 테두리 1회 밝아짐(HDR, 블룸 문턱 바로 위 — SSOT §2.3 보스 연출 선행) ③ 실행 순간 0.1초에 꺼지고 그 기술의 임팩트로 넘김 ④ 바닥 요철을 따라 붙음(URP Decal) — 늪·강·빛 웅덩이 위에서도 테두리가 읽힘 |
| 색 — **적 예고 팔레트 신설** | 테두리 `#c8402a`, 채움 `#5a1a10`(알파 0.18 → 0.42), 실행 직전 밝아짐 `#e8a080`. 적 전용 — 플레이어 이펙트 금지. 맵 붉은 태양 빛 웅덩이(아트 바이블 D12)와 구분되게 **테두리 선이 있는 쪽이 예고**로 고정 |
| 크기 일치 | 데칼 모양·크기는 반드시 Core 판정값에서 계산(손으로 맞추지 않음). 판정 경계 ±4px 안 |
| 1x 기준 | 3종이 같은 언어로 보임, 남은 시간이 채움으로 읽힘, 플레이어 피격·자기 기술보다 먼저 읽힘(§2.5-2). 프레임 수·판정 시간은 보스전 총괄 값 그대로 |

### 3.4 독액 기포 (맵 보드 §6.2 T2)

| 항목 | 내용 |
|---|---|
| 위치 | 맵 쪽이 늪·강 표면에 뿌린 **기포 스폰 지점**(맵 총괄 제공: 점 집합 또는 표면 메시 + 밀도 맵). VFX는 효과만, 배치는 맵 |
| 주기 | 부풀기 0.6~1.4초 → 터짐 0.08초 → 동심원 물결 0.6초 + 방울 4~6줄기(늘인 조각, 0.3초) + 짧은 증기 0.5초. 크기 0.15~0.5× 캐릭터 키, 주기·크기·위치 개체마다 무작위(L9) |
| 그래프 | 부풀기 = `SG_ToxicBubble` 메시(GPU 인스턴싱, 정점 부풀림·프레넬 막·터지기 직전 막 얇아짐), 터짐·물결·방울·증기 = VFX Graph 하나. 화면당 동시 24개, 화면 밖 생략 |
| 색 | **맵 독액 색(아트 바이블 D5, 40~65°)**을 따른다 — 전투 독(85~95°)과 섞지 않는다. 평소 채도·명도 낮게, 터지는 0.08초만 HDR로 살짝 밝게(블룸 문턱 아래~바로 위, 전투 코어보다 약하게) |
| 소리 | 터짐 위치·시각만 사운드 총괄에 넘김(T6) |
| 1x 기준 | 5초 영상에서 기포가 같은 박자로 보이지 않음, 늪이 살아 있되 전투 피사체·텔레그래프가 먼저 읽힘, 화면이 초록으로 덮이지 않음(맵 §6.3) |
