## 기동불꽃 광량·잔광 조정 (2026-09-29)

재발 방지와 후속 수정 검수 기준은 [기동불꽃 과광원·잔광 재발 방지 기록](CHAIN_FLAME_LIGHT_QA_20260929.md)을 따른다.

Shift 사슬기동 중 우클릭/Space 착지의 밝은 섬광과 장판 전체의 지속 조명을 줄인다. 불꽃 장판의 피해·범위·300f 기본 수명·스택 강화·기폭은 유지한다.

| 적용 위치 | 이전 | 현재 |
|---|---|---|
| `chain_assault_impact` | speed=12, 108f (약 1.8초), 기본 alpha=1 | speed=4, 36f (약 0.6초), baseAlpha=.5 |
| 착지 화면 섬광 `G._flashT` | 티어 1/2/3: 4/8/14 | 티어 1/2/3: .6/.8/1; 화면 alpha 최대 .108/.144/.18 |
| `assaultFlame` 광원 반경 | `r*2.6` | `r*1.35` |
| `assaultFlame` 광원 세기 | `.68+sin(frame*.13+zoneIndex)*.10` 지속 | `(.24+sin(frame*.13+zoneIndex)*.03)*max(0,1-t/24)^2` |
| 광원 종료 | 장판 수명 동안 유지 | 장판 나이 24f (약 0.4초)부터 광원 미생성 |
| 중첩·재사용 | 장판 시간 `t=0` | 동일하게 `t=0`에서 짧은 잔광 재생; 장판 수명에 비례해 늘어나지 않음 |

WebGL 가산 및 Canvas2D 폴백에 동일한 baseAlpha를 전달한다. RGB `[255,140,50]`, 프리셋 7과 다른 화염·얼음·환경 조명은 기존 계약을 따른다. `chainSlam`은 2026-09-29 전방 세 갈래 대지가르기 계약으로 대체됐다.


두 시트의 각 418px 셀에서 효과 픽셀의 세로 중심은 `y=281px`이며 셀 중심 `y=209px`보다 `+72px` 낮다. 따라서 충격점 `P.y`에 중심을 맞추는 y 보정은 화염 `72 / 384 = .1875 → .19`, 충격 `72 / 256 = .28125 → .28`이다.

## 이전 기동강타 황토 시트 기록 (2026-09-05, 2026-09-29 대체)

아래 공유 시트 연출은 현재 기동파괴에서 사용하지 않는다. 현재 판정·재질·수명은 [전방 세 갈래 대지가르기](CHAIN_SLAM_FORWARD_CLEAVE_20260929.md)를 따른다.

`chainSlam` 착지는 기존 `chain_slam_impact` 3×3 시트와 별도로 황토 대지의 `assets/vfx/giant_slam_impact_sheet.png`를 공유한다. 이 보조 레이어는 1024×1024 RGBA 2×2(셀 512px)이며, `_slamFrame=min(3,floor((t/maxT)×4))`의 4프레임을 `source-over`로 그린다. 크기는 `maxR×1.8×(0.72→1.0)`이다.

| 적용 대상 | 기존 시트 | 공유 영웅 시트 | 유지되는 지면층 | 전투 영향 |
|---|---|---|---|---|
| `chainSlam` / 사슬기동 중 E·좌클릭 착지 | `chain_slam_impact`, 1254×1254 3×3·418px, `lighter` | `giant_slam_impact_sheet.png`, 1024×1024 2×2·512px, `source-over` | 크레이터·16갈래 균열·18개 암석 파편, 기존 24f 충격파 | 없음 — 피해·범위·포이즈·자원·쿨다운·기동불꽃 기폭 불변 |

## 생성 계약

OpenAI 내장 이미지 생성 API로 제작했다. 이 게임의 VFX 배치는 WebGL 가산 합성이므로, 미사용 픽셀을 투명/체크보드가 아니라 **완전 불투명 순검정 `#000000`**으로 생성한다. 순검정은 가산 합성에서 광량 0으로 처리되어 배경 사각형을 남기지 않는다. 출력은 RGB PNG(color type 2), `1254×1254`, 3×3 셀 `418×418`을 유지해야 하며, 기존 VFX와 같은 WebGL 가산 배치(`lighter`)를 사용한다.
