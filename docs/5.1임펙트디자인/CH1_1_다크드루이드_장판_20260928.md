# CH1-1 다크드루이드 장판 비주얼 (2026-09-28)

## 의도

CH1-1의 부패한 생체숲에서 경고 장판이 불투명한 녹색 원반처럼 보이던 문제를 수정한다. 경고 범위는 읽히되 플레이어, 보스, 지형의 중앙 가독성을 유지한다. 피해 판정, 반경, 지속시간은 변경하지 않는다.

## 적용 위치

| 대상 | 코드 위치 | 표시 규칙 | 판정 |
|---|---|---|---|
| 다크드루이드 `chaseAoe` 예고 | `game.html` `_chaseAoes`의 `z.druid` | 아트 알파 `min(1,t/delay) × (0.55 + 0.12 × pulse)`, `pulse=0.78+sin(now×0.018+zoneIndex)×0.22` | 기존 `z.r` 유지 |
| `chaseAoe` 발동 | 같은 렌더 분기 | 알파 `(1-explT/explMax)×0.68`, 그림 반경 `z.r×(1+explT/explMax×0.25)` | 기존 피해 처리 유지 |
| `groundFissure` 종착 경고 | `_fissures`의 `fs2.druid` | 기존 단색 녹색 방사형 면과 중앙 점을 제거하고 뿌리 아트 알파 `0.32+sin(now×0.018)×0.035`; 내부 반경 78%를 잘라 중앙을 비우고 경계는 18개 부러진 흙빛 호로 표시 | 기존 `explR` 유지, 최대 750 |
| `groundFissure` 종착 폭발 | 같은 렌더 분기 | 뿌리 아트 알파 `(1-ep)×0.48`, 표시 반경 `explR×(1+ep×0.12)` | 기존 폭발 판정 유지 |
| 다크드루이드 용암 장판 | `_lavaPools`, stage 0/3 | 예고 최대 0.42, 활성 최대 0.65, 종료 시 페이드 | 기존 `lp.r` 유지 |
| 다크드루이드 독 장판 | `_poisonPools`, stage 0/3 | 생존 페이드 `ppF×0.68` | 기존 `pp.r` 유지 |
| 최종 페이즈 장판 | `_drawDruidFinalePool` | 예고 `0.36×fade`, 활성 `0.72×fade`; 기존 위험 테두리 유지 | 기존 `lp.r` 유지 |

그림은 월드 좌표의 원형 위험 반경에 맞춰 그리며, 각 장판은 고정 각도로 회전해 반복 무늬가 겹쳐 보이지 않게 한다. 이미지 로딩 실패 시 얇은 연녹색 원형 테두리를 그린다. 기존 8프레임 다크드루이드 AOE 시트는 최종 페이즈 장판의 보조 폴백으로 남긴다. 다른 보스와 다른 스테이지의 장판 렌더는 이 변경 대상이 아니다.

## 확인

로컬 `server.cjs`의 `/game.html?bosstest=0`에서 `chaseAoe`를 실행해 이미지 로드 크기 384와 stage 0 표시를 확인했다. 추가로 `groundFissure`를 실행해 반경 약 691의 녹색 원반이 실제 문제 경로임을 재현했고, 그라디언트 원반을 뿌리 아트로 교체했다. 캐릭터가 장판 안에서도 보이는 것을 브라우저 화면으로 확인했다. 터미널 실행 오류로 저장소 전체 문서 검색, Git 상태 확인, 커밋 및 CLI 테스트는 수행하지 못했다.
