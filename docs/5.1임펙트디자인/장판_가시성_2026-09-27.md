# 장판 공격 가시성 기준 (2026-09-27)

`game.html`의 장판 렌더 기준이다. 장판은 바닥의 위험 범위와 발동 시점을 알려야 하지만, 같은 좌표의 몬스터와 탄막을 덮어서는 안 된다. 아래 수치는 렌더 불투명도만 조정한다. 피해량, 판정 반경, 발동 시간, 지속 시간은 변경하지 않는다.

| 렌더 대상 | 코드 위치/식별자 | 바닥·이미지 최대 알파 | 위험 범위 표시 |
|---|---|---:|---|
| 암흑영역 | `_DZ_STOPS` | 중심 0.30, 중간 0.18 | 기존 경계 유지 |
| 일반 독웅덩이 | `_PP_STOPS` | 중심 0.26, 중간 0.14 | 기존 가장자리 유지 |
| 전격이동 전류장판 | `shockField`의 `_sfFade` | 이미지 계수 0.24 (3개 전기 시트가 중첩됨) | 번개와 기존 착지 효과 유지 |
| 악의폭풍·해골번개 | `storm`/`boneStorm`의 3개 스프라이트 | 기존 `_fzFade`에 각각 0.25, 0.22, 0.20을 곱함 (12~16개가 중첩됨) | 외곽 전기 표시 유지 |
| 용암소환 전체 화면 착색 | `_lavaField` | 빨강 0.08×펄스, 하단 0.06 | 남은 시간 표시 유지 |
| 추적 장판 타격 면 | `_chaseAoes` | 드루이드 0.14, 일반 0.18 | 드루이드 경고 링 폭 8→1.5px, 수축 링 5→1.5px |
| 드루이드 피날레 독늪 | `_drawDruidFinalePool` | 면 0.10/0.04, 시트 0.24/0.10 (활성/전조) | 외곽·수축 링 3/5→1.5px, 알파 0.62; `__strokeBak`으로 해당 경고 링만 표시 |
| 드루이드 용암 장판 시트 | `_lavaPools` | 경고 최대 0.18, 활성 최대 0.26 | 반경 1.2px 녹색 링 |
| 일반 용암 장판 | `_lavaPools` 폴백 | 바깥 면 0.15, 안쪽 면 0.08±0.04 | 기존 판정 반경 유지 |
| 화염비 | `_fireRains` | 타격 면 0.18, 경고 오각형 이미지 0.07~0.16, 경고 면 0.10 | 기존 타격 링 유지 |
| 도넛 강타 | `_donutSlams` | 타격 면 0.16, 안전 안쪽 면 0.10 | 기존 경고 링 유지 |
| 드루이드 독웅덩이 시트 | `_poisonPools` | 0.25×수명 페이드 | 반경 1.2px 녹색 링 |

조정 원칙: 넓은 면 채움과 겹치는 스프라이트를 먼저 낮추고, 경고 윤곽·발동 링은 가는 선으로 남긴다. 새 장판도 몬스터/탄막 위에 합성되는 바닥 아트는 활성 상태 최대 알파 0.3을 기준으로 제작한다. 여러 시트가 중첩되거나 `lighter` 합성을 쓰면 개별 시트의 알파를 더 낮춘다. 수치상 피해 범위와 시각 경고 반경은 일치시키되 선 자체는 1~2px 범위로 둔다.
