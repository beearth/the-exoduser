사용자 지시: “테스트 베드를 만들어 똑바로”. 이전에 기존 본편을 연 것과 달리, 인트로·난이도·튜토리얼 없이 기검참과 대지 충격을 직접 발동하는 독립 VFX 시험 공간을 구현했다.

3333은 본편에 응답했으나 이번 새 파일들에는 404를 응답했다. 해당 서버를 강제 종료·재시작하지 않고, 직접 실행한 별도 3345 인스턴스에서 새 HTML·CSS·모듈의 HTTP 200 및 디스크 바이트 일치를 검증했다. 전역 설정·예약 작업·자동 재시작은 추가하지 않았다.

## 사용 방법

| 입력·조작 | 동작 |
|---|---|
| W/A/S/D 또는 방향키 | 전사 이동, 카메라 추적 |
| 훈련장 마우스 이동 | 조준 방향 변경 |
| 훈련장 좌클릭 / 큰 발동 버튼 | 1 → 2 → 3타 입력. 세 번째 입력을 유지하면 충전, 놓으면 한 번 발사 |
| 1타·2타·3타 버튼 / 숫자키 1·2·3 | 해당 타격을 바로 발동. 3타는 선택한 충전 단계 사용. 검토 편의를 위해 이 바로 발동 경로는 쿨다운을 기다리지 않음 |
| Space / 강타 버튼 | 선택한 분노량으로 지면 충격 발동 |
| 시안·원본·나란히 | 같은 시뮬레이션 상태의 렌더러만 전환. 나란히는 상태 업데이트·접촉을 두 번 실행하지 않음 |
| B | 원본/시안 전환 |
| 정지 / P | 시간 정지·재개 |
| 1프레임 / 마침표 | 정지 상태에서 한 틱 전진 |
| 속도 | 1× / 0.25× / 0.1× |
| 반복 | 기검참은 1·2·3타 순서, 강타는 같은 조건으로 반복 발동 |
| 표적 배치 | 단일 1개 / 일렬 5개 / 밀집 14개. 변경 시 원위치·누른 입력·충전·효과·접촉 기록 초기화 |
| 화면 배율 | 50~180%, 5% 간격. 기본 100% |
| 접촉 범위 | 검기의 원형 접촉 반경과 강타 500 반경을 점선으로 확인 |
| 명중 임팩트 | 공용 명중 시트를 추가/제외. 기본은 꺼 두어 검기 본체와 지면 충격을 먼저 확인 |
| 초기화 / R | 원위치·입력·콤보·충전·효과·횟수·반복 초기화 |

분노량은 0~100%, 20% 간격의 시각 검토 조건이다. 후보의 최초 국소 강조 크기를 `65+rage×0.9`로 조절하며 피해나 접촉 반경을 변경하지 않는다. 본편의 분노 피해 공식·소모·분노별 추가 용암을 구현했다는 의미가 아니다.

## 시험 공간의 시간·좌표 계약

아래는 테스트베드가 소비하는 원본 표현 계약과 독립 시험 공간 설정이다. 본편의 게임 규칙을 새로 확정하는 표가 아니다.

| 항목 | 테스트베드 값 | 근거·구분 |
|---|---|---|
| 시뮬레이션 | 고정 60Hz | 원본 틱 단위를 분리 시험 |
| 검기 속도 | 14px/틱 | 원본 `spawnCrescent` |
| 검기 기본 거리 / life | 1타 250/17틱, 2타 300/21틱, 3타 350/25틱 | `floor(기본거리/14)`. 레벨 보너스 미사용 |
| 검기 접촉 반경 | 1·2타 55, 3타 120×scale | scale=1+0.4×충전단계 |
| 충전 | 40틱마다 1단, 120틱 상한, 0~3단 | 최대 2초. 충전 중 무발사·해제 1회 |
| 콤보 유지 / 입력 쿨다운 | 120틱 / 1·2타 12틱, 3타 20틱 | 일반 좌클릭 경로에서만 대기 |
| 강타 | 반경500, 45틱 수명 | 접촉은 발동 즉시 계산. 확산 영상 때문에 접촉을 늦추거나 추가하지 않음 |
| 명중 효과 | 12틱 수명, 표적 밝기10틱 | 기존 4프레임 명중 시트의 분리 표시 |
| 이동 | 4px/틱, 대각선 정규화, X ±680 / Y ±430 | 시험 공간 전용 범위, 본편 이동 속도 변경 아님 |
| 큐 상한 | 검기24, 강타8, 명중32, 최근 발동64, 최근 접촉128 | 장시간 반복 시 무제한 축적 방지 |
| 렌더링 | 검기 9프레임 / 강타 4프레임. DPR 최대2 | source-over 검은 층·먼지 / lighter 은빛 검기 / 원본 강타 screen |
| 검기 수직 위치 | 코어 발사점 Y−22, 표시 추가 Y−32 = 발 위치 기준 Y−54 | 훈련장 전사의 손 높이로 맞춘 독립 어댑터 |
| 명중 표시 높이 | 표적 Y−28−26 = Y−54 | 검격 접점과 같은 표시 높이 |
| 전사 스트립 | 48px 셀. idle 2 / walk 8 / attack 8, 8방향. 160px 사각으로 그리며 위쪽 Y−137 | 기존 H5 이미지, 새 캐릭터 생성 없음 |
| 강타 시트 크기 | 2×500×0.9×(0.72+0.28×min(1,progress×3.5)) | 원본 지면 강타의 시트 크기 진행 비교 |
| 반복 간격 | 기검참45틱 / 강타90틱 | 검토 도구 전용. 실제 자동공격 주기가 아님 |
| 화면 | 폭901px 이상은 화면 높이 안에 훈련장·발동·시간 조작 배치, 우측 조건만 내부 스크롤. 900/520px에서 반응형 배치 전환 | 실제 확인은 1280×720, 다른 화면 폭은 구현만 하고 실기 미검수 |

표적은 원형 겹침으로 접촉 위치를 보여주며 HP·가짜 피해 숫자를 만들지 않는다. 같은 검기는 같은 표적에 한 번만 접촉한다. 이는 VFX의 접촉 위치 확인이며 EXODUSER의 모든 근접/검기 판정·스탯·범위 계약 검증으로 확대하지 않는다.
