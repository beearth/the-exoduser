# 추적전격 후속 이동 VFX

`bladeEcho` 연계에 칼날 궤적을 따라 순간적으로 번쩍이는 청백 전격을 적용한다. 현행 수치·단계는 [스킬 계약](../2_1%20스킬관리+합체시스템+자원/추적전격_합체_20260927.md)의 후속 전격 이동 VFX 표가 기준이다.

| 시각 계층 | 표현 | 역할 |
|---|---|---|
| 최외곽 | 34px 짙은 시안, 투명도 0.10 | GPU 렌더러에서도 경로 외측을 넓게 번짐 |
| 외곽 | 20px 시안, 투명도 0.23, 그림자 흐림 22px | 어두운 지형에서 경로를 읽히게 함 |
| 중간 | 9px 청색, 투명도 0.58, 그림자 흐림 12px | 전기 에너지의 두께 |
| 중심 | 3px 흰색, 투명도 0.95 | 순간적인 밝은 플래시의 핵 |
| 캐릭터 | 경로를 가로지르는 4개 청백 섬광선과 반경 `28±3px` 링 | 이동 방향과 속도 전달. GPU 렌더러의 타원 채움은 사용하지 않음 |
| 순간 강조 | 시작·명중·착지의 기존 `spawnElecBurst`, `_addBlastLight`, 화면 플래시 | 타격과 착지 시점을 분명히 함 |
| 착지 잔광 | 마지막 18개 경로 지점을 180ms 동안 감쇠 | 짧은 이동에서도 지나간 궤적을 읽을 시간 제공 |

런타임은 `drawP()`의 월드 좌표에서 `_drawBladeEchoVfx()`를 호출한다. 기존 VFX 풀과 전기 버스트 아틀라스를 재사용하며 신규 이미지·사운드 파일은 없다. 경로 렌더는 이동 중과 착지 후 180ms 동안 활성화한다.
