# 비화염 장판의 과도한 주황 광원 수정 (2026-09-10)

사용자 스크린샷 `스크린샷 2026-09-10 144000.png`: 가시덫 주위에 넓은 황색 안개처럼 빛이 깔려 바닥·캐릭터 대비가 약해지는 현상.

## 원인

`G._fireZones`는 이름과 달리 물리 가시덫, 회복·약화 영역, 암흑기둥, 전기·얼음 장판도 보관하는 공용 배열이다. `_collectLights()`가 `iceStorm`을 제외한 모든 원소에 화염 광원을 생성해 가시덫에도 반경 `r*2.6`의 주황빛과 어둠 제거 홀이 생겼다. 앞선 [GPU 캐시 갱신 수정](../12퍼포먼스·최적화/LIGHTING_TEXTURE_FRESHNESS_20260910.md)은 조명 픽셀 전달을 복구했지만 장판 분류 문제는 남아 있었다.

| 가시덫 예시 | 공격 반경 | 기존 잘못된 광원 반경 | 현재 추가 화염 광원 |
|---|---|---|---|
| Lv1 | 300 | 780 | 없음 |
| Lv10 | 435 | 1131 | 없음 |
| Lv20 | 585 | 1521 | 없음 |
| 기둥가시 합체 | 가시덫 9개 + 암흑기둥 9개까지 | 각 원소마다 잘못된 주황빛이 중첩 | 비화염 18개 모두 추가 광원 없음 |

## 현재 장판 조명 계약

`_collectLights()`의 기존 `else`를 `else if(_fz.el===EL.F)`로 제한한다. `EL.F=1`. `iceStorm`은 기존 특수 분기가 우선이다.

| 대상 / 판정 | 광원 반경 | 세기 | RGB / 프리셋 |
|---|---|---|---|
| `type==='iceStorm'` (el 필드 없어도 적용) | `r*2.4` | `.55` | `[68,200,255]`, 기존 `_colIdx` 선택 |
| 나머지 중 `el===EL.F` | `r*2.6` | `.68+sin(_gameFrame*.13+_fzL)*.10` | `[255,140,50]`, `ci=7` |
| `spikeTrap`, `darkPillar`, `holyDome`, `holyPrison`, `weakPhys/Mag/Pj/Rev`, `maliceDome`, `storm`, `boneStorm`, `hellRay`, `vortex`, `iceVortex`, `shockField` 등 비화염 | 생성하지 않음 | — | 각 스킬 고유 VFX만 유지 |
| 타입 없는 원소 | `el===EL.F`인 불장판만 위 화염 규칙 적용 | 위와 동일 | el 없는 원소는 자동 화염 취급 금지 |

실제 화염 `fireTrail`, `assaultFlame`, `fireAura`, 타입 없는 불장판은 생성부에서 `el:EL.F`를 지정하므로 기존 조명을 유지한다. 프리셋 7 색상·falloff, 실제 화염/얼음 조명의 반경·강도, 모닥불·보스·펫·플레이어 조명은 변경하지 않는다. 가시덫 이미지 `sprites/spike_trap/spike_thorn.png`, 회전·배치·크기·피해·슬로우·지속·쿨다운은 변경하지 않는다.
