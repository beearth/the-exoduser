# 1-1 앵글러(크라켄) 물 에너지구 VFX 다시 만들기 — G1 설계표 (임펙트 총괄, 2026-11-04)

- 계기: 사용자 11-04 "크라켄 vfx 니가 만든 거냐", "퀄리티 저게 팬텀블레이드 보고 배운 거냐".
- 사실 확인:
  - Unity에서 앵글러가 쏘는 에너지구(Core `FieldBossFireEnergy`: El 2, Sz 48, 판정 R 20, 10px/틱, 수명 320)에는 **물 원화가 없다.** 지금은 빙결 원소구 시트(`proj_elem_orb_v3` 빙결 행)로 대신 그린다(`NativeBossView.FieldBullets.cs` 14행 주석).
  - 이 원소구를 막았을 때의 물 패링은 RETOUCH 4(`72158392e`)에서 빙결 충격 시트를 물색으로 다시 칠한 것뿐이다.
  - 둘 다 임펙트 레인 산출물이다. [PBZ·도타2 실측](IMPACT_REFERENCE_PBZ_DOTA2_20261103.md) R1~R8 중 R1(코어 5틱)만 지켰다. R5(접촉 스파크)·R6(바닥 데칼 3.5초)·방향성 본체는 빠졌다.
- 이번에는 **비행·발사·피격·패링·소멸**을 한 벌로 새로 만든다. Core 수치·판정은 바꾸지 않는다.

## 2. 기술 표 (60fps 1틱 = 1f, 34° 화면, 영웅 키 H ≈ 90px)

| 단계 | Core 신호 | VFX | 크기 | 길이 |
|---|---|---|---|---|
| 충전(예고) | 앵글러 에너지 충전 180틱(`FieldBossEnergyCharge`), 촉수 끝 `FieldBossFeeler` | 촉수 끝에 물이 소용돌이치며 모여 구가 자란다(0 → 몸 크기). 마지막 30틱은 표면 회전이 빨라지고 하이라이트가 커진다. 예고 빨간 링은 기존 것(겹쳐도 링이 위) | 몸 0 → 48 Core px | 180틱 |
| 발사 | `EmitFieldBossShot`(ElemBall, El 2) | 촉수 끝에서 진행 방향으로 짧은 물 분사 원뿔(±20°) 0.15초 + 물방울 줄기 4개 | 원뿔 길이 0.8H | 9틱 |
| 비행 | 탄 위치·속도 | 위 §1의 몸 + 리본 꼬리 + 물방울. 몸 표면 결은 플립북 24프레임 루프(2초) | 몸 지름 48 Core px(≈36px 화면) | 수명 320 |
| 플레이어 피격 | 탄 소멸 + 플레이어 피격 | 코어 0.5H 5틱 → 진행 방향 물 왕관 + 물살 판(플립북 16프레임, 0.25초) → 물방울 줄기 8~12개(0.3~0.5초, 중력) → 바닥 젖은 자국(어두운 물색 알파 ≤.35, 3.5초 + 1초 페이드) | 본체 지름 2.5~3H | 0.5초 + 데칼 |
| 막기·Q 패링 | `FeedbackKind.Parry`(물탄, 마법 패링 → 블루콩 반사) | 코어 5틱 + R5 스파크(막기 30~60개·완벽 80~130개, 키×0.10~0.25, 0.3~0.5초) + 방패 면에서 양옆으로 갈라지는 물살(플립북 반쪽 2장) + 물방울. 완벽 패링만 R2 플래시(Δ≤40, ≤6틱). 반사된 파란콩은 기존 그대로 | 물살 폭 2H | 0.5초 |
| 벽·수명 끝 소멸 | 탄 소멸(대상 없음) | 작은 물 튐(피격의 0.5배) + 젖은 자국 2초 | 1.2H | 0.3초 + 데칼 |

- **가독성:** 탄 몸은 배경 늪·독액 위에서 명도 대비로 읽혀야 한다. 비행 중 꼬리·물방울은 몸보다 어둡고, 탄 판정 원(R20) 밖으로 꼬리가 뻗어도 몸의 윤곽이 먼저 보여야 한다. 아군 효과·바닥 자국이 적 탄과 예고를 가리지 않는다(마스터 §2.5, R7).
- **색:** 물 램프 `#0f1c26 → #3a6a88 → #8db4c8 → #dcebf0`(마스터 §2.2 물 행). 네온 시안·원색 파랑 0. 빙결 회청과 구분되게 더 깊고 어둡게 한다.
- **점 금지:** 물방울은 늘인 줄기와 작은 판으로 그리고, 낱점·반짝이·거품 점은 쓰지 않는다. 3x 크롭 낱점 0.
