## 목표와 실제 판정

직접 본 레퍼런스는 `I:/EXODUSER-Storage/codex-takeover/quality-reference-20261030/map-combat-board.jpg`와 `screenshots/nrftw-01.jpg`. 차가운 암부·작은 따뜻한 광원·중앙 전투 선명도를 참고했다. 원작 3D의 볼륨·접지·투영 그림자를 2D 후처리로 달성했다고 보지 않는다. 에셋 생성·외부 자산 반입 없음.

목표는 기존 1-1의 표면색을 유지하면서 빛 주변의 명암을 만들고, 중앙 전투와 적 탄을 선명하게 두는 것이다. 최초 RGB→RGBA framebuffer 복사 실패는 RGB8로 고쳤다. 단독 재현에서 RGBA/RGBA8은 `INVALID_OPERATION`, RGB8은 오류 0이었다. 수정 후 실제 전체 경로 GL 오류 0과 렌더 상태 복원을 확인했다.

**시험 범위 시각 판정: PASS** — 1920×1080 1x의 기존 대비 국소광·차가운 주변부·약한 번짐·중앙 초점과 짧은 타격 피드백을 확인했다. **전체 아트 완성 판정은 아니다.** 원본의 평면 바닥·기존 큰 펫 대화·기존 스킬 외형은 그대로 남는다. 모든 보스/탄종/다른 카메라 모드·Mac·NW.js·음향·1-1 자연 클리어는 미검증이다.

## 강도와 수치 계약

모든 강도는 0~100%, 0은 해당 추가 효과 없음이다. 기존 효과를 제거하는 값은 아니다.

| bloom | 블룸 | 30 | 밝기 max(RGB)의 0.55~0.95 threshold. 8방향 5/13px 샘플, 가중치 0.065/0.035, 최종 ×0.35×강도/100 |
| grade | 차가운 그늘 / 따뜻한 빛 | 45 | 암부 (0.88,0.97,1.10), 밝은 부분 (1.07,1.01,0.91), 휘도 0.08~0.55 전환. 채도 ×(1−0.12×강도/100) |
| vignette | 비네트 | 28 | 중심 거리 0.26~0.74 감쇠, 최대 추가 어두움 0.32×강도/100 |

확인된 `hurtE`의 HP 피해 접점에서만 타격 알림. DOT와 bladeShard/maliceHunt/iceBlade/beam/dot/ltnChaser/lightning의 조용한 타격은 제외한다. 공통 타격 알림 간격 55ms. 시험 입자의 독립 PRNG는 게임 `Math.random`을 소비하지 않는다. 타격 정지는 고정 업데이트 축적을 버려 후속 catch-up을 막고, 적/영웅 물리를 함께 멈춘다. 렌더·패널은 계속 동작한다. Q/E 패링 분류·피해 공식·수치·세이브 구조는 변경하지 않았다.
