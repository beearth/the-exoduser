# 임팩트(VFX) 총괄 마스터 — 지옥의 길 (2026-10-26 신설)

> 사용자 지시(2026-10-26): 「임펙트 총괄 vfx」 — 「게임에 들어가는 임펙트들을 어느정도 일관성있게 디자인하고 전체 총괄하면돼」.
> 이 문서가 게임 안 모든 이펙트(타격·스킬·투사체·장판·보스 전조·사망·화면 피드백)의 **디자인 기준·현황·백로그·결정 기록 SSOT**다.
> 상세 구현 기록은 기존 문서([VFX_구현가이드](VFX_구현가이드.md), 개별 `*_ENGINE_*.md`, [ANIMATION_VFX_TEAM_MASTER](ANIMATION_VFX_TEAM_MASTER.md) 운영 대장)에 두고, 여기에는 **기준·현재 상태·다음 할 일**만 둔다.

## 1. 역할과 판정 기준

| 항목 | 내용 |
|---|---|
| 담당 | 임팩트 총괄(PC Claude 세션). 이펙트 디자인 언어 확정·후보 선별·명세·시각 판정·문서. 반복 작업(일괄 재채색·시트 교체·캡처)은 Sonnet 단순작업 세션에 명세로 넘긴다 |
| 목표 | 「어느 정도 일관성」 — 서로 다른 출처의 이펙트가 **한 게임에서 나온 것처럼** 보이게 한다. 완벽한 통일보다 눈에 띄는 이질감 제거가 먼저 |
| 디자인 기준 | 통합 컨셉 「음습하고 아름다운 지옥」 + UI의 Hell Gothic(흑철·뼈색·붉은 지옥불). 이펙트 해석은 §2 |
| 채택 규칙 | 새 이펙트·교체본은 **실제 게임 화면 1x 캡처(기존 이펙트 옆)로 판정** 후 채택. 수치·테스트 PASS만으로 채택하지 않는다. 사용자 판정이 필요한 것(기준 화풍 확정 등)은 후보를 나란히 보여 주고 고르게 한다 |
| 불변 | 이펙트 작업은 **시각만** 바꾼다. 피해·판정·쿨다운·사거리·전조 프레임 수는 바꾸지 않는다(필요하면 해당 시스템 문서·담당과 별도 결정). 돌진/패링/방패(`docs/2_3`) 설계 불변 |
| 웹↔Unity | 마스터 보드 F02 원칙: 이펙트는 **웹 구조(언제·어디서·얼마나 크게) 위에서 Unity가 새로 제작해도 된다**. 이 문서의 디자인 기준은 웹·Unity 공통 |

## 2. 이펙트 디자인 언어 (VFX 스타일 기준 — 총괄 초안, 사용자 확인 전)

> 아래는 총괄 **제안**이다. §6 VFX-01에서 기준 에셋을 사용자에게 보여 주고 확정하면 「초안」 표시를 지운다.

### 2.1 화풍 한 줄

**어둠 속에서 터지는 탁한 빛.** 코어 한 점만 밝고, 바깥은 불씨·그을음·연기로 빨리 어두워진다. 반사실(painterly) 플립북이 기본.

| 한다 | 하지 않는다 |
|---|---|
| 코어 밝음 → 주변 급감쇠, 그을음·연기·잔불로 마무리 | 화면 전체를 밝히는 큰 원형 글로우 |
| 탁한 지옥불(주황·적갈), 녹슨 금속, 뼈색, 차가운 회청 | 네온 마젠타·시안·라임 같은 원색, 형광 |
| 불규칙한 실루엣(찢긴 불꽃·파편·먼지) | 만화식 뾰족 별, 두꺼운 흰 외곽선, 균일한 원 |
| 반사실 질감, 1x에서 형태가 바로 읽힘 | 점·잔점·디더링·반짝이 점(CLAUDE.md §8) |
| 플레이어 기술=은·뼈·지옥불 / 적=탁한 독·어둠·핏빛 | 같은 화면에 픽셀아트·만화풍·사실풍 혼재 |

- **게임 안에서 색이 바래는 점(실측)**: 원소 피격은 알파 0.45·가산·약 70~110px로 그려지고 화면 전체 색보정이 겹쳐, 시트에서 차분한 중간색은 게임에서 회색으로 보인다. 그래서 시트 제작 시 ① 흰 코어를 원소 중간색과 45:55로 섞고 ② 중간톤 채도를 2.0배 보정한다(`tools/vfx/gen_hit_impacts.py`). 판정은 항상 게임 캡처로 한다.
- **붉은 경고색 예약**: 바닥 붉은 링·붉은 펄스는 **적 공격 예고 전용**. 플레이어 기술의 바닥 이펙트는 화염이라도 주황·금빛 쪽으로 둬서 예고와 헷갈리지 않게 한다.

### 2.3 크기·층·길이 3단계

PoE2 학습([POE2_REFERENCE_STUDY](POE2_REFERENCE_STUDY.md) §3.1·§6.5)의 층 구조를 우리 기준으로 고정한다.

| 단계 | 대상 | 층 수 | 총 길이 | 구성 |
|---|---|---|---|---|
| S 소 | 일반 타격·투사체 명중·잡몹 피격 | 2층 | 0.15~0.35초 | 코어 섬광 + 파편/불씨 |
| M 중 | 스킬 명중·폭발·패링·처치 | 3~4층 | 0.4~0.8초 | 섬광 + 링/충격파 + 플립북 + 그을음/연기 |
| L 대 | 궁극·보스 강공·페이즈 전환 | 5~8층 | 0.8~1.5초 | 위 + 바닥 데칼(균열·그을음, 2~3초) + 잔광 |

- 층 시작은 0~0.15초 사이로 흩뿌린다(동시 시작 금지).
- 섬광(가산 합성)은 0.05~0.1초 안에 정점을 지나야 한다. 길게 남는 것은 연기·그을음(일반 합성)뿐.
- 보스 공격 연출은 판정보다 60~90ms 먼저 터진다(PoE2 §6.5 수치 가이드).

### 2.4 손맛 피드백 단계 (히트스톱·흔들림·화면 플래시)

수치 변경 없이 **현재 값을 단계로 묶어 기록**한다. 새 이펙트는 아래 단계 중 하나를 고른다.

| 단계 | 히트스톱(틱, `_HS` 8674행) | 흔들림 `shake(n)` | 화면 플래시 `doHitFlash` |
|---|---|---|---|
| S 소 | 0~3 (blink2·charge2·proj3·meleeSh3) | 2~5 | 원소 코어색, 0.1 이하 |
| M 중 | 4~6 (melee4·kill4·finisher5·parry6·detonate6) | 6~10 | 원소 코어색, 0.15 |
| L 대 | 7~9 (parryReflect7·groggy8·blackStar8·projBombBlue9) | 12~20 | 흰색~코어색, 0.2 |
| 특수 | 12~35 (보스 연출 직접 대입) | 25~45 | 보스·페이즈 연출 전용 |

현재 분포(실측): `shake(` 217곳 중 숫자 직접 지정 189곳 — 1~7 74곳, 8~10 58곳, 12~16 36곳, 18~30 15곳, 32~45 6곳(나머지는 변수 인자). `doHitFlash(` 20곳.

### 2.5 합성·가독성 규칙

1. 빛(섬광·번개·검기)=가산(`_setBlend(true)` / Canvas2D `'lighter'` 둘 다 지정). 연기·흙·피·그을음=일반 합성. GPU 프록시에서 `globalCompositeOperation`만 바꾸면 무효다.
2. 가독성 우선순위: **적 공격 예고 > 플레이어 피격 > 적 피격 표시 > 플레이어 타격 이펙트 > 장식**. 아래 순위 이펙트가 위 순위를 덮으면 크기·알파를 줄인다.
3. 화면을 덮는 이펙트(반경이 화면 폭 40% 이상)는 알파 상한 0.6, 지속 1초 이하.
4. 밀집 전투에서 프레임당 임팩트 상한은 기존 `_addImpact`의 2개+보스 예외 구조를 따른다(성능 규칙은 `12퍼포먼스·최적화`).

### 2.6 제작 규칙

- 이미지 생성 기본 = MagicLight(Seedream 5.0 Pro), 절차는 [MAP_OBJECT_SEEDREAM_PIPELINE](../4.1맵디자인+설정/MAP_OBJECT_SEEDREAM_PIPELINE_20260930.md)의 회색·검정 배경 + 키잉. **녹색 크로마 배경은 피한다**(가장자리 녹색 번짐).
- 프롬프트 공통 골격: `dark fantasy hell VFX, painterly semi-realistic, muted embers, soot and smoke falloff, bright core only, no neon, no cartoon star, no outline, no dots, no glitter, on flat black background`.
- 시트 형식: 정사각 셀, 4×4 또는 6×6, 128~256px/셀, 첫 프레임 빈칸 금지. 메타는 `data/vfx/*.json`(기존 `atlas-clip-runtime` 형식)으로.
- 채택 전 1x 확대로 점·가장자리 녹색·잘린 프레임 확인.

| 반복 | 1차 잔점·원형 → 2차 줄기 위주 → 3~5차 게임 내 회색화 대응(코어 혼합·채도·알파 인코딩) → 6차 빙결색·el5 규격 |
