## 1. 공통 기준

### 1.1 34° 화면 크기 (1080p, 피치 34°·거리 16.5·FOV 46.9453 — 카메라 LOCK)

| 항목 | 값 | 근거 |
|---|---|---|
| 바닥 가로 1 Core px | 약 0.75 화면 px | 1u = 100 Core px, 보스 거리에서 1u ≈ 75.4px(PREP §2 0.01327u/px) |
| 바닥 깊이 1 Core px | 약 0.42 화면 px | 위 × sin34° |
| 영웅 키 H | 약 90px | 표시 1.31u, 적 G0 표의 세로 환산 68.4px/u |
| 보스 키 | 약 250px | 영웅 × 2.8(뿔 끝) |
| 판정 원 r260(내려찍기·심장 안전 고리) | 화면 지름 가로 392 × 세로 218px 타원 | 위 비율 |

크기는 두 가지로 정한다. **범위가 있는 층**(충격 고리·균열·바닥 자국)은 Core 판정 반경·길이를 그대로 쓴다. 그래서 판정 경계와 ±4px 안에서 맞아야 한다. **접점 층**(코어·파편)은 영웅 키 배수로 정한다(마스터 §2.7.3). 보스 강공 코어는 L 1~1.5H = 90~135px, 근접 코어는 M 0.5~0.8H = 45~72px이다.

금지: 원색·네온·라임(76~87° 신규 금지), 만화 별·십자 섬광·외곽선 고리, 잔점·반짝이·디더(점 금지 — 파티클은 늘인 조각 3×10px 이상), 화면 전체 밝은 덮개. 붉은 테두리 `#c8402a`는 **예고 전용**이라 본체에 쓰지 않는다.

### 1.3 탄막·예고 가독성

1. **그리는 순서:** 바닥 자국·먼지 → 예고 데칼(빨간 테두리) → 배우 → 탄. 본체 이펙트가 예고 테두리나 탄 위로 올라오지 않는다. 같은 칸에서는 알파를 0.5 이하로 낮춘다.
2. **플레이어를 가리는 시간:** 보스 이펙트가 플레이어 몸 상자를 0.2초(12틱) 넘게 가리지 않는다(R7). 잡기 흡수 뿌리는 몸 테두리까지만 닿는다.
3. **화면 폭 40% 이상 이펙트**(돌진 흙길·균열 전체·심장 파동): 알파 ≤0.45, 밝은 덮개 0, 띠는 얇게. 심장 파동은 띠 폭 ≤40 Core px를 12틱 안에 통과한다.
4. **먼 적·기둥 그림자를 지우지 않는다**(카메라 LOCK). 먼지·연기는 낮게 깔고(높이 ≤0.4H) 0.8초 안에 사라진다.
5. 동시 상한: 보스 본체 스프라이트는 틱당 새로 2개, 동시 24개, 데칼 8개. 넘치면 오래된 것부터 지운다.
6. **판정 캡처:** 기술마다 예고 데칼·탄·먼 적이 같이 보이는 장면을 넣는다.
