## 2. 모디파이어 (LT 홀드 + 버튼)

| 입력 | 키보드 대응 | 기능 |
|------|------------|------|
| **LT + A** | 1 | 스킬슬롯 1 |
| **LT + B** | 2 | 스킬슬롯 2 |
| **LT + Y** | 3 | 스킬슬롯 3 (`_LT_COMBO[3]`) |
| **LT + X** | 4 | 스킬슬롯 4 (`_LT_COMBO[2]`) |
| **LT 단독 탭** | F | 회복 영역 |
| **LT + RT** | X | 처형 (execution) |

> LT 홀드 중 ABXY를 누르면 스킬슬롯 발동, KeyF는 안 나감.
> LT를 ABXY 없이 뗄 때만 KeyF 탭 발동 (100ms).

## 4. D-pad (메뉴/UI 바로가기)

| 방향 | 키보드 대응 | 기능 |
