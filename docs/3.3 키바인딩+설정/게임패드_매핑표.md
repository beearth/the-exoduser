## 2. 모디파이어 (LT 홀드 + 버튼)

|------|------------|------|
| **LT + A** | 1 | 스킬슬롯 1 |
| **LT + B** | 2 | 스킬슬롯 2 |
| **LT + Y** | 3 | 스킬슬롯 3 (`_LT_COMBO[3]`) |
| **LT + X** | 4 | 스킬슬롯 4 (`_LT_COMBO[2]`) |

## 4. D-pad (메뉴/UI 바로가기)

| 방향 | 키보드 대응 | 기능 |
|------|------------|------|
| **↑** | K | 스킬 창 열기 (`skillPanel`) |
| **↓** | G | 대장간 열기 |
| **←** | J | 능력치 창 열기 (`statPanel`) |
| **→** | N | 인벤토리 보관함 탭 열기 (`openInventoryStorage`) |

> D-pad 패널 열기는 **열린 패널이 없을 때만** 동작한다(`_pollGamepad` D-pad 블록의 `!_anyPanelOpen`). 패널이 열려 있으면 D-pad는 항목 이동 전용이므로 같은 버튼으로 닫히지 않는다. 닫기는 Back(Select) 또는 B(뒤로가기).
