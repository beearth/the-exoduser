## 입력 규칙

- 구르기 = **방향키(이동 키)를 누른 채 구르기 키**, 또는 구르기 키를 누른 채 방향키. 대각선은 두 방향키로.
- 키 설정에 `BINDS.roll`(기본 `Space`, 보조 `BINDS2.roll`)이 있고, 설정 창 키 목록에 **"구르기 (방향키 +)" / "Roll (Arrow Keys +)"** 줄이 있다(석궁 줄 바로 옆, 사슬 이동 다음).
- 구르기 키 == 석궁 키(기본 둘 다 Space): **방향 입력이 있으면 구르기, 없으면 석궁/지옥강타**. 다르면 구르기 키는 방향키와 함께일 때만 구르기이고 단독 입력은 아무 일도 하지 않는다.
- 구르기 키는 **키보드 키만** 지정할 수 있다(마우스 버튼 지정 시 "구르기는 키보드 키로 지정하세요." 안내 후 거부).
- 게임패드: 패드 B(버튼 1) = `Space` 키 주입, 좌스틱 = WASD 주입 → **LS + B = 구르기**. 별도 패드 매핑 추가 없음(`_GP_KEY[1]='Space'`가 곧 구르기 키). 패드 도움말 글리프 `_PAD_GLYPH_KEY['Space']='Ⓑ'` 유지.
- 사슬기동(`_harpActive`/`_dashActive`) 중에는 구르기 키 입력을 구르기로 소비하지 않는다(기동불꽃 입력 보호, 전격이동과 동일).
- 구르기는 마법사 계열이 아닌 영웅(전사·실버테일) 전원의 기본 기동이다.

## 전격이동(bladeDash) 정리

- `SKILL_LIST`의 `bladeDash`에 `mageOnly:true`. 스킬창(K)은 마법사 계열이 아니면 목록에서 숨긴다.
- `mkP()` 시작 스킬에서 제거. `_MAGE_CHAR_IDS=['exoduser_transmuter','exoduser_spearmage']`(둘 다 아직 `CHAR_LIST`에 없음·로비 `comingSoon`)인 영웅만 `bladeDash` 1렙을 기본 보장(`_ensureMobilitySkill`).
- 합체 `bladeEcho`(추적전격)·`thunderGhost`(전격의창)는 전사가 만들 수 없다. 추천 빌드 3단계는 전사 경로에서 `bladeDash`·`thunderGhost`를 뺐다(`추천빌드_SKILL_REC_PATH.md`).
- 마법사 계열 영웅이 생기면: 방향키+Space와 더블탭 둘 다 사용, MP+0.7칸 비용·착지 전류장판 그대로(기존 `bladeDash*` 테스트가 계약).
