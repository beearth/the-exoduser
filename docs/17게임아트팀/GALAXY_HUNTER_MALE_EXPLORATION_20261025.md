# R08 남성 외계 사냥꾼 — 신규 탐색안 (2026-10-25)

사용자 최신 지시: “차라리 프레데터 버전같이 남케를 해볼까 뭔가 이상한 그냥 ai이미지느낌만난다”. 여성 R07의 크롬 의상 장식 중심 접근을 중단하고 남성 외계 사냥꾼의 실루엣/종족/장비를 새로 설계한다. 과거 거절된 남성 후보를 재사용하는 지시가 아니다. 남성 전환의 탐색 요청이며 최종 성별/외형 채택이나 게임 ID 변경은 아니다.

## 제안하는 한 안

한 줄: **자기 몸을 개조해 거대 외계 생물을 사냥하는, 거친 피부와 각진 금속 관절의 남성 갤럭시 헌터.**

| 요소 | 제작 방향 | 상태 |
|---|---|---|
| 핵심 인상 | 위협적인 사냥꾼의 덩치와 사냥 경력이 읽히는 장비. 프레데터는 위압감/사냥 문화의 분위기 참고 | 사용자 방향 + 제작 해석 |

| 종족/얼굴 | 잿빛 거친 피부, 단단한 이마뼈와 낮은 광대, 깊고 좁은 눈, 오래된 흉터. 얼굴을 드러내고 머리 뒤 짧은 골판이 고유 실루엣을 만듦 | 새 종족 제안 |
| 몸과 크롬 | 주재료는 피부와 무광의 닳은 외장. 쇄골/갈비 옆/골반의 짧고 각진 매립 패널과 오른 기계팔. 광택은 모서리와 마모면에 집중 | 제작 해석 |

| 자세 | 거대한 총을 다루는 데 익숙한 자연스러운 무게중심. 전신/양손/총이 읽히는 3/4 자세 | 제안 |
| 배색/재료 | 잿빛 피부·무광 흑철·마모된 크롬·작은 암적색 표식. 거울처럼 번쩍이는 전신 은색보다 큰 재료 면을 우선 | 제안 |

## AI 장식 느낌을 줄이는 검수 기준

- 작은 장식보다 큰 실루엣, 얼굴, 총을 먼저 읽을 수 있어야 한다.
- 보호판/관절/벨트/탄약통마다 연결과 사용 이유가 보여야 한다.
- 크롬은 피부에 이어지는 접합/패널 이음새로 표현하고 덩굴/문양처럼 얹지 않는다.
- 피부와 금속의 거칠기/광택을 구분하고 동일한 잔금속 패턴을 온몸에 반복하지 않는다.
- R02의 총을 보존하되 인물에 맞춘 파지와 무게중심을 실제 수신 이미지에서 검토한다.

## 제작 경로와 상태

현재 MagicLight의 Nano Banana 2.1/Flare/Sunburst는 실제 Create 시 구독 만료/회원 전용 화면을 열었다. Higgsfield 잔액은 현재 조회 0.13 credits, 직전 GPT Image 2.5 Flare 최저 견적 0.25 / Nano Banana 2.1 견적 1.5보다 적다. 이 문서는 검토 가능한 새 남성안의 설계이며 새 남성 이미지는 아직 생성하지 않았다. 다른 이미지 생성 도구 전환은 프로젝트 AGENTS.md의 별도 사용자 지시 조건을 따른다.

여성 R02/R04/R07과 과거 남성 거절본은 보존한다. 새 시안 수신·사용자 채택·게임/3D 반영·배포는 각각 별도 상태다.
