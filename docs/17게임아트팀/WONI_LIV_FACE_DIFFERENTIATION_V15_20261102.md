# 여성 캐릭터 얼굴 분리 v15 — 원이 / 리브 참고

사용자 “둘이 얼굴 다르게해 한명은 리브얼굴써봐 같은거같은데 지금”에 따라 왼쪽 복근형은 기존 원이 참고 얼굴을 유지하고 오른쪽 창법사는 리센느 리브 사진을 참고한 얼굴로 교정했다. 채택된 비대칭 단발·비대칭 올림머리는 유지한다. 새 얼굴 출력은 사용자 검토 전이며 기존 헤어 채택과 구분한다.

| 출력 | 왼쪽 | 오른쪽 | 파일 |
|---|---|---|---|
| 얼굴 확대 3열 | 복근형 원이 참고 | 중앙 단발·우측 올림머리 모두 동일 리브 참고 창법사 | woni_liv_face_compare_v15.png |
| 전신 01 | 복근형 기존 얼굴·하프업 | 창법사 리브 참고 얼굴·비대칭 단발 | woni_liv_fullbody_bob_v15.png |
| 전신 03 | 복근형 기존 얼굴·레이어드컷 | 창법사 리브 참고 얼굴·비대칭 올림머리 | woni_liv_fullbody_updo_v15.png |

단순 헤어·눈 색 차이 대신 눈의 개방 형태·눈썹·코·입술·볼과 턱 비율을 교정했다. 실제 확대판에서 왼쪽은 좁은 눈매·직선적인 눈썹, 오른쪽은 더 열린 눈·부드러운 볼·짧은 하안부·도톰한 입술로 차이가 보인다. 정확한 닮음과 충분한 인물 구별은 사용자 검토가 남았다. 오른쪽 두 헤어에서 동일 인물 기준을 사용했다.

리브 입력 사진: [팬페이지 프로필](https://rescene.love/en/members/liv/), [이미지 미러](https://rescene.love/media/members/liv.webp). 팬페이지는 Runaway 공식 프로필 사진으로 표기하나 직접 공식 이미지 호스트까지 검증한 자료는 아니다. 원본 webp·출처 영수증은 reference_liv_profile_20261102.webp 및 동명 receipt.json으로 저장했다. 외부 사진은 얼굴 참고용이며 게임 에셋에 사진을 붙여 쓰지 않았다.

생성: 내장 image_gen. 얼굴 확대 1회 후 이를 얼굴 정체성 참조로 전신 2회 편집했다. 실제 모델 ID·비용 미노출. 세 출력의 원본·전체 프롬프트·입력 역할·규격·SHA-256은 woni_liv_faces_v15.receipt.json에 기록했다. 프로젝트 output/character_style_variations_20261101/ 및 바탕화면 동일 검토 폴더 사본을 검증했다. 비교 페이지 woni_liv_faces_v15.html을 새로 만들고 기존 비교판에 진입 링크를 추가했다. 이전 PNG·헤어 승인 정본은 보존했다.

원하는 얼굴 교정 방향을 반영한 검토 출력이며 얼굴 최종 채택·게임·3D·애니메이션 적용 완료가 아니다. 전신은 생성 편집이므로 의상 소품·피부 명암의 작은 편차가 있다. 마법창 승인 기준 및 금속 강체 기준을 바꾸지 않았다. 저장 도우미 save-woni-liv-faces-v15.cjs와 별도 Git 백업 도우미를 사용한다.
