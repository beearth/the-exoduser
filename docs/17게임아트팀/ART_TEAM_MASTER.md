## 3. 제작 파이프라인

### 3.1 모델 선택

> **2026-09-30 최신 사용자 지시 적용:** 신규 이미지는 MagicLight Toolbox 잔여 포인트를 우선 사용한다. 물체·아이템은 Seedream을 먼저 시험하며 작업 시 모델·비용·잔액을 확인한다. 포인트 부족이 실제 확인되면 연결된 Higgsfield GPT 이미지 모델로 전환한다. 아래 비용은 과거 기록이며 고정 현재가가 아니다. 별도 사용자 지시가 없는 다른 모델로 임의 전환하지 않는다.

|---|---|---|
| 맵 오브젝트·배경·텍스처·인물 작은 풍경 | **Seedream** (MagicLight Toolbox 우선, 실제 제공 모델 확인) | 과거 MagicLight 100/장 기록, 작업 시 재조회 |
