## 인게임 이식 경계와 남은 검수

unity-import-profile.json은 실제 골격의 부모 관계로 만든 Humanoid 후보 매핑이다. 이름과 높이 순서가 반대인 **Hips → Spine02 → Spine01 → Spine → neck → Head**를 확인했으므로 Spine02=Spine, Spine01=Chest, Spine=UpperChest로 기록했다. 아직 Unity Avatar 검증을 통과한 설정은 아니다. 원본 GLB의 0.01 루트에 단위를 중복 적용하지 않는다.
