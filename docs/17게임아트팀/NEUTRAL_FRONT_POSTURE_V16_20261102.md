내장 image_gen으로 기존 v15 PNG를 편집했다. 실제 모델 ID·비용은 미노출이다. 그림에서 정면 얼굴과 수평 눈높이·직립 목, 몸 중앙에 골반을 둔 접지 자세를 확인했다. 숫자 yaw/roll/pitch=0은 생성 프롬프트의 목표이며 실제 측정값으로 주장하지 않는다. 얼굴 확대판의 왼쪽 최상단 잔머리는 위쪽 경계와 가깝다. 자세를 돌리는 과정에서 얼굴 닮음·의상 소품·부피의 생성 편차가 생길 수 있으며 사용자 검토가 남았다.

원본·전체 프롬프트·입력·규격·해시는 neutral_front_v16.receipt.json에 보존했다. 원본/프로젝트/바탕화면 PNG SHA-256 일치 및 HTML/이미지 HTTP 응답 바이트 일치를 확인했다. 비교판 neutral_front_v16.html을 저장하고 이전 비교 페이지에도 최신 진입 링크를 추가했다. v15와 기존 채택 헤어 정본은 보존했다.

새 출력은 검토 후보이며 게임·3D·애니메이션·실제 대기 동작의 검증이 아니다. 저장 도우미 save-neutral-front-v16.cjs는 본 작업 파일과 관련 docs만 변경한다. 승인 마법창 3종과 금속 강체 규칙은 그대로다.
