# 대검전사 스토리 v6 — 마지막 컷 정리

> **최신 실행안 v7:** [컷별 기획·마지막 대사 분리](WARINTRO_REALISM_V7_PRODUCTION_20260909.md). 가족 장면 실사풍으로 후반을 재제작한다. 마지막 대사를 “지옥을 탈출하라.” → 약1.2초 쉼 → “죄인이여.”로 분리한 음성 초안과 원화14장 준비. 의미상21대사·자막22cue·101초, 질문 뒤3.7초 유지. 후반 영상16개와 검·갑옷 교정 영상2개 생성·다운로드 완료. 대사·22cue 자막 포함101초 합본 제작 및 전체 디코딩 완료. 수정 컷 표본 검수 완료, 전체 실시간 재생·청취 승인은 미완료. v5/v6 및 아래 파일/검사값은 불채택 제작 이력이다.

2026-09-09 사용자 “마지막컷 정리좀해라 이상한데” 반영. W16-C의 짧은 얼굴 재등장과 탈출 영상의 자세·망토 변화, W16 앞뒤의 전사 외형 불일치를 정리했다. v6 제작 이력 문서이며 현재 승인 기준은 위 실사풍 재제작 문서다. 이전 v4/v5 파일과 문서는 제작 이력으로 보존한다.

상태: **사용자 불채택 — 정지 이미지 확대·그림체 불일치**. 다음 검사는 당시의 기술·정지 표본 확인 이력이다. 15개 총합본 표본과 12개 엔딩 표본, 원화2장, 디코딩·프레임·음성·자막 및 Chrome 오디오 검사 완료. 게임 런타임 적용과 물리 스피커 청취 승인은 수행하지 않았다.
