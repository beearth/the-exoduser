기존 합본·개별 원본 보존. v2는 별도 파일로 제작하며 게임 미적용. 힉스필드 video-editing + subtitles 워크플로 사용. 기존 Whisper 컷별 타이밍은 실제 편집 오프셋만 반영해 보존하고, 새 합본 전체 영어 원고 193단어를 재대조한다. 음성·자막이 화면 전환 양쪽에 존재하는지 표본과 PCM으로 확인한다. 라이브 편집기 도구는 제공되지 않아 파일 기반 프로젝트와 MP4로 납본한다.

상태: 수정 합본·9초 구간 확인본·검수 자료 로컬 저장 및 업로드 완료. 원본 보존, 게임 미적용.

기술 기록: 설치된 higgsedit의 `cut()`은 종류와 관계없이 lane 0에 배치하므로 독립 WAV를 `p.cut`으로 겹치면 visual/audio 동일 트랙 오류가 발생했다. 실제 설치 코드의 `over(handle)`는 별도 lane을 할당한다. 빌드 성공을 요구하는 회귀 검사를 먼저 실패시킨 뒤 음성 한 줄을 `p.over(voice,{at,dur:4})`로 변경했다. HTML 오버레이나 런타임 패키지 변경은 없다. 원본 음성과 수정본 음성의 파형 상관 검사를 추가해 무음·중복·시간 이동을 검사한다.
