## 3. 컨셉 — 수천의 세계, 단 하나의 구덩이

| 층 | 은유 | 화면 원칙 |
|---|---|---|
| 셀 수 없는 세계 | 각자 사연을 가진 참가자들의 고향 | SF 행성 금지. 회색 허공에 떠 있는 희미한 빛 덩어리들. 성·건물이 박힌 구체 금지 |
| 단 하나의 지옥 | 폐쇄된 경기장 | 모든 빛과 형체가 한 방향, 아래 한 점으로 빨려든다 |
| 흘러든 자들 | 숫자 대신 시대가 다른 복장의 참가자 | 재처럼 떨어지는 작은 인물들. 서로 다른 시대의 무기·갑옷 |
| 규칙 | 탈락은 형체 상실 | 쓰러진 자에게서 악의가 위로 빨려 올라간다 |
| 탈출 | 오징어게임의 상금이 아닌 출구 | 구덩이 위 단 하나의 빛 기둥 (N 컷의 세로 빛) |

톤 레퍼런스는 다크소울·엘든링의 성질만 쓴다: 말 없는 거대한 풍경, 작은 인물, 탁한 재·뼈·숯 팔레트, 한 점의 강한 색. 프롬프트에 IP 이름을 넣지 않는다.
