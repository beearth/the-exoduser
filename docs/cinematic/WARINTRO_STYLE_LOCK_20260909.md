후반 재제작 대상은46~101초의55초다. 기준이 되는 앞 가족 장면은 유지한다. 영어 목소리·의미상21대사·전체101초·질문 뒤3.7초 간격을 보존한다. 최신 사용자 지시로 마지막 명령 안에 쉼을 넣고 자막을2개로 나누므로 v7은22cue다. 후반의 최종 컷 수와 세부 화면 전환은 영상 제작 후 확정하며, v6의27컷을 새 영상의 확정값으로 간주하지 않는다.

제작 순서: 가족 참조와 동일 주인공 기준 고정 → 후반 원화를 나란히 비교해 그림체/외형 확인 → 실제 영상 생성 → 움직임/연속성 확인 → 기존 음성·자막 합성 → 전체 재생 검수. 원화 검수는 중간 공정이며 영상 납품을 대신하지 않는다.
