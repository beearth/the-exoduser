## 업로드 복구 및 첫 요청

## 마지막 대사 호흡 — 최신 변경

영어 더빙과 기존 목소리를 유지한다. 한국어 자막만 바꾸고 음성은 붙여 읽는 방식은 불가하다. 의미상 원문21대사는 유지하면서 마지막1문장을 화면상2cue로 나눠 전체22cue가 된다.

| 항목 | v6 이력 | v7 초안 |
|---|---|---|
| 질문 발화 | 90~91.34초 | 유지 |
| 질문 뒤 간격 | 3.7초 | 유지 |
| 첫 명령 | 문장 전체95.04~96.38초 | “Escape from hell.” 기존 단어 정렬95.04~96.04초 |
| 구절 사이 쉼 | 기존 단어 정렬상 .16초 | 약1.2초 목표: 1.04초 무음 추가 |
| 호명 | “sinner.”96.2~96.38초 | 97.24~97.42초 (기존 단어 정렬+1.04초) |

`realism_v7/render_dialogue.py`가 기존 full_review_v4/final.mp4 음성을48kHz stereo float PCM으로 디코딩하고96.095초에서 분리한다. 단어 사이 에너지 골을 이용하며 이음부 양쪽3ms fade,1.04초 디지털 무음을 삽입한다. 마지막에 잘리는 원본1.04초가 완전 무음인지 검사한다. 이음부 밖 샘플은 이동을 제외하고 원본과 완전히 같다. 발화 속도·피치·목소리를 바꾸거나 TTS를 새로 호출하지 않았다.

단어 타임스탬프는 기존 alignment.json 기준이며 음절/잔향의 실제 경계와 연기는 청취 검수 후 확정한다.1.2초는 연출 초안으로 명시하며 사용자가 초 단위 길이를 확정한 것으로 취급하지 않는다.
