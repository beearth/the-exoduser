# 세계관 인트로 후반 — 전투·단일 구덩이·탈출 개정

2026-09-07 사용자 최신 요청 및 "해보자"에 따른 제작 기준. 게임 코드·런타임 순서는 변경하지 않는다.

## 확정 방향

- 11컷의 기존 B04 v1 낙하 실루엣 영상은 사용자에게 메시지가 맞지 않는 것으로 지적되었다. 현행 후보에서 제외하고 파일은 이력으로 보존한다.
- 판타지·사이버펑크와 서로 다른 능력의 존재가 **같은 단 하나의 구덩이에서 서로 싸운다**. 여러 우주로 화면을 분할하거나 단순 폐허·낙하만 보여주지 않는다.
- 사용자가 고친 표현은 **초능력을 지닌 자도**. '기적을 부리는 자'로 대체하지 않는다.
- 후반은 서로 겨누는 자들 → 단 하나의 바람인 탈출 → 추락에 맞서는 EXODUSER로 마무리한다.
- EXODUSER를 자아 없는 모든 괴물의 자동 명칭으로 확대하지 않는다. 탈출 의지와 추락에 대한 저항이 결말의 초점이다.

## 버전·길이 관리

기존 18컷 검토표와 130.292초 합산은 **이번 후반 개정 이전 구안**이다. B05~B06 및 A08/A09/E01/E02의 기존 파일·문서를 삭제하지 않으며, 새 결말에 모두 자동 삽입하지도 않는다. 새 후반 분할·더빙 길이가 정해진 뒤 전체 길이를 다시 계산한다.

11컷 제작 당시에는 한 컷씩 확인하는 범위였다. 이후 사용자가 "자고올테니까 오토로 끝까지"라고 요청하여, **12~14컷·암전 타이틀·전체 영어 더빙/한글 자막 합본까지 자동 완성**으로 범위를 확대했다. 게임 적용·외부 게시·추가 요금제 결제는 제외한다. 원본과 과거 편집은 모두 보존한다. 자동 제작과 기술/표본 검수는 사용자 감상 승인을 의미하지 않는다.

자동 제작 상세·최종 상태: [AUTO_FINAL_20260907](AUTO_FINAL_20260907.md). 이후 [합본 v2](WORLD_INTRO_V2_BRIDGE_20260907.md)에서 8~9컷 침묵만 4초 줄여 후반의 절대 시작 시각도 4초 앞당긴다. 후반 대사·개별 컷 길이·순서는 그대로다. 11컷 세부 납본 기록은 [B04 v2](B04_V2_HIGGSFIELD_VIDEO_REVIEW.md).
