## 범위와 결론

사용자 요청: 전체 검토 및 A09 재제작. A09는 기존 껍질을 잡고 미세하게 압박하는 상태로 끝낸다. 파열·탈피·탈출 성공·전진 연출은 취소한다. 대사 '찢고 나가는 것.'은 유지한다.

최초 전체 검토는 대사, 기존 콘티, 개별 제작 기록, A01~A08·엔딩의 저장된 검사 프레임, p12~p17 원화를 대조한 것이다. 하나의 완성 합본을 처음부터 끝까지 재생·청취한 검수는 아니다. 후속 사용자 요청으로 B01 v2·B03·B04 영어 더빙·한글 자막 검수본과 B02 무대사 검수본을 완료했다. B05~B06은 아직 신규 납본이 없으므로 전체 영상 완료로 보고하지 않는다. 게임 적용 없음.

**결론: 기본 세계관→망각→저항→선의의 흐름은 성립한다. B01~B06을 누락 없이 복원하고 순서를 정리해야 한다.** 아래 재배치는 승인 전 제안이며 실제 편집·런타임 순서를 바꾸지 않았다.

## 세계관 정합과 문서 충돌

- 최신 B01 사용자 요청은 사이버펑크·판타지 혼재를 명시적으로 보여주는 것이다. 기존 네온·SF 직접 노출 금지보다 이를 우선하며 B01 v2에 한정해 기록한다. 나머지 컷을 자동으로 재제작하지 않는다.

- 단일 지옥·악의 수렴·잔류에 따른 괴물화는 WORLDVIEW v2와 일치한다.
- 기존 세계관 문서는 '악의의 임계 초과'를 조건으로 두지만, 사용자 최신 승인 문장은 '죄를 지은 모든 생명'이다. 표현 범위 차이를 기록한다. 최신 사용자 문장을 임의로 완화하거나 바꾸지 않는다.
- A06의 자신의 파괴적 에너지 형상화와 기존 잔류의 법칙은 표현 초점이 다르다. 본 인트로는 사용자 최신 해석을 우선하고 외부 에너지 주입으로 바꾸지 않는다.
- '시간은 의미를 잃는다'는 체감과 서사의 표현이며, 시간이 물리적으로 완전 정지한다는 설정을 새로 추가하지 않는다.
- '선의'는 남은 태도·행동이다. 새로운 신성 에너지나 구원의 빛을 부여하지 않는다.
- WORLDVIEW v2의 S0 공개 제한과 기존 시네마틱 문서의 공개 범위는 일치하지 않는 부분이 있다. 이번 사용자는 게임 세계관 인트로를 직접 승인 중이므로 해당 요청 범위를 따른다. 외부 마케팅 영상으로 전환 시 공개 범위를 별도 확인해야 한다.
- 옛 콘티의 'B는 마케팅 전용', '영상 생성 안 함', 'KO/EN 별도 녹음', 42/64초 같은 수치는 과거 이력이다. 현재 제작은 영어 내레이션+한글 자막이며 B도 전체 서사에 포함된다.
- 전쟁에서 돌아온 남자 인트로와 혼합하지 않는다. 서사 비밀·특정 탈출 사례를 화면이나 대사에 추가하지 않는다.
