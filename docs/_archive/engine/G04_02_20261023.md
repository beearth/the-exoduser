## 검수 방법

웹은 원본 `godot/source_snapshot/game.html` SHA256 `dee094fd165e9b2fb3fbf0eb9cacc3bc3eddeb2c8eeea9c4772ba6cbc1f05209`를 HTTP 응답으로 제공하고 나머지는 기준 SHA의 파일을 사용한다. 기존 `sweep_b_pc_web.cjs growth`만 사용한다. 창 모드 Chrome headless=false, deviceScaleFactor1, 실제 ANGLE Metal Apple M5 Pro GPU 사용을 기록한다. 최초선택 pAtk와 pMagic 선택을 촬영한다. 폰트 loaded, 가시 이미지 실패0을 확인한다.

Godot은 기존 `sweep_b_pc_capture.gd --mode=growth`에서 실제 로비→게임→J 패널을 열고 엔진 내부 viewport texture를 저장한다. 각1920×1080, 비교3840×1080. `captures/G-04_compare_1x.png`, `G-04_detail_1x.png`는 웹 왼쪽/Godot 오른쪽, crop도 1x이며 보간 확대하지 않는다. 캡처는 시각 fixture이며 전체 E2E가 아니다.

기존 `test_demo11_growth_ui`는 USERDIR만 새 격리 namespace로 바꾸고 assertions/기대값은 보존한다. 새 진단 테스트 파일·전체 E2E 없음. import/테스트/캡처 로그, 최종 판정은 DONE에 기록한다. 실패 테스트는 수정 없이 재실행하지 않는다.
