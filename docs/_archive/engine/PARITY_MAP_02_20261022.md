## 1440p 청크 (제작 이력; 현행 상주는 MAP-03 참조)

지정 `realesrgan-ncnn-vulkan -n realesrgan-x4plus -s4`를 사용한다. 원본1024core의 이웃64px를 붙인1152² 입력64개다. 최종 core1334² + 공통master의1px bleed(1336²), 논리1000px/좌표/레이어 불변. 1440p 카메라1.0에서1334/(1000×1440/1080)=1.0005 texel/px다. 모델의 색 이동을 그대로 사용하지 않는다. 원본 chroma/alpha·국소 톤을 유지하고, `delta=clamp(.6*(modelY−Gaussian3(modelY)−sourceY+Gaussian3(sourceY)),−8,8)`를 RGB 모두에 더한다(Y=.299R+.587G+.114B). 후처리는 최종16px 이웃 문맥에서 계산한다. 알파는 원본 리샘플값이다. bleed는 독립생성하지 않고 완성된공통master에서 취한다. 당시 원본64장은 보존하며 로딩실패시 원본으로 폴백했다. 현행 MAP-03은 원본 PNG를 보존하되 fallback 로드 없이 사전 압축 Image + 가시/1링 고정 슬롯을 사용한다. 실제 출력은 **1336²(원본1024core 대비 약1.3배)**이며 x4는 중간 모델 배율이지 런타임 해상도가 아니다.
