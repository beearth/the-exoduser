# Steam 인터페이스 번역 보충 — 2026-09-09

## 현재 작업 단위

Steam 지원 언어 목표의 공통 UI 원본은 `localization/ui-source.json` 576행이며, 실제 언어별 보충 대상은 `localization/ui-needed.json`에 고정되어 있다. 이 문서는 첫 번째 중국어 작업 단위를 기록한다. 전체 27개 대상 언어의 번역이 완료되었다는 뜻은 아니다. 오디오·더빙은 작업 대상에서 제외한다.

| 언어 | 파일 | 필요 키 | 작성 키 | 필요 키 누락 | 빈 값 | 영어 원문 그대로 복사 |
|---|---|---:|---:|---:|---:|---:|
| 간체 중국어 `zh` | [zh.json](../../localization/ui/zh.json) | 488 | 488 | 0 | 0 | 0 |
| 번체 중국어 `zht` | [zht.json](../../localization/ui/zht.json) | 483 | 483 | 0 | 0 | 0 |
| 이번 단위 합계 | 두 파일 | 971 | 971 | 0 | 0 | 0 |

최초 작업 목록은 27개 언어, 총 13,273행이다. 이 작업 단위 이후 나머지 25개 언어의 12,302행은 별도 작업 대상으로 남는다. 이번 작업자가 다른 언어 파일이나 게임 코드, 생성 번들을 변경하지 않았다. 실제 번들 반영 및 브라우저 화면 검증은 통합 작업에서 수행한다.

## 데이터 계약과 검증

파일은 UTF-8 JSON이며 `{한국어 원문 키: 현지어 문자열}`의 평평한 객체다. 해당 언어의 필요 키만 포함한다. 기존 카탈로그는 유지하고 보충 객체를 런타임에 병합하는 구조를 따른다.

| 검사 | `zh` | `zht` | 기준 |
|---|---:|---:|---|
| JSON 파싱 | 통과 | 통과 | Node.js `JSON.parse` |
| 필요 키와 작성 키 집합 | 일치 | 일치 | 추가 키와 누락 키 모두 0 |
| 치환 토큰 포함 행 | 36 | 36 | EN 원문의 `{n}`, `{p0}` 등 토큰과 중복 횟수까지 동일 |
| 고정 숫자 포함 행 | 163 | 163 | 치환 토큰을 제외한 KO 원문 숫자 다중집합과 동일 |
| 이모지 포함 행 | 25 | 25 | KO 원문의 이모지 다중집합과 동일 |
| 값에 한글 잔류 | 0 | 0 | 한국어 키는 원문 그대로 유지 |
| 영어 원문과 동일한 값 | 0 | 0 | 기술 약어는 문장 안에서 보존 가능 |

`Q/E/F/R/Space/Shift/Ctrl/LMB/RMB/T/K` 등의 조작 키와 `HP/MP/ST/SP/AP/STR/DEX/INT/DOT`, `_skMul`, `magicRef`, `bowPierce`, `pPierce` 식별자는 유지한다. 무지개·보라 마법탄은 Q, 물리탄은 E라는 원문 구분을 보존한다.

번체는 간체 초안의 의미를 공유하면서 한자 변환 후 별도 표현을 보정했다. `後/於/並/範圍/防禦/雲端/鬆開/軀幹/製作` 등의 다의자와 `滑鼠/游標/預設/雷射/載入/畫面/點選/網路/導引/搜尋`을 검토했다. 한자 구간만 변환하여 이모지와 치환 토큰이 변형되지 않게 했다. 외부 번역 API를 사용하지 않았다. 원어민 검수 완료로 표기하지 않는다.

## KO와 EN 원문 차이 처리

| 한국어 원문을 찾는 기준 | 발견한 차이 | 이번 보충 번역 |
|---|---|---|
| `[고정: T 자동] 초고속 바늘 연발...` | EN 설명에는 KO의 `Lv당 뎀+100%`가 빠져 있음 | 매 레벨 피해 +100%를 보존 |
| `5초간 유령화 — 무적+이동...` | KO는 통과한 적과 탄막을 모두 계산하지만 EN은 적만 언급 | 적/탄막 양쪽 명시 |
| `적에게 약점노출 디버프...` | EN은 `DOT excluded`로 축약되어 장판 제외가 드러나지 않음 | DOT와 지면 지속 피해 제외를 모두 명시 |
| `지진폭풍+추적암전 → 6단합체: 폭풍빔` | EN은 합체 구성 중 추적암전이 생략됨 | 두 구성 스킬 모두 명시 |
| `합체 Lv.{p0}...추적빔뎀...` / `합체 Lv.{p0}...진동파뎀...` | EN에만 `3-Fuse`가 붙고 KO는 일반 합체 표기 | KO처럼 일반 `合体/合體` 표기; 피해 수치·치환 토큰 동일 |
| `작은 탄막블랙홀을 즉시 설치해...` | `기본 ATK×8(Lv당×10 성장)`, `거리감쇠 30%`는 축약만으로 해석이 모호함 | 기본 ×8에 레벨 성장의 추가 배율이 최대 ×10, 거리 감쇠 후 최소 30% 피해가 남는다고 표현 |

탄막블랙홀의 마지막 항목은 `game.html`의 `fireLavaSummon()`을 읽어 확인했다. `_ult10xMul = 1 + ((slv - 1) * 9 / 19)`이며 Lv1=1.0, Lv20=10.0이고 기본 피해에 `8 * _ult10xMul`이 곱해진다. 거리 감쇠는 `Math.max(0.3, 1 - d / blastR)`이다. 코드는 수정하지 않았다.
