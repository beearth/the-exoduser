## JSON·런타임 연결 계약

| 필드 | 타입 | 적용 위치/규칙 |
|---|---|---|
| `prologue` | `{[id]: string}` | `PROLOGUE_LINES.ko`의 같은 `id`에 해당하는 `text`만 교체 |
| `intro` | `{[id]: string}` | `INTRO_CUTSCENE_LINES.ko`의 같은 `id`에 해당하는 `text`만 교체 |
| `speakers` | `{GODDESS, DIROY, HECTOR}` | 화자 표시용. 내부 화자 ID 유지. `GODDESS`의 표시명은 역할명 ‘여신’이 아닌 고유명 ‘네메시아’의 각 언어 표기 |
| 숫자형 ID | JSON 문자열 키 | 예: 원문 숫자 `3` → JSON 키 `"3"` |
| 문자열형 ID | 그대로 유지 | `wa02`, `10c`, `18b`, `22b` 등 |
| 줄바꿈 | JSON `\n` | 원문에서 의미가 이어지는 문장 구획에 사용. 화면 줄바꿈은 렌더러 책임 |
| 빈 연출 항목 | 번역 JSON에 없음 | `text: ''`, `img`, `t`, `dur`, 카메라, VFX, 전환, 효과음, `exit` 등 원문 연출 metadata 보존 |
| 생략 부호 | `intro.24 = "..."` | 의도적 침묵, 모든 언어 공통. 영어 미번역으로 계산하지 않음 |

영어 인트로 배열을 복제하고 번역만 덮으면 원문에 존재하는 `22b`가 사라진다. 반드시 한국어의 27개 항목을 기준으로 연결해야 한다. 이 데이터에는 연출 타이밍이나 오디오 경로가 들어 있지 않다.
