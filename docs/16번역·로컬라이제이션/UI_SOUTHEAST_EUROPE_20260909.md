불가리아어 기존 원소추적탄의 `Елементарен следотрасер`, 사슬기동의 `Ривок`·`тире` 혼합/오역을 교정하고 `terminology.json`에서 단독명에도 적용했다. 영웅=`Героичен`, 근성=`Упоритост`, 뇌전창=`Мълниеносен кол`, 합체 전격의창=`Мълниеносно копие`다.

필수 한국어 키·변수·HTML·수치를 보존한다. 블랙홀은 Lv20 추가배율 최대10·피해 하한30%, 기둥은 어둠 피해·지옥강타2 합체, 쇠뇌는 설치20초다. HP포함 경계와 배정키·칼날 발사·전격이동2회째 조건을 보존한다. 업화선은 최종 통합에서 직선 차징·최대5초·레벨별 MP·시전속도 쿨다운으로 전체 언어를 함께 교정했다.

그리스어는 치환 토큰·수치·명칭을 통합 담당이 검토했다. 독립 검토는 담당의 세션 사용량 제한으로 미완료이므로 PASS로 표기하지 않는다. 원어민 감수 완료나 전체 언어 번들 완료를 의미하지 않는다.
