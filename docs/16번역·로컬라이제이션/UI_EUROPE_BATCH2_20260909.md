# 유럽권 UI 번역 보완 2차 — 2026-09-09

Steam 인터페이스·자막 지원 목표의 독일어·브라질 포르투갈어·이탈리아어·러시아어·우크라이나어 MAIN 누락 문구를 보완했다. 전체 언어 적용 및 화면 검증 상태는 [언어 범위](STEAM_LANGUAGE_SCOPE_20260909.md), 런타임 사실 확인은 [유럽권 통합 기록](UI_EUROPE_TRANSLATIONS_20260909.md)을 따른다. 이 묶음은 번역 데이터 작업이며 음성 더빙 작업을 포함하지 않는다.

## 파일 및 검증 범위

기준은 `localization/ui-source.json` 576개 중 `ui-needed.json`의 언어별 작업 목록이다. 각 파일의 키 집합은 해당 목록과 정확히 같다. 본문 스킬·합체·추천 빌드·강화 템플릿·스탯과 패시브 투자 및 환불·인벤토리와 제작·전투 안내·로비 오류 및 로딩 문구를 포함한다. 한국어 키를 보존하고 한국어를 번역 의미의 기준으로 삼았다.

EXTRA 5개 파일은 별도 통합 작업에서 이미 각 66개를 번역했다. 이 작업에서는 읽어 명칭을 참조했고 수정하지 않았다. 유효 기본 MAIN은 `tools/localization-catalog.mjs`의 `loadCatalogs().tables[code]`로 조회했다. 과거 중복으로 오염된 `_BASE`의 값은 기본 스킬 명칭의 근거로 사용하지 않았다. 외부 번역 API를 사용하지 않았다.

설치형 뇌전창은 `terminology.json` 확정값을 따라 합체 전격의창과 구별했다. 러시아어·우크라이나어 문장 안에서는 명칭을 문법에 따라 격변화하되 제목과 같은 개념으로 유지했다. 칼등날개와 기동칼날개를 구별하고, 합체명은 별도 EXTRA 파일에 맞췄다. 영웅 등급은 기본 MAIN의 Heroic 계열 명칭과 연결한다.

선택은 선택 동작, 도감 등록은 등록 동작, SP 부족은 보유량과 필요량이 뒤따르는 경고로 썼다. 저사양 모드는 낮은 성능을 유발하는 옵션이 아니라 저사양 PC용 옵션임을 명확히 했다. 어픽스 리롤은 재배정이 아닌 재생성으로 표현했다. 키 바인딩 Shift/Space/Ctrl/CT/Q/E/F/L/R/T/K는 그대로 유지했다. 물리탄은 E, 보라·무지개 마법탄은 Q라는 설명을 보존했다.

## 검증 기록

다섯 JSON 파일 전체를 다시 파싱해 아래를 검사했다.

다섯 언어 모두 별도 검토의 수정 요청을 반영하고 원문·품질 PASS를 받았다. 우크라이나어 HP 경계값 보완 및 러시아어·우크라이나어 배정된 스킬 키 명료화를 포함한다. 스탯 약어, 단위, 키 바인딩, 코드 식별자와 통용 차용어는 영어 미번역 문장으로 취급하지 않는다. 이 검토를 원어민 감수 또는 브라우저 화면 검증 완료로 표시하지 않는다.

`rg -l '번역|로컬라이제이션|뇌전창|지옥강타' docs --glob '*.md'`로 관련 문서를 검색했다. 범위·번역 가이드·아시아권/유럽권 기록을 확인했다. 현행 게임 수치나 스킬 기능을 바꾸지 않았으며, 전체 진행표·번들·런타임·배포 및 공통 문서 동기화는 통합 담당 범위다. 이 작업의 변경 파일은 위 MAIN 5개와 이 문서뿐이다.
