## 기본 공식 (2026-04-17 변경)

```
데미지 = ref() × stat() × passive() × _skMul('skillId') × _fuseMul('skillId')

  → 스킬레벨 효과 절반 (10단계→20단계 쪼개기)

스킬 성장 내용:
- Lv1: base 값 (기본)

스킬레벨 캡: Lv20 (_skMaxLv=20, 50렙당 1렙 해금), Lv1→Lv20 = 약 ×1.5~2.0 성장
```

## ⚠ 카테고리별 데미지 공식 규칙 (절대 준수)

**스킬의 cat 값에 따라 아래 공식을 반드시 따른다. 새 스킬 추가·기존 스킬 수정 시 카테고리 공식 누락 금지.**

### 물리 근접 (cat:'phys')
```
meleeRef() × statStr() × pAtkMul() × _skMul(skId) × _fuseMul(skId)
```
- **ref**: meleeRef() — 무기ATK + 강화 + STR
- **stat**: statStr() — STR 배율
- **passive**: pAtkMul() = _passDmgSum('melee') — 맹공0.10×Lv+인간성0.05×Lv+제단+광전사0.15×Lv를 1에 합산 후 ×0.7. 풍요는 별도 hurtE에서 적HP≥70% 조건으로 적용
- **해당 스킬**: kiSlash, whirlwind, giantSlam, giantSlam2, maliceHunt, boneWall

### 물리 이동 (cat:'move', STR 스케일)
```
meleeRef() × statStr() × pAtkMul() × _skMul(skId) × _fuseMul(skId)
```
- **phys와 동일 공식** — 이동기라도 물리 데미지면 pAtkMul 필수
- **해당 스킬**: chainSlam(기동파괴), chainSlash(기동칼날개), chargeBoost(사슬기동:충돌)

### 마법 (cat:'magic')
```
magicRef() × statInt() × pMagicMul() × _skMul(skId) × _fuseMul(skId)
```
- **ref**: magicRef() — 마법ATK + INT
- **stat**: statInt() — INT 배율
- **passive**: pMagicMul() = _passDmgSum('magic')×(1+유니크)×2 — 공통 맹공0.10×Lv+인간성0.05×Lv+제단+마력폭주0.10×Lv+장비/내재를 1에 합산 후 ×0.7·유니크 배율. 풍요는 별도 hurtE에서 적HP≥70% 조건으로 적용
- **해당 스킬**: fireball, omniBeam, fireAura, maliceMortar, maliceStorm, hellRay, elemMissile, thunderStake

### 마법 이동 (cat:'move', INT 스케일)
```
magicRef() × statInt() × pMagicMul() × _skMul(skId) × _fuseMul(skId)
```
- **magic과 동일 공식**
- **해당 스킬**: chainAssault(기동불꽃), magicBlink(사슬기동:화염)
- **magicBlink 전용 너프 (2026-05-07)**: 직접타격 `×0.5`, fireTrail DOT `×0.5` 추가 적용

### 석궁 (cat:'bow')
```
bowRef() × statDex() × pBowMul() × _skMul(skId) × _fuseMul(skId)
```
- **ref**: bowRef() — 석궁ATK + DEX
- **stat**: statDex() — DEX 배율
- **passive**: pBowMul() = _passDmgSum('bow') — 정밀사격 투사체뎀 합연산 (+15%/Lv, 비-석궁 투사체는 hurtE에서 적용)
- **해당 스킬**: blastShot, fanShot, needleShot, fireBeam, blueShot, iceOrb

### 방어/반사 (cat:'def')
```
별도 공식 (패링 기반, pParryProjDmg 등) — _skMul 미적용 가능
```
- **해당 스킬**: detonate, maliceSwipe, guardian, peaceShield

### 유틸 (cat:'tech')
```
데미지 없음 (noDmg:true) 또는 별도 공식
```
- **해당 스킬**: holyDome, holyPrison, iceStorm
- **phys 탭 유틸 장판(별도)**: spikeTrap — 설치·출혈 장판, 피해 공식에 ×0.75 (2026-09-13 직전 피해의 50%)

## 통일 관통 시스템 (`_pierceRate`)

모든 투사체는 `_pierceRate` 베이스 값을 가지고, 어픽스/패시브로 추가됨.

### 공식
```
총 관통률 = 베이스 + bowPierce 어픽스 × 1000 + pPierce 패시브 × 100
보장 관통수 = floor(관통률 × 91 / 1000)  ← 1000=91, 2000=182
보장 초과 시: 1회=90%, 2회=80%, ..., 9회=10% (최대 +9회 추가)
최종 최대 = 보장수 + 9
```

| 스킬 | 베이스 _pierceRate | 보장 (Lv1) | 비고 |
|---|---|---|---|
| **기본값 (모든 투사체)** | **50** | **4회** | `_resetPProj`에서 자동 부여 |
| 푸른비 (blueShot) | 200 | 18 | + 어픽스/패시브 |
| 악의 사냥 (maliceHunt) | 800 + Lv×20 + bowPierce×300 + pPierce×30 | 약 74 + 장비/패시브 가산 | 별도 로직 (`_mhMaxPierce`) |

## ref 함수 구조

```
meleeRef() = (주무기ATK + enhMulAtk(강화) + slotFlatAtk + baseAtk + STR) × 봉인배율
bowRef()   = (석궁ATK   + enhMulAtk(강화) + slotFlatAtk + baseAtk + DEX) × 봉인배율
magicRef() = (마법ATK   + enhMulAtk(강화) + slotFlatAtk + baseAtk + INT) × 봉인배율

아이템 ATK = (200 + tier×200 + P.lv) × **0.5** (2026-04-18 반감)
baseAtk = 15 + (stage-1)×2
enhMulAtk(n) = n × 0.25 (1강당 +0.25, 2차반감 2026-05-03)
봉인배율 = weaponSeal 중이면 ×0.3, 아니면 ×1
몬스터 ATK (2026-09-12 기존 대비20% 상향):
  baseLin = ((보스?75:50) + monLv×(보스?2.9:1.95)) × 0.6
  ATK     = floor(baseLin × 난이도 × 정예배율)
  → 배율1: Lv100 일반147, Lv500 일반615, Lv1000 일반1200 (보스1785)
```

## 관통 스케일링 — 관통률 = 스킬 총 파워 (2026-06-05)

관통률이 올라가면 투사체 하나가 다수 적을 타격하므로 **총 딜량이 관통 횟수에 비례**해서 증가한다.
관통 데미지 보존율도 패시브로 100%를 넘기므로, 밀집 상황에서 스킬 파워가 폭발적으로 상승한다.

### 관통 데미지 보존 공식

```
관통 후 뎀 = floor(원뎀 × min(1, 0.85 + pPierce × 0.03))
```

| pPierce Lv | 관통 확률 | 최대 관통 횟수 | 관통당 뎀 보존 | 적 3체 관통 시 총 딜 |
|---|---|---|---|---|
| 0 | 0% | 0 | 85% | 100% (1체만 타격) |
| 3 | 15% | 3 | 94% | 100 + 94 + 88 = 282% |
| 5 | 25% | 5 | **100%** | 300% (손실 없음) |
| 10 | 50% | 10 | **115%** | 100 + 115 + 132 = **347%** |

> **pPierce Lv5 = 손실 제로**, Lv10 = **관통할수록 뎀 증가** (0.85 + 0.30 = 1.15)

### 관통 스케일링이 큰 스킬

## 지속시간 스케일링 — 지속시간 = 스킬 총 파워 (2026-06-05)

장판/지속/DOT 스킬은 지속시간이 곧 총 딜량이다. 지속시간 2배 = 총 딜 2배.
DOT는 **지속시간(pDotDur)** + **축적률(pDotPool)** 이중 스케일링으로 효과가 극적이다.

### 패시브 침식 (pDot) 공식

```
pDotDur()  = 1 + pDot × 0.10    ← DOT 타이머 감소 속도 역수 (지속시간 연장)
pDotPool() = 1 + pDot × 0.05    ← DOT 풀 축적량 증가
pDotDmg()  = 별도 배율           ← DOT 틱 데미지 배율
```
