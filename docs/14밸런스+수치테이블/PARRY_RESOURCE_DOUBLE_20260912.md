# 패링 자원 수급 — HP/MP/ST 기본50 (2026-09-13)

최신 사용자 지시: 패링 기본 회복량을50으로 통일한다. game.html / game-easy-test.html 공통 doParry에 적용하며, 기존 패링 문서의 HP/MP/ST 수급량보다 이 변경이 우선한다. 기동력·분노·악의의 기존2배 수급은 유지한다.

| 자원 | 기본값 (특수탄·장비 배율 전) |
|---|---|
| HP / MP / ST 각각 | Q 100→50, E 60→50. Q/E 구분 없는 기본50 |
| 노란 기동력 | 일반20, 빨콩10, 무지개30 |
| 분노 | 일반20, 빨콩10, 무지개30. Q 유니크 추가 분노도2배 |
| 악의 | 일반2000, 빨콩1000, 무지개4000 |

HP/MP/ST 공식: `floor(50 × (1+parryBonus) × (1+pRegen×0.20) × 탄종계수 × resourceBonus)`. 탄종계수는 빨콩0.5/무지개1.5/그 외1. 기존 HP/MP/ST 최종2배는 제거하며 최종 산출값을 한 번만 정수 절삭한다. `resourceBonus=max(1,입력배율||1)`이며 물리탄3/대형탄10을 유지한다. 기동력·악의는 기존 탄종 기본값 × resourceBonus ×2, 분노는 `(기존 탄종 기본값 × resourceBonus + Q 유니크 추가량) ×2`다. 각 자원은 기존 최대치를 넘지 않는다.

| 패링 종류 | HP/MP/ST 각각 (장비·패시브 미적용) |
|---|---:|
| 일반 Q / 근접 E | 50 |
| 일반 물리탄 E (3배) | 150 |
| 빨콩 물리탄 E (0.5×3배) | 75 |
| 무지개 Q (1.5배) | 75 |
| 일반 속성 대형탄 Q (10배) | 500 |

정신력(해골눈)은 패링당1개, 물리탄 쿨다운 회복은 한 발당30f와 장비 추가 회복의 기존 규칙을 유지한다. 반사 피해·패링 판정·적 공격은 변경하지 않는다. 실습도 실제 doParry를 호출하면 기본50 공식을 사용한다. 전투 실습의 매 틱 MP/ST 보충은 별도 연습 지원이며 패링 회복량이 아니다.

검증: `test/physicalProjectileScaleReward.test.js`는 실제 doParry를 실행하여 Q/E 기본50, 빨콩·무지개·물리3배·대형10배·장비/패시브·정수 절삭·최대치·해골눈·쿨다운·그 밖의 수급을 검사한다. 두 HTML의 doParry 동일성도 확인한다. `test/bigEnergyParrySplit.test.js`, `test/maliceEconomyRegression.test.js`와 함께29개 PASS. 이전 E 반사 루프 문자열 검사는 현재 `_eCanReflectProjectile`의 대형탄 제외 동작을 실행하도록 갱신했다.
