# 보석 품질(q)·소켓석 수치표 (2026-10-08)

> 티어 규약: **1티어=최상, 10티어=최하.** `티어 = 10 − floor((q−1)/10)` — q91~100=1티어 … q1~10=10티어. 같은 티어 안에서는 q 높을수록 좋음. 시스템 규칙: `docs/2_7 인벤토리+장비시스템/2_7 인벤토리+장비시스템.md` §보석 품질·소켓석.

## 1) 보석 품질 배율 (crystalEffects 내부 적용 — 모든 소비처 공통)

`보석 배율 = 0.75 + 0.5 × q/100`

| q | 배율 | 비고 |
|---|---|---|
| 1 | ×0.755 | 최저 |
| 50 | ×1.000 | 구세이브 마이그레이션 기본값 (파워 불변) |
| 91 | ×1.205 | 1티어 하한 |
| 100 | ×1.250 | 최고 |

- 획득 q: 드랍·가루 제작·악의 제작 전부 1~100 균등(`_qRoll`).
- 합성(자동합성·대장간 단일/일괄/일괄강화+합성) 결과 q = 소모 3개 q의 반올림 평균(`_crFuseQ`). 강화(+enh) 재료 소모는 대상 q 불변.

## 2) 홈 보너스 (socketMul)

`b = (q홈 − 1)/99`, **공명**(홈 티어 == 장착 보석 티어) 시 b×2.
`최종 보석 효과 = crystalEffects(cr) × (1 + b × (공명?2:1))`

### 워크드 예시

| 홈 q (티어) | 보석 티어 | 공명 | b | 최종 배수 | 보너스 |
|---|---|---|---|---|---|
| 100 (T1) | T1 | ○ | 1.0000 | ×3.000 | **+200%** (이론 최상) |
| 91 (T1) | T1 | ○ | 0.9091 | ×2.818 | +181.8% |
| 91 (T1) | T2 | × | 0.9091 | ×1.909 | +90.9% |
| 55 (T5) | T5 | ○ | 0.5455 | ×2.091 | +109.1% |
| 1 (T10) | 임의 | ×(q=1은 공명 무효) | 0 | ×1.000 | +0% (자연 홈·마이그레이션 홈) |

- q=1 홈은 b=0이라 공명이어도 보너스 0 — `socketResonant`는 q>1에서만 true(표시용).
- 적용 소비처: applyStats(결정 스탯 합산)·calcCP(결정 파워 ×2×socketMul)·장비 툴팁 2종·보석 탭 상세/홈 title. 전 소비처 동일 값.

### 티어 가중치 — 깊이(챕터) 의존

`w(t) = B^(10−t)`, `B = min(0.78, 0.42 + 0.06×hi)` (hi = `SI_TO_HELL[G.stage]` 0~6). 티어 확정 후 해당 10분위에서 q 균등 (`q = (10−t)×10 + 1~10`).

| 티어 | 1장(hi=0, B=0.42) | 7장(hi=6, B=0.78) |
|---|---|---|
| T10 | 58.01% | 24.00% |
| T9 | 24.36% | 18.72% |
| T8 | 10.23% | 14.60% |
| T7 | 4.30% | 11.39% |
| T6 | 1.81% | 8.88% |
| T5 | 0.76% | 6.93% |
| T4 | 0.32% | 5.40% |
| T3 | 0.13% | 4.22% |
| T2 | 0.056% | 3.29% |
| T1 | 0.024% | 2.56% |

데모 1-1(1장)은 T10~T7이 96.9% — 설계 의도(초반 거의 하위 티어, T1 극희귀) 충족.

|---|---|
| 최대 홈 수 | 5 (전 부위, 유골함 포함) |
