# 1-1 돌진 몬스터 제외

| 항목 | 계약 |
|---|---|
| 대상 | game.html, game-easy-test.html의 si=0 비보스 |
| 제외 etype | 2 돌진 사도, 22 서리 늑대, 30 사냥개 사도, 43 악마견 |
| 자연 출현 | 1장 풀에서 2/22 제외. 원거리50%/근거리50% 선택 후 남은 각 그룹 가중치로 추첨 |
| 예외 경로 | 소환·이전 세이브가 제외 etype을 mkEn으로 요청하면 기본 하급사도(0)로 생성 |
| 다른 스테이지·보스 | 기존 출현/전투 유지 |
| 총량 | 소환굴 S25/M50/L50 유지. 종류 교체가 처치율 분모를 추가로 줄이지 않음 |
| 적용 | 1-1 새 진입 및 이후 신규 생성. 이미 생성된 몬스터의 상태는 중간 변경하지 않음 |
