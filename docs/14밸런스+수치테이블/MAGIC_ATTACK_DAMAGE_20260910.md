# 마법 공격 2배 (2026-09-10)

최신 사용자 지시: 마법은 우선2배. 직전 평타·기검참·기본 석궁3배 조정은 유지한다.

| 항목 | 현재 코드 계약 | 적용 위치 |
|---|---|---|
| 공통 마법 배율 | `pMagicMul(forAttack=true)=_passDmgSum('magic')×(1+(_uEq('_uHelmMagic') 또는0))×(forAttack?2:1)` | game.html 공통 함수 |
| 미투자 기본 | 기존0.7→1.4 | 전체0.7 조정·합연산 자체는 그대로 |
| 마력폭주5·유니크50% 예 | 기존1.575→3.15 | 다른 가산0 기준 |
| 직격·폭발 | 기존 마법 기반 피해2배 | 악의구, 원소추적탄, 업화선, 버스트루프, 폭독칼날, 얼음보주, 푸른비 |
| 빔·지속 | 강화된 마법 기반 피해 사용 | 얼음송곳, 멸살광선, 참회, 지옥진, 악의폭풍, 악의기둥, 뇌전창, 가시덫 |
| 이동·소환·특수 | 강화된 마법 기반 피해 사용 | 사슬화염, 기동불꽃, 전격이동, 뇌전걸음, 폭풍소환, 천공쇄기, 전대, 허수아비, 탄막블랙홀 |
| 평화의보호 해제 | `floor(magicRef×statInt×(Lv×.15+.85)×(보호막반경/200+.5))×2` | 공통 패시브를 쓰지 않는 독립 _psBoomDmg만2배 |
| Q패링 장비스케일 | `magicRef×statInt×pMagicMul(false)` | 공격 상향을 제외한 기존 값; E패링도 그대로 |
| UI | 기존 마법 공격력 및 마법 스킬 추정치가 공통 함수를 호출 | 새 배율 자동 반영 |

스킬별 `_SK_MUL`의 b/g, 투사체 수, 차징 배율, 후속 폭발 비율, DOT 틱 수·비율은 유지한다. 강화된 원피해를 후속 피해가 상속하므로 타격 처리에서2배를 다시 곱하지 않는다. MP 소비·시전속도·쿨다운·회복량·보호막량은 변경하지 않는다.

정수화 전 마법 기반 부분을2배로 올리므로 반올림 오차가 있을 수 있다. MP소비 보너스, 흡수한 적 탄막 피해, 적HP% 피해처럼 별도로 더하거나 비교하는 항목은 기존 값이다. 따라서 이런 혼합 공식의 최종 표시 피해가 항상 정확히2배라는 뜻은 아니다. 이미 생성된 피해 스냅샷은 기존 값을 유지하고 다음 시전부터 새 배율을 사용한다.

`test/magicAttackDamage.test.js`는 미투자/투자·유니크 배율, MP·시전속도 보존, 실제 악의구 산출식840→1680, 가시덫490→980, 기검참 배율 유지, Q/E반사616/501 보존을 검사한다. 기존 기본공격·빔·악의구·반사 회귀검사도 실행한다. 적용 대상은 현재 소스이며 실행파일 재패키징은 포함하지 않는다.
