# 빈 바닥 패링 — 지속 피해 오판정 수정 (2026-09-14)

적·투사체·덫이 없어도 몸에 남은 중독 또는 화상 틱을 Q 패링으로 처리하는 경로를 재현했다. `hurtP`의 눌림/해제 패링 조건에 지속 피해 제외가 빠져 있었다. 사용자가 본 모든 사례가 이 원인이라고 단정하지 않으며, 지뢰·덫 가시성 문제와 구분한다.

| 항목 | 현재 계약 |
|---|---|
| 적용 파일 | `game.html`, `game-easy-test.html`의 `hurtP` |
| 적용 경로 | 해제 패링, 평화의보호 눌림, 기본 Q 눌림의 3개 조건 |
| 조건 | 기존 패링 조건에 `!_isDotEarly` 추가. `_isDotEarly=opts&&opts.dot` |
| 지속 피해 | `opts.dot=true`이면 패링 성공·자원 회복·성공 효과를 발생시키지 않음 |
| 패링 시간 | 지속 피해는 `_sbParryT`를 소모하지 않음. 후속 직접 공격을 받을 시간 유지 |
| 피해·방어 | 기존 지속 피해 및 보호막의 DOT 흡수율 절반 계산 유지. 패링 실패 포이즈 패널티 없음 |
| 직접 공격 | 기존 Q 패링 유지. 지뢰·덫의 `magic` 분류/Q 처리 유지 |
| 적용 사례 | 중독, 화상, 누적 독·화상, 독안개 등 `dot:true`를 전달하는 피해 |
| 검증 | 신규 실제 `hurtP` 실행 테스트 12개: 양쪽 HTML × 해제/기본 Q/평화의보호 × 지속/직접 피해. 중독·화상 모두 검증. 수정 전 지속 피해 6개 실패 → 수정 후 전체 통과 |
| 회귀 검사 | 지속 피해·피격음·Q 홀드/해제·투사체 분류·덫 가시성 합계 38개 통과 |

수정 금지된 `2_3 돌진+패링+방패시스템` 문서는 보존하고, 이 버그 수정의 현재 조건은 본 문서에 기록한다.
