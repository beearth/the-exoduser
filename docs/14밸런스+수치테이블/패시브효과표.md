## 정확한 계산·조건

레벨업 연출은 `pDemon>pHuman`이면 보라빛, 동률·미투자·인간성 우세는 금빛이며 머리 위 레벨 숫자도 같은 계열이다. 이는 시각 분기이며 아래 실제 부활 확률·스탯 공식과 독립이다. [연출 계약](../5.1임펙트디자인/LEVEL_UP_GOLD_20260910.md).

| 항목 | 공식 / 적용 위치 |
|---|---|
| 공통 피해 | `_passDmgSum(type)=(1+s)*0.7`. s에는 맹공0.10×Lv, 인간성0.05×Lv, 제단 보너스. melee는 광전사0.15×Lv, magic은 마력폭주0.10×Lv+장비/내재, bow/proj는 정밀사격0.15×Lv, xbow는 쇠뇌력0.05×Lv, dot는 침식0.15×Lv. 풍요는 이 함수에 없음 |
| 풍요 | `hurtE`에서 적HP≥70% 추가피해0.20×Lv. `pAbundRegen=0.05×Lv`는 항상 적용 |
| 약자포식 | 적HP≤30% 피해0.20×Lv. 자신HP≤30%일 때 재생0.10×Lv/이속0.05×Lv |
| 카운터 | `pParryDmg=1+0.5×Lv`. E공속 `1+0.1×Lv`, 무지개탄DR `min(0.5,0.1×Lv)`. Q 무지개탄 패링 계약 유지 |
| ST 비용 | 맹공 `max(0.6,1−0.04×Lv)` × 광전사 `max(0.5,1−0.05×Lv)` = 둘다Lv10이면0.30. 석궁은 정밀사격 `max(0.6,1−0.04×Lv)` |
| MP 비용 | `max(0.4,1−0.04×pMagic−mpCostRed−유니크)`. 패시브만Lv10이면0.60이며 장비 포함 최저0.40 |
| 시전속도 | `(2+0.08×pMagic)×(1+castSpeed+headbandCastSpd)`; 기본×2, 패시브만Lv10 ×2.8 |
| 보호막 | `min(0.50,0.30+0.02×pGuard)`, DOT 흡수율 절반. 잔존 `pGuardRegen()` 정의는 추가 성장 효과로 제시하지 않음 |
| 급소 | `statCrit`에1.5%p×Lv, `statCritDmg`에0.08×Lv. 기본 치명타 배율1.5 |
| 회복력 | HP/ST 재생 `1+0.03×Lv`, 물약쿨 감소 `min(0.30,0.03×Lv)`, `doParry` 회복배율 `1+0.20×Lv` |
| 마력회복 | MP/쉴드 재생 `1+0.03×Lv`, 쉴드 쿨 배율 `1−min(0.30,0.03×Lv)` |
| 관통 | 기본 확률 `min(0.95,0.05×Lv)` 및 추가 횟수Lv. 피해유지 `min(1,0.85+0.03×Lv)`. 일부 스킬은 별도 관통값 사용, 장비와 합산 |
| 추적자 | 기본상한5×Lv, 어픽스 추가상한 별도. 중첩당 피해3%. 직접 명중+1, 빔4틱마다1, DOT/장판 제외. 초당20% 감소,5초 미명중 초기화 |
| 그릇 | pVital MP+50×Lv/MP재생×(1+0.01×Lv). pStamina ST+50×Lv/ST재생×(1+0.01×Lv) |
| ST 수정 | `recalcSt` 최종식에 `50×pStamina`를 포함. `applyStats`의 덮어써지던 중간 최대ST 가산을 제거하고 재생배율만 적용. 반복 재계산해도 중복 가산/누락 없음 |
| 자원/방어 | 강인 HP+300×Lv, 철벽 물리DEF+20×Lv. 광전사3%×Lv는 기본HP 묶음의 배율이며 모든 후가산 HP에 곱하지 않음 |
| 인간성 | 공통피해5%×Lv, HP/MP/ST각100×Lv. 부활 확률에서10%p×Lv 차감 |
| 악마성 | 부활확률에2%p×Lv 가산. 기본 쿨 프레임 `max(6000,36000−1800×Lv)` 후장비배율(60fps), 기본600초/최저100초. 부활 성공은 HP/MP/ST 전부 회복. 구 HP+5%/Lv 설명 폐기 |
| 분노폭주 | 최대분노 `(100+무기/어픽스고정)×(1+0.10×Lv)`, 분노 피해 계수에 `(1+0.10×Lv)` |
| 사냥꾼 | 보스/정예/etype≥90이면 최종배율 `1+0.10×Lv` |
| 드롭 | pDrop은 드롭배율에0.08×Lv 가산. pMalice 악의획득배율 `1+0.08×Lv` |
| AP | 단계비용 `[1,1,1,2,2,2,3,3,3,5]`, Lv10 총23AP, 초과레벨 폴백5AP. 환불은 실제 단계비용 반환 |
| 삭제 패시브 | pShield/pPhysPen/pMagPen은 신규투자 불가. 기존 세이브의 삭제 패시브 값은 증가 불가·보존/전체환불 가능 |
