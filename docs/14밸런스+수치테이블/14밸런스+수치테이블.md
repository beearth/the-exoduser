## 크리티컬 공식
- 크리 발동 시 데미지 = 일반뎀 × `statCritDmg()`
- `statCritDmg() = 1.5 + LCK×0.002 + pCrit×0.08 + 어픽스 + 결정` — **기본 +50%** (1.5배)
- LCK 1000 = 1.5 + 2.0 = **3.5** (크리뎀 +200%)
- 크리뎀 어픽스: `critDmgW` 무기/왕관 또는 반지/목걸이/팔찌 +10~50% (T1~T5 .10/.20/.30/.40/.50), `neckCritDmg` 목걸이 +6~34%, `glovesCritDmg` 장갑 +6~34% (`critDmgA`/`critDmgB`는 합산식에만 있고 AFFIX_POOL 정의 없음)
- 크리 확률(%): `_eqLckTotal() × 0.025 + pCrit×1.5 + 반지1/반지2/목걸이 베이스 critRate(반지 5, 목걸이 10) + critRate 어픽스×100 + 결정`
  - `_eqLckTotal() = STATS.lck + _lvB() + _eqStat('Lck') + lckFlatN + lckFlatR`

## 데미지 공식

### 벽 충돌 데미지
- 공식: `max(넉백속도×4, 적 최대HP × min(8%, 넉백속도×0.4%))`
- 고정뎀 vs %뎀 중 큰 쪽 적용 → 만렙에도 유효
- 넉백속도 2 이하: 데미지 없음 (임계값)
- 예시: 넉백속도 10 → max(40, mhp×4%) / 넉백속도 20 → max(80, mhp×8%캡)

## 강화 시스템
- 스킬 강화의 현행 악의구슬 검사·실차감(두 게임 HTML): `cost=_malCost(sk.upMat||0)`. `upMat=0`이면 악의구슬 비용 0이며 수동 `canUp`와 일괄 `_matGate`도 0으로 검사한다. 장비 강화 비용은 아래 식과 별개다.
- `enhMul()`, `enhCost()` — 상한 없음 (1000+ 가능)
- 강화 비용(현행 `game.html`/`game-easy-test.html`): `enhCostRaw(n)=max(20000,ceil((20000+n×3500)×1.5))`, 실제 악의구슬 `cost=_malCost(ceil(enhCostRaw(n)×등급배율))`, `_malCost(v)=max(1,ceil(v×0.5))`(양수일 때). 기존 `ceil((1+n×0.15)×1.5)` 표기는 현행 강화 비용식이 아니다.
- 등급배율: 일반 0.5, 마법 0.7, 희귀 1.0, 영웅 1.3, 전설 1.8
- 강화 확률: max(0.5, 99 × 0.99^n) % — 최소 0.5% 하한 보장 (2026-04-22, 기존 공식 유지 + 하한 추가)

| 강화 전 단계 n | 희귀(등급배율 1.0) `enhCostRaw(n)` | 실제 악의구슬 비용 | 성공 확률 |
|---:|---:|---:|---:|
| 0 | 30,000 | 15,000 | 99% |
| 100 | 555,000 | 277,500 | `max(0.5,99×0.99^100)`% |
| 1000 | 5,280,000 | 2,640,000 | 0.5% 하한 |
- **강화 성공률 표시 정밀도** (2026-04-17): `game.html` 강화 패널 `ratePct`(~L50864) 표시 반올림 수정. ≥10% 정수 / 1~10% 소수점1자리 / 0.01~1% 소수점2자리 / <0.01% 소수점3자리. 이전 `~~(rate*100)` 내림 방식은 <1% 구간에서 전부 "0%"로 표시돼 +500 이상 강화 시 "왜 0%냐" 혼란 유발 (+500=0.65% / +831=0.023% 등). 확률 공식은 유지, 표시만 정밀화.
- **강화 공식 (ATK)** `enhMulAtk(n)`: 1강당 **+0.25** (선형, 2026-05-03 2차반감)
- **강화 공식 (DEF)** `enhMul(n)`: 1강당 **+0.25** (선형, 2026-04-12 하향)
- **무기류** (weapon, bow, helmet): ATK + enhMulAtk(enh) = ATK + 강화×0.25

### SP/AP 저장·복원
- 로드 시 저장된 `P.sp`, `P.ap` 값을 **그대로 복원** (재계산 없음)
- SP 변동은 레벨업·스킬습득·합체·스탯투자·보스클리어 등 이벤트마다 실시간 반영 + 자동저장
- 기본 스킬 (kiSlash, fireball): **완전 무료 보너스** — 습득비·강화비 0, 해제해도 SP 환불 없음
