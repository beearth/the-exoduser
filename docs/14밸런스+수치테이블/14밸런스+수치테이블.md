## 크리티컬 공식
- 크리 발동 시 데미지 = 일반뎀 × `statCritDmg()`
- `statCritDmg() = 1.5 + LCK×0.002 + pCrit×0.08 + 어픽스 + 결정` — **기본 +50%** (1.5배)
- LCK 1000 = 1.5 + 2.0 = **3.5** (크리뎀 +200%)
- 크리뎀 어픽스: 반지 +5~25%, 목걸이 +10~50%
- 크리 확률: _eqLckTotal() 기반 총행운을 사용하며, 현행 전체 식은 아래 source57 행운 합산 표를 따른다.

## 데미지 공식
- `hurtE(e, dmg, ang)` — 적에게 데미지
- `hurtP(dmg)` — 플레이어 피격
- DR 공식: `DEF / (DEF + 2500)`, 캡 75% (`DR_CAP=0.75`)
  - 물리: `pDR = min(0.75, pDef/(pDef+2500) + physDR어픽스)`
  - 속성: `eDR = min(0.75, eDef/(eDef+2500))` — **전 속성 공통** (화염/냉기/암흑/번개/신성)
  - DEF 2500 → 50%, DEF 7500 → 75%(캡)
- **방어구 베이스 DEF/eDef 대폭 하향** (2026-04-10): 방어도 올리기 극악 난이도. 풀 T4레전더리 장비 DEF ≈ 50, eDef ≈ 20 → 강화/어픽스로 올려야 함
- **eDef 어픽스**: `eDefFlat` SUFFIX 3티어 [50/100/150], weight 40 (희귀), 슬롯 armor/helm/neck/shield/cloak/bracelet/headband/ring
- **eDef 장착 슬롯**: helmet, necklace, ring1/2, cape, shield, armor, boots, gloves, pants, belt, bracelet, headband, headband2 (어픽스 롤링 슬롯 전부 합산)
- **한방 데미지 캡**: HP의 33% (`_hitCap=~~(P.mhp*.33)`), 발동 시 60f(1초) 무적
- **최소 데미지 1 보장** — DR 중첩 시 `~~()` 절삭으로 0뎀 방지. STR 배율 적용 후 `if(dmg<1)dmg=1`
- **엘리트 등급 적용** — 일반 필드몹만 장별 `ELITE_PROB`로 매직/레어/챔피언을 판정한다. 보스와 레어 etype(90~99)는 제외. 등급 배율·외형·공격 접사는 [적 AI 등급표](../9적ai패턴디자인/9_적AI패턴디자인.md) 기준. M29~M32 돌진/진원 충격파/번개 연사/지옥 포격 추가 (2026-09-23). 공격 예고가 겹치지 않도록 적별 잠금 M19/M30 54f, M29 78f, M31 45f, M32 126f 적용.

### 벽 충돌 데미지
- 공식: `max(넉백속도×4, 적 최대HP × min(8%, 넉백속도×0.4%))`
- 고정뎀 vs %뎀 중 큰 쪽 적용 → 만렙에도 유효
- 넉백속도 2 이하: 데미지 없음 (임계값)
- 예시: 넉백속도 10 → max(40, mhp×4%) / 넉백속도 20 → max(80, mhp×8%캡)

## 강화 시스템
- 스킬 강화의 현행 악의 검사·실차감(두 게임 HTML): `cost=_malCost(sk.upMat||0)`. `upMat=0`이면 악의 비용 0이며 수동 `canUp`와 일괄 `_matGate`도 0으로 검사한다. 장비 강화 비용은 아래 식과 별개다.
- `enhMul()`, `enhCost()` — 상한 없음 (1000+ 가능)
- 강화 비용(현행 `game.html`/`game-easy-test.html`): `enhCostRaw(n)=max(20000,ceil((20000+n×3500)×1.5))`, 실제 악의 `cost=_malCost(ceil(enhCostRaw(n)×등급배율))`, `_malCost(v)=max(1,ceil(v×0.5))`(양수일 때). 기존 `ceil((1+n×0.15)×1.5)` 표기는 현행 강화 비용식이 아니다.
- 등급배율: 일반 0.5, 마법 0.7, 희귀 1.0, 영웅 1.3, 전설 1.8
- 강화 확률: max(0.5, 99 × 0.99^n) % — 최소 0.5% 하한 보장 (2026-04-22, 기존 공식 유지 + 하한 추가)

| 강화 전 단계 n | 희귀(등급배율 1.0) `enhCostRaw(n)` | 실제 악의 비용 | 성공 확률 |
|---:|---:|---:|---:|
| 0 | 30,000 | 15,000 | 99% |
| 100 | 555,000 | 277,500 | `max(0.5,99×0.99^100)`% |
| 1000 | 5,280,000 | 2,640,000 | 0.5% 하한 |
- **강화 성공률 표시 정밀도** (2026-04-17): `game.html:34443` 표시 반올림 수정. ≥10% 정수 / 1~10% 소수점1자리 / 0.01~1% 소수점2자리 / <0.01% 소수점3자리. 이전 `~~(rate*100)` 내림 방식은 <1% 구간에서 전부 "0%"로 표시돼 +500 이상 강화 시 "왜 0%냐" 혼란 유발 (+500=0.65% / +831=0.023% 등). 확률 공식은 유지, 표시만 정밀화.
- **강화 공식 (ATK)** `enhMulAtk(n)`: 1강당 **+0.25** (선형, 2026-05-03 2차반감)
- **강화 공식 (DEF)** `enhMul(n)`: 1강당 **+0.25** (선형, 2026-04-12 하향)
- **무기류** (weapon, bow, helmet): ATK + enhMulAtk(enh) = ATK + 강화×0.25
- **아이템 ATK 맥스**: `(200 + tier×200 + P.lv) × 0.25` (2026-05-03 2차반감, T4 Lv600 = 400)
- **DEF 강화 소비**: `hurtP`의 물리·속성 방어는 shield/armor/cape 3슬롯의 `~~(enhMul(sh().enh||0)+enhMul(ar().enh||0)+enhMul(cp().enh||0))`를 각각 합산한다. 강화계수는 ×0.25이며 장갑/바지/부츠 강화는 HP 세트다. 기존 능력치 패널의 9슬롯 강화DEF 표시는 별도 불일치로 미해결이다.
- **HP 강화**: `_hpEnhSet={gloves,pants,boots}`, 각 강화레벨×1.0을 합산한 뒤 `applyStats`의 기존 최대HP 식을 적용한다.

- 기본 스킬 (kiSlash, fireball): **완전 무료 보너스** — 습득비·강화비 0, 해제해도 SP 환불 없음

### 💪 근성 (보조스텟) — SP 소모, 무한 레벨
| 항목 | 값 |
|---|---|
| 변수 | `_grit` (세이브: `grit`) |
| 효과 | HP/MP/ST 최대치 각각 **+1/lv**, 물리·속성 방어 **+0.5/lv** (합산 방어 증가분은 정수 절삭) |
| SP 비용 | `1 SP = 근성 1`; 투자·환불 조작은 1포인트씩 |
| 최대 레벨 | 없음 (무한) |
| UI 위치 | J 능력치·패시브 패널의 근성(GRIT) 인장 선택 후 상세에서 1포인트씩 투자·환불. ×1/×10 선택 버튼 없음 |
| 공식 | `_gritTotal() = (+_grit \|\| 0) + _lvB() + _eqStat('Grit') + _eqAffix('gritFlatN') + _eqAffix('gritFlatR')`. HP/MP/ST에 각각 이 값 추가, DEF/eDEF에 각각 `~~(_gritTotal()*.5)` 추가 |
