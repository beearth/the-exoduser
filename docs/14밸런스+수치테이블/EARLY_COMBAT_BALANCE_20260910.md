# 초반 처치 타수 조사와 공통 체력 조정 — 2026-09-10

사용자: 초반 약10레벨에서 악의구·기검참이 약하고, 몬스터 HP 대비 몇 번 맞혀야 죽는지 조사하고 전체 밸런스를 맞출 것.

## 측정 조건과 원인

- 일반 난이도(표시±0, `OPT.diff=5`, dm1), stage0, 플레이어=몬스터 레벨. 현재 사용자 세이브를 특정한 측정이 아니라 재현 가능한 초반 비교군이다.
- `defaultItems()` T0 일반 장비 seed910. 녹슨 검 atk17 / 낡은 머리띠 atk23 / 낡은 석궁 atk32, 기본 내재옵션 포함. 강화·스탯 투자·패시브 투자 없음. `applyStats()`와 실제 ref/hurtE를 사용한다.
- 스킬1 비교와 `min(20,floor(플레이어Lv/5)+1)` 투자 예시는 별도 조건이다. 캐릭터 레벨이 스킬 레벨을 자동으로 올린다는 뜻이 아니다.
- 타수는 명중한 공격의 직접 피해 기준. 치명타·독 지속피해·회피·공격 간격·쉴드 재생·넉백 충돌·자동 동시 공격 제외. 실제 전투 시간(TTK)이 아니다. 검기는 무한관통하므로 이 타수로 여러 적을 함께 처리할 수 있다.
- 악의구는 일반몹 직격100%+폭발60%를 합산했다. 빗맞은 폭발만 맞으면 피해가 작고, 10초 중독은 즉시 피해가 아니다. 같은 속성에는 elMul0.5, 상성에는2가 적용된다. 검기는 EL.P이고 elMul 별도 곱 없음.
- 종전 Lv1 일반몹 HP875+쉴드875가 Lv10 HP7283+쉴드7283으로8.32배 증가하는 동안 이 장비의 검기는1881→2175(1.16배), 악의구 직격+폭발은1128→1276(1.13배)였다. 개별 스킬을 올려도 빠른 레벨 스케일링으로 타수가 다시 늘어나는 구조였다.
- 추가 결함: `bowRecover` 중 LMB 캔슬은 검기 계수가1.2/1.2/2이고 idle은7/7/7이었다. 같은 콤보가 입력 직전 상태에 따라17.14%/17.14%/28.57% 피해만 냈다.
