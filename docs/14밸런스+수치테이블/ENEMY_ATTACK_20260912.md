# 적 기본 공격력 20% 상향 — 2026-09-12

사용자 요청을 적이 주는 피해 상향으로 적용했다. `game.html`과 `game-easy-test.html` 모두 반영.

| 생성 경로 | 변경 전 | 변경 후 |
|---|---|---|
| mkEn 일반·정예·레어·보스 | 선형 기초식×0.5 | 선형 기초식×0.6, 이후 난이도·정예 배율과 floor |
| _fbMk 필드보스 | trunc(20+P.lv×3) | trunc((20+P.lv×3)×1.2) |
| _wmMkAt 지상뱀장어 | trunc(16+P.lv×2.5) | trunc((16+P.lv×2.5)×1.2) |
| _fdMk 화마귀 | trunc(18+P.lv×2.8) | trunc((18+P.lv×2.8)×1.2) |

보스 피날레 기준값 `_druidBaseAtk`도 mkEn 공격력을 받아 페이즈별 기존 배율을 유지한다. HP·공격 주기·이동 속도·플레이어 공격력·별도 튜토리얼 연습 피해는 변경하지 않았다. 이미 생성된 적은 실시간 수정하지 않으며 새 스폰부터 적용한다. 쉬운 테스트판의 기존 최종피해0.5배는 유지한다.

공격력 기반 근접·탄막·소환체 피해에 반영된다. HP비례 고정 피해·환경 함정·플레이어 HP 비용은 공통20% 배율을 추가하지 않는다. 최종 HP 감소량은 정수 절삭과 방어/흡수 때문에 약20%와 다를 수 있다.

검증: `node --test test/enemyAttackTuning.test.js test/earlyCombatBalance.test.js test/druidFinalePacing.test.js` 17개 통과. 두 진입점의 레벨1~1000, 난이도·정예 조합, 보스 기준값, 별도 필드 적 공격력 및 기존 HP/피날레 진행을 확인했다. 기존 피날레 테스트의 window 대역 누락은 해당 테스트에 빈 window를 제공해 보완했다. 실플레이 체감 검증·배포는 수행하지 않았다.
