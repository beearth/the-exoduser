## 기록 원칙

| 구분 | 기록 내용 |
|---|---|
| 현행 구현 | 실제 코드에 적용된 값·공식·적용 대상. 계획값을 현행 수치에 섞지 않는다 |
| 측정 결과 | 캐릭터/몬스터 레벨, 지역, 난이도, 장비·강화·내재/어픽스, 스탯·패시브·스킬 레벨, 속성, 표본·증거 경로 |
| 조정 목표 | 목표 타수·시간·자원 효율과 근거. 미측정 목표는 잠정이라고 표시 |
| 변경 이력 | 변경 전→후, 변경 이유, 영향받는 시스템, 검증 결과, 사용자 체감 |
| 판정 | 미측정 / 계산 확인 / 런타임 확인 / 실전 확인 / 재조정. 테스트 통과를 실전 밸런스 확정으로 쓰지 않는다 |

한 차수에서 원인을 특정하고 주된 변수 하나를 조정한다. 연동된 HP·쉴드·포이즈처럼 함께 변하는 항목은 한 묶음으로 기록한다. 입력 상태에 따른 피해 누락 같은 버그는 밸런스 수치와 별도 항목으로 관리한다. 비교군이 달라지면 이전 결과와 같은 행에서 전후 개선으로 표시하지 않는다.

초반 일반몹의 잠정 기준은 **Lv10/일반 난이도/기본 장비/스킬1/무속성 대상에서 검기2~3타 또는 악의구 직격+폭발3~4발**이다. Lv1이나 투자 빌드까지 이 타수로 강제하지 않는다. 정예·보스의 적정 타수/시간은 다음 실전 측정 후 설정한다. 현재 정예4/6/9검기와 일반 보스41검기는 계산 결과이며 목표값이 아니다.

## 타수와 함께 기록할 지표

| 지표 | 측정 방법 / 주의점 |
|---|---|
| 직접 처치 타수 | HP와 쉴드를 모두 포함. 검기 단독, 근접 칼날+검기, 마법 직격+폭발, 폭발만 적중을 구분 |
| 실제 처치 시간 | 첫 공격 입력부터 최종 사망까지. 명중률·추적·선후딜·회피·페이즈 무적·부활 포함 여부 명시 |
| 자원 효율 | 적1마리와 동일한 적 무리 각각의 MP/ST/기동게이지 순소비, 고갈까지 처치 수, 리젠/패링 회수/물약 사용량 |
| 범위·지속 피해 | 동일 적 배치로 총 피해/처치 수. 단일 대상과 관통·폭발 다수 적중을 별도 비교. 독10초 총량을 즉시 피해로 합산하지 않음 |
| 생존 | 플레이어 HP+쉴드, 동일 공격 피격 횟수, 연속 피격·회피 실패·물약 사용. 적 공격 주기와 실제 입력 조건 명시 |
| 방어·상성 | 무속성, 같은 속성, 상성, 방패 정면/후면, 정예 방어모드 각각 비교 |
| 보조 화력 | 자동 석궁 단독 및 주력과 동시 사용 비교. 단독 발수를 전체 전투 시간으로 환산하지 않음 |
| 보스 | 일반 보스, 독립 필드보스, 데모 피날레를 따로 측정. HP식·피격 경로·쉴드·반사·부활 차이 기록 |

같은 조건을 반복해 범위와 중앙값을 기록하고, 장비 난수가 개입하면 seed 또는 실제 장비 목록을 보관한다. 반복 횟수와 표본 수를 결과에 함께 남긴다. 사용자가 느낀 지루함·타격감·자원 답답함은 숫자와 별도로 기록한다.
