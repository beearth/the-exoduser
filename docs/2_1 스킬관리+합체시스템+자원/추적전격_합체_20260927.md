# 추적전격 (`bladeEcho`) — 추적칼날 + 전격이동

2026-09-27 사용자 요청. `maliceHunt`가 발사하는 유도 칼날의 실제 궤적을 플레이어가 전격으로 따라가며 같은 경로에 추가 피해를 준다. 합체 등록은 `game.html`의 `_FUSE_PAIRS.bladeEcho`, `_FUSE_GEM_GROUPS.bladeEcho`가 담당한다.

| 항목 / id | 현재 구현값 | 적용 위치 |
|---|---|---|
| 합체 | `bladeEcho`, 2성, `maliceHunt` + `bladeDash`, 최소 레벨 1 | 합체 쌍·보석 그룹. 기존 `bladeFuse` 및 `thunderGhost`와 별도 합체 |
| 데모 접근 | `_DEMO_MODE=true`인 현재 빌드에서도 합체 가능 | `_DEMO_FUSE_ALLOWED`에 `bladeEcho` 포함 |
| 호스트/조작 | `maliceHunt`가 장착된 스킬 슬롯 키를 재입력 | 스킬 발동 `case 'maliceHunt'`. 일반 15초(최소 10초) 쿨다운보다 연계 입력을 우선 판정 |
| 선행 | 두 스킬 습득 및 `bladeEcho` 합체 완료 | `P.skills.bladeDash>=1`, `_isFused('bladeEcho')` |
| 발동 창 | 해당 발사의 첫 유도 칼날 종료부터 30프레임(60fps 기준 0.5초) | `P._bladeEchoReady.until=_gameFrame+30` |
| 경로 | 유도 칼날의 실제 x/y를 최소 18px 간격으로 기록, 발사점 포함, 최대 512점 | `_bladeEchoRecord`, 벽 반사·유도 굴절도 기록. 합체 전 칼날 및 독사탄에는 기록하지 않음 |
| 다발 칼날 | 먼저 끝난 칼날 1개의 궤적을 연계 대상으로 사용 | 동일 발사 식별자 `P._bladeEchoCast`; 연계 1회만 허용 |
| 이동 | 기록된 첫 지점으로 전격 이동 후 프레임당 약 4점씩 경로 재생. 각 지점 `canMv` 검사 | `_bladeEchoTryStart`, `_tickBladeEcho`. 벽 막힘 시 중단 |
| 추가 피해 | 경로에 닿은 적마다 칼날 1발의 `p.dmg`를 딱 1회 추가, 번개 원소 `EL.L`, 에너지쉴드 타격 | `_tickBladeEcho`, `run.hit` 집합. 기본 칼날 피해 및 합체 배율은 발사 시 이미 `p.dmg`에 반영 |
| 무적 | 연계 시작 15프레임, 이동 중 최소 4프레임 갱신, 종료 시 15프레임 | `P.iframes` |
| 추가 자원 | 없음 | 최초 악의사냥의 악의 30 + ST 50 및 쿨다운 유지. 일반 전격이동의 MP·공용 기동게이지를 연계에 중복 부과하지 않음 |
| 숙련도 | 재입력으로 `maliceHunt` 숙련도를 중복 지급하지 않음 | 최초 발사 시 기존 숙련도 처리 유지 |
| 피드백 | 종료 시 재입력 안내, 청백 전기 잔상·시작/경로/명중/착지 임팩트 및 사운드 | 기존 전기 버스트·사슬 이동 SFX 재사용, 신규 이미지 없음 |
| 저장 | 합체 여부 `P._fused.bladeEcho`는 기존 합체 저장 구조 사용 | 진행 중 경로·연계 창은 전투 임시 상태로 저장하지 않음 |

경직·기절·사망에서는 연계를 시작하지 않는다. 합체가 없는 `maliceHunt`와 방향키 더블탭 `bladeDash`의 원래 조작은 그대로다. 기존 `bladeFuse`와 함께 구성되면 악의 해방의 여러 칼날 중 처음 끝난 1발의 궤적을 사용한다. 추적전격의 추가 피해는 적별 1회로 제한하며 공격 티켓 제한을 만들지 않는다.
