## 0. 목표 & 범위

**목표**: char_create.html 프로토타입에만 존재하는(현재 `comingSoon:true` 잠금) 신규 3캐릭터를 **실제 플레이 가능**하게 만든다. 각 캐릭터는 고유 3스킬(LMB/RMB/SPACE) 킷을 가진다.

**현 상태**: 스펙만 존재(char_create.html), 게임 미구현. 스프라이트 아틀라스 없음(초상/영상/엠블럼만).

## 2. 아키텍처: 스킬이 게임에 배선되는 법 (구현 체크리스트)

한 스킬을 완성하려면 아래 지점을 모두 배선한다(기존 스킬 1개를 템플릿으로 복제 권장):

1. **스킬 데이터/분류**: cat(데미지 공식 소속) + type(전달) 결정 → `docs §전체 스킬 분류표` 등록.
2. **자원·비용**: `mpCost()`/ST/HP 소모. 신규 자원(HP탄약·영혼스택)은 P에 상태변수 추가 + HUD 표기.
3. **슬롯·키 배선**: 신규 캐릭 킷은 LMB/RMB/SPACE 3키. 기존 슬롯 시스템(`P.activeLMBSk`/`activeRMBSk`/`SKILL_SLOTS`) 위에 **per-캐릭터 킷 매핑** 필요 — §3-A 설계 결정 참조.
4. **발동 로직**: `useSkill` 스위치(`case '<id>'`) 또는 전용 핸들러. 쿨다운 타이머(`P._<id>Cd`), 상태 플래그(`P._<id>Active`).
5. **데미지 적용**: cat 공식으로 `hurtE()` 호출. `_skMul`(스킬 배율)·`_fuseMul` 적용.
6. **틱/상태 처리**: `update()` 루프에 상태 진행(투사체 이동·채널·설치물·블링크).
7. **렌더/VFX**: `draw()`/`drawP()`에 스킬 VFX. 조준 인디케이터(설치·투척).
8. **번역**: 이름/설명 KO+EN → `_EN` + 26개 lang_*.js (CLAUDE.md §번역 규칙, `번역대상_전체목록.md` 넘버링).
9. **밸런스 표**: `docs/14밸런스+수치테이블/스킬별_DPS_자원소비표.md` 등록.
10. **세이브/마이그레이션**: `P.skills.<id>` 직렬화, 로드 폴백.

## 3. 팀장 설계 결정 (확정 전 검토)

### 3-A. 신규 캐릭은 "간소 3스킬 킷" — 워리어 슬롯 트리와 분리
현 슬롯 시스템은 워리어 아키타입(기검참 LMB·사슬기동 Shift·마법 RMB·CT·선택슬롯·합체) 전제. 신규 캐릭은 char_create대로 **LMB/RMB/SPACE 3고정 킷**이 자연스럽다.
- **결정**: 신규 캐릭은 `charIdx` 분기로 **per-캐릭터 고정 킷**을 우선 배선(선택슬롯/합체 트리 미노출). 공유 인프라(자원·쿨다운·투사체·블링크)는 최대 재사용.
- **근거**: 워리어 트리 전체를 신규 캐릭에 이식하면 범위 폭증 + 밸런스 지옥. 3스킬 킷으로 먼저 "플레이 가능·재미"를 확보하고, 이후 확장.

### 3-B. 스케일 스탯
헬거너=DEX(석궁 공식), 변성술사=INT(청염 마법), 창법사=INT(공허 마법). `move` 스킬은 스케일 스탯의 phys/magic 공식을 따름([[2_1 스킬관리+합체시스템]] cat 표).

### 3-C. 신규 자원 3종
- 헬거너 **혈탄(HP 소모)**: 기존 HP바 사용, 별도 UI 최소. 저체력 게이트.
- 변성술사 **영혼 스택**: `P._soulStk`(0~N), 처치 시 +1, HUD 소형 카운터.
- 창법사 **룬 슬롯**: `P._runes[]`(최대 3), 미니맵/월드 인디케이터.

### 3-D. 밸런스 타깃
신규 캐릭 3스킬 킷의 종합 DPS는 **동레벨 워리어 대표 빌드의 0.9~1.1×** 목표(난이도 스탯 반영: 창법사 고난이도=고상한계). 초기값은 기존 유사 스킬(석궁·회전참·블링크) 수치에서 파생.
