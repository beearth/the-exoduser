## 1. 호출(call) 의존성
| 지점 | 현행 사실 | 이식 요구 |
|---|---|---|
| 캐릭터 인덱스 | `CHAR_LIST`(game.html:10007) 현재 2항목(0 전사/1 실버테일). `_charIdx` localStorage `_charIdx` 지속 | 헬거너 = charIdx 2 항목 추가(`{id,name,desc,folder,fw,fh,idleN,walkN,...}`) |
| LMB 라우팅 | 전사 LMB = `P.activeLMBSk`(3769: kiSlash/whirlwind 분기). 좌클 입력→activeLMBSk 스킬 발동 | 헬거너는 관통 창격이 LMB 주력 → **charIdx===2 분기**로 좌클 시 `activatePierceShot()` 호출(기존 kiSlash 경로 비간섭). `activeLMBSk` 값 신설 or charIdx 게이트 |
| 발동 함수 | 기존 bow 스킬 `activateNeedleShot`(43561)·`activateBladeShot`가 템플릿. 투사체 `pProjs`(15781, player arrows 배열)에 push | `activatePierceShot()` 신설: 자원 게이트 → `pProjs.push({관통탄})` → SFX/텍스트. **SKILL-02 교훈: 게이트=차감=확정원가 일치 필수** |
| 투사체 업데이트/충돌 | `pProjs` 업데이트 루프가 이동·적중·수명 처리 | **확인 필요**: `pProjs` 오브젝트의 **관통(pierce) 필드 지원 여부**. 미지원 시 관통 로직 추가(1적 1회 hitSet) |
| 쿨다운 | 스킬별 `P._<id>Cd`, `_skCdMap`(26823)에 등록 | `P._psCd`(미사용 변수명 확인) 추가 + `_skCdMap` 등록 |
| T 자동석궁 라우터 | 27236~ bow 스킬 라우팅(`_effAbs===...`) | 관통 창격을 T 자동에 넣을지 or LMB 전용인지 결정(헌장=LMB 주력 → T 제외 가능) |
