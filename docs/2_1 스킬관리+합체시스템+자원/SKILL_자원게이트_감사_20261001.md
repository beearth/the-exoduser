# SKILL 자원 게이트 계약 전수 감사 — 2026-10-01

> **SKILL 팀장**. 총괄 배정: 기존 `activate*` 함수의 ST/MP·쿨다운 게이트 계약 전수 감사 — 표시 비용·발동 조건·실제 차감이 할인/강화 후 경계값(정확 비용/1 부족/쿨 직전·종료)에서 일치하는지. **기존 확정 공식 유지, 재현된 불일치만 좁게 수정, main/easy 양쪽, 내 함수 hunk만 소유.** SKILL-02([[BALANCE_ECONOMY_TEAM_MASTER]] PM-013-B, 수정 commit 0e26bfa01) 후속.

## 방법
`game.html`/`game-easy-test.html`에서 `function activate*` 24종 + useSkill 라우터/`_skCdMap`를 정적·소스 대조. 자원별로 **게이트 표현식 값 == 차감 표현식 값** 확인. `_malCost`(악의 50% 할인)·ST/MP는 실비 기준. 쿨다운은 게이트 변수 == 설정 변수. (경계값 실행 재현은 SKILL-02처럼 추출 하니스로 가능하나, 불일치가 발견된 경우에 한해 수행.)

## 결과 1 — 개별 activate 함수: **전부 일치 (불일치 0)**
| 자원 | 확인 내용 | 결과 |
|---|---|---|
| 악의(_malCost) | 게이트 `<_malCost(N)` vs 차감 `-=_malCost(N)` 인접쌍 | spikeTrap10·plagueBurst15·giantSlam20·maliceHunt30·boneWall(fire)12·chainBlast20·blastShot5(수정본) — **전부 N 일치** |
| ST | 게이트 `P.st<_xxStCost` vs 차감 `P.st=Math.max(0,P.st-_xxStCost)`/`P.st-=` | maliceHunt50·venomBlade40·ltnChaser40·bladeShot(_bsStC)·blastShot(_bsStC)·needleShot8·ghostXbow100 — **전부 동일 변수** |
| MP | 게이트 `P.mp<X` vs 차감 `P.mp-=X` | bladeDash(_bdCost)·skyCrusher(spec.mpCost)·timeWarp(_twMpCost)·maliceDome60·hellRay100 — **전부 X 일치** |
| 쿨다운 | 라우터 `_skCdMap`/케이스 `(P._xxCd)<=0` vs activate `P._xxCd=` | 각 스킬 게이트 변수 == 설정 변수 (blastShot _bsCd2 포함) — **일치** |
| 표시 비용(desc) | 악의=원가(할인전) 표기, ST/MP=실비 표기 규약 | maliceHunt(악의30+ST50)·venomBlade(ST40)·blastShot(악의5)·needleShot(ST8)·boneWall(2스택+악의12) — **규약 일치** |

→ **개별 activate 계약은 건전. SKILL-02가 유일한 게이트/차감 불일치였고 이미 수정됨.** 내 소유 범위에 좁게 수정할 재현 결함 없음 → **game.html 무변경**.

## 결과 2 — 스택 조준-설치형 라우터 게이트: **관찰(핸드오프, 미수정)**
스택(충전제) 마법 스킬의 **useSkill 라우터**에 표시 비용·실제 차감에 없는 **MP 게이트**가 존재:

| 스킬 | 라우터 게이트 | 시전 실제 차감 | 표시 비용(desc) | 판정 |
|---|---|---|---|---|
| hellRay | MP100 | `P.mp-=100` + 스택 | (MP100) | **일치(정상)** |
| iceStorm | **MP40** | `_isStk--`(스택1)만, **MP 차감 0** | 2스택 충전(자체 desc에 MP 비용 불명확) | **팬텀 MP 게이트 의심** |
| boneWall | **MP50** | `_bwStk--`(스택1) + `_malCost(12)`(악의12), **MP 차감 0** | "2스택 + 악의12"(MP 언급 없음) | **팬텀 MP 게이트(표시=차감엔 없는 MP 요구)** |

- 증상: MP<40/50이면 발동 거부("MP 부족!")되나 시전은 MP를 소비하지 않음. 표시 비용·실제 차감과 불일치.
- **미수정 사유(3중)**: ① 게이트가 **개별 activate 함수가 아닌 useSkill 라우터(공용)**에 위치 — 내 소유 범위 밖. ② 수정 방향이 확정 공식에 의존(게이트 제거=스택/악의 전용으로 정합 vs MP 차감 추가=MP 비용 신설) — 확정 공식은 BALANCE/총괄 소유. ③ 어느 쪽이든 발동 난이도·자원 곡선을 바꾸는 **밸런스/설계 결정**.
- **핸드오프**: 라우터 MP 게이트 소유팀 + BALANCE에 확정 공식(스택 전용? 스택+MP?) 확인 요청. 확인 후 정합 수정은 소유팀/승인 범위에서.
