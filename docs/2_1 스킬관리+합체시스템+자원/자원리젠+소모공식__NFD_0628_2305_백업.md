# 자원 리젠 & 소모 총정리

> **2026-09-10 마법 공격 2배:** `pMagicMul(forAttack=true)=_passDmgSum('magic')×(1+_uHelmMagic)×2`. 아래 공식의 `pMagicMul()`에 이미2배가 포함되므로 스킬 계수·후속 폭발·DOT에 다시 곱하지 않는다. `pMagicMul(false)`는 Q패링 장비스케일 전용으로 기존 값을 유지한다. 계수 표의 숫자는 이 공통 배율을 곱하기 전 값이다. [상세 계약](../14밸런스+수치테이블/MAGIC_ATTACK_DAMAGE_20260910.md).


## 0. 자원 최대치 공식 (2026-04-17 레벨 성장 시스템 변경)

### 레벨 자동 성장 시스템
**핵심**: 레벨업 시 HP/ST/MP/Shield 직접 증가 **제거**, 대신 전 스탯(STR/DEX/INT/LCK)이 매 레벨마다 **+0.5** 씩 증가.
- Lv1000 = 모든 스탯 +500 자동

## 악의 소비 전역 배율 (2026-04-14)

| 항목 | 공식 | 비고 |
|------|------|------|
| **악의 최종 소비량** | `_malCost(v) = max(1, ceil(v × 0.5))` | 악의를 소모하는 모든 체크/차감 경로에 공통 적용 |
| **0 비용 예외** | `v <= 0 → 0` | 무료 스킬/무료 기능은 그대로 무료 |

### 스탯 계산 공식
```
s = {
  str: STATS.str + eqStr + floor(Lv × 0.5),
  dex: STATS.dex + eqDex + floor(Lv × 0.5),
  int: STATS.int + eqInt + floor(Lv × 0.5),
  lck: STATS.lck + floor(Lv × 0.5)
}
```

| 자원 | 공식 | 비고 |
|------|------|------|
| **최대ST (mst)** | `200 + s.dex×2 + bonusSt + maxSTFlat어픽스 + 결정ST` | **NO Lv×1 직접 보너스** — DEX만 2배 스케일. bonusSt = 방어구 6슬롯 bonusSt 합산 |
| **최대MP (mmp)** | `200 + s.int×2 + bonusMp + maxMPFlat어픽스 + 결정MP` | **NO Lv×1 직접 보너스** — INT만 2배 스케일. bonusMp = 장신구 6슬롯 bonusMp 합산 |

### maxSTFlat / maxMPFlat 어픽스
- 5티어: T0=20, T1=40, T2=60, T3=80, T4=100
- 장착 슬롯: 방어구 10종 (armor, helm, shield, boots, gloves, pants, belt, cloak, bracelet, headband)
- 최대치: 10슬롯 × T4(100) = +1000 (ST/MP 각각)
| **최대HP (mhp)** | 별도 공식 (STR/VIT/장비 등) | recalcStats 참조 |

## 1. 자원 리젠 공식

### 기본 리젠 (recalcStats) — 레벨 의존도 제거 (2026-04-17)

| 자원 | 공식 | 비고 |
|------|------|------|
| **ST리젠** | `0.05 + s.dex×0.005` | **NO Lv×0.0015** — DEX만 0.005 스케일 |
| **HP리젠** | `0.05 + s.str×0.002 + lifeRegen` | **NO Lv×0.001** — STR만 0.002 스케일 |
| **MP리젠** | `0.05 + s.int×0.005` | **NO Lv×0.0015** — INT만 0.005 스케일 |

- 기본치 0.05 = 스탯 0일 때 초당 약 0.375 (÷8 적용)
- **리젠도 스탯 투자의 보상**: 레벨은 스탯만 올리고, 리젠 개선은 스탯(STR/DEX/INT) 투자로만 가능
  - 예시: Lv1000 DEX500 (레벨+자체) = 500+500=1000 DEX → stR = 0.05+1000×0.005 = **5.05** → idle 초당 ~38 회복

### 상태별 리젠 배율

| 상태 | ST | HP | MP |
|------|----|----|-----|
| **대기 (idle)** | ÷8 | ÷8 | ÷8 |
| **행동 중** | ÷16 | ÷16 | ÷16 |
| **빔 사용 중** | ÷16 | ÷16 | ÷16 × 0.5 (50% 감소) |

### 추가 배율
- **회복의 영역 (holyDome)**: 리젠 ×2
- **장비 어픽스**: stRegen, mpRegen 별도 가산
- **패시브 (회복력 등)**: pRegenMul(), pMRegenMul() 곱연산

## 2. 소모 시스템 구조

### 실제 소모 경로: _COST_BASE + stCost()/mpCost()

```
stCost(key) = min( _COST_BASE[key] × (1 + (skLv-1) × _COST_DPS[key]) × _stDisc(key), P.mst × 0.90 )
// 최대ST 90% 캡 — ST 풀이면 어떤 스킬이든 항상 발동 가능
mpCost(key) = _COST_BASE[key] × (1 + (skLv-1) × _COST_DPS[key]) × pMagicCost()
```

- `_COST_DPS[key]`: 해당 스킬의 DPS 성장률 (비용 성장 = DPS 성장, 효율 불변)
- `_stDisc(key)`: pAtkCost() 또는 pBowCost() 자동 선택

### 패시브 할인 함수

| 함수 | 대상 | 할인 | 캡 |
|------|------|------|----|
| pAtkCost() | 무기/방패/돌진/회전참/지옥강타 1 | -4%/lv | 최소 60% |
| pBowCost() | 석궁/칼날살/만화방창 | -4%/lv | 최소 60% |
| pMagicCost() | 마법 전체 + 빔 틱 | -4%/lv | 최소 60% |

## 6. 채널링 — 고정값/초 소모 (2등급)

### 공통 규칙
- **레벨 스케일 소비**: 초당 `(10 + (Lv-1) × 10)` — COST_GLOBAL 레거시 삭제됨

### DoT 설계 원칙
- 각 카테고리의 스킬은 **해당 카테고리의 DoT만** 부여해야 함
- 화상과 전기도트는 모두 INT 스케일 (마법 카테고리 내 서브타입)
- **D4식 DOT 풀 시스템**: 히트 데미지의 %를 풀에 축적, 틱마다 풀/잔여초 드레인. 크리=강한 DOT (자연 스케일)
- **스택 10 캡**: 10스택 도달 시 풀 축적 중단 (mHP 캡 없음, 디아블로식)
- 스택: 적용마다 +1, 최대 10. 10이면 풀에 더 이상 추가 안 됨. 시간 종료 시 풀+스택 리셋
- **출혈**: 히트뎀 10% 풀 축적, 5초(300f), 10스택 캡. bleedPool += dmg×0.10
- **중독**: 히트뎀 10% 풀 축적, 5초(300f), 10스택 캡. poisonPool += dmg×0.10
- **화상**: 히트뎀 10% 풀 축적, 3초(180f), 10스택 캡. burnPool += dmg×0.10
- 틱 데미지 = pool / 잔여초 (매초 1회). 풀에서 틱뎀만큼 차감

## 12. 설계 의도

- **리젠은 스탯 투자의 보상**: 기본치를 낮춰 스탯 없이는 회복 느림. ST리젠은 DEX 주력(0.005)으로 민첩 투자 보상
- **채널링은 고정값/초 (2등급)**: `(10+(Lv-1)×10)×COST_GLOBAL` 공식. 자원풀 투자 → 지속시간 증가
- **채널링 패시브 할인 삭제**: 채널링 스킬은 고정비용, 할인 미적용. 1회성 스킬은 여전히 패시브 할인 캡 60% 적용
- **리젠 감소**: 빔 사용 중 MP리젠 반감 → 소모와 회복의 균형
