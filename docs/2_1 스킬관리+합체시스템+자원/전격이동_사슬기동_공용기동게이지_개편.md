## 설계 의도

기동 행동마다 별도 스톡을 보유하던 구조를 없애고, 플레이어가 현재 남은 이동 선택지를 한 개의 노란 원형 게이지에서 즉시 읽도록 통합한다. 게이지의 한 칸은 **Shift 탭으로 나가는 최소 사슬기동 거리 1회분**이며, 전격이동은 2026-09-10 자원30% 감소로0.7칸(31.5)을 사용한다.

## 공용 기동게이지 규칙

| 구분 | 값 | 적용 위치 |
|---|---:|---|
| 1단 Shift 사슬기동 비용 | `45` | `_HARP_GAUGE_COST[1]` |
| 2단 Shift 사슬기동 비용 | `98` | `_HARP_GAUGE_COST[2]` |
| 3단 Shift 사슬기동 비용 | `150` | `_HARP_GAUGE_COST[3]` |
| 기본 게이지 | `5칸 = 225` | `_HARP_GAUGE_BASE_CELLS` |
| 전격이동 비용 | `31.5` + MP `(10+(Lv−1)×5)×7/10` | `activateBladeDash()` |
| 게이지 회복 | 기존 `_harpGauge` 회복 규칙 유지 | 프레임 갱신 |

기존 합체/차지 보너스는 공용 게이지의 최대치에 계속 반영한다. 기본 상태만 5칸이며, 차지 보유 시 6칸, 차원분쇄 B 보유 시 7칸, `dimThunder` 합체 시 9칸, `dimRush` 합체 시 10칸이다. `extraST` 장비 어픽스의 추가 수치는 기존처럼 최대치에 합산한다.

## 전격이동 변경

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 사용 가능 횟수 | 전격이동 전용 `10스톡` | 공용 기동게이지의 남은 칸 |
| 회복 | 전용 `_bdRech` 재충전 | `_harpGauge` 공용 회복 |
| 발동 조건 | 전격이동 스톡 + MP | 공용 게이지 `31.5` 이상 + 감소된 MP 비용 |
| 발동 비용 | MP `10 + (레벨-1)×5` | MP `(10+(Lv−1)×5)×7/10` + 공용 게이지 `31.5` |
| HUD | 전용 `⚡ 스톡` 숫자 | 노란 기동 원형 게이지 |

전격이동의 방향키 더블탭 조작, 250유닛 순간이동, 15프레임 무적, 상태이상 탈출, 착지 전류장판 효과는 유지한다. 2026-09-10에는 MP와 기동게이지 비용을 각각30% 줄였다. MP는1렙7/5렙21/10렙38.5/20렙73.5이며 소수값을 유지한다.

## HUD 표현

노란 기동 원형 게이지는 칸 수에 맞춰 원주를 동일한 구간으로 나누며, 인접 칸 사이에는 3도 점선 간격을 둔다. 현재 최대치가 바뀌면 칸 수도 즉시 다시 계산한다. 따라서 게이지의 노란 칸 하나는 최소 Shift 탭 1회(45)에 해당한다. 전격이동1회는0.7칸(31.5)이다. 전격이동 시 떠오르는 ⚡숫자는 floor(현재게이지/31.5) / floor(최대게이지/31.5)로, 기본최대225에서는 총7회분이다 (MP 제한 제외).

## 2026-09-10 이동 거리 회귀 수정

사용자 확인: 자원만 줄여야 하는데 전격이동 거리가 두 배로 느껴졌다. 원인은 자원 변경 이전의 E 차징 유지 커밋 `c840b8a68`이다. 종전에는 P.st2=12가 공통 update와 bladeDash 분기에서 각각 감소해 정상속도에서6회×(500/12)=250유닛 이동했다. 독립 _bdMoveT=12로 분리하면서12회=500유닛이 되어 실거리가 두 배가 됐다. 문서의 기존500표기도 실제 동작과 달랐다.

| 항목 | 수정 후 |
|---|---|
| 이동 거리·시간 | 250유닛 / 6게임프레임, 속도250/6으로 종전 실속도 유지 |
| 마지막 갱신 | _bdStep=min(sp,_bdMoveT), 남은 시간만 이동·차감하여 슬로우 중 초과 이동 방지 |
| 완료 상태 | 남은 이동시간≤0 또는 sp≤0이면 즉시 반환, 착지·이동 재실행 금지 |
| E 차징 | 독립 _bdMoveT는 유지하며 sDraw/kiGather·릴리즈 sBash를 보존 |
| 자원 | MP=(10+(Lv−1)×5)×7/10, 기동게이지31.5 그대로 |
| 무적·착지 | 시작15f/진행최소3f/착지최소15f, 착지 전류장판1회 그대로 |
| 별도 패링 | 실버테일 E 차징 돌진의150+175×(mult−1)은 별개이며 그대로 |
| 검증 | 비용·거리·분할시간·완료중복·E차징 유지18 PASS. 실제 더블탭 검증 tools/verify_blade_dash_distance.py, output/qa/blade_dash_distance_20260910.json |

수정 금지인2_3 문서의 bladeDash500px/12f 언급은 당시 E돌진 조정의 역사적 참조다. 현행 전격이동의 계약은 이 문서의250유닛/6f가 우선하며 해당 문서를 수정하지 않는다.
