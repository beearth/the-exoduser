## 설계 의도

기동 행동마다 별도 스톡을 보유하던 구조를 없애고, 플레이어가 현재 남은 이동 선택지를 한 개의 노란 원형 게이지에서 즉시 읽도록 통합한다. 게이지의 한 칸은 **Shift 탭으로 나가는 최소 사슬기동 거리 1회분**이며, 전격이동도 정확히 같은 1칸을 사용한다.

## 공용 기동게이지 규칙

| 구분 | 값 | 적용 위치 |
|---|---:|---|
| 1단 Shift 사슬기동 비용 | `45` | `_HARP_GAUGE_COST[1]` |
| 2단 Shift 사슬기동 비용 | `98` | `_HARP_GAUGE_COST[2]` |
| 3단 Shift 사슬기동 비용 | `150` | `_HARP_GAUGE_COST[3]` |
| 기본 게이지 | `5칸 = 225` | `_HARP_GAUGE_BASE_CELLS` |
| 전격이동 비용 | `45` + 기존 MP 비용 | `activateBladeDash()` |
| 게이지 회복 | 기존 `_harpGauge` 회복 규칙 유지 | 프레임 갱신 |

기존 합체/차지 보너스는 공용 게이지의 최대치에 계속 반영한다. 기본 상태만 5칸이며, 차지 보유 시 6칸, 차원분쇄 B 보유 시 7칸, `dimThunder` 합체 시 9칸, `dimRush` 합체 시 10칸이다. `extraST` 장비 어픽스의 추가 수치는 기존처럼 최대치에 합산한다.

## 전격이동 변경

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 사용 가능 횟수 | 전격이동 전용 `10스톡` | 공용 기동게이지의 남은 칸 |
| 회복 | 전용 `_bdRech` 재충전 | `_harpGauge` 공용 회복 |
| 발동 조건 | 전격이동 스톡 + MP | 공용 게이지 `45` 이상 + MP |
| 발동 비용 | MP `10 + (레벨-1)×5` | 동일 MP + 공용 게이지 `45` |
| HUD | 전용 `⚡ 스톡` 숫자 | 노란 기동 원형 게이지 |

전격이동의 방향키 더블탭 조작, 500유닛 순간이동, 15프레임 무적, 상태이상 탈출, 착지 전류장판 효과는 유지한다. MP 비용은 이번 개편 범위가 아니므로 바꾸지 않는다.

## HUD 표현

노란 기동 원형 게이지는 칸 수에 맞춰 원주를 동일한 구간으로 나누며, 인접 칸 사이에는 3도 점선 간격을 둔다. 현재 최대치가 바뀌면 칸 수도 즉시 다시 계산한다. 따라서 게이지의 노란 칸 하나는 최소 Shift 탭 1회 또는 전격이동 더블탭 1회에 해당한다.

## 구현 검증 기준

| 검증 항목 | 기대 결과 |
|---|---|
