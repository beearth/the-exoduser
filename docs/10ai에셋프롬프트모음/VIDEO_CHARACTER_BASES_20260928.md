브라우저에서 비교 페이지의 이미지 6개 요소(선택 기본 4종, 닫힘 재표시, 개방 시안)가 모두 2688×1520으로 로드되는 것과 가로 넘침이 없는 것을 확인했다. 좁은 인앱 브라우저에서는 한 열로 표시되며 이미지 원본 링크를 제공한다.
