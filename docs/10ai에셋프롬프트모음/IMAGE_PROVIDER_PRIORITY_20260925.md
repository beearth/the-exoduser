## 기능 확인 근거

2026-09-30 [MagicLight 공식 이미지 생성 안내](https://magiclight.ai/ja/create/ai-image-generator/)에서 Image 탭, 텍스트 프롬프트, 참고 이미지 업로드, 이미지 생성·다운로드 지원을 확인했다. 공식 안내에는 GPT 계열 이미지 모델도 제시되어 있다. 사용자 계정의 로그인·잔액·현재 모델 목록은 이번 공개 안내 확인만으로 검증하지 않았다.
