# 이미지 생성 서비스 우선순위 — 2026-09-25

사용자 최신 지시: “힉스필드 먼저쓰고 토큰없을때 GPT를 쓰는걸로해”. 기존 GPT API 단일 경로 규칙을 아래 순서로 대체한다. 과거 제작 기록의 서비스·모델 정보는 그대로 보존한다.

| 항목 | 현행 규칙 |
|---|---|
| 적용 | 신규 이미지·텍스처·VFX·UI 아트 생성 및 편집 |
| 1순위 | 연결된 Higgsfield의 GPT 이미지 모델 |
| 전환 조건 | Higgsfield 크레딧 소진 또는 해당 요청에 필요한 크레딧 부족 확인 |
| 2순위 | 연결된 OpenAI GPT Image API |
| 추가 확인 | 이 순서의 서비스 전환은 이미 승인됨. 반복 승인 요청 없음 |
| 오류 구분 | 인증·네트워크 오류를 크레딧 소진으로 간주하지 않음 |
| 모델 | 다른 이미지 모델로 임의 변경하지 않음. 가능한 경우 모델·참조 이미지·해상도·품질을 유지 |
| 기록 | 실제 서비스·모델·프롬프트·규격·저장 위치를 해당 에셋 문서에 기록 |
| 보안·저장 | 인증정보 노출 금지. 결과는 프로젝트 img/ 또는 assets/에 저장하고 로딩 폴백·투명도·합성 확인 |

이번 변경은 향후 작업 규칙의 기록이며 이미지 생성 요청이나 크레딧 사용은 없다. 영상·음성 생성 우선순위는 변경하지 않는다.
