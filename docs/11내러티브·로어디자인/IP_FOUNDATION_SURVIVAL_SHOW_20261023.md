## 한 줄

지옥은 천상계가 구경하는 서바이벌 쇼다. 네메시아는 그 쇼의 진행자이자 전 우승자이고, 주인공은 쇼를 깨고 운영권을 빼앗아 HELL LORD가 된다.

## 세계 구조

| 요소 | 설정 |
|---|---|
| 관람석 | 천상계. 지옥에 떨어진 자들을 저열하고 필요 없는 존재로 보고, 그들의 탈출 경쟁을 오락으로 소비한다 |
| 쇼 = 채굴 | 경쟁이 격할수록 망자의 분노·절망(악의)이 더 나온다. 지옥이 동력원이라는 기존 설정과 이어진다 |
| 경기장 | 지옥. 7장 = 7라운드, 장보스 = 라운드 관문 (`HELL_BOSSES` 구성 유지) |
| 참가자 | 매일 떨어지는 망자. 디로이·핵터도 참가자다 |
| 우승 보상 | 환생 또는 탈출 중 하나를 고를 권리 |
| 보상의 진실 | 거짓. 단절의 법칙상 환생은 불가능하고, 우승자는 다음 진행자로 배치될 뿐이다 |
| 진행자 | 네메시아. 전 우승자. 환멸을 품고도 임무를 수행한다 |
| 운영자 | 지옥 군주. 최초의 탈주 이후 천상계가 세운 간수 |
| 유일한 예외 | 최초의 탈주자(주인공의 전생). 보상이 아니라 게임을 부수고 나갔다 |
| 시즌제 | 새 시즌 = 새 참가자, 엔드게임 순위표 = 천상계의 시청률표 |

## 차용 범위 (지킬 선)

- 오징어게임에서는 구조(관람당하는 생존 경쟁, 전 우승자 진행자)만 가져온다. 진행요원·가면·한국 전통놀이·상금 유리볼 같은 고유 이미지는 쓰지 않는다. 외형은 헬 고딕을 유지한다.
- 네메시아의 "이병헌 같은 느낌"은 인물 유형 참고일 뿐이다. 실존 배우의 외모는 참조하지 않고, `NEMESIA_DESIGN_LOCK.md`를 유지한다.
- 천상계의 오락은 웃기기보다 섬뜩하게 그린다. 천사형 클리셰(흰 날개·후광)는 금지한다(WORLDVIEW v2 §9).

## 우주 구조 — 지하상층과 지옥 (2026-10-25 사용자 제시)

사람들은 천상이 하늘 위에 있다고 믿지만, 실제로는 다른 차원(4차원)의 세계가 아래로 층층이 놓여 있다. 지하 1~10층이 **지하상층**이고 그 아래가 지옥이다. "천상"은 지하상층의 신들이 스스로 붙여 인간에게 퍼뜨린 이름이다.

| 층 | 이름 | 설정 |
|---|---|---|
| 지상 | 인간계 | 천상이 하늘 위에 있다고 믿는다 |
| 지하 1~10층 | 지하상층 (자칭 "천상") | 신들의 층. 10층 바닥이 관람석의 유리 바닥이다 |
| 지하 11~17층 (제안) | 지옥 7라운드 | 썩은 숲(11)부터 지옥성(17)까지 |
| 그 아래 | 측정 불가 | 지옥은 끝이 없다(WORLDVIEW v2) |

- 용어: 설정·내레이션은 "지하상층", 인간의 신앙이나 신들의 자칭은 "천상". 이 문서 위쪽의 "천상계"는 지하상층을 가리킨다.
- 지옥의 모든 것이 흐르는 방향은 위, 지하상층이다. 악의가 올라가 신들의 바닥을 데운다.
- 지옥 하늘의 "별"은 관람석 바닥에서 내려다보는 신들의 눈이다.
- 지상으로 탈출하려면 지하상층 10개 층을 뚫고 올라가야 한다. 최초의 탈주자의 "단 하나의 구덩이"는 지하상층을 관통한 구멍이다.
- 후속작 무대는 지하상층 10개 층을 거꾸로 올라가는 이야기다.
- **다중우주 공통의 단일 사후세계 (2026-10-25 사용자 확정):** 무수한 우주와 시대가 있지만 죽은 자가 가는 곳은 이 탑 하나다(WORLDVIEW v2 수렴의 법칙). 그래서 엘프·도깨비·미래의 저격수가 같은 시즌에 떨어지고, 같은 인물의 다른 우주 버전이 한 지옥에서 마주칠 수 있다(중첩의 법칙). 각 세계의 "천상" 신앙이 가리키는 곳도 모두 같은 지하상층이다. IP 확장 시 어떤 세계관의 인물도 "죽어서 여기로 온 자"로 등장시킬 수 있다(DLC·콜라보·시즌 참가자).

## 숨은 층위 — 프로그램으로 돌아가는 사후세계 (2026-10-25 방향 제시, 세부는 제안)

탑은 신들이 만든 것이 아니라 누군가 설계한 규칙으로 돌아가는 거대한 프로그램이고, 지하상층의 신들은 그것을 찾아내 운영하는 자들이다. 본편은 배경으로만 깔고 후속작에서 드러낸다.

| 세계관 요소 | 프로그램으로 보면 |
|---|---|
| 4대 법칙 | 바꿀 수 없는 시스템 규칙. 신들도 예외를 못 만든다 |
| 영혼의 부활 | 리스폰. 게임의 부활이 세계관 안에서 설명된다 |
| 악의 | 탑을 돌리는 연산 자원. 신들이 빼돌려 산다 |
| 낙인 4계열 | 입장 시 분류 태그 |
| 시즌 | 한 번의 실행과 초기화 |
| 권능 조각 7개·왕관 | 나눠 숨긴 최고 권한. 모으면 규칙을 고칠 수 있다 |
| 최초의 탈주자 | 시스템의 유일한 버그. 제약(사슬)을 뜯고 나간 예외 |
| 지옥 군주 | 그 버그의 재발을 막는 감시 장치 |
| 별(눈)·빛의 기둥 | 감시 화면, 데이터 투입(후원)과 삭제(고목) |
| 선창자 | 창조자가 아닌 운영자. 진짜 설계자는 부재 |

- 톤: 세계 안의 말은 신화·의례 어휘로만 쓴다("코드", "버그" 금지). 예외는 미래 시대에서 온 서하 한 명.
- 데미지 숫자·레벨·드롭 같은 UI는 "탑이 남기는 기록"으로 설명할 수 있다.
- 후속작 훅: 지하상층 꼭대기 너머에는 아무도 없는 방과 규칙을 쓴 자의 흔적만 있다. 왕관(최고 권한)을 가진 주인공이 규칙을 다시 쓸 것인가.
