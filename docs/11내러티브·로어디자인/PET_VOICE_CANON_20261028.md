### 2.1 디로이 (고양이) — 도도·직설·실용, 속정은 있다

- 반말 평서·짧은 명령. 설명 역할(키 안내·시스템 팁)은 디로이 몫으로 유지한다.
- **느낌표는 위급 경고와 처치 직후에만, 한 개.** `!!`·`!!!`·`?!` 금지(긴급 경고 `_petSayUrgent` 중 기존 `!!` 2줄은 가독성 때문에 그대로 둔다).
- 칭찬은 인정 한마디("제법인데", "인정할게", "나쁘지 않네"). **"짱·천재·대박·미친·멋져·최고" 금지.**
- 겁먹은 아이 말투 금지("으으", "무서워", "끔찍해"). 혐오·경계는 건조하게("기분 나빠", "최악이야"). 고양이 몸(털·발)을 빌린 짜증은 허용.
- 늘인 어미 금지("~", "마아", "살자아", "차려어").
- 메타·게이머 말 금지("게이머", "스피드런", "운빨 게임", "다른 사람들", "모드 즐기자", "챕터 클리어"). 단, 게임 기능 이름(TAB·G·K·패링뱅크·오패링·그로기)은 안내에 필요하므로 허용.
- 속정: 누나의 영혼이다. 사망 화면·첫 보스 앞에서는 다정해도 된다("겁먹지 마, 우리도 있어").
- 주인공 호칭은 "너"·"이 인간". "우리 주인" 금지(디로이는 펫이 아니라 여신이 보낸 안내자).

### 2.2 핵터 (까마귀) — 냉소·관찰·짧은 명령, 건조한 유머 (현행 유지)

- 전투 중에는 "…"로 시작하는 짧은 관찰과 명령. 컷신에서는 구어체로 길게 말할 수 있다(인트로).
- 안내자는 "아는 자"다. 전해 들은 말투("~대") 쓰지 않는다.
- 주인공을 움직이는 축은 **복수와 구출 둘 다**. 여신의 인트로 미끼("네가 구해야 할 이가… 아직도 너를 기다리고 있다")를 펫이 이어받는 줄을 사망 화면에 하나 둔다.

## 5. 반영 규칙 (단순작업 세션용)

1. 원격 `origin/main` 워크트리에서 한다(로컬 main 8bf094fe6 번들 push 금지). 커밋은 `git commit -m ... -- <경로>`만.
2. game.html 원문 문자열을 표의 새 문장으로 바꾼다. 같은 문자열이 두 곳(T-10 9656·38780)이면 둘 다.
3. 번역: 새 문장마다 `_EN`·27개 `lang_*.js`에 새 키 추가. **옛 키는 lang 파일에 남긴다**(B2 규칙 5와 같음). 번역대상 목록은 옛 행의 KO·EN을 새 문장으로 고치고(번호 유지), 목록에 없던 줄은 새 No.(3720 다음, 결번 3700·3701 재사용 금지)로 등록한다.
4. 클리어 패널·피날레처럼 `localization/ui/*.json`에 같은 키가 있으면 그쪽을 먼저 확인한다(B2 알아 둔 사실).
5. 문서 동기화: `2_4 펫시스템/대사_스크립트.md`(본문 표의 해당 문장 + 성격 가이드), `2_4 펫시스템.md` 펫 표, `펫_대사_스크립트.md`, `16번역·로컬라이제이션/번역대상_펫대사.md`.
