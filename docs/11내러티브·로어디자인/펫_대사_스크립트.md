## 구현 참고

- **1회성 대사**: `_petTut`는 각 분기의 계약으로 관리한다. `tut_firstItem`만 `_petSayCD` true 수락 후 flag를 소비하고 return하며 false는 미소비 후 후속 분기를 검사한다. 다른 튜토리얼의 flag·return 계약은 유지한다. 수락은 DOM 표시·후발 대사 완료를 뜻하지 않는다.
- **반복 대사**: `_petSayCD(id, who, txt, dur, cdSec)` — cdSec초 쿨다운
- **페어 대사**: 까마귀 먼저 → 고양이 이어서 (또는 반대)
- **말풍선**: 폰트 15px, 줄 높이 20px, 최대 22자/줄, 페이드아웃 30f
- **우선순위**: 비긴급 즉시 대사는 활성 bubble·ID CD·티어 CD 등에 거절될 수 있다. 기존 T5 `_petSayUrgent` 입찰과 mid-fire는 먼저 실행하며 ID CD/같은 UID 활성 가드를 유지하고 필요 시 기존 bubble·pair를 중단한다. firstItem false는 이 긴급 정책을 바꾸지 않고 후속 검사로 진행한다. 전체 T5·DOM 보장은 별도 검수다.
