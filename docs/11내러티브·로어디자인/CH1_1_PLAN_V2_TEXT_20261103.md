## 0. 원칙

- 흐름 "좁힘 → 열림 → 쉼 → 다리 → 뿌리길 → 큰 전투 → 관문"(PLAN V2)을 제목으로 한 번씩만 짚는다. 제목은 장소 이름이고 설명문이 아니다.
- 서사는 1장 뼈대 그대로: 썩은 숲 = 하나의 기생 생물, 다크드루이드 = 새로 떨어진 자를 거름으로 거두는 **숲지기**. 1-1에서 드루이드는 정체를 다 드러내지 않는다.
- 비문·안내판 텍스트 없음(비문은 2장부터, 뼈대 §4). 길 안내는 지형·랜드마크로.
- 드루이드 대사(등장 "새 거름이 떨어졌군." / 침강 "숲은 아직 배고프다. 둥지에서 보자.")와 펫 처치 대사는 기존 확정분(No.3343~3349)을 그대로 쓴다. 이 문서는 **새로 필요한 것만** 더한다.
- 기존 4지역 이름(북서·어둠 등, `_REG_CH1_KO`)은 필드보스 정화 HUD용으로 그대로 둔다. 아래 제목은 그와 별개인 **구간 진입 제목**이다.

- 표시 시점: 구간 경계 트리거 첫 통과 1회. 제목 3.0초 안팎, 대사는 제목이 사라진 뒤. 전투 중(근처 적 활성)에는 대사를 미루고 제목만.
