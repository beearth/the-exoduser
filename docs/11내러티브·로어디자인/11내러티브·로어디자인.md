## 캐릭터 스토리 자막 하단 배치 (2026-09-07)

사용자 스크린샷의 “이웃이자 친구였던 킬루가 그의 가문을 짓밟았다.”는 game.html의 PROLOGUE_LINES wa06이다. 기존 일반 내레이션이 화면 높이 50%에 고정돼 있던 것을 하단 중앙으로 이동했다. index.html 세계관 영상의 선택형 자막과 별개다.

| 항목 | 현행 값·적용 위치 |
|---|---|
| 렌더 | game.html `_renderIntroCutscene()`의 `ln.narr && ln.text`, 일반 내레이션(`!ln.title`) |
| 수평 | `cw * .5`, textAlign=center |
| 수직 | 첫 줄 `_nCy = ch * .88 - (줄 수 - 1) * _nLh`, 마지막 줄 중심은 `ch * .88` |
| 기준 영역 | 레터박스 보정 후 영상 영역 cw/ch. 좌표는 _lbX/_lbY 이동 후 적용 |
| 글꼴·간격 | 기존 유지: 일반 `_nFs = Math.max(14,ch*.031)`, 실제 폰트 크기 `~~_nFs`, `_nLh = _nFs*1.5`, textBaseline=middle |
| 다중 행 | 기존 명시적 개행 split 유지, 마지막 줄을 하단에 고정하고 앞줄은 위로 쌓음 |
| 타이틀 예외 | 기존 메탈 로고 중앙 배치 유지. 글자 폴백 `_nCy=ch*.5-(줄 수-1)*_nLh*.5` 유지 |
| 유지 범위 | 캐릭터 대화창(ln.speaker), 색·크기·그림자·페이드·대사·보이스·컷 시간·BGM 및 세계관 인트로 변경 없음 |
| 회귀 테스트 | `test/characterStorySubtitlePosition.test.js` 2개 PASS. 높이 450/720/1080 × 1/2/3줄 마지막 줄 88%, 타이틀 중앙 보존. 세계관 16개 포함 총 18개 PASS |
| 시각 검사 | `tmp/verify_character_story_subtitle.py`: 게임 소스의 실제 내레이션 렌더 블록을 독립 Chromium Canvas에서 실행. 1280×720에서 x=640/y=633.6, 스크린샷 문구 하단 표시 직접 확인 |
| 검수 파일·한계 | `output/cinematic/character_story_subtitle_bottom_20260907.png`. 독립 렌더 블록 검수이며 새 캐릭터 전체 진행·세이브 접근 없음 |
