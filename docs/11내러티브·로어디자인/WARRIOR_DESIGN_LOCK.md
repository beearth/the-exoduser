## 어깨갑옷 통일 방법 (2026-10-04)

생성 시 레퍼런스를 **블러 구도 + `warrior_identity_ref.png` + 07번 어깨 크롭(갑옷 기준) + 05번 목마 크롭(소품 기준)** 4장으로 넣고, 프롬프트에 `smooth rounded overlapping steel plates exactly as image 3, NO spikes`를 넣는다. 레퍼런스 없이 생성하면 톱니 비늘형 견갑이 나온다(05·19·20 사고).

`warrior_cut.png`는 얼굴이 작아 얼굴 레퍼런스로 약하다(06번이 어린 장발 얼굴로 나온 사고). 얼굴이 보이는 컷은 **확정된 인트로 07번에서 얼굴만 크롭한 이미지**를 얼굴 레퍼런스로, `warrior_identity_ref.png`를 갑옷·망토 레퍼런스로 함께 첨부한다(구도 블러 + 얼굴 + 갑옷 = 3장). 배경은 앞뒤 컷과 같은 장소로 명시.
