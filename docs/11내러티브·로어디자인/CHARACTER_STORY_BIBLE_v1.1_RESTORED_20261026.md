## 1. 세계관 코어 [world_core v1.0 2026.05.07]

### 1-1 악의와 선의
- 악의 = 타인에게 해를 끼치려는 의지 / 선의 = 타인에게 도움이 되려는 의지 [04.30 확정]
- 의지 기준, 결과 기준 아님. 동기와 무관 (정의로운 복수도 의지가 살해면 악의). 무관심 = 선의 결핍이지 악의 아님
- 구덩이(지옥) = 악의가 선의보다 컸던 인간이 떨어지는 곳. 나이 무관, 영혼 무게 기준
- 악의 4법칙: 1) 악의는 생물만 만든다 2) 씨앗 = 탐욕의 도구(폭력+구속) 3) 뿌리 = 균형 붕괴 4) 운동 = 블랙홀, 팽창 후 무한 흡수
- 악의 = 균형을 깨는 모든 힘. 항상 외부에서 자기로의 흡수 방향. 지옥은 명사가 아니라 동사로 작동하는 세계
- 단일 에너지 법칙: 지옥에는 악의 외 에너지가 없다. 생성/파괴/무기/음식/회복/이동/공격/방어 전부 악의의 운용

### 1-2 3층 구조
- 상층 천계: 표면 평화/질서, 실체 부패/정치/권력 다툼. 핵심 모순 = 평화 유지에 악의가 필요
- 중층 네메시아: 천계에 악의를 공급하는 중간관리자로 위장
- 하층 지옥: 악의 발생/응결 원천. 악마 = 악의가 형체를 얻은 것, 거주민 = 채굴 대상(영혼)
- [v1 04.15] 지옥왕은 악의 에너지 지배자, 천상에서도 최상위 권력

### 1-3 악의충
- 네메시아가 인간 안에 심는 씨앗. 숙주는 자유롭다고 믿으며 네메시아가 원하는 행동을 한다
- 숙주는 솟아나는 분노/욕망/공포를 자기 것이라 믿음. 실제로는 충의 압력
- 그리피스는 사람을 죽였다. 네메시아는 사람이 자기 손으로 사랑하는 자를 죽이게 만든다
- 시스템 해석: 보스/엘리트 = 충 숙주 / 펫 = 길들여진 충 / 6원소 = 충 6변종 / 강화 = 충 농축
- BULLET LANGUAGE = 탄환은 악의의 언어, 색은 충의 종류, 패링은 흐름을 읽고 역류시키는 행위
- CHAIN DRIVE = 사슬은 천계가 지옥에 박은 채굴 라인. 주인공은 모르고 그것을 동력으로 써왔다 (7장 폭로)

### 1-4 4중 비극 (주인공의 진실)
- 표층: 가족이 죽었다 / 중층: 살해당했다 / 심층: 친구가 살해했다
- 최심층: 친구는 충에 조종당했다. 친구를 미치게 한 것, 주인공이 친구를 죽이게 한 것, 그 절망으로 잠재악의가 폭발한 것, 그 폭발로 더 많은 사람을 죽인 것 - 전부 한 사람의 설계
- 게임 시작 시점 주인공 = 이미 학살자. 본인은 피해자라고 믿음

### 1-5 35보스 = 35사연 (검은신화 오공형)
- 35보스 = 35명의 한때 인간. 각자 충에 잠식된 사연
- 사연 표현: A 정적 이미지+텍스트 5~10초(큰 보스) / B 1초 인간 형체 컷(일반) / C 아레나가 잠시 멀쩡해지는 메모리 에코 1~2초
- 챕터 분배 [world_core]: 1 추락(농부/어부/어머니/노인/아이) 2 적응(병사/사제/상인/무희/학자) 3 발견(옛 영웅, 채굴시설 등장) 4 의심(네메시아 직속 사도) 5 폭로 시작(추방된 옛 천계 신) 6 배신의 그림자(친구/가족/옛 동료, 친구 보스전) 7 진실(지옥마왕 + 호위 + 네메시아)
- 떡밥 비율: 환경 오브젝트 50 / 적·보스 디자인 20 / 보스 사망 직전 한 줄 15 / 거점 대화 10 / 챕터 끝 컷신(30초 이내) 5
- 읽을 텍스트가 없어도 끝까지 진행 가능. 추적자도 무시하는 자도 7장에서 같은 충격

### 1-6 비주얼 랭귀지
- 채도 낮은 바탕 + 한 점의 강한 색(피/불/영혼광). 강한 색 = 흡수당하는 중, 곧 사라질 것
- 비대칭: 흡수한 쪽 비대, 빼앗긴 쪽 결손. 보스 = 가장 많이 흡수한 자 = 가장 비대하고 일그러진 자, 약점은 흡수기관
- 네메시아 예외: 홀로 정제된 형상. 등장 시 주변 환경이 일그러지지 않음 -> 무의식적 정체 폭로
