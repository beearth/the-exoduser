## 1. 현행(v6) 구조 진단

### 1-1. 우선순위 없음 (가장 심각)
- `_checkPetDialogue()`가 매 프레임 `_petSayCD(...)`를 **코드 작성 순서대로** 실행.
- 먼저 조건 통과한 대사가 말풍선을 점유하고 `_petGlobalCD=900`(15초)로 **나머지 전부 차단**.
- 결과: **우선순위 = 코드 줄 번호**(자의적). 사소한 idle 팁 하나가 중요한 전투 경고를 15초간 묵살.
- **urgent끼리도 우선순위 없음**: 한 프레임에 `hp_critical`(HP<10%)과 `boss_groggy`가 동시 참이면, 코드상 나중 줄(`boss_groggy`)이 앞 대사를 덮어씀 → **생존 경고가 밀림**.

### 1-2. 상황 부정합
- `boss_elem`: 내 무기가 **이미 약점을 찌르고 있어도** 30초마다 "속성 바꿔" 발동.
- `enemy_ice`: 화면 반대편 잡몹 하나만 얼어도 발동(플레이어와 무관).
- `resource_*`: HP/MP/ST 중 **실제로 부족한 자원**을 안 짚고 뭉뚱그림.
- idle 팁: 현재 상황과 **완전 무관한 랜덤**.

### 1-3. 디테일 없음
- 동적 텍스트 전무. 보스 인트로가 챕터 index 고정 문구("벌레의 왕")라 **실제 보스 이름/속성** 미반영.
- 속성 힌트도 "화염엔 빙결!" 일반론 — 지금 이 보스가 무슨 속성인지 안 알려줌.

## 2. v7 신규 아키텍처

### 2-1. 우선순위 디스패처 (핵심)
**즉시발동 → 프레임당 최고 우선순위 1건 선택**으로 교체.

- 각 후보 대사는 발동 대신 **입찰**한다: `_petBid(tier, weight, id, who, txt, dur, cdSec, pair...)`
- 입찰은 **단일 재사용 슬롯 객체**(`_PB`)의 필드를 제자리 덮어씀 → **매 프레임 신규 할당 0** (핫패스 규칙 준수).
- 더 높은 `tier`, 동일 tier면 더 높은 `weight`가 이긴다.
- 프레임 끝에서 승자 1건만 `_petSay`. 개별 CD·글로벌 CD는 발동 시점에만 검사.

```
슬롯 _PB = {tier:-1, weight:0, id, who, txt, dur, cd, pw, pt, pd}  // 모듈 상수, 재사용
_petBid(tier,weight,...):
  if(tier<_PB.tier) return           // 더 낮으면 무시
  if(tier===_PB.tier && weight<=_PB.weight) return
  if(_petDlgCD[id]>0) return          // 개별 쿨 중이면 입찰 불가
  _PB.tier=tier; _PB.weight=weight; ...필드 덮어쓰기...
프레임 끝:
  if(_PB.tier>=0) _petFireBid()       // 티어별 글로벌쿨 검사 후 발동
  _PB.tier=-1                          // 리셋(할당 없음)
```

### 2-4. 상황정합 게이팅 (문제 ②)
- `boss_elem`: **내 무기 속성이 보스 약점을 안 찌를 때만** 입찰. 이미 찌르면 침묵.
- `enemy_ice`: **플레이어 반경 300px 내** 빙결 적이 있을 때만.
- `resource_*`: 실제 부족한 자원명(HP/MP/ST)을 짚어 분기.
- idle 팁: 컨텍스트 편향 풀 — 미소비 SP/AP 있으면 해당 팁 가중, 악의 부족하면 분해 팁 가중.

### 2-5. 디테일 강화 (문제 ③)
**런타임 문자열 조립은 번역을 깨므로 지양.** 두 갈래로 처리:

- **(A) 문구 구체화(기본)**: 키는 문장 단위 유지(번역 깔끔), 내용만 상황을 또렷이 반영하게 재작성. 예) 챕터별 보스 인트로를 그 보스의 실제 정체·속성·주의 패턴이 드러나게.
- **(B) 이름 토큰 주입(선택)**: 이미 `_T`로 개별 번역되는 **고유명(보스명/속성명)** 한 토큰만 고정 문장에 끼움. 예) `_T('이 녀석은 ')+elemName+_T(' 속성이다.')`. 조각 키가 늘지만 진짜 "지금 이 보스" 느낌. → 보스 인트로·속성 힌트에 한해 적용 검토.

## 4. 디테일 재작성 대상 (문제 ③ 집중)

우선 재작성 후보(전면 재설계지만 임팩트 큰 것부터):

1. **보스 인트로 7종** → 디테일(B) 적용. 챕터 고정 → 실제 보스명+속성+핵심 주의패턴 1개.
2. **속성 힌트(boss_elem)** → 지금 보스 속성명 주입 + 카운터 속성 지목.
3. **챕터 진입/환경 14종** → 각 챕터의 실제 환경 위협(맵 오브젝트/기믹) 반영.
4. **자원 힌트** → 부족 자원별 전용 문구(HP/MP/ST 각각).
5. **idle 팁 17종** → 컨텍스트 편향 + 오래된 팁 정리(중복/사문화 제거).

> 실제 문구(한/영/26개국어)는 승인 후 4장을 확장하여 확정. 문구 변경 시 **26개 lang 파일 키 갱신** 필수.
