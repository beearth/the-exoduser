### 함수
| 함수 | 용도 | 동작 |
|---|---|---|
| `_petTierOf(id)` | id→티어 추론 | 접두 매칭(무할당). 예외: `boss_elem`=T3, `enh_hint`=T1, `chapter_clear_`=T2 |
| `_petBidCD(id,...)` | **프레임 경쟁 입찰** | 즉시 발동 안 함. 최고 티어 1건만 슬롯(`_PB`)에 남김. 동일티어는 코드순 먼저 우선 |
| `_petSayUrgent(id,...)` | 생존(T5) | 프레임 내: T5 입찰(내부 weight `_PET_SURV_W`). 프레임 외(이벤트): 즉시 인터럽트 |
| `_petFireBid()` | 승자 발동 | 프레임 끝(및 생존 mid-fire)에 `_PB` 승자 1건 발동. T5는 현재 말풍선 강제종료 |
| `_petSayCD(id,...)` | 즉시 대사 | 튜토리얼·이벤트 콜백 전용. 티어별 글로벌쿨(`_petTierCD[]`) 준수 |

- **무할당**: `_PB` 단일 재사용 슬롯 + 접두 매칭 → 핫패스 신규할당 0.
- **호출 흐름**: `_checkPetDialogue` 시작 시 `_PB.tier=-1;_petInFrame=true` → 생존블록 입찰 → mid `_petFireBid()`(생존 인터럽트) → 경쟁블록 `_petBidCD` 입찰 → 끝에서 `_petFireBid()`(승자 발동).
- 생존 내부 우선순위 `_PET_SURV_W`: hp_critical100 > hp_oneshot95 > grab/aoe90 > stun80 > groggy70 > crisis_hp30 60 > warn_hp50 40.
- `id`: 대사 고유 키 / `who`: 선발 화자 (`crow`=핵터, `cat`=디로이) / `pairWho/pairTxt`: 티키타카(후발 대사)
