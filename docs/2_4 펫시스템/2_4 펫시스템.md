## 유령불꽃 시스템
- **크기**: 1~100 조절 가능 (ESC 설정 → 슬라이더, 기본값 20)
- **적 탐색 반경**: 800px
- **악의 소모**: 없음 (무료)
- **조명 효과**:
  - 메인 광원: 반경 200+(sz/100×600)px, 밝기 0.6~1.0, RGB(255,170,50)
  - 코어 광원: 메인의 40%, RGB(255,230,150)
  - 주변 광원: 메인의 130%, RGB(200,120,30)
  - 동적 광원 방식 (_pushLight) — 캐릭터 글로우와 동일 시스템, 자동으로 따라감
  - **토치 오버레이 조명** (destination-out 방식, 횃불과 동일):
    - 외곽 소프트 글로우: 반경 450px, alpha=flickr×0.45
    - 내곽 코어: 반경 220px, alpha=flickr×0.7
    - flickr 범위: 0.49~0.81 (sin 2파장 합성)
- **렌더링**: 고정 크기 불꽃
  - 번짐 글로우 헤일로: 반경 55px (#2288ff, alpha=0.18×flickr) + 반경 36px (#44bbff, alpha=0.12×flickr)
  - 불꽃 코어: 반경 14px (#44ccff) + 핵 반경 7px (#eeffff)
  - 날개: 좌우 ellipse, 펄럭임 sin(t×0.12)
  - 위로 올라가는 꼬리 파티클 8개 (#88eeff→#2288ff)
- **궤도**: cos(t×0.015+π/2) × 55px, 정현파 Y오프셋 (느린 타원)
- **세이브**: `game.irisSz` (G._irisSz)에 저장/로드
- **토글**: Y키 (BINDS.irisToggle = KeyY) — ON/OFF 전환, G._irisOff 플래그
  - ON 시: 플레이어 본체 광원 최소화 (800→60, 1.0→0.08) + 불꽃 _pushLight 3겹이 주 광원
  - OFF 시: 업데이트/렌더링/광원/토치오버레이 모두 중단, 악의 소모 없음

## [15] 빌드 힌트 — 스탯 소스 버그 수정 (2026-08-17) ✅ FIXED

> **위치**: `game.html` `_checkPetDialogue()` — mp_warn(`[?]`), 빌드 힌트 블록(`if(!G.bossAlive&&P.lv>=50&&G.frame%300===0)`).

**증상 (P1, 데모 몰입 저해)**: 펫의 빌드 코칭이 100% 오작동. STR/DEX/INT/LCK 힌트가 **한 번도 발동 안 됨**(죽은 기능), 동시에 lv50+에서 "VIT 좀 찍어! HP 너무 적어!" 나그가 **모든 빌드에서 상시 오발동**(str200·grit50 탱커에게도).

**근본 원인 (CONFIRMED)**: 스탯 시스템 리팩터로 배분 스탯이 `STATS.{str,dex,int,lck}`(+ 생존=STR/GRIT)로 이동하고 **VIT는 할당 UI(`STAT_DEF`)에서 제거**됐으나, 펫 AI는 구 필드 `P.a{str,dex,int,lck,vit}`를 계속 읽음. 이 필드들은 **코드 어디서도 기록되지 않아 항상 0** → 모든 비율 비교(`_s>_d*1.5` 등)가 `0>0`=false로 죽고, `_v<10`(=`P.avit`=0<10)은 항상 true라 VIT 나그가 상시 발동.

**수정 (최소·3곳)**:
1. mp_warn 판정: `P.aint/astr/adex` → `STATS.int/str/dex`.
2. 빌드 힌트 판정: `const _s=STATS.str||0,_d=STATS.dex||0,_i2=STATS.int||0,_l=STATS.lck||0;` (구 `P.a*` 제거, `_v` 삭제).
3. **`build_vit_low` 나그 제거**: VIT는 사탈 스탯(항상 0)이며, 생존력은 STR(+5HP)·GRIT·장비 등 복수 출처로 HP가 결정돼 단일 스탯 임계로 이식 불가 → 오조언 근절 위해 제거.

**검증 (Playwright, before/after 동일 harness, lv60, `_checkPetDialogue` 직접 구동)**:
| 빌드 | BEFORE 발동 | AFTER 발동 |
|---|---|---|
| STR(str100) | (힌트 없음) + `build_vit_low` | **`build_str`** / VIT 나그 없음 |
| INT(int100) | (없음) + `build_vit_low` | **`build_int`** / 없음 |
| LCK(str40·lck40) | (없음) + `build_vit_low` | **`build_str`+`build_lck_high`** / 없음 |
| TANK(str200·grit50) | **`build_vit_low` 오발동** | **`build_str`** / 오발동 없음 |
- pageerror 0, 게임 정상 로드·플레이·스테이지 전환 정상.

**번역 팔로우업 (미처리, 다른 세션 소유)**: `build_vit_low` 제거로 `docs/16번역·로컬라이제이션/번역대상_전체목록.md`의 관련 항목(예: 0889 "VIT 좀 찍어! HP 너무 적어!" 및 대응 crow 라인)이 **고아(orphan) 상태**가 됨. 해당 파일은 현재 타 세션이 편집 중 → **본 작업에서 미수정**. 번역 세션에서 해당 항목 정리(prune) 필요.

**향후 개선(선택)**: 실제 HP 기반(예: `P.mhp`/레벨 기대치) 생존력 힌트를 새로 설계하면 VIT 나그를 대체 가능(신규 휴리스틱 = 별건).
