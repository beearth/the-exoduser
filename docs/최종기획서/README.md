## 편집과 검수 기록

Word 두 파일은 `word/document.xml`만 수정했다. 원본 ZIP의 다른 구성요소·이미지·관계 파일은 바이트 동일을 확인했고, XML 파싱과 문서 재열기, 신규 전략 문구 및 기존 시스템 내용 보존을 검사했다. 변경 전 원본은 `tmp/support-20260930/backups/before-overall-plan-131449.zip`에 보존했다.

번들 DOCX 렌더러 실행은 `LibreOffice soffice.exe was not found on PATH`로 실패했다. 현재 런타임에 번들 LibreOffice 실행 파일이 없어 두 Word 파일의 실제 페이지 수·줄바꿈·표 넘침에 대한 시각 검수는 미완료다. 내용·패키지 검증을 레이아웃 검수로 대체하지 않는다.

`v4.0.docx`는 이전 버전으로 보존한다. 기존 `build_document.py`는 과거 경로·내용을 사용하는 생성 스크립트이므로 실행 결과가 이 전략 갱신을 포함한다고 간주하지 않는다. 다시 생성할 경우 공통 기획 기준과 최신 문서를 대조해 전략을 포함하고 전체 페이지를 검수해야 한다. 이번 수정으로 기존 문서의 다른 기술·콘텐츠 수량·가격·일정·성과가 재검증된 것은 아니다.
