## 1. 공간 원소 정의

### COMBAT BASIN (주 전투 분지)
- **역할**: 핵심 전투. 적 8~15 + 회피/대시 여유.
- **권장 크기**: 지름 **32~54타일**(1280~2160px). 대략 화면 세로(27타일)~1.3화면.
- **근거**: CH1 CENTRAL r1080(27타일반경=54직경), LOWER r880(44직경). 적 다수+대시 버스트(~1.6타일) 수용.
- **연결**: 입출 통로 **≥2개**(막다른 아레나 금지). 형태 비원형(가로/세로 김) 권장.

### SECONDARY BASIN (보조 분지)
- **역할**: 소규모 조우/전환 완충. 메인 리듬 사이 호흡.
- **권장 크기**: 지름 **20~30타일**(800~1200px).
- **연결**: 1~2 통로. 사이드포켓과 겸용 가능.

### CORRIDOR (연결로)
- **역할**: 이동·긴장·매복·공간전환. **대규모 전투 배치 금지.**
- **권장 폭**: **10~14타일**(400~560px). 최소 10 LOCK.
- **권장 길이**: 15~40타일. 완만한 곡선(직선복도 금지).
- **매복**: 좁은 목 1~2 포인트 소규모만.

### SIDE POCKET (사이드 포켓)
- **역할**: 탐험 보상(전리품/소환굴/이벤트).
- **권장 크기**: 18~28타일 폭.
- **연결 규칙 LOCK**: **진입로 ≥2**(막다른 길 금지). 목 폭 ≥10타일. 비대칭.
- **근거**: CH1 WEST(=CENTRAL+LOWER), EAST(=CENTRAL+UPPER).

### EVENT ZONE (이벤트)
- **역할**: 제단/스크립트/함정/보상 트리거.
- **권장 크기**: 12~20타일. 사이드포켓 or 분지 가장자리에 부착.

### MINIBOSS ZONE
- **역할**: COMBAT 정점. 예고형 공격 회피 공간 필요.
- **권장 크기**: 지름 **30~40타일**(1200~1600px). 탈출 통로 1(봉인 선택).

### BOSS ARENA (거대 보스)
- **역할**: 장보스전. **별도 맵 로딩**(genBossArena 128×108, 중심64,54).
- **아레나 타입**(hell별): 원형/대성당/십자/팔각/타원 (`_BOSS_ARENA_TYPE`).
- **연결**: 탐험 맵 → 관문 → 로딩 → 아레나. 필드에 두지 않음.

### GATE ZONE (관문)
- **역할**: 층/스테이지 경계 로딩 지점. 병목 연출.
- **권장 크기**: **6~10타일 초크**. 은유: 성문/동굴/거대뿌리/승강/봉인문.
- **근거**: 보스 게이트 12시(cx100,cy18), 80% 처치 개방(`35591`).

### RIM (경계)
- **역할**: PLAY↔OUTER 경계 자연화. invisible wall 체감 제거.
- **권장 깊이**: **6~20타일 밴드**(절벽/뼈/폐허/독늪). 대형 오브젝트 간격 ≥20타일.
- **구현**: 비충돌 or 충돌메타 오브젝트 + `[EDGE-FADE]`(`9801`).

### OUTER (외곽 세계)
- **역할**: 세계 스케일. 타일 footprint 없음(패럴랙스/vista).
- **상세**: `OUTER_DEPTH_MODEL.md`.

## 2. 공간 비율 (스테이지 전체)

| 레이어 | 목표 |
|---|---|
| PLAY (분지+통로+포켓) | 65~72% 개활 |
| RIM | 15~25% |
| OUTER | 시각 전용(footprint 0) |

- 개활도 65~72% = CH1 실측. 이 밴드 유지 시 "넓은 전투 + 좁은 길" 리듬 성립.

## 3. 연결 규칙 (그래프 무결성)

1. START는 첫 COMBAT BASIN까지 짧은 CORRIDOR로.
2. 모든 COMBAT BASIN은 **≥2 통로**(진행+우회/백트래킹).
3. SIDE POCKET·EVENT는 **≥2 진입**(막다른 길 0).
4. CORRIDOR는 분지 사이에만. 분지-분지 직결(통로 없이) 금지.
5. 통로 폭 **≥10타일** 절대. GATE만 예외(6~10 초크, 의도적 병목).
6. 메인 루트는 지그재그(직선 x축 복도 금지). CH1: START→LOWER(서)→CENTRAL(동)→UPPER(서)→EXIT.

## 4. 표준 스테이지 리듬 (권장)

```
START → CORRIDOR → COMBAT BASIN A ─(SIDE POCKET)
      → CORRIDOR → COMBAT BASIN B ─(EVENT)
      → CORRIDOR → SECONDARY BASIN / MINIBOSS
      → CORRIDOR → COMBAT BASIN C
      → GATE → [BOSS ARENA 로딩] → EXIT(상승 통로)
```
- 스테이지당 COMBAT BASIN 2~4개 권장(200×200 = 세로 7.4화면이라 3~4개 여유).
