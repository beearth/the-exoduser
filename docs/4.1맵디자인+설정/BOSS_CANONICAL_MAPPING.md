> **역할**: UD-MAP-02 해소. 보스의 **Design/Lore Identity**(바이블 서사)와 **Runtime ID**(HELL_BOSSES 구현체)를 **분리·매핑**한다. **어느 쪽도 삭제/덮어쓰지 않는다.**
> **결정(LOCKED)**: 서사 identity = design canonical. 구현체 = runtime canonical. 둘은 아래 매핑 테이블로 연결. 불일치는 "MAPPING NOTE"로 보존(충돌 아님).
> **상태**: 2026-08-23. 코드 변경 없음. 근거: `game.html` HELL_BOSSES(13733–13741)/`_BOSS_MOVESET`(8717–8761), `8.1보스디자인바이블/`, MAP/MASTER BIBLE.

## 0. 이중 정체성 원칙

- **Lore Identity (design canonical)**: 바이블의 서사 보스 — 챕터당 장보스 1 + 미니보스들 (총 19종). 세계관·연출·아트 방향의 진실.
- **Runtime ID (runtime canonical)**: `HELL_BOSSES[hell][floor]` — si마다 고유 아레나 보스 1종 (총 35종). 코드 동작의 진실.
- **원칙**: 서사 19 ⊂ 런타임 35. 런타임이 중간 층을 채우는 이름을 **추가**한다(로어에 없는 보스). 삭제·통합 없이 **매핑만** 유지.

## 3. 매핑 관찰 (전부 보존, 해소 대상 아님)

1. **런타임 > 로어**: 로어 19 named(미니+장보스) ⊂ 런타임 35. runtime-only 14종(점액 괴수/살벽의 군주/얼음 망령/얼어붙은 감시자/화염 악마/불기둥 수호자/화염 전사/불벌레 군주/전쟁의 잔해/악마 사령관/살점의 수호자/인간뼈 감시자/뒤틀린 자/검은 성의 수호자) = 로어 엔트리 없음. → **로어 보강 후보**(디자인 시 서사 부여).
2. **si2 명칭 드리프트**: runtime/BOSS_02=지옥기형, lore/BATTLE_SETTINGS §6=숲의 사냥꾼. → 표기 통일은 후속 UD.
3. **si0 이중보스**: 필드보스 심연의 앵글러(`_fbTick` 51979, si0 전용, 2500px 게이트, HP=1800+lv×350) ≠ 아레나 보스 흑요염 파괴자. HELL_BOSSES/_BOSS_MOVESET에 앵글러 없음.
4. **흑요염 파괴자**=2026-05-09 런타임 추가 first-boss(로어 19 부재). 구 로어 si0=눈나무의 파수꾼(보류).
5. **전용 보스문서 hell0만**(si0–2). hell1–6 per-boss 문서 없음 → 후속 제작 대상.
