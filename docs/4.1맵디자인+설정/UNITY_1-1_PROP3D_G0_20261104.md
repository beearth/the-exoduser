## 2. 제작 방법

1. **입력:** 웹 원화를 그대로 쓴다. 합성 원화(캠프)는 요소별로 잘라 각각 입력한다.
   - 캠프 분해: 텐트, 녹색 상자, 모닥불 돌 고리, 붉은 살덩이 꼬투리 무리, 뿌리.
   - 배치는 원화의 상대 위치를 웹 좌표 안에서 그대로 재현한다.
2. **생성:** 이미지 → 3D(Meshy 최신 모델, 원화 텍스처, PBR, 30k 삼각형 이하). Tripo는 같은 대상의 대체 경로로만 쓴다.
3. **정리:** 크기는 원 카드 높이에 맞춘다. 피벗은 바닥에 두고 지형에 2~8cm 묻는다. 접촉 그림자를 넣는다. 색은 원 카드 평균색에 맞추고, 원화에 구워진 명암은 유지한다.
4. **배치:** 같은 웹 좌표에 놓는다. 카드는 끄고, 기존 투명화(시야선 원형 구멍) 대상에 포함한다.
5. **유지할 카드:** 원경 숲 실루엣, 고사리·덤불, 바닥 타일, 낙엽. 레퍼런스 게임들도 이것들은 카드나 데칼로 둔다.
6. **위험과 대비**
   - 10-31 A2 속빈 거목 1차가 '판형'(두께 없는 판)으로 실패했다. 그때 원화 크롭 + t2.5 SmartTopology 무텍스처로 바꿔 형체를 얻었다.
   - 그래서 시험 3종을 먼저 만든다. 판형·녹은 형태·톤 불일치가 2종 이상이면, 남은 종류를 만들지 않고 방법을 바꾼다. 대안은 크롭 무텍스처 + Unity 원화 투영 텍스처, 또는 ProBuilder 조립이다.

## 4. 합격선 (종류마다)

1. 34° 실제 게임 카메라, 1x, 같은 자리에서 **카드 | 3D**를 나란히 놓았을 때 원화 느낌(색·재질·실루엣)을 유지하면서 입체로 읽힌다. 영웅이 둘레를 돌 때 종이처럼 보이지 않는다.
2. 판형 0: 측면 두께가 보인다.
3. 접지: 떠 있는 물체 0. 접촉 그림자가 있다.
4. 3x 크롭에서 점·잔점 0.
5. 먼 적 보임이 유지된다. 시야선 투명화가 작동한다.
6. 성능: 3840 캠프 fps 하락이 10% 이내다. 삼각형 예산은 소품 30k, 나무 60k 이하다.
7. 중단 조건: 같은 방법으로 만든 두 후보가 같은 핵심 결함으로 FAIL이면 방법을 바꾼다.
