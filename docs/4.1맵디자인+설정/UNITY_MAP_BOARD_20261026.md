## 5. 판정

1. 구현 세션이 1920×1080 게임 카메라 컷, 1x 확대 크롭, 같은 좌표의 Godot C/D 비교, 충돌 오버레이 컷, 30초 FPS를 제출한다.
2. 맵 총괄이 스크린샷을 직접 보고 G1~G8로 판정한다. 평균색 같은 수치는 기록일 뿐 통과 조건이 아니다. 통과 조건은 "음습하고 아름다운 지옥으로 매력 있게 보이는가"이다.
3. 톤·재질 판단이 아트 바이블과 엇갈리면 디자인 총괄 판정을 따른다.
4. 대표 컷(R2 G8, 전체 8컷)은 사용자가 최종 판정한다.

## 6. 독성 늪·독성 강 — CH1-1 역동성 (사용자 지시 2026-10-26)

사용자: "게임에는 항상 역동성이 들어가야 맵이 살아있는 느낌이 든다. 1-1에는 독성 늪을 많이 만들어서 기포가 터지고 뭔가 썩어서 흐물거리게 해서 살려보자", "사이드에 독성 강이 흐르게 하는 것도 좋을 듯".

### 6.1 배치 원칙

| 항목 | 내용 |
|---|---|
| 독성 늪 | 여러 곳. 1순위 = 비보행 구역(53점 경계 바깥 띠, 포켓 안쪽 함몰, 외곽 덩어리 사이 틈). 기존 독 구덩이(R7)·제단 독액 도랑(R5)은 같은 재질로 다시 만든다 |
| 독성 강 | 서·동 양 사이드, 보행 바닥 경계와 외곽 덩어리 사이 띠를 따라 남→북으로 흐른다. 외곽 벽 균열에서 흘러들어오는 지류·작은 낙차를 군데군데 둔다 |
| 충돌 | **바꾸지 않는다.** 보행 바닥 위에 피해를 주는 늪을 새로 놓는 것은 게임 규칙 변경이라 웹과 달라진다 → 사용자 결정 전까지 보행 바닥 위에는 놓지 않는다. 보행 바닥 가장자리는 젖은 기슭·흘러넘친 얇은 막(시각 전용, 피해 없음)까지만 |
| 지역 리듬 | 지역마다 늪 크기·밀도를 다르게: R1은 작게(첫 인상), R2·R6 사이드는 강이 화면 양끝을 흐름, R5 제단 주변·R7 측면은 큰 늪. 모든 늪이 같은 원형으로 보이지 않게 모양을 지형에 맞춘다 |

### 6.2 움직임 (흐물거림·기포·흐름)

| # | 요소 | 구현 방식 |
|---|---|---|
| T1 | 늪 표면 | 깊이 따라 색이 짙어지는 반투명 표면, 느린 이중 흐름맵, 표면을 덮는 썩은 막(scum)이 갈라졌다 다시 덮임. 기슭은 젖은 광택 |
| T2 | 기포 | 표면 아래서 부풀어 오름 → 터짐 → 동심원 물결 + 작은 방울 튐 + 짧은 증기. 크기·주기·위치를 개체마다 다르게(L9). GPU 인스턴싱, 화면당 상한 |
| T3 | 썩어 흐물거림 | 늪 가장자리 살덩이·뿌리가 정점 셰이더로 느리게 처지고 출렁임, 떠다니는 썩은 덩어리가 천천히 떠오르다 가라앉음, 기슭 살막이 녹아 흘러내림 |
| T4 | 독성 강 흐름 | 흐름 방향 따라 스크롤하는 리본 메시, 굽이·폭 변화, 떠내려가는 부유물, 지류 합류부 거품, 낙차 지점 물보라 |
| T5 | 빛·대기 | 표면이 약하게 스스로 빛나 주변 바닥을 물들이고(소수 광원), 낮게 깔린 독기 안개가 표면 위를 흐름 |
| T6 | 소리 연계 | 기포 터짐·흐름 소리는 사운드 총괄에 위치 정보만 넘긴다(구현은 사운드 쪽) |

### 6.3 색과 가독성

- 독액 색은 아트 바이블에서 디자인 총괄이 정한다. CH1 바탕이 붉은 생체지옥이므로 대비 색(병든 황록 계열 후보)은 **채도·명도를 눌러** 쓰고, 기포가 터질 때만 잠깐 밝게 한다.
- 적 탄막·독 계열 스킬 VFX와 색이 겹치지 않아야 한다(G2). 늪이 많아도 화면 전체가 초록으로 덮이면 RETOUCH.

### 6.4 완료 조건

- START·R2 사이드·R5 제단 3컷 1920×1080 + 1x 크롭, 정지 화면이 아니라 **5초 영상 또는 연속 프레임 6장**으로 움직임 확인(기포 터짐·흐물거림·강 흐름이 각각 보일 것).
- 충돌 오버레이 컷에서 보행 영역 변화 0.
- 30초 FPS(늪·강 켬/끔 비교).
- 판정: "맵이 살아 숨쉬는가, 그러면서 전투 피사체가 먼저 읽히는가".
