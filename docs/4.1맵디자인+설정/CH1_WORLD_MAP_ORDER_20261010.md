근거는 현행 `CH1_1_PRODUCTION_FINISH_20260916.md`와 `CH1_1_COMPOSE_초안.md` CURRENT RUNTIME이다. 기존 nav·중앙 우회·진행 조건을 보존한다. 1-2의 ID·입구/출구·진행 조건은 그 정본의 연결 관련 범위를 처음 확인하며 발명하지 않는다.

지금 병렬 제작할 산출은 독립 world 연결 manifest와 원본 보존 1-1 source-ground/nav/높이 등록·배치 후보다. manifest에 검증된 areaID·region graph·지역 scene/resource 참조·입구/출구 대응·waypoint 발견/활성 조건·지역 지도 표시·필요 자원을 담는다. 전체 지역 목록은 정본으로 확인된 ID만 작성하고, 첫 두 지역 외 실제 소비되지 않은 지역은 미구현으로 표시한다.

미확정 엔진 필드는 `PENDING_ENGINE_CONTRACT`로 남기고 엔진팀과 합의한다. 맵 설계와 geometry/height/navigation 도구 구현을 혼동하지 않는다. 허용된 별도 후보 외 원PNG·원scene·nav·LOCK·전투·save를 변경하지 않는다. 새 원화·게임용 모델 제작은 해당 도구의 실제 인수 뒤 별도 한 범위로 배정한다.

PoE는 지역 연결·지도·활성 waypoint 구조를 참고한다. 활성화 후 이동 가능한 구분은 [GGG 공식 안내](https://www.pathofexile.com/forum/view-thread/46046)를 참고한 본 pilot 규칙이며 PoE의 외형·완성 지도·최신 전체 시스템을 복사한다는 뜻이 아니다.

계약 확정 뒤 실제 입력으로 지역 지도·waypoint 활성·1-1↔1-2 이동을 시험한다. JSON/BFS/좌표 주입은 실제 이동을 대신하지 않는다. §23 MAP PRODUCTION REPORT·VISUAL VERDICT와 새 카메라 증거로 관측·미구현·미검수를 구분한다. 무조건 전체 원화 확대·20px 일률 이동0, 기존 r9 Hell Rift/완료 부분주행 재실행0. 초안·전달·기술 PASS는 완성맵 인수가 아니다.
