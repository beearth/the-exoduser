## 4. 베이스 고정 및 부분 편집 절차

1. 공간: 넓은 공터·남북 진행·외곽 랜드마크를 확인하고 작업본을 별도로 보존한다.
2. 레이어: 공간 기준 / 피부 지면 / 동맥 / 외곽 부패 고목 / 생체 조직 / 구덩이 / 접촉 그림자·오염 / 움직임을 구분한다. 이 구분은 제작 계획이며 현재 파일에 모두 존재한다는 뜻이 아니다.
3. 선택: 수정할 구역을 자르고 좌표·크기·보호할 영역을 기록한다. 콘셉트가 틀린 식생은 해당 영역에서 교체한다.
4. 편집: 실제 베이스 이미지를 참조 입력으로 연결한다. 목질·피부·생체조직의 형태와 접지를 먼저 해결하고 작은 장식은 마지막에 더한다.
5. 합성: 수정 레이어·알파/마스크·원본을 각각 보존한다. 지정 영역 밖 변화와 경계 접합을 확인한다.
6. 비교: 같은 위치·크기로 전후 확대와 전체맵을 함께 본다. 좁은 전투 공간·싱싱한 식생이 재등장하면 재작업한다.
7. 런타임: 원화가 잡힌 뒤 collision/높이/동선 정합, 실제8카메라, 다수 적·탄·VFX 가독성과 종주를 별도로 확인한다.
