## 컷별 촬영 계약

1. Unity 후보와 기존 Godot의 초점·카메라 yaw/pitch/distance/zoom, 1920×1080을 맞춘다. 지면 초점 기준 1유닛=1px 매핑과 Z 반사 규칙을 유지한다.
2. 후보마다 전체 화면 1장과 1배 크롭 3장(플레이어 접지, 외곽 구조, 피부 바닥)을 보존한다. 카메라 위치가 바뀌었을 때 나무·뿌리·벽의 가림이 달라지는지 추가 측면 컷에서 확인한다.
3. S1의 비교 화면은 지면 평면 청크·나무 빌보드·밝게 끊기는 mass가 남아 있어 **RETOUCH**다. S2에서 같은 구도의 전후 컷으로 실제 메시, 노멀, 접촉 그림자, 재질 경계의 차이를 보여야 한다.
4. 시각 게이트 뒤 기본 카메라로 24적 이상 실제 전투, 조명 효과, 스킬 타격, 이동·회피를 촬영한다. 적 식별과 길의 경계가 무너지면 수정한다. 스크립트로 적을 숨긴 정지 캡처를 전투 증거로 사용하지 않는다.
5. 충돌 오버레이와 보행 QA에서 `canMv/isW`와 보이는 지면 경계가 일치해야 한다. 6시 시작→12시 출구, 양측 우회가 열려 있어야 한다.
6. 성능은 Windows 실제 빌드에서 정지 장면 30초 평균·최저 1초·순간 최저를 기록하고, 전투에서는 별도 측정한다. 스팀 이미지 선별은 실플레이 화면과 시각 게이트 통과 이후다.
