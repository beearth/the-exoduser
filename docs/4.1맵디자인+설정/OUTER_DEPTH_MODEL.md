# OUTER DEPTH MODEL — 외곽 심도 모델 (Section E)

> **역할**: OUTER를 3계층(OUTER-A/B/C)으로 정의. 각 계층의 시각 역할·gameplay 영향 여부.
> **주의**: 구현 수단은 **LOCK하지 않는다.** 현재 runtime 가능 후보와 risk만 기록.
> **상태**: 2026-08-23. 코드 변경 없음.

---

## 0. OUTER란

PLAY(플레이 가능)와 RIM(경계) 너머, **보이지만 플레이하지 않는 세계**. 세계의 스케일·수직 상승감·거대보스 존재감을 만든다. 타일 footprint 0.

---

## 1. 3계층 정의

### OUTER-A — 근외곽 (Near Outer)
- **시각 역할**: RIM 바로 너머. 절벽 아래 심연, 방금 지나온 하층, 인접 지형. 패럴랙스 배속 중(0.3~0.5).
- **gameplay 영향**: **없음**(진입 불가). 단 낙사 연출/시야 단서로 상승감 제공(`VERTICAL_ASCENT_LANGUAGE §3`).
- **내용**: 심연/용암 균열/하층 조망/거대 뿌리 하단.

### OUTER-B — 중외곽 (Mid Outer)
- **시각 역할**: 원경 지형·구조물. 패럴랙스 배속 저(0.15~0.3). 거대 실루엣(지옥성/거대 생물/시체 산/폐허 도시).
- **gameplay 영향**: **없음**. 거대보스 LADDER-1 실루엣이 여기 배치(`GIANT_BOSS_PRESENCE_LADDER §1`).
- **내용**: 다음 층 목표 실루엣, 거대보스 원경, 군단 대열.

### OUTER-C — 원외곽 (Far Outer / Sky)
- **시각 역할**: 최원경·하늘·대기. 패럴랙스 배속 최저(0~0.15) 또는 고정. 깊이·분위기.
- **gameplay 영향**: **없음**.
- **내용**: 지옥 하늘/재/오로라/먼 화염 글로우/대기 그라디언트.

| 계층 | 배속 | 역할 | gameplay |
|---|---|---|---|
| OUTER-A | 0.3~0.5 | 근접 심도·하층 조망·낙사 | 없음(시야 단서) |
| OUTER-B | 0.15~0.3 | 거대 실루엣·목표·보스원경 | 없음(LADDER-1) |
| OUTER-C | 0~0.15 | 하늘·대기·최원경 | 없음 |

## 2. 현재 runtime 구현 후보 (LOCK 아님)

### 후보 1 — 비활성 패럴랙스 6레이어 재활성
- **위치**: config `game.html:9631–9636` (6레이어 `{cvs, parallax:0/.15/.3/.5/.75/.9, opacity}`). 현재 `_bgLayers=null`(`43539`)로 **하드 비활성**(void 바닥타일로 대체됨).
- **적합**: A/B/C 배속이 이미 config에 존재 → OUTER-A/B/C에 거의 1:1 매핑 가능.
- **risk**: 왜 비활성됐나(코너클리핑/바닥통일 `43539` 주석). 재활성 시 `_fillVoidWithFloor`([EDGE-FADE] `9781`)와 **경계 충돌** 가능 → RIM/void 렌더 순서 재조정 필요. 드리프트(패럴랙스-바닥 정합).

### 후보 2 — Vista 경로
- **위치**: `_isVistaMap()`(`9725`) → `_drawVistaWorld(X)`(`43593`). vista 타입 맵 전용 원경 렌더.
- **적합**: 이미 "원경 세계" 렌더 경로. 특정 스테이지(vista:1, 예 CH1-2)에서 OUTER 표현.
- **risk**: vista 맵 한정. 전 스테이지 일반화 시 성능/범위 미검증.

### 후보 3 — MAP_OBJS 대형 비충돌 오브젝트
- **위치**: `MAP_OBJS`(`14039`) + `_OBJ_META`. 거대 실루엣을 맵 오브젝트로.
- **적합**: OUTER-B 거대 실루엣·보스 신체일부(LADDER-3)에 적합. 개별 배치 제어.
- **risk**: 오브젝트 급증 시 draw/컬링/`_colObjs` 비용. 비충돌이라도 draw 리스트 증가.

### 후보 4 — 저해상도 캐시 캔버스 1~2장
- **무엇**: OUTER 전체를 사전 렌더한 저해상도 캔버스로 배속 drawImage(엔티티당 draw 아님).
- **적합**: 성능 최선(1~2 drawImage/frame). OUTER-B/C 정적 원경.
- **risk**: 동적 요소(움직이는 실루엣) 표현 제한 → LADDER-1 애니와 병행 필요.

## 3. 공통 risk / 제약

- **성능 봉인**: 평상시 140fps/700마리 60fps. OUTER draw 증가는 직접 위협 → 캐시 캔버스/저배속 권장, 엔티티당 draw 금지.
- **경계 정합**: `_fillVoidWithFloor`+[EDGE-FADE]와 OUTER 렌더 **순서·클리핑** 충돌 주의(`43539` 비활성 사유).
- **매 프레임 런타임 Y-sort 없음**(`CH1_MAP_KIT_OptionB §6`; 단 MAP_OBJS 빌드시 1회 Y정렬은 존재 = 데코 내부 앞뒤 순서 한정, OUTER 레이어링 무관) → OUTER는 항상 최후면 레이어로만(플레이어 앞 렌더 불가 = 전경 occluder 별도).
- **줌 0.80**(보스) 시 OUTER 노출 면적 증가 → 스케일/컬링 재검토.
- **원색 남발 금지**: OUTER 저채도 후퇴(아트 디렉션).

## 4. gameplay 영향 판정 (요약)

- OUTER-A/B/C **전부 gameplay 영향 없음**(진입 불가, 순수 시각). 유일 간접 영향 = 시야 단서/상승감/보스 존재감(심리적).
- 예외 후보: LADDER-3 신체일부가 RIM 경계에서 **부분 충돌/약공격 대상**이 될 수 있음 → 그 경우 RIM으로 승격(OUTER 아님).
