## 2. 제작 방식 (확정) — 1-1 동형

본편 35에리어 전부 `type:'field'`, **200×200 타일 (8000×8000px)**.
방·복도로 길을 그리지 않는다. 지형은 대형 충돌 오브젝트다.

런타임 (2026-08-16): `_getFixedMapForStage`가 `FIXED_MAPS[0]`을 복제한다. 던전 스텁(벽 미로)은 플레이에 안 쓴다. 소환굴 좌표만 스테이지 시드로 살짝 흔든다.
장식: `_CH_DECO[0~6]`. 필드(200×200 tileRLE)는 대형 28~56 (간격 760, 중앙 65%), scatter 40~90 (간격 400, 대형과 중첩 금지), 소형 50~140. 던전은 기존 캡.

2026-08-16 오브젝트 패스: 1-1 실루엣 다양성을 기준으로 대형 랜드마크 13종 추가 (우물/수레/갈비제단/등롱/우상 + 장별 hive/webp/iceshrine/icecage/brazier/banner/eyetotem/gargoyle). 파일·수치 표는 `맵오브젝트_에셋목록.md` 「장별 테마 대형」. rot 180/270 금지, flip만.

### 2.1 고정 골격 (1-1에서 그대로 복사)

`FIXED_MAPS[0]`이 마스터 템플릿이다. 새 맵은 이 값을 복사한 뒤 컨셉 레이어만 갈아끼운다.

| 항목 | 고정값 |
|------|--------|
| 크기 | `mw:200, mh:200` |
| tileRLE | `[1,40000]` 전바닥 |
| 시작 | 6시 `player_start` (cx 100, cy 190 부근) |
| 보스문 | 12시 (cx 100, cy 18 부근) |
| 방 메타 | start / combat×3 / forge / boss — 스폰 앵커용. 벽은 안 그림 |
| 소환굴 | 9개 전후 (S/M/L 혼합, 간격 500px, 최소 6 최대 15) |
| 생성 | `genFromTemplate` + tileRLE |
| 렌더 | 스트리밍 |
| 클리어 | 처치 80% → 지옥문 → 보스 아레나 (아레나는 본맵과 별개) |

### 2.2 컨셉 레이어 (맵마다 다름)

같은 벌판이 다른 장소로 읽히게 하는 6칸. **이 6칸이 안 바뀌면 복붙은 실패다.**

| # | 레이어 | 1-1 값 | 바꾸는 법 |
|---|--------|--------|-----------|

| 2 | 대형 충돌 (지형) | 저주나무 12종 | 장 테마 대형 8+ (얼음기둥, 알주머니, 성벽잔해…) |
| 3 | 랜드마크 | 중앙 3D 용해골 + 시작 근처 2D 해골 | 맵당 **다른** 유니크 1~2. `G.stage===0` 하드코딩 금지, 데이터로 |

### 2.3 장 안에서 컨셉이 커지는 방식

타입을 바꾸지 않고 **밀도·랜드마크·기믹**만 올린다.

| 층 | 역할 | 밀도 | 기믹 |
|----|------|------|------|

## 5. 제작 파이프라인 (맵 하나 만드는 순서)

1장에서 검증된 순서. 새 장도 동일.

```
A. FIXED_MAPS[0] 복사 → si만 바꿈 (200×200, tileRLE [1,40000], 6시/12시)
B. 소환굴 좌표만 시드 다르게 (개수 9 전후, 간격 500px)
C. 컨셉 6칸 적용: 바닥 / 대형충돌 / 랜드마크 / 기믹 / 밀도 / 팔레트

E. maps_data.js FIXED_MAPS[si] 교체
F. STAGES[si] = {type:'field', mw:200, mh:200}
G. 스트리밍으로 6시→12시 보행 검수 (막힘·끼임·빈 벌판)
H. 본 문서 완성 칸 갱신
```

한 장 만드는 시간 목표: CH1은 에셋 있으므로 **컨셉 배치만**. 2장부터는 바닥2+대형8+랜드마크1이 선행.

- 런타임 에셋은 `assets/map/ch{N}/`만
- `floor_objects/` 비충돌, `collision/` 충돌
- `assets/objects/`는 창고. 런타임 로드 금지

- 통로 폭 5 미만 + 대형 오브젝트 = 소프트락. 게이트 보호 규칙을 기믹 타일에도 적용

## 9.5 에디터 — 새로 만들지 말 것 (2026-08-16)

**결론: 맵 에디터를 새로 만들지 않는다.** 기존 2개를 쓰고, 부족한 버튼만 얹는다.

### 지금 있는 것

| 파일 | 역할 | 상태 |
|------|------|------|
| `editor.html` | **레이아웃 에디터 (정본)**. 타일 0~3, 오브젝트, 소환굴, genSnake/genHoriz/grid, FIXED_MAPS 내보내기 | 1-1 포함 35맵이 이 파이프로 나옴 |
| `tile-texture-editor.html` | **텍스처 스탬프**. 바닥 PNG 칠하기, 레이어, PNG 내보내기 | 있음. 가이드 URL과 동일 |
| `docs/4.1맵디자인+설정/tilemap-editor.html` | editor.html 포크 (스케일·타일링 UI 추가) | 분기본. 정본으로 쓰지 말 것 |

서버는 루트를 그대로 서빙한다. 접속:
- 레이아웃: `http://localhost:3333/editor.html`
- 텍스처: `http://localhost:3333/tile-texture-editor.html`

### 왜 새로 안 만드나

- 게임 입력 형식(`FIXED_MAPS` + `tileRLE` + `spawnHoles` + `rooms`)을 이미 내보낸다.
- field는 새 생성기가 아니라 **전바닥 칠하기**다. 브러시로 이미 가능.
- vert/horiz/grid 생성기가 에디터 안에 있다.
- 다시 짜면 P1(1장 완성)이 수 주 밀린다. 맵이 안 늘어난다.

### 부족한 것 = 패치 목록 (새 앱 아님)

| 우선 | 기능 | 이유 |
|------|------|------|
| P0 | `field 전바닥` 버튼 | 200×200을 브러시로 다 칠하지 않게 |
| P0 | 재생성 타입 분기 | 지금 `regenCurrent`가 horiz도 `genSnake`로 덮음 |
| P0 | **현재 스테이지만** 내보내기 | 전체 35 덤프 후 손으로 `maps_data.js` 붙이는 게 병목 |
| P1 | `FIXED_MAPS[0] 복제` 버튼 | 새 스테이지를 1-1 골격으로 |
| P1 | 포크 기능 흡수 | tilemap-editor의 오브젝트 스케일만 `editor.html`로 |
| P3 | 팔레트 5/7/8/9 (빙판/점액/독/불기둥) | 기믹 타일 런타임과 같이 |
| 안 함 | 존 에디터, 크기 변경, vert/grid 생성기로 본맵 | 동형 필드 정책과 충돌 |

`전체재생성`은 35맵 스텁을 한 번에 갈아엎는다. field 완성맵을 지우므로 **실사용 금지**.
