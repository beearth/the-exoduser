## 1. 키워드 해석

**"음습하고 아름다운 지옥"** = 축축한 생체 질감 + 그림 같은 빛의 명암 리듬.

| 해야 한다 | 하면 안 된다 |
|---|---|
| 같은 어둠 안에서 **색상**으로 지옥을 말한다: 바닥은 옥스블러드(붉은 갈색), 외곽은 멍든 장밋빛 살·상아 힘줄·병든 황록 이끼 | 명도만 맞추고 색을 잃는다 → 회갈 진흙 (슬라이스 v2) |
| 습기는 **재질별로 다르게**: 살·피·독액은 번들, 껍질·뼈는 무광, 바닥 중앙은 축축한 반무광 | 화면 전체를 번들거리게 하거나(플라스틱), 전부 무광으로 말린다(마른 흙) |
| 빛은 **웅덩이**로: 진홍·독액·안개광 3색이 화면 가장자리에서 리듬을 만들고, 사이는 어둡게 남긴다 | 화면 전체를 고르게 밝히거나, 붉은 조명을 화면 가득 칠한다 |
| 썩음과 생장이 같이 있다: 썩은 껍질 사이로 살이 부풀고, 뿌리가 뼈를 감싸고, 이끼가 자란다 | 해골·내장 나열로 단순 공포를 만든다 |
| 중앙 전투면은 **고요하게**, 디테일과 대비는 가장자리로 | 바닥 중앙에 촘촘한 뿌리·반사·데칼을 깔아 적·탄막을 묻는다 (제단 시안의 바닥 밀도) |
| 보라는 네메시아·디로이 전용, 주황 용암·불은 CH1 금지 | 인트로 컷의 보라 조명, 루트월드 v2의 용암 주황을 맵에 가져온다 |

## 4. 명도 스크립트 — 전투 가독성(G2)

환경은 아래 대역 안에서만 쓴다. **L50 이상은 전투 몫**(캐릭터 테두리광·적 눈·탄막·VFX·UI)으로 비워 둔다.

| 대역 | L | 내용 | 상한 |
|---|---|---|---|
| 깊은 그늘·공백 | 0~8 | 광원 사이 어둠, 벽 틈, 화면 밖 경계 | — |
| 전투 바닥 | 10~24 | 중앙값 12~16. 청크 변주 폭은 ±6 | 플레이어 주변 반경 400u에서 L30 넘는 면 0 |
| 외곽 벽 몸체 | 15~38 | 껍질·살·뿌리 | — |
| 광원 웅덩이 코어·안개 | 30~50 | 채도 높은 색으로. 중성 흰색 금지 | 웅덩이 코어는 화면 가장자리 쪽 |
| 젖은 반사·뼈 끝 | 45~60 | 긴 선 모양 반사, 힘줄·뼈 빛면 | L50 넘는 면적 화면 0.7% 이하, 전투 중앙 0 |
| **전투 예약** | 50~100 | 캐릭터 테두리광(L55 이상 목표), 적 눈, 탄막, VFX, UI | 환경이 이 대역을 쓰면 G2 RETOUCH |

`value_script_target_v1.jpg`: 목표 화면은 중앙 전투면이 한 대역(L8~24)으로 묶이고, L50 이상은 0.65%로 외곽 반사·뼈 끝과 상단 안개광 일부뿐이다. 참고로 슬라이스 v1·v2는 상위 1%가 L33·L29에서 끝난다. **반사 하이라이트가 전혀 없어서** 습기와 입체감이 안 읽혔다.

단, 목표 화면 상단의 차가운 안개광은 전투면을 L38~50까지 밝힌다. 실제 게임에서는 그 자리가 전투면이면 L30 이하로 누른다.

## 6. 독액 기준 (독성 늪·독성 강, 맵 보드 §6 연동)

게임의 독 VFX·피해 숫자는 **순녹색**이다(`#44dd44` 색상각 120°, `#88ff00` 88°, `#66cc44` 105°, `#33aa22` 112°, `#44cc00` 100°, 독가스 `#556633` 80°). 맵 독액은 이것과 겹치지 않도록 **황토·올리브 쪽**으로 둔다.

| 항목 | 기준 |
|---|---|
| 색상각 | 맵 독액·독무는 **40~65°**(병든 황록·올리브). **75° 이상 금지**. 75°부터 독 VFX 색과 겹친다. 이끼는 정적·어두운 면이므로 75°까지 허용 |
| 몸체 | `#3a2e0a`~`#4a3a0c` (L20~25, 채도 70~85%, 명도 V 25~30%). 깊은 곳일수록 어둡고 갈색 쪽(`#2a200a`) |
| 표면 막(scum) | `#4a4220`~`#5a5030` 무광 막. 갈라진 틈으로만 몸체 반사가 보임 |
| 상시 발광 | 표면이 약하게 스스로 빛남. **코어 L35 이하**, 주변 바닥 물들임 반경 120~200u, 세기는 붉은 광원의 절반 이하 |
| 기포 터짐 섬광 | `#a8a23a`까지 순간 밝아짐(L65 이하). 지속 0.15~0.3초, 지름 기포 크기의 2배 이내. 화면 안 동시 섬광 3개 이하 |
| 기슭 | 젖은 살·뿌리 재질(§5), 독액이 묻은 테두리는 `#5a5020` 반사 |
| 독무 | 바닥 독무 `#4a4a2e`, 높이 0~40u, 알파 .25 이하. 늪·벽 기슭에만 고이고 전투 중앙으로 흘러나와도 알파 .10 이하 |
| 면적 | 한 화면에서 독액 표면 **12% 이하**, 발광 면 3% 이하. 화면이 초록·노랑으로 덮이면 RETOUCH (맵 보드 §6.3) |
| 붉은 바탕과의 관계 | 독액은 붉은 생체지옥의 **보색 포인트**다. 진홍 광원 웅덩이와 같은 화면에 둘 때 서로 반대편 가장자리에 두어 색 리듬을 만든다(목표 START: 좌 독액·우 진홍) |

판정: 늪·강 컷 옆에 독 스킬 VFX가 터진 프레임을 같이 놓고, VFX가 먼저 읽히면 PASS.

## 7. 조명 원칙

### 7.1 칠한 빛 70% + 동적 조명 30%
- 큰 에셋(외곽 벽·랜드마크)에는 **칠한 빛 마스크**를 텍스처에 굽는다: 위쪽 밝음, 아래 20% AO, 가장자리 테두리광 띠. Meshy PBR 결과는 그대로 쓰지 않고 이 마스크로 한 번 다시 칠한다.
- 셰이더 최종색 = 칠한 빛 0.7 + 동적 조명 0.3. 동적 광원이 꺼져도 형태가 읽히고, 켜지면 색이 물든다.
- 구역 단위 "빛 칠하기" 레이어: 지면·벽에 걸치는 큰 빛 웅덩이·그늘 마스크(저해상도 텍스처 1장/구역).

### 7.2 광원 웅덩이 리듬
- 한 화면(1920×1080 게임 카메라)에 웅덩이 **3~4개**. 색은 진홍·독액·안개광 3종을 돌려 쓰고, 같은 색이 바로 붙지 않게 한다.
- 웅덩이 반경 180~320u. 웅덩이 사이에는 반경 1개 이상의 어둠(바닥 L10 이하)을 남긴다.
- 웅덩이 코어는 채도 높은 색(§3 광원 군). 중성 흰빛 금지.
- 웅덩이 위치는 주로 **화면 가장자리·외곽 기슭**이다. 전투 중앙은 플레이어 등불(따뜻한 약한 빛)만 둔다.

### 7.3 습기 반사 하이라이트
- 반사는 광원 웅덩이 안과 벽 기슭에서만 강하다. 웅덩이 밖 바닥은 반무광.
- 살·피·독액·힘줄은 광원 색을 그대로 반사한다. 진홍 웅덩이 옆 살은 붉게, 독액 옆 살은 황록으로 테두리가 선다.
- 반사 모양은 긴 선·면이다. 점 반짝임은 금지(§5 공통).

### 7.4 안개층
| 층 | 색 | 높이·위치 | 알파 |
|---|---|---|---|
| 바닥 독무 | `#4a4a2e` | 0~40u, 늪·벽 기슭 | ≤ .25 (전투 중앙 ≤ .10) |
| 중층 안개 | `#47434b` | 거리·높이, 외곽 벽 위를 반쯤 가림 | 외곽 ≤ .45 |
| 광원 산란 | 광원 색 | 광원 주변 halo, S3에서 볼류메트릭 | 코어 L50 넘지 않게 |

### 7.5 캐릭터 테두리광 (G8)
- 캐릭터·적은 가까운 웅덩이 색으로 테두리광을 받는다. 테두리 L55 이상이 목표다. 바닥 대역(L10~24)과 분리되는 핵심 장치다.

4. 살·피·독액에 **긴 반사**가 있고, 껍질·뼈는 무광이다.
5. 캐릭터가 바닥보다 먼저 읽힌다(테두리광).
6. 정지 화면이 아니다: 빛 숨쉬기·그림자·흔들림 중 2가지 이상이 보인다.
