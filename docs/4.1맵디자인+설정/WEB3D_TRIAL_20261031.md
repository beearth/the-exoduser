## 에셋과 목교 맵

R3 독립 납품 `woodbridge-r3/source/승인구도_납품동일.blend`를 읽기 전용으로 glTF 변환한다. 원본 18개 메시·1548개 배치를 공유 기하와 InstancedMesh로 묶는다. `tools/web3d-export.py`가 원본을 저장하지 않고 정확한 소스와 변환 영수증을 기록한다. 원본 FBX와 동일한 소스 메시를 사용하며 FBX의 별도 재수입 오차를 피한다. 원본 FBX 경로는 R3 납품 Models에 보존된다.

PBR은 모듈명으로 파일을 추측하지 않고 실제 Unity .mat→텍스처 .meta GUID를 해석한다. `tools/web3d-textures.cjs`가 BaseColor(거목2048, 나머지1024), Normal1024, ORM1024로 변환한다. ORM은 R=AO/G=1−Smoothness/B=Metallic. 데이터 맵은 선형, BaseColor만 sRGB. 공유 파단목질·식물 atlas를 실제 GUID대로 인수한다. 원본 SHA·정확한 경로는 `assets/web3d/texture-intake.json`.

목교의 큰 파손부·강둑 입구가 native 보행을 끊는 것을 샘플로 확인했다. 이 시험만 하부 보수 판자를 추가해 원본 상부 판자의 파손과 목질을 유지하면서 보행면을 만든다. 수면 위 지면을 .4m 간격으로 표본화하고, 시작점에서 연결된 셀만 native tileRLE로 전달한다. 나무 밑동은 보행에서 제외한다. 최종 nav 수치와 실제 검증 결과는 REPORT 및 scene.json을 따른다.
