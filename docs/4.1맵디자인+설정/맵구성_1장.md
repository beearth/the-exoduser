### 1-2 뒤틀린 숲길 (si 1)

**문장:** 헬스케이프 분지. 그림이 세계고, 걸을 곳만 흙이다.

방법 (다른 게임과 같음): **비스타 + 워크메쉬.**
1. 투시 그림은 세계 배경 (성·독늪·나무는 밟지 않음)
2. 걸을 수 있는 분지만 흙 타일 (타원 `basin` + 북쪽 통로)
3. 분지 가장자리는 알파로 그림에 녹임. 화면 정렬 사각형 금지

| 칸 | 값 |
|----|----|
| 비스타 | `void_vista.jpg` 월드 cover. `_drawVistaWorld` |
| 분지 | `{cx:100,cy:122,rx:80,ry:64}` + 게이트 통로. `_buildBasinRLE` |
| 흙 | 분지 안에만. 가장자리 4타일 페이드 |
| 벽 | 투명 (그림이 보임). 검정/해골벽 없음 |
| 코드 | `vista:1` + `basin` + `hand:1` |

## 4. 구현 / 검수

코드: `game.html` `_MAP_COMPOSE` + `initMapObjects`.
- `_MAP_COMPOSE[si]` 없으면 예전 균등 살포 (2~7장, 아직 기획 전)
- 1-1(`si=0`)은 드래곤 분기 유지. 통바닥 `[1,40000]`
- `hand:1`이면 통바닥 + compose `lm`/`mega`만. 자동 살포 없음. **중심 타일 → 커스텀 하나씩**
- 랜드마크 `scale` = 지정 sz / 메타 sz

테스트:
| URL | 봐야 할 것 |
|-----|------------|
| `?stage=0` | 용해골. 달라지면 실패 |
| `?stage=1` | 헬스케이프만 보임. 흙 사각형·검정 테두리 있으면 실패 |
| `?stage=2` | 거대 버섯이 주인공, 나무가 벽지가 아님 |
| `?stage=3` | 가운데가 비고 북쪽에 왕좌 |

다음 장(2장 벌레굴)은 이 네 구역이 문장대로 읽힌 뒤에 같은 형식으로 기획한다.
