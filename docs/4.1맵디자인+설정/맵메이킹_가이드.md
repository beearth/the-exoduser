## 1. 전체 구조

### 맵 생성 파이프라인
```
1) FIXED_MAPS (방/복도 레이아웃)  →  genFromTemplate()  →  좁은 통로 자동 확장 (폭5미만→양쪽+1)  →  tileRLE
   현재 런타임은 바닥/벽 이진화. P3(`맵유형_확장기획.md`)에서 용암/빙판/점액 타일값 보존 예정.
   field 타입은 전바닥 tileRLE (`[1, mw*mh]`). 방 카빙 없음.
2) 타일 텍스처 에디터            →  PNG 내보내기        →  게임 렌더링에서 바닥 위에 덮어쓰기
3) MAP_OBJS (오브젝트 배치)      →  에디터 or 자동배치  →  게임 렌더링
```

| 3 | 벽 엣지 | 벽/바닥 경계에 엣지 텍스처 |
| 4 | 데칼 | 알둥지, 고치, 점액 등 |

| 6 | 오버레이 | 바닥 노이즈, 벽 때 |
| 7 | MAP_OBJS | 나무, 뼈, 버섯, 거미줄 등 |

## 5. 에디터 사용법

### 기본 워크플로우
1. **맵 선택**: 왼쪽 장탭 → 스테이지 클릭
2. **타일 선택**: 팔레트에서 텍스처 클릭 (1~9 단축키)
3. **스탬프 찍기**: 캔버스에 클릭/드래그
4. **회전/반전**: R(90°), F(좌우), V(상하), 화살표키
5. **저장**: 💾현재맵 저장 or 💾전체저장 (.json)
6. **내보내기**: 📤 PNG내보내기 (게임 해상도 40px/tile)

### 단축키
| 키 | 기능 |
|----|------|
| S | 스탬프 도구 |
| E | 지우개 도구 |
| Space(홀드) | 이동 도구 |
| R | 90° 회전 |
| F | 좌우 반전 |
| V | 상하 반전 |
| [ / ] | 스탬프 크기 ±1타일 |
| 1~9 | 팔레트 선택 |
| Ctrl+Z | 되돌리기 |
| 마우스휠 | 줌 |
| 마우스 가운데 | 이동 |

### 레이어 시스템
- 배경(바닥), 엣지, 데칼 등 레이어 분리 가능
- 레이어 추가/삭제/병합/가시성
- 불투명도 조절 (스탬프 블렌딩)

### 맵 가이드
- 🗺️맵가이드 버튼: map_tiles.json의 tileRLE 데이터를 오버레이
- 벽/바닥 경계선 표시 → 텍스처 칠할 영역 확인

## 통로·포탈·게이트 보호 규칙 (절대)

1. **게이트·포탈 주변 반경 7타일(≈300px)은 강제 바닥** — caveSmooth·기둥·장애물 배치 이후에 실행
2. **좁은 통로(폭 5타일 미만)에 장애물·기둥·충격물 배치 금지** — 주변 바닥 타일 수 체크 후 배치
3. **connectivity 검증 전에 보호 실행** — 보호 안 하면 검증이 도달 불가로 판단해 벽 복구함
4. **출구/게이트/포탈 근처 400px 이내 대형 충돌 오브젝트 배치 금지** — 대형 장식, 유니크 오브젝트 모두 포함
5. **대형 충돌체 간 최소 간격 900px** (`_lgMinDist=900`), 최대 배치 수 `floor/400`개 (기존 600px, floor/200)
6. **유니크 충돌 오브젝트 간 최소 간격 880px** (`_uniMinDist=880`). `_gridNear`는 표시 반경으로 칸을 넓혀 중첩 금지
7. **코드 위치**: `game.html` markBossRoomAsIsolated() → caveSmooth → 기둥 배치 → **게이트 보호(여기)** → 출구 생성 → connectivity 검증 → 오브젝트 배치(출구 400px 보호)
