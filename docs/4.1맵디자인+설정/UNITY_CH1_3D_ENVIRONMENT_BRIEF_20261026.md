# CH1-1 실제 3D 맵 환경 제작 기준 — 2026-10-26

## 사용자 지시와 범위

- 사용자는 현재 스팀 후보 화면의 생동감·입체감·원근감이 부족하다고 판정했다. `No Rest for the Wicked`는 아트 품질 비교 기준이며 지형을 고지대로 만들라는 지시가 아니다. 고유 자산과 구도는 복제하지 않는다.
- **맵 환경을 실제 3D로 제작한다.** 평면 그림을 원근 카메라에 놓거나 2D 장식을 늘리는 것은 이 요구의 완료 조건이 아니다. 캐릭터·UI·전투 규칙은 이 제작 단위에서 변경하지 않는다.
- CH1-1의 넓은 피부 전투 바닥, 꿈틀거리는 동맥, 부패한 생체나무, 서늘하고 음침한 살아 있는 지옥, 6시 시작에서 12시 출구까지의 통행을 보존한다. 중앙 전투 시야와 다수 적 이동 공간을 보호한다.

## 제작 순서와 화면 목표

1. **MASTER PLAN / LARGE OUTER MASS:** 기존 CH1-1 충돌·보행·출구를 읽기 전용 기준으로 고정하고, 외곽의 높낮이와 실루엣을 실제 메시로 만든다. 속 빈 고목, 갈라진 수피, 생체 조직, 뿌리의 앞·뒤 면이 카메라 이동 시 구분되어야 한다. 사각형 mass의 밝은 절단면과 반복 패턴을 해결한다.
2. **MEDIUM / GROUND CONNECTION:** 중앙 보행면을 넓게 두면서 낮은 융기·홈·피부 주름과 외곽 뿌리의 접합을 3D 지면 메시·일관된 재질로 만든다. 바닥과 오브젝트 사이에 그림자·오염·이음새가 자연스럽게 이어져야 한다. 평면 질감 위에 동그란 장식 이미지만 얹지 않는다.
3. **PLAYABLE / LANDMARK:** 6시 시작→12시 출구와 전투 회피 동선·몬스터 가시성을 검증한다. 생체나무·독 구덩이·제단을 시선이 머무는 큰 형태로 배치하고, 중앙 전투를 가리는 덩어리는 외곽으로 옮긴다.
4. **LIGHT / LIFE:** 따뜻한 국소 광원과 차가운 채움광의 명암, 그림자, 접지, 거리 안개를 실제 3D 면에서 검수한다. 동맥·나무 끝·고치의 작은 움직임은 원점/밑동을 고정하고 전투 가독성을 해치지 않게 한다. bloom만 늘려 입체감을 대신하지 않는다.
5. **CAMERA / TECH QA:** 기본 전투 카메라, 먼 시점, 외곽, 랜드마크, 다수 적 전투를 같은 좌표에서 캡처한다. 전체 화면과 1배 확대를 함께 보고 높이·앞뒤 가림·접지·조명·적 식별·성능을 판정한다.

## 통합 계약과 작업 소유

- PC Unity 전체총괄과 `origin/main`의 `docs/engine/orders/UNITY_CLAUDE_CODEX_AGREEMENT_20261026.md` §7에서 소유·통합 순서를 정했다. PC는 `claude/unity-pc-map3d-20261026`의 3D 구현 파일을 소유하고, Codex 맵은 본 시각 기준과 카메라 QA를 소유한다. 기존 S1 브랜치와 dirty worktree를 직접 수정하지 않는다.
- 제작 방법에 대한 Codex 제안: 첫 START~ARENA 검증 구간은 비용이 없는 직접 제작 메시(수작업 또는 절차형)와 사용 권한을 확인한 기존 텍스처로 만든다. 평면 사각 mass의 높이만 늘리는 방식은 제외한다. 유료 AI 3D 서비스 크레딧이나 에셋 구매는 이 제안에 포함되지 않으며, 사용자 선택으로 확정된 것으로 기록하지 않는다.
- PC가 먼저 피부 지면의 높낮이·노멀, 부패한 생체나무의 앞뒤 면, 경계 mass의 유기적 실루엣을 실제 메시로 만들고, 같은 카메라의 S1/S2 전후 컷과 충돌 오버레이를 제출한다. Codex는 그 결과를 `UNITY_CH1_3D_CAMERA_QA_20261026.md`의 8컷 기준으로 판정한다.
- 게임 시뮬레이션은 기존 2D px 좌표·충돌 데이터를 유지하고 Unity 환경 렌더로 매핑한다. 3D 높이는 시각·가림·광원에 먼저 적용하며 보행·스킬 판정 변경은 별도로 검수한다.
- 3D 제작 화면을 런타임에 연결하고 실플레이에서 확인하기 전까지 Steam 이미지로 교체하지 않는다. 스팀 초안 저장·베타·공개 반영은 각각 별도 상태로 기록한다.
