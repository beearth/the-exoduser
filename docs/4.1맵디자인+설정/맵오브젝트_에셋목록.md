# 맵 장식 오브젝트 에셋 목록

## 에셋 경로 규칙

### 원칙: 챕터 폴더 = 해당 챕터의 유일한 에셋 소스
- **CH1**: `assets/map/ch1/` — CH1에서 사용하는 모든 오브젝트 에셋은 이 폴더에서 로드
  - `floor_objects/` — 비충돌 장식 에셋
  - `collision/` — 충돌 에셋 (저주나무, 구덩이, 썩은나무, 애니나무, 보스게이트)
- **CH2~CH7**: `assets/map/ch2/` ~ `assets/map/ch7/` (추후 각 챕터별 폴더에 에셋 배치)
- 장별 최소 세트·제작 순서: `맵유형_확장기획.md` §4.2 (바닥2+벽1+엣지1, 대형8+유니크4). `_CH_DECO`는 hell 0~6 전부 등록. 1-1 유니크 21종 + 장별 테마 대형(prop_a/b + 신규 랜드마크).
- **`assets/objects/`는 창고(아카이브)**. 게임 런타임에서 직접 로드하지 않음. 원본 보관·백업 용도

### 코드 적용
- `_OBJ_SPR_MAP`: 모든 경로가 `assets/map/ch1/...`로 지정됨
- `_CH_DECO`: `assets/map/ch{N}/` + `(dir||'floor_objects')` + `file`로 자동 합성. `dir:'collision'` 등으로 서브폴더 지정 가능
- 벽 나무/눈깔 등 프로시저럴 장식도 `assets/map/ch1/` 경로 사용
- 새 챕터 추가 시: 해당 챕터 폴더에 에셋 넣고 `_OBJ_SPR_MAP` 경로를 챕터별로 분기하거나, `_CH_DECO` 시스템 활용

### 에셋 추가/교체 절차
1. 새 에셋 파일을 해당 챕터 폴더에 저장 (예: `assets/map/ch1/new_object.png`)
2. `_OBJ_SPR_MAP`에 경로 등록 또는 `_CH_DECO` 배열에 추가
3. `_OBJ_META`에 sz/collision/light/anim 등 메타 설정
4. `assets/objects/`에도 백업 복사 (선택)

- 에디터 폴더: `docs/4.1맵디자인+설정/objects/`
- 카테고리: 에디터는 `장식-대형`/`장식-중형`/`장식-소형` 3분류, 자동 배치는 챕터별
- 크기 배율(scale): 에디터에서 0.3~3.0x 슬라이더로 조절 가능, MAP_OBJS에 `scale` 프로퍼티로 저장

## 자동 배치 시스템 (`_CH_DECO`)
- `initMapObjects()`에서 해당 챕터 에셋을 바닥 타일에 자동 배치
- 시드 기반 난수로 동일 스테이지 = 동일 배치
- **hand 맵** (`hand:1`): 통바닥 + compose에 적은 커스텀만. 1-2 = 예배당+눈나무 4기
- **path 맵** (`path`): 길 타일 + 길 밖 이미지. 지금은 1-2에 안 씀

### 대형 에셋 자동 배치 (1차 패스)
- `_CH_DECO`에서 `large:1` 플래그가 있는 에셋만 대상
- 필드 맵당 대형 28~56 (간격 **760px**), 던전은 최대 22·간격 900px. 사이드 35% + 중앙 65% (필드)
- 벽에서 2~4타일 범위가 사이드 판정. `_gridNear`는 보이는 크기(`sz×0.55`)로 검색 반경을 늘림 — 200px 칸 3×3만 보면 중첩됨
- **소환굴 200px 이내 배치 금지** — 소환굴 스폰 영역 보호
- **복도(좁은 통로) 배치 금지** — 주변 6타일 범위에 바닥 120칸 이상 확보 필수 (통로 막힘 방지)
- 충돌 판정: `isW()`에서 `col:1` 또는 `collision:true` 모두 벽으로 처리. 코드: `_pm.collision||_pm.col`
  - **원형 충돌** (기본): 배치 인스턴스 반경 = (`colSz` || `sz × 0.4`) × (`MAP_OBJS[i].scale` || 1)
  - **타원 충돌**: 배치 인스턴스 가로/세로반경 = `colW`/(`colH` || `colW`) × (`MAP_OBJS[i].scale` || 1). 수식: `(dx²/scaledColW²) + (dy²/scaledColH²) < 1`
  - 스케일이 `undefined` 또는 `0`이면 `1`로 폴백한다. `_rebuildColObjs()`가 충돌 캐시 생성 시 `_colW`/`_colH`/`_colSz`를 인스턴스에 1회 저장하고, 게임루프 `isW()`는 저장값만 읽는다.
  - **타원 오프셋**: `colOy` — 충돌 타원 중심을 Y방향으로 오프셋 (이미지 중심과 콘텐츠 중심이 다를 때)
  - **규칙**: 충돌 크기는 이미지 실측 기반으로 산출. 이미지의 불투명 영역(alpha>30) 바운딩박스를 구하고, 게임 스케일(sz/이미지폭)을 곱한 뒤 ×0.45 축소하여 타원 반경으로 사용. 오프셋은 콘텐츠 중심 - 이미지 중심 × 스케일.
- 대형 에셋: m_ctree1~12 (저주나무 12종, sz:400, col:1)

### 일반(소/중형) 에셋 자동 배치 (2차 패스)
- 바닥 100타일당 1개, 최소 8개 최대 60개
- 벽에서 2타일 이상, 기존 오브젝트와 sz 기반 동적 거리 유지 (최소 60px, 대형 에셋은 (sz+32)/2, sz≥150 scatter 에셋은 500px)
- 시작방/보스방/대장간 근처 제외
- **충돌체(col/collision) 오브젝트**: 소환굴 200px, 시작방/보스방 300px 이내 배치 금지 + 주변 4타일 범위 바닥 60칸 이상 필수 (통로 막힘 방지)
- **겹침 방지**: 그리드에는 배치 인스턴스 스케일을 반영한 `colR`과 `visR`을 저장한다. `MAP_OBJS.push` 래퍼의 `_gridAdd(x,y,type,scale)`가 단일 등록 경로이며 mega의 별도 직접 push는 없다. `_moGridMaxR`은 저장된 최대 `visR`을 유지하고, `_gridNear`는 `ceil(max(요청거리,newVisR,_moGridMaxR,200)/200)+1`칸을 보아 기존 대형 오브젝트도 검색 범위에서 누락하지 않는다. 실제 거리는 `max(요청간격,otherR+newVisR+56)` 미만이면 거부한다. 충돌 판정(`isW`)의 colSz와 별개.
- CH1 벽 눈깔: 바닥 인접 벽 타일에 2% 확률로 eyeball/eye1_bloodshot/eye2_terror 배치 (sz:72)
- 자동 배치 에셋 크기: 나무 100, 뼈 48, 꽃/벌레 40, 눈깔/유충 56
- 추가 에셋 (PixelLab): flesh_pile 64, spider_web 56, tombstone 56, weapon_pile 64, meat_stake 64, acid_pool 56

#### 던전 포탈 (출구 타일 루프 뒤)
```
조건: !G._bossArena && G.exits.length>0 && G.bossGate && G.bossAlive
위치: 출구 타일 중심 좌표 (자동 계산)
크기: sz=250
```

#### 보스 아레나 포탈 (맵 캐시 직후)
```
조건: G._bossArena && G._bossArenaEntry
위치: (entryX+0.5)*T, (entryY+2.5)*T  — 6시 입구
크기: sz=400
```

#### 출구 타일 바닥 처리
```
포탈 이미지 로드 완료 시: 출구 타일 바닥색 fill 생략 (포탈이 덮음)
포탈 미로드 시: 기존 바닥색으로 fill
```

### 4. 진입/리스폰 로직

#### 보스방 진입
```
플레이어 타일 == 출구 타일 → G._bossLoadPhase=1 (로딩 시작)
  → _enterBossArena() 호출
  → _preArenaBackup에 현재 맵/출구/게이트/소환굴 백업
  → genBossArena(si) 새 아레나 생성
  → 플레이어를 아레나 entryY에 배치
```

#### 보스방 사망 → 리스폰
```
G._bossArena && _preArenaBackup 존재 시:
  1) MAP_OBJS=[] 초기화
  2) 백업에서 맵/출구/게이트 복원
  3) boss_gate_col 충돌 재생성: (bossCx+0.5, gateY-1)*T
  4) 리스폰 위치: (bossCx, gateY+6) — exit 아래, 재입장 방지
  5) buildMapCache + initMapObjects 재호출
  6) G.bossAlive=true, G._bossArena=false
```

#### 진입 텍스트
```
"▼ 보스방 ▼" — 출구 가운데 타일(ei===exits.length/2)에서만 표시
플레이어 5타일 이내 접근 시 알파 페이드인
```

### 5. 전체 파이프라인 순서 (한 프레임 기준)

```
맵 생성 (initStage)
 ├── genFromTemplate / genGauntlet
 │    ├── 보스방 생성 + 격리 (tile=4)
 │    ├── 게이트 방향 결정 (4방향 스캔)
 │    ├── 게이트 타일 3칸 배치 (_gateTiles, _gateY)
 │    ├── 출구 타일 3줄×5칸 배치 (gateY+1~3, bossCx±2, tile=2)
 │    ├── 바닥 카빙 (gateY ~ gateY+8)
 │    └── boss_gate_col 충돌: (bossCx+0.5, gateY-1)*T
 └── buildMapCache
      ├── 게이트 이미지 렌더 (스트리밍/풀빌드)
      ├── Pass 3.5: tile=3 대문 렌더
      └── Pass 3.7: 장식 (핏자국, 동상, 룬)

매 프레임 렌더 (메인 루프)
 ├── 맵 캐시 청크 그리기
 ├── [아레나] _drawPortal() — 6시 입구, sz=400
 ├── 출구 타일 루프
 │    ├── 포탈 로드 시: 바닥 fill 생략
 │    ├── 보스 생존: 진입 텍스트 표시
 │    └── 보스 사망: 초록 맥동 출구
 ├── [던전] 나무 실시간 렌더: (gateY+0.5)*T 중심, 600px
 ├── [던전] _drawPortal(): exit 타일 중심 (gateY+2+0.5)*T, sz=250
 └── MAP_OBJS 렌더 (boss_gate_col은 스프라이트 없이 충돌만)

보스방 진입
 ├── 출구 타일 밟음 → _bossLoadPhase=1
 ├── _preArenaBackup 백업
 ├── genBossArena(si) → 새 아레나 맵
 └── 플레이어 entryY 배치

보스방 사망 → 리스폰
 ├── MAP_OBJS=[] 초기화
 ├── 백업 복원 (맵/출구/게이트)
 ├── boss_gate_col 재생성: (bossCx+0.5, gateY-1)*T
 ├── 리스폰: gateY+6 (exit 타일 아래, 재입장 방지)
 └── buildMapCache + initMapObjects
```
