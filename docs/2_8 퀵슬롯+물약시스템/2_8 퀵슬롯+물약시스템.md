## useQuickslot()
- 슬롯 인덱스로 사용
- 쿨다운 관리
- 물약 기본 쿨다운: 420프레임(7초), 패시브/장비로 감소 가능
- 자동사용: HP/ST가 일정 이하일 때 자동 발동

## 물약 강화 (POT_LV)
- 대장간(G키) → 물약 탭에서 강화
- 최대 10단
- 강화 비용: `(lv+1) × 5` 악의 (5, 10, 15, ... 50)
- **레벨 요구**: 1단=Lv.100, 2단=Lv.200, ... 10단=Lv.1000 (`(lv+1) × 100`)
- 회복량: 0강=100, 1강=150, 2강=200, 3강=300 ... 10강=1000 (`lv<=0?100:lv===1?150:lv*100`)
- 즉시회복/마나물약/물약제작 삭제 — 대장간에 강화만 존재
- 퀵슬롯 불필요 — HP가 물약 회복량 이상 빠지면 악의 1개 소모로 자동 섭취
- 쿨다운: 7초 기본 (장갑/벨트/회복력 패시브로 감소)
- potionPower 어픽스로 회복량 증가

## HP 추출
- 악의(G.mats)를 HP로 변환
- 물약 대체 수단
- 월드 드롭 렌더는 `POT.hp.col`을 플라스크 본체와 바닥 글로우에 공통 사용한다. 전투 중 회복 아이템을 직관적으로 구별하기 위해 적색이 아닌 녹색을 유지한다.

## 자동 물약 (auto-potion) — 트리거 + `autoPotThr` 설정 감사 (2026-08-17)

**실제 트리거 (game.html ~L29262, 설계대로 동작)**: `autoPotCd<=0 && P.hp>0 && G.mats>0 && (P.mhp-P.hp) >= _apHealAmt` — 즉 **"부족 HP ≥ 물약 회복량"**이면 악의 1개 소모로 자동 섭취(위 "물약 강화" 섹션 문서와 일치). 임계 % 방식이 아님.
- `_apHealAmt = potHeal('hp')×(1+potionPower)`. 쿨다운 `_potCdBase=420f`(장갑/벨트/회복력 패시브로 감소, 최소 6f).

**`OPT.autoPotThr` = 오펀(orphan) 설정 (미배선)**:
- 정의 `OPT.autoPotThr:0.99`(0~1 비율, game.html ~L5326), 슬라이더 `#optAutoPot`, oninput(`/100`)·populate(`×100`)만 존재. **자동물약 트리거(L29262)는 이 값을 읽지 않음**(grep: autoPotThr 참조 3곳=default/oninput/populate, 런타임 소비 0).
- 런타임 확증: 80% HP에서 threshold 0.10 vs 0.99 모두 트리거 조건 `missing(1479)≥heal(100)`로 동일 발동 → **임계값 무시**(설정 조작 무효). 기본 동작이 "부족≥회복량"(≈98.6% 이상 상시 발동)이라 기본값 99%와 우연히 근사 → 오배선이 눈에 안 띄었음.

**이번 수정 (UI 정합 correctness만, 2026-08-17)**:
- 슬라이더 범위 불일치 해소: `min=30 max=95 step=5 value=99` → `min=30 max=99 step=1 value=99`. 기존엔 기본값 99%가 max=95·step=5로 **표현 불가**(브라우저가 95로 클램프)했음.
- 저장 단위/기본값 불변(0~1 비율, 0.99). **세이브 마이그레이션 없음** — 기존 값 0.30~0.99 전부 신규 범위 내 표현·round-trip.
- 검증(Playwright): clamp 99→99·100→99, round-trip 30/60/99→0.30/0.60/0.99, populate 0.99/0.95/0.60/0.30→99/95/60/30, 스테이지 전환·pageerror 0.

**⚠ 미결(별도 결정 필요, 이번 미수정)**: `autoPotThr` 슬라이더는 여전히 **런타임 무효**(오펀). 실제 기능화하려면 트리거에 `P.hp/P.mhp ≤ OPT.autoPotThr` 게이트 추가가 필요하나, 이는 **문서화된 heal-amount 설계를 변경**(GAME-DESIGN, 자동물약 거동 변경) → 사용자 승인 필요. 대안: 오펀 슬라이더 제거. 본 작업은 UI 정합만 처리(거동 불변).
