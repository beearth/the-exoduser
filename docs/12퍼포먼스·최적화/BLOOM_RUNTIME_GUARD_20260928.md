# 블룸 초기화 안전 가드 — 2026-09-28

| 항목 | 값 | 코드 위치 | 목적 |
|---|---|---|---|
| 블룸 실행 최소 캔버스 | `C.width >= 6` 및 `C.height >= 6` | `game.html::_renderBloom` | 6분의 1 해상도 오프스크린 캔버스가 0×0이 되는 초기 프레임 차단 |
| 차단 조건 | bloom 비활성·low/mid 품질·메인 캔버스 폭 또는 높이 6px 미만 | `_renderBloom` 첫 줄 | `drawImage(_bloomCvs, …)` InvalidStateError 방지 |
| 재개 | 메인 캔버스가 유효 크기가 된 다음 프레임 | 기존 `_initBloom` 경로 | 시각 품질 설정은 변경하지 않음 |

테스트 슬롯 초기화에서 재현된 오류는 0×0 `_bloomCvs`를 `drawImage`에 넘긴 것이 원인이다. 이미지 객체만 검사하던 전역 안전 래퍼에 의존하지 않고, 0 크기를 생산하는 블룸 단계에서 렌더를 건너뛴다.
