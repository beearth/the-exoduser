# 얼음보주·동시 사망 프레임 개선 (2026-09-09)

사용자 승인 범위: 얼음보주 끊김, 대량 처치 프레임, 트레일러 소리/자막 개선. 새 재현 증거를 근거로 아래 CPU/연출 경로만 수정한다. GPU Track D 및 맵 텍스처 수명은 변경하지 않는다.

## 측정 및 검사

RX 9070 XT 로컬 Chrome, 1920×1080, 256기 진단 배치. 진단은 HP=1, 에너지쉴드=0, 부활 방지로 사망 경로만 비교하며 정상 난이도 DPS 검증이 아니다. 이전 샘플 29.7ms / UI 171회 / 시체 8.2ms. UI 병합만 적용한 중간 샘플 24.9ms / 동기 UI 0회 / 시체 9.3ms. 랜덤 드롭 및 JIT 영향이 있으므로 이 두 수치를 안정적인 FPS 보장으로 해석하지 않는다.

회귀 검사: `test/combatPresentationTiming.test.js` — UI 병합, 30/60/144/240Hz 생성 시간, 파쇄 우선순위/물리 시간, 고어 캐시와 시체 계약. 수정 전 실패를 확인한 뒤 수정 후 통과.

고어 캐시까지 적용한 콜드 샘플은 256기 전원 사망, 강타 호출 24.1ms, 시체 처리 합계 6.8ms였다. 촬영 중 실제 프레임 간격과 최대 지연은 [V2 원본별 표](../13출시·마케팅/GAMEPLAY_TRAILER_V2_20260909.md)에 별도로 기록한다. 이 개선만으로 대규모 전투의 순간 프레임 저하가 모두 제거된 것은 아니다.

트레일러는 `tools/trailer_realtime_20260909.mjs`로 게임 Canvas 레이어를 1920×1080/60fps로 합성하고 최종 `_comp` 출력을 MediaStream에 연결해 VP9+Opus로 함께 녹화한다. API/서버 저장을 끈 테스트 캐릭터에서만 촬영. 캡처 시 별도 SFX 샘플을 임의 길이로 잘라 붙이지 않는다. 지도 정지 촬영의 `G.shake` 잔류는 촬영 세션에서 0으로 초기화한다.

2026-09-10: 공용 촬영 runtime은 `__rt.damageText=true`일 때 원본 `G.txts`를 그대로 그린다. 기본값(미지정/false)은 V22의 부유 텍스트 숨김을 유지한다. [V24 데미지 텍스트 버전](../13출시·마케팅/SKILL_TRAILER_V24_DAMAGE_TEXT_20260910.md)에서 사용하며 게임의 숫자 수치·스타일·40칸 링 버퍼는 바꾸지 않는다.
