## 3. 측정 방법

`tools/qa_frame_probe.mjs` (게임 소스 무수정, 페이지 주입만):

| 지표 | 수집 방법 |
|---|---|
| 프레임 간격 | `requestAnimationFrame` 래퍼의 타임스탬프 차 (fpsCap 0이므로 draw 간격과 같음) |
| 프레임당 JS / update / draw | rAF 콜백 합산 시간, `window.update`·`window.draw` 래퍼 |
| GPU 시간 | `EXT_disjoint_timer_query_webgl2` — `loop()` 1회 범위, 메인 GL 컨텍스트 |
| 스타일·레이아웃 | CDP `Performance.getMetrics`의 `RecalcStyleDuration`·`LayoutDuration` 차분 |
| 긴 프레임 원인 | Long Animation Frame, CDP 샘플링 프로파일러(`--profile=1`), GL·2D 호출 시간 기록(`--gl=1`: `texImage2D` 소스 URL·크기, `getImageData`·`measureText` 호출 스택) |
| 메모리 | `performance.memory.usedJSHeapSize` 0.5초 샘플, DOM 노드 수 |
| 유효성 | hidden·resize·GL loss 이벤트, pageerror, 시스템 CPU(구간 평균) |

시나리오: IDLE 10초 / MOVE 20초(실제 W·D·W·A·S 키) / COMBAT 20초(좌클릭 홀드 + 1~4·Space·F를 0.6초마다 1회, 적 120 유지) / COMBAT2(같은 세션 이어지는 교전) / PANELS 24초(Tab→유골함→보석→보관함→장비→닫기→Esc 설정 열기·닫기, 2회) / POST 12초.
