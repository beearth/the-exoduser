## 5. 브라우저 스모크 결과

| 항목 | 로비 | 게임 |
|---|---:|---:|
| pageerror | 0 | 0 |

| 게임 상태 | 해당 없음 | `G.on=true`, stage 0, 200×200, WebGL2 |
| AudioContext autoplay 반복 경고 | 해당 없음 | 0 |

Google Fonts, Supabase CDN, unpkg Three.js 모듈은 격리 네트워크에서 `ERR_NETWORK_ACCESS_DENIED`가 발생했다. 로컬 파일 404가 아니며, 특히 로비 Supabase CDN은 localhost OAuth 문서 계약 때문에 무조건 제거하거나 차단하지 않는다. `intro.mp4`/BGM의 `ERR_ABORTED`는 페이지 전환·재생 교체에 따른 취소 요청으로 분류한다.

최종 헤드리스 Chrome 재실행에서 지옥강타 1/지옥강타 2 시트가 각각 올바른 512×512 셀을 선택해 화면 900×900/980×980px로 렌더되는 것을 캡처했다. 이 과정에서 `wall_black_void_tile.png`의 실제 파일 누락으로 로컬 404를 재현했고, 생성기 출력과 파일 존재 회귀를 추가한 뒤 `pageerror=0`, 로컬 HTTP 4xx/5xx 0으로 재검증했다. `intro.mp4`의 `net::ERR_ABORTED`만 브라우저 주도 미디어 취소로 남았으며 서버 Range 응답은 206이다. 사용자 실게임 콘솔에서 발견된 `_bfR2`·`_wwDetAbs` 선언 누락 2종도 회귀 테스트로 고정했으며 최종 자동 회귀는 **471/471 PASS**다.

Headless Chromium은 SwiftShader, `ReadPixels`, 자산 콜드 로드 영향을 받으므로 해당 실행의 frame p50/p95와 `[LONG TASK]`는 실기기 성능 회귀 판정값으로 쓰지 않는다. 새 최적화는 실기기 프로파일의 재현 증거가 생길 때만 진행한다.
