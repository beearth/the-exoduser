# 물리탄 표시 크기·패링 자원 3배 — 2026-09-10

사용자 지시: 물리탄을 3배 크게 표시하고 자원 회복 효과를 3배로 높인다. 기존 `parryClass`를 기준으로 적용한다. 수정 금지 `2_3 돌진+패링+방패시스템` 문서는 보존하며 이 문서가 최신 물리 투사체 배율의 계약이다.

## 표시 크기

| id / 적용 위치 | 한글명 | 현재 공식 / 값 |
|---|---|---|
| `_physicalProjectileMultiplier(p)` | 물리탄 공통 배율 | p 존재, `!friendly`, `_projectileParryClass(p)==='physical'`이면3, 그 외1 |
| draw `_sSc` | 공통 본체 크기 | `max(1.2,min(4,(sz||1)×1.5))×0.7×multiplier` |
| redBean 물리 | 회백색 이빨입 | 기존 `_rb=3.5×_sSc`, 높이=`_rb×6.3`, 가로=높이×2. 최대 가로×세로 **370.44×185.22px** (기존123.48×61.74) |
| 일반 물리 | 입/관통탄 | 높이=`20×_sSc×1.19`, 가로=높이×2. 최대 **399.84×199.92px** |
| fast 물리 | 빠른 입탄 | 높이=`18×_sSc×1.19`, 가로=높이×2. 최대 **359.856×179.928px** |
| titanEye | 혈안 눈알 | 가로/세로=`21.7×_sSc`, 최대 **182.28px** (기존60.76) |
| draw `_hr` | 궤적 굵기 | `max(2.5,(sz||1)×2.2)×_flk×multiplier`. 궤적 길이/수명은 기존값 |
| `_drawDruidPoisonShot` | 드루이드 원본 물리 독탄 | 기존 dw에 multiplier를 곱하고 dh=dw×ch/cw. 일반 원본 물리는 **288~540px**. 원본 마법은96~180px, elemBall/지뢰240px |
| friendly | 반사 블루콩 | multiplier1, 기존 반사 외형 |

시트 폴백도 공통 `_sSc`를 사용한다. 분류가 physical인 검기파 등 공통 렌더 분기도 같은 배율이다. 지뢰·덫·폭탄·장판 및 대형 에너지탄은 기존 원본 분류에 따라 확대하지 않는다. 드루이드의 피해 속성 EL.P와 원본 패링 분류는 별개이므로 Q 독탄까지 커지지 않는다.

`sz/r/dmg/vx/vy/life`와 충돌/패링 반경은 변경하지 않는다. 별도 광원·글로우 반경과 패링 임팩트 크기도 기존값이다.

## 자원 회복

반사 전 `_physicalResourceMul`에 배율을 저장한다. 이후 `friendly/blueBean/el`을 바꿔도 원래 물리탄의 보상이 유지된다. 기존 `doParry` 여섯째 인자 `_resourceMul`에 저장값을 전달한다.

| 자원 | 빨콩 물리 E | 일반 물리 E | 공식·상한 |
|---|---:|---:|---|
| HP/MP/ST 각각 | 45 | 90 | `trunc(E기본30×빨콩0.5또는일반1×(1+parryBonus)×(1+pRegen×0.20)×3)`, 각 최대치 캡 |
| 작살 | 15 | 30 | 기존5/10×3, `_HARP_GAUGE_MAX` 캡 |
| 분노 | 15 | 30 | 기존5/10×3, `_rageMax()` 캡. 기존 Q 유니크 추가량은 배율 뒤 가산 |
| 악의 | 1500 | 3000 | 기존500/1000×3 |
| 포이즈 / 무적 | +1 / 25f | +1 / 25f | 기존값 |

| 적용 경로 | 저장 위치 | 기존 보상 호출 수 |
|---|---|---:|
| 실버테일 차징 전진 | 전방 각도 통과 후 변환 전 | 2 |
| 칼등치기 단발 | `_bashParried++` 직후 | 3 |
| 투사체 충돌 E | `_wrongR` 설정 전 | 4 (빨콩, 입탄, 혈안탄, 레거시 흰탄) |
| 파워웨이브 | 투사체 직사각형 판정 통과 후 | 1 |

기존 보상 호출이 없는 무스킬 일반탄 반사에는 새 보상 호출을 만들지 않는다. 혈안탄은 평소 빨콩 경로가 우선하므로 빨콩 보상을 받는다. 별도 혈안탄·레거시 흰탄 분기는 일반 보상 기준이다. 마법/Q·근접 E·무지개 보상, 대형 에너지탄×10, 반사 피해/기폭 저장량 및 쿨다운 감소는 기존값이다.
