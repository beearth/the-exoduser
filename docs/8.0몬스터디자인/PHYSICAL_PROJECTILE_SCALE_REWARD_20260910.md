# 물리탄 표시 크기 2배·패링 자원 3배 — 2026-09-10

2026-09-10 지시 (공통 이빨입은 2026-09-16 추가×0.55 축소·부착 연출 적용): 물리탄 표시 크기를 기존 3배에서 2배로 조정한다. 자원 회복 효과는 3배를 유지한다. 기존 `parryClass`를 기준으로 적용한다. 수정 금지 `2_3 돌진+패링+방패시스템` 문서는 보존하며 이 문서가 최신 물리 투사체 배율의 계약이다.

시트 폴백도 공통 `_sSc`를 사용한다. 분류가 physical인 검기파·관통·환영검·일반탄은 혈안탄을 제외하고 이빨입 외형으로 통일한다. 시트 미준비 시에도 같은 크기의 불투명 입 실루엣을 표시하며 작은 원/회전구체 폴백은 사용하지 않는다. [가시성 계약](PHYSICAL_PROJECTILE_VISIBILITY_20260914.md). 지뢰·덫·폭탄·장판 및 대형 에너지탄은 기존 원본 분류에 따라 확대하지 않는다. 드루이드의 피해 속성 EL.P와 원본 패링 분류는 별개이므로 Q 독탄까지 커지지 않는다.

`sz/r/dmg/vx/vy/life`와 충돌/패링 반경은 변경하지 않는다. 별도 광원·글로우 반경과 패링 임팩트 크기도 기존값이다.

반사 전 `_physicalResourceMul`에 배율을 저장한다. 이후 `friendly/blueBean/el`을 바꿔도 원래 물리탄의 보상이 유지된다. 기존 `doParry` 여섯째 인자 `_resourceMul`에 저장값을 전달한다.

## 물리탄 패링 분노 쿨다운 회복 (2026-09-10)

물리탄은 반사 전 `_physicalResourceMul=3`으로 판별하여 패링 한 발마다 **30f(0.5초)**를 회복한다. 같은 프레임 다발 패링도 누적된다. 지옥강타 1·2는 `P._gslCd=max(0,남은값−30)`, 천공쇄기는 `_tickSkyCrusherRecharge(30)`으로 다음 충전을 회복하며 초과 회복량은 다음 충전에 이월한다. 자원3배는 쿨다운 회복에 곱하지 않는다. 망토 `_uParryRageCd` 30~60f 추가 회복과 비물리 패링의 천공쇄기 기본30f는 `G.frame`당1회 유지한다. 천공쇄기에 물리 기본30f와 기존 기본30f를 중복 합산하지 않는다.

| id | 분노 스킬 | 기본 회복 | 하한 / 충전 처리 |
|---|---|---|---|
| giantSlam / giantSlam2 | 지옥강타 1·2 및 해당 합체 | 물리탄 한 발마다30f | 공유 `_gslCd`, 하한0 |
| skyCrusher | 천공쇄기 | 물리탄 한 발마다30f | `_scCd` 충전 복구·이월, 최대3충전 |

수정 금지 `2_3` 문서는 보존한다. 이 계약이 물리탄의 최신 기본 쿨다운 회복 규칙이다.
