# 일반 필드 공통 탄막 밀도 — 2026-09-10

일반 필드에서 몬스터 무리가 과도한 탄막을 겹쳐 발사한다는 사용자 피드백을 반영한다. 개별 공격의 예고와 패링 판정은 유지하면서 공통 탄막의 빈도와 첫 교전 집중도를 낮춘다.

## 런타임 계약

| 항목 / 적용 위치 | 이전 | 현재 |
|---|---|---|
| `mkEn` 비보스 공통 `projCd` | 120f | 240f |
| 비보스 초기 `projT` | `70+Math.random()*50`f | `180+Math.random()*120`f |
| 보스 `projCd` / 초기 `projT` | 50f / `70+Math.random()*50`f | 유지 |
| 첫 교전 추가 빨간콩 | 비보스가 거리 1200px 안에서 1회 추가 발사 | 발사 분기 삭제. 호환 필드 `_firstShot:false` 유지 |
| `updateE` 잘못된 일반 쿨다운 복구 | `projCd>=9000`이면 `~~(100+Math.random()*60)` | 비보스·제외 etype 아님 조건에서 `projCd=240`, `projT=180+Math.random()*120` |
| 차징 / 완료탄 | 60f / `_commit:true` | 유지. 예고가 끝난 탄을 밀도 제한으로 삭제하지 않음 |
| 제외 etype 기본값 | 5,9,11,20,24,50~59 → 9999 | 유지. 기존 정예·M02 보정은 이 값에도 적용되므로 모든 변종의 발사 금지를 의미하지 않음 |

공통 주기는 대기 240f+차징 60f로 약 5초다(이전 약 3초). `sp=1`이고 사거리·idle 조건이 연속 충족되면 차징 완료 프레임에서 대기도 감소하므로 정확한 반복 간격은 299f(이전 179f)다. 첫 차징 완료는 대략 240~360f에 분산된다. AI 상태 전환·사거리·속도 보정으로 실전 시간은 달라진다.

| 공통 쿨다운 보정 | 공식 / 순서 | 현재 값 |
|---|---|---|
| 일반 | 240 | 240f |
| M02 | `~~(240*0.85)` | 204f |
| elite1 | `~~(240*0.8)` | 192f |
| elite2 | `~~(240*0.7)` | 168f |
| elite3 이상 | `~~(240*0.6)` | 144f |
| M02 + elite1 / 2 / 3 이상 | M02 정수화 후 정예 배율 정수화 | 163 / 142 / 122f |

적용 기준은 `!ib`다. 비보스 희귀/미니보스도 공통 경로에서는 같은 기본값을 받는다. 보스와 특수 AI의 전용 패턴은 이번 변경 대상이 아니다. 탄속·데미지·수명·속성·차징 시각·Q/E 패링 분류는 변경하지 않는다. 공격 인원 제한은 추가하지 않는다.
