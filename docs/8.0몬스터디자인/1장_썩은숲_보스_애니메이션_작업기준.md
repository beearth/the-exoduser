## 작업 원칙
- `1장부터 완성` 기준 문서에서 `1장`은 항상 `썩은 숲`으로 적는다.
- 보스 리디자인 가능성이 있으므로 `현행 실사용 자산`과 `리디자인안`을 같은 줄에서 섞어 기록하지 않는다.
- 보스 실작업 우선순위는 `현행 런타임 보스 자산 보완`과 `리디자인안 별도 트랙`으로 분리한다.

## 다음 정리 대상
- `1장` 일반몹 풀과 `si0~si3` 콘셉트 보스명 관계를 따로 정리한다.
- `독버섯 거인 / 숲의 사냥꾼 / 숲의 기생수`가 현재 런타임 보스 자산과 어떻게 대응되는지 확인 후 문서를 합친다.

## 전투 기전 — 다크드루이드 ORB 탄막 (구현됨, WIP)
- **커스텀 ORB 탄막**은 `G._druidOrbs` 별도 배열(일반 `projs` 아님). 필드=`{x,y,vx,vy,t,r,dmg}`, 색 필드 없음(전용 스프라이트 `_druidSheets.orb` 8프레임 회전 렌더). 파링 루프는 `projs`만 순회 → **ORB는 파링 시스템이 구조적으로 감지 불가 = 패링 불가 보스전용 탄**.
- **그자리 폭발 원칙(2026-08 구현)**: 패링 불가 탄은 접촉 시 무조건 **제자리 폭발**한다(패링 실패=폭발). ORB가 플레이어에 닿으면:
  - **녹색 폭발 VFX**(파티클 `#66dd22`/`#33aa22`) + **적 AOE 데미지**(반경 90, `max(40, dmg×1.2)`, 무포이즈).
  - **파링 윈도우 중**(`isPWin()`): 플레이어 무피해 + `parryBank += _obDmg`(패링 크레딧). 되받아치기(반사)는 없음 — 제자리 폭발만.
  - **비파링 + 무적 아님**: 플레이어 피격(`hurtP`) + `poison +3` + `_webSlow=80`(속박 `☠속박!`).
  - **무적(iframes) 중**: 폭발만, 플레이어 무피해.
- 참고 대조: 일반 `blackBean`(무지개탄)은 `projs` 소속 → 파링 윈도우 충돌 시 `blueBean` 반사(되받아치기), 실패 시 `무지개폭발`(플레이어 피격). ORB는 반사가 없고 제자리 폭발만이라는 점이 다르다.

## 전투 기전 — 다크드루이드 전용 공격 `burrowStrike` (지네돌진, 2026-08 구현)
- **무브 정의**: `{id:'burrowStrike',idx:58,tele:50,rec:40,range:[150,600],phase:[0~4],cd:200,tags:gap-close/melee/ambush}`. **`_BOSS_MOVESET[3]`**(si3 드루이드 실사용 세트, 런타임=`_BOSS_MOVESET[G.stage]`)에 등록. **드루이드 전용** — teleStrike(공중 낙하형, 타 보스 공유)와 별개. ⚠최초 [0]에 잘못 등록→si3 미노출(2026-08-25 [3]로 정정).
- **트리거 조건**: 플레이어가 `150~600` 거리일 때 발동하는 매복 공격. (range 280~900→150~600 조정 2026-08: tags 근접/갭클로즈와 정합, 실 교전거리 포함해 편향 교정)
- **AI 편향 교정(2026-08)**: `_bossScore`에 원거리/매복 무브 보정 추가 — 근접 무브 3연속 픽 후 `ranged`/`ambush` 태그 무브 스코어 ×3(G.stage===3 게이트, `e._meleeStreak` 추적). 드루이드가 근접만 반복하던 편향 완화(burrowStrike/rapidMissile 노출 개선). ⚠측정: 정지 플레이어+소표본으로 분산 큼, 300초 각 3회는 통계적 미확정.
- **상태 머신 3단**:
  - `bossDruidDive` (침강 50f): 제자리서 땅속 다이빙(dive 시트 프레임 0→7) + 녹색 가시 파티클 텔레그래프.
  - `bossDruidUnder` (잠행 45f): 땅속에서 플레이어 발밑으로 이동(origin→목적지 보간, 목적지는 플레이어 완만 추적). **무적**(iframes, 회피 불가 매복). **완전 잠수(2026-08-25 수정)**: 스프라이트 숨기고 **이동하는 흙두둑(ellipse)만** 렌더 → "완전히 땅속" 꼼장어 잠행. Erupt에서 dive 프레임 7→0 역순 기어나옴.
  - `bossDruidErupt` (분출 40f): 플레이어 발밑서 분출(dive 프레임 7→0) + **1회 AOE 매복 타격**(반경 `r+120`, `atk×2.2`). 파링 가능(isPWin→스턴+parryBank), 실패 시 `poison+4`·`webSlow=90`·넉백.
- **애니메이션**: 신규 `dive.png`(4×2, 8프레임, `boss_dark_druid_dive.png`). `_drawDruidBoss` `_isDive` 분기가 침강/잠행/분출 프레임 매핑.
