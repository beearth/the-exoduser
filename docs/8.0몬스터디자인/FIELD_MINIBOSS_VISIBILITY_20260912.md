# 필드 부보스 화면 밖 탄막 차단 (2026-09-12)

화면 밖에서 부보스 탄막이 날아오는 문제를 막기 위해 일반/시험용 게임 HTML에 동일한 발사 조건을 적용한다.

| 대상 | 변경 |
|---|---|
| 심연의 앵글러 | 화면 밖에서 에너지 충전·대기 연사 취소. 화면 안에서만 충전 시작과 큰 에너지탄·혈안탄 발사 |
| 화마귀 | 화면 밖에서 에너지 충전·대기 연사 취소. 추적 이동은 계속하며 화면 안에서 충전부터 다시 시작 |
| 곰치 | 화면 밖에서는 _wmFire 발사 차단. 기존 등장·잠복·이동 주기는 진행 |
| 1-1 다안 육괴 | _emitEnemyShot에서 화면 밖 발사 준비 차단. 지연 공격도 방출 전에 다시 검사하여 화면 밖이면 취소 |
| 화면 조건 | 중심이 카메라 기준 좌우 VW/2−64, 상하 VH/2−64 안에 들어와야 함. 다안 육괴는 월드 렌더와 같이 G._camZoom 반영 |
| 재진입 | 앵글러·화마귀는 기존180틱 충전을 처음부터 보여준 뒤 발사 |
| 적용 범위 | 새 탄막의 발사·예약. 이미 화면 안에서 발사된 탄은 기존 수명·피격 규칙 유지 |

공통 함수는 _fieldEnemyCanShoot. 이 변경은 몬스터 공격 허용 조건만 수정하며 맵 배치와 카메라 이동은 바꾸지 않는다. tools/test-field-enemy-visibility.cjs에서 양쪽 HTML의 실제 함수와 공격 분기를 실행하여 화면 경계, 화면 밖 발사 차단, 충전·연사 취소, 재진입 충전, 다안 육괴 지연 발사 조건을 검증한다. 실제 브라우저 플레이 화면은 미확인이다.
