# 몬스터 공격 시스템

## 핵심 원칙
- **주력은 탄막 + 리듬게임식 전투** — 대부분의 몬스터는 탄막으로 공격, 패링/회피 가능
- 탄의 원본 분류(`parryClass`)별로 패링 입력이 다름: 물리=`E`, 마법(무지개 포함)=`Q`, 전용 위험물=`패링 불가`. 외형 재사용 플래그(`redBean`)만으로 입력을 결정하지 않는다.
- **근접 접촉 데미지 (예외적 존재)**: `_meleeET`(etype 0·2·4·5·6·10·12·18·19)은 플레이어에 밀착(`d<e.r+P.r+8`) 시 **atk×0.8** 접촉 타격 + 쿨다운 40~60f. (그 외 일반 몬스터는 겹쳐도 밀어내기만, 데미지 없음)
- **돌진 적중 데미지**: 동물형 돌진 3종(22 서리늑대/30 사냥개사도/43 악마견)이 `eCharge` 중 플레이어 적중 시 **atk×30** + `fire_medium` 임팩트 + 넉백 (9적ai패턴디자인 돌진형 참조, 2026-06-28)
  - etype 2(돌진사도)는 2026-06-28 돌진 제거 → `_meleeET` 접촉뎀만
  - **전조 VFX (2026-09-02)**: 90f 동안 START 검붉은 균열 + BODY 반투명 안개·양쪽 균열선 + END 별도 창촉을 표시한다. 30f(0.5초) fade-in, BODY 면 alpha 0.27, 중앙 0.11, 외곽 0.62±3.5%, START 0.56, END 0.70, 폭 `e.r×1.7`. `eCharge` 전환 순간 즉시 제거. 속도·지속·거리·피해·판정 불변.

|---|---|---|---:|---|---|
| `eChargeWind` | 3파트 다크 판타지 돌진 예고 | 22 서리늑대, 30 사냥개사도, 43 악마견 | 90f(1.5초) | `charge_start_rift.png` + `charge_body_mist.png` + `charge_end_spear.png` | st2 소진 → 전조 즉시 제거 + `eCharge`, 속도·지속·거리·피해·sweep 히트박스 유지 |

- **카메라 거리 컬링**: 카메라 중심 기준 **2500px 이상** 떨어진 적 투사체 즉시 제거 (`6,250,000 = 2500²`)

## HP 공식 (v10 — v9 ×1.3, 2026-05-05 약스킬 상향 + HP 30%↑)
```
기본커브 = (Lv≤500 ? 0.4×Lv³ + 199×Lv + 100 : 50,000,000 × 1.0014^(Lv-500)) × 1.3
최종HP = 기본커브 × (보스?24:1) × dm × et.hpMul × (1 + stage×0.02)
```

### 보스 부활
- 항상 100% 부활 (확률 판정 없음)
- 풀피 부활 (HP 변동 없음) + eShield도 mhp로 갱신
- 부활마다: ATK ×1.5, SPD ×1.25, 포이즈 ×1.5, 패턴쿨 -30f

## 이동속도 공식
```
일반몹: SPD = (ETYPE_SPD[etype] + rand(0~0.08)) × 1.5
보스:   SPD = 0.5 (배율 미적용)
레어:   SPD = (_rd.spd + rand(0~0.05)) × 1.5
```
- M02 모드: ×1.5
- 부활 시: ×1.25 (캡: 일반 1.6, 7장 2.0)

## 포이즈 공식
```
poise = maxPoise = HP × 0.5
```
- 부활 시: maxPoise ×1.5

## 에너지쉴드
```
eShield = eShieldMax = HP (동일값)
```
- HP와 별도 체력바 — 물리/에너지 이원 방어
- 쉴드 리젠: 5초 미피격 후, 쉴드>0일 때 mhp×0.5%/프레임
- 쉴드 완파 시 복구 안 됨

## 보스 몸통 충돌 (2026-04-23)
- **보스(ib=true)만** 플레이어와 몸통 충돌 — 통과 불가
- 충돌 반경: `e.r + P.r`
- 겹치면 플레이어를 바깥으로 밀어내기 (`canMv` 체크 후 위치 보정)
- **예외**: 돌진(charge), 전격이동(bladeDash) 중에는 통과 가능
- 일반몹은 충돌 없음 (기존 유지)

## ATK 공식 (선형 반감, 2026-05-03 전면 50% 하향)
```
baseLin = ((보스?75:50) + monLv×(보스?2.9:1.95)) × 0.5
ATK     = floor(baseLin × dm × et.atkMul)

monLv = P.lv + 난이도오프셋
dm = DIFF_MUL[난이도]
DIFF_MUL = [1.00, 1.12, 1.25, 1.40, 1.58, 1.78, 2.00, 2.25, 2.52, 2.82, 3.15]
```

## 패링 시스템

### 투사체 원본 분류 SSOT (`parryClass`, 2026-09-04)

`spawnProj()`는 모든 적 탄에 `physical` / `magic` / `forbidden`을 한 번 저장한다. 이후 탄속, 외형, Q/E 패링 분기가 모두 이 값만 사용한다. `redBean`·색상·원소 하나만으로 판정하지 않는다.

| `parryClass` | 생성·설정 기준 | 외형 | 탄속 | 패링 |
|---|---|---|---|---|
| `physical` | `EL.P` 일반/관통탄, `redBean+EL.P`, `titanEye`(색은 `EL.F`여도 물리) | **회백색 이빨입** 또는 혈안 | 300px/s | E(sBash) |
| `magic` | `blackBean`, `redBean+EL.F`, `fireMagic`, `waterBean`, `gbBean`, 비물리 원소탄, **지뢰·덫**, `fbEnergy`/`fdEnergy` | 무지개·속성 혜성·보라 암흑 구체·물 구체·정지 함정 | 500~600px/s(대형·정지탄은 전용) | Q(sBlock/해제/peaceShield) |
| `forbidden` | `noParry`, 웹·폭탄·장판·일반 `elemBall` | 각 전용 위험물 외형 | 전용 | Q/E 반사 불가 |

> `blackBean`은 **무지개 전용 탄종**이며 `EL.P` 레거시 데이터값과 무관하게 `magic`/Q 패링이다. `gbBean`은 `EL.D` 보라색 암흑 구체이고 무지개 렌더를 쓰지 않는다. `elemBall`은 전속성 표기가 아니라 **단일 `el`을 가진 대형 투사체의 형태 플래그**다. 정지 `mine`/`trap`은 Q 반사 뒤 friendly/blueBean 가드에서 즉시 회수되어 자원을 지급하며, `fbEnergy`/`fdEnergy`만 일반 `elemBall` 금지보다 앞서는 대형 에너지 Q 예외다.
