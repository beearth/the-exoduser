## 1-B. 탄막 데미지 3-Tier 시스템 (2026-04-17)

### 개요
**이전 시스템의 문제**:
- Caller의 dmgMult(변수: 0.8~1.5) × beanRoll의 배율(1.0~1.5) = 최종배율 0.8~2.25배 (불규칙적 & 예측 불가)

**새 시스템** (2026-04-21 평준화 후 현행 코드 기준):
- `_beanRoll`이 `EL.P/D/I/F` 공통 탄은 원소별 고정 dmgM을 반환(호출 dmgMult 무시). **그 밖의 원소 기본탄과 `eShootWind` 특수 `eProjAt`은 호출 dmgMult를 그대로 사용**
- 최종 데미지 = `floor(ATK × dmgM)` → spawnProj 이동탄 `×2.0`(redBean은 이후 `×0.5`). 엘리트 배율은 ATK 생성 시 이미 포함

### Tier 정의

| Tier | 분류 | 포함 탄막 | 데미지 배율 | 설계 의도 |
|------|------|----------|----------|---------|
| **Tier 1** | 일반탄/들러리 | 다크볼(gbBean, `EL.D`), 노랑탄, 보라탄 | **×1.0** | 약한 기본 공격, 플레이어 유리. 화이트볼 제거 |
| **Tier 2** | 원소 고정탄 | 물리 이빨(redBean+`EL.P`), 물 파란콩(`EL.I`), 화성송(`EL.F`) | **×1.2** | 중간 난이도, 패링 필수. 근접빨콩(_closeBean)은 제거 |
| **Tier 3** | 강력 추적탄 | 무지개탄(blackBean, 전용 공격만) | **×1.5** | 최강 탄막, 리듬게임 난이도의 핵심 |

### 예시 계산

**보스 Lv500, ATK=915** (`floor((75+500×2.9)×0.6)`, 난이도·정예 배율1)

| 탄막 | Tier | 기본배율 | 엘리트배율 | 최종 데미지(spawnProj 배율 전) |
|-----|------|--------|----------|----------|
| 다크볼 | T1 | ×1.0 | ×1.0 | 915×1.0 = **915** |
| 물리 이빨 | T2 | ×1.2 | ×1.0 | floor(915×1.2) = **1098** |
| 무지개탄 | T3 | ×1.5 | ×1.0 | floor(915×1.5) = **1372** |

**보스 부활 1회 이후** (ATK floor(915×1.5) = 1372):
| 탄막 | Tier | 기본배율 | 엘리트배율 | 최종 데미지(spawnProj 배율 전) |
|-----|------|--------|----------|----------|
| 다크볼 | T1 | ×1.0 | ×1.0 | 1372×1.0 = **1372** |
| 무지개탄 | T3 | ×1.5 | ×1.0 | floor(1372×1.5) = **2058** |

### Tier 적용 규칙

1. **특수탄(원소구, 팬텀소드, 함정류)**: Tier 미적용, 각자 고정 배율 사용 (×3.0, ×1.8, ×0.3 등)
2. **엘리트 보너스**: mkEn에서 ATK 생성 시 엘리트 atkMul이 이미 곱해짐 (예: T1 ×1.0 × 매직 ATK ×1.3)
3. **부활 기간**: ATK 상향으로 자동 증가 (Tier 배율 고정)

- **틱 순서/주기**: `t-=sp` → `tick+=sp` → `t<=0`이면 제거 → 살아 있는 스택의 `tick>=30`이면 `tick=0` 후 피해 요청. 연속 idle/sp1에서 30~570틱에 총 **19회** 요청하고 600틱은 만료가 우선해 20번째 요청이 없다. 회복/경직에서 idle로 전환한 호출도 다음 idle 분기부터 진행한다.

### 물리탄 크기·패링 자원 배율 (2026-09-10)

`_physicalProjectileMultiplier(p,physicalScale=3)`는 적대 `parryClass='physical'`이면 지정 배율, 그 외는 **1**이다. 시각 기본 배율은 `(p,2)`의 **2배**이며, 공통 이빨입 본체·꼬리에는 추가 **×0.55**를 적용한다(2026-09-16). 자원 보상은 `(p)`의 기본 **3배**를 유지하며, 반사 전 `_physicalResourceMul`에 저장한 값을 기존 `doParry`의 여섯째 인자로 전달한다. 일반 E 충돌·칼등치기·실버테일 차징 전진·파워웨이브의 기존 보상 경로에 공통 적용한다.

| 항목 | 물리 빨콩 E | 일반 물리탄 E | 적용 위치·공식 |
|---|---:|---:|---|
| HP/MP/ST 각각 | 기본 **75** | 기본 **150** | `trunc(50×redMul×(1+parryBonus)×(1+pRegen×0.20)×3)`, redMul=빨콩0.5/일반1; 각 최대치 캡 |

혈안탄(titanEye)은 기존 빨콩 경로를 우선하며, 별도 titanEye 및 레거시 bwBean 경로는 기존 일반 보상×3이다. 반사 후 friendly 블루콩의 표시 크기는 기존값으로 돌아간다. 마법탄·무지개·지뢰·덫·근접 E 보상은 기존값, 대형 Q 에너지탄은 기존×10이다. 반사 피해·parryBank·쿨다운 감소·광원 반경은 이번 배율 대상이 아니다. 기존 보상 호출이 없는 무스킬 일반탄 반사 분기는 새 보상을 만들지 않는다.

물리탄은 반사 전 `_physicalResourceMul=3`으로 판별하여 패링 한 발마다 **30f(0.5초)**를 회복한다. 같은 프레임 다발 패링도 누적된다. 지옥강타 1·2는 `P._gslCd=max(0,남은값−30)`, 천공쇄기는 `_tickSkyCrusherRecharge(30)`으로 다음 충전을 회복하며 초과 회복량은 다음 충전에 이월한다. 자원3배는 쿨다운 회복에 곱하지 않는다. 망토 `_uParryRageCd` 30~60f 추가 회복과 비물리 패링의 천공쇄기 기본30f는 `G.frame`당1회 유지한다. 천공쇄기에 물리 기본30f와 기존 기본30f를 중복 합산하지 않는다.

상세 시각 수치와 검증은 [물리탄 크기 2배·자원 3배 계약](PHYSICAL_PROJECTILE_SCALE_REWARD_20260910.md)을 따른다. 수정 금지인 `2_3` 문서는 보존하며 최신 사용자 지시의 물리 투사체 배율은 이 계약을 우선한다.

### pParryProjDmg 공식
```javascript
function pParryProjDmg(bulletDmg, isQ){
  const scale = isQ ? magicRef()*statInt()*pMagicMul(false)    // Q: 마법 기반
                     : meleeRef()*statStr()*pAtkMul();     // E(칼등): 물리 기반
  const _gearBonus = Math.min(1, scale/300);               // 장비보너스 0~100%
  const _base = bulletDmg * (1 + _gearBonus) * 0.5;       // 탄뎀 50% 감소
  const _afxPB = 1 + _eqAffix('parryBonus');               // 패링보너스 어픽스
  const _legSP = sh()._lShieldParry || 1;                  // 레전더리 패시브
  const _calc  = ~~(_base * pParryDmg() * _afxPB * _legSP);
  const _kiFloor = ~~(meleeRef()*14*statStr()*pAtkMul()); // 최소: 과거 기검참 기준 고정14×
  return Math.max(_calc, _kiFloor);
}
```
> **플로어 규칙 (2026-05-19 추가)**: 탄막이 약해도 반사 데미지는 과거 기검참 기준 고정14×을 항상 보장.

## 13. eProjAt — 적 탄 발사 함수

```javascript
function eProjAt(e, ang, spd, dmgMult, el, life, col, sz){
  life = ~~(life * 1.5);              // 수명 1.5배
  const b = e.s==='eShootWind' ? {el,col:ELC[el]||col,sz,spd,dmgM:dmgMult} : _beanRoll(el, col, sz, spd, dmgMult, e); // 특수는 예고 속성 유지
  _emitEnemyShot(e, {
    x, y,                             // 입 위치(_eMouthXY)
    vx: cos(ang)*b.spd, vy: sin(ang)*b.spd,
    dmg: ~~(e.atk * b.dmgM),
    el: b.el, friendly: false,
    life: b.blackBean ? 400 : life,    // 무지개탄 수명 고정
    col: b.col, sz: b.sz,
    redBean, blackBean, bwBean, gbBean, homing, fireMagic, waterBean,
    _closeBean, _commit:true
  });
}
```
