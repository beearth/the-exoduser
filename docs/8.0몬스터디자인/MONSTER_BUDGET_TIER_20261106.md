## 5. 동작 원칙 — 모델 밀도와 별개

- **NRftW 원칙은 그대로 둔다**: 무게를 싣는 예비동작(몸 전체 참여, 몸통 회전 ≥19°·예고 정점이 대기와 1x에서 구분, G0 §4.1.7), 끝까지 가는 공격(접점 프레임 = Core 발동 틱), 큰 동작 뒤 **접점 뒤 낮은 자세·빈틈**(반격 창 36~45틱 동안 정지 자세, G0 §5). 이것은 클립(동작)의 품질이고, 삼각형·텍스처(모델 밀도)와 독립이다.
- PoE2·황천급 밀도로 내려가도 동작 틱 일치(감사 §2 항목 3)와 피격 반응(감사 §2.1)은 그대로 요구한다. 4k△ 모델에서도 예고 정점은 실루엣으로 읽혀야 하므로, 리토폴로지 때 **관절·손·무기 끝**의 면을 남긴다.
