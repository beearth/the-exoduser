# 3.2 메타 · 진행 시스템

> 전체 메타 설계는 미작성이다. 아래는 PM-013에서 실제 코드와 기존 시스템 SSOT를 대조한 현행 성장·경제 경로만 기록한다. 신규 밸런스 확정안이 아니다.

## 2026-10-01 성장·경제 현행 경로 (PM-013)

| 항목 | 현행 값·흐름 | 코드 / 상세 SSOT |
|---|---|---|
| 경험치 | Lv1000 미만은 몬스터 기본 XP에 콤보 배율을 적용한 뒤 `addExp`에서 1/3 절삭하고 보너스를 적용한다. Lv1000 이상 처치 XP는 일반 1·정예 2·보스 10으로 호출하며 1/3 절삭을 건너뛴다 | `game.html`의 처치 경로·`addExp`; [수치표](../14밸런스+수치테이블/14밸런스+수치테이블.md) |
| 레벨 보상 | 레벨마다 SP +3, 짝수 레벨마다 AP +1. Lv1000 이상은 하루 한 번 레벨업 제한. 현재 공개 데모는 Lv100 상한 | `game.html`의 `addExp`; [수치표](../14밸런스+수치테이블/14밸런스+수치테이블.md) |
| 스탯·패시브 | STR/DEX/INT/LCK 직접 투자 각 500 상한·1 SP/pt, 근성 1 SP/lv·무한. 패시브 일반 Lv10, 단계별 AP 비용 1/2/3/5 | [수치표](../14밸런스+수치테이블/14밸런스+수치테이블.md) |
| 장비 드롭 | 일반 45%×드롭 보너스/1롤, 정예 1롤, 레어몹 2롤, 스테이지 보스 3롤, 챕터 보스 5롤과 첫 전설 보장. 등급은 몹 분류별 가중치 롤 | `game.html`의 `rollDrop`; [아이템 시스템](../7아이템디자인/exoduser-item-system-full.md) |
| 악의 소비 | 양수 기준 원가에 `_malCost(v)=max(1,ceil(v×0.5))`를 적용. HP 물약은 1 악의, 강화는 단계·등급 비용식 적용 | `game.html`의 `_malCost`·`useQuickslot`·`enhCost`; [자원표](../14밸런스+수치테이블/자원소비량표.md) |
| 강화 | 성공 확률 `max(0.5,99×0.99^n)%`; 비용 `enhCostRaw(n)=max(20000,ceil((20000+n×3500)×1.5))`에 등급배율을 곱하고 `_malCost` 적용. 유니크 경제 배율은 전설 단계(1.8)로 취급 | `game.html`의 `enhCost`·`_itemEconomyRarity`; [수치표](../14밸런스+수치테이블/14밸런스+수치테이블.md) |

현재 로비는 데모로 고정되어 본편 전 구간의 실플레이 성장값을 이 표의 검증 결과로 간주하지 않는다. 세 판의 실행 구분과 남은 측정은 [BALANCE 팀 대장](../14밸런스+수치테이블/BALANCE_ECONOMY_TEAM_MASTER.md)에 기록한다.
