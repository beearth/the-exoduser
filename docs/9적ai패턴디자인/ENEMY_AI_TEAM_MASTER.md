## 3. ENEMY-001 — 벽끼임 보스 즉사 결함 (수정·검수 완료)

**결함:** 메인 적 루프의 벽끼임 처리(`game.html:32702~32708`)가 중심+4코너 끼임 시 5링×8방향 구조를 시도하고, **실패하면 `e.hp=0;e.alive=false;rollDrop;addExp;G.kills++;G._stageKills++;_regKill` 로 무조건 즉사**시켰다. `e.ib`(보스) 예외가 없어, 페이즈 전환·잡기·순간이동으로 벽 지오메트리에 박힌 보스가 **전리품·킬 크레딧과 함께 무료로 사라지고 보스전이 종료**되며 킬카운터가 desync될 수 있었다. 어떤 설계 문서도 이를 의도하지 않음(명백한 버그).

**수정:** 구조 실패 분기를 보스/비보스로 분리.
- **보스(e.ib):** 즉사 금지. 넓은 링(6~12타일) 재배치 → 실패 시 `canMv(P.x,P.y)` 플레이어 위치 → 그래도 실패면 제자리 유지(다음 프레임 재시도). 어느 경우도 죽이지 않음.
- **비보스:** 기존 정리 킬 유지(도달 불가 몹이 진행을 막는 소프트락 방지 — 기존 계약 불변).

**변경 파일:** `game.html`(끼임 블록 1곳, `32702` 부근), `test/enemyWallStuckBossKill.test.js`(신규 회귀).

**검수 증거:**
1. 회귀 테스트 `test/enemyWallStuckBossKill.test.js` 2/2 PASS (보스 분기에 kill/rollDrop/_regKill 부재, canMv 폴백 존재 / 비보스 정리킬 유지).

## 3-C. ENEMY-F06 — 타임버짓 break 배열 꼬리 AI 기아 (결정적 하니스 재현·계측 / 수정=QA 인계)

**소유 경계:** 재현·계측·하니스·수정 후보 = ENEMY(`test/`). **실제 수정 대상 코드(공용 메인 적 루프/update)는 QA 소유** → 여기선 수정하지 않고 QA 인계란(§아래)에 최소 후보·함수 범위만 남긴다.

**결함:** 메인 적 루프(`game.html:32853`)가 항상 `_ei=0`부터 순회하고, 타임버짓 break(`32855`, `_ei%32===0 && _ei>0 && !ib && now-start>12ms`)가 걸리면 **인덱스 ≥ break점 나머지 적 전부 그 프레임 미처리**(timers·state 갱신 포함). 순회 순서 = 배열(스폰) 순서이며 break점이 매 프레임 거의 같은 곳 → **같은 꼬리 인덱스 적이 반복 기아**. LOD 티어(T1<150px 매프레임)와 무관하게, **근접 적도 배열 꼬리에 있으면 완전 동결**된다(거리 아닌 스폰순서 편향).

**결정적 하니스 계측** (`test/enemyTimeBudgetStarvation.test.js`, 실제 게이팅 충실 복제·소스 시그니처 대조 PASS. 소스 git `4911fb639`, game.html sha256 `1a70bec9…`. 고정조건 budget=12ms·Ctimer=2µs·frames=480·inView=1200px·nearFrac=0.5·seed=12345):

|---:|---:|---:|---:|---|---:|
| 100 | 40~120 | 0% | — | 0 / 0 | 1f |
| 200 | 80 | 0% | — | 0 / 0 | 1f |
