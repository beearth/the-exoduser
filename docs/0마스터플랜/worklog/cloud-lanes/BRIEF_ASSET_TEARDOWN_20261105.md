## 0. 금지·범위
- 상용 게임 파일 추출·언패킹·프레임 캡처(RenderDoc/PIX) 금지. 디아블로4·PoE2·황천 파일은 열지 않는다.
- **CC0·명시적 재배포 허용 라이선스만** 내려받는다. 라이선스 원문 URL을 문서에 적는다. 로그인이 필요한 곳(Fab/Quixel, Unity Asset Store, Sketchfab 로그인 다운로드)은 **사용자가 직접 로그인**해 내려받아 넘겨준 파일만 쓴다. 대리 로그인·계정 생성 금지.
- 내려받은 자산은 **연구용**이다. 게임에 반입하지 않는다(반입 여부는 별도 결정). 저장 위치는 Git 밖(`~/EXODUSER-Storage/asset-teardown/<출처>/<자산>/`), Git에는 측정표·이미지만 올린다.
- 무창·무음. Blender는 `--background` 스크립트로만. 결과 이미지·폴더를 사용자 화면에 자동으로 열지 않는다.
- 유료 지출 0.

## 1. 대상 (같은 종류끼리 비교)
우리 1-1 소품과 같은 종류를 고른다. 1차는 **고목·나무 줄기 2개, 바위 2개, 통나무/다리 1개**, 총 5개 이내.

| 종류 | 공개 자산 후보(로그인 불필요, CC0) | 우리 쪽 비교 대상(unity/main `unity/Assets/…`) |
|---|---|---|
| 고목·죽은 나무 | Poly Haven `models` 카테고리 nature → dead tree / tree trunk 계열 (polyhaven.com, CC0) | 1-1 거대 고목(거목각 19,888△), Hollow(26,876△) |
| 바위·이끼 바위 | Poly Haven rock / boulder 계열, ambientCG Model(CC0) | 1-1 늪가 바위 |
| 통나무·나무 다리 | Poly Haven wooden log / bridge 계열 | 1-1 전경 로그(45,719△), 남→북 다리 |

- 후보가 없거나 품질이 낮으면 대체: Quaternius(CC0, 저폴리라 참고만), Kenney(CC0, 참고만). AAA급은 Megascans(Fab, Epic 로그인 → 사용자)이며, 사용자가 내려받아 주면 2차로 분해한다.
- 우리 자산 경로는 `unity/Assets/Exoduser`(또는 `unity/Assets/ForestKit` 계열)에서 `grep -ril "hollow\|log\|rock\|tree" --include=*.fbx --include=*.prefab`로 찾아 파일명·경로를 표에 적는다. 못 찾으면 "미확인"으로 둔다.

## 2. 측정 항목 (자산마다 같은 표)
Blender 4.x `--background --python teardown.py -- <파일>`로 자동 측정하고, 사람이 보는 이미지 4장을 뽑는다.

| # | 항목 | 어떻게 | 왜 |
|---|---|---|---|
| M1 | 삼각형 수(LOD별), 정점 수, 오브젝트·머티리얼 수 | bpy 통계 | 우리 상한(큰 소품 6~12k) 검증 |
| M2 | 바운딩 크기(m), 원점(피벗) 위치(바닥 중앙인지) | bpy | 접지·배치 관례 |
| M3 | 폴리곤 밀도 분포 | 면적당 삼각형, 상/중/하 1/3 구간별 비율 | 어디에 폴리곤을 쓰는지(실루엣 vs 평면) |
| M4 | UV: 아일랜드 수, 겹침 유무, 타일링/트림 여부, 0~1 사용률 | bpy UV 통계 + UV 레이아웃 이미지 | 텍스처 효율 관례 |
| M5 | 텍셀 밀도(px/m) | 텍스처 해상도 ÷ UV 월드 면적 | 우리 2.4GB 텍스처 문제의 기준 |
| M6 | 텍스처 채널 구성·해상도·포맷 | 파일 목록(albedo/normal/rough/AO/disp/opacity) | 채널 패킹 관례 |
| M7 | 노멀맵이 담당하는 디테일 vs 지오메트리 디테일 | 노멀맵 끄고/켜고 2장 | 어디까지 조형, 어디부터 맵인지 |
| M8 | 실루엣 | 우리 카메라 각(피치 34°, 거리 16.5u 상당)에서 단색 렌더 1장 | 1-1 카메라에서 읽히는 형태 |
| M9 | 가장자리·접지 처리 | 바닥 접점 확대 1장(루트 플레어, 데칼, 이끼 전이) | 접지 관례 |
| M10 | 우리 자산 같은 항목 | M1~M9를 우리 소품에 동일 적용 | **차이표**가 결과물 |

이미지 4장(자산당): ① 와이어프레임 34° ② UV 레이아웃 ③ 채널 시트(albedo/normal/rough/AO 나란히) ④ 실루엣 34°. 전부 1x PNG, 점·블러 보정 없음.
