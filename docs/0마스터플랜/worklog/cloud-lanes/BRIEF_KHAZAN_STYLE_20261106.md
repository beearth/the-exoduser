# 브리프 KZ — 카잔(The First Berserker: Khazan)식 3D 툰 그래픽 제작 방식 연구 (2026-11-06)

사용자 원문(14:20 KST): "2D 카툰 같은 카잔 같은 그래픽은 어떠냐." 배경: 11-06 오전 사용자 결정 — 모델링 목표 급 PoE2·황천(동시 100마리), 룩 "로우폴리 상위 도트"(3D 세계 + 픽셀 렌더 캐릭터), 엔진은 "언리얼이 더 좋아 보여"(K3 키샷 + K4 과부하 테스트 뒤 확정). 현재 맵은 "고무 느낌"(재질·조명 기준선 문제) 판정. 이 레인은 **툰 셰이딩 경로가 우리 조건(33° 쿼터뷰·동시 100마리·탄막 가독성·2.5D)에 맞는지**를 공부로 판단할 재료를 만든다. 결정은 사용자가 K3 키샷의 PBR 변형과 툰 변형을 나란히 보고 한다.
