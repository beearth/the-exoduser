# 브리프 CW — Core 변경: 기본 공격 1타 예비(wWindup) 6틱 (2026-11-05)

사용자 결정(11-05 14:10 KST, Mac 창 원문 "6틱, 총 길이 유지"): 기본 공격 **1타**에 예비 6틱을 넣고, 회복에서 6틱을 빼서 총 길이를 유지한다. 측정 상태 기준 0/5/34 → **6/5/28**, 합계 39틱. 배경: MO 레인 채점에서 "예비동작 없음"이 Core 제약으로 확인됨(`MANUAL/MOTION_PIPELINE_20261105.md` D-MO-2).

## 0. 규칙
- 이것은 **승인된 Core 변경**이다. 변경 범위는 아래 §1뿐이고, 그 밖의 Core 수치·판정은 건드리지 않는다.
- 웹 oracle(game.html)은 예비 0이므로 이 항목은 의도된 불일치다. oracle 비교 테스트에서 이 차이를 허용 목록으로 처리하되, 다른 항목의 불일치가 새로 생기면 FAIL이다.
- 설계 금지(어택 티켓·무지개탄 Q 패링·docs/2_3 설계 불변) 그대로.
- `git add -A` 금지, 자기 경로만 커밋, 비강제 push, CRLF 보존, 코드와 docs(아래 §3)를 같은 커밋에.

## 2. 확인할 것 (구현 전 조사 → 문서에 표로)

- Core 테스트(oracle 534건 등)에서 영향받는 케이스 목록과 기대값 갱신 방식.
- AI 적의 "플레이어 공격 예측"이 swing 진입을 기준으로 하면 6틱 어긋나는지.
