## 지하45틱의 실제 경로

- 읽기 전용 `Core/DruidBoss.Moves.cs:393`이 지하45틱을 설정한다. `NativeDruidRigPolicy.cs:133`은 `burrow_dive` 마지막 프레임의 Held 계획을 이미 제공한다.
- B1 보고서의 "Held→Idle@0"는 sampler의 분류 결함이었다. 실제 뷰 `NativeDruidRigPixelView.cs:98`·`:99`는 지하 본체를 숨긴다. P3 heap-only 경로(`:159`)도 `motion.Sample`(`:193`)을 건너뛰므로 지하45틱 전체를 화면에서 Idle로 그린다고 단정할 수 없다.
- 금지 파일인 뷰/정책 수정 없이 sampler의 잘못된 대체만 제거했다. 지하에서 본체를 감추고 P3 더미를 유지하는 기존 동작은 그대로다. 재등장 샘플에서는 긴 간격의 오래된 자세를 보간하지 않는다.
