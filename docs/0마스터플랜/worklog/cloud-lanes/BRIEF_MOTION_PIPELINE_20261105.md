- 게임 코드·자산 반입은 이 레인에서 하지 않는다(동결). 결과는 브랜치와 비교 영상으로만.

## 1. 왜 부자연스러운가 (먼저 사실 확인, G0)
현재 영웅 동작의 출처·구조를 unity/main에서 읽고 표로 적는다.
- 영웅 리그·클립 파일 위치(`unity/Assets/Exoduser/…` 리깅 FBX·AnimationClip·Animator Controller), 본 수, 클립 수·길이(프레임), 루트 모션 여부, 블렌드 트리·전환 시간, IK 유무.
- 클립이 어떻게 만들어졌나(스크립트 키·손키·Mixamo 등) — 커밋 로그·docs(`engine/UNITY_CHARACTER_BOARD_20261027.md`, `17게임아트팀/`, `FDG_RIG_*`)에서 근거 찾기.
- Core에서 동작 타이밍을 정하는 수치: `Runtime/Core/Skills/SkillRules.cs` 등에서 기본 공격 1타·구르기·피격·사망의 예비/접점/회복 틱, 이동 속도(u/tick). 이것이 **타이밍 표**의 입력이다.
- 픽셀 렌더 경로(`PixelActorPass`/rigpixel): 캡처 해상도·fps·카메라 각, 동작이 몇 fps로 양자화돼 보이는지.
- 부자연스러움을 **항목으로 쪼갠다**(사용자 영상 판정 기준): 예비동작 없음 / 무게 이동 없음 / 팔로스루 없음 / 발 미끄러짐 / 전환 끊김 / 타이밍이 Core와 불일치 / 포즈 자체가 어색. 현재 idle·walk·attack1 3개를 이 항목으로 채점(○×)한다.

## 2. 동작 데이터 출처 (사용자 결정 D-MO-1)
| 순위 | 출처 | 장점 | 제약 |
|---|---|---|---|
| 1 | **사용자 직접 연기 + 단일 카메라 영상 모캡**(Move One 등 무료 티어) | 우리 게임의 무게감을 직접 넣는다. 라이선스 문제 없음. 반복 촬영 가능 | 사용자 시간, 폰 촬영, 무료 티어 길이 제한. 촬영 가이드는 이 레인이 쓴다 |
| 2 | Epic Game Animation Sample(500+ 모캡, 무료) | 품질 높음, 모션 매칭 세트 | **UE 전용 라이선스** → UE 실험 K8에서만 쓰고 Unity 반입 불가 |
| 3 | Mixamo(무료, Adobe 로그인) | 즉시 사용, 리타깃 쉬움 | 품질 중, 무게감 약함, 모두가 쓰는 동작 |
| 4 | Blender 손키 | 완전 통제 | 숙련 필요. 스크립트 키는 지금 결과의 원인이므로 금지 |
- 레인은 1순위 전제로 **촬영 가이드**(카메라 높이·거리·배경·의상·조명, 동작 목록 idle 10초/walk 왕복/attack1 5회, 슬레이트 방법)를 먼저 써서 사용자에게 준다. 사용자가 다른 순위를 고르면 그대로 바꾼다.
