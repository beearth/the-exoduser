- 상태: 초안 | 연구 반영: d4_04_anim(가족 설계·데스 킷), conventions, pbz(적 반응 4단계) | 연구 반영 대기: 1-1 etype별 실제 AI 프레임(Core `EnemyAi.cs` 확인 필요), D4 몬스터 가족별 이동 리듬 실측(공개 자료 없음)
- 범위: 근접·원거리·돌진·소환·엘리트의 이동 리듬, 예비동작 하한, 피격 경직·넉백, 사망의 표현. / 정하지 않는 것: HP·공격력·경직 시간·포이즈·AI 선택(Core). 어택 티켓(동시공격 제한)은 만들지 않는다(핵앤슬래시, CLAUDE.md 7절).

## 1. 목표 장면·레퍼런스 (무엇을, 왜)
- 목표 장면: 1-1 남→북 다리, 먼 적 여러 마리가 작게 보이다가 다가오는 화면. 먼 적도 "무슨 종류인지" 걸음으로 읽혀야 한다.
- 레퍼런스: 디아블로4 몬스터 가족 설계(가족마다 전투 방식·느낌이 다름 [사실]), 죽인 기술에 따라 다르게 죽는 데스 킷 [사실], PBZ 적 반응 4단계.
- 왜: 같은 걸음·같은 죽음이 반복되면 전투가 단조롭다.

## 2. 디렉션 원칙
1. 가족마다 걸음 성격이 다르다(뛴다·기어간다·끈다·떠다닌다). 이유: 실루엣보다 리듬이 먼저 종류를 알린다.
2. 공격 예비동작은 몸 밖으로 무기·팔이 나가는 큰 실루엣 변화다. 이유: 플레이어가 피할 근거.
3. 예비 길이는 Core를 줄이지 않는다. 표현은 그 안에서 앞 1/3에 큰 변화를 둔다. 이유: 가독성.
4. 피격 반응은 4단계: 움찔→경직→자세 붕괴→큰 반격(PBZ 규칙6). 이유: 단계가 보이면 보상이 읽힌다.
5. 사망은 몹당 2종 이상(주저앉음/날아감), 죽인 기술에 따라 고른다. 이유: D4 데스 킷.
6. 군집은 위상을 개체마다 어긋나게 한다(시작 위상 0~1 무작위). 이유: 동시 동작은 로봇처럼 보인다.
7. 먼 적을 지우지 않는다: 안개·어둠·비네트에 묻혀 먼 적이 안 보이면 FAIL(카메라 LOCK). 이유: 먼 적이 보이는 생동감이 핵심.
8. 소멸은 사망 포즈가 끝난 뒤. 점묘·디더 소멸 금지. 이유: 점 금지.
9. 피격 섬광은 1~3틱, 흰 원판 금지. 이유: 탄막·예고 가림 방지.

### 3.1 유형별 표
| 유형 | 이동 리듬 | 예비 길이 하한(표현이 보장) | 피격·경직 | 사망 |
|---|---|---|---|---|
| 근접(일반) | 일정한 걸음, 사정거리 안에서 멈춤 8~12틱 | Core 예비가 짧으면 정점 홀드 2틱 + 팔 몸 밖 6텍셀 | 움찔→경직(Core 길이). 포이즈 0이면 그로기 180틱 | 주저앉음 / 강타 날아감 |
| 원거리 | 거리 유지, 걷다 멈추고 조준 | 조준 정점 홀드 4틱, 발사 팔 끝 섬광 3틱 | 경직 중 조준 포즈 해제 | 주저앉음 / 날아감 |
| 돌진 | 웅크려 멈춤→가속(예비 홀드 6틱) | 웅크림 정점이 하한. 돌진 경로는 바닥 표시(02 예고 문법) | 돌진 중 경직은 넘어지며 미끄럼 1걸음 | 날아감 우선 |
| 소환 | 제자리, 손 들기 | 손 들기 정점 홀드 6틱 + 바닥 문양 | 경직 시 소환 취소 포즈 | 주저앉음 + 소환체 같이 소멸 |
| 엘리트 | 일반의 0.8배 속도 느낌, 큰 보폭 | 예비 하한 일반보다 +2틱 홀드, 과장 +2텍셀 | 경직 시 반대 방향 한 번 버팀 후 휘청 | 2종 + 짧은 마무리 포즈 |
Core 값(예비·쿨다운)은 `Core/EnemyAi.cs`, `Core/EliteTables.cs`에서 읽어 채운다: Core 확인 필요.

## 4. 제작 도구 — 확정 추천: Blender 손키 + 가족별 공용 클립 라이브러리
| 역할 | Unity 추천 | UE5 대응 |
|---|---|---|
| 모델 | Blender 직접 조형 또는 Meshy 이미지→3D 후 Blender 수정(승인분만) | 동일 |
| 리그/클립 | Blender 수동 리그, 가족당 공용 스켈레톤 + 리타깃 | 공용 스켈레톤, IK Retargeter |
| 상태 연결 | Animator(Generic) + Animation Rigging 발 IK | Animation Blueprint + Control Rig |
| 군집 위상 | Animator 시작 Offset 무작위 | Montage Start Position 무작위 |
- 대안: 자동 리그(Meshy·Mixamo) — 치마·뿔 가중치가 깨져 제외 [단일, d4_04_anim 5.2].
- 커스텀 툴 1개 — "가족 클립 세트 검증기": 입력 = 가족 폴더의 FBX, 처리 = 필수 클립(이동·공격·피격·경직·사망A·사망B) 누락과 길이 검사, 출력 = 체크표. 사용자 = 구현 레인.

## 5. 절차
### 5.1 공통
1. 입력: 가족 사양(§3.1), Core 상태 길이, 실루엣 스케치(1x 높이).
2. 작업: 걷기 4포즈 → 공격 키포즈 3~5 → 피격 2방향 → 사망 2종. 각각 1x 단색 실루엣 판정.
3. 출력: FBX, 클립명 `<가족>_<동작>`(예: `skel_walk`, `skel_death_b`), 제자리, 60fps 표본, 클립 길이 = Core 길이/60.
### 5.2 Unity 반입
- Generic, Bake Into Pose, 상태 = Core 1:1, 군집 Offset은 스폰 시 무작위, 렌더는 픽셀 RT 레이어(30).
### 5.3 UE5 반입 (대응만)
- Root Motion 끔, 공격은 Montage + Notify, 군집 Start Position 무작위, 풀링된 액터 재사용 시 상태 리셋.

## 6. 합격 기준
- 1x 비교판: 한 가족의 걷기·공격 예비·피격·사망을 같은 크기로 D4 공개 영상 옆에 놓는다(감각 대조).
- 1920×1080과 3840×1080에서 가장 먼 적(약 10타일)의 종류가 걸음으로 구분된다. 3x 크롭 점 0.
- 10초 무음 영상: 같은 종류 6마리가 군집일 때 동기화되어 보이지 않는다.
- 예산: 가족당 클립 ≥ 6, 화면 동시 애니메이션 몬스터는 Core 상한(`Core/EnemyCap`)을 따르며 60fps 유지.

## 7. 금지
