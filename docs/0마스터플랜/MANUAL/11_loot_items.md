## 1. 목표 장면·레퍼런스 (무엇을, 왜)

- 목표 장면: 1-1 적을 처치하면 아이템이 튀어나와 바닥에 떨어지고, 등급색 빛기둥이 서고, 등급색 이름표가 읽힌다. 고등급은 소리와 기둥으로 멀리서도 알아챈다. 일반 등급은 조용하다.
- 한 화면에 드롭이 겹쳐도 이름이 읽힌다(겹침 자동 정렬). 먼 적·탄막은 드롭 연출에 가려지지 않는다(카메라 LOCK).
- 레퍼런스: 디아블로3·4, PoE2, Last Epoch, 그림 돈(Grim Dawn)의 공통 관례(3편 이상 공통만 채택): 등급색 이름표, 표시 키 토글, 등급별 빛기둥, 고등급 전용 드롭음, 줍기 필터, 툴팁 비교. 직접 캡처 대조는 대기.
- 현황 기록(코드 정독, 화면 미검증): 아이콘 + 등급별 빛기둥은 있고, 바닥 이름표는 없으며, 획득 토스트는 한국어 고정 문자열이다. 이 문서는 목표를 정하며 구현은 확정 후다.

## 2. 디렉션 원칙

1. **등급은 색 하나로만 말하지 않는다.** 색 + 빛기둥 높이/밝기 + 이름 글자 + 소리 층. 이유: 색약 접근성(XAG 103: 한 감각에만 기대지 않기).
2. **화려함은 희귀도에 비례한다.** 일반은 거의 무음·무광, 유니크는 기둥·소리·섬광. 이유: 모든 드롭이 화려하면 큰 보상이 묻힌다.
3. **이름표는 등급색, 장식은 은빛.** 색은 이름 글자에만, 라벨 판은 무채색 흑철. 이유: 실버 헬 "등급 색은 아이템 이름 글자에만".
4. **라벨은 겹치지 않는다.** 가까운 라벨은 세로로 밀어 정렬한다. 이유: 겹친 이름은 정보가 아니다.
5. **표시 키로 켜고 끈다.** 필터와 별개로 Alt 길게/토글로 모든 이름표를 본다. 이유: 장르 공통, 평소 화면을 깨끗하게.
6. **빛기둥은 낮고 가늘게, 먼 적을 가리지 않는다.** 이유: 카메라 LOCK과 탄막 가독성이 우선.
7. **줍기 필터는 화면 소음 규칙이다.** 등급 이하 숨김 설정이 이름표·기둥·소리 모두를 끈다. 이유: 필터가 반만 동작하면 혼란.
8. **획득 알림은 짧고 번역된다.** 등급색 이름 + 번역 키. 이유: 한국어 고정 토스트는 29개 언어 위반.
9. **툴팁은 비교가 기본이다.** 착용 중인 장비와 나란히, 차이를 숫자·화살표(모양)로 표시. 이유: 색만으로 우열을 말하지 않는다.
10. **드롭 소리는 층으로 쌓는다.** 떨어짐 → 등급 장식음 → 줍기. 매번 피치·볼륨 변주. 이유: 반복 청취 피로 방지.
11. **아이콘은 배경 없이 바닥에 놓인다.** 어두운 사각 배경 금지, 접지 그림자 있음. 이유: 바닥에서 떠 보이면 HUD와 같은 "붕 뜸" 문제.

## 5. 절차

### 5.1 공통 (입력 → 작업 → 출력 형식)

1. **등급 스타일 표 작성**: 입력 = 3.1·3.2. 출력 = JSON 한 장(등급, 이름 색 hex, 기둥 타일, 높이 %, 발광, 소리 키, 번역 키).
2. **드롭 프리뷰 장면**: 5~20개 드롭을 한꺼번에 놓는 고정 장면(`드롭_프리뷰_테스트.md`의 방식). 모든 등급 포함.
3. **기둥 원화 보강**: 등급별 타일은 기존 아틀라스 재사용, 부족하면 Blender/셰이더로 단색 가산 빔(잡티·디더 0). 출력 PNG RGBA, 2프레임.
4. **라벨**: 글자 + 무채색 판. 판은 9-slice 흑철(MANUAL 09 조각 파이프라인 재사용).
5. **툴팁 비교**: 장비 슬롯 비교 규칙 표(3.3)를 따라 레이아웃. 수치 계산은 인벤토리 시스템이 한다(표시만).
6. **소리 연결**: 키는 MANUAL 12 버스(`Skill`/`UI`/`Step` 구분)에서 정한다.
7. **번역 등록**: 신규 표시 문자열(등급명, "획득!", 라벨 표시 안내)은 MANUAL 14 절차로 `번역대상_전체목록.md`에 등록.

### 5.2 Unity 반입

- 빛기둥 아틀라스: `Resources/Art/vfx/world_item_drop_beams_v3_01/02` 형식 유지. Sprite, Mipmap 끔, Additive 머티리얼, 2프레임 교대 180ms.
- 바닥 아이콘: SpriteRenderer(SpriteMeshType.FullRect), 100 px/unit, 접지 그림자는 아래 평면 메시.
- 라벨: IMGUI `GUI.matrix` 높이 기준 배율, 글자는 `GUIStyle` + 2px 그림자 두 번 그리기.
- 줍기: `Simulation.TryCollectLoot`(Core) 경로를 그대로 사용, 표시만 바꿈. 토스트 문자열은 번역 키로 교체(`RarityNames` 한국어 고정 제거).
- 레이어: 드롭 아이콘·기둥은 월드 레이어, 라벨은 UI 레이어로 적 예고·보스 바보다 아래.

### 5.3 UE5 반입 (대응만)

- 기둥 = Niagara Sprite Emitter 또는 Billboard Mesh + Additive Translucent Material, 아이콘 = Billboard Component.
- 라벨 = 월드 위치에 붙는 Widget Component(Screen Space), 겹침 정렬은 틱에서 한 번. 등급 표 = Data Table.
- 수치·톤은 3절 그대로.
