- 상태: 초안 | 연구 반영: d4_01_env(§4~§5), poe2(§3~§4, §9 L1~P1), yellowsky(전투·임팩트 쪽 규칙만), d4_03_cam(R5 먼 적 보호), conventions(B4, C1) | 연구 반영 대기: **Downfall of Yellowsky의 광원·안개·색 처리 연구(공개 근거 0건, yellowsky.md §2.5가 "적지 않는다"고 명시)**, PoE2 발표 영상(S02)의 안개·톤매핑 방식, 연구 tech budget

## 1. 목표 장면·레퍼런스 (무엇을, 왜)

| 장면 유형 | 목표 인상 | 레퍼런스 역할 |
|---|---|---|
| 필드(1-1 숲길) | 어두운 바탕 + 빛 웅덩이 2~4곳 + 그 사이 그늘. 늪 위 낮게 깔린 공기. 먼 적은 또렷 | 분위기 = Yellowsky(사용자 레퍼런스 영상), 구조 = D4 "옛 거장 명암", 어둠의 하한 = PoE2 불만 사례 |
| 보스 아레나 | 중앙 시선 유도. 아레나 가장자리 어둡고 보스 주변 읽힘 | D4 보스 가독성, 03의 거리 줌 |
| 실내·던전(후속) | 좁은 방, 장소 광원 중심 | PoE2 광원 역할 분리 |
| 타이틀·로비 | 큰 메인 이미지에 깔끔한 UI (CLAUDE.md 4.2) | 13번 문서 |

핵심 긴장: **분위기를 위해 어두워질수록 먼 적이 지워진다.** 카메라 LOCK의 먼 적 보임이 분위기보다 위다. PoE2는 "맵이 너무 어둡다"는 불만이 반복된 사례다 [사실, poe2 S12a·S12b].

## 2. 디렉션 원칙

1. **광원은 역할이 셋이다.** 장면 키라이트 1, 영웅 주변 빛 1(그림자 없음), 장소 광원(횃불·화로·마법). 역할 없는 광원은 두지 않는다. 이유: 광원 난립이 성능과 판독을 동시에 깬다 [단일, poe2 R1].
2. **그늘은 검지 않고 색이 남는다.** 간접광을 반드시 둔다. 이유: 어둠이 "검은 구멍"이면 형태가 사라진다 [사실, poe2 R3].
3. **빛이 색을 가진다. 바탕은 좁은 색역이다.** 이유: 토널리스트식 회색조 바탕 위에 빛만 색을 가지면 화면이 통일된다 [추정, d4_01 §4].
4. **안개는 높이 안개가 기본, 거리 안개는 쓰지 않거나 극히 약하게.** 이유: 거리 안개는 탑다운에서 먼 적을 먼저 지운다 [추정, poe2 F1].
5. **적과 영웅은 배경보다 한 단계 밝거나 테두리 빛을 가진다.** 이유: 어두운 맵일수록 판독이 우선이다 [사실, poe2 R4 / yellowsky 규칙 5].
6. **노출은 장면마다 고정, 자동 노출 없음.** 이유: 밝기가 저절로 바뀌면 결함으로 읽힌다 [단일, poe2 S26].
7. **색 보정은 한 사람(한 도구)이 소유한다.** 톤맵 → 색 보정 → LUT 순. 이유: 여러 곳이 만지면 키샷과 실게임 색이 달라진다 [단일, d4_01 E20].
8. **고채도는 화면의 0.5% 이하.** 발광·피·위험 신호에만. 이유: 신호색이 의미를 가지려면 희귀해야 한다 [추정, 아트 바이블 V6].
9. **그림자 광원 수를 제한한다.** 이유: 가장 비싼 항목 [사실, poe2 S14a·S14b].
10. **후처리는 먼 적 영역을 어둡게 하지 않는다.** 비네트·그레인·강한 블룸 금지. 이유: 카메라 LOCK과 점 금지.

### 5.2 Unity 반입

| 항목 | 설정 |
|---|---|
| 방향광 | Mode = Mixed, Lighting Mode = Shadowmask, Progressive GPU Lightmapper, 해상도 8~12 texel/u |
| APV | 장면에 볼륨 1개, 최소 프로브 간격 1m, 최대 9m, 현재 렌더러 에셋의 라이트 프로브 시스템 키를 켬(지금은 꺼짐) |
| 렌더러 | Forward+ 전환(렌더러 에셋 렌더링 모드 키). Mac 실측 후 확정 |
| 안개 | 엔진 거리 안개 끔, `HellFogFeature`만. 적 셰이더에서 안개 계수 상한 |
| 후처리 | 전역 볼륨 `GlobalVolume_Hell` 1개: 톤매핑 → 색 조정 → 그늘/중간/밝음 → Color Lookup(LUT: sRGB 끔, 압축 없음) → 블룸 → (비네트) |
| 영웅 빛 | 점광원, 그림자 없음, 영웅 따라다님 |

### 5.3 UE5 반입 (대응만)

Directional Light + Lumen 또는 베이크, Exponential Height Fog, 단일 Post Process Volume(Unbound), LUT는 Color Grading LUT 슬롯. 노출은 Manual 고정.

## 7. 금지

- 먼 적을 지우는 안개·비네트·어둠. 거리 안개 켜기(D02-1 결정 전까지 현재 값 변경 금지).
- 순흑 영역(UI 제외). 자동 노출. 필름 그레인·노이즈·디더링.
- 원색 초록·노랑 광원. 파란 안개·회색 안개(아트 바이블 C7이 유지될 때).
- 역할 없는 광원. 그림자 광원 한도 초과.
- 흰 원판 블룸(L9 사고). 패링 신호색의 다른 용도 사용.
