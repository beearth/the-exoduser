## 2. 디렉션 원칙

1. **광원은 역할이 셋이다.** 장면 키라이트 1, 영웅 주변 빛 1(그림자 없음), 장소 광원(횃불·화로·마법). 역할 없는 광원은 두지 않는다. 이유: 광원 난립이 성능과 판독을 동시에 깬다 [단일, poe2 R1].
2. **그늘은 검지 않고 색이 남는다.** 간접광을 반드시 둔다. 이유: 어둠이 "검은 구멍"이면 형태가 사라진다 [사실, poe2 R3].
3. **빛이 색을 가진다. 바탕은 좁은 색역이다.** 이유: 토널리스트식 회색조 바탕 위에 빛만 색을 가지면 화면이 통일된다 [추정, d4_01 §4].
4. **안개는 높이 안개가 기본, 거리 안개는 쓰지 않거나 극히 약하게.** 이유: 거리 안개는 탑다운에서 먼 적을 먼저 지운다 [추정, poe2 F1].
5. **적과 영웅은 배경보다 한 단계 밝거나 테두리 빛을 가진다.** 이유: 어두운 맵일수록 판독이 우선이다 [사실, poe2 R4 / yellowsky 규칙 5].
6. **노출은 장면마다 고정, 자동 노출 없음.** 이유: 밝기가 저절로 바뀌면 결함으로 읽힌다 [단일, poe2 S26].
7. **색 보정은 한 사람(한 도구)이 소유한다.** 톤맵 → 색 보정 → LUT 순. 이유: 여러 곳이 만지면 키샷과 실게임 색이 달라진다 [단일, d4_01 E20].
8. **고채도는 화면의 0.5% 이하.** 발광·피·위험 신호에만. 이유: 신호색이 의미를 가지려면 희귀해야 한다 [추정, 아트 바이블 V6]. 〔CX29 R23〕 측정 정의 [제안, Mac 보정 전 시작값]: 최종 sRGB 프레임(HUD 끔)에서 HSV 채도 ≥ 0.80 이고 명도(V) ≥ 0.60인 픽셀 수 ÷ 화면 전체 픽셀. 프레임마다 계산해 10초 구간의 최대값을 기록(정지 1장 판정 금지). 위험 예고(바닥 경고)는 분모·분자 모두에 포함하고, 초과하면 예고가 아닌 장식 고채도부터 줄인다(예고를 어둡게 해서 통과시키는 것 금지). 가산 VFX 면적 12%·HDR 단계(15번 3.5)·순백 면적은 **서로 다른 지표**다.
9. **그림자 광원 수를 제한한다.** 이유: 가장 비싼 항목 [사실, poe2 S14a·S14b].
10. **후처리는 먼 적 영역을 어둡게 하지 않는다.** 비네트·그레인·강한 블룸 금지. 이유: 카메라 LOCK과 점 금지.

**검증 순서(codex_urp_mood §10, 이 연구에서는 실행하지 않음):** 카메라 34° 고정, 같은 장면·같은 적·같은 이동으로 `안개 없음 → 거리/높이 안개 → 볼류메트릭 → 림 → LUT`를 한 단계씩 비교한다. 저해상도 캐릭터 RT가 있으면 그 출력까지 포함한다. 정지 화면 외에 적 이동·카메라 이동·가림·광선 중첩·다수 적을 넣는다. GPU 사용 측정은 플랫폼별로 다르다(Windows DX11/DX12 지원, macOS Metal은 Xcode GPU Frame Debugger). 지원되지 않는 측정의 0ms를 "무료"로 해석하지 않는다. 장치·API·해상도·렌더 스케일·AA·광원/적 수·워밍업이 없는 단일 FPS는 채택 근거로 쓰지 않는다. 이 연구의 성능 측정값은 전부 미확인이다.

**우선순위(제안, [추정]):** 정적 라이트맵 + 이동체 APV → 적의 명암 분리 → 약한 높이 안개 → 제한된 림 → 고정된 톤매퍼/LUT. 볼류메트릭은 가독성이 유지되는 국소 영역에 한해 추가. 전역 노출을 내리기보다 배경의 어두운 면과 국소 조명을 설계한다 (codex_urp_mood §1·§11).

### 5.3 UE5 반입 (대응만)

Directional Light + Lumen 또는 베이크, Exponential Height Fog(+ Volumetric Fog, 광원별 Volumetric Scattering Intensity로 산란 조절 [사실, TOOLCHAIN W34]). Mac Apple Silicon에서 Lumen 소프트웨어 RT는 동작, 하드웨어 RT는 실험적(ENGINE_DECISION §2). UE5가 안개·광산란의 "가장 가까운 결과"일 가능성이 높으나 [추정] 엔진 결정은 ENGINE_DECISION 실험 후다. **3차(ENGINE_TRIAL_UE5_PLAN §3 정합):** 비교 실험의 첫 기준은 Deferred/Metal, 1920×1080, screen percentage 100%, 고정 노출, motion blur·DOF·grain·비네트 끔이고 **Lumen은 끄고** 직접광 + 환경광으로 구도·명암을 먼저 맞춘다. Lumen을 켠 결과는 설정을 따로 적은 추가 결과로만 둔다. UE만 과한 안개·광택·심도로 미화해 엔진 차이라고 부르지 않는다. Yellowsky가 Lumen·Height Fog를 썼다는 근거는 없다(엔진 UE5는 2024 자기 신고 1건, 나머지 미확인). 단일 Post Process Volume(Unbound), LUT는 Color Grading LUT 슬롯. 노출은 Manual 고정.
