## 2. 디렉션 원칙

1. **피치는 영원히 고정이다. 줌은 거리만 바꾼다.** 이유: 카메라 LOCK(11-03). 피치가 바뀌면 소품·그림자·판정 모양이 전부 달라진다.
2. **카메라를 먼저 고정하고 아트를 거기에 맞춘다.** 이유: D4가 그렇게 했다 [사실, d4_03 §1.2].
3. **가림은 두 단계다.** 1단계 가리는 물체를 연하게, 2단계 완전히 가려진 부분만 실루엣. 이유: D4는 완전 가림에서만 실루엣이라 불만이 남았다 [사실, d4_03 §2.3].
4. **가림은 매끈한 알파로. 디더·스크린도어 점 패턴 금지.** 이유: 점 금지.
5. **땅·다리·늪 수면은 가림 대상이 아니다.** 이유: 발밑 판독 유지.
6. **먼 적은 어떤 연출로도 지우지 않는다.** 이유: 카메라 LOCK 핵심.
7. **엘리트·보스는 가려져도 실루엣으로 보인다. 일반 적은 기본 끔.** 이유: 화면 소음 방지 [추정, d4_03 R5].
8. **흔들림은 위치 오프셋만, 큰 사건에만, 끌 수 있다.** 이유: 회전 흔들림은 피치 LOCK을 깬다. 접근성 [사실, d4_03 §1.3, poe2 R10].
9. **발밑 원은 어떤 상태에서도 사라지지 않는다.** 이유: D4 버프 중 원이 사라져 캐릭터를 못 찾는 버그 사례 [단일, d4_03 §2.1].
10. **시네마틱 카메라는 게임 카메라와 별개이고, 끝나면 블렌드로 돌아온다.** 이유: LOCK 보호, 13번 문서와 연결.

## 4. 제작 도구

| 역할 | Unity 추천 (확정) | UE5 대응 | 대안 |
|---|---|---|---|
| 게임 카메라 리그 | Cinemachine 3: PositionComposer 거리만 보간, 피치·FOV는 잠금 필드 | Camera Boom(SpringArm) + 피치 고정 | 자체 스크립트(LOCK 위반 위험, 비추천) |
| 흔들림 | Cinemachine Impulse Source(위치만) | Camera Shake Source | 자체 오프셋 |
| 가림 1단계 | 구형 캐스트 + 알파 블렌드 셰이더(깊이 선패스 + 블렌드 본패스), 속성 블록으로 `_Fade` 제어 | Material Parameter + 투명 머티리얼 | 화면 원형 컷아웃(부드러운 그라디언트) |
| 가림 2단계 | 렌더러 기능 Render Objects 2패스(깊이 테스트 Greater로 가려진 픽셀만 단색) | Custom Depth + Post Process 외곽/실루엣 | — |
| 시네마틱 카메라 | 별도 카메라 + 0.4초 블렌드 | Sequencer/Camera Cut | — |
| 판정 | 공용 실행기 캡처, 고정 위치 | 같음 | — |

커스텀 툴: 없음. 단, `OccluderFade` 컴포넌트(가림 대상 표시 + 페이드 값 관리)를 구현 서브에이전트가 만든다. 입력 = 레이어·캐스트 반경·시간 표, 출력 = 렌더러별 `_Fade`.

### 5.2 Unity 반입

| 항목 | 설정 |
|---|---|
| 레이어 | `Occluder`(고목·큰 바위·벽), `Hero`, `EliteBoss` |
| 셰이더 | URP Lit 기반 커스텀: 패스1 ZWrite On/ColorMask 0, 패스2 알파 블렌드 |
| 속성 | MaterialPropertyBlock `_Fade` 1 → 0.30 |
| 실루엣 | URP Renderer Feature Render Objects 2개: 대상 레이어, Depth Test = Greater, 단색 머티리얼 |
| 카메라 | Cinemachine 3 `CinemachinePositionComposer`, 거리 값만 보간, 피치는 잠금 |
| 흔들림 | `CinemachineImpulseSource` 위치 오프셋, 옵션 토글 연동 |
| 발밑 원 | Decal 또는 Projector, ZTest Always, 영웅 반경 내 |
| 안개 상한 | 적 레이어 셰이더에서 안개 계수 `min(fog, 0.25)` |

### 5.3 UE5 반입 (대응만)

SpringArm(피치 고정, 길이만 변경), Camera Shake(위치만), 가림은 투명 머티리얼 파라미터 + Custom Depth 스텐실 실루엣, 발밑 원은 Decal.

## 7. 금지

- 피치 변경, FOV 변경으로 줌 흉내, 마우스 휠 줌, 회전 흔들림.
- 디더·스크린도어 점 패턴 가림.
- 땅·다리·늪 수면을 투명화 대상에 넣기.

- 발밑 원을 버프·연출 때문에 숨기기.
- 실루엣에 빨강 사용.
- 카메라 규칙을 규칙 코어 수치(판정 범위)와 연동해 바꾸기.
