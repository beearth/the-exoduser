## 1. 목표 장면·레퍼런스 (무엇을, 왜)

- 목표 장면: 1-1 전투. 숲 바탕음 위에 약한 음악이 깔리고, 휘두름 → 타격(재질) → 피격 목소리 → 처치가 층으로 들린다. 적의 예고음(텔)은 어떤 혼잡 속에서도 들린다. 보스 방에 들어가면 음악이 전면으로 올라오고 바탕음이 내려간다.
- 사운드 디자인 기준: 「음습하고 아름다운 지옥」. 무겁고 짧은 타격, 마른 감쇠, 탁한 저역, 금속은 녹슨 흑철, 마법은 탁한 지옥불. 맑은 차임·밝은 판타지·긴 리버브 금지(`SOUND_LEAD_MASTER` §1).
- 레퍼런스: 디아블로4(오디오 중요도 시스템, 매 재생 변주, 몬스터 목소리 마지막 층), 디아블로2·3·PoE2(작은 필드 음악 + 환경음 휴지, 보스 음악 전면화), Phantom Blade Zero(타격음 무게는 임팩트 매뉴얼과 연동). 공개 수치가 없는 곳은 우리 시작값이며 청음으로 확정한다.
- 판정 원칙: 사운드는 **동작 영상과 함께** 고른다(사용자 11-04: "모션이 보여야 사운드를 고르지"). 청음 카드마다 장면 영상을 붙인다.

## 2. 디렉션 원칙

1. **예고(텔)가 항상 이긴다.** 적 공격 예고음은 우선순위 최상이고, 울릴 때 다른 전투 버스를 덕킹한다. 이유: 들리지 않는 예고는 불공정한 죽음이다.
2. **중요도로 믹스를 정한다.** 위험 소리(보스 예고·엘리트 기합)는 동시 발음 상한과 덕킹을 면제한다. 이유: D4 오디오 중요도 시스템의 핵심.
3. **음악은 작게 깔리고 쉰다.** 필드 음악은 낮은 레벨로 가끔 쉬고, 휴지에는 환경음이 드러난다. 보스에서만 전면화. 이유: 장시간 플레이 피로와 몰입.
4. **소리는 층이다.** 휘두름 → 타격(재질) → 피격 목소리 → 처치 고어/비명. 한 소리에 모든 걸 담지 않는다. 이유: 층 교체로 변주와 재질 구분을 만든다.
5. **같은 소리는 두 번 같지 않다.** 매 재생 피치·볼륨 변주, 같은 키 연속 억제. 이유: 반복 피로 방지, 타격감.
6. **화려함의 위계.** 큰 소리·긴 꼬리는 궁극기·보스 대기술만. 기본 공격은 배경에 녹는다. 이유: 클라이맥스를 만들 여지.
7. **모든 버스는 사용자가 나눠 조절한다.** 전체·음악·효과음(·음성) 분리. 이유: 접근성(XAG 105), 청각 취향.
8. **소리 없는 정보는 없다.** 시각 예고에는 반드시 소리가 같이 있다(색약·청각 보완은 반대로 시각 + 소리 중복). 이유: XAG 103.
9. **빈 칸을 숨기지 않는다.** 소리가 없는 장면은 목록에서 "없음"으로 남기고 청음 라운드에 올린다. 이유: 임시음이 영구음이 되는 것을 막는다.
10. **무음 자동 실행.** 자동 캡처·테스트는 소리 0, 청음은 사용자가 직접. 이유: CLAUDE.md 3.3.

## 4. 제작 도구

| 단계 | 역할 | Unity 추천(확정) | UE5 대응 |
|---|---|---|---|
| 믹스·덕킹 | 버스·스냅샷·사이드체인 | **Unity Audio Mixer(그룹 + Duck Volume) + 자체 `SfxPlayer`(풀·변주·우선순위)** — 이미 구현된 `NativeAudioMixer`/`NativeFeedbackAudio` 유지 | Sound Class/Submix + Sound Mix Modifier, 우선순위는 Concurrency Group |
| 효과음 생성 | 후보 생성 | **ElevenLabs(SFX Forge, SDK 직접 호출)**: 후보 3~4개, 전후 잔액 보고, 사용자 청음 후 채택 | 동일 에셋(wav/ogg) |
| 음악 | 곡 반입·루프 | **기존 BGM 파일 + 크로스페이드 컨트롤러**, 신곡은 사용자 지시 시 Suno 프롬프트(`주제가_SUNO_프롬프트.md`) | MetaSounds 또는 Quartz 크로스페이드 |
| 변주 | 피치/볼륨 랜덤, 쿨다운 | **`SfxPlayer` 설정 표(키별 피치 범위·쿨다운)** | MetaSound 랜덤 + Concurrency |
| 라우드니스 | 파일 정규화 | **ffmpeg loudnorm 일괄 + 결과 JSON**(`UNITY_BGM_IMPORT_P1_LOUDNORM`) | 동일 파일 |
| 청음 판정 | 후보 청음 페이지 | **HTML 청음 페이지(영상 + 소리 동시 재생)**, 사용자가 선택 | 동일 |
| 미들웨어 | 대안 | FMOD/Wwise: 데모 v0 규모에서 이득 < 비용으로 **기각** | UE5도 내장 오디오로 충분 |

- 커스텀 툴 명세 `sfx_audit`: 자동화 = 키별 파일 존재·길이·피크·LUFS·`.meta` 검사, 장면표(3.5) 대비 누락 목록 생성. 입력 = 오디오 폴더 + 장면 표. 출력 = 누락/임시/채택 상태표(JSON → 마크다운). 사용자 = 사운드 총괄·구현자. 만드는 사람 = 구현 에이전트(node).
- 유료 생성은 `docs/API연결_가이드.md` 범위 안에서만, 예약·차감은 SPEND_LOG.

## 5. 절차

### 5.1 공통 (입력 → 작업 → 출력 형식)

1. **장면 표 갱신**: 소리가 필요한 순간을 장면 순서로 나열(키, 상태: 채택/웹 이식/임시/없음). 출력 = `DEMO_1-1_SOUND_SCENES` 형식 표.
2. **후보 생성**: 입력 = 키 이름 + 길이 + 분위기 문장(「음습하고 아름다운 지옥」 금지어 포함). 출력 = 키당 3~4개 mp3/wav(44.1kHz, 16bit 이상), `v1~v4` 명명.
3. **영상과 같이 청음**: 후보마다 해당 동작 영상(5~8초 무음 영상)을 붙인 카드에서 동시 재생. 사용자 선택 후에만 채택(promote).
4. **정규화·트림**: 앞뒤 무음 제거, loudnorm, 피크 ≤ −1dBFS, 모노(효과음)/스테레오(음악·환경). 출력 `sfx/<분류>/<키>.ogg|wav`.
5. **키 등록**: 논리 키 → 파일 → 버스(그룹) → 우선순위 → 피치 범위 → 쿨다운을 한 표에 기록.
6. **믹스 판정**: 50체 전투 녹음(무음 환경 캡처가 아닌 오디오 덤프)에서 예고음 가시성(파형), 같은 소리 10연속 비교, 보스 진입 전환.
7. **소리 없는 장면 보고**: "없음" 칸을 표에 남긴다.

### 5.2 Unity 반입

- 오디오 클립: Sound 효과음은 Decompress On Load(짧은 것)/Compressed In Memory(긴 것), Load Type, 모노 강제(효과음), 음악 Streaming. `.meta` 포함 커밋.
- 믹서: `Exoduser.mixer` 그룹 구조 유지(`Exoduser/RM1 Sound/Build Mixer` 메뉴). 신규 그룹은 3.1 표에 추가.
- 코드: 이벤트는 Core가 틱·위치만 큐잉하고 재생 변주·게인·믹서는 어댑터(`NativeFeedbackAudio`)가 결정. Core 난수열을 바꾸지 않는다.
- 설정: `SfxVol`/`MusicVol` 노출 파라미터 유지, 음성 슬라이더가 필요하면 Voice 그룹에 파라미터 추가(D12-4).
- 번역: 소리 관련 설정 라벨은 MANUAL 14 절차로 등록.

### 5.3 UE5 반입 (대응만)

- 효과음 = Sound Wave(모노) + Sound Cue/MetaSound(피치·볼륨 랜덤), 버스 = Sound Class 계층(Master → Music/Ambience/SFX → 하위 8), 덕킹 = Sound Mix, 동시 발음 = Concurrency Group(Resolution Rule: Stop Lowest Priority).
- 스냅샷 Explore/Boss = Sound Mix 전환. 크로스페이드 = Audio Component Fade.
- 수치·우선순위 표는 3절 그대로.

## 6. 합격 기준

- 비교판은 소리용으로 읽는다: **같은 장면 영상에 현재판 소리 vs 새 소리**를 번갈아 청음, 10초 무음 영상은 시각 확인용 동기화 기준.
- 해상도 항목은 해당 없음(시각 UI 매뉴얼 참조). 1920×1080·3840×1080에서 소리 UI(슬라이더·자막)가 잘리지 않는지는 MANUAL 10에서 확인.

| ID | 합격 조건 | 확인 방법 |
|---|---|---|
| S1 | 50체 전투 오디오 덤프에서 예고음이 항상 파형에 보이고 들림 | 덤프 파형 + 청음 |
| S2 | 같은 소리 10연속 재생이 서로 다르게 들림(피치·볼륨 변주) | 청음 |
| S3 | 일반 타격과 강타(히트스톱 구간)가 구분됨 | 10초 영상 + 청음 |
| S4 | 보스 진입 크로스페이드 2.5초, 음악이 전면화되고 바탕음이 −8dB | 청음 + 믹서 값 |
| S5 | 필드 음악 휴지 구간에 환경음이 드러남 | 청음 |
| S6 | 예고·위험 소리가 있는 모든 시각 예고에 소리가 짝지어짐(장면표 "없음" 0) | 장면표 |
| S7 | 설정 슬라이더 0%에서 해당 버스가 완전 무음, 100%에서 클리핑 0 | 덤프 |
| S8 | 무창·무음 자동 실행에서 소리 출력 0 | 로그 |
| S9 | 사용자 청음 선택으로 채택된 소리만 `sfx/`에 존재 | 파일 대조 |

- 예산: 오디오 스레드 CPU ≤ 1.0ms [단일: d4_03_cam.md], 동시 활성 음성 ≤ 48(현행), 타격 층 CPU ≤ 0.2ms/GC 0B [단일].
- 같은 청음 라운드에서 같은 이유로 두 번 반려되면 생성 방법(프롬프트·도구)을 바꾼다.

## 7. 금지

- 청음·사용자 선택 전에 AI 생성 소리를 `sfx/`에 채택하는 것.
- 맑은 차임·밝은 판타지·긴 리버브. 모든 소리에 같은 꼬리.
- 예고음을 낮은 우선순위로 두는 것. 예고 덕킹 면제 없이 혼잡 장면을 닫는 것.
- Core 상태·난수열을 바꾸는 재생 로직. Core 판정 수치 변경.
- 자동 실행에서 소리 재생(창·소리 금지). 사용자 프로그램 종료.
- 웹 소리를 "이식 완료"로 계산하면서 청음 없이 새 소리와 섞는 것.
- 레퍼런스 게임 음원 반입. 승인 밖 유료 생성.
- 소리 설정 UI 문자열을 번역 등록 없이 표시.
