## 2. 디렉션 원칙

1. **연출은 게임 카메라 LOCK 안에서 한다.** 피치 고정, 거리만 변경. 이유: 03과 같은 이유, 연출이 끝나면 정확히 원위치.
2. **시네마틱은 실게임 모델·실게임 엔진 안에서만 만든다.** 렌더 컷, 합성, 별도 영상 소스 금지. 이유: 실게임 증명이 데모의 신뢰다 [사실, yellowsky 규칙 9, D4 엔진 시네마틱 d4_04 S42·S43].
3. **모든 연출은 건너뛸 수 있다. 홀드로.** 이유: 죽은 시간 방지, 내부 관례 [사실 내부, conventions J3].
4. **연출 중에도 Core 시간은 규칙 코어가 정한다.** 표현 전용 시계(애니메이션·VFX·카메라)만 따로 다룰 수 있고, 어떤 시계에 적용하는지는 D13-10★에서 정한다. 승인 전에는 Core 신호의 표현 소비(07 §3.1b)만 한다. 이유: 판정은 코어가 정답.
5. **짧고 무겁게.** 등장 4초 이내, 퇴장 3초 이내. 이유: 죽은 시간.
6. **정적을 설계한다.** 연출 끝 → 체력바 → 첫 예비동작 사이에 숨 돌릴 시간을 둔다. 이유: 보스 템포 읽기 [추정, d4_04 ⑩].
7. **연출 음 먼저, 그다음 화면.** 예고음은 시각과 동시, 다른 음은 덕킹 [사실 내부, conventions E4].
8. **움직임 줄이기 옵션을 연출이 존중한다.** 흔들림·늘이기 0, 페이드는 유지. 이유: 접근성 [사실, d4_03 §1, conventions K5].
9. **영상 데모는 편집으로 거짓말하지 않는다.** 컷만 허용, 속도 조작·합성 금지. 이유: 신뢰.
10. **먼 적은 연출 중에도 가려지지 않는다.** 이유: 카메라 LOCK.

## 7. 금지

- 피치 변경, 회전 카메라, 렌더 컷·합성·속도 조작.
- 스킵 불가 연출. 코어 시간 정지로 히트스톱 구현.
- 4초 넘는 등장, 3초 넘는 퇴장.
- 먼 적을 가리는 연출, 검은 판·블러 채움 화면.
- 필름 그레인·디더 페이드, 점 패턴 전환.
- 연출 때문에 규칙 코어 판정 변경. 발을 숨겨 높이를 속이는 시네마틱 기법(발밑 = 코어 원).
- 사용자 모니터에 창·소리를 띄우는 캡처.
- 근접 홍보 카메라·트레일러 푸시인을 플레이 중 매 타격 반응이나 카메라 변경 근거로 옮기기(codex_synthesis §1.12·§2). PBZ 푸시인은 실측 플레이 값이 아님.
- 연출 종료 뒤 상태·음악·자막·입력 복귀를 확인하지 않고 완료 처리하기. 시네마틱 렌더 자동화 성공을 실제 플레이 검증으로 대신하기.
