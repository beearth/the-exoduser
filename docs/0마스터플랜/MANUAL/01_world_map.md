# MANUAL 01 — 월드·맵 (지형·재질·소품 군집·접지·물·늪) (초안 2026-11-05)

- 상태: 초안 | 연구 반영: d4_01_env(D4_STUDY/01_environment.md), poe2(GAME_STUDY/poe2.md), conventions(ARPG_CONVENTIONS_CHECKLIST_20261105.md), yellowsky(GAME_STUDY/downfall_of_yellowsky.md, 맵 근거 없음 확인) | 연구 반영 대기: Yellowsky 환경 연구(공개 근거 0건), PoE2 발표 영상(S02)의 지형 블렌드 세부, D4 원문 대조(E1·E5·E8·E14~E18), 연구 tech budget(15번 문서와 연동)
- 범위: 1-1 숲길(남→북 다리·양쪽 늪·고목 전경)의 지형, 지면 재질, 소품 군집, 접지, 물·늪 표현, 제작 순서. 1-2 이후는 같은 키트에 테마만 갈아 끼우는 규칙까지.
- 이 문서가 정하지 않는 것: 광원·안개·색 보정(02), 카메라·가림(03), 게임 규칙(걷기 칸·충돌·NavMesh는 규칙 코어 `unity/Assets/Exoduser/Runtime/Core`가 정답), 웹 1-1 소품의 좌표와 종류(CLAUDE.md "맵": 웹 좌표 그대로).
- 사용자 평가(11-04): "붕 뜨고, 안 맞고, 듬성듬성, 색이 구리다." 이 문서는 이 네 가지에 각각 답한다. 붕 뜸 = 접지, 안 맞음 = 재질 경계와 스케일, 듬성듬성 = 군집과 식생 밀도, 색 = 명도 리듬(02와 공동).

## 2. 디렉션 원칙

1. **웹 소품의 좌표·종류는 고정, 바꾸는 것은 곁가지뿐이다.** 곁가지 = 소품 둘레의 작은 잔해·풀·뿌리·데칼. 이유: 사용자 규칙이고 규칙 코어의 걷기 칸과 맞아야 한다.
2. **길은 비우고 길가를 채운다.** 다리·통로 위 소품 0, 가장자리와 늪가에 무리. 이유: 전투 판독과 이동 판독을 지킨다 (PoE2 R8, D4 관찰).
3. **소품은 혼자 두지 않고 무리로 둔다.** 큰 것 1 + 중간 2~3 + 작은 것 5~8 + 카드(풀) 6~12. 이유: "듬성듬성"의 직접 해법. 밀도가 있어야 빛 웅덩이와 그늘의 대비가 생긴다.
4. **세로 소품은 반드시 접지 3종 세트를 가진다.** 접촉 그늘, 쌓임, 하단 블렌드. 이유: 화면 공간 AO만으로는 먼 카메라에서 접지가 안 된다 [단일, D4 조사 E9 Digital Foundry].
5. **재질 경계에 직선이 없다.** 모든 경계는 높이 기반 섞임. 이유: 아트 바이블 §6 규칙, "안 맞음"의 가장 큰 원인.
6. **한 층이 한 화면의 60%를 넘지 않는다.** 바닥 재질은 4층을 모두 보이게. 이유: 단색 바닥이 "색이 구리다"의 큰 부분이다 [추정].
7. **같은 소품은 변형 3종 이상.** 온전·부서짐·반쯤 무너짐. 이유: 반복이 눈에 띄지 않게 [단일, PoE2 S19a].
8. **식생(풀·덤불·뿌리 카드)이 빈 바닥을 채우는 주 수단이다.** 이유: D4는 다른 3D 에셋보다 식생에 훨씬 많이 기댄다 [단일, D4 조사 E17].
9. **물과 늪 기슭은 번쩍이지 않는다.** 스페큘러 상한을 둔다. 이유: 고정 카메라에서는 하이라이트가 눈에 거슬린다 [단일, D4 조사 E18].
10. **키샷 구역이 PASS하기 전에 다른 구역으로 넓히지 않는다.** 이유: 요소별 따로 PASS는 한 화면에서 처음 만나면 안 맞는다 [추정, d4_01 §6].

**커스텀 툴 명세 `ForestKit Scatter`**

| 항목 | 내용 |
|---|---|
| 자동화하는 것 | 웹 소품 둘레의 곁가지 배치(중간·작은 소품·카드·접지 데칼)와 군집 사이 낙엽 띠 |
| 입력 | 웹 소품 좌표 목록, 걷기 경로 마스크, `ForestKit` 데이터(크기 등급·최소 간격·접지 데칼 지정), 시드 |
| 출력 | 씬에 굳은 프리팹 인스턴스(런타임 무작위 아님), 걷기 칸·NavMesh 차이 보고 |
| 사용자 | 환경 구현 서브에이전트(Sonnet) |
| 만드는 사람 | 총괄 세션의 구현 서브에이전트, Mac에서 1회 검증 |
| 규칙 | 시드 고정 포아송 원판 간격, 길 마스크 제외, 큰 소품 5타일 간격(웹 W3 산포 규칙과 같은 정신) |

## 5. 절차

### 5.1 공통 (입력 → 작업 → 출력 형식)

| 단계 | 입력 | 작업 | 출력 형식 |
|---|---|---|---|
| S1 키샷 고정 | 1-1 장면, 카메라 LOCK | 카메라 위치·적 배치·HUD 켬을 명세로 고정 | 캡처 명세 1장(위치·시각·파일명 규칙 `keyshot_<단계>_<해상도>.png`) |
| S2 블록아웃 | 웹 소품 좌표, 아트 바이블 명도 V1~V6 | 회색 재질로 형태·명도 리듬만 맞춤 | 회색 상자 캡처 1920×1080, 3840×1080 |
| S3 지면 재질 | 4층 정의 | 타일 4종 제작, 높이 블렌드 연결, 저주파 마스크 칠하기 | 타일: 2048² PNG/TGA(색 sRGB, 노멀, 마스크 선형), 알파맵 512² |
| S4 소품 군집 | 웹 소품 좌표, ForestKit | 배치 도구 실행, 길 비우기 확인 | 씬 프리팹 + 배치 보고(걷기 칸 덮임 수) |
| S5 접지 | 세로 소품 목록 | 접촉 그늘·쌓임 데칼 부착, 하단 블렌드 머티리얼 | 데칼 아틀라스 2048² PNG(알파, 8칸) |
| S6 물·늪 | 늪 영역, 젖음 띠 폭 | 기슭 띠와 수면 머티리얼, 스페큘러 상한 | 수면 머티리얼 + 기슭 데칼 |
| S7 식생 | 빈 바닥 비율 측정 | 카드 무리로 35% 이하까지 채움 | 카드 FBX + 알파 PNG |
| S8 단계 캡처 | 위 모두 | 단계마다 같은 위치에서 캡처, "남길 것/더할 것" 기록 | 단계별 PNG + 메모 1줄 |

명명: 소품 `Forest_<종류>_<변형번호>`, 데칼 `Decal_<종류>_<번호>`. 모델 FBX는 Y-up, 1 단위 = 1m, 변환 적용.

### 5.2 Unity 반입

| 항목 | 설정 |
|---|---|
| 모델 | Scale Factor 1, Read/Write 끔, Generate Lightmap UVs는 정적 베이크 대상만 켬 |
| 지형 레이어 | TerrainLayer: Diffuse sRGB, Normal 타입 Normal map, Mask Map 선형. 지형 머티리얼에서 높이 기반 블렌드(Enable Height-based Blend) 켬(레이어 4개 이하) |
| 코드 조립분 알파맵 | PNG 512²를 `TerrainData.SetAlphamaps`로 반입 |
| 데칼 | URP Decal Renderer Feature(DBuffer). Decal Projector 깊이 0.5u. 키트 프리팹에 포함 |
| 식생 카드 | URP Lit, Alpha Clipping 0.4, 그림자 켬, GPU Instancing 켬 |
| 하단 블렌드 | Shader Graph: 오브젝트 높이 → 지형 재질 Lerp |
| 이끼 윗면 | Shader Graph: 월드 법선 Y → Smoothstep → Lerp |
| 레이어 | `Occluder`(가림 대상, 03 참고), `Ground`, `Decor` |
| 정적 플래그 | 군집 소품은 Static |

## 6. 합격 기준

| 판정 | 방법 | 합격 |
|---|---|---|
| 비교판 1 | 이전·이후 같은 위치 캡처를 나란히 | 나아짐 또는 같음. 나빠지면 병합 금지(방향 전환 새 규칙) |

| 1x 크롭 | 직선 경계 0, 소품이 뜨지 않음 | 0건 |
| 3x 크롭 | 점·잡티 0, 계단 0, 데칼 가장자리 선 0 | 0건 |
| 10초 무음 영상 | 영웅이 다리를 걸어 고목을 지나감. 바닥 타일 반복, 데칼 깜빡임 확인 | 깜빡임 0 |
| 먼 적 | 위쪽 25% 구간에 적 3마리 이상이 보임 | 가려지면 FAIL |
| 걷기 칸 | 소품·데칼이 걷기 칸을 덮은 수 | 0, NavMesh 차이 0 |
| 예산 | 화면 삼각형 300k 이하, 15번 문서 한도 | 초과 시 RETOUCH |

RETOUCH는 PASS가 아니다. 결함·담당·다음 산출물을 적는다.

## 7. 금지

- 새 구도를 그리는 것. 웹 소품 좌표를 옮기는 것.
- 직선 재질 경계. 단색 바닥. 디더링·점묘 마스크(점 금지).
- 화면 공간 AO만으로 접지를 PASS하는 것.
- 길 위 소품. 먼 적 위를 덮는 전경 덤불.
- 늪 수면의 강한 스페큘러 번쩍임.
