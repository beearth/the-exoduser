# Mixamo 공격 클립 선택표 (2026-11-05, Mac)

**다운로드 전 표다. 미리보기 썸네일과 프레임 수만 봤고 파일은 받지 않았다.** 자세는 8칸 썸네일을 눈으로 본 것이고 측정이 아니다. 길이는 Mixamo 화면의 total frames(30fps)이며, 표시가 늦게 갱신되는 경우가 있어 받은 뒤 다시 확인한다.

사용자 판정: Downward Slash FAIL("야구 같다"). 예비에서 양손을 어깨 높이로 올리고 칼을 뒤로 눕히는 자세가 타자와 같다.
