# MANUAL 07 — 전투 임팩트 디렉션 (초안 2026-11-05)
- 상태: 초안 | 연구 반영: pbz(Phantom Blade Zero), d4_03_cam(§8.7 피격·§8.8 숫자·흔들림), d4_04_anim A7, yellowsky 규칙6, 5.1 IMPACT_REFERENCE_PBZ_DOTA2_20261103 R1~R8 | 연구 반영 대기: PBZ 실제 게임 프레임 데이터(공개 자료 없음), 피 데칼 3.5초 Mac 실측, 소리 층 수치(06사운드 매뉴얼과 연동)
- 범위: 히트스톱·포즈 홀드, 카메라 임펄스, 섬광·잔상, 피해 숫자, 처치 연출, 패링 등급 연출. / 정하지 않는 것: 데미지·패링 판정·보상 수치(Core, `Core/ParryRewards.cs` 등). 2_3 설계는 바꾸지 않는다.

## 1. 목표 장면·레퍼런스 (무엇을, 왜)
- 목표 장면: 적 여러 마리가 있는 1x 화면에서 한 번 베고, 한 번 패링하고, 한 마리 죽일 때 "맞았다"가 즉시 읽히는 장면.
- 기준: Phantom Blade Zero(끊기지 않는 흐름, 등급별 방어 구분, 어두운 세계에서 밝음은 접점에만). 보조: 디아블로4(숫자 색 구분), 도타2(11-03 실측).
- 왜: "임팩트가 다 엉망"(사용자). 단, PBZ도 "접촉이 약하다"는 평을 받았다 — 같은 비판을 피해야 한다.

## 2. 디렉션 원칙
1. 시뮬레이션 시간은 멈추지 않는다(11-03 R3 유지안). 대신 맞은 대상 하나에 즉시 확인을 찍는다. 이유: 적이 많으면 전역 정지가 화면을 끊는다.
2. 접점 순간만 밝다: 코어 5틱(최대 8), 따뜻한 백색 선 스파크, 나머지 화면은 어둡게. 이유: 어두운 세계의 밝음은 접점에만(PBZ 규칙9).
3. 패링 등급은 동작·소리·빛 세 채널 모두 다르다. 이유: 막기와 완벽 패링이 같아 보이면 PBZ가 받은 비판을 받는다.
4. 정지 대신 반응: 흰 히트 플래시 2~3틱, 몸 밀림, 스파크. 이유: 작은 캐릭터는 몸 반응이 안 읽힌다.
5. 카메라 흔들림은 위치 오프셋만, 회전 0, 큰 사건에서만, 옵션으로 끈다. 이유: 피치 LOCK과 멀미.
6. 숫자는 종류별 색(일반·치명·특수)이고 원색 노랑을 쓰지 않는다. 이유: 실버 헬 토큰.
7. 아군 효과가 적 예고를 가리지 않는다(대상 가림 ≤0.2초). 이유: 적 예고가 항상 위.
8. 피는 무광 어두운 적갈, 바닥 데칼로 남긴다. 이유: 탑다운에서 바닥 데칼이 가장 잘 보인다.
9. 처치는 사망 포즈 → 피/파편 → 소멸 순서이고 점묘 소멸 금지.
10. 모든 섬광·플래시는 뼈색/은백 계열. 시안·네온 금지(R8).

## 4. 제작 도구 — 확정 추천: 엔진 파티클 시스템 + 플립북 시트(Blender/기존 시트 재사용)
| 역할 | Unity 추천 | UE5 대응 |
|---|---|---|
| 접점 스파크/먼지/피 | Shuriken 파티클 + 플립북 시트(가산/알파) | Niagara 스프라이트 이미터 |
| 대상 히트 플래시 | 머티리얼 프로퍼티 블록 `_HitFlash` 2~3틱 | 다이내믹 머티리얼 파라미터 |
| 카메라 임펄스 | 자체 오프셋(기존 리그 유지) 위치만 | Camera Shake(위치 채널만) |
| 포즈 홀드 | Animator 속도 0 해당 대상만, 2~6틱 | Anim Montage Play Rate 0 해당 대상만 |
| 숫자 | TextMeshPro, Cinzel 숫자 | UMG/Slate 또는 3D 텍스트 |
| 소리 층 | 믹서 그룹 분리(접촉·무게·꼬리) | MetaSound/Sound Class 분리 |
- 대안: VFX Graph / Niagara GPU — 대량 입자(독안개)에만.
- 커스텀 툴 — "임팩트 이벤트 프리뷰어": 입력 이벤트 종류(막기/완벽 패링/경타/마무리/처치)와 등급, 출력 같은 크기 비교판 PNG 한 장·무음 6초 영상. 사용자 = VFX 레인과 총괄. 이유: 등급별 차이를 한눈에 판정.

## 5. 절차
### 5.1 공통
1. 입력: 이벤트 목록(Core FeedbackEvent 종류), 등급별 3채널 표(§3.2).
2. 작업: 접점 → 스파크/플래시 → 소리 층 → 흔들림 → 숫자 순서로 하나씩 켜며 1x에서 확인. 한 번에 다 켜지 않는다.
3. 출력: 플립북 시트 PNG(4×4, 128 또는 256 셀, 알파 premultiplied), 이름 `fx_<종류>_<등급>_<셀수>.png`, 파티클 프리셋 `fx_<종류>_<등급>`, 소리 에셋 `sfx_<종류>_<층>`.
### 5.2 Unity 반입
- 텍스처 Bilinear, mipmap 없음, 압축 없음(점 방지). 머티리얼 SkillAdditive(빛) / 알파(피·먼지). 피드백은 Core FeedbackEvent를 읽어 표시 전용 뷰에서 재생(Core RNG 소비 0).
### 5.3 UE5 반입 (대응만)
- 플립북은 Sub UV 이미터, 표시 전용 이벤트는 델리게이트로 구독, 믹서는 Sound Class.

## 6. 합격 기준
- 비교판: 막기 / 완벽 패링 / 경타 / 마무리 / 처치 5장면을 같은 크기로 PBZ 공개 영상 옆(감각 대조, 복제 아님). 1920×1080·3840×1080.
- 1x에서 막기와 완벽 패링이 소리 끄고도 구분된다(빛·스파크 수). 10초 무음 영상으로 확인.
- 3x 크롭 점 0. 50체 전투에서 숫자가 플레이어 실루엣을 덮지 않음, 먼 적이 섬광에 지워지지 않음.
- 예산: 히트 이벤트 CPU 0.1ms 이하, GC 0B/프레임(숫자), 60fps.

## 7. 금지
- Core 시간 정지를 사용자 결정 없이 추가. 슬로모션.
- 시안·네온 섬광, 빨강 예고(빨콩과 혼동), 잉크·먹선 이펙트 본체.
- 흔들림에 회전 사용(피치 LOCK 위반). 전역 화면 플래시 Δ>40.
- 가림 알파가 먼 적을 지우는 비네트 펄스. 그레인·디더·잔점.
- 무지개탄은 Q로만 패링(E 불가) 표현 위반: E 패링 성공 연출을 무지개탄에 붙이지 않는다.

## 8. 사용자 결정 필요 항목
- D07-1: 11-03 R3("히트스톱·슬로 없음")를 유지하되, 표현 포즈 홀드를 허용하는가? 연구 A는 ≤2틱, 연구 B는 경타 2~3·강타 4~6틱. 추천: 안 A(≤2틱, 대상 한 개) + 히트 플래시 필수. 대안: 안 B, 또는 홀드 0.
- D07-2: Core의 패링 히트스톱 2틱·포이즈 붕괴 슬로 20을 표현에서 억제(보상 규칙은 불변)하는가? 추천: 슬로만 억제, 히트스톱 2는 D07-1 따름. 이것은 Core 제안이다.
- D07-3: 푸시인 2~3%(R4)를 유지하는가? 추천: 유지하되 근거를 "트레일러 편집"으로 정정, 거리만 변경.
