# EXODUSER 추가 팀 구성 제안

작성일: 2026-09-30. 사용자가 아트·맵·스킬·UI/UX·아이템·사운드 6개 팀을 신설했다고 설명하고 추가로 필요한 팀을 질문한 데 따른 제안이다. 이 문서는 새 팀·채팅·에이전트를 생성하거나 기존 팀에 업무를 전달한 기록이 아니다.

후속 사용자 지시로 Codex가 총괄 프로젝트 팀장을 맡았다. 현행 팀 등록부와 실행 우선순위는 [총괄 프로젝트 관리](PROJECT_MANAGEMENT_MASTER.md)를 따른다. 아래 추가 5팀은 계속 신설 제안 상태다.

## 먼저 추가할 역할

| 우선순위 | 제안 팀 | 담당 범위 | 초기 산출물 |
|---|---|---|---|
| 1 | QA·성능 최적화팀 | 프레임 드랍 재현, CPU/GPU·메모리 측정, 입력 지연, 저장·진행 오류, 실제 브라우저와 Windows 패키지 회귀 검수 | 동일 장면·조건의 수정 전후 측정과 재현 절차, 미해결 결함 목록 |
| 2 | 몬스터·보스·AI팀 | 일반몹·희귀몹·보스 행동, 공격 예고와 판정, 추적·길찾기, 전투 조합과 보스전 완성도 | 적 유형별 패턴·약점·대응표와 실제 교전 검수 |
| 3 | 통합·빌드팀 | 팀 간 공용 코드 변경 조율, 에셋 실제 연결, 의존성·캐시·패키지 포함 확인, 웹·NW.js·Steam용 빌드의 버전 추적 | 포함 변경 목록, 원본과 패키지 버전 식별, 실행 검수 및 배포 상태 기록 |

현재 프레임 드랍 제보에 대응하는 QA·성능 역할을 가장 먼저 둔다. 성능 결론은 같은 조건의 실측에 근거한다. 기존 렌더러·맵의 LOCK 규칙을 유지하며, 구체적 변경은 해당 문서와 최신 사용자 지시를 따른다. 공격 동시 제한으로 부하를 숨기는 설계는 허용하지 않는다.

## 다음으로 분리할 역할

| 제안 팀 | 별도 책임 | 기존 팀과의 경계 |
|---|---|---|
| 전투 밸런스·성장 경제팀 | 스킬·아이템·적 수치의 통합 검증, 빌드 다양성, 드롭·성장·강화 비용과 난이도 흐름 | 개별 콘텐츠 제작은 기존 팀. 공통 수치 변경안을 검증하고 확정 설계는 임의 변경하지 않음 |
| 애니메이션·VFX팀 | 캐릭터·적 동작, 공격 선후딜 표현, 피격·타격 피드백, 스킬 효과 가독성 | 아트팀은 외형·재질·원화 기준, 스킬팀은 동작 규칙·피해·자원 계약을 제공. 전투 타이밍과 효과를 함께 검수 |

내러티브·퀘스트와 현지화는 담당자를 지정해 두고, 제작 범위가 늘어날 때 별도 팀으로 분리한다. 지원사업·퍼블리싱·홍보 자료는 현재 사업화 작업 흐름에서 이어갈 수 있다.

## 공통 운영 기준

- 각 팀은 담당 문서·파일·함수 범위, 현재 작업, 검수 결과와 남은 문제를 기록한다.
- `game.html` 등 공용 파일은 수정 구역과 공통 계약을 먼저 정하고, 겹치는 변경은 통합 담당이 조율한다. 여러 팀이 같은 함수나 수치를 동시에 덮어쓰지 않는다.
- 제작팀이 결과물을 연결하고 자체 검수한 뒤 QA팀이 실제 플레이와 성능을 확인하고, 통합·빌드팀이 배포 대상 패키지를 검수한다.
- 코드·에셋 작성, 실제 게임 적용, 검수 통과, 패키징, 업로드·배포를 각각 구분해 보고한다.
- 새 팀 생성·기존 채팅 메시지 전송·담당자 지정은 이번 질문만으로 실행하지 않는다.
