## 2. 엔진 영향 — 결정(11-05 20:00 KST, §0 ① 확인 뒤)
- **웹 필수가 확인됐다(§0 ①).** 따라서 **이번 제출은 Unity WebGL/WebGPU 빌드(A)로 간다.** UE5는 제출 경로가 없다. 웹 H5판(B)은 A가 1주 실측(아래 실패 조건)을 못 넘을 때의 대안으로만 둔다.
- 실패 조건(A 포기 기준): 축소 빌드 ≤300MB·첫 화면 ≤20초·1080p WebGPU 30fps 이상·1-1 전투 1분 예외 0. 선행 실측 DT-16(10-28, 축소 174.9MB·12.4초·WebGPU 진입 OK)이 있어 통과 가능성이 높다. 남은 결함: ReadPixels WebGPU 실패(리그픽셀 캡처 경로), HUD 슬롯 바 회색 띠, 기기별 텍스처 포맷, WebGL2 폴백·fps·전투 미측정(PC 재측정 중).
- **UE5 비교 실험은 제출(01-07) 뒤로 보류한다.** Mac·PC의 UE 작업을 멈추고 그 시간을 캐릭터·모션·1-1 웹 빌드에 쓴다. 지금까지의 UE 결과(빈 바닥·C1 반입·Day1 문서)는 브랜치에 보존. "제출 뒤 전환 여부"는 그때 K1으로.
- 매뉴얼 4·5절(도구·반입)은 Unity판만 먼저 확정한다.
- 카테고리: 액션 RPG 항목이 없어 **Experimental(open format)** 로 낸다(§0 위험표). 제출당 1카테고리.
- 새 위험에 대한 조치: ① **권리 점검 레인 LC** — Unity 프로젝트가 참조하는 모든 자산(모델·텍스처·음악·효과음·폰트·영상)의 출처·라이선스 표, 권리 불명은 교체 목록(Fontainebleau 측정물은 반입 금지 유지) ② **폭력 수위**: 처치·피 데칼·절단 연출을 "YouTube 허용 수준"으로 정하는 기준을 매뉴얼 07에 넣고, 사용자 결정 ③ **개인 자격**: 사용자 개인 명의 제출(회사 명의 불가) — 사용자 확인 ④ **AI 혁신 25%**: 생성 메시 금지는 유지하되, 우리 파이프라인(에이전트 제작·절차·출처 기록)과 ElevenLabs 사운드를 BTS로 보여준다. Meshy 올해의 게임상은 노리지 않는다(사용자가 바꾸면 그때) ⑤ **제작 시작일 상충**: 규칙 페이지(기존 프로젝트 가능) 우선, 주최 문의는 사용자 계정으로.

## 4. 스폰서·AI 도구 관련
- 심사는 출력물 기준이라 스폰서 도구 사용은 의무가 아니다(AI 도구 1개 이상 사용은 필수 — 우리 파이프라인이 충족). 우리 파이프라인 자체(Claude/Codex 에이전트 제작, 문서화된 절차)가 비하인드 신의 재료다.
- ElevenLabs 효과음·보이스는 이미 매뉴얼 12의 계획(승인 대기)이라 자연스럽다. **Meshy 스폰서상은 생성 메시 폐기 결정(11-05 09:30)과 충돌** — 노리지 않는다(사용자가 바꾸면 그때).
- 무료 스폰서 크레딧 신청은 사용자 계정이 필요하므로 사용자 몫.
