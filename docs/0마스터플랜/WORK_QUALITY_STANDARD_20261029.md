판정 등급은 [AAA 기준](AAA_QUALITY_STANDARD_20260927.md), 배정·자동화·진행 순서는 [작업 매뉴얼 v3](WORK_MANUAL_20261029.md)에만 둔다. 아래는 화면/동작/청취의 통과 조건이다.

## 1. 분야별 통과 조건

| 분야 | 통과 조건·실제 근거 |
|---|---|
| 타이틀·로비·메뉴·캐릭터 선택 | 최신 화면별 승인 계약, 큰 메인 이미지·정보 위계·재질·조명·UI의 조화. 필요한 원화/9-slice를 기본 CSS·벡터 도형·색/테두리 변경으로 대신하지 않음 |
| HUD·이식 UI | 웹의 해당 source SHA·배치·크기·글꼴·입력 피드백 유지. 실제 해상도·1x에서 정보 판독 가능 |
| 맵 | 현행 LOCK의 큰 구도·외곽 질량·깊이·접합·재질·접지·전투 공간이 실제 게임 카메라에서 성립. 작은 소품·평균색 일치로 큰 결함을 덮지 않음 |
| VFX | 예고→접점/방향→본체→잔여가 판정과 맞고 밀집 전투의 적 탄막·위험·대상을 가리지 않음. 이식 효과는 원본 계약, 승인 리모델은 해당 SSOT로 비교 |
| 보스·캐릭터 3D | DESIGN LOCK의 정체성·체형·실루엣·재질·접지, 리그·대기/이동/공격/전환이 실제 게임에서 성립. 폭 축소·발광·소품으로 잘못된 조형을 감추지 않음 |
| 동작·연출 | 실제 게임 영상/연속 프레임에서 무게·타이밍·발 미끄러짐·무기 파지·전환·VFX/SFX 연동을 확인. 정지 PNG로 동작 PASS 금지 |
| 사운드 | 장면/동작과 함께 실제 청취해 타격감·레벨·루프·가림을 확인. 파일·파라미터·수치만으로 청취 완료 금지, 기존 사용자 선택 권한 유지 |
| AI 이미지·재질 | 1x에서 잔점/디더링·이음새·늘어짐·유실 텍스처가 없고 부위별 소재가 읽힘. 게임 톤·개별 LOCK을 지킴 |
| 텍스트·번역 | 게임 글꼴 토큰, 현행 지원 언어 전체의 최종 병합 테이블·동적 문자열·1x 가독성 확인 |

## 2. 나란히 비교 절차

1. 제작자가 작업 중 필요한 실제 레퍼런스 이미지·영상 프레임을 직접 열고 파일/출처/확인 시점·배울 특성을 기존 브리프에 연결한다. 기억·글 요약·남의 과거 열람은 본인의 검수를 대신하지 않는다.
2. 목표 장면/경험·현재 핵심 차이·제작 방법·가장 이른 실물 판정·합격/중단 조건을 정하고 큰 형태/구도부터 만든다. 모든 분야에 같은 테·폰트·색 수를 강제하지 않는다.
3. 같은 후보를 실제 게임의 카메라·배경·해상도에서 캡처한다. 전체 화면과 1x 세부, 동작은 영상/연속 프레임, 소리는 청취 근거를 남긴다. 스튜디오/검수 조명·강제 상태는 표시한다.
4. 같은 화면상 크기의 **레퍼런스 | 결과** 비교 이미지를 만든다. 카메라·노출·배경 차이를 표시하고 구도·실루엣·재질·조명·접지·가독성·동작 중 적용 항목을 대조한다.
5. 가장 큰 실제 결함 하나를 고치고 다시 비교한다. 목표 품질의 큰 차이·핵심 결함이 남으면 최종 완료본으로 제출하지 않는다. EXODUSER의 의도적인 정체성 차이를 복제해 없애지 않는다.
6. 평가 범위·실제로 본 근거·등급·구체 결함·다음 행동을 기존 보드에 남긴다. 결함·차단·미검증은 즉시 3줄 보고하며, 사용자가 중간 시안을 요청하면 현재 판정과 함께 보여준다.

새 PC 비교 출력은 I:/EXODUSER-Storage/<역할>/<실행ID>/, Mac은 승인된 해당 호스트 경로다. 외부 레퍼런스 파일은 Git·게임 에셋에 넣지 않는다.
