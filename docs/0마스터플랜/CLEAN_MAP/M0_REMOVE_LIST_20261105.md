## 3. 끄기 전에 확인할 것

코드와 기록에서 읽은 내용이고 **실행으로 확인하지는 않았다.**

1. **보이지 않는 벽.** 거목은 그림과 별개로 통행·투사체를 막는다(`A2BlockedCore`, `SolidCore`, KS:234). 브리프대로 좌표를 유지하면 빈 바닥에 투명한 벽이 남는다. 나무 아래 충돌은 Core 변경 0 원칙과 부딪치므로 **CTO 판단이 필요하다.**
2. **공중 부양.** Hollow, Stump, Fallen_Log, 뿌리는 변형 뒤 `A2FieldRegister`로 지면 높이에 등록된다(KS:99). 렌더러만 끄면 영웅이 안 보이는 물체 위에 뜰 수 있다. 등록까지 함께 건너뛰어야 하는지 M0 캡처에서 영웅 발밑을 확인한다.
3. **지면 변형.** 뿌리 부조와 수로가 지면 메시에 영향을 주는지는 보지 않았다.
4. **나무가 없어져 보이는 조명 변화.** 거목이 그림자와 차광을 맡고 있었으므로 "지금 조명 그대로"여도 화면은 크게 밝아질 수 있다. M2 전 M0 판정에 감안한다.

## 4. 한계

- 입장 시점의 장면 1회 기록이다. 실행 중 켜지는 소품은 다른 값일 수 있다. 꺼진 Renderer 241개(`RF3_Withered_Shrub` 114개, 화로 등)는 표에서 뺐고 CSV에 있다.
- `Graphics.DrawMesh` 계열은 A2 파일과 `NativeGame.Remodel3D.cs`를 검색해 없음을 확인했다. 그 밖의 코드는 훑지 않았다.
- 분해 문서의 이끼 바위(`RF3_Moss_Rock_*`)는 이번 기록에 켜진 상태로 없다.
- 미확인은 "문서에서 못 찾음"이라는 뜻이다. PC의 `I:/EXODUSER-Storage/demo-art/blender-env/`에 있는 영수증은 Mac에서 볼 수 없다.
- 카메라·프레임당 삼각형은 재지 않았다. 표는 장면 전체 합계다.

## 5. 판정 방법 (이 브랜치에 기록할 내용)

PC가 M0~M3 캡처를 올리면 단계마다 다음을 적는다: 전·후 비교판, 3x 점 검사, 먼 적 3마리, 접지, 황천·La Divina Commedia 기준 캡처 옆 비교. 합격 기준은 브리프 `BRIEF_CLEAN_MAP_20261105.md` §1이다.
