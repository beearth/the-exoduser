# 프로젝트 공통 품질 목표 — AAA급 게임

2026-09-27 사용자 확정: **모든 작업은 AAA급 완성도를 목표로 하며 AI가 할 수 있는 최선을 다한다.** 목표 선언·문서·파일 생성·테스트 통과만으로 AAA 달성이나 제품 완료를 주장하지 않는다.
실제 실행 결과와 승인된 게임 설계·분야별 LOCK을 기준으로 평가한다. 제작·비교 방법은 [품질 기준](WORK_QUALITY_STANDARD_20261029.md), 실행 순서는 [매뉴얼](WORK_MANUAL_20261029.md)에만 둔다.

## 완료 판단

기능·시각/동작/청취·실게임·원격·사용자가 여는 실행본의 증거를 구분한다. 해당 작업의 필수 항목이 충족돼야 그 범위의 완료다. 사용자 채택·유료 지출·배포 권한을 자동으로 얻지 않는다.

## 2026-10-29 실행 규칙 — 시각 완성도와 재작업 책임

### 합격선 — 기준 샘플과 단계별 탈락 조건

| 등급 | 의미 |
|---|---|
| FAIL | 승인된 정체성·큰 형태·재질·조명/접지·동작·기능의 핵심 결함. FAIL 아트는 채택하지 않고 원인이 있는 제작 단계로 돌아감 |
| 미검증 | 해당 화면·동작·청취·실게임 등 필요한 증거가 없음. 확인한 일부 항목으로 전체 등급을 올리지 않음 |
| RETOUCH | 평가 범위의 정체성·큰 형태가 성립하고 남은 결함의 부위·원인·수정 방법을 한정할 수 있음. 완료가 아니며 기존 허용된 기능 통합과 품질 상태는 별도 |
| PASS | 명시한 평가 범위의 적용 기준을 모두 충족하고 알려진 품질 결함이 없으며 필요한 실제 증거가 있음. 부분 형태 PASS를 제품 전체 PASS로 확대하지 않음 |

같은 핵심 결함을 같은 제작법으로 고친 두 후보가 연속 FAIL이면 실제 제작 단계·방법을 바꾸며 유료 상한을 늘리거나 이름만 바꾸어 반복하지 않는다.
기존 비교 앵커·단계별 구체 기준·드루이드 판정 예시는 [총괄대장 보존 기록](PROJECT_MANAGEMENT_MASTER.md#aaa-단계별-검수판정-예시-보존)을 참조한다. 당시 관측을 현재 후보의 합격이나 상태로 재사용하지 않는다.
