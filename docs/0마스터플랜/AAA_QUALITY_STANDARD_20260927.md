# 프로젝트 공통 품질 목표 — AAA급 게임

2026-09-27 사용자 확정: **모든 작업은 AAA급 게임이 목표이며, AI가 할 수 있는 최선을 다한다.**

이 기준은 모든 에이전트와 후속 세션에 적용한다. 작업 시작 시 읽는 루트 `AGENTS.md`에도 동일한 공통 원칙을 기록했다.

| 영역 | 적용 기준 |
|---|---|
| 기획·구현 | 사용자의 목적과 승인된 설계를 끝까지 구현한다. 눈앞의 한 기능만 동작시키고 전체 흐름의 누락을 방치하지 않는다 |
| UI/UX | 정보 위계·화면 구도·가독성·선택/호버/비활성 상태·입력 피드백·반응형·접근성을 함께 검수한다. 기본 박스와 테두리를 늘어놓은 결과로 마감하지 않는다 |
| 그래픽 | 게임의 미술 방향에 맞는 재질·조명·크기·밀도·색상·디테일을 통일한다. 기존 에셋을 적절히 재사용하고 새 에셋 생성 시 프로젝트 생성 규칙을 따른다 |
| 전투·애니메이션·VFX·사운드 | 조작과 판정, 타이밍, 타격 피드백, 시청각 연동을 실제 플레이에서 확인한다. 장식 추가만으로 품질 향상을 주장하지 않는다 |
| 성능·안정성 | 품질 개선과 함께 프레임·로딩·저장·데이터 보존·회귀를 고려한다. 시각적 개선 때문에 기존 기능을 훼손하지 않는다 |
| 검수 | 실제 실행 화면과 사용자 흐름을 확인하고 부족한 부분을 수정한다. 테스트 PASS와 시각/플레이 품질을 구분한다 |
| 지속성 | 도구 실패 시 허용된 대안을 확인한다. 승인된 범위의 세부사항은 스스로 판단하고 반복 컨펌으로 사용자를 방해하지 않는다 |
| 기록·보고 | 코드와 관련 docs를 동기화한다. 완료한 작업·검증한 범위·남은 문제를 정확히 밝히며 AAA 달성을 근거 없이 선언하지 않는다 |

## 완료 판단

1. 요청의 핵심 목적과 승인된 기능이 구현되었는가.
2. 프로젝트의 미술·설계 방향과 일관되는가.
3. 실제 화면 또는 플레이에서 결과를 확인했는가.
4. 검수에서 발견한 문제를 가능한 범위까지 수정했는가.
5. 관련 문서와 수치·구조·구현 상태가 일치하는가.
6. 하지 못한 검증이나 남은 제약을 숨기지 않았는가.

이 기준은 무관한 범위 확장, 승인 없는 비용 발생, 보안·권한 제한 우회, 확정 설계 변경을 허용하지 않는다. 사용자의 최신 지시와 상위 규칙 안에서 최선의 결과를 만든다.
