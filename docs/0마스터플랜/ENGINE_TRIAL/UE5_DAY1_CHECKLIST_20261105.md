## 2. Xcode 27.2 상태에서의 판정

CTO 지시: 에디터·캡처는 진행하고, 패키징이 막히면 PC로 넘긴다.

다만 상위 계획 §9는 에디터 미리보기만 있는 결과를 실행 증거 FAIL로 두고, §10-2는 환경 교집합이 없으면 중단으로 둔다. PC 패키지는 같은 M5 Pro 비교도 아니다. 그래서 다음처럼 기록한다.

- 에디터 화면만 있으면 **`부분 확인`** 까지만 쓴다. 전체 PASS를 주지 않는다.
- PC 패키지 결과는 구도·화면 증거로만 쓰고, Mac 성능 비교에 합치지 않는다.
- Xcode 26.1.1을 나란히 설치하는 방안은 Apple 계정 로그인이 필요하고, 이 macOS에서 실행되는지 미확인이다. 사용자 결정 전에는 진행하지 않는다.

## 4. 카메라 값

| 항목 | Unity | UE 입력 | 근거 |
|---|---|---|---|
| 피치 | 34° | SpringArm pitch -34, 최종 forward가 하향 34°인지 확인 | [코드] `NativeRemodel3D.Pitch` |
| 거리 | 16.5u | `TargetArmLength` 1650 (1u=1m 가정) | [코드] `NativeRemodel3D.DistU` |
| 대상 기준 카메라 위치 | | 뒤 1367.9cm, 위 922.7cm | [계산] |
| 세로 FOV | 46.9453° | | `remodel_camera.json` |
| 가로 FOV 16:9 | | **75.3356°** | [계산] |
| 가로 FOV 32:9 | | **114.1397°** (Unity의 세로 FOV 유지 규칙과 대조용) | [계산] |
| 표시 밀도 | 75.4px/u | 1m당 약 75px, 화면 중앙·정면 기준 | [계산] |

- SpringArm 충돌 검사, 카메라 lag, 회전 상속, 자동 yaw, 줌을 끈다.
- `remodel_camera.json`의 48.7°/14는 A2 값이 아니다. 피치와 거리에 쓰지 않는다.
- aspect-axis constraint는 세로 FOV 유지로 두고, 유효 세로 FOV를 역산해 46.9453°와 맞는지 확인한다. [미검증]

## 5. 안개와 조명 시작값

**Lumen은 CTO 지시와 상위 계획 사이에 차이가 있다.** 지시는 "Lumen 기본값", 계획 §3은 "첫 기준은 끄고 추가 결과를 별도 표기"다. 둘 다 남기는 순서로 한다: 템플릿 기본값 기록 → 꺼서 기준 화면 → 기본값으로 켠 화면을 별도 표기.

| 항목 | Unity A2 [코드] | UE 시작점 [미검증] |
|---|---|---|
| 안개 방식 | Linear, 19~62u | Exponential Height Fog. 곡선이 달라 같은 안개가 아니다 |
| 안개 시작 | 19u | Start Distance 1900cm |
| 안개 끝 | 62u | 대응 값 없음. 62u 지점 화면 농도를 기준 키샷과 눈으로 맞춘다 |
| 안개 색 | (.105, .145, .17) | Fog Inscattering Color 시작값. 선형/감마 해석 차이 확인 |
| 주광 | Euler (62,35,0), 색 (.85,.89,1), 세기 1, 그림자 .85 | 방향은 좌표 변환해 넣고, 세기는 단위가 달라 명암 계층으로 맞춘다 |
| 환경광 | `A2Ambient()` — 미기록 | G0에서 읽은 뒤 결정 |

먼 적이 안개에 가려지면 FAIL이다. 밀도 값은 지어내지 않고 G4에서 맞춘 값을 기록한다.

## 7. 캡처 스크립트 초안 — 미실행

게임 카메라 준비 판정과 `Shot` 호출은 레벨 안의 fixture가 해야 한다. 아직 없다. 아래는 패키지 실행과 5분 상한만 맡는다. Mac에는 `timeout`이 없어 `perl alarm`을 쓴다.

```bash
#!/bin/bash
# usage: ue_shot.sh <패키지 실행 파일 절대경로> <출력 폴더>
set -u
APP="$1"; OUT="$2"; mkdir -p "$OUT"
perl -e 'alarm 300; exec @ARGV' "$APP" /Game/Trial/L_11_Keyshot \
  -RenderOffScreen -unattended -nosound -ResX=1920 -ResY=1080 -stdout \
  </dev/null >"$OUT/capture.log" 2>&1
echo "exit=$?"
```

- `-nullrhi`를 붙이지 않는다.
- 창이 뜨거나 소리가 나거나 화면이 검으면 그 경로를 중단한다.
- PNG 위치는 Mac 실제 경로를 로그와 파일에서 찾는다. 원본이 1920×1080인지 확인한다.
- 패키지가 막힌 동안 찍는 에디터 화면은 파일명에 `editor`를 넣어 런타임 증거와 구분한다.
