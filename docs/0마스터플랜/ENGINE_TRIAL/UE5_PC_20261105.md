- 성능 run: 준비 15초·측정 20초. Actor tick 간 wall time CSV로 평균 FPS 계산. 가장 느린 ceil(N×0.01)개 프레임 시간 평균의 역수가 1% low다. GPU timestamp 측정이 아니다.
- RSS: FPlatformMemory::GetStats().UsedPhysical을 측정 구간 1Hz로 표본화한 평균·최대와 process lifetime peak를 구분하도록 준비했다. 결과가 없어 수치는 기입하지 않는다.
- -RenderOffscreen, -nosound, 순차·BelowNormal이 실행 조건이다. 성능 run에 스크린샷·DumpMovie·고정 timestep을 넣지 않는다.
- 공통 시험 인자: -TrialRadiusCm=5.2 -TrialSpeedCms=300 -TrialWarmup=15 -TrialMeasure=20 -TrialOut=<E: 조건별 경로>. 추가 -TrialCount=0|80, -TrialPattern=circle|spiral|fan, -ResX=1920|3840 -ResY=1080.
- 10초 영상은 성능과 별도다. 소스상 -DumpMovie -benchmark -fps=30은 PNG 연속 저장이며 MP4 직접 출력이 아니다. 준비된 장면의 연속 300장을 확인한 뒤 기존 FFmpeg로 30fps·10초 무음 인코딩할 계획이다. -benchmarkseconds=10만으로 준비된 300장을 보장하지 않는다. 실제 프레임·영상은 없다.
- FFmpeg 명령 경로는 발견했으나 실행·버전 확인·인코딩·설치는 하지 않았다.

1. C: 자동 로그·설정 예외 여부 또는 예외 없이 성립하는 전체 저장 경로를 확정한다.

3. 성능 4조건을 순차 실행하고 Dota 상태·우선순위·해상도·렌더 설정을 기록한다.
