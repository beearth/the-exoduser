# 시네마틱·연출 및 게임 텍스트·폰트 공개 자료 연구

조사일: 2026-11-05(KST). 연구 문서이며 구현·디자인 확정안이 아니다.

## 1. 범위와 증거 읽는 법

- **[사실]**: 연결한 공개 자료가 직접 설명하는 내용이다. 개발 중 설명과 과거 패치 기록에는 시점을 붙인다. 현재 모든 플랫폼에서 동일하게 동작한다는 뜻으로 확대하지 않는다.
- **[추정]**: 출처에서 도출한 해석·검증안·설계 후보다. 게임의 실제 구현값이나 업계 전체의 통계로 취급하지 않는다.
- **[미확인]**: 이번에 열람한 자료로 확정하지 못했다. 기능이 없다는 판정이 아니다. 표의 출처는 확인 범위를 보여 주며, 미확인값을 증명하는 문서라는 뜻이 아니다.
- 조사 방법: 로그인 없이 공개 웹 페이지의 본문·공식 발표·패치 노트·게시 영상 메타데이터를 확인했다. 영상 프레임을 직접 계측하지 않았고 게임을 실행하지 않았다. **영상 계측으로 얻은 길이 추정치는 이번 조사에 없다.** 이미지·영상·폰트·게임 파일은 다운로드하거나 문서에 삽입하지 않았다. 대사·자막 원문과 장문 인용은 수록하지 않았다.
- 비교 대상: Diablo IV 본편 관련 발표·패치 기록, **Hades 1편**, Path of Exile 2 공식 오프닝·0.2.0 기록. 최신 확장팩이나 Hades II의 값을 혼합하지 않는다. 문서 안의 날짜·수치는 해당 출처의 범위다. [D01] [D02] [H01] [P01] [P02]

## 2. 공통 관례: 관찰 통계가 아닌 공개 접근성 권고

**[사실]** GAG와 XAG는 자막·읽기 속도·정보 접근에 관한 공개 권고를 제공한다. 아래 내용을 세 게임 모두의 구현이라고 볼 근거는 없다. 특히 XAG의 본문 크기와 별도 접근성 기능 태그의 자격 기준은 적용 범위가 다른 자료다. [G01] [G02] [X01] [X04]

| 항목 | 공개 근거와 해석 | 적용 범위 |
|---|---|---|
| 인트로 이전 설정 | [사실] 자막은 첫 관련 음성이 나오기 전에 설정할 수 있게 하거나 기본으로 켠다. [G03] [X03] | 첫 실행 인트로도 포함한다. |

| 재확인 | [사실] GAG의 고급 지침에는 이야기와 지시를 다시 볼 수 있게 하는 항목이 있다. [G04] | 최초 감상 뒤 다시 읽는 경로를 검토할 근거다. |
| 고정 연출 길이 | [미확인] 열람한 지침에서 인트로·보스 등장·클리어·사망을 각각 몇 초로 제작하라는 장르 공통 표준은 확인하지 못했다. [G02] [G04] [X03] | 임의의 초 단위를 관례라고 쓰지 않는다. |

### 3.5 추후 영상 계측 시 기록할 방법 — 이번에는 미실행

아래는 **[추정·연구 방법 제안]**이다. 공개본과 게임 내 상태를 구분하고 읽기 시간을 분리하려는 기록 방식이며, 출처가 보증하는 계측 표준은 아니다. [P01] [P04] [G02]

1. 영상 URL·게시자·게시일·기재 빌드·플랫폼·언어·재생 속도·첫 방문/재방문을 기록한다. 빌드가 없으면 빌드 미확인으로 남긴다.
2. 인트로는 첫 서사 화면/음성부터 장면 종료까지, 보스는 등장 시작부터 전투 가능 상태까지 경계를 정한다. 영상만으로 조작 가능 여부를 알 수 없으면 그 부분은 미확인이다.
3. 클리어는 승리 판정의 시각적 신호→결과 정보 완성→사용자 종료를 나눈다. 사망은 치명타/사망 확정→연출 종료→복귀 선택 가능→복귀 후 조작 가능을 나눈다.
4. 시작·종료 타임코드와 경계 선택 이유를 남기고 `관찰 길이 = 종료 - 시작`으로 계산한다. 대화 대기·사용자 입력 대기·로딩은 별도 열에 적는다. 서로 다른 성격의 시간을 한 수치로 합치지 않는다.
5. 결과는 반드시 **[추정]**으로 표시한다. 편집 컷·일시정지·스킵·재생 속도 변경·출처 불명의 로딩 제거가 있으면 연속 재생 길이로 사용하지 않는다. 다른 언어의 음성·자막 속도까지 일반화하지 않는다.
6. 초 단위 플레이어 표시만 읽었다면 각 경계의 분해능을 함께 적는다. 경계를 각각 ±1초로 판단한 경우 차이는 보수적으로 ±2초 범위로 보고한다. 이는 향후 기록 예시이며 이번 게임의 실측 오차가 아니다.

**[사실]** Noto 공식 문서는 문자권별 패밀리와 공통 라틴용 패밀리의 조합을 설명하고, CJK용 Sans/Serif 및 지역별 패밀리를 제공한다. **[추정]** Noto는 문자권 커버리지 후보를 정리하는 참고 사례로 쓸 수 있다. 특정 게임의 사용 폰트·최종 선택·최소 크기·파일 용량으로 해석하지 않는다. 이번에는 폰트 파일과 라이선스 파일을 받지 않았다. [N01] [N02]

**[미확인]** 세 비교 게임의 29개 언어 폴백 체인·아틀라스 분할·실제 배포 폰트명은 공개 근거를 확보하지 못했다. PoE 2의 열람 시 Steam 언어표는 9개이므로 이 구성안을 해당 게임의 지원 현황으로 옮기면 안 된다. [D01] [H01] [P03]

### 5.2 아랍어: RTL, 연결형, 숫자를 별도 처리

- **[사실]** Unicode UAX #9는 논리 순서로 저장된 텍스트의 양방향 배치를 설명한다. 아랍어 문장 안의 숫자와 라틴 단어는 다른 방향의 구간을 만들 수 있다. 단순 문자열 전체 뒤집기와 같은 처리가 아니다. [B01]
- **[사실]** UAX #9의 shaping 설명은 아랍어처럼 연결되는 문자에서 이웃 문자에 따른 위치별 자형 선택이 필요하다고 설명한다. 방향 처리와 자형 선택은 구별되는 문제다. [B01]
- **[사실·Unity 6.0 문서]** UI Toolkit의 Advanced Text Generator는 HarfBuzz·ICU·FreeType을 사용하고 RTL·텍스트 shaping을 지원한다. 대상 언어를 포함한 동적 폰트 에셋이 필요하다. 이 설명은 **UI Toolkit 경로**에 대한 것이며 기존 TMP 컴포넌트 전부에 자동 적용된다는 설명이 아니다. [U04]
- **[사실·동일 문서]** 해당 문서는 일부 리치 텍스트 태그와 간격 속성 등에 제한을 명시한다. **[미확인]** 현 프로젝트의 Unity·uGUI 패키지 버전 및 UI 구성에서의 실제 지원은 실행 검증하지 않았다. 버전 확인 전 자동 전환을 확정하지 않는다. [U04]
- **[추정·검토안]** 아랍어 UI·자막·데미지 숫자 각각에서 연결형, 줄바꿈, 결합 부호, 괄호, 음수, 퍼센트, 라틴 아이템명, 키 아이콘이 섞인 경우를 검토한다. 숫자 자체를 반전시키지 않고 방향 구간을 올바르게 배치하는지 본다. [B01] [U04]
- **[추정·검토안]** 타이핑 효과나 문자 단위 강조도 완성된 연결형을 깨뜨리지 않는지 확인한다. 폴백에 아랍어 글리프가 있다는 사실만으로 RTL·연결형·혼합 문장 지원 완료라고 판정하지 않는다. [U01] [U04] [B01]

### 5.3 CJK와 장문 확장

- **[사실]** Noto CJK 문서는 지역별 글리프 선택을 구분하며, 언어 태깅과 OpenType `locl` 지원 여부에 따라 언어에 맞는 자형 선택을 설명한다. **[추정]** 한자 코드포인트가 같아도 일본어·한국어·간체·번체용 후보와 실제 렌더러의 선택을 각각 확인하는 편이 타당하다. [N02]
- **[추정·검토안]** 번역 전체에 등장하는 문자와 동적 문자열의 허용 범위를 먼저 정리하고, 이름·수치·문장부호·기호가 추가되는 경로를 따로 검토한다. 정적 아틀라스가 모든 미래 입력을 담는다고 가정하지 않는다. [U01] [U02]
- **[추정·검토안]** CJK의 문장부호 줄 시작/끝, 금칙 처리, 장문 버튼의 확장·줄바꿈·잘림을 확인한다. 공개 자막의 40자 권고만으로 각 언어의 행 너비가 같다고 가정하지 않는다. [G05] [X03] [U04]
- **[미확인]** 현행 29개 언어의 누락 글리프 0건, 네모 문자 0건, 모든 줄바꿈 정상, 모든 폴백의 굵기·윤곽선 일치 여부는 이번 연구에서 검증하지 않았다. [U01] [U03] [U04]

- **[추정·후속 조사 항목]** 구체적인 보스/클리어 사건과 빌드·언어를 먼저 고르고 §3.5 방식의 계측, 최종 해상도의 문자 높이·대비 검사, 29개 로케일의 실제 조판 검토를 분리하는 것이 적절하다. 이번 과업에서는 연구 문서만 작성했다. [G02] [X01] [X02] [U04]
