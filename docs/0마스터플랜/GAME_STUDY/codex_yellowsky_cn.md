## 5. 기존 결론에서 바로잡거나 보류할 부분

1. **UE5:** 기존 문서가 가리키는 모집글 원문은 이번에 재확인하지 못했다. 내부 전사 `引擎：虚幻5`를 새로 확보한 원문 발췌처럼 인용하지 않는다. 후보 URL은 남겨 후속 검증 가능하게 했다.
2. **모집글의 간접 확인:** [《独立游戏通讯》2024-#37 재게시](https://www.sohu.com/a/815163617_211762)는 `3D 俯视角动作游戏《黄天逆途》`와 회원 `伽马聚集工作室`를 열거한다. 이는 **모집글 제목·발신명에 대한 간접 단서**이며 본문 엔진 문구는 없다. 앞 항목의 다른 게임에 붙은 ‘10명·4개월 Demo·8개월 출시’ 내용을 이 작품에 옮기면 안 된다.
3. **완전 3D·픽셀 아님:** 모델 제작 사실과 사용자 정의 2.5D 태그만으로 게임 전체 합성 구조·렌더 해상도를 확정할 수 없다. ‘실시간 3D일 가능성’ 수준의 기술 해석은 **[추정]**으로만 취급한다.
4. **빛·안개:** Lumen·Height Fog·Volumetric Fog는 사용 사실을 입증한 원문이 없다. 엔진 후보, 화면 인상, 일반 UE 제작법을 결합해 확정하면 안 된다.
5. **팀명 관계:** 2025년 보도의 伽马聚集과 2026년 공식 望虚社는 같은 작품을 가리키지만 개명·법인 승계 관계의 당사자 원문은 미확인. Steam의 현재 개발·배급 표기는 望虚社로 유지한다.
6. **팀·돈:** 보도 8/10/11명을 현재 인원 하나로 합치지 않는다. 원격 참여자를 자동으로 정규 인원에 더하지 않는다. 투자 0·외주 수입·향후 모금 계획은 각각 다른 재원 상태이며 개발비·확보 자금액을 뜻하지 않는다.
