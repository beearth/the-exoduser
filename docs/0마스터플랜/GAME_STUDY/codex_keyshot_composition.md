# 키샷·스크린샷 구도 연구 — Steam 규격과 1-1 적용안

작성일: 2026-11-05 KST. 상태: **규격 조사 완료 / 네 게임 이미지 직접 관찰 미완 / 1-1 구도안은 설계 제안**.

## 1. 증거의 범위와 읽는 법

이 문서의 `[사실]`은 연결한 문서·페이지의 텍스트에서 확인한 내용이다. `[추정]`은 해석·검증 가설·우리 게임에 대한 제안이며, 해당 게임 제작사의 의도로 단정하지 않는다. 직접 인용은 사용하지 않았다.

조사 실행 기록: 공개 웹 검색과 페이지 텍스트 열람은 가능했으나, 브라우저 도구가 `The browser access host is unavailable`을 반환했다. SteamDB의 스크린샷 페이지도 텍스트 결과에는 이미지 본문 대신 섹션 제목만 나왔다. 이미지를 별도로 요청·다운로드·저장하거나 생성하지 않았다. **따라서 이번 문서에는 직접 본 스크린샷의 좌표 측정값이 없다.** 아래 게임별 페이지 URL은 열람·대조 위치이며, 이미지 구도를 확인했다는 증거가 아니다.

`[사실]` Steam은 캡슐용 키아트와 실제 플레이 스크린샷을 구분한다. 스크린샷 영역에 콘셉트 아트나 사전 렌더 시네마틱을 넣는 방식은 허용되는 스크린샷 작성법이 아니다. 출처: [Steam 스토어 이미지 공식 문서][S1].

`[추정]` 이 연구에서 ‘키샷’은 기존 게임 카메라로 얻을 대표 플레이 장면을 뜻하도록 한정한다. 키아트의 주인공 확대나 로고 중심 배치를 게임 카메라 변경의 근거로 삼지 않는다. 근거: [Steam의 용도 구분][S1], [프로젝트 카메라 LOCK][P].

### 키아트에 관해 실제로 확인한 비교점

`[사실]` SteamDB의 `logo_position/pinned_position`은 Diablo IV·Path of Exile 2·No Rest for the Wicked에서 `BottomLeft`, 黄天逆途에서는 `BottomCenter`다. 이것은 **라이브러리 로고의 배치 메타데이터**이며, 스토어 헤더 안에 그려진 로고 위치나 캐릭터 위치를 측정한 값이 아니다. 출처: [Diablo IV][DM], [PoE2][EM], [Wicked][NM], [黄天逆途][YM].

### 후속 관찰에서 숫자를 쓸 때의 기록 형식

`[추정·조사 방법 제안]` 각 게임의 전투 스크린샷·이동 스크린샷·스토어 헤더를 구분하고, 각각 페이지 URL, 이미지 고유 식별자 또는 갤러리 순번과 장면 설명을 함께 적는다. 갤러리 순번만으로 이미지를 식별하지 않는다. 비교 대상: [D4][D], [PoE2][E], [Wicked][N], [黄天逆途][Y].

`[추정·조사 방법 제안]` 좌표는 이미지 자체의 좌상단 `(0%,0%)`, 우하단 `(100%,100%)` 기준으로 적는다. 캐릭터 위치는 발 접점, 높이는 머리부터 발까지의 이미지 높이 대비 비율로 정의한다. 브라우저 여백·스토어 UI는 분모에서 제외한다. 육안 수치는 이미지 식별자와 함께 `[추정]`으로 표기하고, 광원 방향도 ‘화면상 상단 왼쪽에서 오는 듯함’처럼 관찰과 해석을 분리한다. 적용 대상: [네 게임 중 D4 갤러리 예시][D].

`[사실]` 라이브러리 히어로에는 문자를 넣지 않고, 라이브러리 로고는 별도 투명 배경 자산으로 구분한다. 이는 스토어 스크린샷 규격과 별개다. 출처: [Library Graphical Asset Rules][S2].

`[추정·적용]` 우리 키샷 3안은 실제 플레이 스크린샷 후보로 취급한다. 캡슐 제작 시에는 별도 규격과 로고 배치를 검토한다. 16:9 화면을 세로 캡슐로 단순 절단하는 방식을 기본값으로 삼지 않는다. 근거: [서로 다른 제출 규격][S1], [캡슐·라이브러리의 내용 규칙][S2].

## 5. 1-1 적용의 고정 조건과 좌표 해석

`[사실·프로젝트 지시]` 기존 1-1은 남→북 나무다리, 양쪽 늪, 고목 전경, ForestA2 원근 카메라 피치 34°를 유지한다. 먼 적이 보여야 하며, 안개·어둠·비네트가 먼 적을 지우면 안 된다. 출처: [현재 체크아웃의 작업 매뉴얼 §3][P]. **이번 사용자 지시에 따라 거리도 고정**하며, 매뉴얼의 보스 아레나 거리 변경 예외는 이 연구에 적용하지 않는다. 거리 고정의 출처는 이번 작업 지시다.

`[추정·설계 전제]` 아래는 실제 화면 실측이 아닌 **희망 투영 범위**다. 피치·거리·FOV·카메라 회전·추적 오프셋을 바꾸거나 크롭으로 재구도하지 않는다. 영웅의 발 접점은 세 안 모두 `(50%,60%)` 부근이라는 임시 가정을 쓴다. 실제 고정 카메라의 접점이 다르면 그 값을 세 안에 공통 적용하고, 좌표를 맞추려고 카메라를 옮기지 않는다. 근거: [원근 LOCK과 기존 장면 유지][P].

`[추정·설계 전제]` 아래 적 좌표는 기존 적의 자연스러운 이동 중 포착할 순간을 뜻한다. 스폰·AI·충돌·맵 좌표를 변경하는 지시가 아니다. 고목·난간·늪의 범위도 현재 장면을 확인할 비교 영역이며, 새 소품이나 새 평면도를 제안하지 않는다. 조명 항목은 기존 조명으로 먼저 대조할 명암 목표다. 근거: [기존 장면·원화·C10 조명 우선 원칙][P].

## 6. 카메라 고정 구도안 3개

### 안 1 — 다리 축선으로 먼 적을 먼저 예고하는 이동 컷

`[추정·제안]` 큰 고목을 가장자리의 전경으로 읽히게 하고, 다리 바닥과 난간이 영웅을 지나 북쪽 작은 적까지 이어지는 순간을 고른다. 핵심은 ‘앞으로 갈 길과 먼저 기다리는 적’이다. 영웅을 확대하지 않고 깊이 차이를 전달하는 안이다. 설계 근거: [1-1의 남→북 다리·고목·먼 적 LOCK][P].

|---|---|---|---|
| 영웅 | 발 `(50,60)%`; 표시 높이는 현행 값 유지 | 세 안 공통 기준. | [LOCK][P] |

| 다리 중경 | 남쪽 진입부 `x=36~64%, y=82~100%` → 북쪽 `x=45~55%, y=24~32%` | 실제 원근 투영과 맞는지 확인할 범위. 난간으로 축선 읽기. | [남→북 다리][P] |
| 양쪽 늪 | 왼쪽 `x=18~35%`, 오른쪽 `x=65~88%`, 주로 `y=35~85%` | 양쪽 늪이 각각 읽히되 중앙보다 강한 초점이 되지 않게 대조. | [양쪽 늪][P] |
| 먼 적 | 발 `(48~54,28~35)%`; 높이 목표 `2~4%H` | 제안값. 현재 원근 크기가 이 범위와 다르면 모델·카메라를 조정하지 않음. | [먼 적 조건][P] |
| 빛·색 | 밝은 면 중심 `(50,38)%`; 차가운 늪, 상대적으로 밝은 다리 | 화면상의 명암 중심 목표. 실제 광원 위치를 의미하지 않음. 먼 적 뒤 바닥과 실루엣 분리. | [기존 조명·먼 적 가독성][P] |

### 안 2 — 중경의 교전과 북쪽 후속 적을 함께 읽는 전투 컷

`[추정·제안]` 영웅 가까이의 교전 한 덩어리와 북쪽의 다음 위협 사이에 빈 바닥을 남기는 순간을 고른다. 전경 고목은 유지하고, 적이 영웅을 완전히 둘러싼 순간보다 공격 방향이 읽히는 순간을 우선한다. 카메라를 대각선으로 돌리는 안이 아니다. 설계 근거: [기존 다리 장면·고정 카메라·먼 적 조건][P].

| 요소 | `[추정]` 화면 좌표·비율 목표 | 의도·제약 | 근거 |
|---|---|---|---|
| 영웅 | 발 `(50,60)%`; 크기 현행 유지 | 안 1과 동일 카메라·동일 표시 기준. | [LOCK][P] |
| 가까운 적 | 발 `(43~48,45~51)%` 또는 `(54~59,45~51)%` | 기존 적이 접근한 한쪽을 포착. 양쪽에 대칭 배치하지 않음. | [기존 장면 유지][P] |
| 공격 접점 | `(48~54,48~54)%` | 접점·적 몸·다리 바닥을 함께 확인. 빛으로 먼 적을 덮지 않음. | [먼 적 가독성][P] |
| 원경 후속 적 | 발 `(48~55,25~32)%`; 높이 `2~4%H` 희망 범위 | 가까운 전투와 분리된 작은 개체로 읽힐 것. | [원근·먼 적][P] |
| 전경·중경·원경 | 가장자리 고목 / `y=43~65%` 교전 / `y=24~35%` 후속 적 | 깊이별 행동 구분. 전경에 적을 새로 배치하지 않음. | [고목·다리 LOCK][P] |
| 빛·색 | 교전의 짧은 강조 `(50,51)%`, 북쪽 바닥의 밝기 구분 유지 | 공격 강조색은 작은 접점에 한정하는 희망안. 기존 VFX 최대 프레임도 별도 대조 대상. | [먼 적을 지우지 않는 명암][P] |

### 안 3 — 고목과 양쪽 늪의 크기로 공간을 보여 주는 탐색 컷

`[추정·제안]` 전투 이펙트가 적은 순간에 가까운 고목의 큰 형태, 다리의 연속성, 북쪽 작은 적을 한 번에 읽는다. 안 1보다 환경과 적의 크기 차이를 검토하는 목적이 크다. 새 광원이나 안개를 추가하는 지시가 아니며, 기존 장면에서 조건이 성립하는지 먼저 확인할 안이다. 설계 근거: [앞 고목은 크게·먼 적은 작게 보이는 1-1 LOCK][P].

| 요소 | `[추정]` 화면 좌표·비율 목표 | 의도·제약 | 근거 |
|---|---|---|---|
| 영웅 | 발 `(50,60)%`; 크기 현행 유지 | 환경 컷이라고 카메라를 멀리 빼지 않음. | [LOCK][P] |
| 큰 고목 | 주된 외곽 `x=0~22%, y=15~100%`; 반대편은 `x=90~100%` | 기존 고목이 이 범위를 차지하는지 대조. 화면 중앙으로 가지를 새로 옮기지 않음. | [고목 전경][P] |
| 늪 두 면 | 왼쪽 `x=22~36%, y=35~85%`, 오른쪽 `x=64~90%, y=35~85%` | 다리 양옆의 서로 다른 물 면이 읽히는 순간 선정. | [양쪽 늪][P] |
| 북쪽 적·경로 | 먼 적 발 `(49~55,26~33)%`; 길의 연속 구간 `x=43~57%, y=30~58%` | 적 몸과 북쪽 길이 모두 남아야 함. 중앙에 안개 장막을 두지 않음. | [먼 적·경로 가독성][P] |
| 빛의 읽힘 | 기존 방향광의 밝은 면을 화면 상단 측면 `(65~80,15~30)%`과 대조 | 실제 광원 좌표 아님. 현행 광원이 반대 방향이면 이 가설을 폐기하고 LOCK 유지. | [기존 C10 조명 우선][P] |
| 색·명암 | 고목은 어두운 외곽, 다리는 중간 명도, 먼 적 뒤 바닥은 구별 가능한 명도 | 차가운 물과 상대적으로 중성인 다리라는 제안. 특정 참고 게임 공통 팔레트라는 주장은 아님. | [기존 조명·원근 유지][P] |

`[추정·세 안의 검토 기준]` 좌표 일치보다 ‘양쪽 늪·고목·다리·영웅·작은 먼 적이 동시에 읽히는가’를 우선한다. 기존 카메라에서 불가능한 목표는 제안 좌표를 폐기한다. 이번 문서는 실게임 검증이나 네 게임 이미지 비교를 통과했다는 판정이 아니며, 공통 관례의 확정에는 이미지별 직접 관찰 기록이 추가로 필요하다. 근거: [프로젝트 LOCK·실게임 판정 원칙][P], [실제 플레이를 보여야 하는 Steam 스크린샷 기준][S1].
