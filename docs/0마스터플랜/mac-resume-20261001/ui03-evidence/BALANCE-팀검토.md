## 1. 최소 patch 후보 (미적용 — 총괄 반영용)

### 후보 A — `game.html:26602` 주석 오기 (533만 → 528만)
근거: `(20000+1000×3500)×1.5 = 5,280,000` = **528만**. docs SSOT(`14밸런스+수치테이블.md:102`)는 5,280,000으로 정확. 공식·수치 불변, **주석 텍스트만**.

```diff
- return Math.max(20000,Math.ceil((20000+n*3500)*1.5)); // 최소 2만(=1만악의), 0강=3만, 100강=55.5만, 1000강=533만
+ return Math.max(20000,Math.ceil((20000+n*3500)*1.5)); // 최소 2만(=1만악의), 0강=3만, 100강=55.5만, 1000강=528만
```

### 후보 B — `game.html:26703` 환수 설명 혼동 (주석만, 환수식 불변)
근거: 누적합이 현행 `enhCostRaw(n)`가 아닌 레거시식 `ceil((1+i×0.15)×1.5)×등급배율`을 사용(`game.html:26708`). 따라서 "실제 강화 비용 누적합의 50%"는 오해 소지. **식·수치·로직 불변, 설명만 정정**.

```diff
-  // 강화 투자분 50% 환수: 실제 강화 비용 누적합의 절반
+  // 환수액 = 레거시 단위누적식 ceil((1+i*0.15)*1.5)*등급배율 의 50%.
+  // ※ 현행 지출식 enhCostRaw(n)와 다른 과거식이라 "실제 지출의 50%"가 아님 (PM-013-D 설계 대기)
```
