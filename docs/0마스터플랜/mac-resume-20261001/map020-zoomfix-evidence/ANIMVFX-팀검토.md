### 3. 현재 소스 불일치 경고 — `game-easy-test.html`은 PM-014/§11 미포함
- `game-easy-test.html:50332-50333`: `if(e._hitFlash>0){ e._hitFlash-=1; }` — **그리기 없는 구(舊) 죽은 코드**(§5.1이 지적한 원 결함). update 감쇠(없음)·GL additive 루프(없음)·사망 소거(없음) 전부 부재.
- 즉 이 파일로 검수하면 "플래시 자체가 안 보이고 감소는 render 기반"인 **수정 전 상태**가 재현됨. **검수·캡처는 반드시 `game.html`로.** (easy-test는 별도 테스트 변형으로, §11 반영 대상에서 제외돼 있음을 기록.)

### 4. 주사율 독립 근거(소스 대조, 측정 아님)
- 루프: `game.html:59539` `while(_acc>=PHYS_STEP){ … update(); _acc-=PHYS_STEP }`, `PHYS_STEP=1000/60`(58309). 매 프레임 `_dtSp=1`(59512) 후 while 진입 → update는 실시간 60Hz 고정.
- update 내 `sp=(G.slowMo>0?.35:1)*_dtSp`(31143) → 통상 sp=1. 감쇠가 update 단일 지점(32888)이므로 **render rate와 무관하게 6틱=100ms** 고정. slowmo/hitstop은 sp로 자동 존중.

### 5. 부활 첫 프레임 잔상 커버리지(소스 대조)
- 핵심: 사망→부활은 항상 `_reviveTimer` 카운트다운(`game.html:32930-32935`)으로 **≥1개 사망 프레임**을 거친 뒤 `alive=true`(보스 32943 / 일반 32978 / 드루이드 `_reviveDruidFinale` 16115, 이 역시 32940 reviveTimer≤0 분기에서 호출). 사망 프레임마다 50624가 `_hitFlash=0` 소거 → **부활 첫 프레임엔 이미 0.**
- GL 경로(5199 `!e.alive` skip)·2D(50622 `!e.alive` 분기)가 죽은 몹을 안 그리므로 소거 전/후 손실 없음.
- `_spawnGhoul`(32975)은 신규 객체(=기본 `_hitFlash=0`).

### 7. 잔여 위험
1. **측정 해석 위험(최우선)**: §10 "REHIT 오표기"는 도구가 rAF(240Hz)마다 기록·draw 4:1이라 생긴 아티팩트. §11 이후 감쇠가 **update(60Hz)** 구동이라, 고주사율 캡처는 per-rAF로 보면 hf가 ~4샘플 유지 후 -1로 보인다. **프레임 수를 세지 말고 dt로 실시간 적분**해 100ms를 판정해야 함(안 그러면 거짓 불일치).
2. **가독성(발견 A/B, 미해결 이관)**: 근접 피격 시 몹 몸통이 기검참 VFX·데미지 숫자·그로기 텍스트에 가려 가산 발광 식별성 약함. **이번 수명/잔상 수정과 분리** — 식별성 강화(흰 실루엣 틴트/림라이트)는 정규 GL 실화면 A/B 확보 후 별도 착수(현 발광 유지).
3. **recover/트윈 부활 경로 스팟체크**: `corpse.alive=true`(37294)·트윈파트너(38730)는 동일 객체 재사용 경로. reviveTimer 경로와 달리 사망 프레임 경과가 자명하진 않으므로 부활 첫 프레임 `_hitFlash=0`을 (F)에 함께 확인 권장(소스상 사망 후 시간차가 있어 커버로 판단되나 캡처로 확정).
4. **§5b 경미사항 #1 해소 확인**: "뷰 밖 _hitFlash 정지"는 감쇠가 render(컬링)→update(항상 실행, 32882)로 이동해 **해소됨**. 재캡처 시 화면 밖 피격 후 복귀 반짝임 부재를 부수 확인.
5. **하니스 부팅**: §9대로 hidden 탭 강제부팅은 GL 경로(`_prepEnemyInstanced`) 미구동 → 거짓 검증. 정규 visible 풀부팅 필수.

### 8. 불변 계약·검수 한계
- 불변 확인: `hurtE` 세팅(=6/=4), death/`e.alive`·보상(`rollDrop`/`addExp`/`G.kills`/`G._stageKills`)·`_addCorpse` 시체 수·`_hitStun`·쿨다운·판정 모두 소스상 미변경. 변경은 `_hitFlash` 감쇠 위치+사망 소거뿐.
- 이 보고는 **정적 소스 대조**이며 실측·캡처·커밋·파일변경·게임 실행 없음. §11 "QA 재캡처 요청" ①②가 아직 미수행이라 **GL 실화면 시각 PASS는 미판정(검수 대기)** 상태가 맞음.

**결론**: §11 4개 편집은 현재 `game.html`에 **전부 일치**하며, 고정스텝·부활 경로 근거도 소스와 일치. 남은 것은 위 §6 조건의 정규 GL 실측 재캡처뿐(측정은 QA 실행 창/총괄 배정 대기). 검수 대상 파일은 `game.html`이며 `game-easy-test.html`은 제외해야 함. 총괄의 순차 실행 배정을 대기합니다.
