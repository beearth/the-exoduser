## docs 인수 후보·미검증

인벤 SSOT의 ‘32비트 변환 유지’는 **현재 생산 구현 기록**으로 보존했다. 총괄이 적용할 때 현재 강화 환수 행을 `Math.floor(누적합×0.5)`로 동기화하고 이전 기록의 동일 변환 제거, 경계·저장 복원 불가·기존 환수정책 불변을 기재해야 한다. BALANCE 대장 PM-013-D는 환수정책 결정 대기를 유지하고 이번 정수 변환 결함만 별도 추가 후보다. 공유 SSOT/대장은 직접 수정하지 않았다.

실제 `equipItem` 전체의 자원차감·장착·자동저장 호출은 실행하지 않았다. 기록 계산과 enh0 저장 모양의 JSON 왕복 fixture만 검증했다. G.mats·실서버·사용자 세이브·브라우저·게임·빌드 미접촉. enh200000의 자연 달성, 전체 저장/재실행·실화면·패키지·비정상 enh 입력 및 Number 안전정수 범위 초과는 미검증이다. 입력 제한300000은 **검사 도구 안전 제한이지 생산 강화 상한 제안이 아니다**.
