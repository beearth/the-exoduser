# 제작 매뉴얼 — 무엇으로, 어떻게, 어떤 스타일로

- 작성: 2026-11-05. 사용자 지시 "뭘 만들어도 매뉴얼과 프로세스대로, 뭘로 만들고 어떻게 만들고 어떤 스타일로".
- 작업 매뉴얼 v4 §3 제작법 표를 이 문서가 대체한다. 일하는 순서(G0~G5)와 안전 규칙은 v4를 따른다.
- 작업을 시작하면 §3에서 해당 줄부터 찾는다. 표에 없는 대상은 만들기 전에 줄부터 추가한다.

## 0. 상태 표기

| 상태 | 뜻 | 쓰는 법 |
|---|---|---|
| 검증됨 | 게임 화면이 레퍼런스 비교를 거쳐 사용자 PASS를 받았고 비교판 경로가 적혀 있다 | 이 방법을 그대로 쓴다 |
| 시험 중 | 아직 PASS가 없다 | 화면 하나로만 시험한다. 맵 전체로 넓히지 않는다 |
| 금지 | 결과가 FAIL로 확인됐다 | 쓰지 않는다 |

### 화면 수치

측정 도구: `unity/Tools/look/look-stats.ps1`. HUD를 뺀 월드 영역을 잰다. 레퍼런스는 다른 장면이라 수치는 범위 확인용이고, 최종 판정은 눈으로 한다.

| 항목 | 노레위 6장 | 현재 실행본 | 빛 수정 후보(FAIL) | 목표 |
|---|---|---|---|---|
| 중간 밝기 p50 | .12~.29 | .27~.29 | .11 | .16~.24 |
| 밝은 쪽 p90 | .32~.64 | .39~.40 | .16~.20 | .38 이상 |
| 최대 빛 p99 | .51~.87 | .53~.57 | .33~.50 | .65 이상 |
| 채도 | .35~.50 | .27~.30 | .24~.30 | .38 이상 |
| 어두운 면적(밝기 .18 미만) | 22~65% | 17~26% | 85~92% | 35~55% |

해석: 현재 실행본은 명암 폭과 채도가 좁아 평평하고, 빛을 줄인 후보는 전체가 어두워졌다. 노레위는 어둠과 강한 빛을 함께 쓴다.

## 2. 공통 순서

1. **기준 고정:** 고정 장면 3개(시작 다리, 전투, 보스)와 레퍼런스를 정한다.
2. **형태:** 회색으로 큰 형태와 길을 먼저 맞춘다. 재질로 형태 부족을 가리지 않는다.
3. **입고:** §3의 도구로 에셋을 받아 크기·색·재질 규칙을 적용한다.
4. **룩:** 조명과 색은 빌드 없이 값 파일로 맞춘다(도구 제작 예정).
5. **비교:** 레퍼런스와 같은 크기로 나란히 놓고 수치를 함께 적는다.
6. **판정:** 사용자가 게임 화면을 보고 PASS 또는 FAIL을 준다.
7. **고정:** PASS면 값과 비교판을 §3에 적고 상태를 검증됨으로 바꾼 뒤 넓힌다.
