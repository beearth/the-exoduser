# 지옥의 길 (EXODUSER) 기획안 초안 — CTO, 2026-11-05 15:50 KST

사용자 원문 "기획안 내봐라"에 대한 1차 답. 지금 Core에 있는 규칙 위에서 정체성을 선명하게 하는 문서이고, 새 시스템을 발명하지 않는다. 열린 항목은 §9. GD 레인(DESIGN_BIBLE_20261105.md)이 밤새 근거 링크와 레퍼런스 조사를 붙여 확장한다.

## 1. 한 문장
**33도 쿼터뷰에서, 근접으로 무리를 베어 넘기면서 탄막을 피하고 되받아치고, 떨어진 장비를 몸에 걸쳐 눈에 보이게 강해지는 핵앤슬래시 액션 RPG.**

## 2. 왜 특색인가 (가설, GD가 검증)
- 탑다운 탄막(동방·건전)은 평면이라 탄이 전부 같은 크기로 읽힌다. 아이소메트릭 ARPG(디아4·PoE2)는 장판·투사체가 있지만 "탄막"이라 부를 밀도는 아니다. **33° 원근 + 탄막 밀도 + 루팅**의 조합은 드물다. 원근 때문에 먼 탄이 작아지는 문제를 해결하면 그 자체가 우리 화면의 특색(먼 적·먼 탄이 보이는 생동감)이 된다.
- 핵앤슬래시(어택 티켓 없음, 다수 동시 공격)와 탄막 회피가 한 화면에 공존한다. 베는 쾌감과 피하는 긴장이 번갈아 온다.
- Q 패링으로 무지개탄을 받아 유도 반사하는 규칙(Core 확정)이 탄막을 "피하는 것"에서 "되돌려 주는 것"으로 바꾼다. 이것이 전투의 서명 동작이다.

## 3. 핵심 루프
탐험(안개 낀 숲, 먼 적이 보임) → 교전(근접 다수 처치 + 탄막 회피·패링·반사) → 드롭(기둥·소리·이름표) → 장비 착용(캐릭터에 보임, 실루엣 변화) → 스킬·합체·성급으로 빌드 성장 → 보스(무게 있는 예비동작, 끝까지 가는 공격, 큰 동작 뒤 빈틈) → 다음 구역.
30초 단위 리듬: 이동 5 → 교전 15 → 줍기·확인 5 → 이동 5. 큰 드롭은 구간당 1회 이상(수치는 LT 레인 뒤 확정).
