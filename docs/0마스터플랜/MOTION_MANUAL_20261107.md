# 무기 동작 제작 매뉴얼 (11-07, CTO)

> 계기: 11-07 대검 손 키 5동작을 "합격 후보"로 넘겼으나, 접점에서 팔이 굽어 손이 몸에 붙고 칼이 몸에서 튀어나와 보였다. 사용자 판정은 "몸에 딱 붙이고 깔짝거리는 건 역동성도 현실성도 없다", "레퍼런스를 보고 분석하라는 거지"였다. 이 매뉴얼은 영웅·적·보스의 모든 무기 동작(대검·한손검·단검·둔기·창)에 적용한다. 손 키, 모캡, 영상 추출, 구매 애니 모두 같은 검사를 통과해야 쓴다.

## 1. 원칙 (사용자 확정)

1. **리치를 최대로 쓴다.** 싸움의 정석은 칼을 최대한 멀리 뻗어 사거리를 늘리는 것이다. 단검도 몸에 붙여 휘두르지 않는다.
2. **팔을 끝까지 펴고 큰 원호를 그린다.** 무거운 칼은 휘두를 때 관성(원심력) 때문에 몸에서 최대한 멀어진다. 팔은 칼을 '미는' 게 아니라 칼에 '끌려가' 펴진다.
3. **몸은 반대로 버틴다.** 칼이 멀리 나가는 만큼 골반·상체가 반대쪽으로 무게를 싣고, 뒷다리를 펴서 받친다.
4. **관성으로 지나쳤다가 멈춘다.** 칼은 목표를 5~10° 지나쳤다가 몸이 붙잡아 멈춘다. 칼끝은 1~2f 늦게 선다. 손목은 칼보다 2~3f 늦게 꺾인다.
5. **무게가 보이게 든다.** 무거운 칼은 천천히 올라가 정점에서 잠깐 멈추고, 1~2f에 떨어진다.
6. **순서가 있다.** 루트(전신 이동) → 골반 → 가슴 → 손 → 칼끝 순으로 시간차를 두고 최고속이 온다.
7. 무기 크기에 비례해 1~5를 크게 잡는다. 우리 영웅 무기는 키만 한 양손 거대검이다.
8. **찌르기는 펜싱 런지처럼 최대한 길게 뻗는다.** 앞발을 크게 내딛어 보폭을 넓히고, 뒷다리는 곧게 펴서 민다. 어깨~팔~칼이 목표를 향해 일직선이 되게 끝까지 뻗는다. 상체는 앞으로 기울여 리치를 더한다. 찌른 뒤에는 같은 선을 따라 빠르게 회수한다.
9. **회전 공격은 회전력으로 팔이 더 펴진다.** 몸통이 돌수록 원심력이 커져 팔과 칼이 바깥으로 끌려 나간다. 회전 중에는 팔꿈치가 거의 펴진 채 칼끝 반경이 최대를 유지하고, 몸은 축을 낮게 잡아(골반 하강, 넓은 발) 버틴다.

## 3. 제작 순서

1. **G0 레퍼런스 형태 분석(숫자 말고 형태부터):** 같은 종류 레퍼런스 동작 2개 이상의 측면 6×4를 열어 접점·예비 정점·팔로스루 프레임마다 팔 펴짐, 칼끝 반경, 몸 기울기를 적는다. 시간 숫자만 재고 형태를 안 보는 것이 11-07 실패 원인이다.
2. **목표 곡선:** 레퍼런스 프레임별 수치(팔꿈치 각, 손~가슴, 칼끝 반경, 부위별 속도)를 우리 Core 틱 길이에 맞춰 시간축만 늘이거나 줄여 목표 곡선을 만든다.
3. **키 잡기:** 정점·접점·팔로스루 끝·회복 포즈를 먼저 잡는다(포즈 투 포즈). 그다음 사이를 채운다. 접점 포즈에서 팔이 다 펴졌는지부터 본다.
4. **물리 손질:** 손목 지연, 칼 오버슈트, 몸 반작용, 발 고정을 넣는다.
5. **자가 검수(4장).** 통과 전에는 보고하지 않는다.

- 시간 숫자만 맞추고 형태를 레퍼런스와 나란히 보지 않은 채 보고하기
