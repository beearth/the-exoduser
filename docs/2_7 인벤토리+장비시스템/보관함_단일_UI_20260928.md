# 보관함 단일 UI (2026-09-28)

| 항목 | 현행 계약 |
|---|---|
| 유일한 진입점 | `invPanel`의 `inventory-tab-storage` 보관함 탭. 상단 패널 네비게이션의 별도 창고 항목과 `storagePanel` DOM은 제거 |
| 단축키 | `BINDS.storage` 기본 `KeyN`, 게임패드 D-pad 오른쪽(button 15). 둘 다 인벤토리 보관함 탭으로 진입하고, 탭이 열린 상태에서 다시 누르면 패널을 닫음 |
| 데이터 | `_getStore()`가 읽는 기존 `STORAGE[0]` 200칸을 그대로 사용. 저장 형식·아이템·용량 변경 및 마이그레이션 없음 |
| 보관 조작 | 보관함 탭에서 왼쪽 가방 격자 또는 보관 목록의 아이템을 우클릭하면 넣고, 오른쪽 `invStorageCol`의 아이템을 우클릭하면 꺼냄. 기존 좌클릭 이동도 유지 |
| 다른 탭 | 가방 우클릭의 일반 장착·유골 등록은 기존대로 유지. 보관함이 가득 차면 아이템을 가방에 남기고 안내만 표시 |
| 이동 후 처리 | 선택 해제, 보관함 저장, 인벤토리 재렌더, 게임 저장. 가방·보관함 용량과 저장 형식은 변경 없음 |
| 보관함 아이콘 | `#invStGrid` 슬롯은 6열(560px 이하 5열)로 너비에 맞춰 커진다. 아이템 아트 래퍼와 `.iskin`/이미지·SVG도 슬롯 너비·높이에서 12px을 뺀 크기를 따라가며 `object-fit:contain`으로 비율을 유지한다. 렌더러의 `_itemSkin(item,34)` 기본값은 CSS가 덮어쓴다 |
| 스타일 캐시 | `ui-refinement.css?v=20260928-storage-icon-gem-picker2`를 일반판·쉬운판에서 사용 |
| 안내 표기 | 조작 안내와 도움말에는 `N — 보관함`으로 표시. 이전 `V — 창고` 안내는 폐기 |

이전 `storagePanel`, `storageGrid`, `storageFloorNav`, `renderStorage()` 관련 디자인 기록은 과거 버전 이력이다. 현재 화면에는 별도 창고 창이 존재하지 않는다.
