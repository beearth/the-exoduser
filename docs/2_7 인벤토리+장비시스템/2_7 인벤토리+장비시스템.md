## 📌 아이템 bonus 슬롯 분리 (2026-04-17)
- **공식**: `tier*50 + floor(random×40)+10` (모든 bonus, 반감 적용)
- **방어구 bonusHp + bonusSt** (tier별 범위):
  | tier | 범위 |
  |---|---|
  | T0 | 10~49 |
  | T1 | 60~99 |
  | T2 | 110~149 |
  | T3 | 160~199 |
  | T4 | 210~249 |
  6슬롯(shield/armor/boots/gloves/pants/cape) — **각각 독립적으로 bonusHp와 bonusSt를 가짐**
- **장신구 bonusShield + bonusMp** (tier별 범위): 동일 (위 표 참조) — 7슬롯(belt/necklace/ring1/ring2/bracelet/headband/headband2) — **각각 독립적으로 bonusShield와 bonusMp를 가짐**
- **무기 파트 (weapon/bow/helmet)**: bonusHp / bonusSt / bonusShield / bonusMp **모두 없음**
- **최대 총합** (T4 최대값 기준): 방어구 6×249 = **1,494 HP** / 방어구 6×249 = **1,494 ST** / 장신구 7×249 = **1,743 Shield** / 장신구 7×249 = **1,743 MP** (아이템 베이스 기준)
- **강화 HP**: `_enhHp += _dit.enh * 1.0` → **1강당 +1.0 HP** (`_hpEnhSet`: gloves/pants/boots — 2026-09-01 코드 기준 정정)
- **강화 MP**: `_enhMp += _dit.enh * 0.2` → **1강당 +0.2 MP** (`_mpEnhSet`: bracelet/necklace/headband/headband2/**ossuary** — 2026-09-01 유골함 추가·수치 정정)
- **강화 ST**: `_enhSt2 += it.enh * 0.2` → **1강당 +0.2 ST** (`_stEnhSet`: ring1/ring2/belt — 2026-09-01 코드 기준 정정)
- **강화 최대 기여** (각 슬롯 1000강 가정): HP 3×1000×1.0 = +3,000 / ST 3×1000×0.2 = +600 / MP (팔찌·목걸이·귀걸이1·귀걸이2·유골함) 5×1000×0.2 = +1,000.
- **변경 이력**:
  - ~2026-04-10: `(tier+1)*40` (T4=200) → 상향
  - 2026-04-11~04-16: `(tier+1)*100` (T4=500) 전 슬롯 동일, bonusHp 12슬롯
  - 2026-04-17: **슬롯 분리** — 방어구 6슬롯=bonusHp만, 장신구 6슬롯=bonusShield만
- **코드 위치**: `game.html` mkItem base 테이블 (라인 ~6723), applyStats (라인 ~14233)

## 유골함 (ossuary) — 유니크 단일 아이템 (2026-09-01 도감 개편)

**등급/티어/어픽스 롤 전면 폐지.** `mkItem('ossuary',…)`는 인자와 무관하게 아래 고정 유니크 1종을 반환한다. 소환 위력은 아이템이 아니라 **유골 도감(부위 수집)**에서 나온다.

| 항목 | 값 (고정) |
|---|---|
| 슬롯 id | `ossuary` (SLOT_NAMES 16번째, index 15 — 페이퍼돌 제외, 도감 패널 전용) |
| 이름/등급 | **전대의 유골함** / 유니크(rarity=5), tier=0, el=P, `unique:true` |
| 획득 | **첫 유골 부위 획득 시 자동 지급+자동 장착** (`_grantOssuaryIfNeeded`). 랜덤 드롭 풀(`DROP_SLOT_POOL`)·대장간 제작(`_craftSlots`)에서 제외 |
| 베이스 스탯 | eDef 60, bonusMp 150, ancPow 0.25(+25% 전대 위력) |
| 어픽스 | `ancHP +90%` 1개 고정 (T3, ancCount 필드 삭제 — 1기 거대 소환 고정). 구세이브의 `ancDur +3초`는 자동으로 전대 최대HP `+90%`로 해석한다. |
| 임플리싯 | `전대 위력 +10%` (`_iAncPow` 10 고정) |
| 전설/유니크 특수 | 없음 (null 고정) |
| 결정 슬롯 | 2개 고정 |
| reqLv | 0 (자동 지급 즉시 장착 가능) |
| 강화 | MP 강화 세트 소속 (`_mpEnhSet`: bracelet/necklace/headband/headband2/ossuary) |
| 아이템 스킨 | `output/imagegen/item-skins/ossuary_phys.png` (원소 변형 없음 — `_ITEM_SKIN_MISSING_VARIANTS` phys 폴백) |
| 세이브 | 구세이브 로드 시 `INV.equipped.ossuary=null` 마이그레이션. 구세이브의 구형(등급롤) 유골함도 그대로 동작하며, 당시 `ancDur` 값은 값 1당 전대 최대HP `+30%`로 호환한다. |

## 유골 부위 (bonePart) 아이템 (2026-09-01 신규)

철갑 전대 도감 수집용 드랍 아이템. 전대 1종 × 4부위 = 4종 콜렉션.

| 항목 | 값 |
|---|---|
| slot | `bonePart` (SLOT_NAMES 미포함 — 페이퍼돌 장착 불가, 도감 등록 전용) |
| 생성 | `mkBonePart(ancIdx, part, tier, rarity)` — ancIdx 0(ANC_ROSTER), part `skull/torso/arms/legs`, tier 0~4 클램프, rarity 0~5 클램프 |
| 필드 | `{slot:'bonePart', anc:ancId, part, rarity, tier, el:0, name:'{전대}의 {부위}', emoji:'🦴', reqLv:0, affixes:[]}` |
| 이름 | 예: `철갑 전대의 두개골`, `철갑 전대의 몸통` (부위 KO: 두개골/몸통/팔/다리) |
| 크기 | 1×1 (ITEM_SIZE.bonePart=[1,1]) |
| 아이콘 | `output/imagegen/item-skins/bone_{skull,torso,arms,legs}.png` (원소 변형 없음, `_itemSkinSrc` bone_ 접두 분기) |
| 픽업 | `pickupItem` 분기: 유골함 미보유 시 자동지급 → `_boneRegister` 자동 도감 등록. **기존 등록분이 같거나 높은 포인트(r+t)면 가방행** (수동 분해 가능) |
| 등록 | 가방에서 우클릭/["도감 등록" 버튼] → `equipItem` 인터셉트 → `registerBonePart`. 상위 포인트만 교체(하위는 거부+notify) |
| 도감 완성 | 철갑 전대의 4부위 모두 등록 → **철갑 전대 소환 해금** ("철갑 전대 해금!" notify+플로팅) |
| 드랍 | rollDrop 내 전용 롤: 일반 2% / 엘리트 6% / 미니보스 20% / 스테이지보스 40% / 챕터보스 100% (×dropBonus). 부위 4종 균등 랜덤, 등급은 몬스터 티어 가중치(_rwMap) 재사용, tier=e.dropTier |
| 필터 | 인벤 필터 바 "유골" 버튼 (`invFilter.slot='bonePart'`). 슬롯 필터에서 ossuary 버튼은 제거 |
| 분해 | salvageVal 표준(등급 기반) — 중복 하위 부위는 분해로 악의 환전 |

### 정렬 (`↕ 정렬` 버튼 / `sortInvBag()` / `_invAutoPlace()`)
정렬 기준: **calcCP() 가상장착 베니핏** — UI의 "CP +/-" 표시와 완전 동일
1. **즐겨찾기(fav)** → 최상단
2. **쓰레기(junk)** → 최하단
3. **업그레이드(CP+) 먼저** → 이득 큰 순
4. **다운그레이드(CP-) 뒤로** → 손해 적은 순

## 장비 장착 사운드 — 무기 타입별 매핑 (2026-08-11 개편)
