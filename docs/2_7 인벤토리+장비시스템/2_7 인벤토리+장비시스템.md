# 2-7. 인벤토리 + 장비 시스템

2026-09-27 같은 아이템의 호버→선택 상세 복귀: 장비/가방에서 선택한 아이템을 호버한 뒤 포인터를 빼면 우측 정보판을 다시 렌더하되, 동일한 아이템과 출처라면 정보판 본문·나란히 비교 카드 2개·펼친 수치 차이의 스크롤 위치와 펼침 상태를 복원한다. 다른 아이템을 가리키면 그 아이템 상세는 처음부터 보여 준다. 아이템 데이터·장착·저장 값은 바꾸지 않는다.

2026-09-27 장비 비교 중 휠 입력: 우측에 장착품/가방품 비교가 보이면 호버 미리보기와 클릭 후 고정 비교 모두 가방 영역의 휠을 두 비교 카드 정보에 전달한다. 아이템 그림·가방 빈 칸 위에서도 동일하다. 카드가 짧거나 끝에 닿아 더 내려갈 내용이 없어도 가방 그리드는 움직이지 않는다. 비교 정보가 닫혀 있을 때만 기존 가방 스크롤을 사용한다. 구현 위치는 `ui-panels.js`의 인벤토리 `wheel` 위임이며 아이템·저장 수치는 변경하지 않는다.

2026-09-27 일반 장비 픽업 현행: `pickupItem`은 빈 장착 슬롯이 있어도 아이템을 `INV.bag`에 넣고 10열 가방 좌표를 배정한다. 장착은 아이템창에서 명시적으로 한다. 첫 유골 부위의 유골함 지급/등록과 대장간 제작 직후 빈 슬롯 장착은 별도 경로로 유지한다. 장비 탭 1200px 초과 본문은 장비판/10열 가방/정보판 `1.28fr / clamp(400px,30vw,600px) / 1fr`이며, 정보판은 격자 바로 옆의 남는 공간을 쓴다. CSS 캐시는 `inventory-space.css?v=20260927-aligned12`.

2026-09-27 보석함 장비칸 최신 이미지 계약: 정사각형 아이템 원화에 맞춰 카드를 1:1 정사각형으로 만들고 `_itemSkin(item,96)`을 확대·잘림 없이 표시한다. 검은 빈 홈은 그림 위 하단에 겹쳐 뚫린 구멍처럼 보인다. 화면 폭 700px 이하는 4열, 480px 이하는 3열로 배열해 카드 비율을 지킨다. 아이템 그림은 입력을 가리지 않으므로 홈 클릭·드롭은 유지한다. 정확한 배치·CSS 캐시는 [보석함 UI 문서](../3.1%20ui%20hud%20디자인/GEM_ATELIER_20260927.md)를 따른다.

2026-09-27 보석 이미지 현행: 장비 보석 홈과 보석함은 [18종 저주 유물 아트 매핑](../3.1%20ui%20hud%20디자인/GEM_ATELIER_20260927.md)의 로컬 시트 2개를 공유한다. 홈에는 20×20px 셀을 표시하며, 시트 로딩에 실패하면 기존 컷 보석으로 되돌린다. 장착/탈착·능력치·저장 수치는 그대로다.

2026-09-27 빈 홈 표시는 검은 홀로 확정한다. `data-filled=false`의 중앙은 순흑, 가장자리는 어두운 금속 링이다. 장착 가능/드래그 대상 강조는 링에만 더하고 검은 중심은 유지한다. 보석이 채워지면 고유 아트가 표시된다. 빈 홈의 `◇` 문자는 화면에서 숨기지만 버튼 접근성 이름과 클릭·드래그 장착 기능은 유지한다.

2026-09-27 보석 장착 화면 최신 피드백: 선택 보석과 호환되는 장착 장비라도 빈 홈이 없으면 `full`로 표시하고 빈 홈이 있으면 `ready`로 표시한다. 선택 보석색으로 실제 장착 가능한 홈만 밝히며, 빈 홈 수를 장비판 안내에 표시한다. 비호환 홈은 disabled, 이미 채워진 홈의 탈착은 유지. [보석함 현행 계약](../3.1%20ui%20hud%20디자인/GEM_ATELIER_20260927.md) 참조.

2026-09-27 보석 좌클릭 홀드 조작: 누르면 해당 보석이 선택되어 호환 빈 홈이 강조되고, 6px 이상 이동해 빈 홈에 놓으면 1개 장착한다. 드롭 순간 현재 장비·빈 홈·보유 원본·부위 호환을 재검증하고 성공 시에만 저장한다. 잘못된 홈/바깥에 놓거나 Escape/포인터 취소하면 이동하지 않는다. 투명한 비활성 패널의 자식 포인터 입력을 꺼 보석 칸 전체의 hover를 회복했다. 클릭 장착·탈착과 키보드 조작도 유지한다.

드래그 시에는 카드나 이름이 아니라 58×58px 보석 그림만 커서 중앙을 따라간다. 보유 묶음 1개면 원래 칸의 보석 그림을 드래그 중 숨기고, 여러 개면 남은 수량을 나타내도록 유지한다. 취소 시 그림을 복구한다. 장착·세이브 판정은 기존 경로를 유지한다.

장착 보석을 확인할 때는 채워진 홈에 hover 또는 키보드 focus를 주면 감정판에 그 보석의 이름·성급·강화·2~3개 실효 옵션·설정을 표시한다. `장착 중: <부위>`/`Equipped: <slot>`으로 보유 보석과 구별하며, 홈에서 벗어나면 기존 선택 보석으로 복귀한다. 이 미리보기는 보유량·장착·저장 값을 바꾸지 않는다.

2026-09-27 상세 원장 마감: 장착 출처 배지, 기본 수치 행 교차 배경·아래선, 특수 옵션 묶음의 배경·간격을 적용했다. 비교 헤더는 긴 단어 줄바꿈 지원. 하단 액션 줄은 기존 한 줄·가로스크롤 유지. 정확한 선택자·수치는 `docs/3.1 ui hud 디자인/UI_COMPOSITION_20260925.md`의 **아이템 상세 원장 마감** 표 참조.

## 인체형 장착창 Paper Doll (2026-09-23, 유골함 제외)

인벤토리는 전체화면이며 장비·가방·정보를 동시에 표시한다. 1201px 이상에서 세 열은 1.25:1.1:.85, 간격 10px이다. 장비판은 654×560px이며 96×96px 소켓 16개를 기사 주변 네 줄로 배치한다. 아이템 스킨은 62×62px(left17/top12px), 이름 띠는 13px(left/right19/bottom12px), 라벨은 10px이다. 기사 표시 영역은 385×560px로 기존 210×320px보다 폭83.3%·높이75% 커졌다. 슬롯 padding은0이며, 기존 승인 프레임 img/ui/ossuary_socket_hf_v2.png를 ::before inset −16px 0 /128×128px로 표시한다. 클릭 영역96×96px와 장식 영역96×128px를 분리해 원본 비율을 유지한다. 기존 선택·호버 상세·우클릭 해제 동작은 유지한다. 카드 스킨은 `armor`, `axe`, `belt`, `boots`, `bracelet`, `cape`, `crossbow`, `earring`, `gloves`, `helmet`, `necklace`, `pants`, `shield`, `sword` 장비군에 한해 `img/ui/item-cutouts/{base}_phys_cutout.png`의 투명 원화를 우선 사용한다. 속성별 원본 정사각 배경은 이 열네 장비군에서 표시하지 않으며 컷아웃 로드 실패 시에만 기존 물리 PNG로 폴백한다.

### 분해 보상 공식 (`salvageVal`, 2026-09-26 코드 동기화)

| 항목 | 현재 코드 |
|---|---|
| 경제 등급 r | `_itemEconomyRarity(rarity)` = 0 이상 정수일 때 min(rarity,4), 나머지0 |
| 기본액 | `[1000,2000,10000,20000,50000][r]` |
| 환수 배율 | `[0.5,0.7,1.0,1.3,1.8][r]` |
| 환수 누적합 | Σ(i=0..enh−1) ceil(max(1,ceil((1+i×0.15)×1.5))×배율) |
| 현재 강화 환수 | `~~(누적합×0.5)` (기존 코드의32비트 정수 변환 유지) |
| 이전 강화 환수 | `_enhRefund>0`이면 max(현재 강화 환수,_enhRefund) |
| 티어 | `(tier||0)×2` |
| 최종 | 기본액+환수+티어 |
| 실제 강화 지출 | `enhCost`: `_malCost(ceil(enhCostRaw(enh)×배율))`; `enhCostRaw(n)=max(20000,ceil((20000+n×3500)×1.5))` |

유니크(5)는 전설(4)과 같은 경제 등급을 사용하며 아이템 표시 등급은 유지한다. 기본 전대의 유골함(tier0/enh0)은50,000. 일반1,000/고급2,000/희귀10,000/영웅20,000/전설50,000은 변경하지 않는다.

이전 문서의 “실제 강화 비용 누적합의50%” 설명은 현재 환수 코드와 달랐다. 위 표가 현재 구현이며 이번 수정에서 환수 밸런스 공식은 바꾸지 않았다. 장비 교체의 old._enhRefund 역시 위 환수 누적식을 사용한다. 실제 강화 지출과 환수식의 단위 차이는 별도 밸런스 검토 항목이다.

## 장비 장착 사운드 — 무기 타입별 매핑 (2026-08-11 개편)

> 🔖 **음원 출처**: `equip_base`=freesound #518850(mrickey13), `equip_sword`/`equip_crossbow`=유저 제공, `equip_rare`=ElevenLabs 잔존. 출시 전 라이선스·표기 확인.

`playEquipSfx(item)`은 실제 장착이 성공한 뒤에만 재생한다. 수동 교체(`equipItem`)와 제작 직후 빈 슬롯 자동 장착이 같은 함수를 사용한다. 바닥 아이템 습득은 장착하지 않으므로 장착음을 재생하지 않는다. 장비 스탯·강화 전승·결정 전승·저장 순서는 바꾸지 않는다.

초기 슬롯 재질 3분화는 폐기하고 **무기 타입별 전용음 + 기본음 폴백**으로 개편했다. `item.wtype`(근접)·`item.btype`(활)로 전용음을 고른다.

| 조건 | 파일 | 볼륨 | 성격 |
|---|---|---:|---|
| 검 `wtype==='sword'` | `sfx/equipment/equip_sword.mp3` | 0.42 | 유저 제공 검 장착음 |
| 석궁 `btype==='crossbow'` | `sfx/equipment/equip_crossbow.mp3` | 0.42 | 유저 제공 석궁 장착음 |
| 그 외 전부 (미매핑 무기·방어구·장신구) | `sfx/equipment/equip_base.mp3` | 0.42 | freesound 기본 장착음 |
| 희귀 이상 `rarity >= 2` | `sfx/equipment/equip_rare.mp3` | 0.28 추가 레이어 | 룬 글린트. 베이스 뒤에 함께 재생 |

- 매핑: `_EQUIP_SFX_BY_WTYPE={sword:'equip_sword'}`, `_EQUIP_SFX_BY_BTYPE={crossbow:'equip_crossbow'}`. 무기 타입(dagger/hammer/mace/club/axe/spear, repeater/arcane) 전용음을 추가하려면 파일 추가 후 이 테이블에 키만 등록.
- 베이스 피치 `1±0.04`, 희귀 룬 레이어 `1±0.03`.
- 해제(`unequipItem`)는 기존 짧은 합성 해제음 유지. 가방 공간 실패·요구 레벨 실패·바닥 아이템 획득에는 장착음 없음.
- (개편 이력: `equip_weapon`/`equip_armor`/`equip_accessory` 슬롯 재질 분화 → 무기타입 매핑. 구 파일·등록 제거.)

## 아이템 습득 사운드 — 그랩/뒤적임 랜덤 풀 (2026-08-11)

> ⚠️ **임시 음원 (교체 가능)**: `sfx/pickup/` 6파일은 프리사운드 foley 가공본. 배선 확정, 음원만 필요 시 교체.
> 🔖 **출시 전 라이선스 확인 필수**: cloth-grab=freesound **#667271**(alegemaate), rummage=freesound **#257570**(kodack). CC 라이선스·저작자 표기 의무 확인 요망.

`playItemPickupSfx(item)`은 아이템을 실제로 습득한 뒤 재생하며, 다른 게임처럼 **등급 무관 그랩/뒤적임("사삭") 6종을 랜덤 재생**한다(초기 등급별 계층안 폐기). 골드·물약·보주·스킬젬 등 비아이템 습득은 기존 범용 절차음 `SFX.pickup()`을 그대로 쓰고, 아이템만 이 함수로 분리한다.

| 조건 | 파일 | 성격 |
|---|---|---|
| 모든 아이템 (등급 무관) | `pickup_item` + `pickup_rummage1`~`5` 중 랜덤 1종, 볼륨 0.5 / 피치 `1±0.05` | cloth-grab 1종 + rummage 슬라이스 5종을 매 습득 랜덤 선택 → 반복감 제거 |

- 함수: `const _PICKUP_SFX_POOL=['pickup_item','pickup_rummage1'…5]; playItemPickupSfx`가 풀에서 `~~(Math.random()*6)`로 1종 선택. 등급 분기 없음.
- 적용 경로: 바닥 아이템 가방 습득(`pickupItem`), 펫 회수(`pickupItem` 경유). 빈 슬롯이어도 가방으로 들어가며 장착음은 재생하지 않는다.
- 필터 미만 즉시 분해(`rarity < OPT.minPickRar`)와 제작 완성음은 아이템 습득이 아니므로 `SFX.pickup()`을 유지한다.
- **이중 재생 정리**: 월드 아이템 습득 콜사이트 2곳이 `pickupItem` 내부 재생과 별도로 `SFX.pickup()`을 한 번 더 울리던 것을 제거했다(1회 습득 = 사운드 1회).
- (폐기 이력: ElevenLabs 등급 계층안 → 단일 스와이프 → 현 랜덤 풀.)

## 줍기 필터 (자동 습득 차단) — 등급 + 티어

설정(ESC)에서 자동 습득/펫 회수를 걸러내는 2종 필터. 둘 다 **월드 드롭 생성 시**와 **펫 회수 시** 적용된다.

| 필터 | OPT 키 | 슬라이더 | 의미 | 기본 |
|---|---|---|---|---|
| 최소 줍기 등급 | `minPickRar` | `#optMinRar` 0~4 | 해당 rarity 미만 드롭 스킵/즉시분해 | 0(일반 이상=off) |
| 최소 줍기 티어 | `minPickLvTier` | `#optMinLv` 0~7 | `reqLv` 하한 미만 드롭 스킵/즉시분해 | 0(사용 안 함=off) |

- **티어→reqLv 임계**: `l = t===7?1000:t*100`, 임계 `= max(0, l−100)`. (헬퍼 `_minPickLvThr()`, off=0 → −1 반환=무필터). 설정 UI(`optMinLv` oninput/populate) 라벨 공식과 동일.
- **적용 지점 (minPickRar와 동일 위치)**: ① 드롭 생성 `rollDrop`(mkItem 직후, `_wiPush` 직전) — 임계 미만이면 월드 아이템 미생성. ② 펫 회수(도착 시 salvage 분기) — 임계 미만이면 습득 대신 즉시 분해(악의 획득).
- `item.reqLv = max(0, floor(P.lv/10)*10 − 10)`(드롭 시 캐릭터 레벨 기반). 티어 필터는 "현재 레벨 브래킷보다 낮은 구형 드롭 자동수거 방지" 용도.
