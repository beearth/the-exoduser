## 제작·검수 결과

- 전체 원본 64종, 무손실 WebP 128판. 중앙 RGB 대조 128/128 일치. 홀수 폭 출력은 중앙 붙임 좌표를 `ext-floor((fullWidth-outputWidth)/2)`로 계산한다. 원본 파일은 수정하지 않았다.
- 두 행 참조 방식에서 색조 경계가 큰 1·5·6·41·63은 전체 파노라마 재시도 후에도 실패해, 128px 가장자리 단독 참조로 제작 방법을 바꿨다. 33의 새 적 생성 후보는 제외하고 96px 지형 가장자리 참조로 재제작했다. 생성 영역에만 색조를 연결하며 원본은 픽셀 그대로다.
- 3840×1080 표시 기준 좌우 각160px·높이1080px의 1x 크롭 64종을 직접 검수했다. 증거: `I:/EXODUSER-Storage/keyart-superwide/20261031/seams-1x/`. LEFT/RIGHT 두 크롭 사이 경계는 검수 보드 배치선이며 실제 그림 경계와 구분한다.
