## 2026-09-27 장비 원화·카드 공통 규격

현행 장비 원화 대부분은 256×256px 정사각형이고 유골함 원화는 128×128px이다. 이전의 가로로 넓은 카드·낮은 이미지 영역·1.26배 확대는 정사각 원화의 위아래를 잘라 규격이 맞지 않았다. `_itemSkin(item,96)`을 사용하고 카드를 너비 기준 **1:1 정사각형**으로 만든다. 이미지는 카드 안쪽 1px를 채우되 `object-fit:contain`, 추가 확대 없음이다. 부위명은 그림 위 상단, 검은 홈과 장착 홈은 그림 위 하단에 겹친다. 아이콘의 `pointer-events:none`으로 홈 클릭·드롭을 보장한다.

| 요소 | 현행 규격 | 입력·시각 계약 |
|---|---|---|
| 원화·카드 | 원화 256×256px(유골함 128×128px), 카드 `aspect-ratio:1`, 최소 높이72px, 이미지 카드 안쪽1px, 확대·크롭 없음 | 형태 비율을 보존하고 카드 밖을 침범하지 않음 |
| 큰 화면 장비판 | 5열×6행, 슬롯별 기존 배치와 중앙 캐릭터 실루엣 유지 | 장비 부위 대응 유지 |
| 700px 이하 | 4열 자동 흐름, 중앙 실루엣 숨김 | 폭이 부족해 5열 카드가 세로로 찌그러지는 문제 방지 |
| 480px 이하 | 3열 자동 흐름 | 390 CSS px 화면에서 카드 약93×93px |
| 부위 이름 | 그림 위 상단, 홈보다 높은 표시 계층 | 어두운 문자 그림자로 읽힘 유지 |
| 빈 보석 홈 | 그림 위 카드 하단, 기존 홈 크기 | 검은 중심과 어두운 외곽 링; 클릭·드롭 가능 |
| 장착된 홈 | 같은 위치 | 보석 그림과 고유색 링; 클릭 탈착 가능 |

후속 장비 원화 제작 규격은 **256×256px RGBA 정사각 캔버스**다. 장비 본체는 x=24~232px·y=20~216px 안에 두고, 바깥 8px는 광채·연기만 허용한다. 홈이 겹치는 하단 40px에는 장비를 알아보는 데 필요한 핵심 문양을 두지 않는다. 카드·홈·부위명·테두리를 원화에 굽지 않으며, 같은 부위 변형끼리는 본체가 차지하는 높이와 중심을 맞춘다. 기존 원화의 불투명 배경·여백 차이는 별도 자산 교체 과제로 남겨두며 현재 코드가 자동으로 제거한다고 가정하지 않는다. 현행 보석함 스타일 캐시는 `inventory-gems-finish.css?v=20260927-square-art2`이다. 이전 문단의 `gem-only1` 값은 당시 검수 버전 기록이다.

## 2026-09-27 장착 청각 피드백

보석을 클릭 또는 드래그로 호환 빈 홈에 실제 장착하면 `attachCrystal`의 공통 성공 지점에서 `SFX.crystalEquip()`이 한 번 재생된다. 취소·비호환·이미 찬 홈·탈착에는 재생하지 않는다. 기존 0.48초 `equip_rare` 파일의 짧은 금속 안착 소리와 마찰·상승/하강 공명을 결합했으며 게임 효과음 볼륨을 따른다. 생성형 SFX 연결 상태와 레이어 수치는 [보석 장착 효과음](../6사운드디자인/보석_장착음_20260927.md)에 기록했다.

## 2026-09-27 보석만 집어 드래그

좌클릭 홀드 상태로 6px 이상 움직이면 보유 칸에서 **보석 아트만** 커서 중앙으로 꺼낸다. 이전 이름·테두리·판 배경이 붙은 드래그 카드(`.inv-cr-drag-name`)는 제거했다. 따라오는 입력 투과 이미지는 64×64px 영역 안의 58×58px 보석 한 개이며 보석 고유색 광택을 준다. 수량이 1개인 칸은 드래그 중 원래 보석 그림을 숨겨 실제로 뽑힌 것처럼 보이고, 묶음 수량이 2개 이상이면 남은 보석을 대표하도록 원래 그림을 유지한다. 이름·성급·수량은 원래 칸에 남는다.

호환 빈 검은 홈에 놓으면 기존 1개 장착·저장 경로를 사용하고, 밖에 놓거나 Escape/포인터 취소 시 따라오던 이미지를 제거하고 원래 칸의 그림을 복구한다. 드롭 검증·부위 제한·옵션 수치·세이브 형식은 그대로다. 드래그 그림은 `aria-hidden=true`, `pointer-events:none`으로 대상 홈의 입력을 가리지 않는다. 당시 CSS 캐시는 `inventory-gems-finish.css?v=20260927-gem-only1`. 격리 브라우저에서 드래그 그림 자식 1개·문자 0, 수량 1개 원래 그림 숨김→취소 시 복구, 견갑 빈 홈 드롭 시 보유 10→9·홈 장착, 수량 2개 묶음 원래 그림 유지, 기존 장착 회귀 16항목 통과를 확인했다. 검증 탭은 `_dbReady=false`로 저장을 차단했다.

## 2026-09-27 빈 홈 = 검은 홀

장비판의 `data-filled=false` 보석 홈은 중앙을 순흑 `#000`으로 파고든 검은 홀로 표시한다. 빈 홈의 `◇` 문자는 화면에서 숨기되 버튼의 부위·홈 번호·장착 가능 여부 `aria-label`은 유지한다. 금속 외곽 링과 안쪽 그림자로 어두운 장비판에서도 구멍 윤곽을 보존한다. 보석이 박힌 `data-filled=true` 홈은 고유 보석 이미지와 기존 보석색 테두리를 유지한다.

| 상태 | 중심 | 테두리·피드백 |
|---|---|---|
| 빈 홈 | 검은 홀 | 어두운 금속 링, 비호환 disabled는 흐리게 표시 |
| 장착 가능 빈 홈 | 검은 홀 유지 | 선택한 보석 고유색 링과 바깥 광택 |
| 드래그 대상 빈 홈 | 검은 홀 유지 | 밝은 금색 이중 링과 광택 |
| 장착된 홈 | 보석 아트 | 장착 보석 고유색 테두리 |

호버나 드래그 중에도 검은 중심을 밝은 색으로 채우지 않는다. 드래그 상태는 `#invCrystalsPanel[data-gem-dragging=true]`에 기록되므로 카드·홈·드롭 대상 강조 CSS도 이 요소를 대상으로 한다. 이전 `#invPanel[data-gem-dragging=true]` 선택자는 실제 상태와 맞지 않아 드래그 강조가 빠졌으며 이번에 바로잡았다. 홈 크기·장착 제한·옵션·세이브는 변경하지 않는다. 현행 CSS 캐시는 `inventory-gems-finish.css?v=20260927-gem-only1`.

## 2026-09-27 호버 정렬 및 좌클릭 홀드 장착

닫힌 `.panel`의 일부 자식(능력치 창의 별·패시브 등)이 자체 `pointer-events:auto`로 투명한 상태에서 보석함 위 입력을 가로챘다. `game.html`에서 `.panel:not(.on) *`의 포인터 입력을 끄므로, 실제 보석 칸의 보이는 사각 영역 전체가 그 칸의 hover 대상이 된다. 보유 보석 위에 커서를 놓으면 감정판이 해당 보석을 미리 보여주고 벗어나면 선택한 보석으로 돌아온다.

| 단계 | 조작·표시 | 데이터 처리 |
|---|---|---|
| 좌클릭 누름 | 보석 선택, 호환되고 비어 있는 장비 홈 `data-ready=true`와 카드 `data-socket-state=ready` 강조 | 저장 없음 |
| 6px 이상 홀드 이동 | 보석 그림만 따라오는 입력 투과 드래그 아이콘 표시, 진입한 유효 홈 `data-drop-target=true` 추가 강조 | 저장 없음 |
| 호환 빈 홈에서 놓음 | 원본 보유 객체·현재 장비·빈 홈·부위 호환을 다시 검사한 뒤 1개 장착 | 성공 시에만 기존 `attachCrystal`→`dbSaveNow`→재렌더 |
| 비호환/가득 찬 홈·바깥에 놓음 | 드래그 표시 제거, 선택 상태만 유지 | 보유량·장비·저장 변경 없음 |
| Escape/포인터 취소 | 드래그 표시와 문서 포인터 리스너 제거 | 장착 없음 |

기존 클릭 장착·클릭 탈착·키보드 초점 선택은 유지한다. 드래그 대상은 빈 홈만 받으며 채워진 홈에 떨어뜨려 탈착시키지 않는다. 적용 CSS 캐시는 `inventory-gems-finish.css?v=20260927-gem-drag1`. 실제 브라우저에서 이전에 가려졌던 `밤의 씨앗` 칸 중앙 hover가 정확히 해당 보석을 가리키는지, `순교자의 눈물`을 견갑 홈에 드래그해 보유 13→12 및 해당 홈 장착, 비호환 `밤의 씨앗`을 견갑에 놓아 보유/장착 무변경을 확인했다. 테스트 탭은 `_dbReady=false`로 세이브를 차단했다.

## 2026-09-27 실제 장착 가능 홈 표시

채워진 홈의 hover/focus는 장착 보석을 왼쪽 감정판에 미리보기로 표시한다. mouseleave/blur 때 보유 목록의 기존 선택으로 돌아간다. 감정판 성급 행에 `장착 중: <부위>` 위치를 붙이고, 같은 옵션 행·고유 문구를 사용한다. 저장·장착·선택 보석 객체는 바꾸지 않는다. 브라우저 실제 런타임에서 무기의 피의 맹세 3옵션 표시 후 선택한 사냥꾼의 눈으로 복귀 확인. 보석함 격리 회귀 내부16항목, Node 전체13테스트 통과.

| 상태 | 판정 | 화면 |
|---|---|---|
| `ready` | 선택 보석과 부위 호환 + `item.crystals`에 빈 홈 ≥1 | 장비 카드 밝은 테두리·광택, 빈 홈에 해당 보석색 링 (`data-ready=true`) |
| `full` | 부위 호환 + 빈 홈 0 | 장착 가능 광택 제거. 채워진 홈은 기존 탈착 가능 |
| `incompatible` | 부위 비호환 | 카드 약한 표시, 빈 홈 disabled 유지 |
| 미선택 | `active=null` | 장비판 기본 안내와 기존 피커 동작 유지 |

`readyCount`는 실제 장착 장비의 호환 빈 홈 수 합계이다. 선택 시 장비판 안내에 숫자와 빛나는 홈 조작을 한국어/영어로 표시한다. 기존 `data-compatible`, 안전 재검증·저장 호출은 유지한다. 채워진 홈은 장착 보석의 고유색 링을 사용한다. 현행 CSS 키는 `inventory-gems-finish.css?v=20260927-gem-only1`. 실제 게임에서 사냥꾼의 눈 선택 시 빈 홈4개·`ready` 왕관/석궁·`full` 무기, 보석함 회귀 내부16항목과 Node 전체13테스트 통과.
