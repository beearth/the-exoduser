# 패시브 AP 자동 투자 예약 (2026-09-27)

패시브 성장창에서 AP가 부족해도 목표 패시브 레벨을 예약할 수 있다. 예약은 누르는 즉시 캐릭터 세이브에 저장되며, 창을 닫아도 유지된다. 기존의 AP가 충분한 변경 계획은 하단의 `변경 적용` 버튼으로 확정하고, 확정 전 창을 닫으면 취소된다.

| 항목 | 규칙 | 코드 위치 |
|---|---|---|
| AP 획득 | 짝수 레벨에 도달할 때마다 1 AP | `game.html`의 `addExp` |
| 패시브 비용 | 1~10레벨 투자 비용 순서 `1, 1, 1, 2, 2, 2, 3, 3, 3, 5` AP | `stat-panel-ui.js`의 `COSTS` |
| 부족한 AP | `자동 투자 예약` 버튼을 활성 상태로 유지하고 예약 | `stat-panel-ui.js`의 `growthUpgrade` |
| 예약 순서 | 먼저 예약한 레벨부터 적용. 첫 예약 비용이 부족하면 뒤 항목을 건너뛰지 않고 대기 | `game.html`의 `_processPassiveQueue` |
| 레벨업 자동 투자 | 매 레벨업 후 예약을 검사한다. 비용이 충분한 레벨만 적용하고 AP를 차감한다 | `game.html`의 `addExp` |
| 패시브 상한 | 현재 레벨과 같은 패시브의 예약 수가 해당 패시브 최대 레벨을 넘지 못한다 | `queuePassive` |
| 예약 취소 | 성장창 아래의 `자동 투자 예약` 목록에서 개별 항목을 누른다 | `cancelQueuedPassive` |
| 환불과 예약 | 패시브 환불 계획을 적용하면 해당 패시브의 기존 예약을 제거한다 | `applyPlan` |

예약은 실제 투자 전에는 효과와 AP를 변경하지 않는다. 충분한 AP가 들어오면 패시브 레벨을 올리고 전투 능력치를 재계산한다. 성장창에는 현재 AP와 예약 개수, 자동 투자 조건을 설명한다.
