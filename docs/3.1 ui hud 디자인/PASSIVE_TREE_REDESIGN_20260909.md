# 전투의 길 — 스탯 통합 패시브 트리 개편 방향

상태: **2026-09-09 사용자 방향 확정 / 노드 설계 초안 / 런타임 미반영**.
현재 게임 구현은 [성장의 각인 현행 계약](능력치_패시브_개편_20260909.md)을 따른다. 본 문서의 예정 구조를 현행 수치로 해석하지 않는다.

## 사용자 확정 방향

| 구분 | 개편 방향 |
|---|---|
| 스탯 | 힘·민첩·지능·행운·근성의 개념과 전투 기여 유지 |
| 별도 배분 창 | 현재 상단 기본 능력치 투자 칸 제거, 능력치 선택을 전투의 길로 편입 |
| 아이템·결정 | 현재 스탯/공격/방어/자원/회복 공급 역할 유지. 보유 장비·소켓 효과를 삭제하거나 평준화하지 않음 |
| 패시브 | 능력치 소형 노드와 전투 옵션을 같은 연결형 트리에서 선택 |
| 화면 | 사용자 선택은 연결형 트리. 중앙에서 전투 계열로 뻗으며 선택 노드까지의 연결을 명확히 표시 |
| 목표 | 선택은 간단하고 조합은 다양하게. 반복 수치 강화뿐 아니라 조건부 효과·전투 방식 변경을 확대 |

스탯 직접 배분 칸을 제거한다는 지시를 스탯 공식 전체 폐기 또는 레벨 자동 성장으로 일괄 대체하는 뜻으로 해석하지 않는다.

## 노드 계층 — 제안

| 종류 | 역할 | 옵션 예시(명칭·수치 미확정) | 시각 표시 |
|---|---|---|---|
| 소형 | 경로를 열면서 기본 성장 확보 | 힘, 민첩, 지능, 행운, 근성, 최대 자원, 회복, 피해 증가 | 작은 원, 습득 시 경로와 함께 점등 |
| 주요 | 특정 전투 성향 강화 | 출혈 대상 근접 피해, 근거리 투사체 피해, 관통, 축적, 자원 조건부 보너스 | 중간 문장과 이름 |
| 핵심 | 이점과 대가로 빌드 방향 결정 | 다발 투사체/발당 피해 감소, 지속 피해 강화/직접 피해 감소, 낮은 HP 전투 특화 | 큰 인장, 이점·대가 동시 표시 |

위 효과는 EXODUSER용 제안이며 PoE2의 실제 노드 이름·정확한 수치를 옮긴 표가 아니다. 모든 효과에 불이익을 강제하지 않고, 핵심 노드에만 빌드 선택을 바꾸는 교환 조건을 우선 검토한다.

읽기 예시: `출발 → 민첩 → 투사체 피해 → 관통 특성 → 투사체 핵심 특성`. 다른 가지와의 연결은 유지하되 길찾기만을 위한 무효 노드는 피한다. 능력치 소형 노드는 실제 성장 효과를 제공한다.

## 현재 코드의 보존 대상과 구현 준비

| 현재 계약 | 확인 위치 | 편입 시 처리 원칙 |
|---|---|---|
| 직접 배분 | `STATS`, `_grit`, `STAT_DEF`, `STAT_MAX` | 신규 투자 UI를 트리 노드로 전환. 기존 투자량은 이력 보관 및 명시적인 환불/이전 절차 필요 |
| 장비 능력치 | `bStr/bDex/bInt`, `_eqStat`, `strFlat/dexFlat/intFlat`, 행운/근성 어픽스 등 | 동일 장비의 보너스 보존, 트리 기여와 중복 계산 금지 |
| 결정 | `CRYSTAL_DEFS`, `crystalVal`, `P._crystalStats` | 현행 결정은 ATK/치명/속성/HP/DEF/속도/회복/드롭/ST/MP 등을 부여. 모든 결정이 STR/DEX/INT를 직접 주는 구조로 오인하지 않음 |
| 최종 전투 수치 | `applyStats`, `recalcSt`, 공격 ref, `statDex/statCrit/statCritDmg`, 쉴드 재생·회피 등 | 장비 + 결정 + 트리 + 기존 기본 성장의 기여를 각 공식의 기존 적용 단계에 합산 |
| 기본 성장 | `_lvB()=floor(P.lv×0.5)`와 스테이지/난이도 기반 값 | 이번 사용자 설명으로 삭제 또는 새 값 확정된 항목이 아님. 트리 전환 시 별도 수치 감사 |
| SP | 액티브 습득·강화·합체와 스탯 투자가 공유. 레벨업 SP+3 | 스탯 창 폐기만으로 SP 자체를 삭제하거나 잔고를 AP와 임의 합치지 않음 |
| AP | 짝수 레벨업 시+1, 기존 패시브 단계 비용 | 노드 비용·총 투자 예산과 기존 AP 이전 규칙은 새 노드 구성에 맞춰 산정 |
| 저장 | `stats/passives/grit`, 자원 잔고, 기존 환불 버전 | 원본 저장 보관·버전 표식·반복 로드 멱등성·이중 환불 방지 필요 |
| 고정 전투 계약 | 무지개탄 Q 전용 패링, E 패링 불가 | 노드 옵션으로 변경하지 않음. 보호된 2_3 문서 수정 없음 |

## 아직 확정하지 않은 구현 값

노드 수, 노드별 수치·비용·선행 연결, 최대 투자 예산, 핵심 동시 선택 제한, 기존 직접 투자분의 반환/전환 비율은 미확정이다. 스탯을 소형 노드로 포함하는 것과 트리 방식을 선택한 것은 확정 방향이며, 수치 확정과 구분한다.

구현 순서: 노드 목록과 연결 시안 → 장비/결정/트리 합산 계약 → 구세이브 이전 → 트리 투자/환불 UI → 실제 전투·자원·장착/해제·저장 회귀 검증. 기존 패시브와 새 노드 효과를 동시에 더해 이중 적용하지 않는다.
