# 전투 HUD 결함표 + 웹·Unity 비교 (2026-11-05, 레인 U1)

- 기준: unity/main `795869009`. Unity 코드는 바꾸지 않았다. 설계와 시안만 담았다.
- 사용자 평가(최우선): "개판이네. 다 붕붕 뜨고 안 맞고 듬성듬성, 색도 이상하게 구리다." 이 평가를 아래 F1~F4로 나눠 px로 쟀다.
- **기준값(2026-11-05 정정)**: 현재 HUD 수치의 정본은 Codex H2 측정표 `current_measure.md`(`codex/unity-hud-measure-20261105` @ `b95b8ead0`, 코드 기준 px·색 전수)다. 이 표가 그 표와 다르면 측정표를 따른다. 아래 값은 그 표의 8절 차이 목록을 반영해 고쳤다.
- 측정 방법: `NativeHudDockLayout.cs`·`NativeHud.cs` 식을 1920×1080 설계 좌표(ArtScale .9)로 계산했다. 텍스처 3장은 node+Playwright로 알파·명도를 실측했다. 같은 식으로 만든 재현본이 `current.html`이다. 실게임 캡처는 이 클라우드 세션에 없다. 재현본과 실기 화면이 같은지는 Mac 캡처로 확인해야 한다(G0_BRIEF "첫 실물 판정").
- 비교판: `compare.html`(같은 영역·같은 배율로 현재·A·B 세 장), `compare.html?x3`(슬롯 3배), `?guides`(레일·구체 중심·슬롯 중심 측정선).
