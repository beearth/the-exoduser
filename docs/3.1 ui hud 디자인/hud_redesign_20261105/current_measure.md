## 1. 표기와 기준 해상도

아래 C# 파일명은 모두 `unity/Assets/Exoduser/Runtime/` 아래다. `HudOrb.shader`는 `unity/Assets/Exoduser/Resources/Shaders/HudOrb.shader`, JSON은 `unity/Assets/Exoduser/Resources/Data/` 아래다. `U1 current.html`, `U1 defects.md`는 위 U1 SHA의 파일이며 본선 파일을 뜻하지 않는다.

- **확정(코드)**: 상수·Rect·폰트 설정 또는 해당 식을 계산한 값. 실화면 픽셀 경계까지 확인했다는 뜻은 아니다.
- **추정**: 코드에 저장된 텍스처 알파 경계, 정사각 아이콘 가정 등. 실제 PNG/GPU 알파를 이번 작업에서 재측정하지 않았다.
- **미확인**: 폰트 CalcSize/번역/세이브/카메라/애니메이션/이미지 내용이 필요해 정적 코드만으로 고정할 수 없는 값.

## 9. 인계·확인 범위

- Node로 소스 상수/SlotLeft를 읽어 Rect·피치·빈 간격·하단 여백을 계산했다. 예: `frameY=1080−10+44×.9−263×.9=872.9`, `barY=1080−10+25−182×.9=931.2`, `slotY=931.2+70×.9=994.2` (`NativeHudDockLayout.cs:26`·`:33`·`:39`).
- 파일:줄은 위 스냅샷에서 확인했다. U1은 git show로 읽기만 했다. 이 문서 외 코드·시안·에셋 변경0. 별도 검사 러너·Unity·브라우저 실행0.
- H1의 기본 수치는 §2~§6을 사용한다. 원화 Rect/알파 모델/액체 원/아이콘 박스/실제 원형 잉크 지름을 같은 항목으로 합치지 않는다.
- 남은 확인: Mac 실제 1920×1080·3840×1080·다른 높이에서 글리프폭·폰트 fallback·키 squeeze·아이콘 알파 경계·최종 합성 RGB·필터링·화면 clipping·동시 조건부 HUD 겹침. 해당 값은 이 표에서 추정 또는 미확인으로 유지한다.
