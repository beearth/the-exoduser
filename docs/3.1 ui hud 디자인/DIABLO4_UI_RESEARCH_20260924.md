## 공식 설명에서 확인한 원칙

- 시스템과 조작 흐름에 맞춰 UI를 반복 수정하고 시각적 마감을 뒤에 진행한다.
- 인벤토리 배경의 밝기·채도를 줄이고 희귀도에 테두리 장식 단서를 추가했다. 작은 아이콘에서는 형태와 자연스러운 재질이 읽혀야 한다.
- 입력 전환이 혼란스럽지 않도록 격자 기반 구조를 쓰면서 마우스와 패드에 각각 적합한 조작 경로를 제공한다.
- 텍스트 크기 선택, 입력 재설정, 강조 표시와 오디오 신호를 제공한다.

## 다음 구현 순서 제안

1. 설정 화면의 범주, 정보 열, 스크롤 경계를 설계한다.
2. 한 화면에서 제목/본문/컨트롤/행동 버튼의 위계를 완성한다.
3. 검은 철·석재 재질과 악마 장식의 연결 및 실제 표시 크기를 다듬는다.
4. 공통 규칙을 장비·스킬·성장에 적용하되 각 화면의 내부 구성은 별도로 설계한다.

사용자가 조사를 우선 요청했으므로 이 문서 작성 시점에서는 추가 구현을 진행하지 않는다.
