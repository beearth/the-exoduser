# EXODUSER UI/UX 개선 프로젝트

> 상태: 진행 중 · 시작: 2026-09-30 · 관리 책임: Codex UI/UX 리드
>
> 이 문서는 UI 개선의 작업대장이다. 실제 규격과 수치는 각 시스템의 기존 SSOT 문서와 코드가 우선한다. 구현·검수 결과가 바뀔 때마다 이 문서의 상태와 근거를 갱신한다.

## 목표

전투 중 필요한 정보를 빠르게 읽고, 메뉴에서는 원하는 항목을 적은 조작으로 찾고 변경하게 한다. 프레임·재질·타이포그래피를 게임의 어두운 금속 미술 방향과 일치시키며 키보드·마우스·게임패드·작은 화면에서 정보와 조작이 잘리지 않게 한다. AAA급 완성도를 목표로 하되 실화면 검수와 동작 증거가 없는 화면을 완료로 표시하지 않는다.

## 관리 원칙

1. 각 패스 시작에 Git 상태와 화면의 현재 모습을 확인한다. 다른 작업의 변경은 보존한다.
2. 사용자 지시, `AGENTS.md`, 각 시스템 SSOT를 먼저 읽고 UI 문제를 **보이는 현상 → 원인 → 수정 → 실제 화면 재검수** 순서로 기록한다.
3. 한 번에 한 흐름을 완성한다. 정보 위계·입력 피드백·스크롤·반응형·접근성·성능 영향을 함께 검토한다.
4. 코드 변경 뒤 `docs/` 전체 관련 키워드를 검색해 동기화하고 코드와 문서를 함께 커밋한다. 본편 `game.html`과 쉬운판 `game-easy-test.html`의 공통 UI는 둘 다 확인한다.
5. 검수 단계는 소스 검사, 자동 테스트, 로컬 실화면, 패키지, 배포를 분리해 기록한다. FPS 또는 입력 지연은 직접 측정하지 않았다면 판정하지 않는다.

## 완료 패스: UI-01

| 항목 | 기준선 / 설계 결정 |
|---|---|
| 기준선 | 게임 탭 내부 순서는 시스템 → 게임 설정. 기존 4개 설정 탭과 옵션 ID·리스너 유지. 1324×982에서 첫 화면은 시스템 액션까지만 보이며 본문 스크롤이 약 400px 남는다. |
| 수정 방향 | 설정 재진입 때 현재 탭 내용의 시작으로 돌아간다. 게임 탭 상단에 시스템·게임 설정 구역 이동을 제공하고 섹션 제목에 초점을 연결한다. |
| 보호 항목 | 프리셋 저장/불러오기, 캐릭터 선택, 리셋·종료, 옵션값과 저장 포맷을 바꾸지 않는다. 사용자 세이브를 쓰는 버튼은 검수 중 실행하지 않는다. |
| 판정 | 본편에서 재진입 시 현재 탭을 유지하며 본문 스크롤 0으로 복귀했다. 본편 390×844에서 두 이동 버튼이 해당 제목에 초점을 주고 고정 이동 바 아래로 맞췄으며 가로 넘침이 없었다. 쉬운판에서도 게임 설정 이동과 가로 넘침 없음을 확인했다. 본편에서 게임 설정 버튼의 Enter 활성화·제목 초점 이동을 확인했다. 새 버튼의 언어 전환 후 문구는 다음 검수에서 확인한다. |

## 완료 패스: UI-02

화면·사운드·조작 탭에서 긴 설정의 탐색과 초점 흐름을 실제 화면으로 확인한다. 위험 동작은 설정 게임 탭의 액션 카드까지 포함해 정보 위계와 조작 피드백을 다시 본다. 검수 후 발견한 문제만 수정하고 각 화면 크기와 입력 방식의 증거를 여기에 기록한다.

| 항목 | 이번 패스의 담당 범위와 판정 기준 |
|---|---|
| 소유 파일·함수 | `ui-panels.js`의 `settings` 섹션 이동 순서, `ui-refinement.css`의 `#settings-page-controls .bind-reset`, 두 HTML의 설정 입력 초점 예외와 공통 캐시 연결. 타 팀이 편집 중인 두 HTML의 게임·맵 코드와 옵션값은 보존했다. |
| 정적 기준선 | 상위 탭 4개는 화살표·Home·End로 이동하고 선택 탭만 `tabIndex=0`; 페이지 전환은 본문 스크롤을 0으로 돌린다. 조작 모드 버튼은 `renderSettings` 재구성 뒤 `data-bind-control`로 초점을 복원한다. 사운드 슬라이더·선택 목록은 기존 ID와 자동 저장을 유지한다. |
| 실화면 게이트 | 본편 1754×1262·1324×982·390×844와 쉬운판 1754×1262·390×844에서 화면·사운드·조작의 가로 넘침 0px과 본문 스크롤·닫기 노출을 확인했다. Tab·Home·End와 조작 모드 전환 초점, 두 초기화 버튼 경고색도 확인했다. 하드웨어 재진단·키 초기화·볼륨 변경·저장·리셋은 실행하지 않았다. |
| 부하 조율 | QA팀 프레임 측정 중에는 새 게임 탭을 열지 않고 소스·문서 조사만 진행한다. 측정 종료 확인 뒤 가벼운 UI 실화면 검수만 한다. 실제 성능 수치는 QA팀 증거와 별도로 둔다. |
