## 3. 레이아웃 (3분할)

화면을 좌 50% / 중 28% / 우 22% 비율로 분할.

### 좌측 50% - 캐릭터 디스플레이

- 선택된 캐릭터 풀바디 또는 흉상 (게임 내 idle 스프라이트 재활용)
- idle 애니메이션 루프 노출
- 캐릭터 뒤에 그라데이션 배경 + 미세한 안개/먼지 파티클
- 무기/장착 이펙트 그대로 노출
- 좌측 하단에 미세한 viginette

### 중앙 28% - 정보 패널

- 캐릭터 이름 (대형 타이틀, 로고 폰트와 통일)
- Lv. + (있다면) 클래스 태그
- 진행도: 예) 1장 썩은 숲 4층
- 플레이타임: hh:mm
- 누적 처치수
- 누적 사망 횟수
- 보유 골드/주요 재료 요약 (3개까지)
- 마지막 플레이: yyyy-mm-dd hh:mm

### 우측 22% - 슬롯 리스트

- 슬롯 카드 세로 정렬 (스크롤 가능)
- 활성 슬롯: 보더 글로우 + opacity 1.0
- 비활성 슬롯: opacity 0.6
- 호버시 scale 1.02, 200ms ease
- 삭제는 호버시에만 우측 끝 X 아이콘 노출

### 상하단

- 좌상단: HELL 로고 작게
- 우상단: LOCAL/ONLINE 모드 토글 + 언어 선택 (커스텀 셀렉트로 교체)
- 우하단: 빌드 버전 (v0.x.x)
- 좌하단: 종료 버튼
- 중앙 하단: 입장 버튼 (대형, 글로우)

## 11. 구현 동기화 — 슈퍼와이드 외형 선택 영상 (2026-08-08)

`index.html`의 풀스크린 외형 선택 팝업(`charVisualPop`)은 캐릭터가 포함된 16:9 아이들 영상 두 종을 기본 `object-fit: cover`로 표시한다. 3440×1440(약 21:9)에서는 중앙 정렬 시 영상 상단이 약 247px 잘려 머리가 화면 밖으로 나가고 전신도 과도하게 확대된다. 슈퍼와이드에서는 원본 프레임을 기준으로 상단 기준 15% 확대와 가로 10% 확장을 적용하며, 남는 좌우 영역에는 금속 프레임 질감을 제한적으로 겹친다.

2026-09-13 전사 영상은 Higgsfield Seedance 2.5 생성 원본을 Topaz로 3840×2160 복원한 `idle_warrior_higgsfield_4k.mp4`(133프레임, 24fps, 파일 길이 약 5.542초)와 전용 포스터를 사용한다. `idleRate:0.75`를 선택 화면/로비의 `defaultPlaybackRate` 및 `playbackRate`에 적용하여 실제 반복 주기는 약 7.389초다. 실버테일 등 `idleRate` 없는 캐릭터는 1배속으로 복원한다. 자세한 제작 수치와 적용 계약은 [남전사 로비 아이들 모션](남전사_로비_아이들_모션_20260908.md)을 따른다.

## 12. 구현 동기화 — 로비 선택 캐릭터 타이틀 (2026-08-08)

로비 좌측 하단의 안내 문구는 캐릭터 초상화 슬롯을 선택했을 때 선택 캐릭터의 이름과 직업을 표시한다. 캐릭터 이미지를 새로 띄우지 않고 기존 로비 배경 위의 텍스트 정보만 갱신한다.

| 상태 | 주 타이틀 | 보조 타이틀 | 데이터 원본 | 적용 위치 |
|---|---|---|---|---|
