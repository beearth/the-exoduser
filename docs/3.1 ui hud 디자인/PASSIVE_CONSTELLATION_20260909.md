# 인체 별자리 패시브 — 2026-09-09 재작업

## 사용자 수정 요구와 범위

이전 금서 시안의31개 노드/35개 선과 인체 비율은 사용자에게 반려됐다. 이전 문서의 육안 PASS는 승인 근거가 아니다. 사용자는 PoE2처럼100개 이상의 작은 노드가 군집과 가지를 이루는 규모를 요구했다.

현행은 **26개 패시브 군집,260개 패시브 투자 단계,5개 능력치 투자 중심,295개 연결선**이다. 26개 중심 인장은 군집 탐색용으로 별도 존재한다.265개 투자 대상과26개 탐색 인장으로 총291개 선택 컨트롤이다.260종의 서로 다른 신규 효과를 추가했다는 뜻은 아니다. 기존26종의 각10단계를 실제 투자 대상으로 펼쳤다.

## 그래프와 실제 거래

| 항목 | 계약 |
|---|---|
| 모델 | `constellationLayout(defs)`는 실제정의의max만큼 노드를 생성. ID는 `key@rank`, rank는1부터max까지 |
| 패시브 단계 | 각 단계는기존 `passiveEffects(key,rank−1) → passiveEffects(key,rank)`의 실제효과. `rankCost(rank−1)`만큼 AP비용 |

| 필터 | 전체는일치하는군집의전단계,습득은계획상습득단계만,변경중은live와계획이달라지는단계만표시. 군집중심은탐색용으로함께유지 |
| 숫자 | growthCount는필터결과의투자노드수/전체투자노드수. 경로버튼은계획상습득단계수+투자한능력치중심수/경로전체노드수. 숫자LTR isolate |
