# 능력치·패시브 — 성장의 각인 / 인체형 전투의 길

2026-09-09 현행 `game.html#statPanel` 계약. J 창은 **5능력치와26패시브를 함께 배치한 인체형 연결 화면**이다. 상단의 별도 능력치 배분판과 패시브 카드 목록은 트리 노드로 전환했다. 배꼽 공통 기점에서 머리·양팔·몸통·양다리로 연결하며 오른쪽 상세에서 계획 → 비교 → 일괄 적용한다.

이번 범위는 기존 투자 UI의 통합이다. 연결선은 선택 노드의 탐색 경로이며 구매 선행 조건이 아니다. 새 효과·추가 비용·강제 환불·세이브 마이그레이션은 없고 기존 장비·결정·스탯·패시브 기여와 저장 형식을 보존한다. 신규 소형/주요/핵심 특성의 전투 설계는 [개편 방향](PASSIVE_TREE_REDESIGN_20260909.md)의 후속 범위다.
