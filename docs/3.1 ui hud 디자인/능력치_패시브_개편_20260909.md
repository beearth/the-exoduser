# 능력치·패시브 리마스터 — 2026-09-09

`game.html#statPanel`의 현행 계약. 기존 즉시 투자·공격/보조 분류·설명 반복 화면을 아래의 **계획 → 비교 → 일괄 적용** 구조로 교체한다. 게임 내 J로 연다.

## 설계 근거와 범위

- [Diablo IV 2026 공식 스킬 개편](https://news.blizzard.com/en-gb/article/24267729/prepare-for-the-reckoning-lord-of-hatred-draws-near)은 빌드를 결정하는 선택의 배치와 스킬 분화를 재구성했다. 이 프로젝트에서는 패시브를 전투 성향별로 탐색하고 효과·조건을 명시하는 방향에 참고했다.
- [Last Epoch Shattered Omens 공식 패치](https://forum.lastepoch.com/t/last-epoch-shattered-omens-patch-notes/80571)의 상세 능력치와 스킬 툴팁 개선을 읽기 쉬운 수치 비교 설계에 참고했다.
- 두 사례에서 특정 화면·수치·노드 구조를 복제하지 않았다. 6개 경로, 미적용 계획, 기여 비교표는 EXODUSER의 기존26개 패시브·5개 능력치에 맞춘 프로젝트 설계다. 선행 노드나 직업 제한은 추가하지 않는다.

이번 구현은 성장 화면·거래 방식·전체 효과 표시의 리마스터와 정합성 수정이다. 신규 패시브 추가나 전체 전투 배율 재밸런싱은 포함하지 않는다. 캐릭터 저장 형식·포인트 보유량을 유지한다.

## 정보 구조

| 영역/ID | 현행 동작 |
|---|---|
| 헤더 | ‘당신의 전투를 설계하라’. `spRemain/apRemain`은 계획 적용 후 남을 SP/AP |
| 능력치 | STR/DEX/INT/LCK/GRIT. 직접 투자값·±1/±10·계획 변경량. 이름 버튼은 능력치 상세 비교표를 연다 |
| 능력치 비교 | `statEffects`: 직접 투자분의 기본 기여. 현재→계획, 변경 없으면 현재→선택 단위만큼 추가. 재생은 초당값. 장비·레벨·패시브 배율이 포함된 최종값은 별도 전투 능력치 창 |
| 자원 | 현재 실제 적용된 HP/ST/MP 최대치, ‘현재 적용된 자원’으로 표시. 계획 수치로 가장하지 않음 |
| 경로 | `growthPaths`: 전체 + 6개 경로. 선택은 필터이며 서로 자유롭게 조합 가능 |
| 목록 | 전체/습득/변경 중 필터, 한국어/영문 이름·효과·ID 검색. 카드에 경로, 첫 효과의 해당레벨 기여, 레벨/비용, 투자 진행선. 계획 변경 카드는 마름모와 현재→계획 레벨 표시 |
| 패시브 상세 | 이름/경로/레벨/진행선, `passiveEffects` 숫자 비교표. 변경이 없으면 현재→다음, 변경이 있으면 실제 현재→계획. 조건·상한·인간성/악마성 상쇄 안내 |
| 계획 거래 | `growthUpgrade/growthRefund`는 계획만 변경. 실제 능력치·잔고·저장 횟수에 영향 없음 |
| 적용 | `growthApply`는 전체 변경을 live 재검증 후 원자적으로 적용. 한번의 applyStats/SFX/dbSaveNow 호출 |
| 취소/닫기 | `growthCancel`은 실제 상태로 계획 복원. J/ESC/닫기/다른 패널 이동으로 창을 닫으면 미적용 계획 폐기. MutationObserver는 statPanel의 class 변경만 관찰 |
| 전체 환불 | `statResetBtn`은 전부0인 계획을 만든다. 적용 전에는 실제 투자/자원이 유지되며 취소 가능 |
| 전투 능력치 | 기존 요약 서랍 유지. ESC/Back은 열린 요약부터 닫는다 |
| 입력 | 검색 입력은 게임 단축키로 전파하지 않음. 버튼 Enter/Space와 Tab은 네이티브 동작. 기존 게임패드 버튼 탐색 유지 |
| DOM | 지정 동적 영역은 replaceChildren, textContent는 생성한 리프/지정 리프만. SVG innerHTML은 신규 detached 리프에 신뢰된 내장 glyph만 |

## 디자인·반응형

검은 금속 바탕, 구리색 투자 표시, 절제한 경로 색상, 명조 제목과 고딕 본문을 사용한다. 배경#10100f, 경계#36302c, 본문#eee8dd, 보조#aaa398. 선택은 외곽선·좌측 선·aria-pressed로도 구분한다.

| 조건 | 구현 |
|---|---|
| 기본 | 최대1760×1020px, 96vw×95vh, padding28px. 3열 최소260/410/310px·비율.95/1.55/1.1 |
| width≤1350 또는 height≤820 | padding20px, 열 최소230/350/260·비율.95/1.5/1.05. 상세 아이콘48px·제목24px, 내부 스크롤 |
| width≤1050 | padding14px, 열 최소190/290/230·비율.85/1.35/1.05. 경로3열, 전체 버튼 한 줄 |
| width≤780 | 세로 섹션, 능력치/패시브2열, 패시브 목록 최대470px. 하단 적용/취소 sticky, 화면 전체 세로 스크롤 |
| 키보드/모션 | focus-visible2px, 버튼 전환.15초, reduced-motion이면 전환 제거. 펫 자막은 패널 열림 동안 숨김 |

세부 스타일 선언은 `stat-panel-ui.css`에 있다. 1920×1080/1280×720/960×720/600×900 확인. 좁은 화면에서 목록과 상세는 스크롤한다.
