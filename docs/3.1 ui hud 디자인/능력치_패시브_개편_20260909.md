# 능력치·패시브 UI — 2026-09-09

`game.html#statPanel`의 현행 UI 계약이다. 기존 phase2 문서의 스탯 패널에 관한 프레임 이미지·행 전체 구매·보라색 패시브·인라인 2열 배치보다 이 문서가 우선한다. 전투 스킬 K창은 별개다.

## 목적과 조사

사용자 스크린샷의 긴 설명 반복, 낮은 대비, 행 클릭 즉시 AP 소모, 펫 대사의 투자 영역 가림을 해결한다. 능력치 효과와 패시브 전투 공식을 유지하고 탐색·투자·환불을 개편한다.

- [Last Epoch Shattered Omens 공식 패치 노트](https://forum.lastepoch.com/t/last-epoch-shattered-omens-patch-notes/80571): 값 없는 상세 능력치를 숨기는 옵션과 UI 개선 사례. 이번 화면에서는 상세 수치를 별도 요약창으로 분리하는 근거로 참고했다.
- [Last Epoch UI Scale 공식 도움말](https://support.lastepoch.com/hc/en-us/articles/46363237395227-How-do-I-change-my-UI-Scale): 화면 크기별 가독성 중요성을 참고했다.
- [Path of Exile 2 공식 패시브 트리](https://pathofexile2.com/game/passive-skill-tree): 패시브 탐색과 배분 상태를 구분하는 사례. 본 게임은 선행 노드 없는 26개 패시브이므로 트리 구조는 도입하지 않았다.

3열 구조, 카드 필터, 금색 선택 테두리는 위 자료를 참고한 본 프로젝트의 디자인 결정이다. 타 게임의 수치·성장 구조를 이식하지 않는다.

## 정보 구조·조작

| 영역 / ID | 현행 표시·동작 |
|---|---|

| 왼쪽 `statLeft` | 힘 STR, 민첩 DEX, 지능 INT, 행운 LCK, 근성 GRIT 순. 표시 값은 직접 투자분이며 레벨·장비 합계는 전투 능력치 창에서 확인 |

| 자원 `growthMetrics` | 현재 `P.mhp`, `P.mst`, `P.mmp` 최대치. 투자·환불 후 `applyStats()`로 갱신 |

| 카드 `growth-passive` | 아이콘, 이름, 효과 2줄 발췌, 현재/최대 레벨, 다음 AP 비용. 클릭은 선택만 수행, AP 차감 없음. AP가 없어도 탐색 가능 |

| 환불 `growthRefund` | 선택 패시브 1레벨 환불, 해당 레벨을 올릴 때의 AP 비용 반환. Lv0 비활성 |

## 수치·거래 계약

| 항목 | 값 / 공식 | 구현 위치 |
|---|---|---|
| 기본 투자 상한 | STR/DEX/INT/LCK 각 500 | `STAT_MAX`, `statChange` |
| SP 거래 | `value'=value+amount`, `SP'=SP-amount`; amount는 정수 ±1 / ±10 | `stat-panel-ui.js` |
| 근성 상한·비용 | 상한 없음, 1 SP/포인트 | `max=Infinity`, `_grit` |
| 근성 효과 표시 | HP/MP/ST 최대치 각각 +1, 물리·속성 방어 +0.5/포인트. 실제 방어 증가분은 `~~(_gritTotal()*.5)` | 기존 `applyStats` / 피격 속성방어 계산 유지 |
| 패시브 최대 | `PASSIVE_DEF.max` 사용, 일반 정의 10. 테스트베드가 20으로 변경한 경우 20까지 표시 | `passiveChange` |
| AP 단계 비용 | Lv1~3:1, Lv4~6:2, Lv7~9:3, Lv10:5. Lv10 이후 런타임 확장 레벨도 기존 폴백 5 | `COSTS=[1,1,1,2,2,2,3,3,3,5]`, `rankCost` |
| AP 환불 | Lv n → n−1: `rankCost(n−1)` 반환 | `passiveChange` |
| 전체 SP 환불 | `sum(Object.values(STATS)) + _grit` | `refundTotals` |
| 전체 AP 환불 | 패시브마다 `sum(rankCost(i), i=0..level−1)`를 합산. Lv10 하나=23 AP, Lv4 하나=5 AP | `refundTotals` |
| 거래 완료 | live 상태 재검증 → 값 변경 → applyStats → SFX → renderStatPanel → dbSaveNow | `game.html` 어댑터 |

기존 초기화는 레벨 합만 AP로 반환하고 근성을 누락했다. 이번 초기화는 실제 지출량을 반환하며 확인창 완료 시점의 최신 투자 상태를 다시 읽는다. 개별 패시브 변경에도 `applyStats()`를 호출해 자원 최대치를 즉시 반영한다.

공격 키: `pAtk,pCharge,pParry,pMagic,pBow,pCrit,pPierce,pMelee,pCombo,pAbund,pPred,pDot,pXbow,pHunter,pRage`. 나머지 `PASSIVE_DEF`는 보조. 삭제된 `pPhysPen,pMagPen`은 분류 목록에서 제거했다.

새 UI 한국어/영어는 명시한 쌍을 사용한다. 영어는 정확한 EN 문구를 우선하며, 기타 언어는 기존 `_L`/`_T` 번역이 있으면 사용하고 없는 새 키는 영어로 폴백한다. 기존 능력치·패시브 이름/효과 번역은 계속 사용한다. 신규 문구의 추가 언어 번역은 후속 대상이다.

검증 산출물: `captures/stat_panel_20260909/` (1920×1080 KO, 1280×720 KO/EN, 960×720 KO, 600×900 KO). 보이는 카드 발췌와 상세 전문을 분리했고, 좁은 화면의 내부 목록은 스크롤한다. 실제 배포 빌드 실행은 이번 UI 검증 범위에 포함하지 않는다.

기존 `PASSIVE_DEF` 설명과 전투 공식의 일치 여부를 전면 재밸런싱하지 않았다. 예컨대 pCrit의 설명 2%와 런타임1.5%는 기존 별도 정합성 검토 대상이며, 이번 UI는 원본 설명을 표시한다.
