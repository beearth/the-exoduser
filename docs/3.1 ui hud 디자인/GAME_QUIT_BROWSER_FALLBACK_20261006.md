# 2026-10-06 인게임 종료 버튼의 브라우저 폴백

| 항목 | 현행 계약 |
|---|---|
| 적용 위치 | `game.html`, `game-easy-test.html`의 `#quitBtn` 클릭 핸들러 |
| 원인 | 일반 브라우저가 `window.close()`를 차단하면 기존 핸들러에 후속 처리가 없어 버튼이 무반응으로 보였다. |
| NW.js | 기존 `window.nw.App.quit()` 유지 |
| Electron | 기존 `window.electronAPI.quitApp()` 유지 |
| 일반 브라우저 | `window.close()` 시도 후 페이지가 남아 있으면 150ms 뒤 기존 `goToLobby()` 호출 |
| 저장·이동 | 기존 `goToLobby()`의 사망 상태 복구 및 `_dbReady`일 때 `dbSave()` 대기 후 이동을 재사용. 데모는 `/?lobby=1&demo=1`, 일반은 `/?lobby=1`. 저장 오류 처리도 기존 계약 유지. |
| 제외 범위 | 로비 전원 아이콘의 확인창·직접 탭 닫기 안내, 저장 형식, 세이브 삭제, 데스크톱 종료 방식은 변경하지 않는다. |
| 회귀 검수 | `test/gameQuit.test.js`: 두 HTML의 실제 핸들러를 추출해 브라우저 차단 시 로비 호출, NW.js/Electron 전용 종료 경로를 검증한다. 브라우저 케이스 수정 전 실패 확인. |
| 증거 경계 | 테스트 통과는 패키지 실행·사용자 세이브 저장 성공을 증명하지 않는다. |

설정 시스템 구역의 버튼 배치는 `SETTINGS_HUD_DETAIL_20260930.md`를 유지한다. 본 문서는 인게임 종료 핸들러의 브라우저 폴백만 갱신한다. 진행 중인 시작 맵 선행 로딩·숲 캐시 작업과 별개다.
