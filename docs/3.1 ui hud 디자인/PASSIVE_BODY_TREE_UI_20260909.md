# 인체형 패시브 UI 구현표 — 2026-09-09

상태: 기존5능력치+26패시브 군집의 실제 투자/환불 UI 구현. 각패시브10단계를작은별로펼쳐260단계+5능력치=265투자대상이며26군집중심은별도탐색인장이다. 새 효과나 선행 구매 제한은 추가하지 않는다. 위치는 화면 기준이며 장비·직업·선택 가능한 노드의 제한이 아니다.
