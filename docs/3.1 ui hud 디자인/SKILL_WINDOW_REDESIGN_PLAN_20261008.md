### 4-3. 메인 뷰 모드

**① 서고 (기본 목록)**
- 카드 112×156 (현 86×132). 원화 96×96, 이름, ★, Lv, ±버튼.
- 카드 아래쪽 띠에 **소속 합체 보석 점**(`_FUSE_GEM_GROUPS.color/color2` 2색 쌍). 마우스를 올리면 같은 합체의 파트너 카드만 금빛 테두리, 나머지는 45% 흐림 (PoE 검색 글로우식). 연결선은 선택/호버 때만 (`#skillFuseLines` 재사용).

**② 합체 설계도 (이번 리디자인의 핵심)** — MHW식 가로 체인 레인 + VS식 수식

- 결과 노드를 클릭하면 **역검색**: 필요한 모든 재료·선행 노드가 점등 (Persona식). 상세 감정판이 해당 합체로 바뀐다.
- 정렬 기본값: 지금 가능 → 하나만 더 → 진행 중 → 완성 → 미착수.

### 4-4. 합체 상태 문법 (색 + 모양 + 문구, 3중 표기)

| 상태 | 판정 (기존 함수) | 노드 표시 | 문구 |
|---|---|---|---|
| 완성 | `P._fused[key]` | 뼈색 실선 프레임, 결과 원화 풀컬러, 각인 체크 장식 | 완성 |
| **지금 합체 가능** | `_canFuse(key)` && SP ≥ 성급×3 | 보석 2색 테두리 + **지옥불 맥동**(2s, reduced-motion 시 정지), 필터 카운트 포함 | 합체 가능 · SP n |
| **하나만 더** | 재료 중 미습득 1개 | 금빛 점선 테두리, 빠진 재료 칸만 붉게 비어 있음 | 재료 1 부족: 이름 |

### 4-5. 합체 확인 창 (흡수 경고)

### 9-1. 제목판 유지에 따른 세로 예산 보정

제목판(약 170px)을 남기므로 4-1의 "본문 ≈ 810px"은 무효. 보정안:

| 구간 | 기존 안 | 보정 |
|---|---|---|
| 메뉴 탭 | 56 | 56 |
| 제목판 | 0 (제거) | **170** (현행 크기. 필요 시 P1에서 150까지 축소 검토 — 유지 결정 범위 안에서) |
| 헤더 + 필터칩 | 64 + 36 | **헤더 한 줄 56px로 합침** (자원 · 모드 3개 · 필터칩 · 검색을 한 행에) |
| 하단 슬롯·버튼 | 88 | **76** (슬롯 52×60) |
| **본문** | 810 | **≈ 700px (65%)** — 현행 627px 대비 +70px 이상 |

- 현행 제목판 아래 4대분류 탭 줄(약 45px)은 왼쪽 분류 레일로 옮기므로 사라진다 → 이 공간이 본문으로 간다.
- 설계도 모드 기본이므로 레인 높이 기준: 레인 1줄 92px(노드 72 + 여백) → 본문 700px에 체인 레인 약 6~7개가 스크롤 없이 보인다.
