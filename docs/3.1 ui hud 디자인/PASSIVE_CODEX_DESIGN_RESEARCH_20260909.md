## 3. 시안 방향

‘금서의 인체도’:캐릭터 성장을 오래된 의식서의 도해처럼 읽는다.인체는 지도,노드는 인장,오른쪽은 선택한 인장의 해설과 변경 장부다.앱식 카드 모음이나 장식만 있는 그림으로 대체하지 않는다.

| 영역 | 계획 |
|---|---|
| 상단 |제목과 실제 자원·계획 잔고.중복 설명을 줄인 낮은 헤더 |
| 왼쪽 |전투의 길,검색,6계열+전체,습득/변경중 필터.계열별 습득수/전체수 |
| 중앙 |배꼽 시작 인체도,기존 위치·부위 역할,필터 중에도 옅은 노드 자리 유지,선택/미리보기 경로 구분 |
| 오른쪽 |선택 이름·레벨·현재/다음 수치,조건 안내,변경 계획 목록,추가/환불 |
| 하단 |전체환불·취소·실제 적용·닫기.기존 원자 거래와닫기취소 유지 |
| 작은 화면 |탐색 줄/인체도/상세 세로 배치.확대·드래그·방향키 지원 유지 |
