# 스킬 카드 이미지와 박스 정렬 (2026-09-28)

| 항목 | 현행 규격 |
|---|---|
| 적용 위치 | `game.html`의 `_renderSkillRow()` 축약 카드. 추천 합체 경로와 공격·방어·특수 목록이 같은 렌더러를 사용한다. |
| 카드 | 너비 86px, 높이 132px, 축약 모드 내부 여백 상하 6/5px·좌우 4px. |
| 이미지 | 기존 48×48px 고정 표시를 74×74px로 확대하고 `object-fit:contain`, `image-rendering:pixelated`를 적용한다. 원본 비율을 유지하며 카드 안쪽 폭에 맞춘다. |
| 이미지 없는 스킬 | 이모지 폴백 영역도 74×74px, 글자 2.5rem으로 맞춰 카드별 그림 면적을 통일한다. |
| 보존 | 이름·성급·레벨·± 조작 버튼, 스킬 데이터와 저장 형식은 변경하지 않는다. 펼친 상세 헤더 아이콘 48×48px은 별도 표시 규격으로 유지한다. |
