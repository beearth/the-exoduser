## FDG AAA 스튜디오 인트로 (fdg_intro.html)

`fdg_intro.html`은 사용자가 제공한 원본 아트보드(`img/fdg_intro/fdg_reference.png`) 한 장을 변경 없이 영상 소스로 재생하는 3.0초 독립 인트로 프리뷰다. 게임 시작 전 실제 스플래시 단계는 `video/fdg_intro.mp4`를 사용한다.

| 구간 | 레이어 상태 | 연출 규칙 |
|---|---|---|
| 0.0~0.5s | `fade` | 완전한 블랙, 입력 없음 |
| 0.5~1.0s | `smoke-vignette`, WebGL embers | 하단 양 코너에서 연기와 느린 ember가 나타남 |
| 1.0~3.0s | `art` | 원본 PNG 전체에만 느린 카메라 푸시 인, 별도 로고 재구성 없음 |
| 1.6~2.2s | `fx` | 원본 위에 아주 작은 ember 파티클만 상승 |
| 2.2~2.8s | `smoke` | 원본 하단 양 코너에만 약한 연기 오버레이 |
| 2.8~3.0s | `fade` | 원본과 오버레이를 함께 안정화한 뒤 블랙 페이드 |

## API 영상 생성 파이프라인

`tools/generate_fdg_video.cjs`는 원본 레퍼런스를 OpenAI Videos API의 `input_reference`로 전송해 실제 MP4를 생성한다. API 입력 규격에 맞추기 위해 원본의 종횡비를 유지한 채 1280×720 검은 여백 프레임을 임시 생성하며, 아트워크 픽셀은 변경하지 않는다.

| 단계 | 입력/출력 | 규칙 |
|---|---|---|
| 1 | `img/fdg_intro/fdg_reference.png` | 사용자가 제공한 원본 PNG |
| 2 | `output/fdg_reference_1280x720.png` | 원본 비율 유지 + 검은 레터박스만 추가 |
| 3 | `POST /v1/videos` | `sora-2-pro`, `input_reference`, 1280×720, 8초 |
| 4 | `output/fdg_sora_raw.mp4` | 비동기 작업 완료 후 다운로드 |
| 5 | `output/fdg_studio_intro_3s.mp4` | 오디오 제거, H.264, 정확히 3초로 컷 |

실행 전 `OPENAI_API_KEY`가 필요하다. Sora 생성 API는 비동기 작업이며, 생성 완료 후 MP4 콘텐츠를 별도 다운로드한다.

기존 Sora 작업을 보정할 때는 `FDG_VIDEO_EDIT_SOURCE=<video_id>`와 `FDG_VIDEO_EDIT_PROMPT`를 사용해 `POST /v1/videos/edits`로 편집한다. 영상 생성 모델은 타이포그래피 형태를 완전히 보장하지 않으므로, 브랜드 로고 문자 형태가 바뀌지 않았는지 최종 프레임을 반드시 검수한다.
