# 스플래시 인트로 시퀀스 (index.html)

작성: 2026-07-27 / 최종 수정: 2026-07-27

로비 진입 전 인트로 화면 순서와 각 화면의 동작 규칙. 구현 위치: `index.html` 스플래시 시퀀스 IIFE (`splashOverlay`).

## 시퀀스 순서

| phase | 화면 | 구현 | 지속시간 | 진행 방식 |
|---|---|---|---|---|
| 0 | 경고문 (광과민성 발작) | HTML (`splashContent`) | 4초 | 4초 자동 진행, 클릭/키/패드 즉시 스킵 가능. **현재 기본 비활성** (phase=1부터 시작) |
| 1 | FDG 로고 (늑대 엠블럼 + FOR DEAR GAMERS) | HTML/CSS (`fdgScreen`) | 프롬프트 표시 + 1.2초 후 **자동 진행** | 키 입력 없어도 자동 진행. 클릭/키/패드 즉시 스킵 가능 |
| 2 | 타이틀 키아트 | 캔버스 (`splashCanvas`) | **자동 진행 없음** | 클릭/키/패드 입력 시에만 진행 (press any key 화면) |

## FDG 화면 (phase 1) 타이밍

- `FDG_DUR=5500` (참고값)
- F/D/G 글자 등장: 1200/1400/1580ms
- 양옆 확장 (OR/EAR/AMERS): 2300ms
- PRESENTS: 3200ms
- 부제 타이핑: 3800ms부터 글자당 80ms
- 프롬프트("아무 키나 눌러 계속"): `3800+(부제글자수-1)*80+400` ms
- **자동 진행**: 프롬프트 표시 시점 + 1200ms 후 `nextPhase()` (`fdgTimerId`) — 2026-07-27 추가. 이전에는 키 입력 대기 상태로 멈춰 있었음

## 타이틀 키아트 (phase 2) — 2026-07-27 신규

- 기존: 캔버스 텍스트 "EXODUSER / 지옥의 길" 4초 자동 진행 → **폐기**
- 현재: **`img/title_art_1.png` 여성 캐릭터 키아트 고정** (백발 포니테일, 검, 황야 배경)
  - `img/title_art_2.png` — 남성 캐릭터 (흑발, 쌍검, 지옥 도시 배경) — 완성도 문제로 **미사용 보류** (2026-07-27). 랜덤 2종 표시였다가 여캐 고정으로 변경. 남캐 아트 리터치 후 랜덤 복귀 검토
  - 두 이미지 모두 EXODUSER / HELL LORD 로고 + "THE WORLD WILL FALL. THE EXODUS WILL RISE." 태그라인 포함
- 렌더링: 캔버스 cover-fit (화면 꽉 채움, 넘치는 부분 크롭), 1초 페이드인
- 이미지 로드 실패 시 폴백: 기존 "EXODUSER" 텍스트 렌더
- 1.2초 후 하단(h*0.92)에 "아무 키나 눌러 계속" 깜빡임 표시 (`_TL` 번역 적용, 기존 번역 키 재사용)
- **자동 진행 없음** — 클릭/키보드/게임패드 아무 입력으로 진행 → `endSplash()` → 입력모드 화면

### 버그 수정 이력

- 2026-07-27: `nextPhase()`의 종료 조건이 `phase>=2`여서 FDG 다음에 타이틀 화면을 건너뛰고 바로 `endSplash()`가 호출되던 버그 수정 → `phase>=3`으로 변경. 이전에는 phase 2(타이틀)가 도달 불가능한 죽은 코드였음

## 스킵/진행 입력

- `overlay` 클릭, `fdgEl` 클릭, `keydown`(전역), 게임패드 아무 버튼 (`_GP.on('splash')`)
- 모든 입력은 `skip()` → `nextPhase()` 경유

## 진입 분기

- `?lobby=1` (게임 복귀): 스플래시 전체 스킵
- `localStorage._cinSeen` 있음 (재방문): phase 1 (FDG)부터
- 첫 방문: phase 1부터 (경고문 phase 0은 현재 제거됨)

## 설계 의도

- FDG 브랜딩은 보여주되 유저 입력을 강제하지 않는다 (방치해도 타이틀까지 자동 도달)
- 타이틀 키아트는 전통적 "press any key" 타이틀 화면 — 유저 입력 전까지 유지
- 키아트는 원래 남/여 주인공 병행 노출 목적으로 랜덤 2종이었으나, 남캐 아트 완성도 문제로 여캐 고정 (리터치 후 랜덤 복귀 검토)
