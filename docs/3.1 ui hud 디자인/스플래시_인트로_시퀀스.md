# 스플래시 인트로 시퀀스 (index.html)

## FDG AAA 스튜디오 인트로 (fdg_intro.html)

`fdg_intro.html`은 사용자가 제공한 원본 아트보드(`img/fdg_intro/fdg_reference.png`) 한 장을 변경 없이 영상 소스로 재생하는 3.0초 독립 인트로 프리뷰다. 게임 시작 전 실제 스플래시 단계는 `video/fdg_intro.mp4`를 사용한다.

| 구간 | 레이어 상태 | 연출 규칙 |
|---|---|---|
| 0.0~0.5s | `fade` | 완전한 블랙, 입력 없음 |
| 0.5~1.0s | `smoke-vignette`, WebGL embers | 하단 양 코너에서 연기와 느린 ember가 나타남 |
| 1.0~3.0s | `art` | 원본 PNG 전체에만 느린 카메라 푸시 인, 별도 로고 재구성 없음 |
| 1.6~2.2s | `fx` | 원본 위에 아주 작은 ember 파티클만 상승 |
| 2.2~2.8s | `smoke` | 원본 하단 양 코너에만 약한 연기 오버레이 |
| 2.8~3.0s | `fade` | 원본과 오버레이를 함께 안정화한 뒤 블랙 페이드 |

### 렌더링·해상도 규칙

| 항목 | 값 |
|---|---|
| 렌더러 | WebGL 2.0 `POINTS` 파티클 패스 + DOM/CSS 레이어 |
| 대상 프레임 | 60 FPS, `requestAnimationFrame` |
| 지원 해상도 | 1920×1080, 3840×2160 |
| 4K 백버퍼 | 뷰포트 폭 2560px 초과 시 DPR 1, 그 외 DPR 최대 2 |
| 파티클 수 | 90개, 낮은 알파의 ember만 사용 |
| 인터랙션 | `Replay` 버튼 또는 `R` 키로 재생 |
| 모션 감소 | `prefers-reduced-motion: reduce`에서 파티클 숨김 |

원본 아트워크는 생성·재디자인·분리하지 않는다. 별도 오버레이는 느린 카메라 이동, 연기, ember, 블랙 페이드뿐이며 폭발, 화면 흔들림, 플래시, 공격적인 글로우는 사용하지 않는다.

## API 영상 생성 파이프라인

`tools/generate_fdg_video.cjs`는 원본 레퍼런스를 OpenAI Videos API의 `input_reference`로 전송해 실제 MP4를 생성한다. API 입력 규격에 맞추기 위해 원본의 종횡비를 유지한 채 1280×720 검은 여백 프레임을 임시 생성하며, 아트워크 픽셀은 변경하지 않는다.

| 단계 | 입력/출력 | 규칙 |
|---|---|---|
| 1 | `img/fdg_intro/fdg_reference.png` | 사용자가 제공한 원본 PNG |
| 2 | `output/fdg_reference_1280x720.png` | 원본 비율 유지 + 검은 레터박스만 추가 |
| 3 | `POST /v1/videos` | `sora-2-pro`, `input_reference`, 1280×720, 8초 |
| 4 | `output/fdg_sora_raw.mp4` | 비동기 작업 완료 후 다운로드 |
| 5 | `output/fdg_studio_intro_3s.mp4` | 오디오 제거, H.264, 정확히 3초로 컷 |

실행 전 `OPENAI_API_KEY`가 필요하다. Sora 생성 API는 비동기 작업이며, 생성 완료 후 MP4 콘텐츠를 별도 다운로드한다.

기존 Sora 작업을 보정할 때는 `FDG_VIDEO_EDIT_SOURCE=<video_id>`와 `FDG_VIDEO_EDIT_PROMPT`를 사용해 `POST /v1/videos/edits`로 편집한다. 영상 생성 모델은 타이포그래피 형태를 완전히 보장하지 않으므로, 브랜드 로고 문자 형태가 바뀌지 않았는지 최종 프레임을 반드시 검수한다.

작성: 2026-07-27 / 최종 수정: 2026-07-27

로비 진입 전 인트로 화면 순서와 각 화면의 동작 규칙. 구현 위치: `index.html` 스플래시 시퀀스 IIFE (`splashOverlay`).

## 시퀀스 순서

| phase | 화면 | 구현 | 지속시간 | 진행 방식 |
|---|---|---|---|---|
| 0 | 경고문 (광과민성 발작) | HTML (`splashContent`) | 4초 | 4초 자동 진행, 클릭/키/패드 즉시 스킵 가능. **현재 기본 비활성** (phase=1부터 시작) |
| 1 | FDG 영상 인트로 (늑대 엠블럼 + FOR DEAR GAMERS) | MP4 (`video/fdg_intro.mp4`, `fdgScreen`) | **3.2초** | 시작 1초 암흑→밝아짐, 2.85~3.2초 암전. 후반 꽃잎·불티가 과해지는 구간은 사용하지 않는다. 키 입력·클릭·패드로 즉시 스킵 가능 |
| 2 | 타이틀 키아트 | 캔버스 (`splashCanvas`) | **자동 진행 없음** | 클릭/키/패드 입력 시에만 진행 (press any key 화면) |

## FDG 화면 (phase 1) 타이밍

- `FDG_DUR=3200`
- 영상 파일: `video/fdg_intro.mp4` (`output/fdg_sora_1080p_3_5s.mp4`에서 배포 위치로 복사)
- 배포 해상도: `1920×1080` 네이티브 Sora Pro 원본, H.264 30fps, 앞 3.2초만 사용. 720p 업스케일보다 로고·석재 디테일을 우선한다.
- 이전 파일 보관: `video/fdg_intro_720p_original.mp4`, `video/fdg_intro_4k_upscale_fallback.mp4`
- F/D/G 글자 등장: 1200/1400/1580ms
- 양옆 확장 (OR/EAR/AMERS): 2300ms
- PRESENTS: 3200ms
- 부제 타이핑: 3800ms부터 글자당 80ms
- 프롬프트("아무 키나 눌러 계속"): `3800+(부제글자수-1)*80+400` ms
- **자동 진행**: 프롬프트 표시 시점 + 1200ms 후 `nextPhase()` (`fdgTimerId`) — 2026-07-27 추가. 이전에는 키 입력 대기 상태로 멈춰 있었음

## 스킵/진행 입력

- `overlay` 클릭, `fdgEl` 클릭, `keydown`(전역), 게임패드 아무 버튼 (`_GP.on('splash')`)
- 모든 입력은 `skip()` → `nextPhase()` 경유

## 진입 분기

- `?lobby=1` (게임 복귀): 스플래시 전체 스킵
- `localStorage._cinSeen` 있음 (재방문): phase 1 (FDG)부터
- 첫 방문: phase 1부터 (경고문 phase 0은 현재 제거됨)

## 설계 의도

- FDG 브랜딩은 보여주되 유저 입력을 강제하지 않는다 (방치해도 타이틀까지 자동 도달)
- 타이틀 키아트는 전통적 "press any key" 타이틀 화면 — 유저 입력 전까지 유지
- 키아트는 원래 남/여 주인공 병행 노출 목적으로 랜덤 2종이었으나, 남캐 아트 완성도 문제로 여캐 고정 (리터치 후 랜덤 복귀 검토)
