# EXODUSER 디자인 컨셉 — 실버 헬 (Silver Hell) 2026-10-28

- 소유: 디자인총괄. 이 문서가 **게임 전체 화면 톤의 최상위 기준**이다. 창·HUD·맵 프레임·로비·첫 화면을 새로 만들거나 고칠 때 이 문서를 먼저 따른다.
- 사용자 결정(2026-10-28): "EXODUSER 로고를 메인 컨셉 이미지로 잡고 전체적인 디자인 톤을 가져간다", "전체 디자인 컨셉이 없으니 맵 프레임·설정·인벤·스킬창이 다 따로 논다".
- 메인 컨셉 이미지: `img/logo_exoduser.png`(눈알 로고 A, 1506×719, 2026-10-28). 시안 보드: `tmp/design-review/20261028_silver_ui/concept_board_1920.png`(Git 밖, 원본 HTML `E:/exoduser-wt/_out/silver-ui/concept_board.html`).
- 관계: [UI_FOUNDATION_20260924.md](UI_FOUNDATION_20260924.md)의 Hell Gothic(흑철·악마·지옥불·뼈색 문자)을 **유지하되 금속 색을 금·황동에서 은빛 강철로 바꾼다.** [UI_COMPOSITION_20260925.md](UI_COMPOSITION_20260925.md)의 배치·크기·상호작용 계약은 그대로 두고, 색·선·장식만 이 문서로 갈아 끼운다.

## 1. 한 줄 컨셉

**단조한 은빛 강철 + 사방으로 뻗은 가시 + 지옥의 눈 하나.** 금속은 무채색, 빨강은 "눈"에만 쓴다. 눈은 선택·위험·초점일 때만 뜬다.

## 2. 근거 — 로고 실측 (2026-10-28, 불투명 픽셀 127,339개)

| 항목 | 값 |
|---|---|
| 무채색 비율 | 94% (R·G·B 차이 25 미만) |
| 무채색 명도 분포 | p5 `#2c2e31` · p40 `#4f5352` · p60 `#757774` · p80 `#b7b4b2` · p95 `#f8f7f5` — 약간 차가운 회색, 갈색 기미 없음 |
| 빨강 | 해골 두 눈 + 가운데 눈동자 두 곳뿐. p10 `#bf0a02` · p50 `#a8402c` · p90 `#f16937`(눈 한가운데 심지) |

→ UI도 같은 비율을 지킨다: **화면의 금속·선·바탕은 무채색, 빨강은 한 화면에 몇 군데만.**

## 3. 색 토큰

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--sv-hi` 하이라이트 | `#f6f5f2` | 은빛 글자 꼭대기, 가시 끝, 선택 모서리 |
| `--sv-lt` 은빛 | `#c9c7c3` | 틀 바깥선, 헤어라인 가운데, 슬라이더 채움 끝 |
| `--sv-md` 강철 | `#8a8b88` | 비활성 선, 기본 버튼 테두리 |
| `--sv-dk` 흑철 회색 | `#4f5352` | 틀 그늘, 슬롯 테두리 |
| `--sv-dp` 깊은 흑철 | `#2c2e31` | 슬롯 바탕선, 칸막이 |
| `--iron` 바탕 철 | `#0f0f10` (판 `rgba(14,14,16,.9)`) | 창·판 바탕. 갈색·붉은 기 없는 중성 흑 |
| `--tx` 본문 글자 | `#e6e3dc` | 본문. 뼈빛이 살짝 도는 은색 |
| `--tx-2` 보조 글자 | `#a7a49d` | 설명·라벨 |
| `--tx-3` 비활성 글자 | `#6b6964` | 꺼진 탭·잠김 |
| `--eye` 지옥의 눈 | `#c21a10` | **선택·초점·위험만**: 선택 탭 마름모, 선택 슬롯 안쪽 빛, 주 버튼 끝 마름모, 슬라이더 잡은 손잡이, 경고 문구 |
| `--eye-dp` 눈 그늘 | `#7e0d07` | 선택 버튼 판 가운데 방사 빛 |
| `--eye-hot` 눈 심지 | `#f16937` | 눈 그림 한가운데만(스킬 링 중앙, 문장). 글자·면에 쓰지 않는다 |

**은빛 크롬 띠**(글자·틀 선 그라데이션): 위→아래 `#f6f5f2 0%` → `#c9c7c3 30~38%` → `#4f5352 48~52%` → `#c9c7c3 62~64%` → `#8a8b88 100%`. 로고 글자처럼 위가 밝고 가운데 어두운 띠가 한 번 지나간다.

**폐기·교체**: 틀·헤어라인·버튼 테두리의 금·황동(`rgba(164,147,115,.x)`, `#c9a86a`, `#a49373`, 녹슨 황동 ENTER 등)은 이 문서의 은빛 토큰으로 바꾼다. 예외는 §7.

## 4. 문양 (로고에서 뽑은 4가지)

| # | 문양 | 로고 속 출처 | UI 사용처 |
|---|---|---|---|
| M1 | **눈 고리** (가시 돋은 원 + 가운데 세로 눈동자) | O 자리 | 큰 창 맨 위 가운데 문장(지름 92px, `eye_crest`), 스킬 링, 미니맵 테두리, 로딩 표시. 눈동자 빨강은 문장·스킬 링 중앙만 |
| M2 | **가시 모서리** (직각 L자 + 바깥 대각 가시 + 끝 마름모 + 작은 직각 가시 2개) | 글자 세리프의 뻗은 가시 | 모든 창·판·툴팁(큰 것만)의 네 귀퉁이 |
| M3 | **가시 끝 헤어라인** (양끝 작은 화살 가시 + 가운데 마름모 속 진홍 점) | HELL LORD 양옆 줄 | 구획선, 제목 아래, 툴팁 이름 아래 |
| M4 | **뿔 해골** | X 자리 | 보스 체력바·전설 등급·사망 화면 등 **특별한 곳에만**. 일반 창에는 쓰지 않는다 |

문양은 늘 **은빛 크롬**으로 그린다. 빨강은 M1 눈동자와 M3 가운데 점만.

## 6. 화면별 적용 (이식 순서)

| 순서 | 화면 | 바꿀 것 | 비고 |
|---|---|---|---|
| 1 | 첫 화면 타이틀 메뉴 | 버튼 판 테두리 황동 → 은빛, 아래 장식선 → M3 | 로고·배경은 2026-10-28 반영 완료 |
| 2 | 공통 창 토큰 (`ui-foundation.css`, `ui-refinement.css`, `ui-quiet-tier.css`) | 금·황동 변수 → §3 토큰, 창 틀 → §5 창 틀 + M2 | 한 번에 바꾸면 모든 창이 같이 바뀐다 |
| 3 | 스킬 창 [K] | 제단 링 → M1 눈 고리, 슬롯 원형 은빛, 탭·버튼 §5 | 3D 제단 계약(Skill Forge)은 유지, 색·틀만 |
| 4 | 인벤토리·창고·유골함 | 슬롯·툴팁·탭 §5, 등급 색은 이름 글자만 | |
| 5 | 설정 [ESC] | 조용한 단계 규칙 유지 + 은빛 토큰 | |
| 6 | HUD·미니맵 | 미니맵 틀 M1, 체력·자원 구슬 테두리 은빛, 보스 체력바 M4 | 전투 가독성 판정 필수 |
| 7 | 로비·캐릭터 선택·ENTER | 로비 로고 A, 카드 틀·ENTER 판 은빛 | |

각 단계는 실제 게임 화면 1920·1600 캡처 + 1x 크롭으로 이 문서와 대조해 판정한다(같은 게임처럼 보이는가).

## 7. 하지 않는 것

- 틀·선·버튼에 금·황동·구리색을 다시 쓰지 않는다. (예외: 금화·골드 아이콘 같은 **아이템 자체의 색**)
- 빨강을 넓은 면·글자 본문·테두리 전체에 쓰지 않는다. 눈은 작게, 몇 군데만.
- 네온·형광·주황 빛(지옥 하늘 LOCK과 같은 원칙), 이모지 아이콘, 점·잔노이즈 장식 금지.
- 문양을 장식으로 남발하지 않는다: M2는 창 귀퉁이만, M1 문장은 큰 창 하나에 하나, M4는 특별한 곳만.
- 등급 색(전설 주황·희귀 노랑 등)을 틀이나 바탕에 칠하지 않는다.
