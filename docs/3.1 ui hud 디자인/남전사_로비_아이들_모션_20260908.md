### 폐기안 제작 수치 / 공식

좌표는 1280×720 원본 픽셀 기준. `S(a,b,v)`는 `q=clamp((v-a)/(b-a),0,1)`에 대해 `q²(3−2q)`. `phase=2πt/6`. 모든 sin 위상은 6초 경계에서 이어진다. 발과 검은 변형 가중치를 거의 받지 않도록 제한한다.

| 구분 | 값 / 공식 |
|---|---|
| 메시 | 셀 24px, 마지막 셀은 화면 끝에 clamp, Pillow MESH + BICUBIC 역변환 `(x−dx,y−dy)` |
| 원본 프레임 | ffmpeg fps=30으로 디코딩. `(원본 프레임수−1)×(1−cos(phase))/2` 위치를 앞뒤로 순회하고 인접 프레임을 소수부만큼 blend. 마지막 인접 인덱스 clamp |
| 상체 가중치 B | `exp(−((x−510)/205)^4−((y−300)/245)^4)` |
| 하체 고정 가중치 P | `1−S(470,660,y)` |
| 상체 이동 | `dx=5.5 sin(phase) B P`, `dy=−6 sin(2phase) B P` |
| 망토 가중치 C | `S(550,790,x)×(1−S(1010,1160,x))×S(155,255,y)×(1−S(520,655,y))` |
| 망토 위상 지연 L | `(x−580)/105` |
| 큰 파동 W | `sin(2phase−L)−sin(−L)` |
| 잔물결 R | `sin(4phase−1.5L)−sin(−1.5L)` |
| 망토 이동 추가 | `dx+=C(7W+2R)`, `dy+=C(15W+3R)` |
| 머리 가중치 H | `exp(−((x−503)/64)^4−((y−195)/66)^4)` |
| 머리 이동 추가 | `dx+=1.5 sin(phase) H`, `dy+=−1.5 sin(2phase) H` |

영상 교체는 별도 경로로 연결하여 이전 캐시와 충돌하지 않는다. 기존 원본은 재제작을 위해 남긴다. UI 문구/배치, 인게임 남전사 스프라이트, 스킬/전투/세이브 수치는 변경하지 않는다.
