# 성장창 기사 배경 고정 (2026-09-27)

성장창의 기사 일러스트는 확대·축소 또는 노드 화면 이동에 따라 움직이지 않는다. 패시브 노드와 연결선만 기존 성장 트리의 확대·이동을 따른다.

| 대상 | DOM/CSS 위치 | 확대·이동 적용 | 구현 |
|---|---|---|---|
| 기사 일러스트 | `#growthTreeViewport::before` | 없음. 뷰포트 중앙 고정 | `growth-tree-fixed-background.css` |
| 패시브 노드·이름·연결선 | `#growthTreeScene` | 기존 줌·팬 적용 | `game.html`의 성장 트리 동작 유지 |
| 기존 기사 배경 | `#growthTreeScene::before` | 표시하지 않음 | `content: none` |

데스크톱 적용 범위는 `min-width: 781px`이며 기사 이미지는 뷰포트를 빈 공간 없이 채우도록 `100% 100%`로 표시한다. 따라서 100%에서 175%로 확대해도 기사 이미지 크기와 중앙 위치는 그대로이고 노드와 연결선만 확대된다. 원본은 기존 성장창에 사용 중인 `hf_20260927_102905_7c7fc782-eb73-4bf0-9f4b-4de19dfa79ae.png`다. 이미지 URL은 CSS에 기록되어 있으며 로딩이 실패해도 뷰포트의 기존 어두운 배경이 남는다.

## 화면 정보 밀도

| 대상 | 기본 표시 | 상호작용 시 표시 | 구현 |
|---|---|---|---|
| 성장 트리 노드 이름표 | 숨김 | 노드 호버 또는 키보드 포커스 시 표시 | `growth-tree-information.css` |
| 상단 현재 자원 HP·ST·MP | 숨김 | 없음. 성장창 사용 자원이 아님 | `growth-tree-information.css` |
| 상단 계획 후 SP | 숨김 | 없음. 현재 패시브 화면은 AP만 사용 | `growth-tree-information.css` |
| 상단 계획 후 AP | 표시 | 표시 | 기존 AP 계산 유지 |

데스크톱 성장창에만 적용한다. 노드의 `title`·`aria-label`과 우측 패시브 분석 정보는 유지해 이름을 확인하고 투자할 수 있다.

2026-09-28 빌드 동기화: `growth-tree-fixed-background.css`, `growth-tree-information.css`를 `build-nwjs.mjs`의 공통 FILES 목록에 포함했다. 이 목록을 재사용하는 웹 정적 빌드에도 두 스타일이 복사된다. 화면 규격·게임 수치는 변경하지 않았다.
