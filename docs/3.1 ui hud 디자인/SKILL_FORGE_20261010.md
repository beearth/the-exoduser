## 3. 로직 보존 계약

새 창은 판정·실행을 **기존 함수 호출만** 한다.

| 동작 | 호출 |
|---|---|
| 습득·강화(합체 강화 포함) | `_skLearnUp(sk)` |
| 레벨 다운 | `_skLevelDown(sk)` |
| 리셋/합체 해제(분해) | `_skResetSkill(sk)` — 최상위 완성 그룹 환불·해제 |
| 합성 | `_canFuse(key)` → `_execFuse(key)` |
| 슬롯 배정 | `_canAssignSkillSlot` / `SKILL_SLOT_DEFS` / `ult`, 이후 `updateQS`·`updateSkSlot`·`_updateUltSlot`·`dbSaveForce` |
| 상태(강화 가능·비용·잠금) | `_skCtx(sk)` |

`_skCtx/_skLearnUp/_skLevelDown/_skResetSkill`은 이번에 `_renderSkillRow` 안의 지역 함수(카드 `_skClick`·`_skMinusClick`·리셋 버튼)를 **같은 코드 그대로** 최상위로 옮긴 것이다(패치: `tmp/skill_forge_gamehtml_patch.py`). 구 카드는 이 함수를 호출만 하므로 `?skillForge=0`에서도 동작이 같다. `_skCtx`는 함수 최상위(4칸 들여쓰기)에서 선언된 이름만 반환한다(블록 안 `_fk2` 등 제외 — 테스트로 잠금).
