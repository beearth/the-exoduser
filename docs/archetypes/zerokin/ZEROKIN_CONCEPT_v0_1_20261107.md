# 제로킨(Zerokin) — 번개의 아들 · 캐릭터 설계 v0.1 (2026-11-07)

- 상태: **설계 초안(G1)**. Core 미구현, 원화·3D 0, 게임 표시 텍스트 0. 수치는 전부 초안이며 밸런스 확정 전이다.
- 요청: 사용자 11-07 "케릭터추가 번개의 아들 … 상대의 전기전자를 흡수하여 공격력을 올리고 상대의 공격력을 내리는 주력스킬", "도타2 레이져가 모티브", "몬스터들의 공격력을 빨아들이고 전기로 몸에 들어가고 전력이동을 하고 전류폭풍 필살기를 쓰고 흡수한 전기로 전류 블랙홀을 만드는등의 주력기".
- 이름: **제로킨**(사용자 11-07 확정. 처음 안 "제로키"는 로키 신화와 겹쳐 바꿈).
- 범위: 데모 v0 표(키샷·1-1 한 판·첫인상·패키지) 밖이다. 데모 v0 작업을 밀어내지 않고, 이 문서는 데모 뒤 영웅 트랙의 설계 기준으로 둔다.

## 1. 모티브와 차별

모티브는 "적의 힘을 빨아 내 힘으로 바꾸는 전기 영웅"이라는 **메커니즘**이다(도타2 레이저의 공격력 흡수, 번개로 몸을 바꿔 이동하는 감각). 외형·이름·수치는 가져오지 않는다.

| 가져오지 않는 것 | 제로킨에서 바꾼 것 |
|---|---|
| 채찍 무기 | 오른팔 도체 건틀릿(근접 타격·방전) |
| 온몸이 번개로 된 에너지 인간 | 사람 몸. 왼팔·흉터에만 번개 혈관이 비친다 |
| 파랑·보라 네온 색 | 은빛 강철 + 검정 + 채도 낮은 청백 전류(실버 헬 톤) |
| 원작 스킬 이름·수치·쿨다운 | 아래 표의 새 이름, 이 게임 단위(60fps 틱·웹 좌표 단위)로 새로 잡은 값 |
| 1대1 연결만 하는 흡수 | 핵앤슬래시용: 대상이 죽으면 다음 적으로 옮겨 붙고, 흡수한 전기는 "전하"로 쌓여 블랙홀·폭풍의 연료가 된다 |

## 2. 한 줄 콘셉트·이야기(초안)

- 콘셉트: **"적의 공격력이 곧 내 공격력."** 오래 붙어 싸울수록 적은 약해지고 제로킨은 강해진다. 모은 전기를 한 번에 터뜨리는 것이 손맛의 정점이다.
- 기본 이야기(초안, 게임 미표시): 폭풍이 그치지 않는 고원에서 벼락을 맞고 태어난 아이. 마을은 그를 "번개의 아들"이라 부르며 피뢰침에 묶어 폭풍을 받아 내는 제물로 썼다. 피뢰침이 부러진 밤, 그는 몸에 쌓인 벼락으로 마을을 태웠고 그 죄로 지옥에 떨어졌다. 지옥에서도 그는 남의 힘을 빨아들여야만 살아남는다.
- 게임에 표시할 때 `character_basic_stories.json` 등 29개 언어와 `16번역·로컬라이제이션/번역대상_전체목록.md` 등록을 같은 커밋에서 한다.

## 3. 자원: 전하(Charge)

| 항목 | 초안 값 |
|---|---|
| 범위 | 0~100 |
| 얻기 | 흡착 연결 중 60틱마다 +10 / 적에게 피해 1타마다 +1 / 피격 때 받은 피해와 상관없이 +3(접지 패시브) |
| 잃기 | 마지막 전투 행동 300틱 뒤부터 60틱마다 −5 |
| 쓰기 | 전신 전이(이동 거리 비례), 전류 블랙홀(전부 소비, 40 이상), 전류 폭풍(100 가득) |
| HUD | 기존 MP 줄 아래 얇은 은청 띠 1줄(UI 총괄 배치안 필요, 원색·네온 금지) |

MP·ST는 기존 공통 규칙(`SkillRules.MpCost`·`StCost`)을 그대로 쓴다. 전하는 제로킨 전용 추가 자원이다.

## 4. 기술 목록(초안)

틱 = 60fps 1프레임. 거리 = 웹 좌표 단위(지옥강타 사거리 500과 같은 단위). 피해 배율은 기존 `_SK_MUL` 표 형식(b, g)으로 새 id를 제안한다.

### 4.7 설계 금지 확인

- 어택 티켓(동시공격 제한) 없음. 흡착은 적 수를 제한하지 않는다.
- 블랙홀은 보스를 끌지 않는다(보스 아레나 위치·패턴을 깨지 않기 위해).
- 흡수로 깎는 것은 적 공격력뿐이다. 적의 판정 크기·예고 틱·탄 모양은 바꾸지 않는다.
