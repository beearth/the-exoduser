# 실버테일 r2 웹 실게임 미리보기 — 2026-11-03

브리프 r2 CTO 판정은 대기·보행의 **후보 통과**이며 제품 승인과 다르다. 이 변경은 `codex/silver-r2-preview-20261103` 브랜치의 개발 미리보기다. main 병합·Steam 배포·Unity 반영은 하지 않는다.

## 진입과 경계

- `game.html?spr=silver_r2`에서 실버테일만 교체한다. 플래그 없는 화면은 현행 자산을 쓴다. 새 파일 `silvertail-r2-preview.js`는 Steam 패키지 FILES에도 등록한다.
- 기존 로더·공격 확장·비행 확장을 모두 거친 뒤 여섯 새 atlas를 원자적으로 병합한다. 하나라도 실패하거나 규격이 다르면 원본 전체로 돌아간다. 기존 캐릭터/마스크 전환의 늦은 콜백 폐기 조건도 그대로 적용된다.
- 기존 자산은 덮어쓰지 않는다. 신규 경로는 `assets/characters/silvertail_r2/`. 이미지·메타·실루엣 노멀 초안을 함께 보관하지만 **노멀은 웹 렌더에 적용하지 않는다**.
- 기본 스프라이트에는 `renderScale`이 없다. 신규 프레임만 `.5`를 지정해 2배 자산을 원래 논리 크기에 그린다. 기존 배율 `2×.65=1.3`, 충돌 반지름·이동거리 주기·공격/패링 시간·피해·자원을 유지한다.

## 자산과 발밑 계약

방향 행은 S·SE·E·NE·N·NW·W·SW다. 좌표는 자산 픽셀이고 논리 크기는 절반이다.

| 대기 | 192×768 | 96 / (48,94) | 2슬롯, 같은 대기 자세 중복 |
| 보행 | 384×768 | 96 / (48,94) | 방향별4포즈, 현행 거리 기반 재생 |

SpriteAnimator 중앙 원점에서 발의 논리 Y는 본체23, 공격22, Shift18px다. 원본 `47−24`, `62−40`, `50−32`와 같다. 죽음·기절 등 전용 r2 군이 없는 자세는 대기 폴백이며 별도 사망 애니메이션 승인으로 세지 않는다.

## CTO 지정 두 수정

- N 보행: 상체64행과 검 픽셀을 보존하고 중앙의 찢어진 천 사이로 발끝·뒤꿈치4포즈를 드러냈다. 새 하체 부분 원화는 `output/silvertail_r3/north-legs-source.png`, 프롬프트는 같은 폴더 JSON에 보관한다. 비디더링·최근접 패킹이다.
- SE 2번 프레임: 앞발의 유독 검은 외곽선55픽셀을 같은 군의 외곽선색 `(34,25,28)`로 맞췄다. 알파는 유지한다. 그 외 보행27셀과 나머지5군 atlas는 r2 후보와 같다.

패커: `tools/prepare-silver-r2-preview.py`. r2 원본을 읽어 별도 출력한다. 각 metadata의 atlas SHA와 프레임 RGBA SHA로 최종 입력을 추적한다.

## 검수 재현과 증거

`tools/qa-silver-r2-preview.py --out <I: 절대 출력> --port <격리 서버 포트> --capture`로 headless·`--mute-audio`·별도 프로필/세이브에서 실제 game.html을 실행한다. 기존 `server.cjs`를 자기 작업본에서 사용하며 사용자의 서버/세이브는 건드리지 않는다. 필요한 누락 원본은 HEAD Git blob과 일치하는 파일만 자기 sparse 작업본에 읽어온다.

실게임 원본/r2 1920 캡처와 실제1x 크롭, `ingame_r2_vs_original.png`, N4포즈, 16:9·21:9·32:9 캡처, 10초 무음 동영상의 최종 증거는 `I:/EXODUSER-Storage/codex-takeover/sprites-silver/REPORT.md`에 기록한다. 지정 전달 위치는 `G:/exoduser/tmp/design-review/20261103_sprites_silvertail/ingame/`다.

정지 비교는 실제1-1 renderer에 자세·시계·위치만 고정하는 scene-assisted 검사다. 무플래그 픽셀 검사는 동일한 고정1920 화면에서 정확한 기준 HEAD의 `SpriteAnimator.draw`와 변경 draw를 교대한다. 무플래그 신규 atlas 요청0도 확인한다. 별도의 전체 새 빌드 두 개를 비교한 증거로 확대 해석하지 않는다.

동영상은 실제 키보드/마우스 입력의 Chrome PNG screencast를 무보간 무음으로 인코딩한다. 검수용 무적·Shift 표적 배치와 피격 자세 제어를 사용하므로 자연 완주/FPS 증거는 아니다. 최종 시각 판정·미검증 항목은 REPORT를 따른다.

## 제출 검증

신규6검사 통과. 관련 회귀는30통과·3실패이며 실패3개는 수정 전 기준 HEAD에서도 동일하다(구 공격 정규식2·과거 보행 버전 정규식1). 전체 저장소 무실패로 보고하지 않는다. 1920 기본 화면과 동일 렌더러 반복 대조군의 최종 차이는 각각0픽셀, 새 atlas 요청0이다. 고정 화면13쌍은 위치·충돌 반지름이 일치하고 r2의 실제 선택 프레임/체력을 기록했다. 1600×900·1920×1080·2560×1080·3840×1080 및 무음10.000초/300프레임을 확보했다. 녹화의 마지막0.3초는 마지막 실제 프레임 유지이며 보간 프레임을 만들지 않는다.

브라우저 검토판은 이미지 전부 로드, 가로 넘침0, 오류0, 동영상 readyState4·실제 무음 재생을 확인했다. 자체 시각 확인은 새 캐릭터의1x/3x 판독과 N/SE2 수정·실게임 표시 범위다. 원본 월드 텍스처·전체 전투 품질 또는 독립 CTO 제품 PASS로 확대하지 않는다.
