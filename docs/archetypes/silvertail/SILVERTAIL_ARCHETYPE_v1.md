## [1] 정체성

BLADE DANCER. 회전축에 연결된 단 하나의 검.
멈추면 전부 잃는다.

카피: 회전축에 연결된 단 하나의 검. 그녀의 춤이 곧 파멸이 된다.
ONE BLADE. ONE DANCE. ONLY DESTRUCTION.

전투 축은 이동이다. 서 있으면 아무것도 아니고 움직인 만큼 강해진다.
핵슬 기초인 스피드 액션을 아키타입 하나가 극단까지 밀어붙인 형태.

비주얼: 은발 포니테일, 흑철 갑주, 찢어진 망토가 칼날개로 전개.
Berserk + FromSoftware 작화 언어 유지.

## [2] 아키타입 대비

워리어 작살로 파고든다. 진입이 곧 딜.
마법사 지팡이로 좌표를 심고 회수한다. 배치가 곧 딜.
실버테일 계속 돈다. 멈추지 않는 것이 곧 딜.

셋 다 이동이 딜이지만 시간 구조가 다르다.
워리어는 즉시, 마법사는 10초 전, 실버테일은 계속.

## [3] 공통 기반 [아키타입 불변]

전 아키타입이 공유하는 층. 캐릭터마다 다르게 설계하지 않는다.

bladeDash 전격이동. 방향키 더블탭 또는 Shift + 방향키. 500유닛, 10충전, 8초/1충전.
Q 무지개콩 sBlock 패링. 분노 게이지 적립.
E 빨간콩 sBash 패링. 블루콩 변환 홈잉.
오패링 시 탄이 그 자리에서 폭발. 풀뎀 + 넉백 + 슬로우모.
어택 티켓 없음. 논타겟팅.

분노기는 게이지를 소모하는 스킬이 아니라 축적된 게이지를 방출하는 트리거다.
규모는 축적량에 비례한다. 만충이면 최대, 절반이면 절반.

단계별 효과

 3단 궤도 260 은무 3자루 날개 완전 전개 이동 궤적 연속 히트 이속 +15퍼센트

날개 크기가 곧 게이지 UI다. 플레이어는 화면만 보고 자기 상태를 읽는다.
멈춰서 날개가 접히면 그것이 경고다.

### 4-2 출혈

실버테일 주력 상태이상. 기존 6원소 매트릭스와 별개 축. 아키타입 전용.

중첩 최대 10. 중첩당 초당 틱뎀. 지속 6초, 재부여 시 갱신.
부여원: 무영선, 은무 공전 히트, bladeDash 검흔, 칼날개 히트, 삼섬 난무. 각 1중첩.
소비: 회광 칼날 회수 공격이 경로상 적의 중첩을 전량 폭발. 중첩 1당 계수 가산.

한 번에 크게 때리는 것이 아니라 스치며 여러 번 그어 쌓는 구조.
계속 움직여야 한다는 정체성과 같은 방향.

## [6] 스킬 상세

### 6-1 무영선 [LMB]

기본 공격. 검을 궤도에 태워 회전 타격.
연속 입력할수록 관성 누적, 3단계로 궤도 확대.
3단 도달 후 클릭 유지만으로 회전 지속. ST 지속 소모.
피격 시 연무 1단계 하락. 맞으면 궤도가 줄어든다.
히트당 출혈 1중첩.

### 6-2 은무 [RMB]

검을 축에서 풀어 공중에 띄운다. 뿌려놓고 자율 회전.
RMB 탭 사출, 재입력 회수.
사출된 검은 플레이어를 중심으로 공전하며 통과 적을 지속 타격. 조작 불필요.

자루 수와 공전 반경은 연무 단계에 종속.
 1단 반경 200 1자루 / 2단 반경 350 2자루 / 3단 반경 500 3자루

유지 비용: ST 지속 소모. 연무 감쇠 속도 2배.
연무가 떨어지면 검이 하나씩 자동 회수되며 궤도가 줄어든다.

검 전량 사출 중에는 무영선 사용 불가. 포니테일 근접 견제만 가능.
견제는 저계수 넉백 전용. 버티기 용도.

회수 시 검이 직선 귀환하며 경로 관통 타격. 연무 1단계 상승.

리스크: 뿌리면 화면이 은빛으로 덮이지만 본인은 무장 해제.

### 6-3 삼섬 증폭 [SHIFT]

삼섬 콤보 진행 중에만 작동. 콤보 밖에서는 미작동.
각 섬 발사 직전 Shift 홀딩. 놓는 순간 그 섬이 증폭된다.

 tier1 홀딩 0.2초 길이 1.5배 검흔 지속 1.5배
 tier2 홀딩 0.5초 길이 2배 폭 1.5배 검흔 지속 2배
 tier3 홀딩 0.9초 길이 2.5배 폭 2배 검흔 지속 3배 관통 무제한

비용: 증폭 1회당 연무 1단계 소모.
3섬 전부 증폭 시 난무 시간 +1초.

리스크: 홀딩하려면 멈춰야 한다. 삼섬 콤보 타이머는 3초.
tier3를 세 번 홀딩하면 2.7초를 홀딩에만 쓴다.
정지가 길어지면 연무 소멸 위험. 증폭하려다 증폭 재료를 잃는 구조.

선택지: 전부 tier3로 밀지, 중요한 한 선만 tier3 주고 나머지는 빠르게 그을지,
아예 증폭 없이 3초를 여유롭게 써서 도형을 확실히 닫을지.

### 6-4 bladeDash [SHIFT + 방향키]

공통 기반 이동기. 실버테일 특성 추가.
대시 궤적에 은빛 검흔 0.8초 잔류. 통과 적 타격 + 출혈 1중첩.
연무 +1. 대시 직후 1초간 연무 감쇠 정지.

### 6-5 회광 [QQ]

Q 단탭 sBlock 진입 [기존 무변경].
12프레임 이내 Q 재탭 시 sBlock 캔슬하고 발동.
윈도우 경과 시 sBlock 유지.

발동 즉시 현재 위치에 칼날 1자루를 꽂고 후방 600 순간이동.
전 구간 무적. 착지 6프레임 경직. poise 풀회복. 연무 +2.

꽂힌 칼날은 3초간 잔류. 반경 200 내 적에게 지속 출혈 부여.
3초 후 자동 회수. 칼날이 플레이어에게 직선 귀환하며 경로 전체 관통 타격.
귀환 타격 시 경로상 적의 출혈 중첩 전량 폭발. 중첩 1당 계수 가산.

3충전, 충전 10초. 동시 최대 3자루 존재.

의도: 한 번의 입력이 두 박자다. 지금 도망치고 3초 뒤에 갚는다.
그 3초 동안 무영선과 칼날개로 출혈을 쌓고, 귀환 타이밍에 맞춰
몹을 칼날과 자기 사이에 두면 폭발이 최대로 터진다. 위치 잡기가 실력이 된다.

### 6-6 삼섬 [SPACE, 분노]

1타 SPACE. 커서 방향 직선 기동섬광. 이동 + 경로 타격. 분노 게이지 방출.
2타 3초 내 SPACE. 현재 위치에서 재발동.
3타 3초 내 SPACE. 재발동.
2타 3타 무료. 사이에 bladeDash 자유 삽입 가능.
대시는 콤보 타이머를 소모하지만 초기화하지 않는다.

3타 완료 시 난무 발동. 그은 선을 따라 고속 왕복. 전 구간 무적.
 닫힌 도형 미형성 1초 난무
 닫힌 도형 형성 2초 난무

성립 판정은 선분 교차 검사. 형태 무관. 찌그러진 예각이든 닫히기만 하면 성립.
정삼각형일 필요 없음. 시작점으로 정확히 돌아올 필요 없음.

난무 상세
 왕복 0.25초에 선 전체 1회 주파. 1초 4회, 2초 8회
 타격 판정 선분 60 이내. 동일 적 재타격 간격 6프레임
 넉백 없음. 선 밖으로 밀려나면 안 된다
 보스 포함. 선 위 보스는 왕복 전탄 적중
 히트당 출혈 1중첩

연무 3단에서 발동 시 난무 대미지 2배, 왕복 속도 1.5배.

미완 처리
 1타만 사용 경로 타격만. 3초 후 콤보 소멸
 2타에서 시간 초과 두 선분에 3초 잔류 검흔. 통과 적 지속 타격
 3타 완료 난무 발동

벽 충돌 시 그 지점이 종점. 도형 미성립하되 난무는 정상 발동.
지형 읽기가 실력 요소가 되되 실패가 스킬 무효화로 이어지지 않는다.

의도: 춤의 동선이 곧 도형이다. bladeDash로 각도를 트는 조작 깊이와
그 대시가 올리는 연무 보상이 같은 행동에 묶인다.

### 6-7 칼날개 [패시브]

워리어 chainSlash를 실버테일 기본 내장으로 이관.
워리어 측은 합체 해금분으로 존치. CHAIN DRIVE 차별점 문구 유지.

연무 단계 종속 전개.
 1단 미전개 / 2단 반전개 회전 시 후방 히트 / 3단 완전 전개 이동 궤적 연속 히트

계수: 워리어 chainSlash 대비 3배. 연무 3단에서 추가 1.5배.
히트당 출혈 1중첩.
삼섬 난무 중에는 연무 단계와 무관하게 완전 전개.

의도: 3단 유지 상태의 이동 히트가 무영선 3단 회전과 맞먹어야
"멈추면 안 되는 캐릭"이 성립한다.

## [7] 전투 루프

이동으로 연무를 쌓는다. 연무가 오르면 날개가 펴지고 이동 자체가 출혈을 뿌린다.
Q 패링으로 분노를 쌓는다.
회광으로 칼날을 꽂고 빠진다. 3초 안에 출혈을 최대로 쌓고 위치를 잡는다.
칼날 귀환이 출혈을 터뜨린다.
분노 만충 + 연무 3단에서 삼섬을 그어 전부 태운다.

축적이 세 겹이다. 연무, 출혈, 분노.
전부 이동과 패링에서 나오고 전부 한 번에 터진다.
물약 의존 없음. 전투 구동형 자원 관리.

## [8] 밸런스 가드

어택 티켓 금지 원칙 유지.
히트스톱 보스 한정 유지. 회광 칼날 회수 및 삼섬 난무에 히트스톱 금지.
출혈은 아키타입 전용 축. 6원소 색상 매트릭스 확장 아님.
색-키 매칭 Q/E는 불변. 아키타입이 바뀌어도 건드리지 않는다.
bladeDash는 전 아키타입 공용 기반. 실버테일 특성은 부가 효과로만 얹는다.

## [10] 성능 규약

게임루프 내 new splice filter forEach Date.now 금지.
shQuery 결과는 _shCacheFrom 버퍼 복사 후 사용.
삼섬 선분 교차 판정은 3타 완료 시점 1회. 매 프레임 아님.
난무 대상은 선분별 AABB로 청크 추린 뒤 검사. 대상 배열 사전할당 고정배열 재사용.
난무 20히트는 성립 시점에 대상 배열 1회 확정 후 그 배열로 반복.
은무 공전 검 최대 3자루. 회광 칼날 최대 3자루. 동시 존재 상한 고정.
출혈 중첩은 적 객체 필드로 관리. 별도 배열 생성 금지.
수정 전 grep으로 라인 확인 + .bak 백업. str_replace만 사용.
