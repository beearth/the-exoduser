- 첫 시각 검수에서 기존 가시 장판이 전투 주체를 가리는 문제를 확인하여, 데모 피날레만 지상 반투명 질감과 실제 반경 경고로 수정.
- 본체 분리로 분출 위치가 전조와 어긋나는 경우를 단위 테스트로 재현하고, 피날레 분출의 피해/VFX 중심을 고정 표적 좌표로 맞춤.
- 공통 적 방향 추적이 전조 마지막18f 고정을 덮어쓰는 것을 브라우저에서 재현, 공통 추적에도 `_druidAimLocked`를 적용한 뒤 방향 고정 확인.
- `hurtE`의 실제 방어 경로 조사: 기존 잠행의 `e.iframes=50/5` 필드는 `hurtE`에서 검사하지 않는다. 기존 문서의 잠행 무적 설명을 실제 피격 면역으로 간주하지 말 것. 이번 작업은 이 공용 방어 계약을 변경하지 않았다. 반격 검증은 기존 에너지쉴드가 남은 조건에서 쉴드100 감소로 확인했다.
- 자세한 최종 테스트 수·브라우저 입력/피해 검증·시각 판정은 아래 실행 결과 절에 기록한다. 테스트베드는 강화 캐릭터와 전용 아레나를 사용하므로 실제 데모 장비의 TTK/신성력별 난도 승인을 대체하지 않는다.

## v0.1 설계 기록 (현행 구현은 위 §0 우선)

## 1. 사용자 확정과 설계 목적

사용자 확정: 다크드루이드 보스전은 **데모 피날레**다. 지속적으로 신경 쓰고 다듬어야 하는 핵심 전투다. 첫 보스의 기능 소개를 중심으로 잡았던 초기 해석을 철회한다.

플레이어가 기억할 경험: **독술을 되받아치고, 야수의 추격을 꺾고, 땅속에서 솟아오르는 드루이드를 끝내 제압했다.**

이 문서는 전투의 패턴 구성·연출·반복 검수 계획을 기록한다. 아래 제안값은 현행 수치를 대체하지 않는다. 데모 전용 적용 조건은 구현 전 확정할 항목이며, 기존 si0/si3 공용 경로에 무조건 적용하면 안 된다.

## 3. 전투의 3막 구성 — 제안

HP는 **현재 생명 주기의 `hp/mhp`**다. 부활 이후에는 이 구성이 다시 시작될 수 있으며, 전투 전체 종료는 최종 사망 판정으로 구분한다.

| 막 | HP / 내부 phase | 보스 행동 | 플레이어 경험 | 차별화 |
|---|---|---|---|---|
| 독술사 | 100%~60% 초과 / 0·1 | 독탄으로 압박, 접근하면 지팡이 연계, 야수 돌진을 먼저 보여줌 | 패링으로 접근 기회를 만들고 근접 교환 | 후반에 쓰일 대표 동작과 신호를 미리 제시 |
| 숲의 포식자 | 60% 이하~20% 초과 / 2·3 | 야수 돌진·잠행을 주력으로, 독늪과 순차 연계 | 이동으로 공격을 흘리고 분출 뒤 반격 | 같은 보스가 사냥 방식과 자세를 바꾸는 느낌 |
| 마지막 발악 | 20% 이하 / 4 | 앞에서 본 독탄·돌진·분출을 대표 연계로 연결 | 익힌 대응을 연속 수행하고 큰 공격을 쏟아부음 | 새로운 입력 규칙보다 익숙한 동작의 조합으로 절정 구성 |

60%와 20%는 큰 연출 전환 지점 후보다. 80%와 40%는 압박 변화로 표현하는 안을 우선 검토한다. 현행 모든 경계의 공통 전환 연출·피해를 바꾸려면 데모 프로필 분리가 필요하다.

## 4. 대표 패턴 구성 — 제안

표의 한글명은 연출용 가칭이다. 무브 ID 변경 지시가 아니다.

| 가칭 | 기존 기반 | 전조와 실행 | 대응과 보상 | 다듬을 항목 |
|---|---|---|---|---|
| 부패의 맥동 | Q 리듬탄 | 지팡이 집광 후 녹색 부채꼴 탄막 | Q 반사로 공격에 참여, 측면 이동도 가능 | 잡다한 탄막 사이에 Q 기회가 묻히지 않는가 |
| 고목의 채찍 | `slashCombo` / `sweep` 후보 | 상체와 지팡이를 뒤로 당긴 뒤 근접 연계 | 기존 근접 대응 규칙으로 막타를 넘긴 뒤 공격 | 첫 전조와 마지막 타격이 명확한가 |
| 포식자의 질주 | `charge` / `multiDash` 후보 | 기존 transform→beast, 방향을 읽을 수 있는 예비 동작 | 측면 회피 후 돌진 종료 지점을 공격 | 시작 후 급선회·추가타로 성공한 회피를 무효화하지 않는가 |
| 썩은 숲의 숨결 | `lavaPools` | 기존 3지점 순차 전조와 독늪 | 순서를 읽고 재배치하면서 원거리 공격 유지 | 감속 중에도 판정 포함 통과 가능한가 |
| 땅속의 포식자 | `burrowStrike` | 침강→흙두둑 추적→지점 확정→분출 | 이탈 또는 기존 분출 패링 경로로 대응, 이후 집중 공격 | 표적 추적 종료와 타격 사이 시간, 실제 후딜 |
| 숲의 단말마 | 위 기술의 새 연계 구성 | 독탄→야수 돌진→잠행 분출→명확한 후딜 | 패링·이동·반격을 이어 데모 전투를 완주한 느낌 | 연계 연결마다 대응 신호가 유지되는가 |

1차 전투 원형은 위 핵심군을 중심으로 구성하는 안을 권장한다. 소환·지뢰·독립 ORB 등 나머지 기술은 실제 플레이에서 별도의 재미가 확인된 경우에 채택한다. 특히 독립 ORB는 반사되지 않는 대응 차이를 전달할 수 있을 때 포함한다. 현행 무브셋 및 ORB는 아직 변경하지 않았다.

## 5. 박자와 공정성 — 조정 후보

| 항목 | 초안 목표 | 적용 의미 |
|---|---|---|
| 큰 공격의 읽을 시간 | 최종 타격 전 실효 전조 36~54f(0.6~0.9초, 60fps 환산)부터 시도 | 공통 teleM·지연·애니메이션·시뮬레이션 배율을 적용한 실제 시간으로 측정 |
| 잠행 표적 고정 | 타격 최소 30f(0.5초) 전에 목표 지점 확정부터 시도 | 현재 추적 종료 뒤 짧은 분출 전조와 비교할 후보. 단순 tele 숫자 변경만으로 완료 처리 금지 |
| 큰 연계 후 반격 | 72~108f(1.2~1.8초)의 실제 공격 가능 시간부터 시도 | 단순 recover 상태 길이가 아니라 무적 해제·잔탄·보스 위치까지 확인 |
| 탄막 리듬 | 평시 Q 기회 유지, 변신·분출 전조·반격 구간과 발사 시점 조율 | 필요한 구간에서 드루이드 독립 발사를 잠시 유예하는 안. 재개 시 밀린 웨이브 몰아쏘기 금지 |
| 기존 위험물 | 발사 유예만으로 반격 구간이 생겼다고 간주하지 않음 | 남은 유도탄·ORB·장판 수명까지 추적. 일괄 삭제 대신 자연 소진과 배치 순서를 우선 설계 |
| 페이즈 전환 | 이동/변신 예고 이후 첫 공격을 읽을 수 있게 구성 | 현행 뒤 순간이동 즉시 피해 경로를 데모용으로 분리 검토 |
| 후반 압박 | 후속타·연계 순서로 강화 | 전조의 실효 하한과 실패 후 회복 가능성을 별도로 검증 |

위 숫자는 첫 비교 플레이의 출발값이다. 피해·HP·포이즈·패링 판정·부활 공식을 확정 변경한 것이 아니다. 적 수나 동시공격을 제한하는 어택 티켓은 도입하지 않는다.

## 6. 피날레 연출과 종료 계약 — 제안

- 등장: 기존 emerge/idle로 전신과 지팡이 집광을 읽게 한다. 첫 시도에는 긴장감을 주되 재도전에서는 빠르게 교전에 진입하게 구성한다.
- 변신: 기존 transform/beast를 대표 장면으로 사용한다. 실제 공격 방향과 예고 동작이 연결되어야 한다.
- 위험 식별: 녹색 독 속성을 유지하면서 탄의 형태·궤적·전조로 Q/E/반사 없는 ORB를 구분한다. 색만으로 입력을 판단하게 만들지 않는다.
- 잠행: 땅속 이동 흔적과 분출 예고가 연결되어야 한다. 본체가 숨은 동안 탄이 출처 없이 떠오르는 현상도 확인한다.
- 최종 처치: HP=0만으로 승리 연출을 시작하지 않는다. 즉시 부활과 폴백 부활이 모두 끝난 최종 사망에서 기존 에셋을 이용한 붕괴·잔광 소멸·짧은 여운으로 연결한다.
- 재도전: 같은 소개 연출의 반복 대기를 줄이고, 기존 재시작 자원 완충 계약을 보존한다.

보스 부활은 이 게임의 핵심 시스템이다. 데모 전투 길이를 맞추기 위해 부활 횟수나 신성력 효과를 임의로 제거하지 않는다. 첫 HP 소진 시간과 부활을 포함한 최종 처치 시간을 따로 측정한 뒤 데모 장비 기준과 함께 조정한다. 목표 총 전투 시간은 현재 미확정이다.

| 반격 구간 | 무적·잔탄·장판 때문에 이름뿐인 후딜이 되지 않는가 | 미실시 |
| 시각·성능 | 대표 동작과 투사체 판정이 가려지지 않고 밀집 시 프레임이 안정적인가 | 미실시 |
| 전투 종료 | 즉시/폴백 부활과 최종 사망을 구분하고 승리 뒤 잔여 공격이 문제를 만들지 않는가 | 미실시 |
| 재도전 | 초기 탄막 타이머·전투 상태가 초기화되고 자원이 정상 복원되는가 | 미실시 |

자동 테스트는 상태·판정 회귀 검사용이다. 재미·전조 가독성·피날레 완성도 판정을 대체하지 않는다. 이번 기록은 문서/코드 조사에 기반한 설계이며 브라우저 플레이나 시각 PASS를 주장하지 않는다.
