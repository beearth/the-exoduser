## 4. 현재 드루이드가 약한 이유

| 항목 | 현행 | 공통점 대비 |
|---|---|---|
| 크기 | LOCK §4·§16: 정수리 2.30m / 뿔 끝 2.70m. Unity 축척 `VfxBridge.PxToM=0.01`, keyshot 영웅 화면 높이 0.08~0.11 기준 **영웅의 1.5배, 화면 높이 14%** | 2.5배·25% 미달. 필드 정예몹 크기다(시안 `00_current_druid_1x.png`) |
| 실루엣 | §16 교정(마른 몸통 0.44m, 망토 포함 0.70m)으로 **덩어리가 영웅보다 좁다** | 사용자 요구 "마른 저주받은 노인"은 맞지만, 그 몸만으로는 보스 덩어리가 없다 |
| 등장 | 걸어 들어와 대사, 지팡이 3번 두드림 → 기둥 4개 | 크기 공개 장면 없음 |
| 기술 | 공용 기술 풀에서 고른 12개(채찍·내려찍기·돌진·균열·부채·잡기·잠행·추적·소환·해일·꼬투리·박동) | 개수가 많고 시그니처가 없다. 2D 시트 시절 기술 재활용 |
| 페이즈 | 목숨마다 몸을 100→85→70%로 **균일 축소** | 전환할수록 작고 약해 보인다 — 레퍼런스와 반대 방향 |

결론: 사용자 §16 판정("마른 노인")과 "첫 보스 임팩트"는 **같은 몸 하나로는 동시에 만족할 수 없다.** 노인은 마른 채로 두고, 보스 덩어리는 노인 바깥의 다른 층에서 만든다 — A안의 출발점이다.

### 6.2 등장 (크기 공개, 4초)

1. 아레나 진입 → 가운데 제단에 **노인(2.7m)이 등을 돌리고 무릎 꿇고 있다**. 영웅과 비슷한 크기라 "이게 보스?"로 읽힌다.
2. 일어서며 대사 "새 거름이 떨어졌군."(기존 STY-12 그대로).
3. 지팡이로 바닥 3번(기존 P1 진입 연출) → 아레나 뿌리 기둥 4개가 솟고, 동시에 **바닥 뿌리가 노인을 감아 올려 5.2m 껍질이 된다**(1.6초). 카메라는 보스전 줌 0.80 유지, Cinemachine으로 0.6초 뒤로 물러났다 돌아옴.
4. 껍질 두개골 눈에 불 → 조작 회복. 전체 4초 이내, 등장 중 무적(현행 "start" 이벤트 구간).
